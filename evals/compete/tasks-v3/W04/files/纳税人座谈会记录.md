# 纳税人缴费人座谈会记录（9月18日下午，区税务局四楼会议室）

参加：区工商联推荐的企业代表4人，个体工商户2人，纳服中心3人。

发言要点（记录人手记，口语）：
- 制造企业财务（周女士）：留抵退税这次到账很快，申请了三天就到了，比去年快多了。但是政策口径变得快，希望有个微信群，实时推送。
- 建筑企业（吴先生）：跨区域涉税事项报告还是要跑几次，能不能全程线上。
- 商贸个体户（老陈，60多岁）：电子税务局弄不来，孙子不在家的时候只能跑办税厅，希望窗口再多几个、字再大点。
- 餐饮个体户（小韩）：午休时间办得上很方便，建议周六也上班。
- 物流企业（葛先生）：发票领用额度调整，等了两天，觉得有点慢。
- 科技公司（刘女士）：“税费服务进园区”来过一次，讲得很实用，希望每季度都来。
- 纳服中心回应：周六办税目前人手不够，可以先试行预约办；微信群正在筹备。
