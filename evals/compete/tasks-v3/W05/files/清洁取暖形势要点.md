# 全市冬季清洁取暖形势要点（市住建局提供，内部）

## 去年采暖季（2025年11月—2026年3月）情况
- 全市清洁取暖改造累计完成3.1万户，清洁取暖率达到78.5%。
- 去年冬天因气源紧张，出现过2次局部限供，分别在12月中旬和1月下旬，涉及3个县区的部分小区。
- 因供暖问题接到群众投诉共612件，已全部办结。
- 发生一氧化碳中毒事件1起（未造成死亡），原因是农户自行封闭烟道。

## 今年任务
- 2026年计划改造4.2万户：其中“煤改气”2.3万户、“煤改电”1.4万户、接入集中供热0.5万户。
- 截至10月20日，已完成1.8万户（煤改气1.1万户、煤改电0.5万户、集中供热0.2万户）。
- 供暖期从11月15日开始，到明年3月15日结束。
- 补助标准：煤改气设备及安装补助2600元/户，煤改电补助6800元/户；运行补贴的具体标准市财政还在研究，暂不对外讲。
- 全市困难群众（低保、特困）需兜底保障供暖的3600户。

## 今年要抓的五件事（住建局建议）
1. 倒排工期，加快剩余改造，确保11月10日前全部完工；
2. 落实气源和电网保障，提前签好供气合同，电网配变增容；
3. 抓质量和安全，每户安装一氧化碳报警器，严查施工质量；
4. 兜底保障困难群众，做到应保尽保；
5. 严管散煤，设立检查卡点，同时抓督导考核，通报排名。
