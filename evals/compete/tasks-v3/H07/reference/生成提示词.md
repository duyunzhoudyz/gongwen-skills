# 事实单：青峰县文化馆公众号稿件——非遗剪纸进校园活动

- 单位：青峰县文化馆；活动：“非遗剪纸进校园”启动仪式暨首场体验课；时间：2026年10月14日上午；地点：青峰县第二小学。
- 参加人员：青峰县第二小学三、四年级学生320名，教师18人，县文化馆工作人员6人。
- 授课人：省级非遗代表性传承人薛某某，从事剪纸创作41年，作品曾入选省级民间艺术展。
- 活动内容：薛某某先讲解青峰剪纸的历史（已有200多年）和“窗花、喜花、礼花”三大类，再现场教学，学生用1个半小时剪出“喜鹊登梅”图案；一名叫小雨的四年级女生第一次拿起剪刀，剪出了一只完整的喜鹊，说“原来剪纸一点都不难”。
- 后续安排：全县已有15所学校开设剪纸课，每周1节；2026年内计划再增加10所；11月5日起，学生作品240件在县文化馆一楼展厅展出，展期一个月。
- 县文化馆馆长孙某某表示，希望让更多孩子从小接触传统文化。
- 公众号：“青峰文化”；稿件署名：县文化馆宣传组。
