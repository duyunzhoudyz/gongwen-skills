# 事实单：云岭镇党委书记在全县党风廉政建设警示教育大会上的表态发言

- 发言人：云岭镇党委书记周某某；会议：青峰县2026年党风廉政建设警示教育大会，时间2026年10月20日。
- 云岭镇基本情况：辖14个行政村，常住人口3.8万人。
- 警示案例（县纪委通报）：邻乡某村原村委会主任吴某某，2022年至2025年间，利用负责惠农资金发放的职务便利，虚报冒领、侵占集体资金18.7万元，被判处有期徒刑三年，并被开除党籍。
- 对照反思：云岭镇2024年也发生过一起村干部违规发放补贴的问题，涉及资金2.3万元，已追回，相关责任人受到党内警告处分。
- 本镇已有基础：排查廉政风险点46个；梳理村级小微权力清单28项；2026年1至9月受理群众信访举报19件，办结17件，其余2件正在办理。
- 三项表态：一是带头守纪律，每季度召开1次党委专题会议研究党风廉政建设，每年带头讲廉政党课不少于2次；二是带头抓整改，12月底前实现14个行政村村务公开栏全覆盖，年底前办结剩余的2件信访举报；三是带头管队伍，对镇村干部每季度开展1轮谈心谈话，对苗头性问题早发现、早提醒。
- 结尾：自觉接受县纪委监委和群众的监督。
