# 事实单：丰宁市市场监督管理局放心消费示范创建工作汇报

- 汇报单位：丰宁市市场监督管理局；汇报对象：丰宁市人民政府；创建时间：2026年3月至10月。
- 工作目标：创建放心消费示范单位300家；实际已命名286家，完成率95.3%。
- 做法一，抓示范引领：在商超、餐饮、旅游景区三类场所开展创建；选取30家大型商超开展“线下无理由退货”试点，全市作出无理由退货承诺的经营者共412家。
- 做法二，抓投诉化解：在186个社区设置“消费维权服务站”，聘请消费维权志愿者93名；2026年1至10月受理消费投诉5362件，同比下降8.3%，办结率98.2%，为消费者挽回经济损失1470万元。
- 做法三，抓监管执法：开展“清风”行动，查处假冒伪劣、虚假宣传案件237件，罚没款合计386万元；公布典型案例12起。
- 存在问题：一是农村地区创建覆盖面偏低，已命名的286家中农村地区仅41家；二是线上平台经营者责任落实不到位，网购投诉占比达到47%；三是消费维权志愿者培训不足，只有58名接受过系统培训。
- 下一步：2026年12月底前补齐剩余14家示范单位；在农村地区新增示范单位40家；2027年一季度完成全体志愿者培训。
- 联系人：市场监管局消费者权益保护科 刘某某。
