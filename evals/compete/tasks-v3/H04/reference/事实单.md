# 事实单：丰宁市司法局“小微企业法律体检”工作经验信息

- 单位：丰宁市司法局；工作名称：“小微企业法律体检”；起始时间：2025年3月。
- 工作基础：组建由48名律师和12名法律顾问组成的服务团；累计为620家小微企业提供法律体检；发现风险隐患1870条，整改完成1711条，整改率91.5%；为企业避免、挽回经济损失约3200万元。
- 做法一，“一企一档”：为每家体检企业建立法律风险档案，记录合同管理、劳动用工、知识产权、税务合规四类风险；档案由律师团队专人负责，每半年更新一次。
- 做法二，“体检报告+整改清单”：体检结束后7个工作日内出具体检报告，并列出整改清单，写明风险点、整改建议、完成时限；企业整改后，律师再核查一次。
- 做法三，“回头看”：体检满6个月后上门回访，核实整改落实情况；2026年已对210家企业开展回访，其中有19家企业发现新的风险点。
- 典型案例：北塘区青山食品加工厂有职工63人，体检时发现其中41人没有签订书面劳动合同，且加班费计算方式不合规；律师指导企业在一个月内补签合同，修订考勤和薪酬制度，避免潜在劳动争议赔偿约46万元。
- 下一步：2026年底前覆盖企业达到700家；探索将体检结果与金融机构授信挂钩。
