# 事实单：丰宁市统计局2026年第四季度统计工作要点

- 发文单位：丰宁市统计局；文种：工作要点；适用时间：2026年10月至12月。
- 总体情况：前三季度全市统计工作总体平稳，规模以上工业企业联网直报率达到100%。
- 重点任务一，抓好数据质量：10月下旬对9个县（区）开展数据质量抽查，每个县（区）抽取不少于12家企业；重点核查工业、批发零售业和服务业的“四上”单位，全市“四上”单位共1286家；责任科室：核算科、统计执法科。
- 重点任务二，做好年报工作：12月10日召开2026年统计年报布置培训会，参会人员约180人；年报联网直报系统12月20日开放，2027年1月15日前完成企业年报报送；责任科室：综合科、各专业科室。
- 重点任务三，加强统计执法：对30家存在迟报、拒报、虚报嫌疑的单位开展检查，其中已立案查处的统计违法案件4件；11月完成检查，12月底前处理结案；责任科室：统计执法科。
- 重点任务四，推进统计服务：编印《丰宁统计年鉴（2026）》，2027年1月底前出版，印数500册；10月25日前向市政府报送前三季度经济运行分析报告；责任科室：综合科、核算科。
- 重点任务五，强化队伍建设：11月组织一次业务技能培训，培训对象为各县（区）统计人员，共96人；12月举办一次统计知识测试。
- 保障措施：局长王某某为第一责任人，分管副局长李某某牵头协调；每月25日前各科室报送任务进展，由综合科汇总。
- 联系人：综合科 张某某。
