# 丰宁市统计局2026年第四季度统计工作要点

2026年第四季度，全市统计工作要紧紧围绕市委、市政府中心工作，坚持依法统计、依法治统，着力提高统计数据质量，扎实做好年报各项工作，不断强化统计执法监督，持续优化统计服务，切实加强统计队伍建设，为全市经济社会高质量发展提供坚实统计保障。前三季度，全市统计工作总体平稳，规模以上工业企业联网直报率达到100%，为完成全年目标任务奠定了良好基础。现就第四季度统计工作要点明确如下。

**一、抓好数据质量，夯实统计基础**

10月下旬，对9个县（区）开展数据质量抽查，每个县（区）抽取不少于12家企业。重点核查工业、批发零售业和服务业的“四上”单位，全市“四上”单位共1286家，确保源头数据真实准确、完整及时。抽查工作要坚持问题导向，对发现的数据异常、指标逻辑不符等问题，及时督促整改到位，切实防范统计造假、弄虚作假。责任科室：核算科、统计执法科。

**二、做好年报工作，确保有序推进**

12月10日召开2026年统计年报布置培训会，参会人员约180人，重点讲解年报制度变化、指标口径和填报要求，确保各填报单位准确理解、规范填报。年报联网直报系统12月20日开放，2027年1月15日前完成企业年报报送。各专业科室要加强年报期间的值班值守和业务指导，及时解答填报过程中的疑难问题，确保年报数据质量。责任科室：综合科、各专业科室。

**三、加强统计执法，严肃查处违法行为**

对30家存在迟报、拒报、虚报嫌疑的单位开展检查，其中已立案查处的统计违法案件4件。检查工作要坚持依法依规、程序规范，做到事实清楚、证据确凿、定性准确、处理恰当。11月完成检查，12月底前处理结案，切实发挥统计执法的警示震慑作用，维护统计法律法规权威。责任科室：统计执法科。

**四、推进统计服务，提升服务水平**

编印《丰宁统计年鉴（2026）》，2027年1月底前出版，印数500册，确保内容翔实、数据准确、编校规范。10月25日前向市政府报送前三季度经济运行分析报告，深入分析全市经济运行特点、存在问题和发展趋势，提出有针对性的对策建议，为市委、市政府科学决策提供参考依据。责任科室：综合科、核算科。

**五、强化队伍建设，提升业务能力**

11月组织一次业务技能培训，培训对象为各县（区）统计人员，共96人，重点围绕统计业务知识、数据处理技能和联网直报操作等内容开展培训，切实提高基层统计人员业务水平。12月举办一次统计知识测试，检验学习培训成效，营造比学赶超的良好氛围。

**六、强化保障措施，确保任务落实**

局长王某某为第一责任人，分管副局长李某某牵头协调，各科室要按照职责分工，细化任务措施，明确时间节点，确保各项工作落到实处。每月25日前各科室报送任务进展，由综合科汇总，及时掌握工作推进情况，协调解决存在的困难和问题，确保第四季度各项统计工作任务圆满完成。

联系人：综合科 张某某。
