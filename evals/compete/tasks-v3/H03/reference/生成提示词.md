# 事实单：丰宁市外卖骑手权益保障情况调研报告（摘要）

- 调研单位：丰宁市人力资源和社会保障局、丰宁市总工会联合调研组；调研时间：2026年9月8日至9月26日。
- 调研方式：发放问卷，回收有效问卷412份；召开座谈会6场；走访平台企业及站点5家。
- 基本情况：全市从事外卖配送的骑手约6800人，其中男性占86%，30至45岁占63%；骑手月均收入6180元。
- 主要问题：
  1. 劳动时间偏长：62%的骑手日均在岗超过10小时，其中15%超过12小时；
  2. 社会保障不足：仅37.4%的骑手参加了职业伤害保障或工伤保险，只有21%签订了书面协议；
  3. 权益维护渠道不畅：遇到纠纷后，仅有9%的骑手选择向平台申诉成功，多数“忍了”；
  4. 休息场所缺乏：全市现有骑手服务站点仅14个，平均每个站点服务约486名骑手。
- 对策建议：一是扩大职业伤害保障试点范围，争取2027年底前覆盖全部平台骑手；二是新建骑手服务站点20个；三是推动平台企业公开订单分配和超时处罚规则，保留人工申诉渠道；四是建立劳动纠纷“一站式”调解机制，由市人社局牵头。
