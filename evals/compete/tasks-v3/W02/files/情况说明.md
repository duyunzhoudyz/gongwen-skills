# 情况说明（文旅局办公室 小梁整理）

今年入汛以后连续强降雨，上面表里5处文物点都出了新险情，其中双龙桥和古城墙北段是省保，雨季过后又有位移，必须在上冻前处理。

经费情况：
- 年初县财政给局里安排的文物保护专项经费是280万元。
- 这280万里面，40万元已经用在县博物馆展陈提升上了，合同都签了，不能再动。
- 剩下的钱已经排满了日常巡查、消防设施维护，修缮上没有结余。
- 局长估了一下，缺口大概270万左右，让写个文请县政府帮着解决。

其他：
- 省文物局那边的以奖代补要明年才能申请，等不及。
- 联系人：局文物科 田国强（电话我没记，后面补）
- 文号等办公室编。
- 局长是邓海林，局里的全称：青峰县文化广电和旅游局。要报的是青峰县人民政府。
