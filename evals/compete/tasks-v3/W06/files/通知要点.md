# 治超专项行动 通知要点（局办公室 小潘 记）

- 背景：省交通运输厅10月中旬来了个关于冬季治超的通知（文号我没带，回头补），市政府领导已批示同意开展。
- 名称：丰宁市货车超限超载治理专项行动（暂定名）。
- 起止：2026年11月1日至12月31日，共分三个阶段：
  - 宣传发动：11月1日—11月15日
  - 集中整治：11月16日—12月20日
  - 巩固提升：12月21日—12月31日
- 重点领域（4个）：
  1. 高速公路出入口：全市境内4个收费站，重点“源头劝返”；
  2. 国省干线重点路段：设固定检测点和流动检测点，重点是进出矿区、砂石料场的路线；
  3. 货运源头单位：矿山、砂石料场、混凝土搅拌站、物流园区，前期已摸排63家；
  4. 农村公路和桥梁：限载限高设施补齐，重点是通行重型车辆的农村公路。
- 目标：全市公路货车超限超载率控制在0.5%以下，源头单位装载合格率100%。
- 措施：联合执法每周不少于2次；每月曝光1批典型案例；对严重违法的运输企业纳入失信管理。
- 牵头：市治超办（设在局公路管理科）。成员单位见领导小组名单。
- 经费：局里先垫付，具体金额还没定。
- 各成员单位要报一名联络员，目前都没报上来。
