# 事实单：北塘区人民政府关于表扬“9·3”强降雨防汛抢险先进集体和个人的通报

- 发文单位：北塘区人民政府；文种：通报；对象：全区各街道办事处，区政府各部门，各有关单位。
- 事件：2026年9月3日夜间，北塘区遭遇强降雨，24小时降雨量达到162毫米，为入汛以来最大；全区共转移群众1350人，未发生人员伤亡。
- 表扬决定：为表彰先进，决定对区水务局防汛抢险队、柳河街道办事处、北塘消防救援站3个集体和5名个人予以通报表扬。
- 先进集体事迹：
  1. 区水务局防汛抢险队：连续作战31小时，处置积水点23处，排出积水约9.6万立方米；
  2. 柳河街道办事处：2小时内组织转移老旧小区居民680人，无一人滞留；
  3. 北塘消防救援站：出动救援4次，营救被困群众27人。
- 先进个人（5人）：柳河街道办事处主任赵某某、区水务局科长孙某某、北塘消防救援站班长钱某某、柳河街道社区网格员周某某、区应急管理局干部吴某某。其中钱某某在营救被困老人时手臂受伤，仍坚持完成任务。
- 号召：各单位向先进学习，不松懈、不麻痹，做好后续防汛工作；汛期至2026年10月31日结束。
- 落款：北塘区人民政府；成文日期：2026年9月8日。
