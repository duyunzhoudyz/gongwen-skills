# H02 事实单

- 场合：2026年10月26日，云溪市在市职工文化中心召开全市技能人才表彰大会，云溪市人力资源和社会保障局局长罗某某讲话。
- 表彰对象：命名“云溪工匠”10名、技能标兵30名，表彰优秀技能人才培养单位12家。
- 现状：全市技能人才总量41.6万人，其中高技能人才11.2万人，占26.9%；2025年新增高技能人才1.3万人。
- 平台：已建成技能大师工作室15个。
- 政策：职业技能培训补贴每人每年最高3000元；2026年1月至9月，累计开展补贴性培训5.8万人次。
- 工作要求三点：一是培养，把技能人才的“蓄水池”挖得更大；二是使用，让技能人才在岗位上有舞台；三是待遇，让技能人才有地位、有尊严。
- 号召：在座的获奖者要带好徒弟，把手艺传下去。
