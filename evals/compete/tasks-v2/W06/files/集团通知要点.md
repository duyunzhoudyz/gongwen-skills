# 供水管网漏损治理攻坚行动——集团党委会/总经理办公会定下来的几条（办公室整理，还没成文）

名称：就叫“供水管网漏损治理攻坚行动”，由集团统一部署，各所属单位落实。

目标：集团漏损率（产销差）2025年底是 14.8%，到2027年3月底降到 12% 以下。

时间：2026年11月1日至2027年3月31日，分三个阶段：
1. 摸排阶段：11月1日—12月15日，摸清老旧管网底数，建好分区计量（DMA）台账；
2. 整治阶段：12月16日—2027年2月28日，集中改造、检漏、换表，春节期间暂停施工，具体日期以放假通知为准；
3. 验收总结阶段：2027年3月1日—3月31日，集团组织验收，评估漏损率。

四个重点领域：
1. 老旧管网：1995年以前铺设的铸铁管、镀锌管，优先改造；
2. 分区计量：建成并运行 DMA 分区，实现夜间最小流量监测；
3. 计量表具：大用户表和居民总表集中更换校验；
4. 抢修响应：漏点发现后抢修响应时限压缩，“城区4小时、郊区8小时到场”。

资金：专项资金 2400 万元，其中管网改造 1500 万元，计量设备 600 万元，检漏及监测系统 300 万元，从集团年度预算里列支。

要求：各单位“一把手”负总责；每月5日前报进展；考核结果跟年度绩效挂钩（怎么挂钩办公室还没细化）。
