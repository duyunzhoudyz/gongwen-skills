# 10月9日 企业座谈（县政务中心二楼，6家企业，我记的，比较乱）

人社局这边：科长，我，培训股小郑。

- 第一家（做竹制品的）：旺季订单多的时候招不到人，十月到春节前最缺，缺的是熟练工，年轻人不愿意进车间。希望搞个短期用工对接。
- 第二家（电子厂）：培训班教的东西和我们岗位对不上，学员来了还得重新教。建议培训前先问企业要什么。
- 第三家（餐饮连锁）：创业担保贷款是好政策，就是贴息到账太慢，平均一个半月，资金周转吃紧。
- 第四家（农业合作社）：乡镇劳动保障平台就一个人，又管社保又管就业，村里人来问找不到人。
- 第五家（物流）：社保系统和就业系统是两套，数据不通，招人备案要填两遍。
- 第六家（民营医院）：想招护理员，但本地培训的少，持证的更少。
- 小郑补充：订单班效果好，学员留下来的有八成左右（这个是他估的，没数据）。
- 科长：下一步想搞“企业点单、培训下单”，再把零工市场推到每个乡镇；贴息审核想压缩到一个月内。
