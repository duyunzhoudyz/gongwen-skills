# H08 事实单

- 报告单位与对象：云溪市消防救援支队，向云溪市人民政府报告高层建筑消防安全检查发现问题的整改情况。
- 检查：2026年9月1日至9月30日，对全市312栋高层建筑开展检查，发现问题隐患487处。
- 隐患分类：消防设施故障156处、疏散通道被占用121处、电动自行车违规停放充电98处、其他112处。
- 整改：截至2026年10月20日，已整改438处，整改率89.9%，尚有49处未整改完毕。
- 措施：约谈物业企业23家；行政处罚19起，罚款共18.6万元；对4处存在严重隐患的场所依法临时查封。
- 未整改原因：49处中，需更换消防水泵、消防控制室主机等设备的31处，等待业主大会表决维修资金的18处。
- 下一步：2026年12月15日前完成剩余49处整改；建立高层建筑“一楼一档”台账；11月起每月通报一次整改进度。
- 报告结构四部分：一、检查和整改总体情况；二、主要整改措施；三、尚未整改事项及原因；四、下一步工作。
