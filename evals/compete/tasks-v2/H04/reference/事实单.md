# H04 事实单

- 调研：南湖区住房和城乡建设局于2026年8月至9月，对全区24个老旧小区的物业管理情况开展调研，入户问卷860份。
- 收缴：24个小区物业费平均收缴率71.4%，最低的小区仅48%。
- 经营：15个小区的物业企业处于亏损状态；9个小区成立了业主委员会。
- 维修资金：有11个小区的住宅专项维修资金余额不足，不能满足电梯、水泵等设备大修需要。
- 投诉：2026年1月至9月，全区物业类投诉1260件，占12345热线受理总量的18.5%，投诉集中在保洁、维修响应慢和乱收费三方面。
- 建议四条：一是分类制定老旧小区物业收费指导价，每年公布一次；二是区级设立老旧小区物业托底补助，首批安排300万元；三是推动街道牵头、业委会和物业企业共同参加的“三方议事”机制，在24个小区全部建立；四是建立物业企业信用评价，评价结果每半年公布一次。
