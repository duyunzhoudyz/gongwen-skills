# 医保服务进园区 惠企便民“零距离”——云溪市医疗保障局开展“医保服务进园区”活动

2026年10月18日上午，云溪市医疗保障局“医保服务进园区”活动在云溪高新技术产业园举行。市医保局局长蒋某某到场，与医保局工作人员一同为园区企业和职工送政策、送服务、解难题。

上午9时许，云溪高新技术产业园内人头攒动，闻讯而来的企业职工和人事专员在服务台前排起了队伍。市医保局局长蒋某某来到活动现场，详细了解活动开展情况，并与前来咨询的职工亲切交流，听取大家对医保服务的意见建议。他表示，医保部门要主动靠前服务，把政策送到企业门口，把服务做到职工心坎上，让企业和群众少跑腿、好办事。

活动现场，来自市医保局的8名工作人员围绕职工医保政策咨询、异地就医备案、参保信息变更等高频事项，为园区14家企业的职工和人事专员提供“面对面”答疑、“手把手”帮办服务。工作人员耐心讲解医保政策要点，现场指导职工通过线上渠道办理业务，并发放《职工医保政策问答》手册1500份，帮助企业和职工更全面地了解医保政策、更便捷地享受医保服务。

“以前办一次变更要去大厅排队半天，现在在园区门口就办好了。”某电子企业人事专员周某某在办完业务后感慨地说。她表示，医保服务进园区活动把窗口搬到了企业身边，既节省了时间和精力，也让企业对医保政策有了更清晰的认识，真正解决了人事工作中的实际困难。

据统计，活动当天现场咨询和办理共420人次，其中办结异地就医备案168件、参保登记信息变更97件，切实为园区企业和职工提供了高效便捷的医保服务。

据了解，“医保服务进园区”活动是云溪市医疗保障局优化营商环境、提升医保服务效能的重要举措。下一步，市医保局将在此后每月举办一次活动，计划年内覆盖全市6个产业园区，持续推动医保服务向基层延伸、向企业靠近，让更多企业和职工在家门口享受到优质、高效、便捷的医保服务。
