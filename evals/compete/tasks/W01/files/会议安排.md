# 第四季度安全生产工作会议安排

（清河区安全生产委员会办公室，下称区安委办。10月20日下午主任碰头会上定的，我先记在这儿）

## 基本情况
- 会议名称：全区第四季度安全生产工作会议
- 时间：11月5日（周四）上午9:00开始，预计开到11:30左右
- 形式：现场会议，不搞视频连线，会场就不设分会场了
- 召集：区安委办

## 参会范围
1. 各街道办事处：分管安全生产的负责人、安监办主任，每个街道2人
2. 区安委会各成员单位（一共26家）：分管负责人 + 安全生产科室负责人，每家2人
3. 重点企业：危化、燃气、建筑施工、道路运输四个行业，由各行业主管部门分别推荐，企业主要负责人参加。**这部分由行业主管部门去通知，咱们不直接发文给企业**
4. 区政府分管安全生产的副区长出席并讲话；区应急管理局局长作形势通报

## 议程（就三项）
1. 通报前三季度全区安全生产形势，剖析近期典型事故（区应急管理局）
2. 安排部署第四季度及元旦、春节期间安全生产重点工作（区安委办）
3. 区政府分管副区长讲话

## 回执
- 各单位把参会人员名单（姓名、职务）填好，**11月2日（周一）17:00前**报区安委办
- 不参会的单位也要回，写明原因，别不回
- 回执一个单位填一张就行，不用每人一张
