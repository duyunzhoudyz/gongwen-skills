# 全县冬春季森林防灭火工作部署会议——议程（县森防办拟，未最终定稿）

- 时间：2026年10月28日（周三）上午9:30
- 地点：县政府三楼第一会议室
- 主持：县林业局局长 郑明辉
- 参会：县森林防灭火指挥部成员单位负责人；各乡镇（街道）分管领导、林业站站长；县消防救援大队、县应急管理局、县公安局、县气象局等相关单位负责人
- 说明：县长在市里开会，不参加；由分管副县长陈建华代表县政府讲话

## 议程
1. 县林业局副局长王海通报去年冬春防火期火情情况和今年森林火险形势（约10分钟）
2. 县森林防灭火指挥部与各乡镇签订2026—2027年度森林防灭火责任书
3. 乡镇表态发言：石桥乡、柳河镇（各5分钟）
4. 县政府副县长、县森林防灭火指挥部副指挥长陈建华讲话
5. 主持人小结

## 备注
- 会议预计开到11:30，讲话部分控制在20分钟左右（稿子2500字上下，念起来差不多）。
- 会后各乡镇回去传达，11月1日防火期正式开始。
