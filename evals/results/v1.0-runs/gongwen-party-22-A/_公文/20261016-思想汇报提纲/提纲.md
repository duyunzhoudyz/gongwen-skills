# 思想汇报提纲和填写指引

本文件只有提纲和填写指引，不是成稿。思想汇报要写您自己的学习认识和思想变化：您把【待补】处的内容用几句话告诉我，我帮您整理成1500字左右的成稿。

## 一、提纲

```text
思想汇报

汇报时间段：【待补：按支部要求】

【待补：称呼】

一、这段时间学了什么
【待补：学习的材料名称、篇目，参加的党课、支部学习或活动；印象最深的一两句原文，原样抄来】

二、思想上有什么变化
【待补：读到、听到这些内容后本人是怎么想的；和以前相比，想法上有什么不同】

三、在学习和生活中怎么做的
【待补：本季度本人做的一件具体事：时间、什么事、本人做了什么、结果如何】

四、还有哪些不足
【待补：本人没做好的一件具体事，或老师、同学提过的意见】

五、今后怎么努力
【待补：具体、可检验的打算：做什么、什么时候、做到什么程度】

汇报人：【待补：姓名】
【待补：汇报日期】
```

## 二、填写指引

建议篇幅按总字数1500字分配，是结构上的建议，不是素材。

| 部分 | 建议篇幅 | 需要本人提供的事实 | 句式（空白处填您自己的情况） |
|---|---|---|---|
| 一、学了什么 | 约250字 | 材料名称、篇目或活动名称；印象最深的一两句原文（原样抄来，不凭记忆） | 这个季度，我参加了____，学习了《____》，其中“____”这句话让我印象最深。 |
| 二、思想变化 | 约400字 | 读到、听到之后想到了什么；和以前相比哪里不一样（大白话几句即可，是您自己的想法就行） | 以前我觉得____，学了这些之后，我想到____。 |
| 三、怎么做的 | 约450字 | 本季度学习或生活中的一件具体事：时间、什么事、您做了什么、结果如何 | ____月，在____（课程、实践、宿舍或班级活动）中，我____，结果____。 |
| 四、不足 | 约200字 | 一件没做好的具体事，或老师、同学提过的意见（尽量用原话） | 在____方面，我____（具体表现），造成____。 |
| 五、打算 | 约200字 | 下一步做什么、什么时候、做到什么程度 | 下个季度，我打算____，____前做到____。 |

提醒本人：

1. 写您自己的事。“深刻认识到”“收获很大”这类放在谁身上都成立的话，换成一件具体的事或一句您当时的真实想法。
2. 引用的原文要原样抄，并注明出处（文件或书名、篇目）；记不清的先空着，不要凭印象写。
3. 事例里涉及同学、老师的，写“某同学”“某老师”；学号、成绩、家庭情况不写进汇报，也不要发给联网模型。
4. 举不出事例的部分先空着，不要硬凑；第三、四部分至少各有一件具体的事。
5. 称呼、落款和是否手写，按支部的要求或您上一季度交过的稿子。
6. 填好后发来，我帮您整理成1500字左右的成稿：语句理顺、语气往积极上靠，内容仍用您提供的。

也可以先只回答三个问题，不用写成文章：

1. 这个季度您学了什么？材料或活动的名称、篇目，印象最深的一两句原文（原样抄来）。
2. 读完、听完之后您自己是怎么想的？和以前比，想法上有什么不一样？
3. 这个季度有没有一件具体的事，能说明您是怎么做的，或者哪里没做好？时间、什么事、您做了什么、结果怎样。
