工业园区污水处理工艺改造
——环境科学与工程学科水污染控制团队社会服务典型案例

一、服务背景
【待补：该园区污水处理面临的突出问题和实际需求，须与园区管委会应用证明的表述一致】

二、主要做法
2021年起，环境科学与工程学科水污染控制团队为某市某工业园区设计污水处理工艺改造方案，团队派出3名教师、6名研究生驻点开展技术服务。
【待补：方案的核心技术路线和创新点，驻点服务的具体内容和时间，团队依托的本学科研究基础；某市某工业园区的具体名称，按填报要求决定是否隐去】

三、服务成效
改造后，园区出水水质稳定达标，园区管委会已出具应用证明（佐证材料1）。【待补：执行的排放标准、处理规模、达标持续时间，须与应用证明一致】
该方案被某省生态环境厅采纳（佐证材料2）【采纳证明尚在开具，取得之前请勿报送这一句】。

——以下是说明——

一、这类案例一般怎么写

社会服务典型案例的核心是回答一个问题：学科的专业能力，解决了谁的什么实际问题，有什么可以证明的结果。一般按这样的顺序写：
1. 服务背景：服务对象有什么需求或困难，为什么需要你们学科来做。
2. 主要做法：学科团队具体做了什么，用了什么技术或方法，派了多少人、做了多久，要讲清楚学科的专业贡献在哪里，不要写成项目流水账。
3. 服务成效：解决了什么问题，达到什么结果，最好有量化数据，每一条成效都要有对应的佐证材料。
4. 学科支撑：这件事和学科的研究方向、平台、人才培养怎么挂钩（研究生参与服务也可以在这里体现）。

写法上，每一句话都要能找到证明材料，用事实和数据说话，少用"显著""大幅""有力"这类形容词。字数、格式、佐证材料的要求，以教育部学位中心当次发布的填报说明为准，我这里没有这份说明，没法替您核对。

二、这份素材要特别注意的几处

1. "为企业节约运行成本上千万元"：只有负责人口头说，没有书面证明，我没有写进稿子。建议请园区管委会或相关企业出具书面证明，最好带上测算依据（改造前后的运行成本对比），拿到了再写；拿不到就不写，写了反而会让整份案例的可信度打折。

2. "方案被省生态环境厅采纳"：采纳证明还在开具，我写进去了，但加了标注。证明拿到之前不要报送这一句，拿到后要核对证明上的表述（是"采纳""参考"还是"采用"），稿子里的用词要和证明一致。

3. 负责人调入前的流域治理项目：不建议写进这个案例。学科评估看的是本单位、本学科的贡献，成果一般要属于本校本学科、有本校署名，调入前在原单位完成的项目不能算本校的成果，写进去有成果归属不清的风险（具体以当次填报说明为准）。而且这个案例本身就是水污染控制团队为园区做的改造，把另一个流域项目掺进来，主题也不聚焦。如果负责人确实想体现这段经历，可以放在他个人的简介里，但要写明是调入前的工作。

4. 时间线有一处要核实：素材写团队工作"2021年起至今"，负责人是2023年才从外校调入的。也就是说2021到2023年这个项目是谁牵头、团队里有谁，需要弄清楚。稿子里我没有写负责人，也没有写"负责人带领团队从2021年开始"，就是为了避免这个矛盾。负责人姓名和职称等定稿时再补。

5. 成效要和证明对上：我写"出水水质稳定达标"，依据是素材里说园区管委会已出具应用证明。请对照证明原件，确认证明里确实有"达标"的表述；"稳定"要有时间跨度，最好补上执行的排放标准和达标的时间段。

6. 其他：驻点的3名教师和6名研究生，是否需要写姓名，要看填报要求；案例里的"某市某工业园区"，是实名还是匿名，也看填报要求，但佐证材料上的名称要和案例一致。

三、您接下来需要补的

园区的背景和需求、工艺方案的核心技术点、处理规模、排放标准、达标时间段、应用证明和采纳证明的原件。这些补齐，案例才算完整；现在稿子里【】标出的位置就是这些。
