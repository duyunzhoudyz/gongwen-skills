# 提纲与填写指引：期中表彰大会学生代表发言

## 任务卡

- 讲话类型：代表发言（学生代表）
- 场合：初中期中表彰大会，下周（具体日期待补）
- 讲话人：初二年级的一名女生（姓名、班级待补，稿中用代称）
- 听众：全校师生（家长、来宾是否到场待补）
- 时长：3分钟，按每分钟约200字，约600字（540～660字）
- 素材可支撑：0字。用户没有提供发言人本人的任何经历和感受，所以本轮只出提纲和填写指引，不出完整正文
- 议程位置：待补（发言排第几项，前后有谁讲）
- 稿子用法：讲的稿（学生口头讲，会后一般不印发）
- 角色模式：教学模式（没有单位画像，也没有其他识别信号，按默认）

## 骨架与字数

| 部分 | 约字数 | 约时长 |
|---|---|---|
| 一、称谓、身份和心情 | 80 | 24秒 |
| 二、本人的经历 | 300 | 90秒 |
| 三、体会 | 80 | 24秒 |
| 四、打算 | 100 | 30秒 |
| 五、致谢（可省） | 40 | 12秒 |
| 合计 | 600 | 3分钟 |

经历占一半，因为听的人记得住的是具体的事，不是道理。

## 填写指引

请发言的同学自己说，说给班主任或你听，边说边记几句就行，不用写成文章。每部分的素材到了，我按3分钟（约600字）成稿，用她自己的口吻。

### 一、称谓、身份和心情（约80字）

- 写什么：称谓；她是哪个班的；代表谁发言；此刻心情一句。
- 请提供：
  1. 班级，如“初二（几）班”；
  2. 发言身份：受表彰同学的代表，还是全体同学的代表；
  3. 表彰项目的名称（以学校表彰决定为准）；不要提供分数和名次；
  4. 她此刻真实的心情，一两句她自己的话。

### 二、本人的经历（约300字，一两件事）

- 写什么：这个学期（期中前后）她自己做的一两件具体的事，写清时间、经过、当时怎么想。
- 请提供（每件事）：
  1. 时间：哪个月、哪段时间；
  2. 经过：发生了什么，她做了什么；
  3. 当时的想法：遇到什么困难，心里怎么想；
  4. 后来：事情怎么样了。
- 提示：一件写透，比两件写浅好。帮过她的老师、同学用“数学老师”“同桌”这样的称呼，不写姓名。

### 三、体会（约80字）

- 写什么：从上面的经历里，她自己体会到的一两句话。
- 请提供：她自己的话，哪怕只有一句。我只帮她理顺，不替她“升华”。

### 四、打算（约100字）

- 写什么：接下来她自己做得到的两三件小事。
- 请提供：她想做的具体的事，比如想改掉的一个习惯、想坚持的一件事、想帮同学做的一件事。不写分数、名次和升学目标，不替学校、老师表态。

### 五、致谢（约40字，可省）

- 写什么：感谢谁。
- 请提供：想感谢的老师、同学、家长的称呼（不写姓名）。

## 还需要的大会信息

1. 大会的全称、日期（你说“下周”，具体哪天定了告诉我，我不推算）、她发言排第几项。
2. 到场的人：校领导、老师、同学，有没有家长或来宾。没有名单的，称谓用“老师们、同学们”。

## 来不及问她本人时

可以先由班主任口述两三件她平时真实的表现，我据此写初稿；写成第一人称的内容，请她本人过目确认，有出入的按她的意思改。

## 个人信息

发来的素材里，姓名、学号、分数、家庭情况请先去掉，用“某某同学”“数学老师”代替；稿中同学、老师都用代称，定稿时由你换回，并确认已取得本人同意。
