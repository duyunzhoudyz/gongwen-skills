# 提纲：基层报表负担调研提纲与调研报告框架

本文件分四部分：一、标题备选；二、调研提纲（下周带去用）；三、调研报告框架（调研完按记录填）；四、调研后需要收集的记录，以及报表清单样表。

本文件没有写任何调研发现和结论。调研报告必须基于调研记录，调研前不预写；调研结束后，把座谈记录、访谈记录、问卷结果、实地察看记录、数据表发来，按记录成稿。

## 一、标题备选（报告成稿时用）

1. 关于我县3个乡镇基层报表负担情况的调研报告（平实式，调研前占位用）
2. 摸清基层报表填报情况——关于我县3个乡镇基层报表负担的调研报告（主副标题式，推荐；主标题只写调研要做的事，不写结论）

调研完以后，可以按记录里的发现把主标题改成对仗式或数字概括式。要多套标题比较的，可以转 gongwen-title（专门做标题的 skill）。

## 二、调研提纲

```text
关于基层报表负担情况的调研提纲

一、调研目的：摸清3个乡镇日常填报的报表有哪些、由谁布置、多久填一次、每次用多长时间、有没有重复填报，为领导研究基层报表管理提供依据。
   【待核实：以领导交办的原话为准，请向交办领导确认后修改】

二、调研对象：3个乡镇【待补：乡镇名称】。每个乡镇分三类人：
   （一）乡镇分管领导、党政办（综合办）负责人，了解整体情况；
   （二）一线填报人员，包括乡镇机关干部、站所人员；
   （三）村（社区）干部。
   另外走访报表的主要布置部门（县直部门等）【待补：走访哪几个部门，由领导确定】。

三、调研方式
   1. 座谈：每个乡镇分开开两场，一场管理层，一场一线填报人员。分开开，一线人员更愿意讲实话。
   2. 个别访谈：每个乡镇请几名填报人员，当场翻出最近填过的报表，边看边问。
   3. 调阅资料：看乡镇现有的报表台账、群里和系统里的报表通知。
   4. 调研组自己的安排：轻车简从，不要求乡镇准备汇报材料，不要求乡镇另外填表，不让这次调研给基层增加新的负担。
   5. 不以调研之名行督查检查考核之实（《整治形式主义为基层减负若干规定》第7条）。

四、时间安排：下周【待补：具体日期和3个乡镇的先后顺序，由领导确定】

五、调研问题（一个问题只问一件事，问得出事实；不预设结论，不问“您对报表满意吗”这类只能答是或否的问题）
   （一）面向乡镇分管领导、党政办（综合办）负责人
      1. 2026年以来，乡镇每月、每季度、每年各要向上报送哪些报表？请按布置部门列出来。
      2. 这些报表通过什么渠道布置和报送（业务系统、邮件、微信群、纸质）？
      3. 有没有同一项数据要向不同部门重复报送？请举最近一次的例子。
      4. 乡镇里由谁统一管理报表填报？报表怎么分配给各站所和村（社区）？
      5. 临时布置的报表，一般给多长时间？最近一次是哪张表，给了多长时间？
      6. 各岗位每周大概有多少时间用在填报报表上？
      7. 哪些报表可以合并、减少，或者从系统里直接取数？请说具体是哪几张。
   （二）面向一线填报人员（乡镇机关干部、站所人员、村（社区）干部）
      1. 上个月您填过哪几张表？每张表从接到通知到报出去，各用了多长时间？
      2. 这几张表里，哪一张最费时间？时间主要花在哪个环节（找数据、核对、重复录入、反复修改）？
      3. 有没有同一项数据要在不同的表里填写多次？请举一个例子。
      4. 有没有被要求同时报纸质版和电子版的报表？是哪几张？
      5. 这些表里的数据，哪些可以从系统里导出，哪些只能手工统计？
      6. 一周下来，您大概有多少时间用在填报报表上？
      7. 如果让您改一张表，您想改哪一张，怎么改？
   （三）面向报表的布置部门（县直部门等）
      1. 贵部门向乡镇布置了哪些固定报表？各依据什么文件布置？
      2. 这些报表里的数据，哪些可以从已有的系统获取，或者与其他部门共享？现在实际怎么做？
      3. 布置新报表之前，有没有与其他部门核对、去重的做法？如果有，具体怎么做？
      4. 乡镇报上来的数据，用在了哪些地方？

六、需要收集的数据和资料
   1. 3个乡镇2026年以来接收的报表清单：表名、布置部门、报送频次、填报时限、报送渠道、是否与其他表数据重复（样表见本文件第四部分）。直接取乡镇现有的台账；没有现成台账的，请乡镇口头列举，由调研组当场记录，不要求乡镇另行填表。【待核实：时段以领导确定为准】
   2. 乡镇近期收到的报表通知原文或截图，作为个案。
   3. 县里关于报表管理、数据共享的文件，以及已有的系统情况。

七、调研时可以对照的规定（要点来自工具内置资料，请核对原文）
   1. 第8条：不得频繁要求基层填表格报材料；压缩提供材料的文字量。
   2. 第12条：能通过系统生成或共享获取的数据材料，不再要求基层报送；同类材料最多报一次；不得再要求重复报送纸质材料。
   （均出自《整治形式主义为基层减负若干规定》。对照点：报表是不是被频繁要求、同一数据是不是要报多次、能从系统取的数据是不是还要人工填、是否同时要求纸质和电子。）
```

调研时的记录要求（后面写报告靠它）：

1. 每场座谈、每次访谈单独记一份，写清时间、地点、参加人员的乡镇和岗位，姓名用“某某”代替。
2. 四种内容分开记，不要混在一起：数据（照录，问清口径）；直接观察（调研组亲眼看到的，如当场打开系统演示填报过程）；受访者说法（谁说的、什么岗位、原话要点）；调研组判断（回来后再写，不记在现场记录里）。
3. 数据当场问口径：统计时段、报表口径、计量单位。

## 三、调研报告框架（调研完按记录填）

```text
关于基层报表负担情况的调研报告（标题见第一部分）

开头：调研时间、组织者、调研对象、方式、样本数量（调研后按记录填写）
   惯用写法：×月×日至×日，调研组采取……方式，赴……开展调研。现将调研情况报告如下。

一、基本情况（调研后按资料填写：现状数据、主要做法）
二、主要问题（每个问题对应调研记录中的出处）
三、原因分析（写调研中了解到的原因，区分受访者说法和调研组判断）
四、对策建议（每条建议对应一个问题，写清谁来做、做什么、何时完成）
```

各部分怎么填：

| 部分 | 取自哪类记录 | 怎么写 | 常见失误 |
|---|---|---|---|
| 开头 | 调研通知、行程安排、座谈签到表 | 写实际发生的：何时、谁带队、去了哪3个乡镇、开了几场座谈、访谈几人、调阅了哪些资料；缺的标【待补】 | 把计划写成已经发生的 |
| 一、基本情况 | 乡镇报表台账、数据表、座谈记录 | 数据照录并注明口径和时段；直接观察写“调研组在某乡镇看到……” | 把受访者说的数当成统计数 |
| 二、主要问题 | 座谈记录、访谈记录、问卷、实地察看记录 | 每个问题写清表现和出处；受访者说法写“某乡镇多名受访人员反映……”，注明人数或范围，不写成定论 | 以偏概全，写成“普遍” |
| 三、原因分析 | 座谈记录、对布置部门的访谈记录 | 写调研中了解到的原因，分清“受访人员认为”和“调研组分析” | 凭经验推测原因 |
| 四、对策建议 | 前三部分和访谈中受访人提出的建议 | 一条建议回答一个问题；写清谁来做、做什么、何时完成；可以用“建议” | 建议与问题脱节，或只有“加强统筹协调”这类空话 |

写法对照（空格由记录填，数字没有记录的标【待补】）：

- 误：基层干部普遍反映同一项数据要重复填报。（记录中只走访了3个乡镇）
- 正：走访的3个乡镇中，有__个乡镇的__名填报人员反映，同一项数据要在__张表里重复填写。
- 误：该报表每次要花一天时间。（这是受访者的说法）
- 正：__名受访填报人员反映，该报表每次约用时__小时【待核实：以乡镇填报记录为准】。
