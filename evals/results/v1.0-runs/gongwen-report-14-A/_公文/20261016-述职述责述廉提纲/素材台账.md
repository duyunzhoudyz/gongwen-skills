## 三、缺口清单（与提纲对应，与起草说明“附：填写指引”一致）

| 提纲部分 | 还缺的事实 | 一般去哪里找 |
|---|---|---|
| 标题、开头、落款 | 姓名、任职起始时间、述职年度、分管的具体科室 | 任职文件、分工文件 |
| 一（德） | 全年参加的学习（名称、次数）、讲课或学习体会题目 | 学习记录、会议通知 |
| 二（能） | 解决过的一两件难题、新掌握的业务、证书 | 工作日志、培训记录 |
| 三（勤） | 值班、加班、牵头的急难任务（时间、事项） | 值班表、工作日志 |
| 四（绩） | 财务线、后勤线各1～2件本人牵头或主办的事：事项、本人角色、做法、结果数据 | 预算执行报表、专项资金台账、审计整改台账、办公用房和公务用车台账、项目档案、会议纪要 |
| 五（述责） | 落实“一岗双责”的具体动作：开过的会、谈过的话、查过的问题、整改结果 | 党组会和局长办公会纪要、廉政谈话记录、风险点排查表 |
| 六（廉） | 遵守廉洁规定的具体做法；个人有关事项报告情况；本人确认的表态 | 个人有关事项报告回执、礼品礼金登记、自查记录 |
| 七（不足） | 本人真实的1～3个不足，最好有事例 | 民主评议反馈、审计和巡视反馈、自我检查 |
| 八（努力方向） | 与不足对应的改进做法 | 由本人确定 |
