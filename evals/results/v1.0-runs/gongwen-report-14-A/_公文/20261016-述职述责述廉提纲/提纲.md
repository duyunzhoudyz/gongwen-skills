# 述职述责述廉报告：提纲

状态：框架稿，只有结构和字数分配，不含任何事实。本人事例补齐后再成稿。
对象：某区某局副局长，分管财务、后勤。
说明：述职年度、形式、栏目、字数，以组织部门、纪委监委的通知为准；通知未提供，下列按通用栏目搭。

## 标题备选

1. 平实式（推荐）：某区某局副局长2026年度述职述责述廉报告
2. 署名式：某区某局副局长【待补：姓名】2026年度述职述责述廉报告

述职类材料默认用平实式，不用主副标题。

## 提纲

约3000字（书面述职述责述廉合并不超过3500字，工具约定；现场口头述职按时长另算，约200字/分钟）。

称谓：各位领导、同志们：（现场述职用；书面报送可省）

开头（约100字）：岗位、任职时间、分管工作（财务、后勤）。依据：待补本人信息。

一、政治素质和思想作风（德）（约150字）。依据：待补，本人参加学习、讲课的事实。

二、履职能力（能）（约150字）。依据：待补，本人解决的难题、新掌握的业务。

三、工作作风和勤勉敬业（勤）（约150字）。依据：待补，本人出勤、值班、牵头的急难任务。

四、主要工作实绩（绩）（约1550字，占全文一半以上）
（一）财务管理方面：本人牵头或主办的1～2件事（约700字）。依据：待补，每件写事项、本人角色、做法、结果数据。
（二）后勤保障方面：本人牵头或主办的1～2件事（约700字）。依据：同上。
（三）其他本人牵头或承办的工作：0～1件（约150字，可选）。依据：同上。

五、履行管党治党责任情况（述责）（约300字）。依据：待补，本人落实“一岗双责”的具体动作。栏目名称以通知为准。

六、廉洁自律情况（述廉）（约250字）。依据：待补，本人确认的具体做法，表态由本人确认后再写。栏目名称以通知为准。

七、存在的不足（约150字）。依据：待补，本人真实的1～3个不足，最好有事例。

八、下一步努力方向（约150字）。依据：与第七部分的不足一一对应。

结尾：以上述职，请予评议。

落款：某区某局副局长【待补：姓名】；日期【待补：具体日期】。
