# 提纲：在2026级新生开学典礼上的讲话

## 任务卡

```text
任务卡
讲话类型：典礼讲话（开学典礼）
场合：2026级新生开学典礼（学校体育馆）
讲话人：校长
听众：全体新生、新生家长代表
时长：10分钟左右，按每分钟约200字，约2000字
素材可支撑：约600字（预估）；成稿后实测557字，约2.8分钟
议程位置：材料未给议程，按“典礼上只有这一篇校长讲话”处理
稿子用法：讲的稿（校长看稿讲，会后不印发）
角色模式：教学模式（“我刚到校办”“告诉我为什么这么写”）
```

## 骨架与字数

骨架：典礼讲话骨架——称谓、问候和祝贺、具体的人和事、希望、祝福。

| 部分 | 内容 | 台账序号 | 现稿字数 | 补料后目标字数 |
|---|---|---|---|---|
| 称谓和问候 | 亲爱的同学们，各位家长；欢迎 | 1 | 29 | 约100 |
| 新生情况 | 录取人数、28个省份（本科）、最小和最大年龄 | 2—4 | 104 | 约200 |
| 具体的人和事 | 王某同学暑假支教；校友事例【待补】 | 5、9 | 73（校友段只有引子） | 约700（王某约250，校友约400） |
| 学校的事 | 新图书馆（24小时自习区800座）；本科新生配学业导师 | 6、7 | 108 | 约250 |
| 三个希望 | 学会自己安排时间；多读书；少刷手机 | 8 | 199 | 约600 |
| 祝福 | 一句祝福，致谢 | — | 44 | 约100 |
| 合计 | | | 557（约2.8分钟） | 约2000（10分钟） |

现稿与目标差距约72%。差距来自素材：材料里没有校友事例，校长的意思只有三个短语，学校和新生的事实只有几条。

## 待补清单

1. 署名行：校长姓名。
2. 日期行：典礼具体日期。
3. 具体的人和事：校友事例（人物、毕业年份和专业、经过、结果），需真实、可核实、已征得本人同意。
