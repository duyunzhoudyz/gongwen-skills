# 提纲：在春季开学典礼上的讲话

## 任务卡

```text
任务卡
讲话类型：典礼讲话（小学春季开学典礼）
场合：春季开学第一天早上8:00，学校操场，升旗仪式之后
讲话人：校长
听众：一到六年级全体学生和老师
时长：5分钟，按每分钟约200字，约1000字
素材可支撑：约400字（预估）；成稿后实测383字，约1.9分钟
议程位置：升旗仪式之后，材料没有给其他议程，按“只有这一篇校长讲话”处理
稿子用法：讲的稿（校长看稿讲，会后不印发）；给小学生听，整句不超过25字
角色模式：转译模式（推断：德育主任兼写，“不太会写这种稿子”）
```

## 骨架与字数

骨架：典礼讲话（小学）——称谓、问候、具体的人和事、希望、祝福。小学版把“希望”写成三件做得到的小事。

| 部分 | 内容 | 台账序号 | 现稿字数 | 补料后目标字数 |
|---|---|---|---|---|
| 称谓和问候 | 亲爱的同学们，老师们；早上好；欢迎回到学校 | 1 | 33 | 约100 |
| 学校的变化 | 走廊图书角（1200本书）、跑道重新铺过 | 2、3 | 83 | 约150 |
| 一件好事 | 三年级二班李某同学捡到钱包，和妈妈交给物业，失主送来感谢信 | 4 | 122 | 约250 |
| 校长的话（可选） | 校长对同学们的新学期期望；材料没有给，正文没有设占位，补料后再加 | — | 0 | 约150 |
| 三件事 | 走人行道、看红绿灯、课间不在走廊追跑，每件配一句孩子听得懂的理由或做法 | 6 | 117 | 约250 |
| 祝福 | 新学期快乐，平平安安 | — | 28 | 约100 |
| 合计 | | | 383（约1.9分钟） | 约1000（5分钟） |

现稿与目标差距约62%。差距来自素材：材料里只有两处学校变化、一件好事和三条安全提醒，校长想对孩子们说的话没有给。低年级孩子注意力短，三四分钟本身就合适，是否要补到5分钟，请您和校长商量。

## 本稿没有用的材料

“三年级数学在全区期末统考中排第一名，校长很高兴”：中小学讲话不讲成绩排名，没有写入，理由见起草说明。
