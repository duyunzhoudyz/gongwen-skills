判断：基层（街道）｜教学模式（推断）｜迎检汇报材料、自查报告、佐证台账三件（上行文）｜路线：汇报材料 gongwen-report → gongwen-direct → gongwen-humanize → gongwen-review → gongwen-format；自查报告和台账 gongwen-rectify → gongwen-direct → gongwen-review → gongwen-format

市里来督查，一般要备三样，具体项目以督查通知为准：
1. 迎检汇报材料：督查时汇报用，讲清做了什么、效果如何、有什么困难、需要上级支持什么。
2. 自查报告：对照检查标准逐项查自己，写清哪项做到了、哪项还差、怎么改。
3. 佐证台账：汇报和自查里每个数据、每个结论背后的记录和证据。三样的数据要对得上，台账里查得到。

三件事要走两个不同的模块，先从第一件汇报材料开始。这条路线每一站的作用：
1. gongwen-report：先把您的素材整理成台账，再搭提纲、成稿；数据只用您提供的，缺的标【待补】。您现在手上还没有具体素材，这一站会先出提纲和补料清单，补齐后再成稿。
2. gongwen-direct：把含糊、留后路的说法改成态度明确的写法。
3. gongwen-humanize：去掉机器腔，改成机关里通行的写法。
4. gongwen-review：按“八关”核稿，出问题清单；到这里会停下，等您处理完意见再往下。
5. gongwen-format：排成国标格式的 Word，放在最后，是因为前面改稿会打乱格式。

自查报告和台账交 gongwen-rectify：按检查细则逐项自查，台账随自查一起做，写“已完成”的项目要有佐证；后面几站同上。
