# 提纲：教学成效（学校自评报告第二类）

## 任务卡

```text
任务卡
文书：审核评估自评报告（学校版）第二类“教学成效”一章（第二类第几种未说明，不影响本章结构）
写给谁、用途：学校评估办领导审阅，先起草，统稿进学校自评报告
层级和主语：学校（评估办），“学校”
依据：教督〔2021〕1号；学校撰写说明未提供
篇幅：撰写说明未提供，本章字数【待补】；素材可支撑实写约140字（不含待补标记，预估），保障度、有效度和问题部分没有素材
数据基准：《本科教学状态数据分析报告》（2025学年）
角色模式：教学模式（用户说不熟悉评估材料写法）；自评报告需公示，叠加严谨模式
```

## 提纲

“教学成效”是第二类七个一级指标中的第7个，下设五个二级指标，按此顺序成节。

教学成效
- 一、达成度（台账1、2，实写约45字）
- 二、适应度（台账3，实写约37字）
- 三、保障度（无素材，整节待补）
- 四、有效度（无素材，整节待补）
- 五、满意度（台账4、5、8，实写约61字；台账9校友名单为“略”，未用）
- 六、存在的问题、主要原因及下一步改进措施（无素材，两个占位）

每节先放数据，数据后标时段和来源；材料没有的数据、举措、原因、措施一律标【待补】。台账6（就业指导中心90.2%）不进正文，进口径冲突表和“数据不一致情况说明”。
