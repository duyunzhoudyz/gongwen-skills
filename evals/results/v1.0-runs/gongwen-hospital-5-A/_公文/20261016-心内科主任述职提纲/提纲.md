## 二、给主任的填写指引

主任时间紧的话，先答A、B、D、F、G五项，约10分钟；也可以让主任口述，由科室秘书录音转成文字。每项写清三件事：做了什么、本人的角色、结果。本人的角色请用主任自己的话（牵头、主持、主刀、参与），没有的不写。

| 栏目 | 请主任补充 | 示例（格式示意，数字为×） |
|---|---|---|
| A 医疗质量与安全 | 本人牵头或主持的质量改进事项，至少1件 | 牵头修订科室××处置流程，××及时率由×%提高到×% |
| B 服务能力与DRG | 本人牵头开展或主刀的新技术、新亚专业；四级手术比例提高的原因 | 主刀开展××技术×例 |
| C 学科建设与人才 | 本人推动的亚专业、人才引进与培养；省自然科学基金项目是否由本人主持 | 本人主持省自然科学基金××项目，批准年度××年 |
| D 临床教学 | 本科生授课、带教、教学查房的学时或次数；是否研究生导师、指导硕士和博士各几名；住院医师规范化培训带教；教学奖项和教改项目 | 讲授××课程×学时；指导硕士×名、博士×名 |
| E 科室管理 | 本人主持的管理举措及结果 | 主持××改革，平均住院日由×天缩短到×天 |
| F 医德医风与廉洁自律 | 本人的具体做法和事例 | 拒收红包×次，参加医院警示教育×次 |
| G 存在的问题 | 哪项年度目标没完成；上级检查或考核指出过什么问题；哪项工作比计划慢 | ××指标目标×%，实际×%，原因为×× |
| H 下一步打算 | 与问题对应的打算和目标值 | 明年将××提高到×% |

## 三、数据写法提示

1. 科室成绩写科室，本人作用写本人。附件的数据都是科室数据，没有主任原话之前不写成“本人完成”。
2. 出院患者四级手术比例的变化用“个百分点”；CMI、平均住院日写差值，CMI不带百分号。
3. CMI写明口径。附件为卫生健康委DRG绩效评价口径；医保结算口径的数据另列，不比较、不相加。
4. 统计周期待确认：附件题名为“2026年”，现在是10月，请确认是全年还是截至某月。
