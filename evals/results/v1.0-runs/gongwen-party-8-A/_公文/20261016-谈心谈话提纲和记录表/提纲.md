## 二、谈心谈话提纲

三位委员各用一份，每次谈话前把谈话对象换成对应的委员，第三部分按各人的实际情况填写。

```text
谈心谈话提纲

谈话双方：【待补：谈话人职务】与【待补：谈话对象职务】
时间地点：【待补】
谈话目的：【待补：会前听取意见、日常思想交流或提醒】

一、交流思想
【待补：本人近期的工作和思想情况，准备谈的两三点】

二、征求意见
【待补：请对方提意见的两三个具体问题，如“我分管的____工作，你觉得哪里还不到位”】

三、指出问题
【待补：准备向对方指出的问题，只写本人掌握的具体事实】

四、交换意见
【待补：对改进工作的想法】
```

## 四、填写指引

| 部分 | 谈话前需要您准备的事实 | 谈话后填记录表时 |
|---|---|---|
| 谈话双方、时间地点 | 三位委员的职务；谈话安排 | 如实填实际谈话的时间和地点，没有谈的不填 |
| 一、交流思想 | 您近期的工作和思想情况，准备说的两三点 | 对方谈到的主要情况，按对方的原意记，不拔高、不概括成口号 |
| 二、征求意见 | 请对方提意见的两三个具体问题，例如：我分管的____工作，你觉得哪里还不到位；支部会前学习和组织生活会的准备，你有什么建议 | 对方提出的意见，一条一条照记，不合并、不弱化 |
| 三、指出问题 | 您掌握的具体事实：什么时候、什么事、造成什么影响。只写事实，不写“思想认识不足”这类评价，也不要拿工作建议代替批评意见 | 对方怎么回应，如实记，记不清的写“未记清” |
| 四、交换意见 | 您对改进工作的想法 | 本人的回应和打算；需要跟进的事项写清谁做、做什么、什么时候 |

提醒：

1. 谈话记录由谈话人如实填写，不补写没有谈到的内容；谈得不全的，记录里就只写谈到的部分。
2. 谈话时可以先用手机备忘录记要点，格式：谈话对象（职务）；时间地点；对方谈到的情况；对方提的意见（逐条）；我的回应；要跟进的事（谁、做什么、什么时候）。谈完把笔记发来，可以帮您整理，整理时只整理、不添加，记不清的地方标出来请您确认。
3. 笔记里涉及他人的批评意见和对第三人的评价，用职务或“张某”代称；涉及患者的，不写姓名、病案号、床号，写“某患者”。个人有关事项、处分情况不要写进笔记。
4. 会前谈心谈话的范围（支委之间，还是书记与全体党员）、是否要书面记录和签字、存档格式，以今年组织生活会通知和本单位的规定为准，记录表栏目与单位统一格式不同的，按单位格式。
5. 依据：支部委员之间、委员和党员之间、党员和党员之间，每年谈心谈话一般不少于1次，要坦诚相见、交流思想、交换意见、帮助提高（《中国共产党支部工作条例（试行）》第十九条）；组织生活会会前要学习、谈心谈话、听取意见（同条例第十七条）。以上条款来自工具内置资料，请核对原文。
