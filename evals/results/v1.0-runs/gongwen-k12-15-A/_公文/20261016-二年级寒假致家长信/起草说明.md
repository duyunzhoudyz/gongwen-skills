【起草说明】

一、所作假设

1. 您说刚入职，本稿按教学模式处理，任务卡和结构说明写在末尾的写作要点里。
2. 写给本班家长，用信函体：称呼“尊敬的家长”，落款写学校、班级、班主任和日期。
3. 学段为小学二年级，按义务教育阶段处理。
4. 篇幅按默认的一页以内（800～1200字）。实际 771 字（含标点、标题和落款，不含【待补】标记）。
5. 七项安全提醒和三项作息与锻炼的具体做法，按通用安全常识写，不含数据和政策表述。学校有统一的安全告知书，或对作息、联系方式另有要求的，以学校的为准，增删对应条目。
6. 没有加回执。学校要求回执的，回执只收班级、学生姓名、家长签名、日期和“已阅读本信”，不收身份证号、住址、家长工作单位。
7. 没有提供单位画像，单位类型按小学处理。可以用总入口 gongwen 建一份 3 个字段的简版画像，以后不必再回答这些问题。

二、待补事项（正文共 8 处）

1. 放假日期、开学日期（“一、时间安排”）：学校还没通知，所以没有推算。等学校转发教育局的寒假校历通知后，按通知原文写完整的年月日。一般向学校办公室或教导处要。
2. 班主任联系电话（“四、联系方式”）：您本人的电话。是否对家长公开个人手机号，按学校规定；学校不让公开的，删去这一行，只留学校值班电话。
3. 学校值班电话（“四、联系方式”）：向学校办公室或安全办要。
4. 落款中的学校名称、班级、班主任姓名：照实填写。
5. 发信日期：发出当天的日期，写完整的年月日。

三、待核实事项

1. 学校对寒假信有没有统一的格式和要求，比如是否有统一的安全告知书、是否需要回执、能否写班主任手机号。请向德育处或年级组确认，有出入的以学校为准。

四、机检情况

1. 已运行 `k12_check.py parents`（学段：义务教育）：P0 0 条、P1 0 条、P2 0 条。
2. 已运行 `gongwen_lint.py`（文书类型：其他）：P0 0 处、P1 0 处，P2 8 处，均为【待补】标记。
3. 机检只覆盖能写成规则的项目，放假时间、电话是否与学校通知一致，仍需人工核对。

五、写作要点

1. 任务卡：

```text
任务卡
文书：寒假致家长的一封信（二年级班主任写给本班家长）
写作方和学段：某小学二年级班主任，义务教育
读者和用途：本班学生家长；供您参考后改成自己的信
篇幅：默认一页以内（800～1200字）；素材只有主题和对象，可支撑约 750 字（预估），实际 771 字
角色模式：教学模式
```

2. 文种和结构：这是班主任写给本班家长的告知类信函，不是法定公文，不需要发文字号和版头。结构按家长的阅读顺序排：开头一句事由，开门见山，不写“岁末年初，万象更新”之类的铺垫；然后是时间安排、安全提醒、作息与锻炼、联系方式；最后一句祝福，落款写学校、班级、班主任和日期。家长最先要知道几号放假、几号开学，所以时间放在最前；出了事找谁，放在最后一块，方便翻到。
3. 为什么要写安全提醒：放假前学校要有针对性地集中开展安全教育，监护人配合学校加强安全教育（《中小学幼儿园安全管理办法》第三十九条、第四十六条）。这封信是家庭一侧的配合部分，所以把提醒写成家长能照着做的动作。
4. 为什么不写成绩和排名：义务教育学校的考试结果不排名、不公布，只以适当方式告知学生和家长，也不能在家长群里传播（教基厅函〔2021〕34号；教基厅〔2025〕3号第14条）。寒假信里不要出现“本学期成绩”“班级排名”“期末前几名”之类的内容。要谈孩子的学习情况，单独与家长沟通。
5. 为什么不让家长检查、批改作业，信里也没有写寒假作业：双减意见第4条要求严禁给家长布置或变相布置作业，严禁要求家长检查、批改作业，“请家长每天检查阅读打卡”“拍照上传”都属于变相布置。第5条要求小学一、二年级不布置家庭书面作业，所以二年级的寒假信不写书面作业。需要家长配合的，写成作息、锻炼、陪伴、看护这类生活事项就行。学校另有阅读、实践活动要求的，按学校通知另写，同样不要求家长检查、签字、打卡。
6. 为什么放假和开学时间留【待补】：放假、开学时间以教育局的寒假校历通知为准。学校还没通知，凭往年经验推算容易写错，家长会据此安排出行，所以先不写具体日期，通知下来后照原文填。
7. 三处措辞的用意：
   - 安全提醒写动作，不写口号。误：“请家长切实增强安全意识，确保孩子度过一个平安的假期。”正：“请不要带孩子到结冰的河面、湖面和池塘上行走、玩耍。”家长看完就知道该做什么、不做什么。
   - 用“请”“教孩子”，把做法讲清楚，必要时说明原因（如“冰层厚薄不均，容易破裂”），用商量的口气，比“必须”“严禁”更容易被接受。
   - 作息只写“固定时间”“提前约定”，没有写几点睡、几点起，因为没有学校或教育局的要求可依，不编数字；学校有明确要求的，补进去即可。
8. 这类信常见的失误：开头写大段铺垫；安全提醒空泛；变相给家长布置作业；放假时间没核对；收费没有依据（本信不涉及收费）。
