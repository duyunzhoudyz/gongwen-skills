## 五、写作要点（教学模式）

### （一）为什么写“议案”，和学校发文有什么区别

学校发文（通知、请示、报告、函、纪要等）参照《党政机关公文处理工作条例》和学校的公文处理办法办理，是机关之间行文，目的是让对方执行或批复。公司董事会的议案按《公司法》、公司章程和董事会议事规则办理，是写给董事看的待审议文件，董事在会上逐项表决。差别主要有四处：

1. 依据不同。条例里的“议案”专指人民政府向同级人大或其常委会提请审议的文种（第八条第（十三）项），公司董事会议案不按它写；高校的公文处理办法一般也不设议案文种（如华南师范大学、北京航空航天大学的办法都不含议案）。
2. 版式不同。议案不用红头，没有学校发文那样的发文字号、主送、抄送、印章；开头称“各位董事：”，结尾用“以上议案，请审议。”，落款写提案人和日期；议案如需编号，按董事会议事规则编，格式和签署以公司章程、议事规则为准。
3. 内容不同。议案一案一事。除了方案本身，必须交代“决策程序履行情况”：党内研究走到哪一步、要不要报出资人审批。学校发文一般没有这一栏。
4. 收尾不同。学校发文用“请批示”“特此通知”收尾；议案用“提请审议事项”收尾，要写到董事可以直接表决：同意什么、多少钱、授权谁办。

新人常犯的三个错：把议案写成情况汇报，没有可表决的提请审议事项；把“拟提交党支部委员会研究”写成“已研究”；把董事会通过当成终点，漏写上级审批。

### （二）提纲（结构说明）

标题“关于……的议案” → “各位董事：” → 开头段（事项、金额、提请审议）→ 一、基本情况 → 二、主要内容 → 三、决策程序履行情况 → 四、对公司的影响和风险 → 五、提请审议事项 → “以上议案，请审议。” → 附件、提案人、日期。

顺序按董事的阅读习惯：先知道要审什么，再看方案，再看程序走到哪一步，再看风险，最后表决。第一段不写形势和意义，直接写事项和金额。

### （三）决策链和前置研究的道理

本事项的顺序是：公司党支部委员会研究讨论 → 董事会审议 → 学校国有资产管理委员会审批 → 办理出资。

1. 党支部委员会的研究不代替董事会决策，所以写“同意提交董事会审议”，不写“决定增资”。
2. 董事会审议通过也不是终点。素材第4条规定增资、对外投资超过500万元的须报学校审批，本次1200万元超过500万元，所以议案写“审议通过后报审批”，并把提请审议事项第二项的授权限定在“审批同意后”。
3. 向控股子公司投资，是董事会按章程行使的投资决定权（《公司法》第六十七条、第十五条）；需要报学校审批，是学校自己的规定。两件事不要混在一起写。

### （四）议案、决议、会议记录的区别

议案是会前提交、请董事审议的文件，不写票数，更不能预先写“全票通过”。决议是会后根据会议记录写的，记载董事会的决定和表决结果，由出席董事签署。会议记录记讨论过程和发言。本公司董事5人，过半数（至少3人）出席才能开会，决议须全体董事过半数（至少3票）同意才算通过，章程规定更高比例的按章程（《公司法》第七十三条）。会后要出决议，把会议记录发来，我来核对出席人数和票数。

### （五）三处关键措辞

1. “研究讨论”“审议”“审批”：党支部委员会研究讨论，董事会审议，学校审批，谁用哪个词不能混。把党支部写成“决定”、把董事会写成“批准”，读的人会以为程序已经走完。
2. “拟于董事会审议通过后报审批”：计划用“拟”，不写成“已报”“已批准”。
3. “经学校国有资产管理委员会审批同意后，授权……”：授权带条件，防止批复之前就签协议、划款。

### （六）一处正误对照

误：公司党支部已研究决定向转化公司增资1200万元，请董事会批准，并授权经理层签署增资协议。
正：2026年10月9日，公司党支部委员会研究讨论，同意将本事项提交董事会审议。提请审议：同意公司向转化公司同比例增资1200万元；本事项经学校国有资产管理委员会审批同意后，授权公司经理层办理增资协议签署、出资等相关事宜。
说明：党支部不“决定”，董事会“审议”不“批准”，授权要带上“审批同意后”这个条件。
