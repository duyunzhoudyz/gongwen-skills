# 某社区居委会通知写法

来源：3篇已发文稿（燃气安全入户检查通知、高龄津贴发放对象公示、致辖区居民的一封信）。
适用范围：社区居委会写给居民看的通知、公示、告居民书。向街道、区里写的请示、报告，样本里没有，不在本文范围内。

## 一、三篇共同的写法
1. 对象是居民，所以没有文号、没有主送单位，直接用称呼开头（各位居民：/亲爱的居民朋友们：）；公示不需要称呼。
2. 标题一句话说清事由："关于……的通知""关于……的公示""致……居民的一封信"。
3. 开头一两句说明为什么发、要做什么，然后用"现将有关事项通知如下"（信里用"现将几件事告诉大家"）引出下文。
4. 正文分三条，用"一、二、三"，每条的小标题是短词，不带句号，内容另起一行：检查时间／检查内容／请您配合；投放时间／怎么分／大家一起来。
5. 语言口语化、说人话："查燃气管道有没有漏气""厨余垃圾放绿桶"，句子短，称呼用"您""大家"。
6. 时间写到具体：年月日、几点到几点，不写"近期""尽快"。
7. 结尾给联系办法：联系人加电话，另起一行。联系人按事项定，不是固定一个人：
   - 入户检查：社区网格员（王桂芳）
   - 民政事项：社区民政专干
   - 居民意见建议：社区主任（刘建华）
8. 落款：某社区居民委员会，日期另起一行，写成"2026年9月5日"。
9. 发文日期和事项的间隔：燃气通知提前5天（9月5日发，9月10日开始），告居民书提前6天（9月25日发，10月1日起实行），公示当天发当天起算。

## 二、三种文体的差别
| 文体 | 语气 | 结构骨架 |
|---|---|---|
| 通知 | 平实、客气，用"请您" | 为什么＋现将事项通知如下；一、时间；二、内容；三、请您配合（含注意事项）；联系人；落款 |
| 公示 | 比通知正式，句式固定 | 依据（根据……通知要求，经个人申请、社区初审）＋现将……公示如下；名单；公示起止日期；异议渠道（公示期内向社区居委会反映）；联系电话；落款 |
| 告居民书 | 亲切，用"亲爱的居民朋友们" | 开头说明新规则；一、时间地点；二、怎么做；三、大家一起来（用身边人的例子，鼓励为主）；意见建议渠道；落款 |

## 三、不要照着学的地方
1. 公示名单里不要写完整的身份证号和住址。样本中有两位老人写了完整身份证号，其中一位还写了具体到户的门牌，另一位只写"赵某"和楼栋，三条的写法也不一致。公示是对全体居民公开的，身份证号属于敏感个人信息，也不是居民判断名单对不对所必需的。以后建议：姓名、性别、年龄、所在楼栋即可，不写身份证号和具体门牌；需要核对的由社区和区民政局内部核对。
2. 年龄口径要统一。样本中陈德明写86岁，按他的身份证号推算，到公示日（2026年8月1日）是85周岁，86是用年份相减得出的数。以后统一按公示日的周岁年龄，并以申请材料为准。这一条建议你去核对原始材料，因为我只能看到公示稿。
3. 信的标题和内容要对应。"致辖区居民"里写的是"我们小区"、东门北门，范围只有一个小区。以后：全辖区的事用"致辖区居民"；只有一个小区的事写"致××小区居民"。

## 四、可选改进（样本里没有，建议而已）
- 入户检查类通知，可加一句燃气公司名称、是否收费、怎样核实检查人员身份，防止有人冒充上门。
