## 四、写作要点

你问为什么这么写，下面按“文种、结构、问题、目标、任务、措辞”六点说明。

1. 为什么是“计划”。学校工作计划是对下一学期全部工作作出安排，要写清目标、任务、责任和时间。相近的材料各有分工：工作要点只列重点，比计划简要，常以通知印发；实施方案针对某一项专项任务；总结是回头看。学校计划不在《党政机关公文处理工作条例》第八条所列的15种法定文种之内，是常用的事务性材料，校内要下发时，一般以通知印发（实务做法）。

2. 结构为什么这样搭。同类文书的骨架如下，你以后写别的学期计划也可以套用：

```text
标题：学校名称＋学年学期＋“工作计划”
开头：一句话，写目的和依据（为……，结合……，制定本计划）
一、工作目标        做到什么程度，能量化的量化
二、主要工作        按德育、教学、教研、安全、家校协同、后勤分板块，每项写清谁来做、做什么
三、行事历          按时间排出主要活动
```

目标放在最前，因为计划的价值在于“做到什么程度”。主要工作按条线分板块，是因为学校各处室就是按这些条线分工的，每个板块对应一个处室，方便各处室认领和检查。行事历让各处室一眼看到什么时候要做什么。开头只写一句，不写形势和意义，也不写“根据上级要求”这类没有出处的话。

3. 计划要接着秋季学期的问题写。你整理的情况里有三个具体问题：班主任经验不足，课后服务教师负担重，家访覆盖率没统计。计划里各有一条对应任务。常见的毛病是总结里提了问题，计划里没有对应任务。措施怎么定是学校的决定，所以标了【待补】，没有替学校编。家访覆盖率没统计，就没有基数，所以先写“春季学期统计家访覆盖率”，目标取“本学年每名学生至少家访1次”。

4. 目标怎么写才能衡量：把“秋季基数”和“本学期目标值”放在一起。

   误：进一步提高课后服务质量，让更多学生受益。
   正：参与学生达到【待补：目标人数】人。秋季学期参与学生912人，占全校学生1036人的88.0%。

5. 任务要写清四件事：谁来做、做什么、何时完成、做到什么程度，缺哪项补哪项。

   误：加强班主任队伍建设，提升班主任管理水平。
   正的句式：____前，由____组织____，做到____。

   本稿这一条，措施、时间、责任处室学校还没定，所以写成“针对这一问题，【待补：具体措施】”，等学校定了再按句式填。

6. 几处措辞的用意。
   - 部署内容用肯定句，不用“争取”“尽量”“建议”。目标值没定时先写【待补】，不要用“力争”这类词含糊带过。
   - “书香校园”读书活动：上级的提法照原话写，不换成“阅读推广”之类的近义词，具体要求以上级通知为准。
   - 区督导评估“时间未定”：时间没定的事照实写“时间未定”，不要自己推算日期，等区里通知后再补。
   - 成绩名次：义务教育学校日常考试结果不排名、不公布，学校材料里不写成绩名次。想体现教学质量，可以用等级分布、薄弱学科这类不含名次的数据。

每项【待补】一般到哪里找，已写在“二、待补事项”里。
