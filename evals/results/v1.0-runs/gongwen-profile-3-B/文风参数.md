# 某市某局材料文风参数

来源：4篇局长定稿材料（2025年工作总结、2026年上半年工作总结、关于优化营商环境工作情况的汇报、迎接市委督查工作汇报）。
适用范围：对上的总结、汇报类材料。样本中没有请示、通知、讲话稿等文种，这些文种不适用本参数。
样本说明：4篇都偏短（322至567字，合计约1700字），参数的可靠度中等；有更多定稿材料可补发。

## 一、结构
**总结**
1. 标题：某市某局＋时段＋工作总结
2. 导语一段：先交代背景（在市委、市政府的坚强领导下，我局坚持以人民为中心……），再用"现将……总结如下。"收口
3. 成效部分：两个大块（一、二），每块下面分（一）（二）
4. 三、存在的问题（短，2至3条）
5. 四、下一年（下半年）工作打算（3条）
6. 落款：单位名，日期另起一行

**汇报**
1. 标题：某市某局＋关于……工作情况的汇报（或工作汇报）
2. 主送机关顶格，加冒号（市政府：/市委督查组：）
3. 导语：按照……部署（或2026年以来），我局……。现将……汇报如下。
4. 一、主要做法和成效（或重点任务完成情况）
5. 二、存在的问题
6. 三、下一步工作（打算）
7. 结束语单独一行：以上汇报，不妥之处，请批评指正。
8. 落款：单位名，日期

**总结与汇报的差别**：汇报更短（322至337字，总结482至567字）；汇报有主送机关和结束语；汇报的成效部分只设一个大块，不用对仗标题。

## 二、标题
- 总结的成效大标题用两个四字短语，中间隔一个全角空格：聚焦主责主业　推动提质增效；坚持问题导向　补齐短板弱项；聚焦改革攻坚　推动服务提质；坚持监管为民　守牢安全底线。规律：前半句"聚焦/坚持＋对象"，后半句"推动/补齐/守牢＋结果"。
- 二级标题是4至6字的动宾或名词短语，后面带句号，正文紧跟在同一段里，不另起一行：（一）优化审批服务。（一）深化"一网通办"。（二）市场监管。
- "存在的问题""下一步工作"这类大标题用平实写法，不做对仗。

## 三、段落写法
- 每个二级标题下：先用一句总述交代结果，并带关键数据；再用"一是……；二是……；三是……"分条写做法，每条2至3个，每条以动词开头（推行、开展、上线、取消、整合、打通）并带量化。
- 未完成事项如实写，例如"排查隐患146处，已整改139处，其余7处正在整改"。
- 成效部分不写原因分析，不抒情，不用感叹句。

## 四、数据使用
- 每篇8至20个数字，几乎每个成效段都有数据。
- 数据要带对比：前后对比（由5.2个工作日压缩至3.1个工作日）、同比（同比增长11.2%）、较上年（较上年缩短2.1个工作日）。
- 数量级用法：1.86万件、1240户、320户次、37项；比例保留一位小数。
- 同一指标在不同材料里口径一致，已核对4篇中重复出现的数字（网办率83.6%、企业开办1个工作日以内、审批时长3.1个工作日、由5.2个工作日压缩而来），互相吻合；新材料沿用这些数字作基线，不要另起口径。

## 五、"存在的问题"
- 2至3条，一是……；二是……，每条一句。
- 具体、坦率，常带数字或事实，例如"人均监管市场主体超过400户""基层执法人员年龄结构偏大""智慧监管平台建设进度滞后于计划"。
- 不写原因辩解，不写"客观上"一类的话，不把问题写成成绩。

## 六、"下一步工作"
- 总结3条，汇报2条，一是……；二是……；三是……，动词开头。
- 条目与前文的成效和问题呼应，例如问题里写了数据共享不畅，下一步写"推动跨部门'一件事'改革"。
- 样本里这一部分没有具体目标数字、时限或责任人。这是该局目前的写法；以后若要写得更落地，可以加，但这是在样本之外的改动。

## 七、句式与语气
- 第一人称用"我局"。
- 句子偏短，平均句长21至27字，句号和分号为主。
- 固定开头：在市委、市政府的坚强领导下，我局坚持以人民为中心，……（4篇中有3篇；营商环境汇报没有，改用"按照市政府工作部署"）。
- 日期写作"2026年1月10日"，月日不补零。
- 引号用于专有名词和工作品牌："一网通办""免证办""一窗受理""好差评"。

## 八、高频词（全部4篇约1700字）
统筹推进9次、扎实开展9次、推动9次、压实5次、持续深化5次、落地见效4篇各1次。
- 这些是该局文风的识别特征，我默认沿用。
- 控制办法：同一个词一篇里不超过3次；不用它们去填没有具体内容的句子。样本里"统筹推进年度目标任务，确保全年任务完成"这类句子没有具体信息，不建议学。
- "值得注意的是"在两篇总结中各出现1次，用于在成效段里点出一个遗留问题并说明已列入下一步重点；总结里可选用，每篇不超过1次，汇报不用。

## 九、不当作参数的内容
- "营商环境不是一个部门的事，而是全市各部门的共同责任。"只出现1次，且是口号式的"不是……而是……"句式，与其他3篇的务实笔调不一致，不学。
- 各篇独有的事实和数字（如1.86万件、680户）不作模板。
- "以上汇报，不妥之处，请批评指正。"只用于汇报，总结不用。
