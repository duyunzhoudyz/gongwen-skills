# 党员教师学习心得体会：提纲和填写指引

供学校党支部20位党员老师各自填写，每人一篇，每篇约1500字。下面的提纲所有老师通用；每位老师把【待补】处换成自己的学习内容、认识和工作中的事，不同的人写出来就不会重样。

## 一、提纲

```text
【待补：题目】

学习了【待补：材料名称和篇目】，印象最深的是【待补：一两句原文，原样抄来并注明出处】。

一、主要认识
（一）【待补：第一点认识，联系所学原文】
（二）【待补：第二点认识，联系所学原文】

二、对照查找的差距
【待补：联系本人岗位的具体事】

三、下一步打算
【待补：具体、可检验的打算】
```

## 二、填写指引

| 部分 | 需要本人提供的事实 | 句式 | 参考字数 |
|---|---|---|---|
| 题目 | 本人最主要的一点体会，或学习的主题 | 例：“____给我的启发”（____换成本人的体会） | |
| 学了什么 | 材料名称、篇目；印象最深的一两句原文（原样抄来，不凭记忆）；这部分讲了什么 | 学习了____，印象最深的是“____”（出处）。 | 约200字 |
| 主要认识 | 读到这句话本人想到了什么，大白话几句即可；每点先摆原文要求，再说本人的理解，再联系本人工作 | 原文要求____。我的理解是____。放到我的工作里，____。 | 2～3点，合计约700字 |
| 差距 | 本人工作中与所学要求对不上的一件具体事：什么时候、怎么回事、本人做了什么或没做好什么、影响是什么 | 在____工作中，我____（具体表现），导致____（影响）。 | 约400字 |
| 打算 | 下一步具体做什么、什么时候做、做到什么程度 | 从____起，我将____，做到____。 | 约200字 |

参考字数合计约1500字，是写作参考，不是硬性要求；以上级或学校对心得的字数要求为准。

提醒每位老师：
1. 写自己的事和自己的想法，大白话也行。不用“通过学习，我深刻认识到，必须……”这类对谁都适用的话。
2. 引文只用学习材料里的原句，原样抄来，注明出处；不凭记忆写“领导人说过……”，也不引网上的“金句”。
3. 每点认识都联系本人岗位上的一件具体事；举不出事例的那一点先不写，宁可少一点，也不编。
4. 结尾停在具体打算上，不写“收获颇丰”“受益匪浅”。
5. 涉及学生的事例，不写学生姓名、班级、成绩，写“一名学生”“某班”。
6. 填好后发来，可以逐篇帮助整理成文；没时间填完整的，把学了什么、想到了什么、工作里的一件事用几句话说一下，也可以。
