# 提纲：在全县经济工作会议上的讲话（县委书记）

## 任务卡

- 讲话类型：年度工作会讲话
- 场合：某县2027年经济工作会议，2027年1月上旬召开（具体日期待补）
- 讲话人：县委书记
- 听众：全县经济工作会议的与会人员（范围按会议通知，待补）
- 时长：书记要求80分钟；按不超过60分钟定字数（减负规定第6条），每分钟约200字，上限约12000字（这是工具的换算约定，不是规定要求）
- 素材可支撑：约2700字（预估），约13.5分钟，离60分钟差约9300字（约78%）
- 议程位置：县长另作政府工作部署，两者先后顺序未提供；书记讲话不展开具体项目
- 稿子用法：念的稿（年度工作会讲话，会后一般印发）
- 角色模式：高效模式（用户在县委办写材料）
- 本轮交付：用户要求先出提纲和各部分字数，所以只交提纲，不出正文

## 骨架与各部分字数

## 各部分要点

开场
- 一两句点明会议任务，不写形势背景和意义铺垫。
- 说明县长另作政府工作部署，本人不展开具体项目。
- 县长部署排在书记讲话之前的，加一句表态同意；排在之后的，说明县长随后部署。顺序待确认。

一、算清去年的账，看准今年的势
- 成绩：地区生产总值预计增长6.1%（县统计局快报预计数）；新签约亿元以上项目23个；城乡居民人均可支配收入增速【待补：快报数】。
- 差距：【待补：点到具体环节的差距，不用空话】。
- 形势：【待核实：请提供上级经济工作会议精神原文及出处】；【待补：本县面临的具体形势】。
- 县长部署稿若已含这些数据，书记讲话只用一处，避免同一组数据念两遍。

二、稳住工业基本盘，盯紧园区扩区和3个在建亿元项目投产
- 事实：重点是园区扩区和3个在建亿元项目投产。
- 责任单位、完成时限、项目名称：【待补】，不自定。
- 书记只给了意思的，成稿时展开成要求性语句，展开的部分单列出来请确认。

三、抓好招商引资，全年新签约亿元以上项目不少于25个
- 事实：全年目标不少于25个；2026年为23个，25−23=2，多2个。
- 招商方向、责任部门、完成时限：【待补】，不自定。

四、办好民生实事
- 事实：具体实事清单由县政府定。书记讲话不列清单，不替县政府点项目。
- 只讲原则、标准和要求，要求来自书记：【待补：书记对办好民生实事的原则和要求】。

五、改进作风，少开会、开短会
- 事实：少开会、开短会。
- 具体要求：【待补：书记对会议数量、时长的具体要求】。

结尾
- 回扣开场的会议任务，停在一两条要求上，不用“总而言之”，不堆口号。

## 补料清单（按部分，括号内是找谁要）

1. 全年经济运行数据：居民收入增速快报数，工业、投资、消费等其他指标（县统计局）。
2. 第一部分：2026年的主要做法和差距，要点到具体环节（县政府办、各主管部门）。
3. 上级经济工作会议精神的原文及出处，要引用的才需要（县委办、政研部门）。
4. 第二部分：园区扩区的范围、进度、牵头单位、时限；3个在建亿元项目的名称、投产时间、责任单位（主管工业的部门、园区管委会）。
5. 第三部分：招商重点方向、责任部门、2026年招商做法和事例（招商引资主管部门）。
6. 第四部分：县政府确定的民生实事清单，书记要点名的话才需要；书记对办实事的原则和要求（县政府办、书记）。
7. 第五部分：书记对开会数量、时长的具体要求（书记、县委办）。
8. 县长政府工作部署稿，用于核对不重复；会议议程、与会范围、书记讲话与县长部署的先后顺序（县政府办、县委办会务）。
9. 书记想对每一部分强调的观点和要求（书记本人，或通过秘书转达）。
