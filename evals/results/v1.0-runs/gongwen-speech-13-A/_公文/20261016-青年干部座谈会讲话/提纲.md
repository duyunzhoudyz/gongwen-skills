# 提纲：在青年干部座谈会上的讲话（框架稿）

## 任务卡

- 讲话类型：座谈会讲话
- 场合：青年干部座谈会（会议名称、主题、议程未提供）
- 讲话人：区委书记
- 听众：参加座谈会的青年干部
- 时长：10分钟，按每分钟约200字，约2000字（1800～2200字）
- 素材可支撑：约150字（预估）。用户只给了场合、讲话人和时长，没有一条要讲的事实，稿中只有结构、过渡语和小标题，事实和书记的看法要求全部标【待补】
- 议程位置：未提供，按书记听完青年干部发言后讲话处理
- 稿子用法：讲的稿
- 角色模式：高效模式（用户说“今晚就要”，在区委办工作）

## 骨架与字数

骨架按座谈会讲话：回应、几点看法、希望。每一点由观点句、事实、具体要求组成。

|---|---|---|---|---|
| 开场（含称谓） | 点题，衔接刚才的发言，说“讲三点” | 64 | 64 | 座谈会主题（会议通知、承办单位） |

## 每个待补怎么补

1. 事例：写清人物（可用代称）、时间、经过和结果，按“做法—过程—结果”写，一点一例，不拔高。
2. 书记的看法或要求：要书记本人的意思，哪怕是几个要点；只给意思、没给做法的，可以由我展开成要求性语句，展开的部分会列出来请确认。
3. 要引用的纪律要求或上级精神：请给原文和出处，没有原文的我不写、不凭记忆补。
4. 座谈中的意见：发言人的意见不能张冠李戴，以座谈记录为准。

## 标题备选（3套）

1. 在青年干部座谈会上的讲话（正文采用）
2. 听你们说——在青年干部座谈会上的讲话
3. 到一线去　守住规矩——在青年干部座谈会上的讲话（对应第二、三点小标题，书记认可这两点后再用）

## 补料清单

1. 书记的姓名、会议具体日期：会议通知。
2. 座谈会的主题、议程、发言名单和发言要点：座谈会承办单位。
3. 书记想对青年干部强调的看法和要求：书记本人，或通过秘书、分管领导转达。
4. 本区青年干部的情况和一线历练的事例：区委组织部门。
5. 要引用的纪律要求、上级精神原文及出处：区委办、纪检部门。
