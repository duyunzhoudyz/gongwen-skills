【起草说明】

一、所作假设

1. 任务卡：

```text
任务卡
文书：寒假致全市中小学生家长的一封信（完整版；另有家长群版）
写作方和学段：某市教育局（素材来自基础教育处），以市教育局名义发出；义务教育为主
读者和用途：全市中小学生家长；公众号和各校家长群发布
篇幅：默认一页以内（800～1200字）；素材可支撑约 780 字（预估），实际 783 字
角色模式：严谨模式
```

2. 没有单位画像。写作方是市教育局，单位类型按“党政机关”（市级教育行政部门）处理。信面向全体家长并在公众号发布，本稿按严谨模式处理：放假时间、政策表述、举报电话只用素材原文，不另引条款，下面附依据核对清单。
3. 称呼用“尊敬的家长”，落款用“某市教育局”，主语用“市教育局”；面向全市，不写具体学校、班级的安排。
4. 素材只写了“全市义务教育学校”的放假、开学时间，正文照写，没有扩大到普通高中和中等职业学校。标题和读者仍按“中小学生家长”，高中、中职的时间留了待补。
5. 素材中的监督举报电话没有说明受理范围，正文按“学校违反上述规定”（补课、作业）写。
6. 局领导要求写入的“深入学习贯彻……精神”，素材没有给出具体精神和原文，没有自拟，在第一段留了占位。家长群版篇幅有限，没有放这句。
7. 素材“要点”只列了主题。规律作息、五项安全提醒的具体做法，是按通用安全常识展开的，不含数据和政策表述；“规律作息”素材里没有，只写了不含具体时间的通用建议。
8. 字数口径：含标点、标题和落款，不含【待补】标记。完整版 783 字，家长群版 171 字（含称呼和落款）。
9. 本稿只含信本身。需要给各校下发转发通知的，转发通知属于下行通知，交 gongwen-draft 起草，本稿不含。
10. 可以用总入口 gongwen 建一份 3 个字段的简版画像，以后不必再回答这些问题。

二、待补事项

1. 第一段：局领导要求写入的“……精神”的具体名称和原文表述。一般向局办公室，或负责该精神传达的处室索取原文。信是写给家长的，这句话放在开头偏重，写入后请通读一遍语气。
2. “一、放假安排”第一段末：普通高中、中等职业学校的放假和开学时间。一般向基础教育处或职业教育主管处室核对。如果这封信只发义务教育阶段家长，删去该处，并把标题改为“寒假致全市义务教育阶段学生家长的一封信”。
3. 落款：发信日期。公众号推送前按实际发布日期填写。

三、待核实事项

1. 放假、开学时间和文号：素材只摘录了通知的结论，没有通知原文，请对照某教发〔2026〕88号原文核对通知名称、文号和日期。
2. “各学校不得组织集体补课”“减少书面作业”“鼓励体育锻炼、家务劳动、社会实践”：素材“要点”没有注明出自哪份文件，正文没有写成“根据某某通知”，请核对是否出自88号通知，确认后可补出处。
3. 监督举报电话：请与基础教育处核对号码、受理范围和接听时间。
4. 没有提供往年的寒假致家长的信，未做雷同比对；有往年稿的话请发来对照。

四、机检情况

1. 已运行 `k12_check.py parents`（学段：义务教育）：完整版、家长群版均为 P0 0 条、P1 0 条、P2 0 条。
2. 已运行 `gongwen_lint.py`（文书类型：其他）：完整版 P0 0 处、P1 0 处，P2 3 处，均为【待补】标记；家长群版 0 处。
3. 机检只覆盖能写成规则的项目，放假时间、文号、电话是否与通知原文一致，仍需人工核对。
