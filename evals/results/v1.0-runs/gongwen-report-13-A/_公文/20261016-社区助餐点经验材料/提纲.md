# 提纲与标题备选

材料类型：经验材料（书面，社区助餐点）；写给街道；转译模式。
结构：框架一“做法加成效”（经验材料最常用）。居民反映的问题放在最后“下一步”。

## 标题备选

1. 主副标题式（推荐）：把午餐办到老人家门口——某社区居委会开办社区助餐点的做法
2. 平实式：某社区居委会社区助餐点工作经验材料

主标题只概括台账里有的事实：助餐点在社区内、每天中午供餐、60岁以上老人每餐优惠。没有“破解老年人吃饭难”之类需要数据支撑的成效说法。

## 提纲

开头（台账 1～5，约100字）：2026年3月助餐点开业，每天中午供餐，60岁以上老人每餐优惠3元，累计供餐【待补】份。

一、主要做法
（一）经居民代表会议确定，列入年初民生实事（台账 1、2、3，约90字）
（二）每天中午供餐，给60岁以上老人优惠（台账 4、5，供餐时段和价格待补，约60字）
（三）交给运营方运营（台账 6，待核实，约50字）

二、取得的成效
（一）供餐情况（日均就餐人数、享受优惠的老人人数和优惠总额，全部待补，约60字）
（二）老人的反映（台账 7，约40字）

三、下一步（台账 8，措施待补，约40字）

落款：某社区居委会；成文日期待补。

## 篇幅

正文约370字（不含【待补】）；待补的数据补齐后，预计可到600～800字。书面经验材料一般2000～3000字（工具约定），要写到这个长度，还需要补充每项做法的过程和事例，需要补的素材见回复里的补料清单。
