# 起草说明

## 一、所作假设

1. 报告类型：公司为深证100指数样本公司，属于强制披露可持续发展报告的范围，报告名称按“可持续发展报告”写；公司惯用“ESG报告”的，标题可括注，内容不变。依据：esg-baogao 模板第二部分，具体以深交所正式文本为准。
2. 报告期按素材标题“2025年度”，写为2025年1月1日至2025年12月31日（见待核实第2条）。
3. 未提供单位画像，单位类型按国有企业（地方国企控股的上市公司）处理；没有显示角色信号，按教学模式处理，因对外披露叠加严谨模式。
4. 主语统一用“公司”。金额单位本章统一用亿元；温室气体排放量沿用素材的万吨二氧化碳当量，未换算为吨。
5. 本轮只交框架、数据需求清单、“关于本报告”和环境章节；其余章节在已交付稿上续写。
6. 西区园区按公司的园区处理（素材把它放在公司环境数据下），权属和核查边界见待核实第3条。

2. 报告类型和披露时点：深证100指数样本公司的2025年度可持续发展报告，依规最晚应在2026年4月30日前与年报同时披露（esg-baogao 模板第二部分，以深交所正式文本为准）。现在已是2026年10月，请确认本次编制的是补编、改版，还是2026年度报告；如果2025年度报告已经披露，本稿数据口径须与已披露版本一致，不一致的要写明差异原因，不悄悄调成一致（redlines 第三条第3款）。
3. 西区园区的权属、运营主体，以及核查是否覆盖该园区全部范围一和范围二排放。

## 五、修改说明

品牌部的意见，按“看着办”处理如下，前三条是对外表述不夸大的要求（redlines 第六条）：

1. 碳中和：品牌部建议写“公司已实现碳中和”，未采用。素材显示公司2025年范围一和范围二排放仍有126.4万吨二氧化碳当量，碳中和核查只覆盖西区园区。改写为“西区园区2025年经第三方机构核查，实现运营碳中和”，并写明该结论仅适用于西区园区；核查机构、报告编号、范围和实现方式待补（附件未提供）。依据：redlines 第六条第1款；esg-baogao 模板第七部分；机检 SOE-009。
2. 零事故：品牌部建议写“全年安全生产零事故”，未采用。素材第6条写明2025年发生1起一般生产安全事故，造成1人受伤（已结案）。社会章节续写时如实披露起数、伤亡人数和事故等级，不写“零事故”。依据：redlines 第六条第2款；esg-baogao 模板第六部分第5条（负面信息如实写）。
3. 行业第一：品牌部要求突出“光伏技术是行业第一”，未采用。素材没有认定机构、榜单、排名口径和年份。品牌部能提供出处的，按“据某机构某年发布的某榜单，公司某技术排名第几”写出处；提供不了的，改写有数据的技术指标，荣誉写授予机构和年份。依据：redlines 第四条第5款、第六条第3款；机检 SOE-008。
4. 2026年三季度营业收入：素材建议写进展望部分，未采用。三季报10月28日才披露，属未公开财务信息，上市公司不得先出现在ESG报告中；也超出2025年度报告期；“大幅增长”没有具体数据。三季报披露后如需引用，按已披露口径、写明基期，并请董事会办公室确认。依据：redlines 第二条第1款、第三条第1款；esg-baogao 模板第八部分第6条。
5. 比率变化用“百分点”：新能源装机容量占比写“提高7个百分点”，不写“提高7%”。排放量下降5.6%是数量变化，用百分数。算式：133.9－126.4＝7.5万吨；7.5÷133.9＝5.6%。
6. 机检：soe_check（ESG报告，按对外材料从严）P0、P1、P2 均为0；gongwen_lint（其他）P0、P1 为0，P2 共20条，均为【待补】【待核实】标记（待补19、待核实1）。素材台账对账：正文数字全部能在素材台账找到。未提供往年报告，未运行雷同检查。

## 七、写作要点（教学模式）

1. 为什么按“可持续发展报告”搭框架：深证100指数样本公司属于强制披露范围，内容围绕“治理、战略、影响风险和机遇管理、指标与目标”四个核心内容组织；框架按“关于本报告、董事长致辞、公司概况、可持续发展治理、议题识别和重要性评估、环境、社会、治理、关键绩效表、指标索引”排列。议题清单和重要性评估的结论由公司提供，本稿不替公司判定。
2. “关于本报告”要写清报告期、范围、编制依据、数据来源和口径、可比性、不披露的指标和鉴证；这是读者判断数据能不能用的依据，缺一项就要标【待补】。
3. 环境章节每个议题按“管理方针、行动、绩效数据、目标”写，数据带单位、口径和期间，目标和已实现分开。应对气候变化是交易所指引最看重的议题，按“治理、战略与行动、影响风险和机遇管理、指标与目标”四个核心内容分四项写，其余议题按前一种写法。本稿手上只有绩效数据和一两项行动，其余都留了待补，没有用套话填。
4. 本稿的一处正误对照：误：公司已实现碳中和。正：西区园区2025年经第三方机构核查，实现运营碳中和。差别在主体和依据：前者把一个园区的核查结论说成全公司，后者写明范围，可以回查。
5. 各项【待补】一般到哪里找，已在“待补事项”里逐条写明（碳排放核算报告、能源和水资源统计报表、财务报表、环境监测报告、核查报告、董事会文件）。
