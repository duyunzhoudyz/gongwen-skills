# 县农业农村局百日攻坚实施方案（送审稿）对标检查意见

对照文件：某市农业农村局关于开展农村人居环境整治提升百日攻坚行动的通知（某农发〔2026〕33号）。只做对标对表，没有改动送审稿。

## 一页纸摘要

主旨：送审稿与市通知逐条对照，目标和任务里漏了农村生活污水治理，总结报送时限（12月15日）晚于市里的12月10日，工作要求里有多处超出市里要求的加码，二（一）整段照抄。建议改完P0和P1再送审。

1. 漏项：市通知15条要点中，5条没有对应（污水治理的目标和任务2条，上级工作要求3条）；另有2处只落实了一部分（户厕问题台账、设施运维管护）。
2. 照抄：二（一）村庄清洁整段照抄市通知，与上级重合73.1%；全文总重合率25.2%。
3. 时限：3处。总结报送12月15日晚于上级5天（P0）；长效管护11月30日与上级同日，没有提前；村庄清洁、户厕定11月15日，比上级提前15天，偏多。
4. 加码：4处。户厕目标值100%（上级90%以上）；要求乡镇再制定方案并备案；乡镇周报、纸质材料和现场照片；纳入年度考核、一票否决。
5. 另有两点不属于对标但影响报批：方案以县农业农村局名义对乡镇提指令性要求，还给县财政局派任务、定补助，没有看到会签；送审稿里的128个行政村、21360户、每村每年2万元无法在材料中核对。

修改顺序建议：
1. 先改3个P0：补污水治理；总结时限改到12月10日之前；工作要求改成落实上级底线要求。
2. 再删三、工作要求（一）至（三）里的加码内容，户厕目标值改回90%以上，二（一）改成本县措施。
3. 然后补长效管护的设施运维，补助标准和报批方式（县政府同意或会签）先定下来。
4. 时间提醒：市里要求10月20日前制定实施方案，今天是10月16日（周五），到期前只剩周一、周二两个工作日，报批流程要马上启动。
