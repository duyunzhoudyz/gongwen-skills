# 核稿意见：某村秋冬森林防火通知（初稿）

- 核稿对象：《关于加强秋冬季森林防火工作的通知》，落款某村民委员会，成文日期2026年10月15日（用户提供的文件：某村秋冬森林防火通知初稿.txt）
- 处理方式：审稿模式，只列问题，不重写全文；原稿文件未改动

## 一、一页纸摘要

**主旨**：村民委员会向全体村民发出的秋冬季森林防火通知，提出五项内容：划定防火期、禁止野外用火、外来人员进山登记、各户签订责任书、要求村民配合。

**主要问题**

1. 第二、三、四条共有5处是村委会没有权限设定的内容：500元罚款、“一律移送公安机关拘留”、“未登记的不得进山”、要求各户签责任书、拒签就取消年度村集体分红资格。村委会是基层群众性自治组织，没有行政执法权，这5处必须删去（P0）。
2. 开头引用的《森林防火条例》已被《森林草原防灭火条例》取代（2026年1月1日起施行），旧条号也对不上新条例（P1）。
3. 防火期“即日起至明年4月30日”没有写依据。防火期由县级以上地方人民政府规定并公布，需要对照本地公告核定（P1，待确认）。
4. 没有值班电话和火情报告方式；“严禁在山上”的范围不准，确需用火的报批程序也没交代（P1）。
5. 最后一条是公文套话，村民读不出要做什么（P2）。

**处理建议**：建议退回村里修改后再发，不宜按原稿张贴或群发。修改方向是把“罚、拘、禁入、签责任书、扣分红”这几块换成村委会能做的提醒和服务（巡山劝导、发现火情立即报告、报警电话、文明祭扫倡导），法律后果只写“由林业草原主管部门依法处罚”。是否签发由您判断。
