# 体检报告

体检结论：三份快报都没有密级或内部标注，也没有个人信息；有1条P0问题（丙公司统计时段是1—8月，与甲、乙公司的1—9月不一致，未计入汇总）、1条P1问题（乙公司营业收入单位是元，已换算成万元）；资产负债率只有比率、没有分子分母，无法汇总；其余数据可用，见计算底稿。

检查对象：某集团甲公司2026年1—9月经营快报.csv（表A）、乙公司2026年1—9月经营快报.csv（表B）、丙公司2026年1—8月经营快报.csv（表C），各5个指标。检查工具：data_tool.py inspect 和 merge，结果已逐条人工复核。
