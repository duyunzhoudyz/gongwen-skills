写“提高9个百分点”。这句话可以直接放进总结：

2026年1—9月，网办率为71%，比上年的62%提高9个百分点【待核实：上年62%是全年数还是1—9月数，同比应与上年1—9月比】。

为什么这样写：
1. 62%和71%都是比率，两个比率相减，差的单位是“个百分点”：71%－62%＝9个百分点。
2. 不能写“提高了9%”。“提高9%”的意思是在62%的基础上再增长9%，也就是62%×1.09≈67.6%，到不了71%。
3. 14.5%是有来历的：（71－62）÷62＝14.5%，这是网办率本身的相对增幅（62%×1.145≈71%）。数学上没错，但它回答的是“这个比率涨了百分之几”，不是“提高了多少”，读的人很容易看成“提高14.5个百分点”。总结里写率的变化，统一用百分点，不用14.5%；办件数、网办件数这类数量的变化才用百分数。
4. 还有一处要留意：你说“去年是62%，今年1到9月是71%”，如果62%是去年全年的数，拿今年前三季度去比，时段不一致，严格说不能叫“同比”。所以句子里写的是“比上年”，没有写“同比”，句末标了【待核实】。

写作要点，对照记一下：
- 比率的变化用百分点。误：网办率由62%提高到71%，提高了9%。正：网办率由62%提高到71%，提高9个百分点。
- 同比要同时段。误：今年1—9月网办率71%，同比提高9个百分点（比的是去年全年数）。正：1—9月和去年1—9月比才叫同比；去年只有全年数，就写“比上年的62%提高9个百分点”。
- 数据句的顺序：先写本期数，再写变化，写明基期。
