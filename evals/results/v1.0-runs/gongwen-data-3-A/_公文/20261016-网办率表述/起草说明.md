3. 上年62%的统计时段没有说明，句中写“比上年的62%”，没有用“同比”；时段放在待核实事项里请你确认。
4. 可以用总入口 gongwen（帮你建单位画像、分派任务的入口）建一份3个字段的简版画像，以后不必再回答这些问题。

二、待核实事项

1. 正文【待核实】处：上年62%是全年数还是1—9月数。如果是全年数，今年1—9月拿它去比，时段不一致；规范的比法是与上年1—9月比，那时写“同比提高X个百分点”，X 要用上年1—9月的网办率重算。一般到办件管理系统（业务系统）的统计报表、上年的年度总结或上级通报里核实。
2. 两年网办率的统计口径是否一致，即分子（网上办理的事项）、分母（办理总数）的范围是否相同。

三、计算说明

1. 运行了 data_tool.py phrase：--type pp 算百分点，--type growth 算相对增幅（备查，不进正文）；倒推验算用十进制代码。算式见计算底稿。
2. 公式：百分点＝本期比率－基期比率＝71%－62%＝9个百分点；相对增幅＝（本期－基期）÷基期×100%＝14.5%。
3. 表述判断：比率的变化写“个百分点”，不写“提高9%”（国家统计局《“百分数”与“百分点”》）；同比是与上年同期比（国家统计局《同比与环比有何不同》）。

四、写作要点（仅教学模式）

1. 比率的变化用百分点。
   误：网办率由62%提高到71%，提高了9%。
   正：网办率由62%提高到71%，提高9个百分点。
   理由：62%和71%是两个比率，相减的差是“个百分点”。“提高9%”的意思是在62%的基础上再增长9%，即62%×1.09≈67.6%，到不了71%。
2. 14.5%是什么，什么时候用。
   14.5%＝（71%－62%）÷62%，是网办率本身的相对增幅（62%×1.145≈71%）。它回答的是“这个比率涨了百分之几”，不回答“提高了多少”，读者很容易看成“提高14.5个百分点”，所以总结里写率的变化统一用百分点，不写14.5%。数量（办件数、网办件数）的变化才用百分数。
3. 同比要同时段。
   误：2026年1—9月网办率71%，同比提高9个百分点（对比的是上年全年的62%）。
   正：1—9月与上年1—9月比才叫同比；上年只有全年数的，写“比上年的62%提高9个百分点”并说明，或向业务系统要上年1—9月的数再写同比。
4. 数据句的顺序：先写本期数，再写变化，写明基期。例：“网办率为71%，比上年的62%提高9个百分点”，读者既看到水平，又看到变化。
