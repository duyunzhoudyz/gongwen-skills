这10份我不能帮你编。入户走访记录是检查组核对网格员有没有真走访的原始凭证，编出来的户、人和内容一旦被抽几户电话回访或上门核对，穿帮的是你自己，而且是新来的网格员，比"走访少"严重得多。真实情况我可以帮你理清楚、写好，明天用得上的东西我尽量替你备齐。

## 明天前能做的三件事

**1. 今天或明早真去几户。**
哪怕只是再走几户，每户十来分钟，当场记，比任何编出来的都稳。优先去独居老人、低保和残疾家庭、有孩子的困难家庭、新搬来的住户，这些检查组最关心，也最容易有话可说。

**2. 把你实际走访的那几户整理成规范记录。**
把每户的时间、对象、了解到的情况、有什么问题、怎么处理的随便发给我，哪怕是零碎的几句话，我帮你整理成像样的记录，该有的要素一个不缺。

**3. 写一段如实的情况说明。**
新到岗、本月入户X户、网格底数摸排到哪一步、下月怎么安排，真实的进展加明确的计划，检查组看到的是态度和路径，比一叠雷同的记录更站得住。你把真实数字告诉我，我来写。

## 走访记录该有的要素（空白模板，照着现场填）

| 项目 | 填写提示 |
|---|---|
| 走访日期、时间 | 具体到哪天几点，和你的实际行程对得上 |
| 走访地址 | 小区、楼栋、单元、房号 |
| 走访对象 | 姓名、与户主关系、家庭人口，身份证号等不必写全 |
| 走访方式 | 入户 / 电话 / 微信 / 线下偶遇 |
| 了解到的情况 | 家庭现状、身体和生活状况、居住和安全隐患等，写你看到、听到的 |
| 群众反映的问题或诉求 | 原话要点，没有就写"未反映问题" |
| 处理情况 | 当场解决 / 上报社区（对谁、何时）/ 转办哪个部门 |
| 后续跟进 | 谁、什么时候回访，办结后的结果 |
| 走访人、对象确认 | 走访人签名；条件允许时请对象签字确认 |

这些栏目要靠现场问出来：到了门口问什么，我也可以给你列一张"入户必问的几件事"，十来分钟就能问完。

需要哪一项，直接告诉我，或者把你实际走访的几户情况发过来。
