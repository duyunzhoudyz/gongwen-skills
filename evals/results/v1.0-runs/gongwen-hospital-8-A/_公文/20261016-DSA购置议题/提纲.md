# 关于购置数字减影血管造影机（DSA）的议题：提纲

文书：党委会议议题材料。一题一议，正文一般不超过2000字。
上会路径：属于“三重一大”事项，由党委会议研究决定；重要行政、业务工作按规定先由院长办公会议讨论通过，再提交党委会议（据本包资料，以本院议事规则为准）。
要点后标台账序号和计划字数。

页首（约60字）：汇报单位医学装备部；汇报人、分管副院长姓名【待补】；提交会议党委会议（台账1、18）

一、议题事由（约130字）
- 现有DSA 2台，2026年1—9月介入手术3860台，排队平均等待4.5天（台账2至4）
- 医学装备部提出再购置DSA 1台；属于“三重一大”事项，提请党委会议研究决定（台账1、17）

二、方案比较（约300字）
- 方案一：双C臂DSA，预算1280万元，可同时满足神经介入和外周介入（台账5、6）
- 方案二：单C臂DSA，预算760万元，主要满足心血管介入（台账7、8）
- 方案一预算比方案二多520万元（1280－760）；资金来源医院自有资金，财务部尚未出具测算（台账9至11）
- 预期效益、运行成本、风险：【待补】
- 医学装备部倾向方案一，理由【待补】（台账12）

三、前置程序履行情况（约450字）
（一）已履行：分管副院长已同意（台账13）
（二）尚未履行：医疗设备管理委员会尚未论证（台账15）；财务部尚未出具测算（台账11）
（三）履行情况待确认：院长办公会议讨论；会签、法务审查、使用科室意见；上级审批或备案（台账19、20）
（四）需要会议知悉的情况：9月份党政联席会议曾讨论，原则同意，不替代院长办公会议和党委会议（台账14）；科室已与厂家签订意向书，先于论证、测算和会议决定（台账16）

四、提请会议决定的事项（约100字）
- 同意购置双C臂DSA 1台，预算不超过1280万元，资金来源医院自有资金，医学装备部组织实施，装机时限【待补】（台账1、6、10）
