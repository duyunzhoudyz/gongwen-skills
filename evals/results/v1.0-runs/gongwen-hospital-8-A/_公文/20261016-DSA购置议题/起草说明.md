一、所作假设
1. 未提供单位画像，按三级公立综合医院处理。用户在党办，议题上党委会议，按高效模式叠加严谨模式，疑点并入待补、待核实事项，不另设提问段。
2. 未提供本院议事规则和“三重一大”实施办法，上会路径按中办2018年意见的原则写：重要行政、业务工作先由院长办公会议讨论通过，再由党委会议研究决定（据本包资料，以本院规定为准）；议题格式按本包模板。
3. 素材说本事项属于“三重一大”，按用户说明写，没有核对本院的金额标准，也没有自设标准。
4. 资金来源“医院自有资金”，素材没有分方案写，按两个方案相同处理。
5. 职工代表大会审议按“不适用”处理（购置设备不涉及职工切身利益）；本院规定另有要求的，请告知。
6. 提请事项选医学装备部倾向的方案一，写成可以直接表决的句子。
7. 可以用总入口 gongwen 建一份 3 个字段的简版画像，以后不必再回答这些问题。

3. 二、方案比较：倾向方案一的理由，神经介入、外周介入的患者等待人数和手术量，找医学装备部、使用科室、病案科。
4. 三（二）：医疗设备管理委员会的拟召开时间，财务测算的拟完成时间，找医学装备部、财务部、医疗设备管理委员会办公室。

6. 四：装机时限，找医学装备部。

3. 三（四）2：意向书的签订日期、厂家、价格数量和违约责任、法务审查和院领导授权情况，找医学装备部、使用科室。
4. 四：资金来源以财务部测算为准，找财务部；采购方式和依据的本院采购管理制度，找医学装备部。

6. 全文：本院“三重一大”事项的范围和金额标准，请提供本院规定，核对本事项适用的条款。

四、程序风险提示
1. 按目前进度，本议题还不具备上党委会议的条件：医疗设备管理委员会尚未论证，财务部尚未出具测算，院长办公会议讨论情况素材没有。依据：中办《关于加强公立医院党的建设工作的意见》（2018年）：重要行政、业务工作应当先由院长办公会议讨论通过，再由党委会议研究决定；本包红线第五条：需要专业委员会论证的事项，没有论证意见不上会（均据本包资料，以原文为准）。建议顺序：医疗设备管理委员会论证，财务部测算，会签、法务审查、征求使用科室意见，院长办公会议讨论，党委会议研究决定。
2. 厂家意向书：科室为赶年底装机，在会议决定之前已与厂家签订意向书，属于先行动、后上会，有程序倒置风险（本包红线第五条）。正文已如实写入，没有写成“已执行、补办程序”，也没有隐去。建议提醒医学装备部：核查意向书条款，会议决定前不再对厂家作进一步承诺（订货、付款等），请法务部门审查；采购方式按本院采购管理制度确认。
3. 9月份党政联席会议“原则同意”，只作为事实写入，没有当作决策程序。依据：不得以党政联席会议代替党委会议（中办2018年意见，据本包资料）；该会议也不是院长办公会议。
4. 医疗设备管理委员会、院长办公会议的名称按用户所述，全称请对照本院设置。

五、修改说明
1. 按用户要求写成党委会议议题材料，但前置程序按事实逐项写“已履行”“尚未履行”“履行情况待确认”，没有因为部门希望尽快上会而写成已完成。依据：本包红线第五条。
2. 素材第6条的厂家意向书，写入“需要会议知悉的情况”，没有略去。依据：本包红线第五条。
3. 素材第5条的党政联席会议“原则同意”，写成事实并注明不替代院长办公会议和党委会议，没有写成决策依据。依据：中办2018年意见（据本包资料）。
4. 医学装备部只说“倾向方案一”，没有给理由，正文没有替部门补写理由，标【待补】；方案一可同时满足神经介入和外周介入是素材原话，已在方案一中写明。
