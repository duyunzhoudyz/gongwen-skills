台账存在的问题：

**整体**
1. 整改状态没有统一口径：出现“已完成”“基本完成”“长期坚持”，“基本完成”“长期坚持”都不是可销号的状态，应统一为“已完成/整改中/未完成/长期坚持（已阶段性完成）”之类的固定选项。
2. 佐证材料4条中只有2条有，且都不充分：第2条、第3条为空。
3. 责任部门一栏填写不规范：有的是岗位（社区民政专干）、有的是社区自身（社区居委会、社区党委）、有的空缺，没有具体到科室或人。
4. 缺少问题来源和反馈时间、整改启动时间、销号时间、验收人等信息，无法对账销号。
5. 一次性整改与长期机制混在同一条里，状态无法如实反映。

**第1条（低保）**
1. 措施“报街道民政办停发”只是上报，成效标准“3户停发”，佐证只有“民政办回复”，没有停发文件或系统记录，证明力不够。
2. 状态“已完成”，但“每季度复核”是长期措施，尚未发生，不应整条标为已完成。
3. 没有涉及已多领低保金的追缴或处理意见，也没有对其他低保户的排查（举一反三）。
4. 责任部门“社区民政专干”是岗位，不是部门。

**第2条（走访记录）**
1. 责任部门空缺。
2. 状态“基本完成”，但佐证为空，时限（10月31日）未到，不能确认。
3. 措施“补齐走访记录”表述有歧义：是补走访，还是补记录？补记录有造假风险，应写明补走访并入户核实。
4. 只整改了抽查的7户，未排查其余户，也没有走访记录管理的长效措施。
5. 成效标准“7户补齐”只是数量，没有质量要求。

**第3条（活动室）**
1. 完成时限为10月15日，已过期（今天10月16日）；状态为“已完成”，但佐证为空。
2. 问题表现过于笼统：谁占用、占用多久、占用面积、有无违规，均未写。
3. 责任部门“社区居委会”就是社区本身，不具体；责任领导与责任部门的层级不对应。
4. 只有清理，没有对占用人的处理意见，也没有防止再次占用的管理制度。
5. 成效标准“活动室恢复开放”不可量化（开放时间、对谁开放）。

**第4条（微信群）**
1. 完成时限“长期”，不是具体日期，无法考核。
2. 状态“长期坚持”不是状态；“建立通知审核制度”这一次性动作应单列、写明完成日期。
3. 问题表现“不当表述”过于模糊：什么内容、谁发布、影响范围。
4. 没有对发布人的处理意见。
5. 成效标准“通知经书记审核后发布”是流程，不是成效；且责任领导（书记）与审核人是同一人，缺少监督。
6. 佐证只有更正截图，缺少审核制度文件。
7. 责任部门“社区党委”与责任领导“社区书记”重叠。
