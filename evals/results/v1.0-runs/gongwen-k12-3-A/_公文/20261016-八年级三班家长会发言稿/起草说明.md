【起草说明】

一、所作假设

1. 任务卡：

```text
任务卡
文书：家长会班主任发言稿（本班家长）
写作方和学段：某初中八年级三班班主任，义务教育
读者和用途：本班家长，下周四晚上线下家长会上口头讲
篇幅：15 分钟，约 3000 字（每分钟 200 字）；素材可支撑约 850 字（预估）
角色模式：教学模式
```

2. 未提供单位画像，按中小学（初中，八年级，义务教育阶段）处理。
3. 您说第一次开家长会，还要我讲为什么这样写，所以按教学模式处理，写作要点见本说明最后一部分。
4. 按线下家长会、班主任对本班家长讲话处理；“15 分钟”指发言本身，不含家长提问的时间。
5. 篇幅：每分钟约 200 字，15 分钟约 3000 字，±10% 为 2700～3300 字。成稿 835 字（含标点和标题，不含【待补】【待核实】标记），约 4 分钟的量，与目标相差七成以上。原因是材料只有六条；没有用空话和套话凑字数，开场、班级情况、下阶段安排、请家长配合的事、沟通渠道和结尾五个部分都保留了，缺内容的地方写了【待补】，补齐后可以到 3000 字左右。
6. 家长会时间您只说了“下周四晚上”，发言稿里没有用到日期。如要在开场里说具体日期，请直接写具体日期，我没有推算。
7. 就寝时间等需要您或学校来定的标准，没有替您写数字。
8. 写作要点里引用的文件和条款来自工具内置资料，请核对原文。
9. 可以用总入口 gongwen 建一份 3 个字段的简版画像，以后不必再回答这些问题。

二、待补事项（正文共 7 处，按出现顺序；写明补什么、一般到哪里找）

1. 开场：班主任的姓氏、任教学科和一两句自我介绍。您自己定，简短即可。
2. 班级情况：物理、英语两位新任课老师的简要介绍，以及学校和班级帮助孩子适应新老师的做法。可问教务处、年级组和两位老师本人。
3. 班级情况：运动会上班级参加的项目，以及一两个不点名的具体事例。可问体育委员、体育老师，或看班会记录。
4. 班级情况：期中考试后，班级整体在学习习惯和各学科上的具体变化，以及班级针对这一情况实际做了哪些事。可问各科老师，或看您自己的工作记录；只写实际做过的，如谈话、座位调整、错题讲评等，没做的不写。
5. 下阶段安排：时间节点和重要活动，如期末考试的时间、学校和班级的活动。以学校校历和教务处通知为准，不要自己推算。
6. 家长配合：建议的就寝时间。由您或年级组确定；如果要引用对学生睡眠时间的规定，请先对照学校或教育部门的文件，我没有写。
7. 结尾：会后个别交流的安排，以及班主任的联系方式和联系时间。您自己定。

三、待核实事项

1. “期中考试的整体成绩比上学期退步了”：材料里写了期中考试的班级均分和年级名次，并说“比上学期退步”，但没有说退步的是均分，还是年级位次。正文按“整体成绩比上学期退步了”写，没有写均分和名次，请核对后调整说法。

四、修改说明

1. 期中考试的班级均分和年级名次没有写进发言稿。义务教育学校考试结果实行等级评价，不排名、不公布（教基厅函〔2021〕34号；教基厅〔2025〕3号第14条），家长会不公布考试分数和名次。
2. 材料里的“有几个孩子迷手机”，写成“手机玩得比较多，晚上睡得比较晚”，不点名，也不用“迷”这类带标签的词。
3. 运动会“年级团体第二”是比赛名次，不是考试排名，可以写，已写入。
4. 机检：k12_check parents 查出 P0 0 条、P1 0 条、P2 0 条（第一稿有一句“分数和名次我不在这里说”被误判为公布成绩，已改写）；gongwen_lint（文书类型：讲话稿）P0 0 处、P1 0 处、P2 8 处，均为待补和待核实标记；fact_diff 台账对账，正文里的事实数字都能在素材台账中找到，没有对上的只有“第一件、第二件、三件事、两件事、第二天”这类序数和列举数。

五、写作要点

1. 为什么这样搭结构。家长只听一遍，没法回头看，所以开场就说“今天说三件事”，后面每一部分只讲一件事。顺序是先说班里的情况，再说下阶段安排，最后说请家长做的事：前面的情况是铺垫，家长听明白班里发生了什么，才知道为什么要配合。15 分钟大致的时间分配是：开场 1 分钟，班级情况 5 分钟，下阶段安排 2 分钟，请家长配合的事 5 分钟，沟通渠道和结尾 2 分钟。
2. 为什么不写期中考试的分数和名次。义务教育学校考试结果实行等级评价，不排名、不公布（教基厅函〔2021〕34号；教基厅〔2025〕3号第14条），在家长会上讲分数名次，容易让家长拿孩子互相比较，也不符合规定。所以只讲“整体成绩比上学期退步了”，再把话题转到学习的状态和习惯。把退步直接说出来，是因为家长迟早会从孩子那里知道，班主任先开口，更容易赢得信任。
3. 为什么请家长配合的事只写手机和睡眠两件，而且不涉及作业。家长会上请家长做的事，应写生活和陪伴类的内容，如作息、手机使用，不能让家长检查、批改作业，也不能布置打卡任务（双减意见第4条，2021年）。模板建议写 3～5 件，您的材料里只有两件，我没有凑数；还有想请家长配合的事，可以补进来。每件事都按“做什么、怎么做、为什么”讲，把理由放在最后，家长明白了原因，才愿意照做。“怎么做”里的几条（约定使用时间和地方、睡前手机离开床边、大人少刷手机、孩子做到了夸一夸），是我按常见做法拟写的，不是学校规定，您可以按对家长的实际要求增减。
4. 为什么不点名。手机玩得多的孩子，只说“有几个孩子”，不说是谁。当众点名会伤孩子的自尊，也不符合尊重未成年人人格尊严的要求（未成年人保护法第四条）；个别孩子的情况，会后单独沟通更有效。
5. 为什么有这么多待补。讲话人已经做过的事、承诺要做的事，只能来自您提供的材料，我不替您编。需要写“我已经做了什么”的地方，请按待补事项补上真实做过的事。
6. 几处措辞的用意：
   - “我不点名，也不是要批评哪个孩子，更不是要指责哪位家长”：先放下家长的防备，再提要求。
   - “为什么要请大家管一管手机？”：用设问带出理由，口头讲话时比直接讲道理更容易听进去。
   - “咱们班”“孩子们”：新班主任第一次见家长，口气亲近一些。
