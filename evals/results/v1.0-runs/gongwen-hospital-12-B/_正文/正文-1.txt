某医院关于市卫生健康委院感专项检查反馈问题的整改方案

为认真落实市卫生健康委医院感染管理专项检查反馈意见，切实消除医院感染管理隐患，保障医疗安全，结合医院实际，制定本方案。

一、总体要求
坚持问题导向，做到立查立改、举一反三、建章立制。对检查反馈的8个问题逐项建立台账，明确措施、责任科室、完成时限和验收标准，实行销号管理。能够立即整改的，立即整改到位；需要一定周期的，明确时间节点，11月10日前形成整改情况报告上报市卫生健康委；需要长期坚持的，建立长效机制持续落实。

二、组织领导
成立院感专项检查整改工作领导小组。
组　长：【院长】
副组长：【分管副院长】
成　员：院感科、护理部、医务科、总务科、人事科、科教科、设备科及ICU、骨科、内镜中心、口腔科、血液透析室等相关科室负责人。
领导小组办公室设在院感科，负责整改工作的日常调度、督查和台账管理，每周汇总一次整改进展。

三、整改措施
（一）问题1：ICU、骨科手卫生依从率低于60%，速干手消毒剂配置不足
1. 整改目标：手卫生设施配置到位，依从率达到规范和上级质控要求（目标值：【院感科确认】）。
2. 整改措施：（1）已采购的速干手消毒剂，于10月底前配发到ICU、骨科每张床旁、治疗车和医护通道，并核对配置数量是否满足规范要求；（2）院感科和护理部对ICU、骨科医务人员开展手卫生专项培训和现场考核；（3）院感科每周对两个科室手卫生依从率进行现场观察，结果公示，连续观察4周；（4）依从率不达标的科室，对科主任、护士长进行约谈；（5）举一反三，对全院其他重点科室开展手卫生设施和依从率排查。
3. 责任科室：院感科、护理部、ICU、骨科、总务科（物资）。
4. 完成时限：10月底前配发到位；11月5日前完成依从率复测。
5. 验收标准：配置到位记录齐全；复测依从率达到目标值。

（二）问题2：内镜中心软式内镜清洗消毒记录不完整，部分批次缺少生物监测记录
1. 整改目标：每条内镜的使用、清洗、消毒、储存全程可追溯，监测按规范频次开展。
2. 整改措施：（1）已补齐9月份清洗消毒记录，并核查检查所涉时段内其余记录的完整情况；对确实无法追溯补做的记录和监测，如实说明，不得补造；（2）自10月起每周开展生物监测，监测结果由内镜中心和院感科双签；（3）内镜中心专人负责记录核对，院感科每月检查，发现缺失立即纠正；（4）组织内镜中心人员学习《软式内镜清洗消毒技术规范》，并考核。
3. 责任科室：内镜中心、院感科。
4. 完成时限：10月底前完成记录核查及人员培训；监测持续执行。
5. 验收标准：抽查记录完整，监测记录连续，无缺项。

（三）问题3：医疗废物暂存间未上锁，交接登记缺失3天
1. 整改目标：医疗废物暂存管理规范，交接登记完整。
2. 整改措施：（1）已对暂存间上锁，已补登缺失的交接登记（补登须据实，注明补记日期，不得倒签）；（2）明确暂存间专人负责，钥匙或门禁实行专人管理；（3）实行医疗废物“日交接、日登记、双人签字”；（4）院感科和总务科每周巡查暂存间，发现问题立即整改；（5）对医疗废物收集、转运人员开展培训。
3. 责任科室：总务科、院感科。
4. 完成时限：已整改；制度和培训10月底前完成；巡查持续执行。
5. 验收标准：暂存间上锁，交接登记连续完整，巡查有记录。

（四）问题4：多重耐药菌感染患者未落实单间隔离或床旁隔离标识
1. 整改目标：多重耐药菌感染患者100%落实单间隔离或床旁隔离，标识齐全。
2. 整改措施：（1）已发文要求各科落实，院感科对各科落实情况开展督查，核对隔离措施和标识；（2）检出多重耐药菌后，由检验科及时通报临床科室和院感科，临床科室即时落实隔离；（3）为各临床科室配备统一的接触隔离标识和防护用品；（4）院感科每周督查并记录，督查结果纳入科室考核；（5）开展多重耐药菌防控专题培训。
3. 责任科室：院感科、检验科、各临床科室。
4. 完成时限：10月底前完成首轮督查；督查持续执行。
5. 验收标准：督查中应隔离患者隔离措施和标识落实率达到100%。

（五）问题5：新入职人员院感培训覆盖率不足，未见考核记录
1. 整改目标：新入职人员院感培训和考核全覆盖，档案完整。
2. 整改措施：（1）梳理本年度新入职人员名单，对未培训人员10月底前补训，补训后组织考核；（2）已安排11月开展全员院感培训，培训后统一考核；（3）建立院感培训考核档案，记录培训时间、内容、考核成绩；（4）将院感培训纳入新入职人员岗前培训必修内容，未通过考核不得独立上岗。
3. 责任科室：科教科、院感科、人事科。
4. 完成时限：新入职人员补训考核10月底前；全员培训11月底前（须确定具体日期并在11月10日前报告安排）。
5. 验收标准：新入职人员培训覆盖率100%，考核记录齐全。

（六）问题6：口腔科器械未按规定进行灭菌效果监测
1. 整改目标：口腔器械灭菌效果监测规范开展，记录完整。
2. 整改措施：（1）已整改完成，整理开展监测的记录作为佐证；（2）按规范频次持续开展灭菌效果监测，保留原始记录；（3）院感科每月抽查。
3. 责任科室：口腔科、院感科。
4. 完成时限：已整改；监测持续执行。
5. 验收标准：监测记录完整连续，院感科抽查合格。

（七）问题7：血液透析室未开展透析用水细菌学监测
1. 整改目标：透析用水细菌学监测规范开展，结果合格。
2. 整改措施：（1）已联系第三方检测机构，原定11月第一周采样，尽可能提前，最迟不晚于11月6日；（2）收到结果后，院感科和血液透析室评估，不合格的，立即查找原因并整改、复测；（3）制定透析用水定期监测制度，按《血液净化标准操作规程》要求的频次持续监测，监测结果存档；（4）水处理系统定期维护消毒。
3. 责任科室：血液透析室、院感科、设备科。
4. 完成时限：11月6日前完成采样；检测报告出具后5个工作日内完成结果评估；监测制度10月底前制定。
5. 验收标准：检测结果合格，监测制度和记录齐全。

（八）问题8：院感科专职人员配备不足
1. 整改目标：专职人员配备符合《医院感染管理办法》规定的比例。
2. 整改措施：（1）人事科根据医院床位数【　】张，对照规定测算专职人员缺口；（2）提出配备方案（增编、招聘或内部调剂），10月底前报院领导审议；（3）明确到岗时间，人员未到位前，由医院安排临时人员支持院感科日常工作。
3. 责任科室：人事科、院感科。
4. 完成时限：10月底前提出方案；11月10日前明确到岗时间，12月底前人员到位。
5. 验收标准：专职人员数量达到规定要求。

四、长效机制
（一）周调度。领导小组办公室每周汇总整改进展，对滞后事项提出督办。
（二）督导复查。院感科对已整改事项定期复查，防止问题反弹。
（三）考核挂钩。将整改成效纳入科室质控和绩效考核。
（四）举一反三。对手卫生、内镜、医疗废物、多重耐药菌防控、器械灭菌监测等工作，开展全院自查，发现同类问题一并整改。
（五）建章立制。对整改中暴露出的制度缺位，及时修订完善院感管理制度和操作流程。

五、时间安排
（一）10月中旬至10月底：落实各项整改措施，完成培训，形成人员配备方案。
（二）11月1日至11月9日：开展复查验收，完成透析用水采样，汇总整改材料。
（三）11月10日前：形成整改情况报告，连同整改台账报送市卫生健康委。
