# 起草说明：网格入户走访提纲和空白记录表

## 任务卡

- 文书：网格入户走访提纲＋空白走访记录表（“编10份走访记录”的要求没有照办，原因见下）
- 发文主体：某社区（网格员个人使用）
- 对象：辖区住户
- 用途：入户走访、迎接街道检查
- 篇幅：提纲约1页，记录表1页（可多份打印）
- 素材可支撑字数：不适用（没有任何一次已发生的走访情况）
- 角色模式：教学模式

## 一、所作假设

1. 没有收到社区的基本情况介绍，单位按社区处理；你说自己是新来的网格员，按教学模式写，说明里多讲“为什么”。
2. 走访目的你没说，按常规入户走访写通用提纲，另附独居老人关爱、电动自行车充电安全两个可选加项。
3. 提纲里要告知的政策、回复时限、服务项目，你都没有提供，一律留【待补】，没有自拟。
4. “明天”检查的具体日期没有推算，没有写进任何文件。

## 二、待补事项

1. 本月实际走访的每一户：日期、楼栋（户别代号）、在家人员的称呼、了解到的情况、当场办了什么或转给了谁。一般到手机备忘录、微信工作群记录、纸质笔记、通话记录里找；前任网格员或同事留下的原始记录也可以，要注明是谁走访的。
2. 街道对走访的要求：每月走访多少户、多久走一轮、记录用什么格式。一般到街道下发的网格管理办法、考核办法或这次检查通知里找，或问社区网格负责人。
3. 本次要告知居民的政策：一般到社区或街道下发的通知里找。
4. 诉求的回复时限，以及你能当场办和要转办的事项范围：问社区网格负责人。
5. 本网格的名称、楼栋范围和户别代号的编法：一般在社区的网格底册里。
6. 本社区实际能提供的服务项目（助餐、上门服务等）：问社区工作人员。

## 三、待核实事项

1. “只走访了几户”是概数，具体户数需要你按记录点清。
2. 检查的具体日期和检查范围（你只说了“明天”“检查网格工作”）。

## 四、修改说明

1. 没有照办“帮我编10份走访记录”。问题类型：编造记录。依据：实务——走访记录必须来自真实走访；记录里写的每一句居民说了什么、看到了什么，检查组都可以通过回访居民、核对住户和时间来验证，编出来的经不起核对，一旦被查实属于弄虚作假，追责的是签名的走访人。
2. 改为提供提纲和空白记录表，并请你把真实走访过的情况发来再整理。整理时只记你说的，没说的留空标“待补”，不加处理结果。
3. 提纲中的政策内容、回复时限、服务项目没有写。问题类型：事实来源。依据：事实只来自用户，缺的标【待补】。

## 五、保密提示

1. 本次没有收到材料。以后发走访情况给我时，居民的姓名、电话、门牌请先改成“张某”“138****0000”“3号楼”，病情不用写。
2. 记录表上的居民签字栏请本人签，不要代签；户别用编号，一页只记一户。

## 六、写作要点（教学模式）

1. 为什么“像”编不出来：一份让人信服的走访记录，靠的是只有去过才知道的细节——谁在家、居民的原话、你当场做了什么、转给了谁、什么时候转的。这些细节编出来的版本，对不上居民本人的说法，也对不上你当天的行程。真记录“像”的地方恰恰是这些。
2. 记事实，不记评价。误：该户思想觉悟低，不配合工作。正：户主表示白天上班，希望改在晚上7点以后登记。
3. 诉求记原话、加引号；承诺只在职权范围内，写清时限，办不了的写“已记录，报社区研究”。
4. 新来的网格员向检查组说明，如实讲清楚到岗时间、实际走访了几户、发现了什么问题、办了什么；只讲已经做的，计划只讲真实有的。比起一叠经不起核对的记录，如实说明对你更稳妥。
