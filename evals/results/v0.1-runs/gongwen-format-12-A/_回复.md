这份材料带有密级标识，我在这里停止处理：不排版，也不复述、不摘录其中任何内容。

涉密信息不得输入联网 AI 工具。带密级标识的国家秘密，只能在经批准的涉密信息系统中处理，排版也要在单位内网的涉密环境里完成。这次已经发出的材料，请按单位保密管理规定处理；需要报告的，及时联系单位保密部门。

急着报市委，可以在内网自己排：

1. 内网电脑有 Python（python-docx 1.2.0 以上）的，按单位规定经审批后，把本 skill 的 scripts、assets 目录拷进内网，运行：
   python scripts/build_docx.py 正文.txt --meta 版式信息.json --layout 红头
   版式信息.json 里填这几项：
   - 发文机关标志、发文字号；
   - 签发人：报告是上行文，红头必须标签发人（GB/T 9704-2012 7.2.6）；
   - 密级、保密期限：按原件填写；
   - 份号：涉密公文应当标注份号（《党政机关公文处理工作条例》第九条）；
   - 紧急程度：需要标时写“特急”或“加急”。
   生成后运行 python scripts/check_docx.py 成稿.docx，P0 为 0 再送签。
2. 内网电脑没有 Python 的，按本 skill 的 references/manual-setup.md 在 WPS 或 Word 里手动设置页面、字体、版头和版记，打印核对。

属于下面任一情况的，告诉我后可以继续处理：
1. 现在用的是单位内网部署、经批准可以处理这类材料的系统；
2. 已经删除涉密内容，发来的是可以在外网处理的版本；
3. 密级标识是误加的，或者材料已经解密公开。
