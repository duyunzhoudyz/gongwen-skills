# 提纲与标题备选：某学院2026年工作总结

## 任务卡

```text
任务卡
材料类型：年度总结（学院，单位年度总结）
写给谁：学校；党建部分同时报学校党委组织部
用途和场合：书面报送，不上会宣读
篇幅：单位年度总结一般3000～4000字；按现有素材预计约1500字（见文末说明）
截止时间：未说明
单位画像：高校（无画像，按用户所述）
角色模式：严谨模式（"提法一定要准""报学校党委组织部"）
工作模式：新写模式
```

## 标题备选

1. 平实式：某学院2026年工作总结
2. 主副标题式：新增国家级项目4项　引进博士7人
   ——某学院2026年工作总结

## 结构说明

采用总结三段式：主要工作和成效、存在的问题、2027年工作打算。主要工作按高校学院总结的常用板块组织，党建思政放在第一部分，便于单独摘出报学校党委组织部；学校通知规定了栏目和顺序的，按通知调整。

## 提纲

开头：2026年学院主要工作的总体情况一两句，引出下文（台账3、4、9、10、12，约100字）

一、主要工作和成效

（一）抓好理论学习中心组学习和基层党组织建设（台账1、2，约250字）
- 中心组学习10次；学习主题和提法只用学校党委文件原文，没有原文的标【待核实：请对照最新原文】。
- 获评学校"先进基层党组织"，加【待核实：表彰文件名称和文号】。
- 支部建设、党员发展、意识形态工作等具体做法，素材未提供，标【待补】。

（二）完成本研招生，做好毕业生就业（台账3、4、5、6，约200字）
- 招收本科生312人、硕士研究生86人。
- 就业去向落实率：两个口径不一致，拟用学校就业中心口径89.7%，并写明届别和截止日期，待您确认。

（三）组织某某学科参加学科评估（台账7、8，约100字）
- 只写已参评，结果未公布，不写结果和预判。

（四）承担各级科研项目，落实科研经费到账（台账9、10、11，约200字）
- 新增国家级项目4项、省部级项目11项，到账科研经费2368万元；代表性项目和成果标【待补】。

（五）引进青年博士，充实师资队伍（台账12、13，约150字）
- 引进博士7人；1名教师入选省级人才计划，加【待核实：人才计划名称和入选文件】。

二、存在的问题（约250字）

（一）实验室用房紧张（台账14）：照写，后加【待补：具体表现或影响】。
（二）青年教师科研启动经费不足（台账15）：照写，后加【待补：具体表现或影响】。

三、2027年工作打算（约300字）

（一）针对实验室用房紧张问题，【待补：具体措施】（台账14）
（二）针对青年教师科研启动经费不足问题，【待补：具体措施】（台账15）
（三）研究论证新增本科专业申报（台账16）：写"学院正在论证，拟于2027年申报"，不写成已定。

## 篇幅说明

单位年度总结一般3000～4000字（工具约定）。现有材料共16条，按实写约1500字；高校内部材料不受《整治形式主义为基层减负若干规定》第2条字数条款直接约束。补齐素材台账"缺口清单"中党建、人才培养、科研成果和问题措施几项后，可以写到3000字左右，不靠铺垫凑字数。
