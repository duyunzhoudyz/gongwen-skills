# 基层报表负担调研：调研提纲和调研报告框架

本文件分两部分：第一部分是下周调研用的调研提纲，现在就可以报领导看；第二部分是调研报告的框架，调研结束后按调研记录填写成稿。框架中不预填任何调研发现和结论。

## 第一部分　调研提纲

关于基层报表负担情况的调研提纲

一、调研目的

弄清3个乡镇目前需要填报的报表有哪些、来自哪里、多久报一次、怎么填、要花多少时间，了解是否存在重复填报、多头报送、时限过紧等情况，为领导研究减轻基层报表负担提供依据。【待补：领导交办时的原话或具体要求，有的话以原话为准】

二、调研对象

1. 乡镇：【待补：3个乡镇名称】。
2. 每个乡镇约谈三类人员：
（1）分管报表工作的乡镇领导或党政办负责人；
（2）负责填报报表的一线干部（党政办和各站所，按报表多的岗位选，每镇【待补：人数】人）；
（3）村（社区）干部（报表需要村里提供数据的，每镇【待补：人数】人）。
3. 县直部门（可选，时间允许时）：向乡镇发报表较多的【待补：部门名称】，了解报表依据和数据能否共享。

三、调研方式

1. 座谈：每个乡镇1场，乡镇领导、党政办和站所干部参加。
2. 个别访谈：与一线填报人员、村（社区）干部单独谈，每人约【待补：时长】分钟。
3. 调阅资料：调阅乡镇已有的收文登记、报表通知和报送记录，不要求乡镇专门为调研制表或写汇报材料。
4. 问卷（可选）：需要更大样本时再定，问卷内容另行设计。

四、时间安排

【待补：下周具体日期，每个乡镇半天还是一天，带队领导和调研组成员】

五、调研问题

（一）面向乡镇领导、党政办负责人

1. 目前乡镇需要定期填报的报表有多少种？能否提供一份清单（报表名称、发起部门、频次、报送方式）？
2. 这些报表中，按月、按季、按年和临时要求的各有多少？
3. 近一两年报表数量有哪些变化？
4. 乡镇内部报表工作由谁牵头、怎么分工？
5. 目前有没有报表整合、数据共享的做法（如“一表通”之类）？实际用下来怎样？
6. 对县里在报表管理上有什么具体建议？

（二）面向一线填报人员

1. 您负责哪几张报表？一张报表从接到通知到报出，一般要花多长时间？
2. 填报的数据从哪里来：业务系统导出、手工统计，还是向村里要？
3. 有没有同一类数据要报给不同部门，或在不同系统里重复录入的情况？请举最近的一个例子。
4. 填一张报表，哪个环节最费时间？
5. 最近一次遇到的最短报送时限是多长？是什么报表？
6. 您认为哪些报表可以合并，或者可以从系统直接取数？

（三）面向村（社区）干部

1. 村里需要定期向乡镇提供哪些数据或表格？多久一次？
2. 同样的数据，有没有被不同人、不同时间多次要过？请举个例子。
3. 准备这些数据，每月大概要花多少时间？

（四）面向县直部门（可选）

1. 本部门要求乡镇报送哪些报表？依据是什么文件或制度？
2. 这些数据中，哪些可以从现有系统获取，或与其他部门共享？

六、需要收集的数据和资料

1. 每个乡镇【待补：统计时段，如2026年1—9月】收到的报表通知清单：报表名称、发起部门、频次、报送方式（纸质、系统、微信等）、报送时限。从乡镇收文登记和报表通知中整理，不另行要求乡镇制表。
2. 一线人员用于报表的时间：访谈中记录，注明是受访者本人估计。
3. 重复填报、多头报送的具体例子：报表名称、涉及部门、重复的数据项。
4. 乡镇需要登录的填报系统、平台清单。
