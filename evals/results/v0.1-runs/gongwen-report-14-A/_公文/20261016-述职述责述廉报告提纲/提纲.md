# 述职述责述廉报告：提纲和填写指引

本稿只出提纲和填写指引，不生成完整正文。原因：述职述责述廉报告须体现本人真实经历，用户尚未提供本人事例（`references/_shared/guardrails.md` 第六条第4款）。

## 所作假设

1. 未提供单位画像，按用户所述"某区某局"处理，单位类型为基层（县区部门）。
2. 材料为述职述责述廉，按严谨模式处理：政治性提法只用用户提供的通知原文，没有原文的成稿时标【待核实：请对照最新原文】。
3. 未提供区委组织部、区纪委监委的述职通知，栏目按通用的德、能、勤、绩、廉加述责组织（《中华人民共和国公务员法》第三十五条规定考核德、能、勤、绩、廉）；收到通知后按通知栏目调整。
4. 未说明书面报送还是现场述职，篇幅暂按书面述职，述职述责述廉合并不超过3500字（工具约定）；现场述职按约200字/分钟换算。

## 标题备选

1. 【待补：区名】【待补：局名】副局长【待补：姓名】2026年度述职述责述廉报告
2. 按通知规定的标题格式（有通知时以通知为准）

## 提纲

称谓：按述职会议对象，如"各位领导、同志们："（书面报送可省）

开头：任职时间、岗位、分管财务和后勤工作及分管科室（约150字）

一、政治素质和思想作风（德）（约300字）

二、履职能力（能）（约250字）

三、工作作风和勤勉敬业（勤）（约200字）

四、主要工作实绩（绩）（约1500字，占全文一半以上）
（一）财务管理方面：本人牵头或主办的事项，每件写本人角色、做法、结果数据
（二）后勤保障方面：同上
（合计3～5件，按实际分配，哪一方面没有事例就不设该小标题）

五、履行管党治党责任情况（述责）（约350字）

六、廉洁自律情况（廉）（约250字）

七、存在的不足（约200字）

八、下一步努力方向（约200字，与第七部分逐条对应）

结尾：以上述职，请予评议。

合计约3200字。

## 填写指引

句式中的"____"由本人填写，填不出的那一项就不写，不用套话补。"可以从这些方面想"只是帮助回忆的提示，没做过的不写。

| 部分 | 需要本人提供的事实 | 句式示例 | 可以从这些方面想 |
|---|---|---|---|
| 开头 | 任职起始时间；分管的科室名称；分管工作范围 | 本人自____年____月起任____局副局长，分管财务和后勤工作，联系____科、____科。 | 是否还有协管、联系的其他工作 |
| 德 | 参加了哪些学习（名称、次数）；讲过的党课或作过的辅导（题目、时间）；写过的学习体会 | 全年参加局党组理论学习中心组学习____次，围绕____在分管科室讲党课（作辅导）____次。 | 中心组学习、支部学习、专题培训、讲党课 |
| 能 | 解决过的一两件难题；新掌握的业务；参加的培训或取得的证书 | 针对____问题，本人____（做法），____（结果）。 | 财务、采购、资产管理方面遇到的棘手事项；新出台制度的学习运用 |
| 勤 | 出勤、加班、值班情况；牵头完成的急难任务（时间、事项、结果） | ____期间，本人____（承担的任务），____（结果）。 | 预决算编制、审计迎检、节假日值班、应急保障 |
| 绩 | 3～5件本人牵头或主办的工作：事项、本人角色、做法、结果数据 | 本人牵头____，通过____（做法），____（数据结果）。 | 财务：部门预算编制和执行进度、一般性支出和"三公"经费管控、政府采购、内部控制制度建设、财政或审计检查问题整改、往来款清理。后勤：办公用房管理、公务用车管理、机关食堂、安全保卫和消防、节约型机关建设、维修改造项目 |
| 述责 | 落实"一岗双责"的具体动作：主持研究分管领域党风廉政建设的次数；对分管科室负责人的谈话人次；排查的廉政风险点和防控措施；检查发现问题的整改结果 | 全年主持研究分管领域党风廉政建设工作____次，对分管科室负责人开展谈话____人次，排查____环节廉政风险点____个，制定____（防控措施）。 | 资金审批、政府采购、资产处置、公车和办公用房使用等环节；审计、巡察、财政检查指出的分管领域问题 |
| 廉 | 遵守廉洁规定的具体做法；个人有关事项报告情况；由本人确认的表态 | 本人按规定报告个人有关事项____（本人确认后填写）。 | 本人公务用车、办公用房、公务接待执行标准的情况；对亲属和身边工作人员的要求 |
| 不足 | 本人真实存在的1～3个不足，最好有具体事例 | 在____工作中，____（具体表现），导致____。 | 哪项指标没完成；哪项工作比计划晚；上级检查指出过分管领域什么问题 |
| 努力方向 | 与上面不足逐条对应的改进做法 | 针对____，2027年将____。 | 与"不足"一一对应，每条写做什么、何时完成 |

## 提醒

1. "绩"是重点，写本人做的事，与局里整体成绩分开。局里的成绩可以引用，但要写清本人在其中做了什么，例如"在局党组集体研究下，本人负责……"。
2. 不足写本人的具体不足，"对自己要求过高""工作过于投入"属于变相表扬，不用。
3. 廉洁部分的表态（如"严格遵守……规定"）由本人确认后再写进正文，起草时不代替本人作表态。
4. 述责部分的提法，以区委组织部、区纪委监委通知原文为准。
