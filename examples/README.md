# 示例

三个端到端示例，按各 skill 的 SKILL.md 逐步执行得到。单位、人名、数据全部虚构。每个目录里的 `过程记录.md` 写明每一步问了用户什么、运行了哪条命令、脚本输出了什么。

几点约定：
- `.txt` 正文文件中，单独一行的【起草说明】之后是说明内容，机检和排版脚本读到这一行即停止。
- docx 内写的是标准字体名（仿宋_GB2312、方正小标宋简体等），在装有这些字体的电脑上打开显示正常。仓库不附带字体文件。
- 正文中的【待补】【待核实】是有意保留的：材料里没有的事实不编，留给用户补。机检把这些标记计为 P2，并单独统计，提醒定稿前补齐。
- 下列机检数字为 2026-10-16 用当前版本脚本重跑的结果。

## A　医院科室年终总结（转译模式）

- 输入：心内科科秘书的口语化工作记录（约750字，含1名患者的姓名和住院号）和一张指标表（缺2026年CMI、次均住院费用、上年同期平均住院日）。
- 步骤：gongwen-report 建素材台账、搭提纲、成稿 → gongwen-title 出小标题方案并替换 → gongwen-format 排成材料版式 → fact_diff 台账对账。
- 效果：台账43条，每个数字都标了出处；正文中【待补】9处、【待核实】2处（如左心耳封堵“大概20来台”）；患者信息改为“张某”。素材只撑得起约1400字，没有为凑到2000字加写背景和表态，起草说明写明了补哪几项可以写足。机检 P0、P1 均为0，P2 11处全部是待补、待核实标记；check_docx P0、P1 均为0；台账对账没有台账以外的数字。
- 文件：`输入-心内科2026年工作记录.txt`、`输入-心内科主要指标表.csv`、`素材台账.md`、`提纲.md`、`正文.txt`、`起草说明.md`、`标题方案.md`、`成稿.docx`、`过程记录.md`

## B　AI 稿体检（高效模式）

- 输入：一篇模拟 AI 起草的区教育局冬季校园安全检查通知，含段首评论语、“不是……而是……”、破折号、新八股词、Markdown 加粗、结尾号召，“建议各学校”“以上内容仅供参考”，发文字号“[2026]第12号”、日期虚位、序号“1、”、“3～5万元”，以及对家长“一律移交公安机关予以拘留”。
- 步骤：gongwen-direct → gongwen-humanize → gongwen-review（出核稿意见，再按 P0、P1 直接改）→ gongwen-format（红头成稿；送审稿加批注）。每一步都用 fact_diff 比对。
- 效果：机检从 P0 5处、P1 31处、P2 2处降到全部为0；篇幅从1092字压到807字，所有数值未变。核稿意见10条（P0 3条、P1 5条、P2 2条），拘留表述核实后定为 P0 删去。check_docx P0、P1、P2 均为0；10条核稿意见全部写成 Word 批注。
- 文件：`原稿.txt`、`1-direct改稿.txt`、`2-humanize改稿.txt`、`3-核稿意见.md`、`3-核稿意见.json`、`4-核改稿.txt`、`5-版式信息.json`、`5-成稿.docx`、`6-送审稿-批注.docx`、`前后对比.md`、`过程记录.md`

## C　文种判断：申请经费用函（教学模式）

- 输入：用户一句话，“我刚到区教育局办公室，领导让我写个东西报给区财政局，申请追加80万元校舍维修经费，该怎么写？”
- 步骤：gongwen 识别单位、角色、文种、行文方向四个维度 → 判断为函 → 先给提纲，用户补素材后过渡起草 → 机检 → gongwen-format 排成信函格式。
- 效果：区教育局与区财政局不相隶属，请求批准用函，标题写“关于商请……的函”，不写“关于申请……的请示”（《党政机关公文处理工作条例》第八条第（十四）项）。起草说明附写作要点。三个项目预算合计与申请金额核对一致。机检 P0、P1 均为0，P2 2处为待补标记（成文日期、联系电话）；check_docx P0、P1 均为0，P2 3项均为待补提醒（另一处是发文字号）。
- 文件：`正文.txt`、`起草说明.md`、`版式信息.json`、`成稿.docx`、`过程记录.md`
