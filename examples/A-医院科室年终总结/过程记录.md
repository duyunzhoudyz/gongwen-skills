# 过程记录：医院科室年终总结

> 本记录按现行规则生成：核心事实够用，首轮一次交付台账、提纲和正文；用户指定了字数而素材撑不起，用文种常规的工作性表述补足到目标区间，不新增事实、不注水，起草说明里一句话说明哪几部分是常规表述。起草说明只在对话回复中给出（不超过5行），不单独存成文件，所以本记录把每一轮回复连同起草说明原文写出来。机检数字和脚本输出是用当前版本脚本重跑的结果，可供 examples/README.md 引用。

路线：gongwen-report（台账、提纲、成稿，首轮一次交付）→ gongwen-title（小标题三套方案，替换）→ gongwen-format（材料版式）

对应路线表 R01（写年终总结）。R01 的完整路线是 report → direct → humanize → review（停）→ format，这里用户每一轮只要其中一步（先要台账、提纲和正文，再要小标题，再要排版），没有要求去防御腔、去 AI 腔和核稿，按路线表使用规则第4条只走用户要的步骤，不劝。运行环境为 Claude Code，22 个 skill 都已安装，不出交接卡。

用户设定：某市某医院心血管内科科秘书，业务岗兼写材料（转译模式），无单位画像。所有单位、人名、数据均为虚构。对话发生在12月初：1—11月的数据已出，12月数还没出。下文目录名里的日期是当天日期，写作“<当天日期>”。

任务卡只作内部整理，对话和起草说明都不展示（截止时间用户没说，取默认，不影响成稿）。转译模式下，用户话里已能推断出写给谁（医务部）、用途（年终考核、书面交）、篇幅（2000字左右），这三项不问，只问数据口径：指标表是1—11月的数，同期基期是2025年1—11月，所以只问“正文是否先按1—11月写”这一个点。

### 篇幅预估和处理

用户要的是2000字左右，目标区间 1800～2200 字（±10%，不含【待补】标记）。起草前预估：工作记录15段、指标表8项指标，扣掉缺数据、不能写的部分，事实和算出的数能撑起约1300字；差约700字。按 guardrails 第四条第2款和 gongwen-report 第四步第8条，素材不足时用工作性表述补足常规板块，不新增事实，不注水，不在这里降低字数目标。补足的约600字全部是常规工作性表述，种类有：全文导语和各部分导语（分三部分、数据口径、“以下五个方面”“以下四个问题”）、术语简要说明（PCI、门球时间、DSA、左心耳封堵术、CMI，转译模式首次出现术语时加说明）、各板块和全部分的小结句、问题与打算之间的呼应句、办理程序的一般性表述。总结是回顾性文书，不补下一步计划：第三部分只写用户给的4项打算，心力衰竭病组费用超支材料里没有具体措施，只写一句原则性表述，不自拟措施；材料没给的数据（30天再入院率、下半年病历甲级率、抗菌药物使用强度、DRG超支病组数和金额）不编，不用占位凑，列入起草说明。

### 台账、提纲、成稿

1. 台账：拆成60条，见 素材台账.md。一条只记一件事或一个数；类别五种（数据43、工作事项6、问题5、案例3、下步打算3）；状态“待核实”2条（复审结果通知的名称文号未找到、左心耳封堵“大概20来台”），其余58条已确认；算出的增幅、增量、占比另起一行，写明算式（如PCI增长13.8%、增加74台，门诊增加3442人次，医护比约1∶2）；缺口清单12项，说明每项是“待补（正文已标）”“待核实”还是“未写入”。指标表备注栏已写明四级手术占比的分母（科室全部手术，两年口径一致），记已确认；病历甲级率“好像是91%多一点”与指标表91.8%不矛盾，以指标表质控办数为准；“现在应该上来了”是推测，不写成效。
2. 提纲：按总结框架一（三段式），每个要点注明台账序号和计划字数，并标出哪几处是常规表述，见 提纲.md。病历甲级率未达标（台账32）是台账里的“问题”，放在第二部分，整改措施写在同一条下，第一部分不重复。
3. 正文：按提纲逐部分写，每部分写完对照台账核一次。每个事实只写一处。待补的做法：只限必须由用户提供的统计数据，且同一要素只标一处，共2处——开头指标段的“CMI和次均住院费用”（指标表中本行留空）、第一部分（一）的门球时间实际值；其他缺的数据本稿不占位，列入起草说明。复审通过、约20台两处存疑事项，正文采用材料里最可靠的写法（“通过复审”“约20台”），核实事项只进起草说明“待核实”一行，正文没有【待核实】。成文日期用户没给，写“2026年12月　日”，日留空，不标【待补】，起草说明提示按签发日填写。“明年”照原话写“明年上半年”，不换算；二级标题“2027年工作打算”按文种惯例写。
