# 清单投稿文案

## 一、提交时间和共同要求

**时间**：按《顶层设计》7.4 节，发布满 14 天（2026 年 11 月 14 日以后）或仓库满 100 star 后再提交 awesome 清单。skills.sh、SkillsMP 会自动收录，发布当天不必单独提交。

**门槛来源**：下文各清单的门槛，依据 2026 年 10 月 16 日读取的各仓库 CONTRIBUTING.md 和 README 整理。清单规则常有调整，提交前请再读一遍原文。

**共同要求**：

1. 一次只提交一个清单条目，不要同一天群发。
2. 描述写“它做什么”，不写广告语，不对读者喊话，不用 emoji。
3. 不出现关于 AI 检测、替人写稿、官方背书的说法。
4. 两个清单明确要求由本人提交：hesreallyhim/awesome-claude-code 要求推荐由真人在网页表单上填写；travisvn/awesome-claude-skills 不接受用 AI 生成或 AI 辅助提交的 PR。下面给这两个清单的文案只作要点参考，请用自己的话重写后手动提交。
5. 提交前确认：仓库已公开；根目录 LICENSE 能被 GitHub 识别为 PolyForm Noncommercial；README 和 README_EN 首屏有定位、安装方法和保密提示；有 `examples/` 示例和评测报告。

## 二、通用简介

### 英文

gongwen-skills is an open-source collection of 22 Agent Skills for writing Chinese official documents (gongwen) in government agencies, public institutions and state-owned enterprises. Seventeen core skills cover task routing, drafting, revision, review and GB/T 9704 formatting; five industry packs serve township and community offices, public hospitals, universities, K-12 schools and SOEs. Facts are taken only from the user's materials, and missing data is left as a marked placeholder. The project includes a rule-based checker with clause references to GB/T 15834 and GB/T 15835, generates and repairs standard-compliant .docx files with python-docx, and pauses with a warning when the input carries classification or "internal use only" marks. Skills run in Claude Code, Codex, Cursor and other agents; prompt versions can be pasted into web or on-premise LLMs. Licensed under PolyForm Noncommercial 1.0.0: free for personal and noncommercial use.

### 中文

gongwen-skills 是面向机关、事业单位、国企文字工作者的开源公文写作 Skills 集合，共 22 个 skill：17 个核心 skill 覆盖任务路由、起草、改稿、核稿和 GB/T 9704 国标排版，5 个行业包面向乡镇社区、公立医院、高校、中小学和国有企业。事实只取自用户材料，缺的标【待补】，不编造；内置标注 GB/T 15834、GB/T 15835 条款号的机检规则，用 python-docx 生成和修复国标 docx；遇到密级或”内部资料”标识，先停下来提醒。支持 Claude Code、Codex、Cursor 等 Agent 工具，也提供可以粘贴到网页或内网大模型的提示词版。PolyForm Noncommercial 1.0.0 许可，个人及非商业用途免费。

## 三、各清单的门槛与文案

### 1. hesreallyhim/awesome-claude-code

**收录门槛**

- 满足其一：默认分支首次提交满 14 天，且之后还有持续提交；或者满 100 star。不满足的会被自动关闭。
- 一次只能推荐一个资源。
- 清单偏重体现 Claude Code 特有功能的资源。本项目可以突出“插件市场安装、6 个插件按需安装”。

**提交方式**

- 只能用仓库网页上的 issue 表单（recommend-resource）提交，不开 PR，不能用 gh 命令行提交，推荐须由本人填写。
- 许可证由机器人自动读取，读不到时要在 issue 下留言说明。

**要点参考（请用自己的话重写）**

- 描述只写一行，说明它做什么。可参考的意思：一个 Claude Code 插件市场，含 22 个用于起草、核稿和按 GB/T 9704 排版中文公文的 skill，另有行业包；事实只取自用户材料。
- 英文参考：A Claude Code plugin marketplace with 22 skills for drafting, reviewing and formatting Chinese official documents to GB/T 9704, plus industry packs; facts come only from user-provided materials.

### 2. VoltAgent/awesome-agent-skills

**收录门槛**

- 公开仓库，技能可以正常使用；有 README 或 SKILL.md。
- 条目名称要带作者前缀；描述不超过 10 个英文单词。
- 要有真实的社区使用，刚创建的技能不收。建议等到有一定 star 和用户反馈后再提交。

**提交方式**

- 提 PR，把条目加到 README 对应分类的末尾。建议放在 Community Skills 下的 Productivity and Collaboration，没有合适分类时放 Other。
- PR 标题：`Add skill: duyunzhoudyz/gongwen-skills`

**条目文案**

```markdown
- **[duyunzhoudyz/gongwen-skills](https://github.com/duyunzhoudyz/gongwen-skills)** - Chinese official document drafting, review and GB/T formatting
```

### 3. ComposioHQ/awesome-claude-skills

**收录门槛**

- 基于真实用例；文档清楚，有示例；在 Claude.ai、Claude Code 或 API 上测试过；涉及删除等操作前要先确认。
- 没有写明 star 门槛。

**提交方式**

- Fork 后新建分支，在 README 的 Communication & Writing 分类中按字母顺序加条目，再提 PR。
- 其 CONTRIBUTING 描述的是在清单仓库里新建技能文件夹，但 README 中也有直接链接外部仓库的条目。本项目建议以链接外部仓库的方式提交，提交前确认最新规则是否允许。
- PR 标题：`Add gongwen-skills skill`
- PR 说明要写清：解决什么问题、谁在用这个流程、借鉴来源、使用示例。

**条目文案**

```markdown
- [gongwen-skills](https://github.com/duyunzhoudyz/gongwen-skills) - Drafts, reviews and formats Chinese official documents to national standards, using only facts the user provides.
```

**PR 说明草稿**

```text
What it solves: Staff in Chinese government agencies, hospitals, universities, schools and SOEs write official documents (notices, requests, year-end summaries, meeting minutes) under strict national rules. General-purpose AI often invents facts, ignores the GB/T 9704 layout and leaks internal material. These skills keep facts tied to the user's own materials, mark missing data as placeholders, check punctuation and number usage against GB/T 15834 and GB/T 15835, and produce standard-compliant .docx files.

Who uses it: Office clerks, department staff who write reports part-time, and reviewers who check drafts before sign-off.

Attribution: Design ideas from several MIT and Apache-2.0 projects, listed with licenses in THIRD_PARTY_NOTICES.md. No code or text was copied.

Example: "Here are this year's work notes for our department. Draft the year-end summary." The skill builds a source ledger, drafts the summary, marks missing figures as placeholders and lists them after the text for the user to fill in.
```
