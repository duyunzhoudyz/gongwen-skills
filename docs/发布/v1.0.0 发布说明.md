# gongwen-skills v1.0.0

> **保密提示**
>
> 涉密信息严禁输入任何联网 AI 工具。带密级标识、标注“内部资料”“工作秘密”的材料，不要粘贴到任何公网大模型。处理内部材料请用单位内网部署的模型，本项目的提示词版和离线包可以直接在内网模型上使用。完整说明见 [使用须知](https://github.com/duyunzhoudyz/gongwen-skills/blob/main/使用须知.md)。

## 一句话定位

给机关、事业单位、国企文字工作者用的开源公文写作 Skills 集合。懂条例国标，懂单位差异，懂岗位角色；不编造，守保密，帮你做减法。

## 这一版包含什么

v1.0.0 一次发布全部 22 个 skill，分为 6 个插件：核心插件 `gongwen`（17 个 skill）和 5 个行业包插件（各 1 个 skill，需先装核心插件）。核心 skill 按 v1.0 评测结果标注 Stable 或 Beta，行业包统一标 Beta，收到一线反馈后再升级，标签见 README 的技能地图。

## 三个亮点

### 一、防编造：事实只来自你的材料

- 数据、案例、人名、文号、政策依据只取自你提供的材料。缺的写成【待补：××】，存疑的写成【待核实：××】，正文之后附“起草说明”逐条列出。
- 起草前先建素材台账，成稿后用 `fact_diff` 脚本对账，正文里每个数字都要能在材料里找到。
- 对照检查、述职、谈心谈话这类需要本人经历的材料，没有本人事例时只给提纲和填写指引。
- 涉及“本人表态”的句子，例如廉洁自律表态，要本人确认后才写进正文。

### 二、单位与角色差异

- 内置 7 类单位画像：党政机关、县乡基层、街道社区、公立医院、高校、中小学、国有企业，写明各自的发文体系、决策程序、术语和红线。
- 5 种角色模式：教学（新人）、高效（笔杆子）、转译（业务骨干）、审稿（领导）、严谨（党务宣传）。同一个任务，给新人讲为什么，给审稿人只出问题清单。
- `gongwen-profile` 可以从本单位的公文处理办法和历史稿里建画像、学文风，从领导改过的稿子里归纳偏好。只出现过一次的改动先记为“观察中”，不急着当成规律。
- 5 个行业包各带专用文书模板、行业红线和核稿附加清单，例如医院指标口径登记、国企党委前置研究核对、中小学学生名单本地脱敏、基层居民文书的处罚表述检查。

### 三、国标排版和机检

- `gongwen-format` 按 GB/T 9704-2012 生成 docx，支持红头、信函、纪要、白头、材料、简报六种版式（简报无国家标准格式，按机关常见做法），能修复已有 docx，能把核稿意见写成 Word 批注。没有 Python 时，改为给出 WPS、Word 手动设置清单。
- 机检引擎覆盖 12 类检查：残留、标点、数字、格式要素、结构、AI 味、防御性、隐私与保密、法规、减负、待补标记、篇幅。格式、标点、数字规则都标注了 GB/T 9704、GB/T 15834、GB/T 15835 或《党政机关公文处理工作条例》的条款号。
- 讲话、纪要、整改、简报、申报书等 skill 另带专项检查脚本，比如讲话时长估算、督办清单对账、整改状态对账、申报书匿名检查。

## 评测结论

### v1.0

2026 年 10 月 16 日至 20 日，对全部 22 个 skill 做了装与不装的两轮对比评测：372 条用例、2671 项检查，材料全部虚构，两组用同一模型（claude-sonnet-5-5），评分员盲评。第一轮评修复前的版本，按暴露的问题逐个 skill 修复后，第二轮复测装 skill 一组，即本次发布的版本。

| 口径 | 装 skill（第二轮） | 不装 skill |
|---|---|---|
| 全部检查通过率（2671 项） | 98.6% | 54.1% |
| 通用检查通过率（1726 项，不依赖本项目约定） | 99.1% | 68.7% |
| 防编造用例（136 条）中出现编造的运行 | 0 | 66 |
| 带密级、内部资料标识的用例（21 条）完全按要求停止处理 | 21 | 3 |

几点说明：

1. 修复前的第一轮（两组条件完全一致）：全部检查通过率 97.1% 对 54.0%，通用检查 97.7% 对 68.5%。第二轮装 skill 一组用更高的推理强度重跑，不装 skill 一组沿用第一轮的输出，所以第二轮的差距不是等条件对比。
2. 全部 372 条用例中，评分员标出装 skill 一组编造 2 次（都是 gongwen-university 引用自带资料里的日期），复核后不算编造；第一轮为 19 次。
3. 触发评测：440 条说法选对 439 条（99.8%），修改了 8 个 skill 的 description 后复测，修改前为 435 条。
4. 17 个核心 skill 的通过率均不低于 97.4%，防编造 0 次，触发达标，标 Stable；5 个行业包数字也达标，按约定统一标 Beta。
5. 局限：每条用例只跑一次，评分员与被评模型是同一个模型；复测用的是同一批用例；装 skill 一组仍有 37 项检查未通过（分布在 16 个 skill），其中 gongwen-soe 一条用例（学校国资委会议的议题材料）5 项全部未通过，已列为已知局限；没有做跨模型评测和人工盲评，也未经一线测试者实测。

方法、逐条判定和局限见 [evals/results/v1.0-benchmark.md](https://github.com/duyunzhoudyz/gongwen-skills/blob/main/evals/results/v1.0-benchmark.md)。

### v0.1（供参考，7 个 skill）

2026 年 10 月 15 日至 16 日，对 v0.1 的 7 个 skill 做了装与不装的对比评测：104 条用例、621 项检查，材料全部虚构，两组用同一模型（claude-opus-5-5），盲评。

| 口径 | 装 skill | 不装 skill |
|---|---|---|
| 全部检查通过率（621 项） | 94.8% | 59.7% |
| 通用检查通过率（422 项，不依赖本项目约定） | 95.0% | 74.6% |
| 防编造用例（34 条）中出现编造的运行 | 0 | 15 |
| 涉密、内部资料用例（7 条）完全按要求停止处理 | 7 | 2 |
| 改动了用户原文件的运行 | 0 | 2 |

几点说明：

1. 每条用例只跑了一次，评分员与被评模型是同一个模型，存在自评偏差的可能。
2. 约定类检查（如起草说明格式）不装 skill 天然难以满足，所以同时给出通用口径。
3. 评测也暴露了问题，例如教学模式首轮不出稿、篇幅明显不足。31 项待修问题纳入了 v1.0 的修复范围，处理效果以 v1.0 评测为准。

方法、逐条判定和局限见 [evals/results/v0.1-benchmark.md](https://github.com/duyunzhoudyz/gongwen-skills/blob/main/evals/results/v0.1-benchmark.md)。

## 安装

**Claude Code 插件市场**

```bash
/plugin marketplace add duyunzhoudyz/gongwen-skills
/plugin install gongwen@gongwen-skills
# 按需加装行业包，例如医院
/plugin install gongwen-hospital@gongwen-skills
```

**通用安装（Codex、Cursor、Gemini CLI、GitHub Copilot 等）**

```bash
npx skills add duyunzhoudyz/gongwen-skills
```

**一键脚本（自动探测本机已装的 Agent 工具）**

```bash
git clone https://github.com/duyunzhoudyz/gongwen-skills.git
cd gongwen-skills
bash install.sh --pack hospital          # macOS、Linux
# Windows：powershell -ExecutionPolicy Bypass -File .\install.ps1 --pack hospital
```

也可以用 `python tools/install.py --target qwen` 指定工具，`--list-targets` 查看支持的目录。Trae、CodeBuddy（用户级）的目录来自社区资料，安装时会提示。

**网页大模型和内网模型**

打开 `dist/prompts/`，复制对应的提示词文件，粘贴到对话开头再说需求。第一次用建议从 `gongwen.md` 开始。内网环境可以下载 Release 附件中的离线包 `gongwen-skills-offline-1.0.0.zip`。

排版功能需要 Python 3.9 及以上和 `python-docx`、`openpyxl`。字体不随附，仿宋_GB2312、方正小标宋简体等请自行合法获取。

## 使用边界

- 本项目是写作辅助，搭结构、守规矩、查错漏、出格式。文稿的事实、判断和最终表述由使用者负责，正式发文前按本单位程序审核签发。
- 本项目改进的是文风质量，不承诺、也不用于让稿子“查不出是 AI 写的”。
- 政治性提法、上级精神只对照你提供的原文，项目不内置“最新提法库”。
