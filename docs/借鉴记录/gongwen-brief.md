# 借鉴记录：信息简报与宣传（gongwen-brief）

- 模块范围：`skills/gongwen-brief/` 下的 SKILL.md、README.md、references/（不含 `_shared/`）、scripts/brief_check.py、evals/，以及 `tests/brief/`
- 阅读方式：2026-10-16 通过 GitHub API 和 raw.githubusercontent.com 在线读取，未克隆、未下载到本仓库。"读取版本"为当日默认分支的树对象哈希前 7 位。政策法规通过政府网站在线核对。
- 借鉴方式分三种：**思路**（分类方法、判定原则，不涉及文字）；**改写**（参考原文的规则，用自拟的公文语境表述和例句重写）；**依据**（公开的法规、政策文件，按条款引用要点，不整段照录）。本模块所有例句、示例材料、评测材料、测试标本均为自拟，单位、人物、数据均为虚构。

## 四、自研内容

以下设计在调研的项目中没有找到对应实现，为本模块自研：

1. `scripts/brief_check.py` 的专项检查：标题数字概括与正文分项条数比对（排除"两个确立""八项规定"等固定提法）、引语去标点后逐字溯源并区分"原话"和"名称提法"、导语铺垫和时间要素、对外稿的无依据最高级说法和疗效保证、简报报头报尾要素；以及 `tests/brief/` 的必过、必错标本。
2. 选题"新、特、实"三问和"三条都不满足就如实告知采用可能性低"的处理（`references/types/xinxi.md` 第二部分）。
3. 一份素材台账同时输出政务信息、新闻稿、推文三个版本，内部内容只进信息版（SKILL.md"一份台账多版输出"）。
4. 对外发布核对 11 项清单和附表模板，以及七类单位的特别核对项（`references/external-check.md`）。
5. 审稿模式下评估一篇信息"能不能报"的一页纸格式（`references/checklist.md` 第二部分）。
6. 从长材料提炼信息的五步法和"只删不改、数字不变、用 fact_diff 把原材料当台账对账"的做法（`references/condense.md`）。
7. 疗效保证的语境判断（2026-10-16 按独立评审意见修订）：疗效用语分两组，"治愈率""无副作用"等任何语境都按疗效保证处理；"根治""立竿见影""零风险""有效率"等只在同段出现医疗词语或 `--unit` 为医院时按疗效保证处理，其他语境只作 P2 提示；"根治欠薪""根治拖欠"等工作提法列为例外；命中词连同后文在 `--source` 材料中原样出现的降一级，提示核对是否为提法原文。
8. 简报按报头、报尾之间的篇目切分，逐篇核对标题数字概括与本篇条数；引语之外全文最多一处感叹号，正文连续感叹号按标题党处理。
9. 新闻发布会发布词的写法（`references/types/xinwengao.md` 第十一部分、`references/type-cards.md`）：篇幅按约 200 字/分钟换算，与 gongwen-speech 的工具约定一致；答记者问口径只整理用户或业务部门提供的，不代拟。
10. 第二轮评审修订（2026-10-16）：引语溯源增加直引号和单独使用的‘’；去标点后不足 8 字的引语，须在材料的引号内或"某某："记录格式中出现，只在叙述中出现的报 P1；说话人取引号前后的说话动词短语，在材料命中处前 30 字、后 16 字内找不到的，材料别处有报 P2、材料中没有报 P1；"评为、获评、授予、荣获"等引出的荣誉称号在材料中找不到的报 P1。"胃癌根治术""根治性切除"等手术名称列入疗效保证例外。"片面追求升学率""按升学率考核"等批评性语境和内部报送稿中的升学率只作 P2 提示。新增 BRF-016 标题空词，"走在……前列"列入无依据最高级说法。重复报送一条改为"工具约定，参照减负规定第12条的精神"，该条约束的是上级向基层要材料。
11. 第四阶段（W2）修订（2026-10-16），按计划 D11–D21、Q3、Q11、Q14 落实，未引入新的外部来源：首轮交付改按 roles.md 第十节，删去教学、审稿模式“先列候选角度、确认后成稿”的闸门，候选角度写进起草说明；篇幅按 guardrails 第四条第2款（任务卡预估素材可支撑字数、差距超过30%在回复第一段说明并附补料清单、【待补】不计入字数）；转交按 output-format.md 第四部分给交接卡、提示词版说明和安装命令，gongwen-grassroots 未安装时本 skill 照写；会上口头交流发言改交 gongwen-speech；相对时间不推算、用户提法原样保留写入自检清单；manifest 补 rules/tiaoli.md、rules/gbt9704.md、rules/gbt15834.md 以闭合共享资料引用；为控制提示词版字数，压缩 SKILL.md 与 xinxi.md、condense.md、external-check.md、checklist.md 中的重复内容；中文例句改用全角引号。

## 五、有意没有采用的内容

1. 公众号标题、摘要的平台字数上限：未查到可核实的现行平台规则，文中只写"按平台限制"，不写具体数字。
2. 政务信息的计分规则、紧急信息的报送时限：各地不同，且属于应急预案和上级信息部门的规定，本模块不内置数值，一律"以本单位要求为准"。
3. 上市公司信息披露的具体条款号：未核对到《上市公司信息披露管理办法》现行文本的条款号，沿用 `shared/profiles/units/guoqi.md` 的表述，不另写条款。
4. 各来源中带具体数据的完整范文：本模块不提供可直接套用的范文全文，只给结构和短例，避免示例数据被误用。
