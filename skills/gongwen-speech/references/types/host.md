# 主持词

主持词的任务是按议程把会开下来：宣布开会、逐项引出、承接转场、小结、散会。它服务会议流程，篇幅短，不另作长篇讲话。

## 一、骨架

```text
某某会议主持词
（主持人：某某职务　姓名）
同志们：
现在开会。
今天召开……会议，主要任务是……（一两句，取自会议通知或用户说明）。
出席今天会议的领导有：……（按用户给的名单顺序）。参加会议的还有……。
今天的会议共有N项议程：一是……；二是……。
下面，进行会议第一项，请……同志……。
（第一项结束后）
……
会议小结：概括讲话要点和讲话里已有的时间节点
现在散会。
```

主持词本身一般 3～6 分钟（约 600～1200 字，工具约定），会议总时长另算。

## 二、写法要点

1. 只用材料：会议名称、议程顺序、环节名称、出席领导名单、发言人姓名和职务、发言顺序，都按用户给的议程和名单写，不调换、不补充，缺的标【待补】。
2. 引出语一句：如“下面，进行会议第二项，请某某同志讲话”；发言题目或内容用材料中的说法。
3. 承接语以过渡为主：一两句，如“刚才，两家企业作了表态发言，措施都很实”。评价一句即可，不展开，不写“全场响起热烈掌声”“与会同志深受鼓舞”这类未发生的现场反应。
4. 程序环节按需写：清点人数、审议、表决、宣读名单，只在会议确实需要、材料也给出时才写。现场才有的结果不预写，占位合标一处【待补：现场统计的实到人数和表决结果】。
5. 会议小结：
   - 有配套讲话稿或用户给了讲话要点的：用三五句概括讲话要点，带上讲话里已有的时间节点。传达范围、落实时限只在讲话要点或用户给出时才写；没有的不写，也不用【待补】占位，占位同样是在替讲话人加要求。
   - 讲话内容不清楚的：小结标【待补：根据某某同志讲话要点概括】，不写贯彻要求。
   - 不替讲话人“升华”，不加讲话里没有的新要求。
6. 称呼：内部会议称“某某同志”；对外活动按材料称职务或“先生”“女士”。主持人的介绍顺序按出席名单，见 `references/types/ceremony.md` 第五部分。
7. 时长：主持词折算的时间加各环节时长，与会议安排对照；超时的在起草说明提示，并建议压缩哪个环节。

## 三、与讲话稿衔接

同时写主持词和讲话稿的，交付前逐项核对：

- [ ] 主持词中的议程项与议程材料一一对应，顺序一致。
- [ ] 引出讲话时的讲话人职务、讲话题目，与讲话稿标题、署名一致。
- [ ] 小结概括的要点在讲话稿里都有，没有新增要求（含传达范围、时限、“会后传达”之类）。
- [ ] 主持词开场说的会议目的，与讲话稿开场不矛盾，也不大段重复。
- [ ] 交流发言、表态发言的单位顺序与议程一致。

## 四、正误对照

1. 现场结果
   - 误：本次会议应到委员29人，实到27人，符合规定人数，可以开会。（用户没给人数）
   - 正：现在报告出席情况：【待补：现场统计的应到和实到委员人数】。
2. 承接
   - 误：刚才，某某局长作了一个高屋建瓴、内涵丰富、催人奋进的重要讲话。
   - 正：刚才，某某局长就森林防火工作讲了三点意见，任务和时间都很明确。
3. 小结
   - 误：会后，各单位要建立工作台账，每天上传一次巡山照片。（讲话里没有，且增加留痕负担）
   - 正：某某局长讲了三点：一是……，二是……，三是……，（讲话里有时间节点的才带上，没有就不提；只复述要点，不加传达要求）

## 五、常见毛病

1. 凭空写出人数、表决结果、审议结论。
2. 会议不需要表决，主持词却加了表决环节。
3. 调换议程顺序，或弄错发言人先后。
4. 小结比讲话还长，或加入讲话中没有的新要求。
5. 用户只要某一段（如开场或小结），却交付整篇。只要一段的，只交那一段。
