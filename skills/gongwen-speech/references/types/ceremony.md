# 典礼讲话与致辞

适用于开学典礼、毕业典礼讲话，以及欢迎致辞、开幕词、闭幕词、活动致辞。家长会讲话在已安装 gongwen-k12 时交给它，未安装的按本文第一部分和 `references/units.md` 第七部分写。

## 一、典礼讲话（开学、毕业）

听众是学生。要讲具体的人和事，少讲大道理。

骨架：

```text
称谓（亲爱的同学们，老师们：）
问候和祝贺：一两句（欢迎新同学；祝贺毕业）
具体的人和事：一两个，用户提供（本届学生、老师、学校的一件事）
希望：两三条，每条一句观点、一个具体做法
祝福：一句
```

时长：高校校长讲话一般 10～15 分钟；中小学开学典礼 5 分钟左右，低年级学生注意力短，宜更短（工具约定）。

写法：
1. 人和事只用用户提供的。用户要“加个校友故事”“讲个学生的事”却没给的，不编不写，起草说明“待补”写明要补的事例。
2. 学生姓名在稿中用“张某同学”之类的代称，起草说明提示定稿时换回，并确认本人同意。
3. 希望写成能做的事，少用四字格连排。内容来自用户给的讲话人意思，展开成动作时不另加任务（SKILL.md 第四步第 4 条）；一点意思都没给的，标【待补：讲话人对学生的希望】。
4. 高校：可以有思考、有温度，可以用一两处设问；涉及思政和意识形态的表述叠加严谨模式，提法只用用户原文。
5. 中小学：句子更短，给小学生听的整句一般不超过 25 字（工具约定）；用孩子听得懂的词，不用政策术语；不讲成绩排名，不承诺升学结果；可以加一两句安全提醒。

例：给大家提一个小要求：这个学期，至少去听一场本专业以外的讲座，至少交一位外系的朋友。（校长的意思由用户提供）

例（小学）：新学期，老师希望你们做到三件事：早上按时到校，上课大胆举手，自己的书包自己整理。（要求由用户提供）

## 二、欢迎致辞

用于上级领导、兄弟单位、外宾来访，或重要活动的欢迎环节。时长 2～3 分钟，约 400～600 字。

骨架：
1. 称谓：按名单的礼宾顺序（见第五部分）。
2. 致意：代表谁、欢迎谁，一句。
3. 介绍：本单位或本地情况两三句，数据只用用户提供的。
4. 期望：交流合作的具体事项，只用用户提供的；用户没提供的，写一句通用期望即可，不编合作项目。
5. 祝愿：一句。

例：去年，两地在旅游客源互送上合作，互送游客4.5万人次。这次来访，希望在冷链物流上再谈出几个具体项目。（数据和事项由用户提供）

## 三、开幕词

用于代表大会、年度会议、运动会、学术会议等的开幕环节。时长 3～5 分钟。

骨架：
1. 称谓。
2. 宣布或说明会议开幕：由谁宣布开幕以议程为准，主持人宣布的，开幕词不重复。
3. 会议任务：本次会议的议程和要完成的事项，只用议程材料。
4. 对会议的要求：两三条（如开好会、议好事、守纪律）。
5. 预祝会议圆满成功。

开幕词一般会后印发，默认念的稿。职代会、教代会、党代会的工作报告不在开幕词范围内，交 gongwen-report。

## 四、闭幕词

用于会议闭幕环节。时长 3～5 分钟。

骨架：
1. 称谓。
2. 会议完成的议程和形成的成果：只用会议实际结果。会前写的，表决结果、选举结果、通过的文件等标【待补：会议表决（选举）结果】。
3. 贯彻要求：会后怎么传达、怎么落实，两三条。
4. 宣布闭幕，或按议程交主持人宣布。

例：大会审议了工作报告，【待补：表决结果】。（会后按实际结果补写）

## 五、称谓和礼宾顺序

1. 用户给了名单、礼宾次序或模板的，按其顺序，一字不改地用名单中的姓名和职务。
2. 需要点名的具体人物，排在“各位领导”“各位来宾”等泛称之前。
3. 同一组人物，按已知的职务高低和正副关系排列。
4. 已确认的受邀主宾，可以排在本地主要领导之前，这是礼遇安排，不表示级别更高。
5. 跨单位人物无法确定先后的，保持材料中的顺序，不凭企业头衔、地名推断级别。
6. 不补充材料里没有的人物、职务。没给名单的，只用泛称，如“各位领导、各位来宾，老师们、同学们：”。
7. 称谓的排序不改变主持人介绍出席领导的顺序和发言顺序，那两项按议程材料。

## 六、常见毛病

1. 讲成工作报告：开学典礼讲学校全年数据。数据挑学生关心的，全篇一般不超过五六个，小学更少。
2. 编故事、编名言；一句话里四五个四字格。
3. 称谓漏人、错序；闭幕词把会前的表决结果写成已通过。
