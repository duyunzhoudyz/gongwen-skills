# 表态发言与交流发言

表态发言、交流发言由下级单位或个人在会上讲，篇幅短，听众是上级领导和同级单位。《整治形式主义为基层减负若干规定》第6条要求“不搞一般性工作汇报、表态”，所以这两类发言都要讲具体的事。代表发言以发言人本人的经历和感受为主体，规则见第三部分。

## 一、表态发言

适用于动员部署会、签订目标责任书仪式、任职会议等场合的表态。时长 3～5 分钟，约 600～1000 字（工具约定）。

骨架：

```text
称谓
态度：一两句，表明对会议部署的态度
目标：本单位要达到的目标（用户给的，或上级下达的）
措施：三四条，每条写做什么、做到什么程度、何时完成
承诺：一句收尾
```

### （一）承诺要具体

每条承诺都要能检验：有动作、有标准、有时限。措施只用用户给的；缺的按常规写可执行措施，时限须用户定的才写【待补：完成时限】，起草说明列出需补的内容。

误：我们将进一步提高政治站位，压实工作责任，以更加饱满的热情、更加务实的作风，坚决完成全年目标任务。
正：一是清明前把进山的7个路口全部设卡，每个卡口两人值守，进山人员逐一登记；二是4月底前把林区坟头周边的可燃物清理一遍，每个村明确一名清理责任人。（措施、数量和时限由材料提供）

### （二）不超出权限

只承诺本单位职责范围内能做到的事。

1. 不替上级、其他部门、其他单位承诺。
   - 误：县林业局的防火通道项目年底前全部完工。（发言单位是乡政府）
   - 正：配合县林业局做好防火通道建设的征地和群众工作。
2. 不承诺资金、编制、政策等本单位无权决定的事项；需要上级支持的，用“恳请”写在发言末尾，或建议另行请示。
3. 结果性目标（“零事故”“100%完成”“确保不发生……”）只用上级下达或用户确认的；用户没确认的，改成可控的工作目标，并在起草说明提示。
4. 不写绝对化的保证，如“绝不出现任何问题”“确保万无一失”。

### （三）不搞一般性表态

1. 态度部分一两句即可，不超过全文一成。
2. 会议安排的就是一般性表态环节（只表态、不讲措施）的，起草说明提示减负规定第6条，稿子仍写具体措施。
3. 任职表态发言：可以讲对岗位的认识和打算，但打算要具体；个人经历只用用户提供的，不编。

## 二、交流发言

适用于经验交流会、推进会上的交流环节。时长 5～8 分钟，约 1000～1600 字（工具约定）。

骨架：

```text
称谓
点题：一两句，说清本单位做了什么、见了什么效果
做法：两到四条，每条写做了什么、怎么做的、数据或事例
体会：一两条，短
下一步：一句，可省
```

### （一）与经验材料、工作汇报的区别

| 文书 | 用途 | 篇幅和语体 | 归属 |
|---|---|---|---|
| 交流发言 | 在会上讲，供同行借鉴 | 5～8 分钟，口语，一条做法配一个事例或数据 | 本 skill |
| 经验材料 | 书面报送、汇编印发 | 1500～3000 字，书面 | gongwen-report |
| 工作汇报 | 向上级报告全面工作 | 按汇报时长 | gongwen-report |

### （二）写法

1. 只讲会议主题相关的一两件事，不罗列全年工作。
2. 每条做法都有具体内容：怎么组织、用了什么办法、解决了什么问题。做法和数据只用用户给的。
3. 成效只用用户给的数据和事例；没有的不写，不写“取得明显成效”“广受好评”。
4. 不与别的单位比较，不写无依据的“全省首创”“全国领先”。
5. 体会从做法中来，一两条即可，不写成空洞的原则。
6. 学习研讨发言、民主生活会上的发言交 gongwen-party。

误：我们坚持高位推动、系统谋划、多措并举，食堂管理工作取得了显著成效，得到了家长的一致好评。
正：我们把食堂的进货台账搬到了网上，家长在手机上就能查到当天的菜从哪家供应商来。今年上半年，家长陪餐日来了五百多人次。（数据由用户提供）

## 三、代表发言

适用于典礼、表彰会、入职仪式、家长会上的学生代表、教师代表、家长代表、获奖者代表、新职工代表发言。时长 3～5 分钟，约 600～1000 字（工具约定）。

骨架：

```text
称谓
身份和心情：一两句（我是某某岗位的新职工，今天代表……发言）
本人的经历：一两件，用户提供（时间、经过、当时的想法）
体会：从经历中来，一两句
打算：两三条，写本人做得到的事
致谢：一句，可省
```

写法：
1. 主体是发言人本人的经历和感受，只用用户（或发言人本人）提供的，正文用第一人称。
2. 用户没有提供本人经历的，按 `references/_shared/guardrails.md` 第六条第 4 款只出提纲和填写指引，不生成完整正文。先用一句话说明原因。填写指引逐部分写：写什么、约多少字、需要发言人提供哪些素材。
3. 给了部分经历的，按已有的写，缺的标【待补：发言人本人的经历或感受】。
4. 口吻合乎身份：学生代表用学生的话，不写成领导讲话；家长代表不替学校表态；获奖者代表不替单位作承诺。
5. 打算写成本人做得到的事，不喊超出身份的口号。

误（用户只说“帮新职工代表写个发言”）：我还记得第一天走进单位大门时，师傅拍着我的肩膀说……（经历是编的）

正：只交提纲和填写指引，例如：

```text
附：填写指引
1. 身份和心情（约100字）：请提供岗位和入职时间，姓名可用代称。
2. 本人的经历（约300字）：请发言人回忆入职以来印象最深的一两件事，写清时间、经过、当时怎么想的。
3. 体会（约100字）：从上面的经历里说一两句自己的体会。
4. 打算（约100字）：请发言人写两三件今年想做成的事。
```

## 四、常见毛病

1. 表态全是态度：通篇“坚决”“全力以赴”“确保”，没有一条措施。
2. 承诺越权：替上级定项目、定资金，替其他部门定时限。
3. 交流发言变成全年总结：十几项工作一项一段。
4. 成效靠形容词：“显著”“全面”“大幅”，后面没有数据。
5. 超时：3 分钟的表态写了 2000 字。
6. 代表发言编经历：没拿到本人素材，替发言人写出“我还记得……”的故事。
