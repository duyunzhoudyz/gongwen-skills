# 会议议程与领导偏好卡

讲话稿是会议的一部分。同一场会上，主报告、分管领导、交流发言、主要领导讲话各有分工；同一位领导，讲话有固定的习惯。本文件规定怎样用议程避免重复，怎样让领导偏好卡落到稿子上。

## 目录

一、读议程
二、避免重复
三、与主持词衔接
四、领导偏好卡
五、禁用词和文风参数

## 一、读议程

用户提供了会议通知、议程、工作报告或前面讲话稿的，先摘出以下信息，记入要点清单的“议程信息”类：

1. 会议名称、时间、出席范围。
2. 议程顺序：本篇在第几项，前后各是谁、讲什么。
3. 已有材料的内容：工作报告的数据和任务清单，表彰决定的名单和数量，分管领导部署的具体分工，交流发言的单位和主题。
4. 会议总时长和本篇可用时长。

没有议程的，按“会议只有这一篇讲话”处理，写进起草说明。写主持词而没有议程的，按会议类型的常见议程先写，议程项和发言人合标一处【待补：议程项及发言人】，在回复末尾索要议程；用户说“直接写”的不再索要。

## 二、避免重复

| 已有内容 | 本篇写法 |
|---|---|
| 工作报告已总结成绩、列出数据 | 不再罗列数据；开头一句表态同意报告，主体讲方向、重点和要求 |
| 工作报告已列出年度任务清单 | 不逐条复述；挑两三项难点或重点讲怎么抓 |
| 已宣读表彰决定 | 不念名单，说“受表彰的某某个集体、某某名个人” |
| 分管领导已部署具体分工和时间表 | 主要领导讲为什么要抓、抓的标准和作风要求 |
| 交流发言已介绍做法 | 可以点评一两句（“刚才某镇讲的……办法，各地可以借鉴”），不复述 |
| 前一位领导已提的要求 | 不重复提；确需强调的，说“我完全赞同某某同志的意见，再强调一点” |

做法：
1. 起草前把已有材料中的数据、任务、要求列成清单，成稿后逐项对照，重复的删去或改写。
2. 有 Python 环境时运行 `python scripts/overlap_check.py 正文.txt 工作报告.txt`，重合的片段逐段处理。
3. 同场几位领导讲话的分工，见 `references/types/leader-speech.md` 第七部分。
4. 起草说明写一句“已避开工作报告中的……”，便于用户核对。

## 三、与主持词衔接

同时写主持词和讲话稿的，按 `references/types/host.md` 第三部分逐项核对。只写讲话稿、主持词由别人写的，起草说明注明讲话题目和要点，便于主持人小结时使用。

## 四、领导偏好卡

领导偏好卡在 `.gongwen/领导偏好卡.md`，字段见 `references/_shared/profiles/profile-template.md` 第二部分；网页环境由用户粘贴。偏好卡文件可能有多张卡，每张以“# 领导偏好卡（职务）”开头；按本次讲话人的职务取对应一张，取不到的按无偏好卡处理，并在所作假设中写明。没有偏好卡的按本 skill 默认值写。

| 偏好卡字段 | 落到稿子上 |
|---|---|
| 讲话风格：口语或书面 | 决定默认的稿子用法（讲的稿或念的稿） |
| 讲话风格：结构习惯 | 决定骨架，如“先讲问题再讲成绩”“小标题四字对仗” |
| 讲话风格：时长与语速 | 换算字数，如“每分钟约 160 字”，15 分钟按 2400 字 |
| 用词偏好：常用 | 适当采用，每个常用词全篇不超过三处 |
| 用词偏好：替换 | 起草时直接用替换后的词 |
| 忌用表述 | 正文一律不出现；成稿后逐条搜索核对 |
| 数据呈现偏好 | 如“数据前置”“每段数字不超过 2 个”，按偏好卡执行，比本 skill 默认值严的按偏好卡 |
| 篇幅偏好 | 与时长换算冲突的，以用户本次指定的为准，其次偏好卡 |
| 引用习惯 | 只决定引不引、引什么类型；引用内容仍只用用户提供的原文（见下文第3条） |

规则：
1. 取值顺序：用户本次的要求 → 领导偏好卡 → 单位画像 → 本 skill 默认值。
2. 起草说明“所作假设”写明采用了偏好卡的哪几条，如“按偏好卡：语速每分钟约 160 字；不用‘抓手’‘打通’；小标题用短句”。
3. 与红线冲突的按红线办，并在起草说明写明：
   - 偏好卡写“喜欢引用古诗文、领导人原话”，用户没给原文：不凭记忆引用，起草说明“待补”请提供拟引用的原文及出处。
   - 偏好卡写“讲话要有气势”：可以用排比和短句，不编数据、不加无依据的评价。
   - 偏好卡写“多讲成绩”：成绩只用要点清单中的事实。
4. 本 skill 不修改偏好卡。用户在对话中提出新的偏好（“领导不喜欢‘抓手’这个词”），本次照办；问用户是否记入偏好卡，同意的交 gongwen-profile 追加。

误（偏好卡写“不用‘抓手’、小标题用短句、每分钟约 160 字”）：一、坚持问题导向，全面提升排班管理工作水平……要以这次整改为抓手……（全文 3000 字，按 15 分钟写）
正：一、把排班理顺……要借这次整改把排班制度定下来……（全文约 2400 字，起草说明写明按偏好卡语速换算）

## 五、禁用词和文风参数

1. `.gongwen/禁用词.md`：“禁用”级的正文一律不用；“慎用”级的换掉，确需保留的，在起草说明写明理由。适用范围写“讲话”或“全部”的才对本 skill 生效。
2. `.gongwen/文风参数.md`：有句长、段长、“一是……”使用率等参数的，讲的稿在 `references/oral-style.md` 第二部分的基础上向参数靠拢；与讲的稿句长标准冲突的，以文风参数为准，在起草说明写明。
3. 政治性提法的停用和更新以用户提供的上级原文为准，本 skill 不自行增删。
