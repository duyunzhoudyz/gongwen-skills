# 讲话类（gongwen-speech）

> 版本 1.0.0　成熟度：Beta（测试版）

帮机关、事业单位、国企的文字工作者写“拿来讲”的稿子：领导讲话、主持词、致辞、表态发言、交流发言、代表发言。它先弄清场合、讲话人、听众和时长，按每分钟约 200 字定篇幅，再写成便于开口讲的稿子：句子短，有称谓和过渡，前后呼应。数据、事例、引语和讲话人本人的经历只用你给的，缺的标【待补】，要引用却没有原文的标【待核实】，不替你编。

## 能做什么

| 功能 | 说明 |
|---|---|
| 领导讲话 | 动员部署会、推进会、总结表彰会、座谈会、年度工作会议上的讲话；开学、毕业典礼讲话；医师节、护士节、教师节、“七一”表彰讲话 |
| 主持词 | 按议程逐项引出、承接转场、会议小结；可以和讲话稿配套写，讲话题目、小结要点前后对得上 |
| 致辞 | 欢迎致辞、开幕词、闭幕词；称谓按你给的名单和礼宾顺序 |
| 表态发言、交流发言 | 表态发言每条承诺写清做什么、何时完成，不超出本单位权限；交流发言只讲会议主题相关的做法和成效 |
| 代表发言 | 学生、教师、家长、获奖者、新职工代表的发言，用本人口吻；没有本人经历时只给提纲和填写指引，不替发言人编故事 |
| 时长校核 | 按语速换算字数，以±10% 为目标；素材撑不起时，回复第一段说明差距并附补料清单，缺的标【待补】，不凑字数；主要负责同志讲话不超过 1 小时 |
| 避免重复 | 读会议议程和工作报告，讲话不再念报告里的数据、不再念表彰名单 |
| 领导偏好卡 | 读 `.gongwen/领导偏好卡.md`，按领导的语速、结构习惯、忌用词来写 |
| 两版并出 | 同一篇讲话出“讲话版”（口语）和“印发版”（书面），两版事实一致 |

## 可以这样说

1. “局长周三在全市冬季供暖保障会上讲 20 分钟，材料发你，帮我写个讲话稿。”
2. “毕业典礼校长要讲话，十分钟左右，说得让学生爱听。”
3. “明天的会我主持，议程在这，帮我写个主持词，跟书记的讲话接上。”
4. “乡长要在全县森林防火会上表态，三分钟，别光喊口号。”
5. “下周全区经验交流会，我们学校讲 8 分钟食堂管理的做法，帮我整理一下。”

## 输入

- 必需：场合（什么会、什么活动）、讲话人（职务）、时长。没说的最多问 3 个问题；你说“直接写”就按默认值处理，并在起草说明里写明。
- 首轮直接出稿：提纲和正文一起给，缺的标【待补】，要问的问题（最多 3 个）放在回复末尾。只有四种情况停在提纲或停止：你要求先看提纲（比如先请领导拍板）、除了场合和时长没有一条要讲的事实、代表发言缺本人经历、材料涉密。
- 最好提供：要讲的事和数据；会议议程（前后还有谁讲、讲什么）；工作报告或前面的讲话稿；要引用的领导讲话、上级文件原文。
- 可选：单位画像 `.gongwen/单位画像.md`、领导偏好卡、禁用词表。在网页大模型里，把画像和偏好卡粘贴在对话开头即可。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 纯文本讲话稿，不含 Markdown，可直接粘进 Word 或交给 gongwen-format 排版。主持词和讲话一起写时分为 `正文-主持词.txt`、`正文-讲话.txt`；两版并出时为 `正文-讲话版.txt`、`正文-印发版.txt` |
| `起草说明.md` | 所作假设、时长测算、待补事项、待核实事项、保密提示；按需附可选概括句、引语核对清单 |
| `素材台账.md` | 要点清单：每条数据、事例、引语原文的内容和来源 |
| `提纲.md` | 骨架、各部分要点和字数分配 |

在网页大模型里使用提示词版时，依次输出正文和起草说明。路线还有下一站的，起草说明之后附一张交接卡，告诉你下一步粘贴哪个提示词。

有 Python 环境时，可以用 `scripts/speech_check.py` 校核时长：

```text
python scripts/speech_check.py 正文.txt --minutes 20 --rate 200 --style 讲
```

它报告正文字数、预计时长、各部分字数，并列出过长的句子和段落、数字过密的段落、引语清单和来源不明的引文。`--style 念` 用于照本宣读、会后印发的稿子，阈值放宽。

## 注意事项

1. **保密**：请勿输入涉密信息和内部敏感信息；材料涉密的，请使用单位内网部署的模型。材料带密级标识或“内部资料”“不得外传”字样时会停下来；出现学生、患者、群众姓名和证件号时会提醒你脱敏，稿中改用“张某同学”之类的代称。国企讲话涉及未公开的经营数据，会提醒你确认能不能在会上讲；上市公司未披露的重大信息不写进讲话。
2. **不编引语、不编故事**：领导人讲话、上级精神、名人名言、古诗文，只用你给的原文；校友故事、先进事迹、群众原话，以及讲话人本人的经历和调研见闻，只用你给的。部署任务的牵头单位、完成时限也只用你给的，不替你定。缺的标出来，汇总在起草说明里。
3. **“金句”由你挑**：它会另拟两三句概括性的话放在起草说明里，注明是自拟的，你选中了再放进正文。
4. **做减法**：开场一两句点题，不写形势背景和意义铺垫；讲话里不写“纳入考核”“排名通报”，你或领导要求写的，会在起草说明里提示减负规定，请你另行处理；表态发言不写“确保万无一失”这类空表态。
5. **事实和判断由你负责**：它负责搭结构、控时长、守规矩，讲什么、怎么定调由你和领导决定。
6. **机检**：有 Python 时调用 `scripts/gongwen_lint.py` 和 `scripts/speech_check.py`；没有时按人工清单自检，并在起草说明中注明。

## 与其他 skill 的分工

| 需求 | 用哪个 |
|---|---|
| 党课讲稿、民主生活会发言、学习研讨发言 | gongwen-party |
| 职代会、教代会、党代会上的工作报告；向上级领导的汇报材料；述职（含现场口头稿） | gongwen-report |
| 医院科室主任述职（含现场口头稿） | 装了医院行业包时用 gongwen-hospital，没装的用 gongwen-report |
| 新闻发布会发布词、答问口径 | gongwen-brief |
| 会议通知 | gongwen-draft |
| 会议纪要、会议记录 | gongwen-minutes |
| 已有讲话稿要压缩、改口语、按领导批注改 | gongwen-polish |
| 讲话稿 AI 味重 | gongwen-humanize |
| 讲话稿核稿、查提法 | gongwen-review |
| 排成 Word | gongwen-format |
| 家长会讲话（装了中小学行业包时） | gongwen-k12 |

需要转交时，能调用其他 skill 的工具里会直接调用；目标 skill 没装或在网页版里，会给你交接卡、“新开对话粘贴 dist/prompts/<skill>.md 继续”的说明和安装命令（references/_shared/style/output-format.md 第四部分）。

一篇讲话稿的常见链路：gongwen-speech 成稿 → gongwen-humanize 清理文风 → gongwen-review 核稿 → gongwen-format 出 docx。

## 成熟度

Beta。领导讲话、典礼讲话、致辞、主持词、表态发言、交流发言、代表发言的骨架和写法，时长换算与校核，议程避重，领导偏好卡，引语和事例的防编造规则已可用；评测用例见 `evals/`，`scripts/speech_check.py` 配有单元测试。已知局限：

- 时长按字数估算，实际快慢取决于讲话人，偏好卡里写明语速会更准；
- 主持词与议程是否对应、讲话与工作报告是否重复，脚本只能辅助（重复段落可用 `scripts/overlap_check.py` 比对），最终靠清单人工核对；
- 家长会讲话：装了中小学行业包 gongwen-k12 时由它处理，没装的由本 skill 按中小学的要求写。
