# 中小学核稿附加清单

在 gongwen-review 八关核稿的基础上，中小学材料再加查下列项目。本包成稿后自检用；交给 gongwen-review 全面核稿时，告诉它单位类型为中小学，它会按自己的 `unit-checks.md` 第六部分审，本清单作补充。依据编号见 `references/sources.md`，红线条号见 `references/redlines.md`。

## 二、级别说明

1. 级别含义同 gongwen-review：P0 必须改，P1 建议改，P2 请用户判断。
2. 与 gongwen-review `unit-checks.md` 第六部分口径一致：评语贬损用语（“笨”“没出息”等）为 P0，理由是有损未成年人人格尊严（S21）；标签化用语为 P1。收费依据：机检只能看到本段有没有写依据，报 P1；人工确认全文确无依据的，按 gongwen-review 的口径升为 P0。
3. 高中、中职材料：考试排名、家长作业相关项目降一级（P0 降为 P1），按本省规定判断；一、二年级书面作业和课后服务的检查项不适用。
4. gongwen_lint 计算冒号密度（AI-013）时已排除评语正文的“编号：”和信函称呼行“尊敬的家长：”；仍报出的，按正常文风问题处理。

## 三、人工检查清单（不能运行脚本时）

网页版、内网无 Python 时，逐条检查，并在起草说明写“未运行机检，已按人工清单检查”。

学生评语：
- [ ] 全文搜“第”“名”“排”“分”：没有考试名次和分数（比赛获奖的名次可以写，写明比赛名称）。
- [ ] 搜“离异”“单亲”“低保”“困难”“留守”“抑郁”“多动”“随班就读”“处分”：都没有。
- [ ] 搜“笨”“懒”“差生”“后进”“问题学生”“没出息”：都没有。
- [ ] 每条都用“你”；每条只有一条建议，写成能做的事。
- [ ] 把各条的第一句排在一起看：开头没有重复；“希望你再接再厉”之类的同一句话没有在三条以上出现。
- [ ] 每条中的数字、作品名、奖项都能在事实表中找到；缺事实的学生只写了【待补】。
- [ ] 输出用编号，没有学生姓名。

面向家长的材料（家长信、家长会讲话）：
- [ ] 搜“检查”“批改”“签字”“打卡”“上传”：没有要求家长检查、批改作业，没有打卡上传任务（回执签字可以）。
- [ ] 搜“排名”“名次”“成绩”：没有公布成绩和排名。
- [ ] 搜“一年级”“二年级”：没有家庭书面作业。
- [ ] 搜“套”“张”“份”：试卷练习没有超出作业时长要求。
- [ ] 搜“收”“缴”“交”“元”“费”：收费写了依据文件和文号、标准、自愿原则；没有“统一订购”“统一办理保险”。
- [ ] 搜“培训”“辅导班”“补习”：没有推荐校外培训。
- [ ] 搜“保证”“一定能”“重点”：没有承诺升学。
- [ ] 搜“同学”：没有点名批评。
- [ ] 搜“转发”“点赞”“投票”“下载”：没有非必要的要求。
- [ ] 放假、开学时间、联系电话都来自用户提供的材料。

记录类材料：
- [ ] 时间、地点、人数、内容都有用户材料依据，缺的标了【待补】。
- [ ] 效果写的是看得到的结果，没有“效果良好”“意识明显提高”之类的套话。
- [ ] 发言归到了正确的人名下；分不清的写“有教师提出”。
