# 九类文书速查

网页版、内网提示词版读不到 `references/templates/` 时，按本表起草。每类列出结构、必须来自用户的事实、最常见的毛病。“红线”指 `references/redlines.md` 的条号。

## 一、学期工作计划和总结（学校、处室、年级组、教研组）

- 计划结构：开头一两句写本学期重点；一、德育；二、教育教学（课程、常规、作业管理、课后服务）；三、教师队伍；四、安全与后勤；五、家校协同；六、行事历（周次｜时间｜事项｜负责部门）。处室只写本条线。
- 总结结构：开头写学期和总体情况；一、主要工作和成效（按板块）；二、存在的问题；三、下学期打算（与问题对应）。
- 来自用户：学生数、活动次数、参与率、达标率、获奖、问题、下学期安排。
- 常见毛病：开头铺垫“双减”背景意义；写考试排名（红线二）；计划写成口号，没有“谁、做什么、何时”。

## 二、督导评估自评报告

- 结构：开头写学校基本情况和自评组织情况；一、自评总体情况（等级或得分由学校提供）；二、各项指标达成情况（二级标题与指标一一对应，每项写做法、数据、佐证材料名称）；三、特色做法（可选）；四、存在的问题和原因；五、整改措施；附佐证材料清单。
- 来自用户：指标体系、各项落实情况、佐证材料、自评结论。没有指标体系的，按办学方向、课程教学、教师发展、学校管理、学生发展五个方面成稿，起草说明写明正式自评以督导部门下发的指标为准；不按印象编指标。
- 常见毛病：抄指标原文当达成情况；替学校写“全面达标”；“正在推进”写成“已完成”；为迎检补造材料（红线八）。
- 县级教育部门写县域优质均衡自评：按资源配置、政府保障程度、教育质量、社会认可度四个方面，指标和标准值只用用户提供的原文。

## 三、班主任工作计划和总结

- 结构：一、班级基本情况（人数、整体特点，不点名）；二、工作目标（能检验）；三、主要工作（班集体建设、主题班会、学习习惯、安全教育、家校沟通、个别学生关注）；四、行事历。总结按同样板块写完成情况，再写问题和下学期打算。
- 来自用户：人数、班会和活动次数、家访人数、具体事例。
- 常见毛病：写全校通用的话；个案写家庭、心理、处分信息（红线一）；写排名。

## 四、家长会讲话稿

- 结构（班主任约12分钟，约2400字，按扣除家长提问后的时长算）：称呼和感谢，直接说讲几件事；本学期班级情况，用整体数据和不点名的事例；下阶段安排和时间节点；需要家长配合的事3～5件，每件写做什么、怎么做、为什么；沟通渠道和结尾。校长对全校家长讲的，写学校层面的变化和统一要求。
- 时长：每分钟约200字（画像另有语速的按画像），以±10%为目标，超了先删铺垫和重复要求；起草说明写换算依据和实际字数。
- 来自用户：讲话时长、班级人数、活动和集体获奖、时间节点、会后交流安排和联系方式。
- 写法：口语化，短句，称呼“各位家长”；不点名批评，不在学生、班级之间比较；不指责家长，提要求用商量的口气并说明原因；家长配合事项写作息、运动、阅读陪伴、手机使用等生活和陪伴类。
- 常见毛病：开场写景铺垫；公布成绩排名（红线二）；让家长检查作业、签字（红线三）；承诺升学（红线九）；空泛号召，应写成具体做法，如“每周抽一个晚上和孩子聊聊学校里的事”。
- 学段：一年级讲入学适应和接送安全；初三、高三的升学政策只介绍用户提供的当地通知原文；线上家长会每部分更短，会后把事项（不含成绩）发到家长群。

## 六、安全教育记录

- 格式：时间（年月日、星期、节次）；地点；主题；主讲；参加对象和实到人数；形式；主要内容；活动过程；效果和后续安排；记录人。演练另加科目、参演人数、疏散用时、发现的问题。
- 来自用户：全部内容。只整理已开展的活动，不补造没开展的（红线八）。
- 常见毛病：写“效果良好”“意识明显提高”；人数、时间凭推测填。

## 七、致家长的一封信

完整模板随附：按 `references/templates/zhi-jiazhang-xin.md` 写；教育局写给全体家长的，见模板第七部分。

## 八、教研活动记录

- 格式：时间；地点；主持人；参加人员（学科和人数）；活动类型；主题；一、主备人说课或执教情况；二、研讨发言（归到发言人）；三、形成的共识；四、后续安排（谁、何时、做什么）；记录人。
- 来自用户：笔记、录音转写、课件。只整理，不添加；没有共识的照记分歧。
- 常见毛病：把具体发言改成空话；替教研组下结论；补造没开展的活动记录。

## 九、课后服务方案

- 结构：开头写依据和目标；一、服务对象和原则（自愿参加、家长申请）；二、服务时间；三、服务内容（作业辅导、素质拓展）；四、组织实施（报名、编班、师资、考勤、交接）；五、安全管理；六、经费保障；七、监督评价；附课程表、申请表。
- 来自用户：上级通知原文、服务时段、收费或经费依据、本校师资和课程。
- 常见毛病：写“全体必须参加”、安排新课（红线六）；收费无依据（红线五）；照抄上级通知，没有本校流程。

## 十、检查项和级别（审稿模式逐项查；不能运行脚本时自检）

级别：P0 必须改，P1 建议改，P2 请用户判断。高中、中职材料的排名、家长作业两类降为 P1，一、二年级书面作业和课后服务两类不查。

|---|---|---|
| 没有学生姓名、学号、身份证号、家长手机号、住址 | P0 | 看人名和长数字 |
| 没有家庭经济、家庭结构、健康、心理、特殊教育需求、处分信息 | P0 | 搜“离异”“单亲”“低保”“困难”“留守”“抑郁”“随班就读”“处分” |
| 没有考试排名；面向家长的材料没有分数 | P0 | 搜“名”“排”“倒数”“分”；比赛名次可以写，写明比赛名称 |
| 评语没有写考试分数 | P1 | 同上 |
| 没有要求家长检查、批改作业或签字，没有给家长布置作业 | P0 | 搜“检查”“批改”“签字”；回执签字可以 |
| 没有拍照上传、打卡任务 | P1 | 搜“拍照”“打卡”“上传” |
