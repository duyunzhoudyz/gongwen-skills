## 一、学段和办学类型

| 类型 | 本包要注意 |
|---|---|
| 小学 | 一、二年级不布置家庭书面作业、不进行纸笔考试；三至六年级书面作业平均完成时间不超过60分钟（S04、S05） |
| 初中 | 书面作业平均完成时间不超过90分钟；综合素质评价用于高中招生的办法以本省为准 |
| 九年一贯制、完全中学、十二年一贯制 | 分学段适用；材料中按学段分别写 |
| 普通高中 | 双减意见和义务教育考试管理通知不直接约束，按本省规定；综合素质评价按教基二〔2014〕11号和本省办法 |
| 中等职业学校 | 有专业部、实习实训；双减意见不适用；实习安全单列 |
| 特殊教育学校 | 学生信息尤其敏感；评语、记录不写残疾类别和程度 |
| 幼儿园 | 参照本包；不写学业评价式评语，不写“排名”“考试” |

## 二、领导体制和决策程序

1. 公办中小学实行党组织领导的校长负责制（S01）。党组织会议讨论决定“三重一大”等事项；校长办公会议（校务会议）由校长召集，研究教育教学和行政管理工作。
2. 教代会：教职工80人以上建立教代会，不足80人建立教职工大会，每学年至少召开一次（S02）。教代会上的学校工作报告交 gongwen-report。
3. 本包材料涉及的程序：学期计划一般经校长办公会议研究；课后服务方案、收费事项按上级规定和学校程序办理；涉及“三重一大”的由党组织会议研究决定。起草说明提示程序，不替学校决定。

## 五、工作板块

学校计划总结的常用板块：德育（含思政课、主题教育、心理健康）；教育教学（课程实施、教学常规、作业管理、课后服务、质量监测）；教师队伍（师德师风、教研、培训）；安全与后勤（安全教育、校园安全、食品安全）；家校协同；党建（单独成文的交 gongwen-party）。

用户没给分类时，可参照以下两套框架：

1. 《义务教育质量评价指南》（S09）学校层面：办学方向、课程教学、教师发展、学校管理、学生发展。学生发展质量：品德发展、学业发展、身心发展、审美素养、劳动与社会实践。
2. 《义务教育学校管理标准》（S03）六大管理职责：保障学生平等权益、促进学生全面发展、引领教师专业进步、提升教育教学水平、营造和谐美丽环境、建设现代学校制度。

督导自评报告的板块以督导部门下发的指标体系为准，以上框架只在没有指标时用来搭架子，并在起草说明中写明。

## 六、数据口径

| 数据 | 常见来源 | 写法 |
|---|---|---|
| 在校生数、班级数、教职工数、专任教师数 | 教育事业统计、学籍系统 | 写明统计时点 |
| 课后服务参与率 | 课后服务报名记录 | 写明分子、分母，如“538÷612＝87.9%”（数字为示意） |
| 作业时长 | 作业公示和抽查记录 | 写明抽查方式和范围 |
| 体质健康测试达标率 | 国家学生体质健康标准测试数据 | 写明测试年份 |
| 近视率 | 视力筛查记录 | 写明筛查时间 |
| 家访覆盖率 | 班主任家访记录 | 要求为每学年每名学生至少1次（S15） |
| 安全演练次数 | 演练记录 | 要求为每学期至少1次（S18 第四十二条） |
| 进校园活动次数 | 学校登记 | 每校每学期各类进校园活动不超过6次（S12） |

数据只用用户提供的，没有的标【待补】。几份材料说法不一的，列口径冲突表请用户确认。

## 七、学期和时间

1. 学年从9月开始：第一学期为秋季学期（9月至次年1月），第二学期为春季学期（2月至7月）。写法如“2026—2027学年第一学期”。
2. 周次按校历；放假、开学时间以教育局校历通知为准，用户没给的标【待补】。
3. 写作节点见 `references/calendar.md`。

## 八、单位差异

| 情形 | 调整 |
|---|---|
| 城区大规模学校 | 板块齐全；数据多，台账和对账必做 |
| 乡村小规模学校、教学点 | 板块可合并，不凑板块；教师一人多岗，计划写清分工 |
| 寄宿制学校 | 增加宿舍管理、晚自习、周末返校安全 |
| 高校附属中小学 | 发文、编号、用印按大学规定；部分事项报大学相关部门；单位画像可写“高校附属”，落款用附属学校名称 |
| 民办学校 | 决策机构为董事会或理事会；收费按批准的标准，依据由用户提供 |
| 县级教育部门（单位类型：基层） | 可用本包的致家长的一封信、县域督导自评；落款为教育局，主语“我县”“我们” |
| 市级以上教育行政部门（单位类型：党政机关） | 可用本包的致家长的一封信；对外发布叠加严谨模式；其余公文交核心 skill |
