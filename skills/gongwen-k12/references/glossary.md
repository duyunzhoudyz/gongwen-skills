## 一、体制与管理

| 术语 | 解释 | 出处 |
|---|---|---|
| 党组织领导的校长负责制 | 公办中小学的领导体制，党组织全面领导学校工作，校长在党组织领导下全面负责教育教学和行政管理 | S01（2022年） |
| 党组织会议 | 讨论决定"三重一大"、基本管理制度、机构设置和干部任免等事项 | S01 |
| 校长办公会议（校务会议） | 校长召集主持，研究教育教学和行政管理工作 | S01 |
| 教代会 | 教职工代表大会；80人以上建立，不足80人建立教职工大会，每学年至少一次 | S02（2011年） |
| 学校管理标准 | 义务教育学校的六大管理职责 | S03（2017年） |
| 进校园"白名单" | 社会事务进校园实行清单管理；省级白名单一般控制在10项以内，每校每学期各类进校园活动不超过6次 | S12（2025年） |
| 教师减负 | 减轻中小学教师与教育教学无关的负担 | S12、S13 |

## 二、作业、考试与课后服务

| 术语 | 解释 | 出处 |
|---|---|---|
| 双减 | 减轻义务教育阶段学生作业负担和校外培训负担 | S04（2021年） |
| 作业公示 | 学校建立作业校内公示制度 | S04 第4条 |
| 书面作业时长 | 小学一、二年级不布置家庭书面作业；三至六年级平均不超过60分钟；初中平均不超过90分钟 | S04 第5条 |
| 等级评价 | 义务教育学校期中期末考试和日常考试结果实行等级评价，不排名、不公布 | S05（2021年）；S23 第14条（2025年） |
| 课后服务 | 学校在上课日正常教学结束后提供的服务，学生自愿参加，不讲新课 | S04 第9、10条 |
| 5+2 | 课后服务每周5天都开展，每天至少2小时 | S06（2021年） |
| 延时托管 | 对家长接孩子有困难等有特殊需要的学生，在课后服务结束后继续提供托管 | S04 第9条 |
| 弹性上下班 | 学校统筹安排参与课后服务的教师错时上下班 | S04 第9条 |
| 五项管理 | 中小学生作业、睡眠、手机、读物、体质管理 | 共享画像 zhongxiaoxue.md |

## 三、评价与督导

| 术语 | 解释 | 出处 |
|---|---|---|
| 综合素质评价 | 对学生思想品德、学业水平、身心健康、艺术素养、社会实践等方面的评价（普通高中） | S08（2014年） |
| 写实记录 | 综合素质评价的第一个环节，客观记录反映学生综合素质的具体活动，由学生本人记录、教师指导审核（以本省办法为准） | S08 |
| 义务教育质量评价 | 县域、学校、学生三个层面的质量评价 | S09（2021年） |
| 教育督导 | 对政府履行教育职责和学校办学的督导、评估、监测 | 通用说法 |
| 责任督学挂牌督导 | 每所学校设责任督学开展经常性督导，一般1人负责5所左右学校 | S11（2013年） |
| 综合督导 | 每校每年接受县级及以上教育综合督导不超过1项 | S12 |
| 自评报告 | 学校对照督导评估指标逐项自查后形成的报告 | 通用说法 |
| 优质均衡 | 县域义务教育优质均衡发展督导评估，看资源配置、政府保障程度、教育质量、社会认可度 | S10（2017年） |
| 佐证材料 | 证明某项指标落实情况的原始材料 | 通用说法 |

## 四、德育、班级与家校

|---|---|---|
| 班主任职责 | 了解关怀学生、班级管理、组织班会和活动、综合素质评价和操行评定、与家长社区沟通 | S14 第八至十二条（2009年） |
| 操行评定 | 班主任对学生品行表现的评定，实事求是 | S14 第十一条 |

| 家访 | 班主任每学年对每名学生至少开展1次 | S15（2023年） |
| 家长会、学校开放日、家长接待日 | 家校沟通的常规制度 | S15 |
| 家庭教育指导服务活动 | 学校每学期至少组织2次 | S15 |
| 家长委员会 | 学校、年级、班级层面的家长组织；不得以其名义违规收费 | S15 |
| 家校社协同育人 | 学校、家庭、社会共同育人的机制 | S15 |

## 六、安全

| 术语 | 解释 | 出处 |
|---|---|---|
| 安全工作档案 | 学校记录日常安全工作、安全检查和隐患消除等情况的档案 | S18 第二十七条（2006年） |
| 集中安全教育 | 开学初、放假前有针对性地对学生集中开展 | S18 第三十九条 |
| 紧急疏散演练 | 每学期至少一次，针对洪水、地震、火灾等 | S18 第四十二条 |
| 全国中小学生安全教育日 | 每年3月最后一周的星期一 | S19（1996年起） |
| 防溺水"六不" | 教育部基础教育司致家长的信中的防溺水要求 | S20 |
| 一岗双责 | 岗位业务和安全责任一并承担，学校安全管理常用说法 | 通用说法 |
