# 中小学写作日历

按月列出学校的写作高峰和对应 skill。时间是常见惯例，具体以当年教育局校历、上级通知和本校安排为准；提示用户时用“一般”“通常”。共享的通用日历见总入口 gongwen。

## 一、按月

| 月份 | 典型材料 | skill |
|---|---|---|
| 2月 | 学校和各处室学期工作计划；开学安全教育记录；开学致家长的一封信；班主任工作计划 | gongwen-k12 |
| 2–3月 | 开学典礼讲话 | gongwen-speech |
| 3月 | 教代会学校工作报告（多在学期初）；全国中小学生安全教育日（3月最后一周的星期一）安全教育记录 | gongwen-report、gongwen-k12 |
| 4–5月 | 期中家长会讲话；期中成绩统计和图表；期中教学质量分析报告 | gongwen-k12、gongwen-data、gongwen-report |
| 5月 | 防灾减灾日（5月12日）疏散演练记录；防溺水致家长的一封信 | gongwen-k12 |
| 6月 | 中考、高考保障通知；期末工作安排 | gongwen-draft |
| 7月 | 学期工作总结；班主任工作总结；学生期末评语；暑假致家长的一封信；放假前安全教育记录 | gongwen-k12 |
| 8月底–9月 | 学期工作计划；班主任工作计划；课后服务方案（新学期调整）；开学安全教育记录 | gongwen-k12 |
| 9月 | 开学典礼讲话；教师节（9月10日）表彰讲话 | gongwen-speech |
| 10–11月 | 期中家长会讲话；期中成绩统计和图表；期中教学质量分析报告；全国消防日（11月9日）演练记录 | gongwen-k12、gongwen-data、gongwen-report |
| 12月–次年1月 | 学期工作总结；班主任工作总结；学生期末评语；寒假致家长的一封信；放假前安全教育记录；教师学年考核和述职 | gongwen-k12、gongwen-report |

## 二、按周期或事件

| 时间 | 材料 | skill |
|---|---|---|
| 每周或每两周 | 教研活动记录、主题班会记录 | gongwen-k12 |
| 收到督导通知后 | 督导评估自评报告和佐证材料清单 | gongwen-k12 |
| 督导反馈后 | 整改方案、整改报告 | gongwen-rectify |
| 收到上级课后服务、作业管理等文件后 | 课后服务方案（gongwen-k12）；其他落实方案（gongwen-implement） | gongwen-k12、gongwen-implement |
| 按周期（一般3–5年） | 学校发展规划 | gongwen-report |
| 活动结束后 | 校园新闻稿、公众号推文 | gongwen-brief |
| 事件发生后 | 安全事件情况报告 | gongwen-draft |

## 三、提示示例

用户在6月下旬说“最近要准备什么”，画像为中小学、班主任时：

```text
6月下旬到7月初，班主任一般要准备这几件：
1. 本学期班主任工作总结（gongwen-k12）
2. 学生期末评语，可以先把每名学生的具体表现列成事实表（gongwen-k12）
3. 暑假致家长的一封信，放假时间请以教育局校历为准（gongwen-k12）
先从哪一件开始？
```
