# 学期工作计划和总结

适用于学校、处室（教务处、德育处、总务处、安全办）、年级组、教研组以学期为周期的工作计划和总结。班主任的班级计划总结见 `references/templates/banzhuren-jihua-zongjie.md`。

## 一、用途和边界

- 学期计划：学期初（2–3月、9月）写，说清本学期做什么、谁来做、何时完成。
- 学期总结：学期末（1月、7月）写，说清做了什么、做成什么样、还差什么、下学期怎么办。
- 不归本模板：教代会上的学校工作报告、校长述职、学校发展规划交 gongwen-report；依据上级文件逐条落实的专项方案交 gongwen-implement；督导反馈问题的整改交 gongwen-rectify。

## 二、开工前优先问的三件事

1. 哪个学期，以谁的名义（学校、某处室、某年级组），报给谁（教育局、校长室、存档）。
2. 素材：上学期总结、本学期上级要求、各条线报上来的材料、统计数据。
3. 篇幅要求。

其余用默认值，写进起草说明“所作假设”。

## 三、结构

学校学期工作计划：

```text
某小学2026—2027学年第一学期工作计划
开头：一两句，写本学期的工作重点，引出下文。
一、德育工作
二、教育教学（课程实施、教学常规、作业管理、课后服务）
三、教师队伍建设（师德、教研、培训）
四、安全与后勤
五、家校协同
六、行事历（周次｜时间｜事项｜负责部门）
```

处室、年级组、教研组的计划只写本条线，按“目标、任务和措施、行事历”三部分写。

学期工作总结：

```text
某小学2026—2027学年第一学期工作总结
开头：学期、总体情况一两句。
一、主要工作和成效（按德育、教育教学、教师队伍、安全与后勤、家校协同分节）
二、存在的问题
三、下学期工作打算
```

## 四、写法

1. 板块按学校条线分；用户没给分类的，按 `references/profile-detail.md` 第五部分搭框架。
2. 计划的每项任务写到“谁来做、做什么、何时完成”；行事历用表格，周次以校历为准。
3. 总结的成效按“做了什么、数据或事例、结果”写。数据只用用户提供的，缺的标【待补：说明】。
4. 质量部分写措施和变化，不写学生、班级的考试排名（`references/redlines.md` 第二条）。用户材料中有排名的，正文不用，起草说明提示。
5. 计划中出现给教师摊派与教育教学无关的任务、白名单以外的进校园活动，起草说明提示核对（红线第十条）。
6. 问题写具体：哪项工作、差在哪里、有什么影响，只用用户提供的问题。下学期打算与问题一一对应，没有对应措施的，按常规写出可执行措施，责任主体只用材料已有的部门，时限、负责人标【待补】。
7. 状态不升级：计划中的事写“将”“拟”；“准备申报市级文明校园”不写成“已获评”；“劳动实践周”没开展的不写成开展了。
8. 用户提供了本学期计划的，总结逐项对照写完成情况，没完成的写明原因。

## 五、数据项（用户提供才写）

在校生数、班级数、教职工数；课后服务参与人数和参与率；作业公示和抽查情况；体质健康测试达标率、近视率；安全教育和演练次数；家访覆盖率；教研活动次数、公开课节数；获奖（写明级别、名称、主办单位）。

率类指标在素材台账中写出算式，例如“课后服务参与率＝538÷640＝84.1%”（数字为示意）。

## 六、常见毛病

1. 开头铺垫背景和意义。
   - 误：随着“双减”政策的深入推进，教育高质量发展对学校工作提出了新的更高要求。
   - 正：本学期，学校把学生体质健康和食堂管理作为两项重点。现将工作情况总结如下。
2. 写考试排名。
   - 误：本学期七年级数学均分比邻校高出6分，七（4）班列年级第二。
   - 正（材料：七年级英语早读增加了听力跟读）：七年级英语在早读时增加了听力跟读，期末听力部分的等级分布【待补：与上学期相比的变化】。
3. 计划写成口号。
   - 误：进一步加强安全教育，切实提升安全意识。
   - 正：9月第2周各班上好开学安全教育课，德育处负责；10月组织一次消防疏散演练，安全办负责。
4. 问题写成变相表扬。
   - 误：教师工作热情高，经常加班加点。
   - 正（材料：实验室只有一间，五年级分组实验排不开，有的改成老师演示）：科学实验室只有一间，五年级的分组实验排不开，部分实验改为教师演示。

## 七、学段差异

- 小学：作业管理写一、二年级不布置家庭书面作业的落实情况。
- 初中：加入中考备考、学业水平考试安排，时间以上级通知为准。
- 高中：加入选课走班、生涯规划、综合素质评价组织；双减意见和义务教育考试管理通知不直接约束，按本省规定。
- 中职：按德育、专业建设、实习实训、就业升学组织，实习实训安全单列。
