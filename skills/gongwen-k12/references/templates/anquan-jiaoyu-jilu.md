# 安全教育记录

## 一、用途和边界

记录已经开展的安全教育活动：安全主题班会、安全教育课、专题讲座、应急疏散演练，以及开学初、放假前的集中安全教育。学校应当建立安全工作档案（《中小学幼儿园安全管理办法》第二十七条，`references/sources.md` S18），安全教育记录是其中一部分。同一办法还规定：安全教育纳入教学内容（第三十八条）；开学初、放假前有针对性地集中开展安全教育（第三十九条）；每学期至少开展一次针对洪水、地震、火灾等灾害事故的紧急疏散演练（第四十二条）。

借用流程：按 gongwen-minutes 的做法整理，只整理，不添加。

不归本模板：演练方案、安全工作方案交 gongwen-report；安全事件情况报告交 gongwen-draft；给家长的安全提醒用 `references/templates/zhi-jiazhang-xin.md`。

## 二、开工前优先问的三件事

1. 活动类型、时间、地点、组织者或主讲人。
2. 参加对象和人数。
3. 原始材料：笔记、课件、签到表；学校有固定记录表的，请提供栏目。

## 三、记录格式

下面的格式示例中，时间、班级、主题都是示意，实际一律照用户材料填写，材料没有的标【待补】。

```text
安全教育记录
时间：2026年5月11日（星期一）下午第二节
地点：五（4）班教室
主题：防震避险
主讲：班主任
参加对象：五（4）班学生，实到【待补：人数】人
形式：安全教育课
主要内容：
1. ……
2. ……
活动过程：……
效果和后续安排：……
记录人：……
```

应急疏散演练记录另加：演练科目；参演人数；从发出警报到全部到达安全区域的用时；发现的问题和改进措施。数据只用用户提供的。

## 四、只整理，不补造

1. 记录只来自已经开展的活动。时间、地点、组织者、参加对象和人数、内容、过程、效果，都要有用户提供的依据：笔记、签到表、课件、照片说明。
2. 用户要求"补"没有开展过的活动记录的，不写（`references/redlines.md` 第八条）。用一句话说明原因：补造的记录是虚假台账，迎检时也经不起核对。然后提供本学期剩余周次的安全教育安排表和空白记录模板，活动开展后再记录。
3. 活动开展了、细节记不全的，缺的写【待补：说明】，不推测"学生积极参与，效果良好"。
4. 材料写"几个""一些"的，照写"几名""部分"，不换成具体人数；年份没写的，起草说明写明按哪一年记，或标【待核实：年份】。

## 五、写法

1. 时间写全：年、月、日、星期、节次，与校历核对。
2. 内容写具体讲了什么。例如防溺水教育讲"六不"（来源见 S20，以当年原文为准）。
3. 效果写看得到的结果，不写评价套话。
   - 误：通过本次活动，同学们的安全意识得到了极大提高，取得了良好的效果。
   - 正（笔记：请几个学生演示"伏地、遮挡、手抓牢"，有学生躲到了窗边，当场纠正）：活动最后请几名学生上台演示"伏地、遮挡、手抓牢"，有学生躲到了窗边，当场纠正。
4. 不写学生姓名；需要记录个别情况的，用"某同学"。
5. 记录人写实际记录的人。
6. 一次活动一份记录，一般300～600字；用户学校有固定表格的，按表格栏目填。

## 六、全年常见节点

以当年上级通知和校历为准。

| 时间 | 节点 |
|---|---|
| 开学初、放假前 | 集中安全教育（S18 第三十九条） |
| 3月最后一周的星期一 | 全国中小学生安全教育日（1996年起，2026年为3月30日，S19） |
| 5月12日前后 | 全国防灾减灾日，常组织疏散演练 |
| 5月至9月 | 防溺水教育 |
| 11月9日前后 | 全国消防日，常组织消防演练 |
| 每学期 | 至少一次紧急疏散演练（S18 第四十二条） |

## 七、数据项（用户提供才写）

时间（年、月、日、星期、节次）；参加对象和实到人数；活动时长；演练的参演人数和疏散用时；发现的问题条数。笔记里没有的一律标【待补】，签到表在别处的，请用户补报人数。
