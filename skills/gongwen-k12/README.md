# 中小学行业包（gongwen-k12）

> 版本 1.0.0　成熟度：Beta（测试版）

给中小学校长、中层干部、班主任和任课教师用的写作助手，专写学校里特有的材料：学期计划总结、督导自评、班主任计划总结、家长会讲话、学生评语、安全教育记录、致家长的一封信、教研活动记录、课后服务方案。

它先把你给的材料整理成台账或事实表，再搭结构，第一轮就交完整的稿子。你没给的数据一律标【待补】，不替你编；要问的问题（最多 3 个）放在回复末尾，不耽误出稿。学校材料的几条线它会替你守住：学生信息不外露，考试成绩不排名，不给家长布置作业，没开展过的活动不补记录。

## 能做什么

| 文书 | 说明 |
|---|---|
| 学期工作计划和总结 | 学校、处室、年级组、教研组；按德育、教学、教师队伍、安全、家校协同组织，计划带行事历 |
| 督导评估自评报告 | 按督导指标逐项写达成情况和佐证材料，附佐证材料清单；自评等级由学校定。县级教育部门的县域优质均衡自评也能写 |
| 班主任工作计划和总结 | 具体到本班；个别学生只写在校表现和教育措施 |
| 家长会讲话稿 | 按讲话时长控制字数（约每分钟200字），口语化；不点名、不公布成绩 |
| 学生评语 | 期末评语、综合素质评价教师评语；每人按事实写，查雷同；用编号代替姓名 |
| 安全教育记录 | 安全班会、安全教育课、疏散演练；只整理已开展的活动 |
| 致家长的一封信 | 寒暑假、开学、专项安全提醒、课后服务告知；可加家长群短信版 |
| 教研活动记录 | 集体备课、听课评课、主题研讨；发言归属准确 |
| 课后服务方案 | 自愿参加、作业辅导和素质拓展、考勤交接、经费依据 |

## 你可以这样说

1. “期末了，帮我给班上42个孩子写评语，每个孩子的情况我列在表里了。”
2. “下周三开家长会，我是初一班主任，要讲10分钟左右，帮我弄个发言稿。”
3. “市里要来做办学水平督导，这是评估细则和各处室交上来的材料，帮我写个自评报告。”
4. “寒假快到了，以学校名义给家长写封信，提醒一下安全。”
5. “这是上周英语组听课评课的笔记，帮我整理成教研活动记录。”

## 输入

- 必需：你手头的素材。工作记录、处室报上来的情况、学生情况表、录音转写、上级通知都可以，不用先整理。
- 最好说明：写给谁、谁来讲或以谁的名义发、多长或讲几分钟、哪个学段。
- 写评语：请准备学生事实表，每人两三件具体表现和一条需要改进的地方。姓名请用编号（S01、S02）或座号代替。
- 可选：单位画像 `.gongwen/单位画像.md`、领导偏好卡。没有也能用。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 纯文本正文，可直接粘进 Word 或交给 gongwen-format 排版；评语为“编号：评语”每人一段 |
| `起草说明.md` | 所作假设、待补事项、待核实事项、保密提示、写作要点（教学模式） |
| `素材台账.md` 或 `评语事实表.md` | 每条事实的内容和来源 |

在网页大模型里使用提示词版时，依次输出正文、起草说明和台账。

## 本地脱敏和检查脚本

`scripts/k12_check.py` 只用 Python 标准库，不联网（读 .docx 需要 python-docx，读 .xlsx 需要 openpyxl）：

| 命令 | 作用 |
|---|---|
| `python scripts/k12_check.py mask 学生情况.xlsx --drop-sensitive` | 在本机把姓名换成 S01 等编号，删去身份证号、手机号、学号、住址，涉及家庭、健康、处分信息的句子换成【已略去】，另存脱敏稿和对照表。对照表只留在本机 |
| `python scripts/k12_check.py unmask 评语.txt 学生情况-对照表.csv` | 评语写好后，在本机把编号换回姓名 |
| `python scripts/k12_check.py comments 评语.txt --facts 学生情况-脱敏.md` | 查评语：贬损和标签用语、考试排名和分数、家庭健康处分信息、雷同和套句、篇幅、人称，并与事实表对账 |
| `python scripts/k12_check.py parents 家长信.txt` | 查面向家长的材料：要求家长检查批改作业、给家长布置作业、公布成绩分数和排名、收费和统一购买、推荐校外培训、强制参加课后服务、承诺升学、点名批评 |

高中、中职材料加 `--stage 高中` 或 `--stage 中职`。脚本输出的文件已存在时自动加 -v2，不覆盖。

## 注意事项

1. **保密**：请勿输入涉密信息和内部敏感信息；材料涉密的，请使用单位内网部署的模型。标有“内部资料”“不得外传”的材料会先停下来。学生姓名、学号、家长电话、家庭情况、心理健康等信息，请先脱敏。
2. **不编造**：学生表现、活动次数、参与人数、获奖、放假时间、收费标准、自评等级只用你提供的。缺的标【待补】，存疑的标【待核实】，都汇总在起草说明里。你只说“下周四”的，稿子里照写或标【待补：具体日期】，不替你推算日期；材料里加引号的本校提法原样保留。
3. **篇幅不注水**：你给了字数或讲话时长，按 ±10% 写；素材撑不起时，回复第一段会说明差多少、该补哪些材料，缺的地方标【待补】，不拿套话凑字数。
4. **只整理，不补造**：没开展过的班会、教研、家访，不会替你补记录；综合素质评价的写实记录要由学生本人填写，这里只给填写指引。
5. **政策以原文为准**：双减、考试管理、安全管理等要求标了文件和条款（见 `references/sources.md`），各地规定更细的，以你提供的本地文件为准。
6. **事实和判断由你负责**：它负责搭结构、守规矩、查错漏，材料是否报送、怎么定调由你和学校决定。

## 成熟度

Beta。9 类文书的模板、十条行业红线和本地脱敏检查脚本已可用，脚本配有单元测试（`tests/k12/`，含必错和必过标本）；评测用例见 `evals/`。v1.0 真实模型评测（Sonnet 5.5，17 条用例）中，A 组（装 skill）期望通过率 98.4%（124/126），编造 0 次，触发评测正例 10/10、反例 10/10，详见 `evals/results/v1.0-benchmark.md`。按决策 D7，行业包统一标 Beta，要等一线测试者反馈和人工盲评后再升级，条件见 `CONTRIBUTING.md` 的“成熟度从 Beta 升到 Stable”。已知局限：

- 制度依据于 2026-10-16 在线核实，地方规定差异大，督导指标、课后服务时间和收费以当地文件为准；
- 脱敏脚本识别不了家长姓名、单字名的昵称，交给 AI 前请再看一遍脱敏稿；
- 行业内容欢迎一线教师、校长贡献模板和术语。
