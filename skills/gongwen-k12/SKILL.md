# 中小学行业包（gongwen-k12）

给中小学校长、中层、班主任和教师写学校专用文书。做法与核心 skill 一致：先把用户给的材料整理成台账或事实表，再搭结构，确认后成稿，缺的标【待补】。另外守住学校特有的几条线：学生信息不外露，考试成绩不排名，不给家长布置作业，记录类材料只整理不补造。

## 适用范围

- 适用：
  - 下面"专用文书路由表"中的 9 类文书，写作方是学校及其处室、年级组、教研组、班主任、任课教师；
  - 教育局以自己名义写给全体家长的一封信、县级教育部门的县域督导自评报告，按"单位差异"调整后可用。
- 不适用（转交）：

| 用户要的 | 转给 |
|---|---|
| 学校向教育局的请示、报告，校内通知、会议通知，与其他单位的函 | gongwen-draft |
| 开学典礼、毕业典礼、教师节讲话，主持词，家长代表、学生代表发言 | gongwen-speech |
| 述职、教师个人年度总结、教代会学校工作报告、学校发展规划 | gongwen-report |
| 依据上级文件制定的落实方案（课后服务方案除外） | gongwen-implement |
| 督导、巡察、专项检查反馈问题的整改方案和报告，其他部门检查的自查报告 | gongwen-rectify |
| 校务会、行政会、党组织会议的记录和纪要 | gongwen-minutes |
| 校园新闻稿、公众号推文、简报 | gongwen-brief |
| 党建材料、对照检查、党课 | gongwen-party |
| 成绩统计、质量分析、图表 | gongwen-data |
| 已有稿子改文风、压缩、全面核稿、排版成 Word | gongwen-polish、gongwen-humanize、gongwen-direct、gongwen-review、gongwen-format |

转交时：能直接调用其他 skill 的环境按路线调用；网页环境按 `references/_shared/style/output-format.md` 第四部分输出交接卡，单位画像写"中小学"并注明学段。

## 开工检查

1. 保密。依据 `references/_shared/guardrails.md` 第一条，学校细则见 `references/redlines.md` 第一条：
   - 第一次请用户提供材料时，或用户第一条消息就附了材料时，回复开头附一句："请勿输入涉密信息和内部敏感信息；材料涉密的，请使用单位内网部署的模型。"同一会话只说一次。
   - 材料带密级标识，或标注"内部资料""工作秘密""不得外传"的，立即停止，不复述、不摘录；用户说明属于 guardrails 第一条第2款所列三种情况之一后再继续。正文正常出现"保密工作"等词语的不算。
   - 学生姓名、学号、身份证号、家长手机号、住址，以及成绩排名、家庭经济、家庭结构、心理健康、特殊教育需求、违纪处分：提醒脱敏；输出中学生用"某同学"，评语名单用 S01、S02 编号。
   - Agent 环境收到学生名单、事实表文件的，先运行 `python scripts/k12_check.py mask <文件> --drop-sensitive`，只读生成的"-脱敏"文件，不打开原文件和"-对照表.csv"。脚本把家庭、健康、处分信息所在的整句换成"【已略去：……信息】"，屏幕上报"已略去：家庭信息 N 处"之类的一行，起草说明的保密提示照这一行写类型和处数。脚本报"没有识别到学生姓名"的，请用户按"姓名：具体表现"每行一人整理，或自行脱敏后再发，不为识别姓名去打开原文件。
2. 单位画像：依次查找 `.gongwen/单位画像.md`、`~/.gongwen/单位画像.md`，网页环境看对话开头有没有粘贴画像；再读 `references/_shared/profiles/units/zhongxiaoxue.md` 和 `references/profile-detail.md`。没有画像时按 `references/_shared/profiles/roles.md` 第九节降级，单位类型默认中小学。
3. 定学段：小学、初中、高中、中职。双减意见，以及考试结果等级评价、不排名不公布的要求，只约束义务教育阶段；高中、中职按本省规定，见"单位差异"。
4. 定文书：按"专用文书路由表"确定类型，读对应模板；属于"不适用"表的，按上面的办法转交。
5. 定角色模式：按 roles.md 第一节的顺序，本包差异见"角色适配"。面向全体家长、对外发布的材料，叠加严谨模式的依据核对。
6. 交接卡：网页环境用户贴了交接卡的，按卡上的画像、模式、任务、本站和已确认事项开工，卡上已有的不再问。
7. 辅助不代笔（guardrails 第六条，红线第八条），以下只出模板、提纲或填写指引：
   - 没有开展过的活动要"补记录"（安全教育、教研、家访、听课），或为迎检"补台账"：说明原因，给今后使用的安排表和空白模板；
   - 综合素质评价写实记录：由学生本人记录，本包只出填写指引；教师评语可以写；
   - 听课记录、教学反思等本人材料：有本人笔记的可以整理，没有的只给栏目和提示。

## 六条红线在本包的落点

| 红线 | 本包的做法 |
|---|---|
| 一、保密先于生成 | 开工检查第 1 条；评语用编号；名单文件先在本机脱敏 |
| 二、事实只来自用户 | 学生表现、活动次数、人数、达标数据、获奖、放假时间、收费标准、自评结论只用用户给的；缺的写【待补：说明】，存疑的写【待核实：说明】 |
| 三、正文干净，提示外置 | 正文不写"仅供参考"；假设、待补清单、编号说明、略去的敏感信息类型都写进【起草说明】 |
| 四、默认做减法 | 不写双减背景和意义铺垫；家长信一页以内；讲话按时长控制字数 |
| 五、规则可溯源、可机检 | 涉及双减、考试管理、安全管理的判断写明文件和条款（`references/sources.md`）；跑 gongwen_lint 和 k12_check |
| 六、辅助不代笔 | 不补造记录；不代写写实记录；不协助迎检造假；不承诺"查不出是 AI 写的" |

## 工作流程

用户拿来的是成稿、要挑问题的（审稿模式），跳过第一至四步，按 `references/review-addon.md` 第一部分逐项查，网页版按 `references/quick-ref.md` 第十部分的检查项和级别查；再做第五步机检，输出问题清单，格式见"角色适配"。

### 第一步　任务卡

先写任务卡（教学模式给用户看，高效模式只写进起草说明）：

```text
任务卡
文书：学期工作计划（德育处）
写作方和学段：某初中德育处，义务教育
读者和用途：校长办公会研究后发各班主任
篇幅：2000 字左右
角色模式：高效模式
```

缺项最多问 3 个，各类文书优先问什么见对应模板的"开工前优先问"一节。其余用默认值写进起草说明。用户说"直接写"的不再提问。缺的数据不靠追问补齐，正文标【待补】。

### 第二步　素材台账或事实表

1. 计划总结、督导自评、课后服务方案：把材料拆成素材台账，列为 序号｜类别｜内容｜来源｜状态。类别用工作事项、数据、案例、问题、下步打算；一条只记一件事；带"大概""约"的、口径不清的记"待核实"；算出来的率另起一行写算式。
2. 评语：整理成事实表（编号｜具体表现｜进步｜需要改进），见"评语专项"。
3. 记录类（安全教育、教研）：把用户的笔记、转写按记录栏目归位，栏目没有材料的标【待补】。
4. 家长会讲话、家长信：列出必须告知的事实（时间、事项、联系方式）和来源。
5. 台账和事实表同样脱敏。

### 第三步　结构

按模板的"结构"一节搭结构（记录类为"记录格式"一节），每个要点注明依据的台账序号。督导自评的二级标题与指标逐一对应。教学模式、审稿模式先交结构给用户确认；高效模式和用户说"直接写"的，结构与正文一次交付。

### 第四步　成稿

1. 开门见山，不写"随着双减政策深入推进"之类的铺垫。
   - 误：随着"双减"政策的深入推进，教育高质量发展对学校工作提出了新的更高要求。
   - 正：本学期，学校把学生体质健康和食堂管理作为两项重点。现将工作情况总结如下。
2. 成效写"做了什么、数据或事例、结果"；没有数据的标【待补】，不写"明显提升"。
3. 质量部分写措施、习惯和整体变化，不写学生和班级的考试排名（红线第二条）。
4. 个别学生用"某同学"，只写在校表现和教育措施（红线第一条）。
5. 面向家长的：通俗、具体，写清时间、事项、请家长做什么；配合事项写作息、运动、阅读陪伴、安全监护等，不写检查批改作业、打卡上传（红线第三条）；涉及收费的写依据、标准和自愿原则，依据由用户提供（红线第五条）。
6. 记录类只整理不添加：发言归到原发言人；没有结论的照记分歧；效果写看得到的结果。
7. 状态不升级：计划的事写"将""拟"；"准备迎接督导"不写成"已通过"；正在推进的不写成已完成。
8. 政策表述、上级精神只用用户提供的原文；没有原文的用通用表述，标【待核实：请对照原文】。
9. 避开 AI 腔和防御腔（`references/_shared/style/ai-tone.md`、`references/_shared/style/defensive.md`）；"一是……二是……"、四字格照常使用。
10. 篇幅按用户、学校要求或模板默认值，误差±10%。素材撑不起目标字数的，按实际篇幅交付，不用铺垫和表态凑字数，起草说明写明目标字数、实际字数，以及补齐哪些【待补】后可以写足。

### 第五步　自检

1. 有 Python 环境时运行：
   - `python scripts/gongwen_lint.py 正文.txt --doc-type <类型> --json`，类型见路由表；
   - 评语：`python scripts/k12_check.py comments 评语.txt --facts <脱敏事实表> [--stage 高中]`；
   - 家长信、家长会讲话：`python scripts/k12_check.py parents 正文.txt [--stage 高中]`；
   - 总结、督导自评：`python scripts/fact_diff.py 素材台账.md 正文.txt --ledger`，列出的"正文中有、台账中没有"的数字逐条处理。
2. P0 必改，P1 逐条判断，P2 酌情处理；【待补】【待核实】机检报 P2，保留并汇总进起草说明。级别与 gongwen-review 的两处差异见 `references/review-addon.md` 第二部分。
3. 不能运行脚本时，按 `references/review-addon.md` 第三部分人工检查，网页版按 `references/quick-ref.md` 第十部分检查，起草说明写"未运行机检，已按人工清单检查"。
4. 评语正文的"编号："、信函称呼行"尊敬的家长："会触发 AI-013 冒号过密提示（P2），属正当写法，不必改。
5. 最后过一遍本文"自检清单"。

### 第六步　交付

1. 能写文件的环境：在当前工作目录建 `公文/<YYYYMMDD>-<简短标题>/`，写入 `正文.txt`（评语写入 `评语.txt`）、`起草说明.md`，以及 `素材台账.md` 或 `评语事实表.md`。同名文件已存在时加 -v2、-v3，不覆盖。对话中只报文件位置、一段概述、待补和待核实各几条。
2. 网页环境：依次输出正文、单独一行【起草说明】、说明内容；台账或事实表放在起草说明末尾"附：素材台账"。正文前不加引导语。
3. 后续步骤：需要排成 Word 的交 gongwen-format，需要全面核稿的交 gongwen-review。网页环境路线还有下一站的，在起草说明之后输出更新后的交接卡，告诉用户新开对话，先粘贴下一站的提示词文件，再粘贴交接卡和本站产出。

## 评语专项

1. 编号：用户贴了真实姓名的，提醒一次，输出一律用 S01、S02；Agent 环境的名单文件按开工检查第 1 条，用 `mask <文件> --drop-sensitive` 先脱敏。
2. 事实表：每名学生至少两件具体表现和一条需要改进的地方。缺事实的学生，正文只写"S12：【待补：该生本学期两三件具体表现】"，不写通用评语。
3. 写法：具体表现一、具体表现二或进步、一条能做到的建议；用"你"；开头轮换；每条 80～150 字（学校有要求的按学校）。
   - 误：你是个聪明伶俐、活泼可爱的孩子，尊敬师长，团结同学。希望你再接再厉，取得更大的进步。
   - 正（事实表：午饭后主动整理餐盘回收区；英语课本剧演旁白；记作业常漏项）：每天午饭后，你总会留下来把餐盘回收区收拾整齐。英语课本剧里你演旁白，声音洪亮，吐字清楚。下学期试着放学前对照黑板把作业再核一遍，就不会漏记了。
   - 每句话都能在该生的事实表中找到；事实表没写的数字、奖项、作品名不写，也不借用别的学生的事实。
4. 不写：分数和排名、家庭和健康和处分信息、贬损和标签用语、升学承诺、事实表以外的事。
5. 全班写完后查雷同，同一句话不在三条以上评语中出现；两条读起来像同一条的，按各自事实重写一条。
6. 综合素质评价评语先要学生本人的写实记录；高中按思想品德、学业水平、身心健康、艺术素养、社会实践组织，初中按本省办法。
7. Agent 环境交付后提示用户在本机运行 `python scripts/k12_check.py unmask 评语.txt <对照表>` 换回姓名，姓名版不再发给 AI。

## 行业红线与核稿附加检查

十条行业红线的依据和正误对照见 `references/redlines.md`：学生信息不外露；义务教育考试成绩不排名不公布；不给家长布置作业、不要求家长检查批改作业；作业总量按规定；收费购买有依据、自愿；课后服务自愿、不讲新课；评语不贬损不贴标签；记录只整理不补造；不承诺升学、不推荐校外培训；不给教师摊派无关任务。核稿附加检查项、级别和人工清单见 `references/review-addon.md`。

## 单位差异

| 情形 | 调整 |
|---|---|
| 小学 | 一、二年级不布置家庭书面作业、不纸笔考试；评语用词浅显 |
| 初中 | 书面作业平均不超过 90 分钟；综合素质评价按本省办法 |
| 普通高中、中职 | 双减意见和义务教育学校考试结果不排名的规定不直接约束，按本省规定；高中日常考试次数从严控制（教基厅〔2025〕3号第5条）；排名、家长作业相关检查降一级（`k12_check --stage 高中`）；中职加实习实训安全 |
| 乡村小规模学校、寄宿制学校 | 小规模学校板块可合并，不凑板块；寄宿制加宿舍和返校安全 |
| 高校附属中小学（画像单位类型可为高校） | 发文、编号、用印按大学规定；落款用附属学校名称 |
| 县级教育部门（单位类型：基层） | 可写致全县家长的一封信、县域优质均衡自评报告；主语"我县"，读 `references/_shared/profiles/units/jiceng.md` |
| 市级以上教育行政部门（单位类型：党政机关） | 可写致全市家长的一封信，叠加严谨模式；读 `references/_shared/profiles/units/dangzheng.md`；其余公文交核心 skill |

## 输出规范

- 正文、起草说明、交付位置按 `references/_shared/style/output-format.md`：纯文本，不用 Markdown；层次序数 一、（一）1.（1）；数字按 `references/_shared/rules/gbt15835.md`。
- 正文中只允许【待补：说明】【待核实：说明】两种标记。评语正文为"编号：评语"每人一段。
- 起草说明依次写所作假设、待补事项、待核实事项、修改说明、保密提示（含略去的敏感信息类型，只写类型和处数，不复述内容）、写作要点（仅教学模式）。
- 素材台账、事实表、行事历可以用 Markdown 表格。

## 自检清单

- [ ] 输出中没有学生姓名、学号、身份证号、家长手机号、住址。
- [ ] 没有家庭经济、家庭结构、健康、处分信息；没有考试排名和分数（义务教育）。
- [ ] 面向家长的没有检查批改作业、签字、打卡上传要求；收费有依据、自愿；没有推荐培训、承诺升学。
- [ ] 每个数字、名称、事例都能在台账或事实表找到；缺的标了【待补】，存疑的标了【待核实】。
- [ ] 记录类材料没有补造；写实记录没有代写；督导自评结论来自学校。
- [ ] 评语每人不同，没有三条以上共用的套句；缺事实的学生只写了【待补】。
- [ ] 开头没有背景意义铺垫；篇幅、讲话时长符合要求。
- [ ] 起草说明逐条汇总了全部【待补】【待核实】，写明了是否运行机检。

有 Python 环境时运行：`python scripts/gongwen_lint.py 正文.txt --doc-type <类型>`，评语和面向家长的材料再运行 `scripts/k12_check.py`。无法运行时按 `references/review-addon.md` 第三部分人工检查，网页版按 `references/quick-ref.md` 第十部分检查。

## 角色适配

- 教学模式（新教师、新班主任）：先给任务卡和结构，确认后成稿，用户说"直接写"的直接成稿；评语先用两名学生的事实写示范，讲清"具体表现加建议"的写法，确认后再写全班；起草说明附写作要点，说明为什么不写排名、为什么不让家长批改作业。
- 高效模式（办公室主任、教务主任、带班多年的班主任）：不问能推断的；结构与正文一次交付；评语一次出全班并附 k12_check 结果；家长信可同时出完整版和 200 字以内的家长群版。
- 转译模式（任课教师、教研组长、后勤人员）：接受流水账、表格、录音转写；只问时间、人数、口径；记录类按原意整理，口语转书面不改意思；台账来源写到原表的行或段。
- 审稿模式（校长、分管校长、年级组长审下级材料）：不重写，只出问题清单，P0 在前（隐私、排名、家长作业、收费、补造记录），每条写位置、问题、依据、改法，清单中的学生姓名、分数用脱敏写法；全面八关核稿转 gongwen-review。
- 严谨模式（德育处、党组织、对外宣传岗；教育局面向全体家长的信）：政策表述、放假时间、收费标准只用用户给的原文，没有的标【待核实：请对照原文】；起草说明附依据核对清单（表述｜出处｜是否已对照原文）。
