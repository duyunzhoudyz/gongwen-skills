# 村（居）务公开与公示

> 适用：村务公开、居务公开（事务、财务、决策、民生实事）、救助对象等名单公示的公开栏文本和线上同步文本。
> 不适用：对外宣传稿交 gongwen-brief；政府信息公开年报等机关材料交 gongwen-report。
> 何时读：用户要写公开栏内容、公示名单或检查公开内容时。
> 法律依据核验日期：2026-10-16。修改后的《村民委员会组织法》和修订后的《城市居民委员会组织法》均自 2026 年 1 月 1 日起施行，旧稿中的条文号要按新文本更新。

## 一、法定要求

| 项目 | 村务公开 | 居务公开 |
|---|---|---|
| 依据 | 《村民委员会组织法》第三十五条 | 《城市居民委员会组织法》第三十四条 |
| 公开方式 | 设立村务公开栏，可以采用现代信息技术公开 | 设立居务公开栏，可以采用现代信息技术公开 |
| 频次 | 一般事项至少每季度公布一次；集体财务往来较多的，财务收支情况每月公布一次；涉及村民利益的重大事项随时公布 | 及时公布 |
| 公布期限 | 不少于十五日 | 不少于十五日 |
| 真实性 | 保证所公布事项的真实性，接受村民查询 | 保证真实，接受居民查询 |

1. 村民认为村委会不及时公布或公布不真实的，有权向乡镇人民政府或者县级人民政府及其有关主管部门反映（《村民委员会组织法》村务公开相关条款）。公开栏写明监督渠道。
2. 村级重大事项决策实行“四议两公开”，即村党组织提议、村“两委”会议商议、党员大会审议、村民会议或者村民代表会议决议，决议公开、实施结果公开（《中国共产党农村基层组织工作条例》第十九条第三款）。各步骤的具体操作以当地规定为准。
3. 本地有村务公开目录、财务公开格式的，按本地规定执行，本文件的格式让位于本地规定。

## 二、公开什么

按法律列举的范围，结合用户提供的事项确定，常见的有：

| 类别 | 内容举例 | 事实来源 |
|---|---|---|
| 决策 | 村民会议、村民代表会议、居民会议决定的事项及实施情况；组织协商确定的事项及落实情况 | 会议记录、决议 |
| 财务 | 收入、支出、结余；集体资金、资产、资源的使用 | 财务账 |
| 资金物资 | 政府拨款、社会捐赠，救灾救助、补贴补助资金物资的管理使用 | 拨付文件、发放表 |
| 项目 | 公益事业建设项目、民生实事项目进展 | 项目台账 |
| 协助政府工作 | 协助人民政府或街道办事处开展的工作 | 工作台账 |

具体条目以两部法律的原文为准；用户只给了部分材料的，只公开有材料的部分，其余写入起草说明待补事项。

## 三、财务公开表

列为：序号｜日期｜收支项目｜摘要｜收入（元）｜支出（元）｜经办人（职务）｜凭证号。

1. 数据只抄财务账或用户给的明细，不估算、不四舍五入成“约”。
2. 金额统一以元为单位，保留两位小数；用户给的是万元的，换算后在起草说明写明换算。
3. 动手核对：期初余额＋本期收入－本期支出＝期末余额；收入、支出合计等于明细之和。对不上的不改数，标【待核实】并在起草说明列明差额。
4. 摘要写具体用途：“购买垃圾分类桶40个”，不写“办公经费若干”。
5. 招标、采购类支出写明方式和中标单位（来自用户）。

## 四、救助对象等名单公示

低保等救助对象的公示，按民政部门规定执行，与一般村（居）务公开的期限不同：

1. 乡镇人民政府（街道办事处）提出初审意见后，在申请家庭所在村、社区公示，公示期为 7 天（《最低生活保障审核确认办法》第十九条）。村（社区）协助张贴，内容以乡镇（街道）提供的为准。
2. 审核确认后公布的信息为申请人姓名、家庭成员数量、保障金额等，依法保护个人隐私，不得公开无关信息（同办法第二十四条）。
3. 不公开：身份证号、详细住址门牌、电话、病情、残疾等级、收入明细。名单只写到村民小组或楼栋。
4. 写明异议反映渠道和电话。
5. 村（居）务公开里一并张贴低保初审公示的，两个期限分开写：低保部分写“公示时间：7月10日至7月16日”（7 天），整份公开在末尾写“公开时间：7月10日至7月25日”（不少于十五日）。不把低保公示改成十五日，也不把整份公开缩成七日。低保公示的起止日期以乡镇（街道）提供的为准。

其他名单（评先评优、补贴发放、志愿者表彰）同样只公开与事项有关的必要信息。

## 五、公开栏文本的要素

```text
某村2026年第二季度村务公开

一、村民代表会议决定事项及实施情况
……
二、财务收支情况（4月1日至6月30日）
本期收入合计【待补】元，支出合计【待补】元，明细见附表《某村2026年第二季度财务公开表》。
三、民生实事项目进展
……

公开时间：2026年7月10日至7月25日
监督电话：村务监督委员会【待补：电话】；镇农村经营管理站【待补：电话】

某村民委员会
2026年7月10日
```

1. 标题写清单位、期间和“村务公开”或“居务公开”。
2. 公开时间写起止日期，不少于十五日。各地对首日计不计入算法不一（《民法典》第二百零一条规定按日计算期间的，开始的当日不计入），起止日期按本地惯例；拿不准时多留一天，如 7月10日至7月25日。
3. 写监督电话或反映渠道。
4. 线上同步的，内容与公开栏一致。

## 六、常见毛病与正误对照

| 毛病 | 误 | 正 |
|---|---|---|
| 期限不足 | 公示期：7月10日至7月16日（村务公开） | 公开时间：7月10日至7月25日（不少于十五日，留有余量） |
| 摘要笼统 | 支出：办公经费若干元 | 5月20日，购买垃圾分类桶40个，支出3200.00元，凭证第15号 |
| 合计对不上 | 收入合计与明细之和差600元，仍照公布 | 标【待核实：收入合计与明细差额】，请村会计核对后再公布 |
| 个人信息 | 低保户：赵某某，身份证号……，住2组8号，患肺癌 | 2组　赵某　家庭人口3人　月保障金额【待补】元 |
| 只报好的 | 未完成的项目不公开 | 未完成的写进展和原因 |

## 七、交付物

1. `正文.txt`：公开栏文本，纯文本，不放 Markdown 表格；财务部分写合计数和“明细见附表《……财务公开表》”。
2. `财务公开表.md`：Markdown 表格，张贴时作为附表打印；可用 `scripts/md2xlsx.py` 转 Excel，或交 gongwen-format 转成 Word 表格。网页环境把它放在起草说明末尾，标题为“附：财务公开表”。
3. `起草说明.md`：待补、待核实（合计差额）、保密提示（已删去或替换的个人信息）。
4. 有 Python 时运行 `python scripts/notice_check.py 正文.txt --kind 公示`，检查公开期限和个人信息。
