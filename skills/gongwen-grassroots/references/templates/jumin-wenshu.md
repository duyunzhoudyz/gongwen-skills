# 居民文书：通知、告知书、倡议书、温馨提示

> 适用：乡镇（街道）、村（居）委会写给居民、村民、商户的文书。
> 何时读：第一步判定为居民文书后，起草前读第一至六部分；写到处罚、强制、待遇等内容时读第七部分；自检时读第八至十部分。
> 本文件只讲面向群众的文书。乡镇（街道）发给村（社区）的工作通知、会议通知交 gongwen-draft；防汛防火等应急通知见 `yingji-tongzhi.md`；公示和村（居）务公开见 `wugongkai.md`。

## 一、先选对文书

| 想做的事 | 用什么 | 理由 |
|---|---|---|
| 让居民在某个时间、地点参加或办理某事（停水、体检、登记、活动、疫苗接种） | 居民通知 | 有时间、地点、对象要求 |
| 告诉特定对象一件与其权益或义务有关的事，请其在期限内处理（房屋安全隐患、补贴申领条件、车位调整） | 告知书 | 对象特定，常需签收留存 |
| 号召大家自愿参与（文明养犬、垃圾分类、节约用水、移风易俗） | 倡议书 | 只倡导，不强制 |
| 季节性安全提醒（防火、防诈骗、防溺水、燃气安全） | 温馨提示 | 以提醒为主 |
| 公开事务、财务，公示名单 | 公示 | 见 `wugongkai.md` |
| 设定义务、处罚的强制性规定 | 村（社区）不发；乡镇（街道）只在有法定权限时以通告发布，交 gongwen-draft | 居（村）委会是自治组织，没有行政执法权 |

行政处罚事先告知书、责令改正通知书等执法文书，由有执法权的部门按法定格式制作，本包不起草。用户要的是这类文书的通俗说明版（告诉当事人收到文书后怎么办）时，可以写，但不能替代执法文书。

## 二、通用要素

动笔前逐项核对，缺的在正文写【待补：说明】，不编：

| 要素 | 写法 | 例 |
|---|---|---|
| 对象 | 称呼行，以全角冒号结尾 | 各位居民：／12号楼全体住户： |
| 事项 | 第一句说清要做什么 | 12月9日（星期三）上午停电检修。 |
| 时间 | 日期加星期，具体到几点；跨天写起止 | 12月9日（星期三）9:00至16:00 |
| 地点 | 写到楼栋、门牌或明显地标 | 社区服务中心一楼大厅 |
| 需要带什么、怎么做 | 分条，一条一件事 | 请带身份证原件 |
| 特殊人群 | 老人、行动不便者的安排 | 行动不便的，可打电话预约上门 |
| 联系方式 | 联系人加电话；对外发布用工作电话 | 联系人：王某，电话：【待补：联系电话】 |
| 落款 | 发布单位全称；联合发布的并列 | 某社区居民委员会 |
| 日期 | 成文日期，用户没给的写【待补：成文日期】，不取系统日期 | 2026年6月18日 |
| 公章 | 张贴版加盖公章（`references/_shared/profiles/units/jiceng.md` 第八部分第 3 条） | 起草说明提醒 |

写日期时同时写星期的，逐个核对星期（有 Python 时 `scripts/notice_check.py` 自动核对）。日期和星期对不上的，问用户哪个对，不自行改。用户只给了星期几或“下周”“月底”的，正文保留原话或写【待补：具体日期】，不按当天日期推算。

## 三、居民通知

结构：
1. 标题：事项加“通知”，如“停电通知”“关于燃气安全入户检查的通知”。
2. 称呼。
3. 第一段一到两句：什么时间、在哪里、做什么、谁需要参加。
4. 分条写要求：时间、地点、对象、带什么、注意事项。
5. 特殊人群安排、咨询方式。
6. 落款、日期。

写法：
1. 开头直接说事，不写“为切实做好……根据上级有关要求”。用户坚持写依据的，压成半句：“按照区住房城乡建设局安排，……”（依据名称来自用户）。
2. 一句话一件事，单句一般不超过 60 字（工具约定）。
3. 语气是服务和提醒：用“请”“欢迎”“可以”，不用“务必”“必须准时”“否则后果自负”。
4. 涉及收费的，写清收费依据和标准；用户没给依据的标【待核实：收费依据】。
5. 涉及停水停电停气的，写明是哪个单位实施、原因、起止时间，社区只是转告。

误：为切实保障辖区居民用气安全，根据上级有关要求，经研究决定，兹定于近期开展燃气安全入户检查，届时请各户务必予以配合。
正：12月9日（星期三）至12月11日（星期五），每天9:00至17:00，燃气公司工作人员上门检查燃气管道和报警器。请家中留人；白天不在家的，请打电话约在晚上。

## 四、告知书

结构：
1. 标题：“关于……的告知书”。
2. 告知对象：户主或商户名称，可以只写“××号楼××户户主”。
3. 告知事项：发现了什么情况（来自检查记录或用户材料）。
4. 依据：法规或文件名称，只用用户提供的；没给的标【待核实：依据文件名称和条款】。
5. 需要对方做什么、在什么期限内做。
6. 对方的权利：有疑问或异议时找谁、怎么反映。
7. 联系方式、落款、日期。
8. 送达回执（可选）：签收人、签收日期两栏，留空由当事人填写。

写法：
1. 事实写具体：哪栋房子、什么部位、什么问题。检查记录没写的，不补细节。
2. 期限写具体日期，如“请于12月15日前”，不写“尽快”“限期”。
3. 后果只写法定后果和风险提示，处罚内容按第七部分处理。
4. 告知书一户一份时，正文共用，对象栏和事实栏分户填写，不在同一份上列多户信息。

误：经查，你户空调外机支架存在严重安全隐患，限你户立即整改，逾期不整改的将强制拆除并追究法律责任。
正：11月26日，社区网格员巡查时发现你户三楼空调外机支架锈蚀、有松动（见巡查记录）。请于12月15日前请专业人员加固或更换支架；需要联系维修人员的，社区可以帮忙对接。有疑问请联系社区居委会，电话：【待补：联系电话】。

## 五、倡议书

结构：
1. 标题：“××倡议书”。
2. 称呼：“各位居民朋友：”。
3. 缘由一到两句，写用户材料中的事实（如“近一个月，社区收到公共绿地被开垦种菜的反映9件”），没有事实的只写目的，不编数字。
4. 倡议事项分条，每条一个具体行动，3 到 6 条。
5. 结尾一句呼吁。
6. 发起方、日期。

写法：
1. 倡议邀请自愿参与，不带强制性。不用“必须”“严禁”“一律”“不得”，不写处罚、考核、通报、曝光。确实需要强制执行的，须改用通知并写明依据和执法主体，由有权限的主体发布：村（社区）没有这项权限，不写，向用户说明并建议转请乡镇（街道）或执法部门依法另行发布；乡镇（街道）有用户提供的依据和职权的，才改用通知。
2. 行动要具体：写“不在公共绿地种菜，已经种下的收获后请平整地面”，不写“自觉做爱绿护绿的践行者”。
3. 法律已经规定的义务可以提醒，写明出处（来自用户）：“按照《某市绿化条例》，任何单位和个人不得擅自占用绿地”。出处没给的，只写行为提醒，不写“依法”。
4. 发起方写清楚：社区居委会、业主委员会、志愿者协会联合发起的，并列落款。“我们”指谁要一致。
5. 结尾一句即可，不堆口号。

误：全体居民必须严格遵守绿化管理规定，严禁毁绿种菜，违者一律纳入不文明行为黑名单并在小区曝光。
正：公共绿地是大家的，请不要开垦种菜。已经种下的，请在收获后把地面平整好，物业会补种草坪。

## 六、温馨提示与群消息

温馨提示：
1. 3 到 5 条，每条一句话，先说做法再说原因。
2. 风险提示中的“可能”“容易”属于必要的谨慎，保留（`references/_shared/style/defensive.md` 第八部分）。
3. 写求助电话时用通用号码（119、110）和社区值班电话，值班电话来自用户。

群消息：
1. 篇幅控制在一屏以内，约 300 字（工具约定）。
2. 第一句就是事：时间、地点、做什么。
3. 不写标题、文号、主送等格式要素，末尾署名单位。
4. 不点名，不@未办理的居民，不发个人信息和照片。
5. 有张贴版的，群消息是张贴版的压缩版，两版的时间、地点、电话必须一致。

## 七、法律表述怎么写

面向群众的文书，逐句查强制措施和处罚表述。村（居）委会没有行政执法权；乡镇（街道）只能行使法律法规规定的职权，以及省级决定交由其行使的行政处罚权（《行政处罚法》第二十四条），具体以本地公布的赋权目录为准。

| 想说的 | 村（社区）能写 | 乡镇（街道）能写的条件 |
|---|---|---|
| 罚款、拘留 | 不写。可以提醒法定义务，写明法规名称（来自用户） | 本镇（街道）有该项处罚权，且用户提供了法规条款；否则写“由某部门依法处理” |
| 断水断电断气 | 不写 | 不写。供水供电单位按法规和合同办理，乡镇（街道）只转告 |
| 取消低保、补贴、待遇 | 不写 | 不写。低保由县级民政部门审核确认，部分地区已按程序下放乡镇（街道）（《最低生活保障审核确认办法》第二条）；本级有审核确认权的，也不在面向群众的通知里写取消低保 |
| 强制拆除、强制清理 | 不写 | 按法定程序由执法部门出具执法文书，通知中不预先宣布 |
| 曝光、黑名单、通报 | 不写 | 不写（个人信息保护） |
| 后果自负、追究责任、纳入考核 | 改为风险提示 | 改为风险提示或法定后果（写明依据） |

误：对不按规定分类投放的住户，社区将处以50元罚款，并在业主群曝光。
正：请按“厨余、可回收、有害、其他”四类投放。分错了也没关系，督导员会现场帮您分好。
正（用户提供了执法依据时）：按照《某市生活垃圾管理条例》第××条，个人不按规定分类投放的，由城市管理部门依法处理。

误：拒不配合入户排查的，取消其各类补贴资格。
正：入户排查时间可以预约，白天不方便的请打电话约在晚上或周末。

缺依据时：正文不写处罚和强制内容，起草说明写“用户原稿中的‘罚款50元’没有提供法律依据和执法主体，已删去；如确有依据，请提供法规名称和条款，并确认由哪个部门执行”。

## 八、通俗化改写对照

| 公文腔 | 对居民这样写 |
|---|---|
| 兹定于 | 定于、将在 |
| 届时 | 到时、当天 |
| 予以办理 | 帮您办理 |
| 务必 | 请 |
| 相关事宜 | 写明具体事项 |
| 广大居民群众 | 各位居民 |
| 配合做好入户登记工作 | 工作人员会上门登记，请您在家等候或预约时间 |
| 即日起 | 从12月1日起 |
| 高度重视、切实、落实落细 | 删去，直接写做法 |
| 属地管理、网格化、台账 | 换成居民听得懂的说法，如“由您所在楼栋的网格员负责” |

这张表只用于面向群众的文书。写给上级和村（社区）的材料照常使用公文用语。

## 九、张贴版和群消息版

| 项目 | 张贴版 | 群消息版 |
|---|---|---|
| 篇幅 | 300 至 600 字为宜（工具约定） | 约 300 字以内 |
| 格式要素 | 标题、称呼、正文、联系方式、落款、日期、公章 | 不要标题和格式要素，末尾署名 |
| 版式 | 大字号、短段落；时间地点和电话单独成行 | 分行发送，关键信息放前两行 |
| 交付 | 正文.txt，可交 gongwen-format 出 docx（张贴版） | 正文-群消息.txt |

## 十、常见毛病

1. 开头讲意义，第三段才说什么时间、在哪里。
2. 写了日期没写星期，或星期写错；跨月、跨年时最容易错。
3. 没有联系电话，或电话与上一版不一致。
4. 倡议书写成命令：“必须”“严禁”“违者”。
5. 自设罚款、断水断电、取消低保、曝光。
6. 公开居民姓名、门牌、电话；群里点名未办理的人。
7. 联合发布时没写清各方分工，“我们”指代不明。
8. 照抄上级通知，把“各街道要……”原样贴给居民。

## 十一、交付物

1. `正文.txt`：张贴版或主版本。
2. `正文-群消息.txt`：用户需要群发时提供；网页环境附在起草说明末尾，标题为“附：群消息版”。机检用 `python scripts/notice_check.py 正文-群消息.txt --kind 群消息`（文件名含“群消息”时脚本也会自动识别）。
3. `起草说明.md`：所作假设、待补、待核实、修改说明（删去了哪些强制性表述及原因）、保密提示（已替换的个人信息）。
4. 张贴版要排版的，交 gongwen-format，并说明按张贴版处理。
