# 版式信息.json 字段与单位画像对照

build_docx.py 的 `--meta` 参数读取本文件所列字段。键用中文，值为字符串，“附件”“发文机关署名”“签发人”“抄送”也可以写数组。没有写的字段，脚本从正文自动识别；识别不到又必须有的，写入【待补】标记，不编造。

## 一、字段表

| 字段 | 说明 | 未提供时 |
|---|---|---|
| 版式 | 红头、信函、纪要、白头、材料 | 法定公文按白头，常用材料按材料版式 |
| 份号 | 6 位阿拉伯数字，如 000123（7.2.1） | 不排 |
| 密级 | 绝密、机密、秘密（7.2.2） | 不排。涉密材料按红线第一条处理，见 SKILL.md 开工检查 |
| 保密期限 | 如“1年”，排成“机密★1年” | 不排 |
| 紧急程度 | 特急、加急（7.2.3） | 不排 |
| 发文机关标志 | 红头写“××文件”；信函写机关全称或规范化简称；纪要写“××纪要” | 红头、信函写【待补】；纪要用以“纪要”结尾的标题代替 |
| 发文字号 | 如“某发〔2026〕5号”；纪要可写期号“第18期” | 红头、信函写【待补】 |
| 签发人 | 上行文（请示、报告）的签发人姓名 | 红头版式的请示、报告写【待补】 |
| 标题 | 公文标题；要分行时用 \n 分隔 | 从正文首行识别 |
| 主送机关 | 如“各区应急管理局，市直有关单位” | 从标题后以冒号结尾的行识别 |
| 附件 | 附件名称数组，不带序号 | 从“附件：”行识别 |
| 发文机关署名 | 字符串或数组（联合行文） | 从日期前的单位名称行识别；红头、白头、信函识别不到时写【待补】 |
| 成文日期 | “2026年10月16日”或“2026-10-16” | 从末尾日期行识别；红头、白头、信函识别不到时写【待补】，不用当天日期代替 |
| 印章 | 是、否 | 红头、白头、信函按“是”，纪要、材料按“否” |
| 附注 | 如“此件公开发布”，脚本自动加圆括号 | 从日期下一行的括号行识别 |
| 抄送 | 字符串或数组；数组时脚本按“，”连接并加句号 | 从“抄送：”行识别 |
| 印发机关 | 一般是发文机关的办公厅（室） | 红头写【待补】；白头、纪要有抄送时写【待补】 |
| 印发日期 | 同成文日期写法，后面不要写“印发” | 同上 |
| 三级标题加粗 | 是、否；本单位规定三级标题加粗时写“是” | 不加粗 |

## 二、整理步骤

1. 先读 `.gongwen/单位画像.md`（不存在时读 `~/.gongwen/单位画像.md`）中的“发文机关标志”“发文字号格式”“红头或白头”“党政两套代字”字段。
2. 按文种和发文主体选版式：
   - 函、复函，用信函格式；
   - 纪要，有纪要版头的用纪要格式，没有的用白头；
   - 以单位名义正式发文，画像写明用红头的，用红头；
   - 部门内部通知、画像写明用白头的，用白头；
   - 总结、计划、汇报材料、讲话稿、调研报告等，用材料版式。
3. 按发文主体选标志和代字：党委发文用党委标志和党委代字，行政发文用行政标志和行政代字，不能混用。
4. 发文字号的顺序号、成文日期、印发日期、签发人只取用户提供的。画像里只有代字格式（如“X医发〔年〕N号”），没有具体号码时，发文字号写【待补】，不要自编号码。
5. 抄送、印发机关取用户提供的；画像写明“印发机关一般为院长办公室”的，可以采用，并在交付说明中写明“按画像”。
6. 写成 JSON 文件“版式信息.json”，放在正文同目录，运行 build_docx.py。

## 三、从单位画像取值

| 画像字段 | 用于 | 处理 |
|---|---|---|
| 单位类型 | 版式默认值 | 社区一般不用红头；中小学校内通知可用白头 |
| 发文机关标志 | 发文机关标志 | 党政两套时按发文主体选一个 |
| 发文字号格式 | 发文字号 | 只取代字格式，序号向用户要 |
| 红头或白头 | 版式 | 按画像执行 |
| 党政两套代字 | 发文机关标志、发文字号 | 党委管党建、干部、纪检等事项，行政管业务事项 |
| 本单位制度文件 | 与国标不一致的写法 | 按本单位制度执行，交付说明中写明与国标的差异 |

本单位制度与国标不一致时（例如企业办法规定年份用方括号），按本单位制度排版。check_docx.py 会把方括号报为 P0，这类 P0 属于“按本单位制度保留”，在交付说明中逐条写明，不算排版错误。

## 四、医院、高校、国企的红头差异

| 单位 | 发文机关标志示例 | 发文字号示例 | 版式提示 |
|---|---|---|---|
| 公立医院 | 中共某医院委员会文件；某医院文件 | 某医党发〔2026〕N号；某医发〔2026〕N号 | 党委、行政分开编号；部分医院版头加院徽，脚本不生成院徽，需在 Word 中手工插入；职能部门院内通知用白头 |
| 高校 | 中共某大学委员会文件；某大学文件 | 某大党发〔2026〕N号；某大发〔2026〕N号 | 校级用红头，部门用部门版头或白头；校内请示用学校的请示报告单，不套红头 |
| 国有企业 | 中共某集团有限公司委员会文件；某集团有限公司文件 | 某党发〔2026〕N号；某发〔2026〕N号 | 企业红头；董事会议案、决议不用红头；签报用企业签报单 |
| 党政机关 | 某市人民政府文件；某市某局文件 | 某政发〔2026〕N号 | 函用信函格式，纪要用纪要格式，上行文标签发人 |
| 基层、社区 | 某镇人民政府文件 | 某镇政发〔2026〕N号 | 社区一般不用红头；不得用白头、便笺规避发文管理 |

以上示例只示意结构，代字以本单位规定为准（见 `references/_shared/profiles/units/` 下各单位类型画像的“发文体系”“版式差异”）。

## 五、示例

医院行政红头通知：

```json
{
  "版式": "红头",
  "发文机关标志": "某市第一医院文件",
  "发文字号": "某一院发〔2026〕37号",
  "印章": "是",
  "抄送": ["院党委各委员", "院纪委"],
  "印发机关": "某市第一医院院长办公室",
  "印发日期": "2026-10-20"
}
```

高校上行请示（红头，标签发人）：

```json
{
  "版式": "红头",
  "发文机关标志": "某理工大学文件",
  "发文字号": "某理工发〔2026〕52号",
  "签发人": "王某",
  "印发机关": "某理工大学党政办公室",
  "印发日期": "2026-10-20"
}
```

国企致政府部门的函（信函格式）：

```json
{
  "版式": "信函",
  "发文机关标志": "某能源集团有限公司",
  "发文字号": "某能源函〔2026〕8号",
  "抄送": "某市国资委。"
}
```
