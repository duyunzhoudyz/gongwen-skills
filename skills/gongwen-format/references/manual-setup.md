# WPS / Word 手动设置清单（GB/T 9704-2012）

没有 Python、在网页版大模型中使用，或用户自己在 Word、WPS 调格式时，按本清单操作。括号内为 GB/T 9704-2012 条款号，标“实践值”的不是标准原文。WPS 与 Word 选项名称基本一致，菜单位置因版本而异。

## 一、参数速查

版心 15.6 厘米×22.5 厘米，每页 22 行、每行 28 字（5.2.1、5.2.3），其余参数见以下各部分；缺字体先按第十五部分安装。

## 二、页面设置

Word：布局 → 页边距 → 自定义页边距。WPS：页面（旧版“页面布局”）→ 页边距 → 自定义页边距。

1. “页边距”：上 3.7、下 3.5、左 2.8、右 2.6 厘米（5.2.1 及推算），纵向。
2. “纸张”：A4（21 厘米×29.7 厘米，5.1）。
3. “版式”：勾选“奇偶页不同”；页脚距边界 2.5 厘米（实践值，按第十三部分打印后微调）。
4. 应用于“整篇文档”，确定。

## 三、正文样式

先改“正文”样式，再设文档网格，否则网格按旧字号计算字距。

1. 开始 → 样式 → 右键“正文” → 修改（WPS：“修改样式”）。
2. 格式 → 字体：中文字体选仿宋_GB2312（没有时先按第十五部分安装，不要改选“仿宋”），西文字体也选仿宋_GB2312（或“使用中文字体”），字号三号，颜色自动（7.3.3）。
3. 格式 → 段落：
   - 对齐方式：两端对齐；特殊格式：首行缩进 2 字符；段前、段后：0；
   - 行距：固定值 28.9 磅（实践值）；
   - 勾选“如果定义了文档网格，则对齐到网格”。
4. 正文不要用空格缩进。已有的，用“查找和替换”删掉段首全角空格。

## 四、文档网格

Word：布局 → 页面设置（右下角小箭头）→ 文档网格。WPS：页面 → 页面设置 → 文档网格。

1. 网格选“指定行和字符网格”，每行 28 字、每页 22 行。
2. 点“字体设置”，确认中文字体为仿宋_GB2312、三号。
3. 应用于“整篇文档”，确定。设好后 Word 显示的字符跨度约 15.8 磅、行跨度约 28.95 磅。

## 五、标题和层次标题

1. 标题：二号方正小标宋简体（没有时先按第十五部分安装，不要用华文中宋、宋体加粗代替），居中，首行缩进 0；段落取消“对齐到网格”，否则字距被拉开。二号字每行约 20 字，超过时在词意完整处按 Shift+Enter 手动换行，上行不短于下行，排成梯形或菱形，末行不只剩一两个字（7.3.1）。
2. 标题与主送机关之间空一行（7.3.2）。红头文件的标题在红色分隔线下空二行（7.3.1）。
3. 一级标题“一、”整行设黑体；二级“（一）”楷体_GB2312；三级“1.”、四级“（1）”仿宋_GB2312。三号，首行缩进 2 字符，不加粗（7.3.3）。单位规定三级标题加粗的，从其规定。
4. 二级标题和正文同段时，只把句号及以前的标题设为楷体，后面正文仍为仿宋。
5. 独占一行的层次标题：段落 → 换行和分页 → 勾选“与下段同页”，避免落在页末。
6. 建议把一、二级标题做成样式（基于“正文”，只改字体，大纲级别分别设 1、2 级），便于统一修改。

## 六、主送机关、附件说明、署名、成文日期、附注

1. 主送机关：标题下空一行，顶格（首行缩进 0），末尾全角冒号“：”（7.3.2）。
2. 附件说明（7.3.4）：
   - 正文下空一行，“附件：”左空二字；
   - 一个附件：左缩进 5 字符、悬挂缩进 3 字符；
   - 多个附件：第一行写“附件：1. ××××”，左缩进 6.5 字符、悬挂缩进 4.5 字符；从第二个起写“2. ××××”，左缩进 6.5 字符、悬挂缩进 1.5 字符；
   - 附件名称后不加标点。
3. 署名和成文日期（7.3.5）。字数按汉字计 1 字、半角数字计半字，如“2026年10月16日”约 7 字；“字符”指段落缩进单位：
   - 不加盖印章：正文（或附件说明）下空一行。署名左对齐，左缩进 = 26 − 署名字数；日期在下一行，左对齐，左缩进 = 署名左缩进 + 2（日期首字比署名首字右移二字）。
   - 不加盖印章、日期加 2 字后会超出“右空二字”时（日期字数 + 2 > 署名字数）：日期右对齐、右缩进 2 字符；署名左对齐，左缩进 = 26 − 日期字数 − 2。
   - 加盖印章：正文（或附件说明）下空二行（实践值，给印章留位置）。署名、日期两段都设“居中”并设相同的左右缩进，中心就对齐；中心位置 = 28 − 4 − 日期字数 ÷ 2。简便设法：右缩进 0，左缩进 = 2 × 中心位置 − 28。
   - 日期用阿拉伯数字，年份写全，月、日不编虚位：写“2026年1月5日”，不写“2026年01月05日”或“二〇二六年一月五日”。
   - 落款不能单独成页：选中正文最后一段（或附件说明）到成文日期（有附注到附注前一段），段落 → 换行和分页 → 勾选“与下段同页”。放不下时，可按 7.3.5.5 适当调整行距、字距。
4. 附注：成文日期下一行，首行缩进 2 字符，加圆括号（7.3.6）。请示的联系人、电话也写在附注处。

## 七、页码

Word：

1. 确认第二部分已勾选“奇偶页不同”。
2. 第 1 页页脚双击 → 页码 → 页面底端 → “普通数字 3”（居右）。
3. 在页码数字两侧输入一字线和空格，成为“— 1 —”。一字线是 U+2014：插入 → 符号 → 其他符号，字符代码 2014。
4. 选中整行，宋体四号；右缩进 1 字符。
5. 第 2 页页脚选“普通数字 1”（居左），同样加一字线，宋体四号，左缩进 1 字符。
6. 信函格式首页不显示页码：勾选“首页不同”，删除首页页脚页码。

WPS：插入 → 页码，先选页脚位置，再打开“页码设置”。能选“双面打印”或“外侧”的直接选，奇数页居右、偶数页居左；选不到的，按上面 Word 的做法分设奇、偶页页脚。样式里没有一字线时，手动在数字两侧加“—”。

版记页前有空白页的，空白页和版记页都不编页码（7.5）。

## 八、版记

1. 最后一页末尾插入表格（7.4）：有抄送时 1 列 2 行，没有抄送时 1 列 1 行；宽 15.6 厘米，与版心同宽。
2. 边框：只留上框线、下框线（约 1 磅）和行间横线（约 0.75 磅），黑色；去掉左右框线。
3. 表格属性 → 选项：单元格左右边距 0。文字四号仿宋。
4. 抄送行：“抄送：”后接机关名称，之间用逗号，末名后标句号；左右各空一字，回行与冒号后首字对齐（7.4.2）。按四号字计算：左缩进 4 字、悬挂缩进 3 字、右缩进 1 字。
5. 印发行：印发机关左空一字；印发日期右空一字，后加“印发”。右侧设一个右对齐制表位，机关名称后按 Tab 再写日期（7.4.3）。
6. 让版记贴在最后一页底端（末条线与版心下边缘重合，7.4.1）：表格属性 → 文字环绕选“环绕” → 定位 → 垂直位置“底端”、相对于“边距”。WPS 不支持时，在版记前加空行把表格推到页面最下方，改动正文后重新检查。
7. 信函格式的版记只写抄送，不加印发机关、印发日期和分隔线（10.1）。

## 九、红头（文件格式）

1. 份号、密级和保密期限、紧急程度：有的自上而下顶格写在版心左上角；密级、紧急程度三号黑体（7.2.1～7.2.3）。涉密文件只能在涉密环境处理。
2. 发文机关标志：红色、方正小标宋简体、居中；字号以醒目、不超过版心宽为准，常用小初（36 磅），名称长时缩小（7.2.4）。段落取消“对齐到网格”。
3. 标志位置：上边缘距版心上边缘 35 mm。标志段落设段前约 99 磅；上方有份号、密级等行的，每行减 28.9 磅。打印后量准再调。
4. 标志下空二行，居中写发文字号：年份用六角括号“〔〕”（字符代码 3014、3015），年份写全，顺序号不加“第”、不编虚位（7.2.5）。序号还没编的先不写，请用户确认；不用长占位，以免签发人被挤到下一行。
5. 上行文（请示、报告）标注签发人：发文字号居左空一字，“签发人：”三号仿宋、姓名三号楷体，居右空一字，与发文字号同一行（7.2.6）。段落中设一个左对齐制表位（1 字）和一个右对齐制表位（版心宽减 1 字）。
6. 红色分隔线：选中发文字号所在段落 → 边框和底纹 → 只加下框线，红色，约 1.5 磅；“选项”中距正文下边距约 11 磅（约 4 mm）。段落不设左右缩进，线长即版心宽（7.2.7）。
7. 红线下空二行写标题，之后按第五、六部分排主体。
8. 用印好的红头纸套打：只排主体，不排标志和红线；先用白纸试印，对着红头纸核对位置。

## 十、信函格式

1. 页面设置 → 版式：勾选“首页不同”，页眉距边界 3 厘米（10.1）。
2. 首页页眉：发文机关全称或规范化简称，红色小标宋，居中。
3. 标志下 4 mm 印红色双线，上粗下细，线长 170 mm、居中（10.1），比版心两侧各宽 7 mm：给标志段落加下框线，线型选“粗-细”双线；或在标志下加一个空段，标志段落设粗下框线、空段设细下框线；两段左右缩进都设 -0.7 厘米（负值），线长即 17 厘米。
4. 首页页脚：距纸张下边 20 mm 印红色双线，上细下粗，线长同样与版心等宽；首页页脚不放页码。
5. 第一条双线下：份号、密级、紧急程度顶格居左；发文字号顶格居右，与份号同行。
6. 标题居中，与上面最后一个要素相距二行；之后按第五、六部分排主体。
7. 版记只写抄送，放在最后一页版心内最下方。

## 十一、纪要格式

1. 标志写“××××纪要”，红色小标宋，居中，上边缘距版心上边缘 35 mm（10.3）。
2. 期号排在标志下，其下加红色分隔线（实践做法，标准未规定期号位置，以本单位规定为准）。
3. 出席、请假、列席：正文或附件说明下空一行，左空二字写“出席：”，“出席”三号黑体，冒号后的单位和姓名三号仿宋，回行与冒号后首字对齐（左缩进 5 字、悬挂缩进 3 字）。请假、列席另起一行，写法相同，前面不再空行（10.3）。

## 十二、表格

国标未规定正文表格字体字号，以下为实践做法，单位有规定的从其规定。

1. 插入 → 表格；宽度不超过 15.6 厘米（版心宽），居中。
2. 边框：全部框线，0.5 磅，黑色。
3. 文字：仿宋_GB2312 或宋体，四号或小四；表头加粗居中；数字居中，文字居左；垂直居中。
4. 选中整张表 → 段落：首行缩进 0，取消“对齐到网格”，行距单倍或固定值（约字号 1.5 倍），否则行高被拉成 28.9 磅。
5. 表题在表格上方，居中，黑体三号，设“与下段同页”；表格跨页时，表格属性 → 行 → 勾选“在各页顶端以标题行形式重复出现”。
6. 横排表格的页码和表头位置按 GB/T 9704-2012 第 8 章。

## 十三、打印核对

1. 打印第 1 页量：上白边 37 mm、左白边 28 mm，误差不超过 1 mm；版心 156 mm×225 mm（5.2.1）。
2. 数一页是否 22 行、一行是否 28 字。
3. 页码一字线距版心下边缘约 7 mm（7.5）；不对就调“页脚距边界”。
4. 红头文件：量标志上边缘到版心上边缘是否 35 mm，红线是否在发文字号下 4 mm。
5. 双面打印一份，核对单页页码在右、双页在左。
6. 翻看各页：层次标题、表题没落在页末，落款没单独成页。

## 十四、简报

简报无国家标准格式，以下为常见做法，以本单位往期样式为准；页面、正文、页码按第二至七部分。

1. 报头：简报名称红色小标宋、居中、大字号（约小初）；下一行居中写“第×期”，有总期号的写“第×期（总第×期）”，三号仿宋；再下一行左写“××办公室编”、右写日期（右对齐制表位设在版心右边缘），三号仿宋，段落下边框设红色 1.5 磅分隔线，其下空一行。
2. 各篇：标题二号小标宋居中，下空一行排正文，层次标题和正文同第三、五部分；两篇之间空一行；标题设“与下段同页”。
3. 报尾：版心底部一条分隔线，其下依次写“报：”“送：”“发：”或“抄送：”和“（共印×份）”，四号仿宋；没有的不写。

## 十五、字体准备与安装

缺字体时不得用“仿宋”“楷体”“华文中宋”“宋体加粗”等顶替。本项目不提供、不打包字体，请从单位提供或字体厂商官方等可靠来源获取，装好后核对字体列表名称完全一致。

1. 仿宋_GB2312、楷体_GB2312：现行 Windows 不预装。先向单位信息中心或办公室索取，也可从可靠来源下载；名称须是“仿宋_GB2312”，不是“仿宋”。
2. 方正小标宋简体：方正字库（北京北大方正电子有限公司）的商业字体，见 https://www.foundertype.com ；个人非商业使用可免费下载，单位使用需商业授权，先问单位信息中心或办公室。
3. 黑体、宋体：简体中文版 Windows 预装；macOS、Linux 自行安装。
4. 本单位制度明文规定了字体的（如正文用方正仿宋_GBK），以上相应字体换成单位规定的，向单位信息中心或办公室索取，同样须装好、名称一致，不得用国标字体或其他字体顶替。

安装：Windows 右键字体文件选“为所有用户安装”或双击点“安装”；macOS 双击后在“字体册”点“安装字体”；Linux 复制到 ~/.local/share/fonts 后运行 fc-cache -f。装好后重启 Word/WPS；缺字体的电脑不能据此核对版式或打印。
