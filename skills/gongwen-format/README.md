# gongwen-format 国标排版

把写好的公文排成符合 GB/T 9704-2012《党政机关公文格式》的 Word 文档，也能检查、修复已经做好的 Word 文档，把核稿意见写成批注。

成熟度：Beta（v0.1.0）。五种版式都有自动测试，生成的样稿在 LibreOffice 中做过位置测量；Word 和 WPS 下的红头位置、版记位置仍需打印核对。

## 能做什么

| 功能 | 说明 |
|---|---|
| 生成 | 纯文本或 Markdown 正文排成 docx。版式有五种：红头文件、信函、纪要、白头、普通材料（总结、讲话稿等） |
| 检查 | 查纸张、页边距、字体字号、行距、首行缩进、层次标题字体、页码、发文字号、成文日期等，按 P0、P1、P2 分级 |
| 修复 | 统一已有 docx 的页面、字体、行距、缩进、页码，另存新文件并给出修复报告 |
| 批注 | 把 gongwen-review 的核稿意见写成 Word 批注，定位不到的单独列出 |
| 手动清单 | 没有 Python 时，告诉你在 WPS、Word 里一步一步怎么设 |

排版只动格式，不改文字。要改内容，请先用 gongwen、gongwen-report、gongwen-humanize、gongwen-direct、gongwen-review。

## 怎么说

1. “这份通知帮我套个红头，发文字号是某发〔2026〕21号，抄送市安委办。”
2. “把这篇年终总结转成 Word，按公文格式排。”
3. “领导说这个文档格式不对，你帮我改一下。”（附 docx）
4. “核稿意见出来了，帮我批注到文档里，我好对着改。”
5. “我们这儿电脑装不了 Python，你告诉我 WPS 里页码怎么设成‘— 1 —’，单页在右双页在左。”

## 输入和输出

输入：
- 正文：.txt 或 .md，一段一行。正文后有【起草说明】的，排版时自动忽略其后内容。
- 版式信息（可选）：版式信息.json，写版式、发文机关标志、发文字号、签发人、抄送、印发机关等，字段见 `references/meta-fields.md`。不写时自动识别标题、主送机关、附件说明、署名和日期。
- 单位画像（可选）：`.gongwen/单位画像.md` 中的发文机关标志、发文字号格式、红头或白头。
- 修复和批注：已有 .docx，批注还要核稿意见.json。批注加在由送审稿排出的 docx 上（核稿意见是对着送审稿写的），改好的终稿不加批注。

输出：
- 排版默认文件名：正文.txt 输出 `成稿.docx`，正文-××.txt 输出 `成稿-××.docx`，其他输入输出“<输入文件名>.docx”（如送审稿.txt 输出 `送审稿.docx`）；修复、批注输出“原名-修复.docx”“原名-批注.docx”。同名文件存在时加 -v2、-v3，不覆盖。
- 报告：识别结果、待补事项、字体提示、检查结论；修复和批注另存 Markdown 报告。

命令行（在 skill 目录下运行，需要 Python 3.9+ 和 `pip install -U python-docx`，版本 1.2.0 以上）：

```text
python scripts/build_docx.py 正文.txt --meta 版式信息.json -o 成稿.docx
python scripts/check_docx.py 成稿.docx --strict
python scripts/fix_docx.py 旧稿.docx
python scripts/build_docx.py 送审稿.txt --meta 版式信息.json    # 输出 送审稿.docx，供批注用
python scripts/annotate_docx.py 送审稿.docx 核稿意见.json
python scripts/preview_docx.py 成稿.docx    # 本机装有 LibreOffice 时，转成逐页图片目检
```

## 注意事项

1. 字体：不附带任何字体文件。默认写入仿宋_GB2312、楷体_GB2312、黑体、方正小标宋简体，打开文档的电脑上要有这些字体。本机没有时，加 `--font-fallback` 改用系统自带的仿宋、楷体、黑体，标题用华文中宋或宋体加粗。方正小标宋简体是商业字体，需要单位自行取得授权。
2. 不编造：发文字号、成文日期、签发人、印发日期只用你提供的，缺了就写【待补】。
3. 保密：涉密材料不要交给联网 AI 工具处理。脚本本身只在本机运行，不联网。
4. 位置要打印核对：红头标志、红线、页码、版记的位置是近似实现，正式印发前打印一页量一下（清单见 `references/manual-setup.md` 第十二部分）。
5. 不做的事：不生成印章和院徽、校徽；不排附件正文；不支持命令（令）格式；不调整正文中的表格；批注不写修订。
6. 单位规定与国标不同的（例如企业规定年份用方括号），按单位规定排，检查结果中的相应问题会单独说明。
