# 单位差异：本 skill 的调整项

先读 `references/_shared/profiles/units/` 下对应的单位类型画像，再按本文件调整。取值顺序：本单位议事规则和公文处理办法（用户提供）优先，其次是单位画像 `.gongwen/单位画像.md`，再次是单位类型画像和本文件。本单位制度与本文件不一致的，按本单位制度办理，并在起草说明中提示差异。

## 一、敏感内容

各类单位常见的敏感内容：党政机关是未公开的政策、人事酝酿、工作秘密；基层是信访人、困难群众、拆迁户信息；社区是居民身份证号、手机号、住址、低保情况；医院是患者姓名、病案号、住院号、医疗纠纷细节；高校是学号、成绩、处分、心理健康信息；中小学是学生姓名与成绩、家庭情况；国企是未公开财务数据、投标报价、并购信息。

处理按 SKILL.md 开工检查第1条：带密级或内部标识的停止；个人信息脱敏；人事、处分、商业秘密类先提醒确认，纪要按用户确认的发送范围处理。

## 二、党政机关

1. 党组（党委）会议与行政办公会议分开整理、分开编号，各自职权内的事项不混写。
2. 县级以上地方人民政府研究重大行政决策的，会议记录如实载明不同意见（《重大行政决策程序暂行条例》第二条、第三十条第三款），县级以上人民政府部门参照执行（第四十二条）；议题材料的前置程序见 `references/agenda-material.md` 第三部分。
3. 传达学习上级会议、文件精神的议题，名称和表述以原文为准，叠加严谨模式。

## 三、基层

1. 乡镇党委会、街道党（工）委会议与镇长办公会、街道主任办公会分开整理。
2. 调度会、推进会纪要多为任务分解，议定事项写到具体站所、村（社区）。会上确实议定的加码要求照记录写，在起草说明“程序风险提示”中提示减负规定（`references/_shared/rules/jianfu.md`），由会议决定是否调整；记录里没有的加码要求不写，用户要求添加的不照办，说明原因。
3. 督办清单常用于周调度。纪要有具体日期的照写；只有“尽快”“近期”“下周”的照原话写，需要具体日期的标【待补：具体完成日期】，起草说明提示“周调度需要具体日期，请会议明确”，不自行换算或补日期。
4. 纪要中出现信访人、困难群众的，一律用“张某”之类的代称。
5. 县（市、区）政府研究重大行政决策的，同第二部分第2条；县级以上人民政府部门和乡级人民政府参照执行（第四十二条）。

## 四、社区

1. 两委会议、居民会议和“四议两公开”中的党员大会按会议记录整理，不套纪要格式，不排红头。支部党员大会作为“三会一课”召开的，记录交 gongwen-party。
2. 农村村级重大事项按“四议两公开”分环节记录：村党组织提议，两委会议商议，党员大会审议，村民会议或村民代表会议决议，决议和实施结果公开（`references/_shared/profiles/units/shequ.md` 第四部分）。
3. 涉及全体居民利益的事项（如物业选聘、公共收益使用），记录中写清参会户数、表决方式和结果，用户没给的标【待补】。
4. 社区没有行政执法权，记录中会上提出的“罚款”“断水断电”之类的意见照实记录，纪要或公告中不得写成决定事项，在起草说明中提示。

## 五、公立医院

1. 党委会纪要与院长办公会纪要分开整理、分开编号、分开印发（`references/_shared/profiles/units/yiyuan.md` 第八部分）。装有 gongwen-hospital 的，党委会、院长办公会议题交行业包；纪要、记录、督办清单仍由本 skill 处理。
2. 重要行政、业务工作先经院长办公会讨论，再由党委会研究决定；院长办公会纪要中涉及“三重一大”的，写“提交党委会研究”仅限记录中说了的，没说的在起草说明中提示。
3. 不得以党政联席会议代替党委会议。
4. 新技术准入、药品器械引进、伦理相关议题，议题材料写明专业委员会论证意见。
5. 纪要中的患者一律用“患者张某”，不写病案号、住院号、床号。

## 六、高校

1. 党委常委会纪要与校长办公会纪要分开。
2. 学科专业设置、学术评价等学术事项，议题材料写明学术委员会审议情况；涉及教职工切身利益的写明教代会情况。
3. 涉及学生的议题（处分、资助、评优）纪要中用代称，处分决定另按学校规定办理。

## 七、中小学

1. 党组织会议与校长办公会（校务会）分开整理。
2. 重要议题上会前书记和校长先沟通，议题材料写明沟通情况（用户提供的）。
3. 涉及收费、课后服务、学生安全的议定事项，依据只用用户提供的上级文件，缺的标【待补】。
4. 纪要和记录中不写学生成绩排名。会上议定向家长公布考试排名的，照记录写，在起草说明“程序风险提示”中提示义务教育学校考试结果不排名、不公布的要求（`references/_shared/profiles/units/zhongxiaoxue.md` 第六部分），建议会议重新研究。

## 八、国有企业

1. 党委会、董事会、总经理办公会分开整理（`references/_shared/profiles/units/guoqi.md` 第十部分）。
2. 前置事项清单内的事项，议题材料写明党委前置研究的时间和结论；没有的提示程序倒置风险。前置研究不代替董事会、经理层依法决策。
3. 装有 gongwen-soe 的，“三重一大”议题、董事会议案和决议、总经理办公会纪要交行业包；没有装的，本 skill 按议题材料、纪要的要件整理，董事会议案、决议的格式以公司章程和董事会议事规则为准。
4. 涉及职工切身利益的事项写明职代会审议情况。
5. 未公开的经营数据、投标报价不进入对外材料，纪要发送范围按用户确认。
