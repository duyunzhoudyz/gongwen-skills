# 上会议题材料

议题材料供党委会、院长办公会、总经理办公会、校长办公会、政府常务会议等决策会议使用，目的是让与会人员快速看清要决定什么、有哪些选择、程序是否完备。装有 gongwen-hospital、gongwen-soe 的，医院党委会和院长办公会议题、国企“三重一大”议题交行业包，本文件用于其他单位或未装行业包时。

## 一、结构

```text
关于××的议题
汇报单位：××（汇报人：××）
会签部门：××（意见：……）
一、基本情况和依据
二、方案比较
三、需会议决策的事项
四、前置程序完成情况
附件：1. ……
```

篇幅一般 1500～3000 字（工具约定），测算明细、合同文本等放附件。正文是纯文本，不放表格，对照表放在起草说明末尾的附表中。

## 二、各部分写法

正文中只用【待补】【待核实】两种提示：材料说明没做的写事实（“未开展”“审查意见尚未出具”），材料没说的标【待补：说明】并在起草说明中逐条列出。不写“材料未提供”“未提供”，这类话不进起草说明汇总，容易原样带上会。

1. 议题名称：一题一议，“关于……的议题”或“关于审议《……》的议题”。几件事捆在一起的，拆成几个议题。
2. 基本情况和依据：开门见山写为什么上会，即要解决什么问题、依据哪份文件或制度条款。依据只用用户提供的，不写意义铺垫。
3. 方案比较：
   - 正文分项写：“（一）方案一：租用现有用房改造为分馆。……”，每个方案写主要内容、投入、周期、预期效果，数据只用材料里的，不估算。
   - 风险、合规性只写材料里已有的意见（合规审查、财政部门、专家论证等），写明出自谁。风险高低、是否合规由汇报单位和审查部门判断，本 skill 不下结论。
   - 推荐意见单列一项，只写汇报单位或用户给出的倾向和理由，照写，不改成“各有利弊、视情况而定”（`references/_shared/style/defensive.md` 第四部分）；材料没有倾向的，写【待补：汇报单位推荐意见及理由】，在起草说明中提示，不替汇报单位选方案。
     - 误：经综合比较，方案一风险可控、合规性较好，建议采用方案一。（材料中没有风险和合规判断，倾向也不是材料给的）
     - 正：（三）汇报单位意见。文化科倾向方案一，理由是改造周期短、当年可以开放。财务科会签意见：资金可以保障。（均照素材）
   - 只有一个方案的，不编第二个方案，写明“本议题只形成一个方案”。可以把“维持现状”作为对照，维持现状的后果只写材料里有的，没有的标【待补】；起草说明提示“三重一大”事项一般要有方案比选，请补充备选方案。
   - 需要对照表的，在起草说明末尾写“附：方案比较表”（方案｜主要内容｜投入｜周期｜预期效果｜风险｜合规性），各栏只填材料里有的。
4. 需会议决策的事项：逐项写成能回答“同意”或“不同意”的句子。
   - 误：请会议研究。
   - 正：1. 审议《图书馆分馆建设方案》；2. 同意列支改造资金350万元；3. 明确由文化科牵头实施。
5. 前置程序完成情况：正文逐项写，如“1. 专家论证：已组织3名专家论证，书面意见已收到。2. 公众参与：未开展。3. 合法性审查：【待补：是否已送审及审查意见】”。只写用户提供的完成情况，不写“已完成”。核对表（程序｜是否完成｜完成时间｜结论或意见｜佐证材料）放在起草说明末尾“附：前置程序核对表”。
6. 附件：只列实际有的材料。

## 三、前置程序核对

| 单位类型 | 常见前置程序 |
|---|---|
| 党政机关（重大行政决策） | 县级以上地方人民政府适用条例（第二条），县级以上人民政府部门参照执行（第四十二条）。合法性审查必经（第二十五条）；公众参与（第十四条，依法不予公开的除外）、专家论证（第十九条，专业性、技术性较强的）、风险评估（第二十二条，可能对社会稳定、公共安全等造成不利影响的）按条例规定的情形适用；之后集体讨论决定（第三十条） |
| 基层 | 县（市、区）人民政府的重大行政决策同党政机关一行；县级以上人民政府部门和乡级人民政府参照执行（第四十二条）。重大事项经党委会议集体讨论；行政事务经镇长办公会、街道主任办公会研究 |
| 社区 | 重要事项先经党组织研究；农村按“四议两公开”；城市社区涉及全体居民利益的由居民会议决定 |
| 公立医院 | 重要行政、业务工作先经院长办公会讨论，再由党委会研究决定；涉及药事、伦理、医疗质量的先经专业委员会论证 |
| 高校 | 学术事项先经学术委员会审议；涉及教职工切身利益的经教代会；重大事项由党委常委会决定 |
| 中小学 | 重要议题上会前书记和校长先沟通；“三重一大”由党组织会议讨论决定 |
| 国有企业 | 前置事项清单内的事项先经党委（党组）研究讨论，再由董事会或经理层决定；合法合规审查；涉及职工切身利益的经职代会审议 |

依据：党政机关和基层见《重大行政决策程序暂行条例》，其余见 `references/_shared/profiles/units/` 下对应画像第四部分。具体程序以本单位议事规则、“三重一大”实施办法和前置事项清单为准；用户提供了的，按用户提供的核对。

## 四、程序风险提示

以下情况写进起草说明“程序风险提示”，正文不写评论：
1. “三重一大”事项准备以传阅会签、个别征求意见代替会议集体决策。
2. 前置程序没有完成就上会，或已经执行、准备事后补程序。
3. 涉及职工切身利益的事项，没有经过职代会或教代会。
4. 用户要求在材料中写“已经党委前置研究”“已通过合法性审查”，但没有提供会议时间或审查意见：不写，标【待核实：前置研究的会议时间和结论】。
5. 按情形适用的程序（重大行政决策的专家论证、风险评估）没有做的：提示“请确认本事项是否属于条例第十九条、第二十二条规定的情形，属于的需先完成”，不直接写成程序违规。合法性审查没做或意见未出的，提示未经合法性审查的不得提交讨论（第二十五条第二款）；同款规定国家尚无明确规定的探索性改革决策事项，可以明示法律风险后提交讨论，是否属于此类请用户确认。

写法：
- 误：本议题前置程序可能存在一定瑕疵，仅供参考。
- 正：本议题调整职工带薪休假安排，涉及职工切身利益，材料未显示已提交职代会审议。本单位制度规定此类事项须经职代会审议的，建议审议后再提交决策；请对照本单位民主管理制度确认。
