# 议定事项梳理：从记录到结论

写纪要前，先把记录拆成议定事项梳理表（工作底稿，可用表格，文件名 `议定事项梳理表.md`）。纪要里的每条议定事项都从这张表取，表里的每条结论都能在记录中找到原话。

## 一、梳理表

| 序号 | 议题 | 结论原话（位置） | 结论类型 | 责任单位 | 完成时限 | 状态 |
|---|---|---|---|---|---|---|
| 1 | 档案数字化外包 | "就按档案室的方案办，但是人事档案不外包，室里自己扫。档案室牵头，信息中心配合，6月底前完成。"（笔记第2段） | 同意（当场附带调整） | 档案室牵头，信息中心配合 | 6月底前 | 已明确 |
| 2 | 会议室管理办法 | "原则上同意，预约那条办公室再改改，年底前发下去。"（笔记第3段） | 原则同意 | 办公室 | 年底前 | 已明确 |
| 3 | 公务用车更新 | "先放一放，办公室先把车况摸清楚，等明年预算批下来再说。"（笔记第4段） | 暂缓 | 无 | 无 | 已明确 |
| 4 | 公务用车车况摸底 | 同上 | 暂缓下的准备任务 | 办公室 | 【待补】 | 待补 |
| 5 | 图书室延长开放 | "这个大家再琢磨琢磨。"（笔记第5段） | 未形成结论 | 无 | 无 | 列入起草说明 |

示例为虚构的主任办公会，原话均为主持人所说。

1. 结论原话逐字摘录，位置写行号、段落或时间戳。用户只给了笔记的，写"笔记第几段"。
2. 一个议题有几项决定的，拆成几行；一句话里既有同意又有暂缓的，也拆开。
3. 未形成结论的只进起草说明，不进纪要正文和督办清单。
4. 状态四种：已明确；待补（缺责任单位、时限或暂缓原因）；待核实（原话含糊、转写存疑、几处说法不一）；列入起草说明（未形成结论的）。
5. 梳理表同样脱敏：患者、学生、群众姓名写"张某"，号码不进表。

## 二、怎么判定"定了没有"

算定了，写进议定事项：
1. 主持人或会议主要负责人作了结论性表态；
2. 记录写明表决结果；
3. 记录写明"会议同意""一致同意"。

不算定了：
1. 个人提出的建议，即使没人反对，主持人没有表态；
2. 主持人只说"再看看""再琢磨琢磨""回头再说"，没有说下一步；
3. 有不同意见，主持人没有作结论。

不算定了的不写进议定事项，列入起草说明"未形成结论的事项"，写明议题和记录位置。记录里明确说了"另行研究""下次再议""提交下次会议"的，这本身就是结论（另行研究），照写，不写成"暂不调整"。

误：会议议定：职工体检标准提高至每人800元。（工会主席的建议，主持人只说"再算算"）
正：会议议定：职工体检标准调整事项由工会进一步测算后，提交下次会议研究。（主持人原话"工会再算算，下次会上再说"）

## 三、主持人口语与结论词

| 记录中的说法 | 结论类型 | 纪要写法 |
|---|---|---|
| "就这么办""没意见就定了""同意" | 同意 | 会议同意…… |
| "就按××的方案办，但是……要……" | 同意（当场附带调整） | 会议同意……，同时……（调整内容照原话） |
| "原则上同意""大方向可以，具体的再改改" | 原则同意 | 会议原则同意……，由……按会议提出的……修改完善后实施 |
| "先放一放""暂时不动""等……以后再说" | 暂缓 | 会议决定暂缓……，待……后再提交研究 |
| "再研究研究""下次再议" | 另行研究 | ……另行研究；或提交下次会议研究 |
| "拿回去改好了再上会" | 退回修改 | ……由……修改后重新提交会议研究 |
| "不行""不同意" | 不同意 | 会议不同意……（理由照记录写） |
| "情况知道了"，没有表态 | 听取 | 会议听取了……汇报（不写成同意） |

1. 同意、原则同意、暂缓不能互换。原则同意要写出会上提的修改要求；会上没说改什么的，写成"原则同意……【待核实：会上提出的具体修改意见】"。
2. 暂缓要写原因或再议条件，记录没有的标【待补：暂缓原因或再议条件】。暂缓不写成不同意。
3. 附带的条件照写，如"在年度预算内""经法律顾问审核后"。
4. 语气强弱照原话："必须"不弱化成"要"，"尽量"不强化成"必须"。

## 四、责任单位和时限

1. 只写记录中说到的。"老王那边""你们科"能从记录确定单位的，写单位名称，梳理表注明依据；确定不了的写【待核实：责任单位，记录为"老王那边"】。
2. 几个单位的，分清牵头和配合；记录没说谁牵头的，标【待核实：牵头单位】。
3. 时限照原话写，"6月底前"不换算成具体日期；原话只有"尽快""抓紧"的，写"尽快完成【待补：具体完成时限】"。
4. 记录没提时限的，不补时限，写【待补：完成时限】。
5. 前后改口的，以主持人最后的说法为准，梳理表注明"第×行改口"。
6. 责任单位和时限跟着原话所指的事项走，不挪到同一议题的其他事项上。
7. 暂缓、另行研究的事项下指派的准备任务，单列一行，责任单位照原话，时限没说的标【待补】；纪要中写在该事项之后，督办清单也单列。
