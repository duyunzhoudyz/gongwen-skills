# 国有企业行业包（gongwen-soe）

> 版本 1.0.0　成熟度：Beta（测试版）

帮国有企业董事会办公室、总经理办公室、党群、财务、投资、改革、合规部门的同事写国企特有的文书。它先帮你理清这件事走哪条决策链（党委前置研究、董事会、经理层、职代会），再按模板起草；票数、数据、进展只用你给的记录，须你提供的缺了标【待补】，不替你编。

## 能做什么

| 文书 | 说明 |
|---|---|
| “三重一大”议题材料 | 判定事项类别和是否属于前置研究清单，写方案比选、风险、前置程序完成情况表和需决策事项；党委会版和董事会议案版可以一次出 |
| 董事会议案与决议 | 议案写明决策程序履行情况和逐项可表决的提请审议事项；决议按记录写，并核对出席人数、票数之和、同意票是否过半数、关联董事回避 |
| 总经理办公会纪要 | 只记议定事项，分清同意、原则同意、暂缓；核对是否超出董事会授权；可同时出督办清单 |
| 经营分析报告 | 先建指标台账，再写月度、季度分析；比率用百分点，同比写明基期，原因只写材料里有的 |
| 改革任务台账与进展报告 | 按五种状态口径更新台账，已完成要有佐证，过期未完成标“滞后”；进展报告与台账逐项一致 |
| ESG 和社会责任报告 | 判断是否属于强制披露，搭框架，写“关于本报告”的披露口径，第一轮就交框架和第一章（或你指定的章节），其余章节接着写；删去没有依据的“碳中和”“零事故”“行业第一” |
| 党建与经营融合经验材料 | 每条做法对应到具体项目和结果数据，避免“两张皮”；提法只用你提供的原文 |
| 合规管理报告 | 年度报告、专项报告、重大合规风险事件报告；结论写统计依据，个人信息脱敏 |

## 可以这样说

1. “集团要给子公司增资两个亿，下周上党委会，帮我弄个三重一大的上会材料。”
2. “董事会开完了，记录发你，出个决议，票数帮我核一下。”
3. “昨天总经理办公会的录音转成文字了，出个纪要，督办事项列个表。”
4. “这是9月的财务快报，帮我写份经营分析，乙公司亏损的原因你看看怎么写。”（原因材料里没有的，会标【待补】并告诉你该问什么）
5. “我们是深证100样本股，今年的可持续发展报告怎么搭框架？”

## 输入

- 必需：你手头的材料。会议记录或转写稿、财务快报、可研摘要、上级方案、各部门报来的进展、工作情况，不用先整理。
- 最好提供：本企业的前置研究讨论事项清单、“三重一大”实施办法、董事会授权清单、公司章程中的议事规则。没有的按通用规则判断，并在起草说明里写明。
- 可选：单位画像 `.gongwen/单位画像.md`（单位类型写“国有企业”）、领导偏好卡、往年同类材料。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 纯文本正文，可直接粘进 Word 或交给 gongwen-format 排版；两个版本的分别存为 `正文-党委会版.txt`、`正文-董事会议案.txt` |
| `起草说明.md` | 所作假设、待补事项、待核实事项、程序风险提示、保密提示，以及前置程序完成情况表、口径冲突表、提法核对清单 |
| `素材台账.md` | 每条事实、数据的内容、来源和状态 |
| `督办清单.md`、`改革任务台账.md` | 按需输出，装有 openpyxl 时可转成 Excel |

在网页大模型里使用提示词版时，依次输出正文、起草说明；路线还有下一站的，最后给出交接卡。

## 注意事项

1. **保密**：首次会在起草说明末尾提醒：涉密材料请勿输入联网 AI。标注“商业秘密”“内部资料”“不得外传”的材料会停止处理；投标报价、未公开财务数据、并购信息请先确认允许在当前模型中处理；职工名单、身份证号会提醒你脱敏。
2. **程序不倒置**：先开工后上会、“投产后再提交职代会”、拆成几笔规避大额标准的，不会照写，会列进“程序风险提示”并给出按正常顺序推进的写法。纪要不替会议改结论：会上已经定了、但可能超出董事会授权或需要先上党委会的事项，照原意记，在该处标【待核实】，请会议主持人确认后再改。
3. **不编造**：票数、出席人数、指标值、改革进展、ESG 数据、党建成效只用你提供的。缺的标【待补】，存疑的标【待核实】。
4. **对外材料从严**：ESG 报告和对外交流材料会删去未公开信息和没有出处的“领先”“第一”；上市公司的对外数据请董事会办公室确认已披露。决议公告、定期报告不在本包范围内。
5. **事实和判断由你负责**：它帮你搭结构、守程序、查错漏，是否上会、怎么决策由你和你的单位决定。
6. **机检**：有 Python 环境时会运行 `scripts/gongwen_lint.py` 和本包的 `scripts/soe_check.py`（决策程序、表决票数、议题要件、台账状态、ESG 披露口径、对外表述）；没有运行时按人工清单自检，并在起草说明中注明。

## 与其他 skill 的分工

国企的通用文书（通知、总结、讲话等）由核心 skill 写，核心 skill 读同一份单位画像。

| 需求 | 用哪个 |
|---|---|
| 年度工作会报告、职代会报告、年终总结、述职述廉 | gongwen-report |
| 向国资委或上级企业的请示报告、函、通知、呈领导审批的签报 | gongwen-draft |
| 董事长、总经理讲话，主持词 | gongwen-speech |
| 党委会纪要、职代会纪要、会议记录 | gongwen-minutes |
| 民主生活会、组织生活会、党建工作报告、党课 | gongwen-party |
| 新闻稿、公众号推文、政务信息 | gongwen-brief |
| 巡视巡察、审计整改材料 | gongwen-rectify |
| 把上级通知拆成任务分解表、写贯彻落实方案 | gongwen-implement |
| 报表合并、指标计算、出图 | gongwen-data |
| 送签前全面核稿；排成 Word | gongwen-review；gongwen-format |
| 医院、高校、中小学、乡镇街道自身的议题和专用文书（它们所属的国有企业仍用本包） | gongwen-hospital、gongwen-university、gongwen-k12、gongwen-grassroots；没装这些行业包的，议题材料用 gongwen-minutes |

能直接调用其他 skill 且已经安装的，直接转过去。要转去的 skill 没装、或者在网页里用的，会同时给你三样：交接卡；“新开对话，先粘贴 `dist/prompts/<skill 名>.md` 全文，再粘贴交接卡和材料继续”的说明；安装命令（见 `references/_shared/style/output-format.md` 第四部分）。

## 成熟度

Beta。8 类专用文书的模板、决策链核对、行业红线和行业机检脚本已可用；评测用例见 `evals/`。v1.0 真实模型评测（Sonnet 5.5，17 条用例）中，A 组（装 skill）期望通过率 95.9%（116/121），编造 0 次，触发评测正例 10/10、反例 10/10，详见 `evals/results/v1.0-benchmark.md`。按决策 D7，行业包的升级要等一线测试者反馈和人工盲评，条件见 `CONTRIBUTING.md` 的“成熟度从 Beta 升到 Stable”。已知局限：
- 前置研究清单、“三重一大”标准、董事会授权范围各企业不同，没有你提供的清单时只能按通用规则判断；
- 行业制度依据核实至 2026 年 10 月，新一轮国企改革方案（2026—2029 年）全文未公开，任务名称以你单位收到的文件为准；
- 交易所和财政部的可持续披露规则仍在完善，ESG 报告的条款细节以正式发布的文本为准；
- 行业包统一标 Beta，欢迎国企一线的同事贡献模板和术语。
