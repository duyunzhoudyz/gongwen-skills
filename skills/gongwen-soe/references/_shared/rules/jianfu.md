## 一、适用对象

1. 规定面向“地方和部门”（党政机关）以及议事协调机构；第21条还约束群团组织、国有企事业单位、社会组织不得开展以乡镇（街道）、村（社区）、学校为对象的达标活动。
2. 医院、学校、国企的内部发文不受第1、2条的发文数量和字数直接约束。工具约定：对所有单位类型都按本规定的文风要求起草；字数超限对党政机关、基层、社区给 P1，对医院、学校、国企给 P2。

## 三、篇幅条款的准确理解

1. 原文（第2条）：“除部署综合性工作外，地方和部门文件一般不超过5000字，部署专项工作或者具体任务的文件一般不超过4000字。”
2. 按原文分三类：

| 文件类别 | 字数要求 | 工具约定 |
|---|---|---|
| 部署综合性工作的文件 | 规定未设字数上限，仍须坚持“短实新” | 超过5000字给 P2 提示，建议压缩 |
| 其他地方和部门文件 | 一般不超过5000字 | 超过时按第一部分的级别报 |
| 部署专项工作或具体任务的文件 | 一般不超过4000字 | 超过时按第一部分的级别报 |

3. 其他资料把这句话概括为“综合性文件一般不超过5000字、专项文件一般不超过4000字”的，与原文有出入：原文把综合性工作部署文件排除在5000字限制之外。以原文为准。
4. 统计口径：规定未明确。工具约定：统计正文（标题之后、`【起草说明】` 之前）的全部字符，不含空白；附件另行统计并单列；在起草说明中写明口径。
5. 用户指定字数的，按用户要求，但超过上述上限时在起草说明中提示。
6. 规定只约束“文件”。讲话稿以时长为准（第6条）；总结、汇报材料等未设字数，按第8条“压缩提供材料的文字量”从严。

## 四、对写作工具的要求

以下规则供各 skill 执行。“检查”给机检脚本参考，级别为建议值；正则为 Python `re` 语法。

- **JF-01 控制篇幅**（第2条）
  - 做法：先判断文件类别，再按第三部分的上限控制；起草前在提纲阶段估算篇幅
  - 检查：函数：统计字数，按 `--doc-type` 和类别比较
- **JF-02 开门见山**（第2条）
  - 做法：第一段直接写目的、依据或任务；通知、请示、函、批复、通报等不写形势背景、重要意义、主要原则；讲话稿、工作方案、总结、调研报告可按文种惯例写简短背景，控制在一段以内
  - 检查：P1：首段出现“当前，……形势”“具有重要意义”“充分认识……重要性”
- **JF-03 保障措施精炼**（第2条）
  - 做法：“组织领导”“保障措施”部分只写有具体责任主体、具体动作的内容，删掉“高度重视”“加强领导”一类空表态
  - 检查：P2：保障部分占全文比例过高时提示（阈值由脚本作者定）
- **JF-04 不照搬照抄上位文件**（第2条）
  - 做法：用户提供上位文件时，逐段改写为本单位的具体措施；缺本单位措施的按上位要求和文种常规写出可执行措施，不用上位文件原文凑数
  - 检查：P1：与用户提供的上位文件做重合比对，连续重合超过阈值的段落标出（函数实现）
- **JF-05 不层层要报落实情况**（第3条）
  - 做法：下行文默认不写“请于×月×日前报送贯彻落实情况”“各地要制定配套文件”；用户坚持要写的，在起草说明中提示
  - 检查：P2：`报送.{0,6}(贯彻)?落实情况`、`制定(配套文件|实施细则|具体方案)`
- **JF-06 不附带硬性附加要求**（第3条）
  - 做法：非专门文件不对机构编制、干部配备、工资福利、创建示范、达标、一票否决、责任状提具体要求
  - 检查：P2：`一票否决`、`责任状`、`创建示范`、`达标`
- **JF-07 不在文件和讲话中设定督查考核事项**（第7条）
  - 做法：部门文件和讲话稿默认不写“纳入年度考核”“开展专项督查”；用户要求写的，提示核对是否已列入督查检查考核计划
  - 检查：P2：`纳入.{0,8}考核`、`(专项|定期)督查`（讲话稿、部门文件）
- **JF-08 不把留痕当标准**（第8条、第14条）
  - 做法：不写“以照片、台账、学习笔记作为考核依据”“上传工作照片和轨迹”；确需佐证材料的，限定为必要的少量材料
  - 检查：P2：`拍照留痕`、`上传.{0,6}(照片|视频|轨迹)`、`学习笔记.{0,10}(检查|考核)`
- **JF-09 材料报送只报一次**（第12条）
  - 做法：材料报送通知写明报送渠道；不要求同时报纸质版和电子版；能从系统获取的不再要求报
  - 检查：P2：`纸质.{0,10}(电子|扫描)` 或 `(电子|扫描).{0,10}纸质` 同时出现
- **JF-10 压缩材料文字量**（第8条）
  - 做法：报送材料类通知可约定字数上限；汇报材料、总结默认从严压缩
  - 检查：起草说明中提示
- **JF-11 不搞频繁排名和“千分制”**（第8条）
  - 做法：考核方案不设按月、按季排名通报，不用千分制
  - 检查：P2：`(每月|按月|每季度|按季度).{0,10}(排名|通报)`；P1：`千分制`
- **JF-12 不向基层转嫁责任**（第16条）
  - 做法：面向乡镇（街道）、村（社区）的文件不写“签订责任状”“制度上墙”“分解下达指标”
  - 检查：P2：`制度上墙`、`签订.{0,6}责任(状|书)`、`分解下达.{0,4}指标`
- **JF-13 讲话控制时长**（第6条）
  - 做法：讲话稿开工时问清讲话时长；主要负责同志讲话、会议主报告按不超过1小时控制；交流发言不写一般性汇报和表态
  - 检查：起草说明中写明预计时长，字数换算按用户提供的语速
- **JF-14 已发文的事项不再开会部署**（第4条）
  - 做法：会议通知和讲话稿涉及已发文事项的，提示用户确认是否需要专门开会
  - 检查：起草说明中提示
- **JF-15 不协助规避发文管理**（第1条）
  - 做法：拒绝把正式文件改成“白头”、便笺或多文合一来规避发文数量控制，说明原因（见 `references/_shared/guardrails.md` 第六条）
  - 检查：不适用机检
- **JF-16 指令性要求的主体**（第1条）
  - 做法：以议事协调机构、部门名义面向下级党委和政府的文件，不写“必须”“务必”之类的指令性要求；改为商洽或建议口吻，或改由党委、政府办公厅（室）行文
  - 检查：P2：发文主体为部门、主送下级党委政府时提示
- **JF-17 创建达标活动**（第19条、第21条）
  - 做法：起草创建示范、达标活动方案时，提示用户确认已经批准；面向乡镇（街道）、村（社区）、学校的达标活动不予起草方案
  - 检查：P2：`达标(活动|创建)`、`创建示范`

## 五、未纳入或无法核实的内容

1. 规定没有给出字数统计口径、讲话稿字数和材料字数的具体数值。本文件中相关数值均标为工具约定，不得写成规定要求。
2. 各省、各部门的实施细则（如本地发文字数、会议时长的进一步规定）未收录，用户提供时以其为准。
3. 2019年中办《关于解决形式主义突出问题为基层减负的通知》等早期文件中的篇幅要求，本文件未收录；与本规定不一致的，按本规定执行（结尾段）。
4. 会议、借调干部、政务应用程序建设等与写作无关的条款（第5条、第9条至第11条、第13条、第18条、第20条）只在需要时查阅原文。
