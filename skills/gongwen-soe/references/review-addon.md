# 国有企业行业核稿附加清单

起草后自检、审稿模式审下级报来的材料时使用。通用八关核稿交 gongwen-review；本清单只列国企专用文书特有的检查项，级别含义同 `references/_shared/guardrails.md` 和 gongwen-review：P0 必改，P1 建议改，P2 提示。

## 一、通用附加检查

| 序号 | 检查项 | 怎么查 | 级别 |
|---|---|---|---|
| 1 | 决策程序顺序 | 找“先行”“已开工”“已签订”“追认”“投产后再提交职代会”；党委前置研究在董事会、经理层决策之前 | 倒置 P0；缺失 P1 |
| 2 | 前置研究不代替决策 | 党委会材料里有没有“决定投资”“批准合同” | P1 |
| 3 | 经理层授权 | 纪要议定的投资、担保（含“提供担保”）、借款融资、增资、产权转让是否在授权清单内；起草者有没有自行把会议结论改成“提交董事会审议” | 超授权 P1；改结论 P0 |
| 4 | 职工权益程序 | 涉及薪酬、安置、重要规章制度的，是否写明职代会或工会意见 | 缺失 P1；后置 P0 |
| 5 | 商业秘密和未公开信息 | 对外材料中有没有报价、成本、客户、未公开财务数据 | P0 |
| 6 | 信息披露 | 上市公司对外材料的经营数据、重大事项是否已披露 | P1，提示由董事会办公室确认 |
| 7 | 数据一致 | 同一数字在议题、议案、纪要、经营分析、ESG 报告中是否一致；与财务快报一致 | 不一致 P1；前后矛盾 P0 |
| 8 | 比率和单位 | 比率变化用百分点；同比写明基期；金额单位全文统一 | P1 |
| 9 | 绝对化表述 | “行业第一”“国内领先”“碳中和”“零事故”“零违规”有没有出处 | 对内 P1；对外 P0 |
| 10 | 状态不升级 | “拟”“将”有没有写成“已”；“已送审”有没有写成“已审定” | P1 |
| 11 | 个人信息 | 职工名单、身份证号、手机号、病情、处分对象姓名 | P0 |
| 12 | 提法 | 党建融合材料中的提法是否有原文出处 | 无出处 P1 |

## 二、按文书的专项检查

| 文书 | 必查 |
|---|---|
| “三重一大”议题材料 | 一事一议；类别和清单条目；方案比选；风险和措施；前置程序表每项都有依据材料或写“未提供”；需决策事项可表决 |
| 董事会议案 | “关于……的议案”；决策程序履行情况；提请审议事项逐项；须报出资人决定的已写明；关联董事回避 |
| 董事会决议 | 应出席、实际出席、委托出席；票数之和＝出席－回避；无回避的同意票过全体董事半数，有回避的过无关联关系董事人数半数（出席的无关联董事不足三人的提交股东会），章程更高的按章程；会上未通过的照写 |
| 总经理办公会纪要 | 只记议定事项；结论用词（同意、原则同意、暂缓、不同意）；责任部门和时限有出处；结论照会议原意，疑似超授权或须前置的已在起草说明给出依据和替换句 |
| 经营分析 | 指标台账可回查；口径（合并、累计、期末）；原因有材料依据；问题和措施对应 |
| 改革任务台账 | 状态五选一；已完成有佐证；过期未完成标“滞后”；报告与台账一致；完成率分母一致 |
| ESG 和社会责任报告 | 报告期、报告范围、编制依据、数据说明齐全；目标和成效分开；关键绩效表与上年可比 |
| 党建与经营融合材料 | 每条做法都有业务结合点和结果；不把整体增长归于党建；提法核对清单 |
| 合规管理报告 | 结论有统计依据；问题具体；不写个人姓名；审议程序只写已发生的 |

## 三、审稿模式的输出

1. 先给一页纸摘要：材料主旨一句话；程序风险（有或无）；主要问题 3～5 条；修改优先级。
2. 再给问题清单，列为：序号｜级别｜检查项｜位置｜原文｜问题｜依据｜修改建议。原文逐字摘录，个人信息用脱敏写法。
3. 不重写全文；是否上会、是否签发由用户决定。用户说“帮我改一版”时再改，改后按 `references/_shared/style/output-format.md` 输出。

## 四、无法运行脚本时的人工检索词

没有 Python 环境时，在正文中逐个搜索以下词语，命中的按第一部分判断：

1. 程序：先行、提前实施、追认、补办、后补、投产后、直接提交、径直、拆分、分批支付、党委会决定、党委会批准、会议决定投资。
2. 保密和披露：未公开、未披露、内部、报价、底价、中标价、成本价、客户名单、商业秘密。
3. 绝对化：第一、领先、首创、首个、填补、空白、碳中和、零碳、零排放、零事故、零违规、百分之百、100%。
4. 数据：率……增长（或下降）……%、同比、环比、万元、亿元。
5. 决议：应出席、实际出席、委托、同意……票、反对……票、弃权……票、回避；逐项把票数加一遍。
6. 台账：状态列逐行看；已完成行看佐证列；完成时限早于今天的行看状态。
