## 一、用途和适用

1. 用途：把一项“三重一大”事项或重大经营管理事项提交党委会前置研究讨论、董事会审议或总经理办公会研究时的上会材料。形式可以是议题报告、议题说明，也可以用签报形式呈报上会，按本企业制度。
2. 本模板适用：重大投资、增资、产权转让、资产重组、大额度资金运作、重要改革方案、重要规章制度、组织架构调整，以及按管理权限的重要人事事项（人事事项只写程序和职务，不写酝酿名单）。
3. 不适用：一般事项呈领导审批的签报交 gongwen-draft；非国企的议题材料交 gongwen-minutes；医院的党委会、院长办公会议题交 gongwen-hospital。

## 二、先判定：事项类别和决策链

动笔前先填下表，填不出的项标“待核实”，写进起草说明，不靠猜。

| 判定项 | 怎么判 | 写到材料哪里 |
|---|---|---|
| “三重一大”类别 | 重大决策、重要人事任免、重大项目安排、大额度资金运作，四选一或兼有 | 议题基本情况 |
| 是否属于前置研究清单 | 查用户提供的本企业清单，写条目号；没有清单的写“未提供清单，按《中国共产党国有企业基层组织工作条例（试行）》第十五条判断” | 前置程序表 |
| 决策主体 | 党委前置研究后，由董事会或经理层决定；国有独资公司须报出资人的，写明（`references/profile-detail.md` 第三部分） | 需决策事项 |
| 金额是否达到大额标准 | 用本企业标准；没有的列入起草说明“待核实”一行 | 议题基本情况 |
| 是否涉及职工切身利益 | 薪酬、安置、裁员、重要规章制度 | 前置程序表“职代会或工会意见” |
| 是否须上级审批或备案 | 上级企业、国资监管机构的审批事项，按用户材料 | 前置程序表 |

## 三、结构

```text
关于……的议题（或：关于提请审议……的报告）

提交部门：某部
汇报人：某部部长
会签部门：财务部、法律合规部

一、议题基本情况（事项、类别、金额、是否属于前置研究清单）
二、背景和依据（为什么要做；上级要求、规划依据、本企业决议）
三、方案（方案一、方案二的比较；推荐方案及理由）
四、风险分析和应对（市场、财务、法律合规、安全环保；每项写措施）
五、前置程序完成情况（正文按（一）（二）分项写，完整的表格作附件或列为起草说明附表）
六、需决策事项（请某会议研究讨论或审议的具体事项）
附件：1. 可行性研究报告　2. 法律意见书　3. 资产评估报告……
```

正文是纯文本，层次序数不跳级：第五部分写“（一）党委会前置研究讨论：本次提请。（二）合法合规审查：已出具法律意见书，见附件2。”，不在“五、”下直接用“1.”。前置程序完成情况表（工作底稿，可以用表格）：

| 程序 | 是否需要 | 完成情况 | 依据材料 |
|---|---|---|---|
| 党委前置研究讨论 | 是 | 拟提交党委会研究，日期未定 | 前置研究事项清单（条目号有则写） |
| 合法合规审查 | 是 | 已出具法律意见书 | 附件 2 |
| 可行性研究、尽职调查 | 是 | 已完成 | 附件 1 |
| 资产评估及备案 | 视事项 | 未提供 | 无 |
| 职代会审议或听取职工意见 | 涉及职工切身利益的必填 | 未提供 | 无 |
| 上级审批或备案 | 视事项 | 未提供 | 无 |

“完成情况”只有五种写法：已完成（写日期和文件）、办理中（未完成，写当前进度，如“已送审，尚未出具”）、拟于某日完成（日期不明的写“日期未定”）、未提供、不需要（写理由）。已送审不等于已审查通过，已上会不等于已同意。

## 四、写法

1. 一事一议。一份议题只提一件需要决策的事；附带的事项另起议题。
2. 第一段就写清事项、金额、决策主体，不写形势和意义。
3. 方案比较用表：投资额、资金来源、收益、风险、工期、对主业的影响。只有一个方案的，写明不作比选的理由（如上级已明确方式）。数据只用可研、评估、财务部门给的，缺的标【待补】。
4. 推荐方案写明倾向和理由，不写“各有利弊，请领导研究”（`references/_shared/style/defensive.md` 第四部分）。
5. 风险分析写具体风险和措施，不写“风险总体可控”了事。用户没有提供风险评估的，写一处【待补：风险评估结论和应对措施】。
6. 需决策事项写到可表决的程度：同意什么、金额多少、授权谁办理。
   - 党委会：提请研究讨论“关于向某子公司增资1.5亿元的方案，同意后提交董事会审议”。
   - 董事会：提请审议“同意向某子公司增资1.5亿元，授权经理层办理工商变更等后续事项”。
   - 总经理办公会：在授权范围内的写“研究决定”；超授权的写“研究后提交董事会审议”。
7. 党委会材料和董事会议案的区别：党委会材料侧重是否符合党和国家方针政策、发展战略，是否有利于国有资产保值增值，是否维护职工和社会公众利益；董事会议案侧重商业可行性、财务和法律。同一事项两份材料的数据一致。
8. 涉及人员的写职务，不写个人信息；人事任免议题只写程序和岗位，候选人情况由组织人事部门另行提供。

## 五、数据项和要素核对表

起草前逐项核对，缺的关键项标【待补】（一般不超过 3 处），其余写“未提供”，起草说明汇总一行：

1. 事项名称、金额、资金来源；
2. 本企业“三重一大”清单和前置研究清单的条目号；
3. 可研或论证结论；
4. 财务测算（投资回收期、内部收益率等，只用测算报告的数）；
5. 法律合规审查意见（中央企业重大决策由首席合规官签字，`references/glossary.md` 第五部分）；
6. 评估、审计、尽调结论；
7. 职代会或工会意见；
8. 上级审批或备案要求；
9. 会签部门意见（原文照录要点，不推定“一致同意”）。

## 六、常见毛病

1. 程序倒置：已签合同、已开工、已付款再上会；“投产后再提交职代会”。
2. 前置研究代替决策：党委会材料写“党委会决定”经营事项。
3. 化整为零：一个项目拆成几笔，各自低于大额标准。
4. 只有一个方案，或几个方案的数据口径不同，比不出高下。
5. 需决策事项不清：“请领导研究”“请予审定”，没说审定什么。
6. 风险一笔带过；可研数据和议题数据不一致。
7. 前置程序写“已完成”却没有依据材料。
8. 夹带：一份议题里塞进两三件要决策的事。

## 七、正误对照

误：本事项已经总经理办公会研究同意，拟直接提交董事会审议。本事项涉及职工安置，拟于投产后再提交职代会审议。
正：本事项属于公司党委前置研究讨论事项，拟提交党委会前置研究讨论后，再提交董事会审议。本事项涉及职工安置，安置方案须在提交董事会前听取职工意见，职代会审议安排【待补：时间】。

误：两个方案各有优劣，请领导研究决定。
正：两个方案相比，方案二投资少0.6亿元、工期短5个月（数据来自可研报告第四章），建议采用方案二。

误：项目风险总体可控。
正（材料有风险评估的）：照评估原文写风险和措施，素材台账注明出处，写成“主要风险是X，应对措施是Y”（X、Y 均来自可研报告或专项评估）。
正（材料没有风险评估的）：项目风险和应对措施【待补：风险评估结论和应对措施】。（起草说明：材料没有风险评估，请投资部门提供可研报告的风险分析或专项评估。）
