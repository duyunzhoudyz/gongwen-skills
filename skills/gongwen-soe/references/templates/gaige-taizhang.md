## 一、用途和边界

1. 用途：把本企业的改革任务逐项登记，按月或按季更新进展，并据此写阶段进展报告（报出资人、上级企业或本企业改革领导小组）。
2. 背景：国有企业改革深化提升行动（2023—2025 年）已于 2025 年收官；2026 年起各地、各企业按新一轮改革方案部署任务（`references/glossary.md` 第四部分）。任务名称、编号、目标只用用户提供的上级方案和本企业方案，不自拟任务。
3. 边界：只把上级通知拆成任务分解表、写贯彻落实方案的，交 gongwen-implement；巡视巡察、审计整改台账交 gongwen-rectify。

## 二、台账字段

| 字段 | 填写要求 |
|---|---|
| 序号 | 本企业台账编号，长期不变；新增任务往后编，不插号 |
| 改革任务 | 照上级方案或本企业方案原文，注明对应条目（如“方案第三部分第5条”） |
| 具体举措 | 本企业要做的事，写到可检验：做什么、做到什么程度 |
| 牵头部门、配合部门 | 部门名称；不写个人 |
| 责任领导 | 职务 |
| 完成时限 | 具体日期或月份；长期任务写“长期”并写阶段节点 |
| 成果形式 | 制度文件、方案、系统上线、完成交割等，写具体名称 |
| 进展情况 | 本期做了什么，写事实和日期 |
| 状态 | 五选一，见第三部分 |
| 佐证材料 | 文件名称、文号、会议纪要期号；没有的写“无”，不补做 |
| 备注 | 滞后原因、调整依据 |

台账是工作底稿，用 Markdown 表格；需要 Excel 的用 `scripts/md2xlsx.py` 转换。

## 三、状态口径

| 状态 | 认定标准 |
|---|---|
| 已完成 | 成果形式对应的成果已经产生，有佐证材料（如制度已印发、交割已完成） |
| 按计划推进 | 未到完成时限，且阶段节点按期完成 |
| 滞后 | 到了完成时限或阶段节点（时限等于统计截止日的也算）仍未完成；备注写原因和新的时限 |
| 未启动 | 尚未开展工作；已过启动节点的同时标“滞后” |
| 持续推进 | 长期任务，写本期阶段成果 |

1. 做完不等于见效：制度印发只能写“已完成制度制定”，执行效果另起一项或写进进展。
2. “基本完成”“接近完成”不作状态，写“按计划推进”或“滞后”，在进展中写完成比例和依据。
3. 状态由用户材料决定；材料没说的，状态写“待核实”，不替用户判定为“已完成”。

## 四、建账和更新

建账：
1. 把上级方案和本企业方案逐条对应拆到台账，一条任务可拆成几项举措，编号用“5-1”“5-2”。
2. 上级方案中有、本企业没有对应举措的，举措栏写【待补：本企业举措】，不照抄上级原文。
3. 时限早于上级时限；不擅自加码，不新增上级没有的报送要求。

更新：
1. 只改“进展情况”“状态”“佐证材料”“备注”四栏；任务、举措、时限的调整须有依据（如改革领导小组会议纪要），在备注写明。
2. 对照上期台账逐项比对：上期“已完成”的不回退；上期“按计划推进”、本期已过时限仍未完成的，改为“滞后”。
3. 完成率＝已完成项数÷总项数，写明分母（是否含长期任务），前后各期口径一致。
4. 机检：`python scripts/soe_check.py 台账.md --type 改革台账 --as-of <统计截止日期>`（SOE-105），查状态口径、已完成无佐证、过期未完成。完成时限等于统计截止日、到期仍未完成的，按“滞后”处理；只写月日的时限按截止日所在年份计算，“二季度”“上半年”按季末、半年末计算。

## 五、阶段进展报告

```text
某公司关于2026年三季度改革任务进展情况的报告

一、总体进展（总项数、已完成、按计划推进、滞后、未启动的项数和完成率，写明统计截止日期）
二、重点任务进展（按方案板块，每项写台账编号、进展事实、成果）
三、滞后任务和原因（逐项写编号、原因、新时限、措施）
四、下步安排（与滞后任务和下期节点对应）
附件：改革任务台账（截至某日）
```

1. 报告中的项数、状态与台账逐项一致；报告写“已完成”的，台账必须是“已完成”且有佐证。
2. 典型做法只写有事实和数据的，不拔高；改革成效写数据，没有的标【待补】。
3. 滞后任务不隐瞒，不改成“持续推进”。

## 六、常见毛病

1. 任务照抄上级方案，没有本企业举措。
2. 状态口径五花八门：“基本完成”“正在推进”“有序推进”。
3. 已完成没有佐证；把“已起草”“已上会”写成“已完成”。
4. 过期未完成仍标“按计划推进”。
5. 报告和台账数字对不上；完成率分母各期不一致。
6. 为了“进度好看”改时限、删任务。

## 七、正误对照

以下例句为虚构。

误：| 6 | 修订工资总额管理办法 | 财务部 | 2026年4月 | 稳步推进 | 无 |
正：| 6 | 修订工资总额管理办法 | 财务部 | 2026年4月30日 | 滞后 | 无 |，备注写“办法待上级企业审核，【待补：预计完成时限】”。

误：上半年改革工作扎实推进，重点任务亮点纷呈，取得阶段性成效。
正：截至6月30日，台账共28项任务，已完成11项，按计划推进12项，滞后4项，未启动1项，完成率39.3%（11÷28，含长期任务）。
