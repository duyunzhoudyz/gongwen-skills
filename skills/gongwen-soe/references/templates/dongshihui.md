## 一、用途和边界

1. 议案：提交董事会审议的书面文件，由提案人或提交部门起草，董事会办公室汇总。
2. 决议：记载董事会对议案作出的决定和表决结果，由出席董事签署。会议记录另行整理，记录讨论过程和发言（交 gongwen-minutes 的记录流程，或按本模板第三部分只出决议）。
3. 格式和签署以公司章程、董事会议事规则为准，不用红头（`references/_shared/profiles/units/guoqi.md` 第八部分）。董事会的议案、决议按《公司法》和公司章程办理，不按《党政机关公文处理工作条例》的议案、决议写（`references/_shared/rules/doc-types.md` 第五部分）。
4. 上市公司的董事会决议公告由董事会办公室按交易所格式编制，本包只写内部决议文本。

## 二、议案的结构和写法

```text
关于……的议案

各位董事：

（一段说明事项、金额、提请审议的事由。）

一、基本情况（背景、必要性、依据）
二、主要内容（方案要点，详细内容见附件）
三、决策程序履行情况（党委前置研究、专门委员会审议、合法合规审查、职代会或工会意见、上级审批）
四、对公司的影响和风险
五、提请审议事项（逐项写可表决的内容）

以上议案，请审议。

附件：……
提案人（或提交部门）：……
日期：……
```

写法：
1. 标题统一为“关于……的议案”，一案一事。
2. “决策程序履行情况”逐项写，只写用户提供的完成情况：
   - 党委前置研究：写会议时间和结论（如“2026年11月24日公司党委会前置研究讨论，同意提交董事会审议”）；没有的写【待补：党委前置研究讨论情况】。
   - 专门委员会：写委员会名称和审议意见；没有设委员会或不需要的不写。
3. “提请审议事项”写成董事可以逐项表决的句子：
   - 误：请董事会研究。
   - 正：一是同意公司向某子公司增资1.5亿元；二是授权公司经理层办理增资协议签署、工商变更等相关事宜。
4. 国有独资公司须由出资人机构决定的事项（章程修改，合并、分立、解散、申请破产，增减注册资本，分配利润），写“本议案经董事会审议通过后，报履行出资人职责的机构决定”（《公司法》第一百七十二条）。
5. 涉及关联交易的，写明关联关系和需回避的董事（写职务或“某董事”），无关联关系董事不足三人的提示提交股东会（《公司法》第一百三十九条、第一百八十五条）。
6. 数据与党委会议题材料、可研报告一致；不一致的取依据材料的数，列入待核实。

## 三、决议的结构和写法

```text
某公司第某届董事会第某次会议决议

某公司第某届董事会第某次会议于2026年12月8日在公司会议室以现场方式召开。会议通知于2026年11月27日以书面方式送达全体董事。会议应出席董事8人，实际出席董事8人（其中董事某某书面委托董事某某代为出席并表决）。公司部分高级管理人员列席会议。会议由董事长某某召集并主持。

会议审议并通过以下议案：

一、审议通过《关于向某子公司增资的议案》

同意公司向某子公司增资1.5亿元，授权公司经理层办理增资协议签署、工商变更等相关事宜。

表决结果：同意8票，反对0票，弃权0票。

二、……

出席董事签字：
```

写法：
1. 会议基本情况只写记录里有的：届次、时间、地点、方式（现场、通讯、现场结合通讯）、通知时间和方式、应出席和实际出席人数、委托出席、列席、召集人和主持人。缺的省略，届次、时间、地点缺了才标【待补】。
2. “会议的召集、召开和表决程序符合《公司法》和公司章程的规定”这类合法性声明，只在用户确认或记录中有时写；写进去之前核对第四部分的人数和票数。
3. 每项议案写：议案名称（书名号）、决定内容、表决结果。决定内容照议案的“提请审议事项”和会上的修改意见写，会上没改的不改。
4. 有反对票、弃权票的，按记录写明董事和理由（写“某董事”或职务）；记录没写理由的不写理由，不编，列入起草说明待补。
5. 关联董事回避的，写“关联董事某某回避表决”，表决结果按回避后的人数写。
6. 会上未通过、暂缓审议的议案照写结果，不删。
7. 决议不写讨论过程，讨论过程进会议记录。

## 四、表决的核对规则

依据《公司法》第七十三条（有限责任公司）、第一百二十四条（股份有限公司），以公司章程为准。决议成稿后逐项动手算：

| 核对项 | 规则 | 不符时 |
|---|---|---|
| 出席人数 | 实际出席（含委托出席）超过应出席的一半，会议才能举行 | P0，提示会议可能不能举行，不写“会议合法有效” |
| 票数之和 | 同意＋反对＋弃权＝实际出席人数－回避人数 | P0，回到记录核对 |
| 通过 | 无回避的，同意票须超过全体董事的半数；有关联董事回避的，同意票须超过无关联关系董事人数的半数（《公司法》第一百三十九条、第一百八十五条）；章程规定更高比例的，按章程 | P0，不写“审议通过” |
| 无关联董事人数 | 有回避的，出席会议的无关联关系董事不足三人时，该事项提交股东会审议 | P1，提示提交股东会 |
| 一人一票 | 委托出席的，受托董事代为表决，委托书写明授权范围 | 记录没有委托书的列入待核实 |
| 签字 | 出席董事在会议记录、决议上签名 | 不替任何人写“已签” |

章程规定了更高比例（如三分之二以上）的事项，按章程算。机检：`python scripts/soe_check.py 决议.txt --type 决议`（SOE-104）。

## 五、数据项和要素核对表

议案：事项、金额、依据文件、方案要点、党委前置研究情况、专门委员会意见、合规审查意见、职工意见、上级审批要求、提请审议事项、附件清单。

决议：届次、时间、地点、方式、通知情况、应出席、实际出席、委托出席、列席、召集和主持、每项议案的决定内容和票数、反对和弃权理由、回避情况。

## 六、常见毛病

1. 议案写成情况汇报，没有可表决的“提请审议事项”。
2. 议案漏写党委前置研究情况，或把“拟提交党委会”写成“已经党委会研究”。
3. 决议票数相加不等于出席人数；同意票不过半数却写“审议通过”。
4. 决议里预先写好“全票通过”，会前就印好。
5. 把讨论意见写成决议内容，或把“原则同意”写成“同意”。
6. 国有独资公司须报出资人决定的事项，决议写成“董事会决定”了事。
7. 关联交易未写回避；委托出席没有委托书。

## 七、正误对照

以下例句为虚构，只说明核对方法。

误：会议应到董事11人，实到6人，会议合法有效。审议通过《关于修订采购管理办法的议案》，表决结果：同意3票，反对2票，弃权1票。
正：会议应出席董事11人，实际出席董事6人。审议《关于修订采购管理办法的议案》，表决结果：同意3票，反对2票，弃权1票。（起草说明：同意3票未超过全体董事11人的半数，按《公司法》第一百二十四条不能写“审议通过”，请核对记录和章程。）

误：全体董事13人，关联董事4人回避表决，同意6票，反对1票，弃权0票，未超过全体董事13人的半数，议案未通过。
正：关联董事4人回避表决，表决结果：同意6票，反对1票，弃权0票，同意票超过无关联关系董事9人的半数，审议通过。（《公司法》第一百八十五条；章程规定更高比例的按章程）

误：董事会审议了增资事宜，董事们一致认为增资很有必要，同意增资。
正：审议通过《关于向某子公司增资的议案》。同意公司向某子公司增资1.5亿元。表决结果：同意8票，反对0票，弃权0票。
