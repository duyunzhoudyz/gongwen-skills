## 一、企业属性判定

开工时从画像或用户的话里判断以下四项，判断不了的按默认值处理并写进起草说明“所作假设”。

| 属性 | 选项 | 对写作的影响 | 默认值 |
|---|---|---|---|
| 层级 | 集团总部；二级子企业；三级及以下子企业 | 总部写“集团公司”，对下用通知、对出资人用请示报告；子企业的重大事项常须报上级企业审批或备案 | 集团总部 |
| 出资关系 | 国有独资公司；国有资本控股公司（含混合所有制企业）；集团全资子企业；国有参股 | 国有独资公司不设股东会，由履行出资人职责的机构行使股东会职权（《公司法》第一百七十二条）；集团全资子企业的唯一股东是集团公司，不属于国有独资公司，不设股东会，股东决定由集团公司以书面形式作出（《公司法》第六十条），按集团的审批、备案规定写；控股公司有股东会；参股企业一般不按国企程序写 | 国有独资公司 |
| 是否上市 | 上市公司；非上市 | 上市公司的对外表述受信息披露规则约束，决议公告、定期报告由董事会办公室按交易所格式编制，本包只写内部文本 | 非上市 |
| 出资人层级 | 中央企业；地方国企（省、市、县属） | 中央企业直接适用国资委规章；地方国企以本级国资委文件为准，国资委规章多为参照 | 地方国企 |

## 二、治理主体与各自的文书

| 主体 | 本包文书 | 依据 |
|---|---|---|
| 党委（党组）：把方向、管大局、保落实，重大经营管理事项先研究讨论 | 前置研究议题材料、党建与经营融合经验材料 | 《中国共产党国有企业基层组织工作条例（试行）》第十一条、第十五条 |
| 股东会或出资人机构（国有独资公司由出资人机构行使股东会职权） | 议案中“报出资人决定”的事项 | 《公司法》第一百六十九条、第一百七十二条 |
| 董事会及专门委员会 | 董事会议案、决议；议案写“已经某委员会审议” | 《公司法》第六十七条、第一百七十三条；章程、议事规则 |
| 经理层（总经理办公会），在章程和董事会授权范围内决策 | 总经理办公会议题、纪要；经营分析报告 | 《公司法》第七十四条；董事会授权管理办法 |
| 职工代表大会：改制、重大经营问题、重要规章制度听取意见；合并、分立、改制、解散、破产中职工的裁减、分流和安置方案审议通过 | 议题材料中的“职代会审议情况” | 《公司法》第十七条第三款；《企业民主管理规定》（总工发〔2012〕12 号）第十四条第（二）项 |
| 合规管理部门、首席合规官（中央企业重大决策的合规审查意见由首席合规官签字） | 合规管理报告；议题材料中的“合规审查意见” | 《中央企业合规管理办法》第十二条、第二十一条 |

“定战略、作决策、防风险”“谋经营、抓落实、强管理”等常用表述，写进正文时按本企业文件原文。

## 三、决策链速查

先查用户提供的本企业清单；没有清单的，按下表判断，并在起草说明中写“未提供前置研究事项清单，按通用规则判断”。

| 事项 | 决策链 | 本包写法 |
|---|---|---|
| 党的建设、按管理权限的干部任免、纪检 | 党委（党组）讨论决定 | 党委会纪要可写“会议决定”；交 gongwen-party 或 gongwen-minutes |
| 重大经营管理事项（发展战略、中长期规划、重要改革方案、资产重组、产权转让、资本运作、大额投资中的原则性方向性问题、组织架构调整、重要规章制度、涉及安全生产稳定职工权益社会责任的重大事项） | 党委前置研究讨论 → 董事会或经理层决定 | 党委会材料写“研究讨论”“同意提交董事会审议”；决定由董事会或经理层作出（条例第十五条） |
| “三重一大”事项（重大决策、重要人事任免、重大项目安排、大额度资金运作） | 集体决策，不得个人或少数人决定 | 议题材料写明属于哪一类、走哪个会；大额标准用本企业规定，没有的在起草说明“待核实”一行请用户提供 |
| 董事会授权经理层的事项 | 总经理办公会在授权范围内决定，向董事会报告行权情况 | 纪要写“根据董事会授权”，授权依据来自用户；疑似超授权的，纪要照会议原意写，起草说明写依据和“提交董事会审议”的替换句（`references/redlines.md` 第一条第 5 款） |
| 国有独资公司须由出资人机构决定的事项：章程制定修改，合并、分立、解散、申请破产，增减注册资本，分配利润 | 董事会审议 → 报出资人机构决定 | 议案写“审议通过后报履行出资人职责的机构决定”（《公司法》第一百七十二条） |
| 改制、解散、申请破产，经营方面的重大问题，重要规章制度 | 听取工会意见，通过职代会或其他形式听取职工意见 | 议题材料“前置程序”栏写职代会或工会意见的完成情况（《公司法》第十七条第三款） |
| 上市公司达到披露标准的事项 | 董事会或股东会审议，及时披露 | 本包只写内部议案；公告由董事会办公室编制 |

两条通用原则：
1. 前置研究讨论不代替董事会、经理层依法决策。党委会材料不写“党委会决定投资”“党委会批准预算”。
2. 董事会对党委前置研究意见有异议、协调不成的，按规定向上级党组织或出资人报告。这类情形只照用户材料写，不推测。

## 四、发文主体与主语

1. 党委会前置研究议题：提交部门写“某部”；正文主语“公司”“本项目”；请求写“提请党委会前置研究讨论”。
2. 董事会议案：开头“各位董事：”，主语“公司”，结尾“以上议案，请审议。”；决议主语“公司董事会”“会议”，只写决定和表决结果。
3. 总经理办公会纪要：主语“会议”，“会议听取了……汇报”“会议议定”。
4. 经营分析、改革进展、合规报告：主语“公司”“集团公司”；子企业可用代号，任务按台账编号引用。
5. ESG 报告主语“公司”或“本公司”，全篇统一，不与“我们”混用；融合材料主语“公司党委”“某党支部”，做法和结果的主体分清。
6. 企业名称在联网工具中建议用代号（如“A集团”“甲公司”），正文和台账一致。

## 五、关键动词的分寸

| 词 | 用于 | 不用于 |
|---|---|---|
| 研究讨论 | 党委（党组）前置研究 | 董事会、经理层的决定 |
| 审议 | 董事会、股东会、职代会审议议案 | 党委前置研究（写“研究讨论”） |
| 决定、作出决议 | 董事会、股东会、出资人机构；授权范围内的经理层 | 党委对经营事项的前置研究 |
| 审定、审批 | 按本企业制度有审批权的主体 | 没有权限的部门 |
| 原则同意 | 会上同意方向、细节待完善 | 会上已明确同意的事项（写“同意”） |
| 暂缓 | 会上决定推迟研究 | 会上否决的事项（写“不同意”） |
| 备案 | 事后报告，不需批准 | 须批准的事项 |

## 六、其他单位使用本包时

| 用户 | 做法 |
|---|---|
| 国资监管机构的处室（单位类型为党政机关），审下级企业报来的台账、经营分析、ESG 报告 | 用审稿模式，按 `references/review-addon.md` 出问题清单，不替企业补数据 |
| 高校、科研院所所属的资产经营公司 | “报出资人决定”写学校或主管部门，以章程为准 |
| 县、乡所属的国有平台公司 | 按地方国企处理；报本级国资监管机构或政府审批的，审批链来自用户 |
| 金融类国有企业 | 本包只处理通用部分，监管报送材料以监管文件为准 |
| 国企派驻的乡村振兴、驻村干部写村务材料 | 交 gongwen-grassroots |
