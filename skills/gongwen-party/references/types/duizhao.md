## 一、先分清是哪种会、哪份材料

| 项目 | 民主生活会 | 组织生活会 |
|---|---|---|
| 参加对象 | 县以上党和国家机关党员领导干部（《若干规定》第二条第一款）；经济组织、文化组织、社会组织等的党组（党委）成员执行本规定（第二条第二款）；国企、高校、乡镇党委等基层党组织领导干部参照执行（第十九条） | 党支部全体党员，党员领导干部以普通党员身份参加（双重组织生活） |
| 频次 | 每年1次，一般在第四季度；到会人数须达应到的三分之二以上（第七条） | 每年至少1次，一般在第四季度（支部工作条例第十七条） |
| 材料名称 | 领导班子对照检查材料、个人发言提纲（第九条） | 支部班子对照检查材料、党员个人对照检查材料或发言提纲，以通知为准 |
| 对照内容 | 当年通知列出的方面；没有通知的按第六条六项基本内容 | 当年通知；没有通知的按“对照合格党员标准、对照入党誓词”（第十八条） |

用户说不清的，问一句“是班子成员参加的民主生活会，还是支部党员参加的组织生活会？”，不要自行假定；用户说“直接写”的，按本人身份推定（领导班子成员按民主生活会，普通党员按组织生活会），写进所作假设。

## 二、个人对照检查材料（发言提纲）

### （一）结构

1. 开头：一两句交代会前学习、征求意见、谈心谈话情况，事实来自用户。
2. 上一次整改措施落实情况：逐条写，状态按用户说法（`references/writing-rules.md` 第五部分）。
3. 对照检查情况：按通知列出的方面逐项写。每个方面一两个问题，每个问题有本人事例。通知要求“逐条回应征求到的意见”的，把反馈给本人的意见吸收进对应方面。
4. 原因剖析：按通知要求的角度，每条落到具体问题上。本人的想法只用本人说过的话；由事例推出的，在所作假设中请本人确认（`references/writing-rules.md` 第二部分）。
5. 整改措施：与问题一一对应，写时限和标准。
6. 受到诫勉谈话的整改情况：本人受到诫勉谈话的，按本人提供的情况说明整改（《若干规定》第六条），没有的不写。
7. 个人有关事项：只用于民主生活会个人发言提纲（第九条第（四）项），或通知要求时；留【待补：按规定说明的个人有关事项，由本人填写】，内容不经联网模型。组织生活会、民主评议的个人材料不设这一部分。

### （二）写法要点

1. 主语用“我”或“本人”，全文统一。
2. 开头不写形势和意义，不写“在……的正确领导下”。
3. 问题部分篇幅占全文一半左右，原因和措施各占四分之一左右（工具约定，通知另有要求的按通知）。
4. 本人分管领域的问题要写清本人的责任，不推给下属或客观条件。
5. 主要负责人的个人材料，写清本人对班子问题应负的责任。
6. 民主生活会个人发言提纲应当本人动手撰写（第九条第（四）项）。所作假设写明“本稿按本人提供的事例整理，请本人逐段审改定稿”；秘书、支部书记替他人准备的，本人认识只用本人说过的，由事例直接推出的原因请本人确认，转述人的推测不写，标【待补：本人的认识】（SKILL.md 第三步第 7 款）。

## 三、班子对照检查材料

### （一）结构

1. 开头：会前准备情况，征求意见的范围、方式、条数（用户提供）。
2. 上一次民主生活会整改措施落实情况：逐条写，对应《若干规定》第十条第（一）项“通报上一次民主生活会整改措施落实情况”。
3. 对照检查情况：按通知列出的方面写班子集体的问题，吸收征求意见。
4. 原因剖析。
5. 整改措施：每条写责任领导、牵头部门、时限和标准。

### （二）写法要点

1. 主语用“领导班子”“党组（党委）”“我们”。
2. 查集体决策、执行、作风、班子建设的共性问题，不把个别成员的问题写成班子问题。
3. 征求意见全部列入回应表，属于班子的逐条对应问题和措施，属于个人的注明转给哪位班子成员。
4. 整改措施的责任领导写职务，不写全名。
5. 多名成员的个人材料与班子材料一起出的，交叉核对：个人材料不照抄班子问题；同一事项在班子材料和个人材料中的说法、时间、数字一致。

## 四、民主评议党员个人自评

1. 民主评议党员一般每年1次，可结合组织生活会进行（支部工作条例第十八条）。
2. 自评按“对照合格党员标准、对照入党誓词”联系个人实际进行党性分析，栏目以通知和评议表为准。
3. 写本人表现，不用支部成绩代替；“优秀”“合格”等评定等次由党支部综合评定，自评中不写成结论，测评结果也不直接写成组织评定结论。
4. 没有本人事例的，只出提纲和填写指引（`references/frameworks.md` 第一部分）。

## 五、会后整改清单

会后需要整理整改清单的，用表格交付：

| 序号 | 问题 | 整改措施 | 责任人（职务） | 完成时限 | 完成标准 | 进展 |
|---|---|---|---|---|---|---|

1. 问题和措施照对照检查材料原文，不弱化。
2. 进展只按用户说法，未开始的写“未开始”。
3. 需要 Excel 的，有 Python 和 openpyxl 时把表格存为 `整改清单.md`，运行 `python scripts/md2xlsx.py 整改清单.md 整改清单.xlsx --title 民主生活会整改清单`；不能运行的，交付 Markdown 表格，请用户粘贴到 Excel。
4. 巡视巡察、审计反馈问题的整改方案、台账交 gongwen-rectify；专题民主生活会与巡视整改合开的，对照检查材料由本 skill 写，整改台账和整改报告交 gongwen-rectify。

## 六、常见毛病

| 毛病 | 表现 | 改法 |
|---|---|---|
| 千人一面 | 班子成员个人材料问题相同，只换了名字 | 每人按分工补本人事例 |
| 以工作代检查 | 通篇是工作成绩和工作建议 | 问题部分只写问题；成绩一句带过或不写 |
| 照抄往年 | 问题、措施与去年相同 | 雷同检测，补今年情况；去年的问题没改好的，如实写在上年整改情况中 |
| 回避意见 | 征求到的尖锐意见没有出现 | 回应表逐条列出 |
| 措施落空 | 只有表态 | 写动作、时限、标准 |
