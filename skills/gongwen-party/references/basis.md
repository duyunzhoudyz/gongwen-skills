## 一、《县以上党和国家机关党员领导干部民主生活会若干规定》

出处：中共中央印发，2016年12月23日起施行，1990年5月25日中共中央印发的《关于县以上党和国家机关党员领导干部民主生活会的若干规定》同时废止。全文见新华社2017年1月12日播发稿（人民网转载）。下文简称《若干规定》。

| 条款 | 要点 | 本 skill 怎么用 |
|---|---|---|
| 第二条 | 第一款，适用对象：县以上党的各级委员会、纪律检查委员会的常务委员会委员，工作委员会委员，党组（党委）成员，县以上党和国家机关各部门（含人民团体）的党员领导干部。第二款：经济组织、文化组织、社会组织和其他组织的党组（党委）成员执行本规定 | 判断用户开的是民主生活会还是组织生活会；设党组的国企等，党组成员执行而不是参照 |
| 第五条 | 主题一般由上级党组织统一确定，或由领导班子根据自身建设实际确定并报上级党组织同意 | 主题只用通知原文，不自拟 |
| 第六条 | 围绕主题对照检查的基本内容共六项，概括为：（一）遵守党章、贯彻党的理论和路线方针政策、执行政治纪律和政治规矩；（二）领导班子自身建设、民主集中制、组织生活、用人导向、批评和自我批评；（三）正确行使权力、履职尽责、科学民主依法决策；（四）践行社会主义核心价值观、清正廉洁、家庭家教家风；（五）执行群众路线、改进作风、调查研究、联系群众；（六）履行全面从严治党主体责任和监督责任。各项原文以规定全文为准。六项之后另有一句：受到诫勉谈话的，应当说明整改情况 | 没有当年通知时的通用框架，方面标题不逐个标记，起草说明待核实一行请对照本年度通知；本人受到诫勉谈话的，个人发言提纲按本人提供的情况说明整改 |
| 第七条 | 每年召开1次，一般安排在第四季度；提前或延期须报上级党组织同意。到会人数必须达到应到会人数的三分之二以上 | 判断时间节点；整理会议记录、写召开情况报告时核对到会人数 |
| 第八条 | 出现重大决策失误、巡视审计发现重要问题、发生违纪违法案件等情形的，专门召开民主生活会 | 专题民主生活会，主题按通知 |
| 第九条 | 会前：制定会议方案，提前10日报上级党组织审核；学习；征求意见并如实反馈；班子成员互相谈心谈话；撰写领导班子对照检查材料和个人发言提纲。个人发言提纲应当自己动手撰写，并按规定说明个人有关事项 | 本 skill 只做结构与素材组织的依据：个人发言提纲的所作假设提醒本人动手撰写、逐段审改；个人有关事项栏只设在民主生活会个人发言提纲中，内容不进联网模型 |
| 第十条 | 程序：通报上一次整改措施落实情况和本次征求意见情况；主要负责人代表班子对照检查；班子成员逐一对照检查、自我批评，其他成员提出批评意见；主要负责人总结。因故缺席的提交书面发言材料 | 班子材料写上一次整改情况；缺席人员的书面发言按个人材料处理 |
| 第十一条 | 自我批评联系实际、针对问题、触及思想；相互批评开诚布公，防止以工作建议代替批评意见 | 问题、原因、批评意见的写法 |
| 第十三条 | 对检查和反映出的问题，制定整改措施，确定整改目标和完成时限 | 措施必须有时限 |
| 第十五条 | 会后15日内将会议情况报告和会议记录报上级党组织，并报上级纪委和党委组织部门；报告主要内容是征求意见情况、批评和自我批评情况、主要问题及整改措施 | 民主生活会召开情况报告的结构 |
| 第十九条 | 国有企业党组织、高等学校党组织、乡镇党委等基层党组织领导干部民主生活会参照执行 | 单位差异 |

## 二、《中国共产党支部工作条例（试行）》

出处：中共中央印发，2018年10月施行，全文见中国政府网2018年11月25日发布稿。下文简称“支部工作条例”。

| 条款 | 要点 | 本 skill 怎么用 |
|---|---|---|
| 第十一条 | 党员大会一般每季度召开1次；表决须有半数以上有表决权的党员到会，赞成人数超过应到会有表决权党员的半数为通过；村、社区重要事项以及与群众利益密切相关的事项，必须经党员大会讨论 | 记录整理时核对到会人数和表决结果 |
| 第十二条 | 支部委员会会议一般每月召开1次，须有半数以上委员到会；重要事项提交党员大会前一般先经支委会讨论 | 记录整理、支部计划 |
| 第十三条 | 党小组会一般每月召开1次，组织政治学习、谈心谈话、批评和自我批评 | 支部计划 |
| 第十四条 | 党员大会、支委会由书记召集并主持，书记不能参加的可委托副书记或委员 | 记录中的主持人 |
| 第十六条 | 按期开展“三会一课”；党课针对党员思想和工作实际，注重身边人讲身边事；党委（党组）书记每年至少讲1次党课；每月相对固定1天开展主题党日，组织集中学习、过组织生活、民主议事和志愿服务等；开展前确定主题和内容，开展后抓好议定事项落实 | 党课、主题党日、支部计划 |
| 第十七条 | 组织生活会每年至少1次，一般在第四季度；以党员大会、支委会或党小组会形式召开；会前学习、谈心谈话、听取意见，会上查摆问题、批评和自我批评、明确整改方向，会后制定整改措施逐一落实 | 组织生活会材料 |
| 第十八条 | 民主评议党员一般每年1次，对照合格党员标准、对照入党誓词，联系个人实际进行党性分析；可结合组织生活会进行 | 个人自评、组织生活会对照检查的通用框架 |
| 第十九条 | 支部委员之间、委员和党员之间、党员和党员之间，每年谈心谈话一般不少于1次；坦诚相见、交流思想、交换意见、帮助提高 | 谈心谈话提纲 |
| 第二十七条 | 党支部书记每年向上级党组织和党支部党员大会述职，接受评议考核 | 支部书记述职 |

## 三、《中国共产党党员教育管理工作条例》

出处：中共中央印发，2019年5月，全文见中国政府网2019年5月21日发布稿。

| 条款 | 要点 | 本 skill 怎么用 |
|---|---|---|
| 第十六条 | 运用“三会一课”对党员进行经常性教育管理；党员领导干部参加双重组织生活 | 领导干部以普通党员身份参加支部组织生活会时，材料按个人对照检查写 |
| 第十九条 | 党组织负责人经常同党员谈心谈话，有针对性地做好思想政治工作 | 谈心谈话提纲 |

## 四、《党委（党组）书记抓基层党建工作述职评议考核办法（试行）》

出处：中共中央组织部印发，2019年12月30日起施行，全文见共产党员网2020年1月7日发布稿。下文简称“述职评议考核办法”。

| 条款 | 要点 | 本 skill 怎么用 |
|---|---|---|
| 第三条 | 以市、县、乡镇（街道）为重点，推动机关、国有企业和高校、公立医院等事业单位全覆盖 | 各类单位书记述职 |
| 第四条 | 述职内容五方面，概括为：学习贯彻和落实上级部署；书记履行第一责任人职责、推动班子成员履责；落实基层党建重点任务、加强党支部和党员队伍建设；发挥战斗堡垒和先锋模范作用、服务中心工作；推动落实党风廉政建设责任制、意识形态工作责任制等。各地可按年初重点任务确定年度述职重点，注重考核上年度整改清单和巡视巡察反馈中基层党建问题的整改 | 述职框架；上年度点评问题的整改写在前面。各方面原文以办法全文和本级通知为准 |
| 第五条 | 年底或次年年初进行；市、县、乡镇（街道）党（工）委书记一般现场述职；述职要把自己摆进去，总结工作成效，主要查摆突出问题、分析根源、提出措施；述职报告在一定范围内公布 | 现场述职按时长控制篇幅；问题部分写本人责任 |
| 第七条 | 针对评议考核指出的问题列出整改清单，抓好整改 | 下一年述职的“上年度问题整改情况” |
