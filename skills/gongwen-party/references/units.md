# 不同单位类型下的调整

先读 `references/_shared/profiles/units/` 下对应的单位画像，再按本文件调整。本单位制度文件（如本单位党支部工作实施办法、民主生活会通知）与本文件不一致的，按本单位制度。

## 目录

一、党政机关

四、公立医院
五、高校
六、中小学
七、国有企业

## 一、党政机关

1. 民主生活会直接适用《若干规定》，参加对象见第二条；机关党员以普通党员身份参加所在支部组织生活会。
2. 材料报送对象一般是上级党组织和组织部门、纪委（第十五条），篇幅、格式、截止时间以通知为准。
3. 机关支部的党课、主题党日联系本部门业务，不写成部门工作总结。
4. 主语：党组、局党组、领导班子；机关党委、机关支部。

## 二、基层（县乡政府及部门、乡镇、街道）

1. 县直部门党组（党委）成员属于县以上党和国家机关党员领导干部，民主生活会直接适用《若干规定》（第二条第一款）；乡镇党委领导干部参照执行（第十九条）。
2. 乡镇（街道）党（工）委书记抓基层党建一般现场述职（述职评议考核办法第五条），按通知规定的时长换算篇幅；述职重点常涉及村（社区）党组织建设、软弱涣散党组织整顿，事实只用用户提供的。
3. 乡镇干部事例多涉及群众，群众姓名、电话、住址一律脱敏。
4. 主语：镇党委、街道党工委、领导班子。

## 三、社区（居委会、村委会）

1. 村、社区重要事项以及与群众利益密切相关的事项，必须经党支部党员大会讨论（支部工作条例第十一条）。整理党员大会记录时核对议题是否经过讨论、表决是否有效。
2. 老党员、流动党员多：党课和主题党日用语通俗，句子短，少用缩略语和外来词；流动党员参加组织生活的情况按用户提供的写。
3. 主题党日常结合志愿服务、为民办实事，写清服务对象和对接安排；涉及困难群众、残疾人等的，不写真实姓名和家庭情况。
4. 主语：社区党委（党总支、党支部）、村党组织。

## 四、公立医院

1. 党支部建在内设机构，党支部书记一般由内设机构负责人中的党员担任（中办《关于加强公立医院党的建设工作的意见》第（十）项）；科室支部材料常与科室业务交织，党建材料写党员作用，业务数据只用用户提供的。
2. 内设机构党支部严格执行“三会一课”、组织生活会、民主评议党员等制度（同上，第（八）项）。
3. 事例涉及患者的，姓名、病案号、住院号、床号一律脱敏，写“某患者”。
4. 医德医风、行风建设相关事例只用用户提供的，不编表扬信、锦旗数量。
5. 主语：医院党委、某科室党支部。

## 五、高校

1. 高校党组织领导干部民主生活会参照《若干规定》执行（第十九条）。
2. 教工党支部和学生党支部分开：教工支部结合教学科研，学生支部结合学业、实践和成长；支部设置以学校规定为准。
3. 学生党员材料中的学号、成绩、奖惩、家庭情况一律脱敏。
4. 研讨发言、党建工作报告中的学院数据与学校口径一致，用户没说明口径的标【待核实】。
5. 辅导员与学生的谈心谈话属于学生思想政治工作，交 gongwen-university；本 skill 只做党内谈心谈话提纲。
6. 主语：学校党委、学院党委（党总支）、某党支部。

## 六、中小学

1. 学校党组织领导的校长负责制见 `references/_shared/profiles/units/zhongxiaoxue.md` 所列中办意见；多数中小学为党支部或党总支。
2. 党员教师的事例涉及学生的，学生姓名、班级、成绩、家庭情况一律脱敏。
3. 主题党日、党课的时间安排以学校规定为准，用户没说的写【待补】。
4. 主语：学校党支部（党总支）。

## 七、国有企业

1. 设党组的国有企业（如部分中央企业），党组（党委）成员执行《若干规定》（第二条第二款）；国有企业党委等基层党组织领导干部参照执行（第十九条）。以上级通知为准。
2. 党建工作报告写清党建对生产经营的具体作用，事例和数据只用用户提供的；“党建与经营融合”专题经验材料交 gongwen-soe。
3. 经营数据、合同金额、客户名称属于商业秘密的，不写进材料；用户已发来的提醒删除。
4. 车间、项目部党支部的材料结合安全生产、项目攻坚中的党员事例。
5. 主语：公司党委、集团党委、某党支部。
