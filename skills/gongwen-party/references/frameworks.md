# 只出提纲时的交付模板

A 类材料（本人亲历）缺少本人事例时，按本文件交付提纲和填写指引，不生成完整正文（`references/_shared/guardrails.md` 第六条第 4 款）。谈心谈话在任何情况下都只交付提纲和空白记录表。

交付时在回复开头用第五部分的话说明原因（属于首轮交付的情形①），不说教，不拒绝整个任务。提纲和填写指引的位置按本 skill 的“输出规范”。模板内只有标题、层次序数和【待补】【待核实】，说明写在模板外。

## 目录

一、个人对照检查材料和发言提纲
二、研讨发言和心得体会（含思想汇报）
三、书记抓基层党建述职
四、谈心谈话提纲和空白记录表
五、说明原因的话

## 一、个人对照检查材料和发言提纲

（一）提纲

1. 标题按通知；第一部分的会议名称按实际会议二选一；第二部分的方面按通知逐项列出，有几个方面列几项。
2. 第五部分“个人有关事项”只用于民主生活会个人发言提纲（《若干规定》第九条第（四）项）或通知要求时；组织生活会、民主评议的个人材料删去。
3. 本人受到诫勉谈话的，第四部分后加“受到诫勉谈话的整改情况”，内容由本人提供（《若干规定》第六条）。

```text
【待补：标题】

按照通知要求，会前学习了【待补：学习材料名称】，征求意见【待补：方式和条数】，与【待补：谈话对象（职务）】谈心谈话。

一、上一次民主生活会（组织生活会）整改措施落实情况
【待补：去年查摆问题的逐条落实情况】

二、对照检查情况
（一）【待核实：通知列出的第一个方面】
【待补：本人在这方面的具体问题和事例】
（二）【待核实：通知列出的第二个方面】
【待补：本人在这方面的具体问题和事例】

三、产生问题的原因
【待补：每个问题当时本人的想法和做法】

四、整改措施
【待补：每个问题对应的措施、完成时限和标准】

五、个人有关事项
【待补：按规定说明的个人有关事项，由本人填写】
```

（二）填写指引

| 部分 | 需要本人提供的事实 | 句式 |
|---|---|---|
| 上年整改 | 去年查摆问题逐条的落实情况：做了什么、何时完成、效果 | 针对去年查摆的“____”问题，本人____（做法），已于____完成（正在推进），____（效果）。 |
| 每个方面的问题 | 本人工作中的一件具体事：时间、经过、本人做了什么或没做好什么、影响 | 在____工作中，本人____（具体表现），导致____（影响）。 |
| 反馈给本人的意见 | 组织反馈的意见原文 | 对“____”的意见，本人认真对照，问题确实存在，表现在____。 |
| 原因 | 每个问题当时是怎么想的、为什么这样做（本人的真实想法，大白话即可） | ____问题，根子在于本人____（当时的想法和做法）。 |
| 整改措施 | 每个问题打算做什么、什么时候完成、做到什么程度 | 针对____问题，本人将于____前____（具体动作），做到____（标准）。 |

提醒本人：
1. 写本人的事，不照抄班子材料，不写“事事亲力亲为”之类的变相表扬。
2. 每个问题至少一个事例；举不出事例的问题先不写。
3. 民主生活会个人发言提纲应当本人动手撰写（《若干规定》第九条第（四）项）；本提纲只帮助理清结构。个人有关事项的具体内容不要发给联网模型。
4. 填好后发来，可以帮助整理成稿。

## 二、研讨发言和心得体会（含思想汇报）

（一）提纲

题目按研讨主题，或用本人的主要体会作题目。

```text
【待补：题目】

学习了【待补：材料名称和篇目】，谈几点体会。

一、主要认识
（一）【待补：第一点认识，联系所学原文】
（二）【待补：第二点认识】

二、对照查找的差距
【待补：联系本人岗位的具体事】

三、下一步打算
【待补：具体、可检验的打算】
```

（二）填写指引

| 部分 | 需要本人提供的事实 |
|---|---|
| 学了什么 | 材料名称、篇目；印象最深的一两句原文（原样抄来，不凭记忆） |
| 主要认识 | 读到这句话本人想到了什么，大白话几句即可 |
| 差距 | 本人工作中与所学要求对不上的一件事 |
| 打算 | 下一步具体做什么、什么时候 |

思想汇报另按时间段写：这段时间学了什么、思想上有什么变化、工作学习和生活中怎么做的、还有哪些不足、今后怎么努力。入党积极分子、发展对象、预备党员的思想汇报要反映本人的真实想法：本人给了要点的，可以帮助整理语句；没有要点的，只出提纲和填写指引。

## 三、书记抓基层党建述职

（一）提纲

按本 skill“结构速查”中“书记抓基层党建述职”一行列出六个部分，标题按通知，每部分写【待补：……】，提示语按下表“需要本人提供的事实”填写；成效部分的数据只用本人提供的，问题部分写本人的责任。

（二）填写指引

| 部分 | 需要本人提供的事实 |
|---|---|
| 上年度问题整改 | 去年述职点评指出的问题、整改清单逐条完成情况 |
| 履职情况 | 本人主持研究党建工作的次数和议题；到联系点调研的次数、解决的具体问题；讲党课的题目和对象 |
| 成效 | 本单位党建工作的数据和事例（如支部建设、发展党员、软弱涣散党组织整顿），注明来源 |
| 问题 | 本人在抓党建中没做到位的 1～3 件具体事 |
| 措施 | 针对每个问题的做法、时限 |

区分两种材料：支部书记代表支委会向党员大会报告工作，写支部集体工作，按党建工作报告写；书记个人抓党建述职，写本人做了什么、本人的责任，不用支部成绩代替本人履职。

## 四、谈心谈话提纲和空白记录表

（一）提纲

```text
谈心谈话提纲

谈话双方：【待补：谈话人职务】与【待补：谈话对象职务】
时间地点：【待补】
谈话目的：【待补：会前听取意见、日常思想交流或提醒】

一、交流思想
【待补：本人近期的工作和思想情况，准备谈的两三点】

二、征求意见
【待补：请对方提意见的两三个具体问题，如“我分管的____工作，你觉得哪里还不到位”】

三、指出问题
【待补：准备向对方指出的问题，只写本人掌握的具体事实】

四、交换意见
【待补：对改进工作的想法】
```

（二）空白记录表

| 项目 | 内容（谈话后由谈话人如实填写） |
|---|---|
| 谈话时间、地点 | |
| 谈话人、谈话对象（职务） | |
| 对方谈到的主要情况 | |
| 对方提出的意见 | |
| 本人的回应和打算 | |
| 需要跟进的事项 | |

谈话记录由谈话人如实填写，本 skill 不代写；谈话后把笔记发来的，按会议记录整理的规则（只整理、不添加）帮助理顺。

## 五、说明原因的话

1. 对照检查、发言提纲：“对照检查要写本人的真实情况，您还没提供个人事例，我先给提纲和填写指引，补上后发我再成稿。”
2. 心得体会、研讨发言：“心得体会要写您自己的学习认识，我先给提纲和填写指引，您把学了什么、想到了什么用几句话告诉我，我帮您整理成文。”
3. 书记述职：“述职要写您本人做了什么，我先给提纲和要准备的事实清单，补上后再成稿。”
4. 谈心谈话记录：“谈话记录要如实反映谈话内容，我先给谈话提纲和记录表，谈完后把笔记发我，可以帮您整理。”
5. 替他人准备个人材料：“个人材料要反映本人的真实情况，我按您转述的事例整理，您推测的想法不写进去，请本人确认事例、补上认识后逐段审改定稿。”
