# 数据表述规范

> - 适用：各 gongwen skill 中数据的计算口径和文字写法。由 gongwen-data 维护，gongwen-report、gongwen-brief、gongwen-review 等引用。
> - 依据：GB/T 15835-2011（数字写法，见 `references/_shared/rules/gbt15835.md`）；《中华人民共和国民法典》第一千二百五十九条；国家统计局“统计知识”栏目的公开解释（网页日期为页面所示，内容以国家统计局网站原文为准）：《“百分数”与“百分点”》（2023-01-01，https://www.stats.gov.cn/zs/tjws/tjbk/202301/t20230101_1912934.html）；《“番”与“倍”》（2023-01-01，https://www.stats.gov.cn/zs/tjws/tjbk/202301/t20230101_1912930.html）；《同比与环比有何不同》（2025-07-17，https://www.stats.gov.cn/zs/tjws/tjbk/202301/t20230101_1912960.html）；《什么是经济增长贡献率和拉动点》（2025-07-16，https://www.stats.gov.cn/zs/tjws/tjbk/202301/t20230101_1912957.html）；《平均发展速度和平均增长速度》（2023-08-17，https://www.stats.gov.cn/zs/tjll/sjxl/202308/t20230817_1942110.html）。条目后括注出处；未括注的是本项目的写作约定。

## 一、基本要求

1. 数据只来自用户材料（`references/_shared/guardrails.md` 第二条）。材料中明确写着的数据直接引用，不标待核实。算出来的数要附算式，算式写进起草说明或计算底稿，正文不写算式，只写结果（误：“办结率1790÷1824=98.1%”；正：“办结率98.1%”）。
2. 每个对比写清三件事：时段（2026年1—9月）、基期（同比、环比、比上年、比年初）、口径（含不含线上、含不含下属单位）。说不清的标【待核实：说明】。
3. 同一指标全文用同一名称、同一单位、同一小数位数。
4. 先写本期数，再写变化：“出院5423人次，同比增长4.3%”。只写增速不写本期数，读者判断不了量级。
5. 时段不同的数不相加、不比较：1—10月实际数不能加全年预计数，9月当月数不能与1—9月累计数比。

## 二、增长与下降

| 要说的 | 写法 | 算式 | 例 |
|---|---|---|---|
| 增减量 | 增加（减少）X+单位 | 本期－基期 | 比上年同期增加223人次 |
| 增长速度 | 增长（下降）X% | （本期－基期）÷基期×100% | 同比增长4.3% |
| 发展水平 | 为（相当于）基期的X% | 本期÷基期×100% | 为上年同期的104.3% |

1. “增长X%”要扣除基数，“为基期的X%”不扣除：比过去增长45%，是由100到145；降低到原来的45%，是由100到45（国家统计局《“百分数”与“百分点”》）。
2. 同比是与上年同期比，环比是与相邻的上一期比；二者基期不同，不直接比较大小（国家统计局《同比与环比有何不同》）。
3. “同比增长”与“比上年同期增长”选一个，不叠用；“环比”只用于相邻两期，不写“环比去年”。
4. 下降写“下降X%”“减少X+单位”，不写“增长-X%”“负增长X%”。
5. 增速修约后为0的，写“与上年同期持平”。

## 三、百分比与百分点

1. 两个百分数相减，差用“个百分点”。例：第一产业比重由24.6%降至19.9%，下降4.7个百分点，不能说下降4.7%（国家统计局《“百分数”与“百分点”》）。
2. 用百分点的：比率、占比、比重的变化；增速本身的变化；完成率与时间进度的差距。增速变化可写“加快”“回落”。
3. 用百分数的：数量（人次、件、金额）的变化。
4. “个百分点”后面不再加“%”。

误：四级手术占比由21.7%升至24.4%，提高2.7%。
正：四级手术占比由21.7%升至24.4%，提高2.7个百分点。
误：营业收入增速比上年回落1.7%。
正：营业收入增速比上年回落1.7个百分点。
误：门诊人次同比增长2个百分点。
正：门诊人次同比增长2.0%。

## 四、倍数与番数

1. 倍数只用于增加，不用于减少。不写“减少一倍”“成本降低5倍”，按实际数改写为“下降X%”或“降至原来的X%（几分之几）”：由240万元降至40万元，写“下降83.3%”或“降至原来的六分之一”。原句没有实际数、看不出指哪种意思的，不推断，标【待核实：实际数】。
2. “是（为）基期的X倍”含基数，“增长X倍”指净增：由35到280，是原来的8倍，增长7倍，即增长700%。两种说法容易混，公文优先写“是……的X倍”或“增长X%”。
3. 番按几何级数计算：翻一番是原来的2倍，翻两番是4倍（增长300%），翻三番是8倍（国家统计局《“番”与“倍”》）。翻番数＝lg（报告期数÷基数）÷lg2。不足2倍的不说“翻番”；“翻了X倍”是错误说法。

## 五、占比、拉动、贡献率

1. 占比（比重）＝部分÷总体×100%。部分与总体同口径、同时段；各部分占比相加应为100%，修约造成的差异在表注说明。
2. 贡献率＝某部分增量÷总量增量×100%（国家统计局《什么是经济增长贡献率和拉动点》）。总量下降时贡献率含义相反，慎用，改写各部分增减额。
3. 拉动＝贡献率×总量增速，单位是百分点（同上）；等价算法为某部分增量÷总量基期数×100。写“拉动××增长X个百分点”，为负时写“拉低××增速X个百分点”。各部分拉动之和应等于总量增速，可用来验算。
4. 国家统计局按不变价计算 GDP 贡献率和拉动；单位内部指标按用户提供的口径计算，在起草说明中写明。

## 六、完成率与时间进度

1. 完成率＝实际完成数÷目标数×100%。超过100%的写“超额完成”，可同时写完成率。
2. 时间进度＝已过时间÷全期时间×100%，1—8月为66.7%。完成率与时间进度之差用百分点：完成年度目标的61.3%，慢于时间进度5.4个百分点。
3. 目标是“下降”类（如能耗下降7%、事故起数下降）的，不用上面的公式相除，分别写实际降幅和目标降幅。

## 七、平均数

1. 比率和平均数不能相加，也不能把各单位的比率简单平均。全院、全系统的比率用分子合计除以分母合计：全院平均住院日＝出院者占用总床日数÷出院人次。
2. 简单平均只用于各项分量相同的场合，写明平均的对象：“各科室平均”与“全院”不是一回事。
3. 年均增长速度用水平法（几何平均）：（期末数÷期初数）^（1÷年数）－1，不是各年增速的算术平均（国家统计局《平均发展速度和平均增长速度》）。期初、期末为0或负数时不计算。

## 八、约数与上下限

1. 约数用“约”“近”“左右”“多”“余”之一，不叠用，不写“约240人左右”（机检 NUM-011）。
2. “以上”“以下”“以内”“届满”包括本数，“不满”“超过”“以外”不包括本数（《民法典》第一千二百五十九条）。规范性条款需要明确时写“以上（含本数）”。
3. 用户给的是约数（“240多台”“大概两成”）的，正文照写约数并标【待核实：准确数】，不拿约数做精确计算。
4. 基数小（如由7例增至19例）的，增速容易放大，同时写增减量：增加12例，增长171.4%。

## 九、亏损、零和负数

1. 基期为0的不算增速，写“上年同期为0，本期为X”。
2. 基期或本期为负数（亏损）的不算增速，按情形写“扭亏为盈”“减亏X万元”“增亏X万元”“由盈转亏”，配增减额。
3. 正文写“亏损220万元”，不写“利润-220万元”；表格中可以用负号。

## 十、小数位、修约和单位

1. 小数位：百分比、百分点一般保留1位；以万元、亿元计的金额保留1～2位；同一指标全文一致。
2. 修约：本项目统一四舍五入，一次修约到位，不分步修约（5.446保留1位为5.4，不先修成5.45再修成5.5）。
3. 先算后修：用原始数计算，最后一步再修约；不用修约后的数接着算。分项修约后相加与合计差末位的，表注写“因四舍五入，分项之和与合计略有出入”。例外：百分点、完成率与时间进度之差，用正文中写出的两个百分数相减，让读者能直接对上。
4. 分节：正文中的数一般不分节（4738人次、158200元）；表格中位数多的可用千分撇或千分空，全文统一（GB/T 15835-2011 5.1.1）。
5. 大数用“万”“亿”作单位，与阿拉伯数字连用：4.3亿元，不写“4亿3千万元”（GB/T 15835-2011 5.3）。同一文件同一指标统一用万元或亿元。
6. 单位换算：1万元＝10000元，1亿元＝10000万元；1公顷＝10000平方米＝15亩；1吨＝1000千克；1千瓦时＝1度。换算过程写进计算底稿。
7. 不同量纲不换算、不相加：人与人次、户与人、件与次、床日与天。

## 十一、数据段落怎么写

1. 一段写一类指标（业务量、效率、质量、费用、财务），先总后分。
2. 一句话不超过3组数据；几个单位并列比较时，按同一顺序写本期、基期、增减。
3. 原因只写用户给出的。需要写原因而材料里没有的，标【待补：变化原因】，不写“主要得益于……”之类的推测。
4. 程度靠数字说明，少用“大幅”“显著”“明显”。用户或画像规定了标准的（如“增速超过14%称较快增长”）按标准写。
5. 排名、位次只写算得出的，并列的写并列。

误：9月全院业务量大幅增长，四级手术占比提高2.7%，主要得益于学科建设成效显著。
正：9月，全院出院5423人次，同比增长4.3%；四级手术占比24.4%，同比提高2.7个百分点。【待补：变化原因】

## 十二、常见错误正误对照

| 误 | 正 | 原因 |
|---|---|---|
| 网办率由36%提高到44%，提高8% | 提高8个百分点 | 百分数相减用百分点 |
| 比上年同期同比增长7% | 同比增长7.0% | 同比与“比上年同期”叠用 |
| 9月办件量环比去年下降 | 同比下降 | 环比只比相邻两期 |
| 增长-2.7%；负增长2.7% | 下降2.7% | 下降直接写下降 |
| 成本由240万元降至40万元，降低了5倍 | 下降83.3%；或降至原来的六分之一 | 倍数不用于减少；没有实际数的不推断，标【待核实】 |
| 由35增至280，增长了8倍 | 是原来的8倍，增长700% | “增长X倍”指净增 |
| 翻了7倍 | 是原来的8倍；或翻了三番（8倍时） | 番与倍不混用 |
| 由亏损220万元到盈利170万元，增长177.3% | 扭亏为盈，增加390万元 | 负基期不算增速 |
| 26个科室平均住院日相加除以26，得全院8.7天 | 全院平均住院日9.3天（50434÷5423） | 平均数不能简单平均 |
| 约240人左右 | 约240人；240人左右 | 约数不叠用 |
| 完成率比时间进度慢5.4% | 慢于时间进度5.4个百分点 | 两个百分数之差 |
| 1—10月实际数加11—12月预计数，写成“全年完成” | 分开写，预计数写“预计” | 实际与预计不相加 |
| 服务530人（另一材料为530人次） | 统一口径后再写，冲突的标【待核实】 | 人与人次不同 |

## 十三、可机检规则

供机检引擎扩充数据表述检查时使用。编号只在本文件内使用，`lint_rules.json` 的 ID 由脚本作者另定。已实现的相关规则：NUM-011（约数叠用）、NUM-012（比率变化用了百分数）。

1. **DE-01 负增长**（P1）：`负增长|增长\s*[-－]\s*\d`。建议改为“下降X%”。
2. **DE-02 倍数用于减少**（P1）：`(减少|下降|降低|缩小|压缩)了?\s*[\d一二两三四五六七八九十]+(\.\d+)?\s*倍`。
3. **DE-03 番与倍混用**（P1）：`翻了?\s*[\d一二两三四五六七八九十]+(\.\d+)?\s*倍`。
4. **DE-04 同比叠用**（P1）：`比(上年|去年)同期同比|同比(上年|去年)`。
5. **DE-05 环比误用于上年同期**（P1）：`环比(上年|去年)`。
6. **DE-06 增速变化用了百分数**（P1）：`(增速|增幅|增长率|增长速度)[^，。；\n]{0,10}?(提高|加快|回落|下降|上升|降低|放缓)了?\s*\d+(\.\d+)?\s*[%％]`。
7. **DE-07 百分点后带%**（P1）：`个百分点\s*[%％]|\d+(\.\d+)?\s*[%％]\s*个?百分点`。
8. **DE-08 数量变化用了百分点**（P2）：计数单位（人次、件、户、台、例、万元等）之后15字内出现“增长、增加、下降、减少X个百分点”，中间没有“率、占比、比重、比例、增速、增幅、指数”。
9. **DE-09 占比超过100%**（P2）：`占[^。；\n]{0,15}?[1-9]\d{2,}(\.\d+)?\s*[%％]`，“完成率”“为上年的”等不报。
10. **DE-10 约数与上下限叠用**（P2）：`(约|大约|近|将近)[^，。；\n]{0,8}?(以上|多|余)`。
