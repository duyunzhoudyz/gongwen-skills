# 单位类型画像：中小学

适用于公办中小学校（含中等职业学校），公办幼儿园可参照。

## 一、规则基线与参照依据

| 依据 | 适用方式 | 要点 |
|---|---|---|
| 中办《关于建立中小学校党组织领导的校长负责制的意见（试行）》（2022 年 1 月） | 直接适用 | 适用于具有独立法人资格且设立党的基层委员会、总支部委员会或支部委员会的公办中小学校（含中职）；公办幼儿园参照 |
| 《学校教职工代表大会规定》（教育部令第 32 号） | 直接适用 | 教职工 80 人以上建立教代会，不足 80 人建立教职工大会；每学年至少召开一次 |
| 中办、国办《关于减轻中小学教师负担进一步营造教育教学良好环境的若干意见》（2019 年 12 月） | 直接适用 | 统筹规范督查检查评比考核和社会事务进校园 |
| 教育部办公厅《关于进一步减轻中小学教师非教育教学负担若干措施的通知》（2025 年） | 直接适用 | 进校园"白名单"、督查检查考核清单、借调管理等量化要求 |
| 中办、国办"双减"意见（2021 年 7 月） | 直接适用（义务教育阶段） | 作业管理、课后服务、校外培训治理 |
| 上级教育行政部门的公文要求、学校章程 | 用户提供时优先 | 报送格式、编号、签发 |
| 《党政机关公文处理工作条例》、GB/T 9704-2012 | 参照 | 对上正式行文参照执行 |

## 二、发文体系

1. **以学校名义行文为主**，多数学校不设党政两套文号；部分学校有"X校发〔2026〕N号"之类编号，以教育局和学校规定为准。
2. **对上**：向教育行政部门请示、报告，加盖学校公章，按教育局要求报送；向街道、卫健、公安等不相隶属单位商洽工作用函或情况说明。
3. **对内**：校内通知、校务会议和党组织会议纪要、处室（教务、德育、总务等）工作安排、年级组和教研组计划。
4. **对家长**：致家长的一封信、告知书、安全提示、家长会讲话、回执。
5. **内部呈批**：教师、处室向学校申请经费、活动、外出等，用学校内部的申请单或呈批单，不编文号。

## 三、常用文种与典型材料清单

| 频次 | 典型材料 |
|---|---|
| 几乎每周 | 校内通知、安全提示、校园新闻稿、会议纪要 |
| 每学期 | 学校工作计划与总结；教学、德育、教研、安全工作计划与总结；班主任计划与总结；家长会讲话；学生评语；假期致家长的一封信 |
| 每年 | 学校年度工作报告（教代会）；党建工作报告；教职工年度考核；述职 |
| 按周期 | 学校发展规划（一般 3–5 年）；督导评估自评报告；县域义务教育优质均衡发展督导材料；巡察整改 |
| 事件触发 | 安全事件情况报告；舆情情况说明；上级专项检查自查报告 |

常用法定文种约 5 种：通知、请示、报告、函、纪要。

## 四、决策程序与行文特点

1. **领导体制**：党组织领导的校长负责制。学校党组织全面领导学校工作，履行把方向、管大局、作决策、抓班子、带队伍、保落实的领导职责。
2. **党组织会议**：讨论决定"三重一大"事项、学校章程等基本管理制度、内部组织机构设置及负责人人选、干部任免等。
3. **校长办公会议（校务会议）**：校长召集并主持，在广泛听取意见后作出决定；校长按照党组织有关决议，全面负责教育教学和行政管理。
4. **会前沟通**：重要议题上会前，书记和校长先沟通；议事规则按管理权限报教育主管部门审查和备案。
5. **书记校长**：设党委、党总支的学校，书记和校长一般分设；设党支部的学校一般由一人担任，同时设一名专职副书记。
6. **教代会**：审议学校发展规划和涉及教职工切身利益的事项。

## 五、术语表

| 术语 | 解释 |
|---|---|
| 党组织领导的校长负责制 | 中小学校领导体制，见第四节 |
| 双减 | 减轻义务教育阶段学生作业负担和校外培训负担 |
| 课后服务 | 上课日完成国家规定课程后由学校提供的服务，结束时间与当地正常下班时间衔接 |
| 五项管理 | 作业、睡眠、手机、读物、体质管理 |
| 进校园白名单 | 社会事务进校园实行清单管理；省级白名单一般不超过 10 项，每校每学期各类进校园活动不超过 6 次 |
| 督导 | 教育督导和责任督学挂牌督导；每校每年接受县级及以上教育综合督导一般不超过 1 项 |
| 优质均衡 | 县域义务教育优质均衡发展督导评估，教师减负已纳入评估内容 |
| 新课标 | 义务教育课程方案和课程标准（2022 年版） |
| 跨学科主题学习 | 新课标提出的课程组织方式 |
| 综合素质评价 | 对学生思想品德、学业水平、身心健康、艺术素养、社会实践等方面的评价 |
| 家校社协同育人 | 学校、家庭、社会共同育人的机制 |
| 控辍保学 | 防止义务教育阶段学生辍学的工作 |
| 教研组、备课组、年级组 | 学校教学管理的基层单元 |

## 六、红线与禁忌

1. 学生隐私：姓名与成绩、家庭经济困难、心理健康、特殊教育需求、违纪处分等信息不得超范围公开；宣传稿使用学生姓名和照片前确认已获监护人同意。
2. 义务教育学校考试结果不排名、不公布，不得在家长群传播（教育部办公厅 2021 年考试管理通知）；材料中不写学生成绩排名。
3. 面向家长的通知不得布置或变相布置家庭作业，不得要求家长检查、批改作业。
4. 未经白名单安排进校园活动；给教师摊派与教育教学无关的任务。
5. 涉及收费的通知必须有明确依据，依据由用户提供。
6. 学生评语千人一面，或使用贬损、标签化语言。

## 七、年度写作节点

| 时间 | 节点与材料 |
|---|---|
| 2–3 月 | 春季开学：学期工作计划、开学安全检查、开学典礼讲话；教代会多在学期初 |
| 4–5 月 | 期中质量分析；防灾减灾日（5 月 12 日）疏散演练 |
| 6 月 | 中考、高考保障材料；期末工作安排 |
| 7 月 | 学期总结；暑假致家长的一封信（防溺水、交通安全） |
| 9 月 | 秋季开学：学期计划、开学典礼讲话；教师节（9 月 10 日）表彰 |
| 10–11 月 | 期中质量分析；家长会讲话；消防演练 |
| 12 月–次年 1 月 | 期末工作；学年考核；学期总结；寒假致家长的一封信；学生评语 |
| 按周期 | 督导自评；学校发展规划 |

## 八、版式差异

1. 对上正式行文参照 GB/T 9704-2012，按教育局要求编排。
2. 校内通知可简化，保留标题、正文、落款、日期。
3. 致家长的一封信用信函体，称呼为"尊敬的家长"，落款为学校名称和日期，需要回执的附回执栏。
4. 学生评语用第二人称，篇幅按学校统一要求。

## 九、文风特点

1. 面向家长：通俗、亲切、具体，写清时间、事项、需要家长配合的内容。
2. 对上材料：数据准确，与教育事业统计口径一致。
3. 计划总结：按德育、教学、安全、后勤、家校协同等板块组织，每项写具体做法和数据。
4. 评语因人而异，先肯定具体表现，再提一条可操作的建议。

## 十、对各 skill 的提示

| skill | 提示 |
|---|---|
| gongwen-report | 学校和班主任计划总结按德育、教学、安全、家校协同组织；学生人数、活动次数、质量数据只用用户提供的 |
| gongwen-speech | 家长会讲话具体到本班本年级，不承诺升学结果；开学典礼讲话面向学生，口语化 |
| gongwen-review | 额外检查：学生隐私和成绩排名；"双减"相关表述；收费依据；是否给家长布置作业 |
| gongwen-brief | 校园新闻稿核对学生姓名、照片使用是否已获同意 |
| gongwen-draft | 学校向教育局用请示或报告；与街道、卫健等单位商洽用函 |
| gongwen-k12（行业包） | 学生评语由行业包处理；未安装时，gongwen-report 只出评语框架，用户提供每名学生的具体表现后再写 |
