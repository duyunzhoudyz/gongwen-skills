# 公文图表

公文里的图要能黑白打印、看清数、查到出处。

## 一、选图

| 要说明的 | 用 | 不用 |
|---|---|---|
| 各单位、各科室比大小 | 柱状图；类别超过12个或名称长的用条形图，按数值从大到小排 | 饼图、折线图 |
| 一个指标按月、按年的变化 | 折线图；不超过12期也可用柱状图 | 按数值排序 |
| 今年与去年同期逐月对比 | 两条折线（实线和虚线） | 双坐标轴 |
| 总量由哪几部分构成 | 饼图（不超过6类，小类并为“其他”），或堆积柱状图 | 部分相加不等于总体的数据 |
| 突出本单位在全市的位置 | 条形图，本单位深灰、其他浅灰 | 彩色 |

比率、平均数不画饼图和堆积图；不同单位的指标（户和天、万元和%）分开出图。

## 二、图上必须有的

1. 图题写清时段和指标，如“2026年1—6月各街道（乡镇）新登记经营主体”；只用前N项的，图题或图注写“前10位”。
2. 纵轴标题写“单位：户”；图下写“数据来源：登记注册系统”，没给的写【待补：数据来源】并列入待补。
3. 柱、点上标数值，免去对刻度估读。
4. 纵轴从0开始；有负数的画在0以下，不截断纵轴。
5. 合计、小计、“其中”和平均行不入图；空值留空不画成0。

## 三、黑白灰

1. 系列用深灰、中灰、浅灰区分，柱子加黑色细边框；折线用实线、虚线、点线和不同标记区分。
2. 不用彩虹色、渐变、阴影、三维和背景图；网格线用浅灰细线。
3. 用户要彩色（如投影用）的，在 Excel 中自行改色；交付稿仍按黑白灰。
4. 只在本机的 Excel、WPS 或 `scripts/chart_tool.py` 出图，不用在线图表网站和远程渲染的图表插件。

## 四、不能运行脚本时：图表规格卡和手工步骤

起草说明之后先给“附：图表规格卡”，再附操作步骤。

```text
图表规格卡
图1　2026年1—6月新登记经营主体前10位街道（乡镇）
类型：条形图，从大到小排列
分类：街道（乡镇）（10个）
数值：新登记经营主体（单位：户）
数据：东湖街道612，滨江街道547，……
数据来源：登记注册系统
样式：深灰色条，黑色细边框，标数据标签，纵轴从0开始
```

Excel（2016及以上）操作步骤：
1. 把规格卡数据粘贴到两列（分类、数值），首行写列名。
2. 选中数据，“插入”→“图表”，选“簇状条形图”（或柱形图、折线图、饼图）。
3. 点图表右上角“＋”：勾选“数据标签”；只有一个系列时取消“图例”；勾选“坐标轴标题”，纵轴标题改为“单位：户”。
4. 双击柱子→“填充”选深灰纯色，“边框”选黑色实线。
5. 双击数值轴→“坐标轴选项”→“最小值”填0；条形图要第一项在最上面，双击分类轴勾选“逆序类别”。
6. 图表标题改为图题；图下方单元格写“数据来源：……”。

WPS 表格：步骤相同，菜单为“插入”→“全部图表”；数据标签在“图表元素”勾选；“逆序类别”在“设置坐标轴格式”→“坐标轴选项”。

放进 Word：在 Excel 复制图表，在 Word “选择性粘贴”为增强型图元文件；排进国标公文的交 gongwen-format。
