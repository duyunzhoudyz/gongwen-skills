# 数据整理与图表（gongwen-data）

> 版本 1.0.0　成熟度：Beta（测试版）

写总结、汇报、分析报告之前，常要先把一堆报表理清楚：下面报上来的表合计对不上，有的填元有的填万元，同比环比要一个个算，"提高了3%"还是"提高了3个百分点"拿不准，最后还要配几张能黑白打印的图。这个 skill 专做这些事。每个结果都附算式，你能逐个复核；表里没有的数标【待补】，口径对不上的列出来请你确认，不替你凑数。

## 能做什么

| 功能 | 说明 |
|---|---|
| 报表体检 | 查空值和"—""/"之类的占位符、存成文字的数字、合并单元格、单位不一致、时段不一致、重复行；把表里的合计、小计逐项相加对账 |
| 多表合并 | 汇总科室、下级单位、子公司报来的同类报表：自动对齐表头、换算单位并记录，时段不同的表单列出来不计入合计，比率不相加 |
| 指标计算 | 增减量、同比、环比、增速、百分点、占比、拉动、贡献率、完成率和时间进度、倍数、年均增速、平均值，以及台账明细按类别计数，每个结果附算式 |
| 数据转文字 | 把结果写成可以直接放进公文的句子，如"出院6171人次，同比增长5.0%；四级手术占比26.6%，同比提高2.5个百分点" |
| 公文图表 | 生成 Excel 原生图表：黑白灰配色、标数据、纵轴从0开始，图上有单位、图下有数据来源，能在 Excel、WPS 里直接改 |

## 可以这样说

1. "30个科室的9月指标都交上来了，帮我合并一下，算算全院的同比环比。"
2. "这张表的合计好像不对，帮我查查哪儿有问题。"
3. "网办率从62%到71%，这个是提高了9%还是9个百分点？帮我写成一句话。"
4. "三家子公司的经营快报，有的按元填有的按万元填，帮我统一一下再汇总。"
5. "把今年1到9月的办件量做个折线图，要能黑白打印的，跟去年同期放一起比。"

## 输入

- 必需：数据。Excel（.xlsx）、CSV 文件，或直接粘贴的表格、口头说的数字都可以。旧版 .xls 请先另存为 .xlsx。
- 最好说明：统计时段、和什么时候比（同比还是环比）、计量单位、数据从哪个系统导出。没说的会从表头和表注里找，找不到的按默认处理并写明。
- 可选：应报单位名单（用来查谁没交）、单位画像 `.gongwen/单位画像.md`。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 数据段落，纯文本，可直接粘进总结、汇报 |
| `起草说明.md` | 所作假设、待补和待核实事项、用了哪些公式、保密提示 |
| `计算底稿.md` | 每个数的算式、结果、正文写法和来源，便于复核 |
| `体检报告.md` | 表格问题清单，按 P0、P1、P2 分级 |
| `汇总表.xlsx` | 多表合并结果，含明细、问题清单、单位换算记录 |
| `图表-*.xlsx` | Excel 原生图表；装了 matplotlib 时可另出 PNG |

在网页大模型里使用提示词版时，依次输出数据段落和起草说明，计算底稿、体检问题清单附在起草说明后面。网页环境不能生成文件，图表会给出"图表规格卡"和 Excel、WPS 的操作步骤。

## 注意事项

1. **保密**：请勿输入涉密信息和内部敏感信息；材料涉密的，请使用单位内网部署的模型。表格带"秘密★""内部资料""不得外传"等标注的，脚本会停止处理，等你说明情况后再继续。明细表中有患者、学生、居民的姓名和证件号的，请先脱敏，汇总分析只需要统计数。
2. **数据不出本机**：脚本只在你的电脑上运行，不联网，不调用在线图表或远程渲染服务。请不要把内部数据粘贴到在线图表网站。
3. **不编造**：表里没有的数标【待补】，约数（"30多"）标【待核实】，不拿约数做精确计算；变化的原因只写你提供的。
4. **口径冲突不合并**：时段不同、人和人次混用、元和件这种不能换算的，会列出来请你确认，不会悄悄加在一起。比率和平均数用分子分母重新算，不做简单平均。
5. **计算请复核**：有 Python 时用脚本精确计算；网页版是模型手算，会写出算式和验算过程，数据多时会给你 Excel 公式在本机算。
6. **依赖**：脚本需要 Python 3.9 及以上和 openpyxl（`pip install openpyxl`）；出 PNG 另需 matplotlib（可选）。

## 与其他 skill 的分工

| 需求 | 用哪个 |
|---|---|
| 写整篇总结、汇报材料、调研报告 | gongwen-report |
| 医疗质量分析报告、经营分析报告等行业专用文书全文 | 对应行业包（gongwen-hospital、gongwen-soe 等） |
| 政务信息、简报 | gongwen-brief |
| 稿子写好了，核一下数字和百分点 | gongwen-review |
| 整改台账、任务分解表、督办清单转 Excel | gongwen-rectify、gongwen-implement、gongwen-minutes |
| 排成国标格式的 Word | gongwen-format |

常见用法：gongwen-data 体检、合并、算数、出图 → gongwen-report 写成总结或汇报 → gongwen-review 核稿 → gongwen-format 出 docx。

## 成熟度

Beta。体检、合并、计算、转文字、出图五项功能和脚本单元测试已完成，评测用例见 `evals/`。已知局限：
- 表头识别靠规则，特别复杂的报表（三级以上表头、一张工作表里并排几张表）可能识别不准，需要用 `--header-row` 指定表头行，或先把表整理规整；
- 网页版没有脚本，计算靠模型手算，数据量大时请按给出的 Excel 公式在本机计算；
- PNG 图表依赖本机中文字体，没有中文字体时请用 Excel 图表。
