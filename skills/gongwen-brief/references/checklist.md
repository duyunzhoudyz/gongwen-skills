# 人工检查清单与审稿一页纸

不能运行脚本时，按第一部分逐项人工检查，在起草说明“所作假设”中写“未运行机检，已按人工清单检查”。审稿模式下评估用户拿来的信息、新闻稿，按第二部分输出。

## 一、人工检查清单

括号内为对应的机检规则。

### （一）事实（BRF-003、004，fact_diff）

- [ ] 正文每个数字都能在素材台账或原材料找到，数值、单位、口径一致。
- [ ] 引号内的原话、名称、提法都能在材料中逐字找到；没有拼接、润色；说话人与材料一致、身份已交代；短引语不是从材料的转述中截取的；荣誉称号有出处。
- [ ] 没有材料以外的成效、排名、获奖、群众评价；计划写“将”“拟”，试点写“试点”。
- [ ] 限定条件（时段、范围、口径、基期）都保留。

### （二）标题和导语（BRF-002、005、006、016）

- [ ] 标题写出主体和做法，有成效数据的写入标题；没有“多措并举”“扎实推进”“取得明显成效”一类空词。
- [ ] 标题中的数字概括与正文分项条数一致：数一数正文的“一、”“（一）”“一是”或分段做法。
- [ ] 导语第一句是结论，有时间；没有“为深入贯彻……”“随着……”开头。

### （三）篇幅（BRF-001）

- [ ] 正文字数（不含标题、署名、报头报尾，【待补】不计入）在 SKILL.md 速查表或用户、画像要求的范围内；用户指定了字数而素材撑不起的，已在回复第一段说明差距并附补料清单，板块齐全，没有注水。

### （四）宣传用语和语体（BRF-007～011）

- [ ] 没有无依据的“领先”“首创”“第一”“唯一”“填补空白”“零投诉”“走在全国前列”。
- [ ] 医疗语境中没有“治愈率”“根治”“无副作用”等疗效保证（“根治欠薪”一类工作提法、“胃癌根治术”一类手术名称不算）。
- [ ] 没有宣传升学率、“状元”、高分考生（批评“片面追求升学率”的不算）。
- [ ] 标题和正文没有“震惊”“刚刚”“重磅”和连续感叹号；没有网络流行语、自媒体称呼、emoji；引语之外感叹号最多一处。

### （五）简报格式（BRF-012～014）

- [ ] 报头（简报名称、期号、编印单位、印发日期）和报尾（报、送、发）齐全，没给的标了【待补】；每篇标题的数字概括与本篇条数一致。
- [ ] 一期中各篇数据口径分篇对应，没有混用。

### （六）对外和保密（BRF-015，机检 privacy）

- [ ] 对外稿已按 `references/external-check.md` 第二部分逐项核对，起草说明附了核对清单。
- [ ] 照片、视频的授权已在起草说明中提示；未成年人已提示监护人同意。
- [ ] 正文没有身份证号、手机号（工作电话除外）、住址、病案号、学号、真实姓名加性别年龄的组合。
- [ ] 没有未公开的经营数据、人事安排、调查结论。

### （七）通用格式（gongwen_lint）

- [ ] 正文没有 Markdown 符号、免责声明、AI 自述、引导语；层次序数不跳级；中文标点全角；数值范围写全单位（“15%～30%”）。
- [ ] 没有“值得注意的是”“不是……而是……”、提示性冒号和成串破折号（副标题破折号除外）。
- [ ] 【待补】【待核实】全部汇总在起草说明里，起草说明编号连续。

## 二、审稿模式一页纸

用户拿来一篇写好的信息、新闻稿、推文，问“能不能报”“能不能发”“帮我看看”时，不重写全文，按以下格式输出。需要逐字逐句核稿（标点、格式、提法八关）的，建议转 gongwen-review。

```text
一、总体判断
（一句话：可以报送／修改后报送／建议换角度重写，以及最主要的原因）

二、采用要素评估
1. 标题：是否写出主体、做法、效果；数字概括与条数是否一致。
2. 导语：第一句是不是结论；有没有时间。
3. 数据：有几处数据，是否都有来源；有没有空泛评价代替数据。
4. 篇幅：约多少字，是否在要求范围内。
5. 时效和新意：事情发生在什么时候；做法新在哪里。
6. 对外风险（对外稿）：无依据评价、疗效保证、个人信息、照片授权、未公开信息。

三、问题清单（按 P0、P1、P2 排序）
| 级别 | 位置 | 原文 | 问题（依据） | 修改建议 |
|---|---|---|---|---|

四、关键句改法（最多 3 处，通常是标题和导语）
原：……
改：……（改法中的事实只来自原稿，原稿没有的标【待补】）
```

级别：P0 为编造或无出处的数据和引语、泄露个人信息或未公开信息、疗效保证；P1 为标题空泛、导语铺垫、标题数字与条数不符、无依据的最高级说法、篇幅明显超出；P2 为需要作者判断的措辞和结构问题。
