## 一、总览

## 二、党政机关

1. 政务信息选题贴近上级关注点，关注点只来自用户提供的约稿通知、领导批示、上级部署文件。
2. 信息专报（专门报送领导参阅的信息）篇幅更紧，问题和建议写透，用户没有说明格式的，按问题建议类写。
3. 会议新闻写会议部署了什么；领导姓名、职务和排序由用户提供并确认；讲话内容只用审定稿或会议通稿。
4. 提法按严谨模式核对原文；对外稿涉及政策的，只转述用户提供的政策原文。

## 三、基层

1. 与行业包 gongwen-grassroots 的分工：乡镇（街道）、村（社区）报上级党委、政府信息部门的政务信息（动态、经验、问题建议、约稿专报），已安装 grassroots 的交它，选题和篇幅按它的约定；未安装的由本 skill 写。这类单位的紧急信息、简报、新闻稿、推文，以及县（区）直部门报本部门工作的信息，由本 skill 写，篇幅按本 skill 约定（信息 500～800 字，动态类可以更短）。两边篇幅都是工具约定，上级信息部门有要求的从其要求。
2. 本 skill 写基层政务信息时，按被采用情况计分排名的，围绕“上级想知道的”选题，选题依据只来自用户提供的约稿要求。
3. 数据与工作台账一致；不把拍照留痕、学习笔记、点赞转发量写成成效（减负规定第8条、第14条）。
4. 同一事项不换个标题重复报送（工具约定，参照减负规定第12条“同类材料最多报一次”的精神；该条约束的是上级向基层要材料）。
5. 迎检期间的简报只写已完成的工作和台账能佐证的数据，不为迎检“美化”。

## 四、社区

1. 社区信息稿篇幅短，一般 300～500 字（工具约定），用平实的话写清做了什么、多少居民受益。
2. 出现居民姓名、照片的，提醒用户确认已取得本人同意；低保、救助、残疾、独居老人等情况不写到能识别个人的程度。
3. 不写超出社区职权的承诺（如“保证解决”“全部免费”），服务内容和条件照用户材料写。
4. 社区公众号面向居民，服务告知类写清时间、地点、条件、联系电话（工作电话）。

## 五、公立医院

1. 新闻稿、推文不写疗效保证：“治愈率”“有效率”“根治”“无副作用”“最先进”一律不写（`references/_shared/profiles/units/yiyuan.md`）；“胃癌根治术”“根治性切除”等手术名称照材料写。
2. “首例”“首次开展”写明范围（本院、本市），并须有用户提供的依据；没有的标【待核实：认定依据】。
3. 患者隐私：不出现姓名、病案号、住院号、床号；患者故事须本人或家属同意。
4. 医疗技术名称、指标名称照用户材料写，不自行解释疗效；面向公众的推文对专业术语加一句通俗解释。
5. 报卫生健康主管部门的信息，数据口径与院内统计一致，写明统计时段。

## 六、高校

1. 学校新闻稿一般由学院供稿、新闻中心审核发布；学院供稿按学校新闻中心的格式要求，用户没给的按新闻稿通行写法。
2. 学生姓名、学号、成绩、资助、处分、心理健康信息不对外；获奖学生姓名对外发布前确认本人同意。
3. 科研成果报道：论文期刊名称、作者和单位排序、项目名称和级别只用用户材料；不写“国际领先”等无依据评价。
4. 意识形态、思政相关表述按严谨模式，以用户提供的原文为准。
5. 迎评、评估期间的工作简报，数据与学校自评报告和状态数据库口径一致，冲突的标【待核实】。

## 七、中小学

1. 校园新闻稿、推文不宣传升学率、“状元”、高分考生，不公布学生成绩和排名（`references/external-check.md` 第四部分）。
2. 学生照片、姓名使用前提醒学校确认已取得监护人同意；不满十四周岁的学生按敏感个人信息对待。
3. 写活动时，学生的表现只写材料中有的；不替学生编感言，不替家长编评价。
4. 报教育局的信息，数据与教育事业统计口径一致。

## 八、国有企业

1. 未公开的财务数据、投标报价、客户信息、技术参数不进对外稿；上市公司未披露的重大信息不得先在新闻稿、推文中出现（`references/_shared/profiles/units/guoqi.md`）。
2. 不写无依据的“行业第一”“国内领先”“世界一流”；有依据的写明出处（排名机构、年份）。
3. 安全生产相关信息如实写，不淡化、不迟报；事故信息只写已核实的，原因按 `references/types/xinxi.md` 第六部分第 3 条处理，不推测。
4. 报上级集团、国资监管机构的信息，经营指标与财务快报口径一致，写明统计时段。
5. 党建与经营融合的经验材料交行业包 gongwen-soe；本 skill 只写这类工作的短信息和新闻稿。
