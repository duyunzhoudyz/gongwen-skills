# 单位官方公众号推文

医院、学校、机关、国企、社区等单位官方账号上发布的推文。它代表单位对外说话，语言可以比公文通俗、生动，但不写成自媒体腔。推文属于对外发布，一律叠加严谨模式，发布前按 `references/external-check.md` 核对。

> 依据：《国务院办公厅关于推进政务新媒体健康有序发展的意见》（国办发〔2018〕123号）要求运用生动活泼、通俗易懂的语言（三、（一）），严格内容发布审核制度，坚持分级分类审核、先审后发，严把政治关、法律关、政策关、保密关、文字关（四、（二））。医院、学校、国企的账号不一定属于政务新媒体，本 skill 按同样标准起草。

## 一、推文的四种常见类型

| 类型 | 例子 | 写法要点 |
|---|---|---|
| 活动报道 | 义诊、开学典礼、志愿服务、运动会 | 按新闻稿写（`references/types/xinwengao.md`），可以加材料中有的现场细节和照片说明 |
| 服务告知 | 门诊时间调整、报名须知、办事指南、停水通知 | 读者要办事，按"谁、什么时间、在哪里、怎么办、找谁"排，条件写在用得着的位置 |
| 工作成效 | 一项改革、一项服务的成果 | 用一两个具体事例加数据讲清变化，事例只来自材料 |
| 人物 | 先进典型、岗位故事 | 事迹只来自用户提供的事迹材料；细节、心理活动、对话不编；发布前请本人和所在部门确认 |

## 二、标题

1. 写清是什么事、和读者有什么关系。服务告知类把关键信息放进标题，如"10月20日起，门诊午间不停诊"。
2. 可以比公文标题活泼，可以用设问，但要有实在内容。
3. 不做标题党：不用"震惊""刚刚""速看""必看""紧急扩散"，不用连续感叹号，不用"太……了"式感叹。
4. 不夸大：不用"史上最""全网最"，不写无依据的"首创""领先"。

正误：
- 误：重磅！！我院这项服务太贴心了，赶紧收藏！
- 正：10月20日起，某医院门诊中午不停诊
- 误：家人们，咱们社区的助餐点开张啦～
- 正：社区助餐点开门了　60岁以上老人每餐优惠【待补：金额】元

摘要（导读）一句话，写清事和读者的关系，字数按平台限制。

## 三、第一屏

读者在第一屏决定是否往下看。第一屏写清三件事：
1. 什么事：时间、主体、事件；
2. 和读者什么关系：影响谁、带来什么变化；
3. 读者要做什么（服务告知类）：在什么时间、去哪里、带什么。

不用"随着……的不断发展""在这个金秋送爽的季节"之类的开头。

## 四、正文结构

1. 段落短：手机上一段不超过 4 行（约 100 字），一段一个意思。
2. 可以用小标题分段，小标题写成短句，说清这一段讲什么；层次序号按 一、（一）1. 使用，或只用小标题。
3. 服务告知类的关键要素（时间、地点、条件、电话）逐项写清，不藏在长段落里；条件、限制写在相关事项旁边，不集中放到文末小字。
4. 篇幅一般 800～1500 字（工具约定）；服务告知类越短越好，写清即止。
5. 专业术语、内部简称第一次出现时用一句话解释，如"日间手术（当天入院、当天手术、当天或次日出院）"。
6. 政策、制度类内容只转述用户提供的原文，不扩大、不缩小适用范围；处罚、责任、条件照原文的程度写。

## 五、语体：通俗不等于自媒体腔

| 情形 | 自媒体腔（不用） | 通俗规范（可用） |
|---|---|---|
| 称呼读者 | 家人们、宝子们、集美们、亲们 | 各位居民、各位家长、患者朋友 |
| 表达程度 | 绝绝子、yyds、拉满、天花板、炸裂 | 写具体：等候时间由40分钟缩短到15分钟 |
| 感叹 | 太贴心了！！！、哭了！ | 陈述事实；引语之外全文最多一个感叹号，只用于邀请、提示类结尾句（如"欢迎各位居民前来就餐！"） |
| 网络流行语 | 安排上了、冲鸭、码住、种草、干货满满 | 已经开通、欢迎参加、请收藏备用 |
| 语气词 | 啦～、哦～、呢～连用 | 正常书面语，个别句子可以口语化 |
| emoji、颜文字 | 正文夹表情符号 | 不用（正文干净，`references/_shared/guardrails.md` 第三条） |

可以用的通俗写法：短句；"您"；设问引出服务内容；把公文用语换成日常说法（"门诊时间调整"不写成"门诊服务时间优化提升"）。

## 六、配图和视频

1. 正文中需要放图的位置，写【待补：配图，内容为……，须确认授权】，起草说明列图片清单。
2. 照片、视频中能认出的群众、患者、学生、职工，发布前确认已取得本人同意；不满十四周岁的学生，取得监护人同意（`references/external-check.md` 第三部分）。
3. 患者照片避开面部和病历、床头卡、腕带等能识别身份的信息；学生照片不配姓名加班级加成绩的说明。
4. 不用来源不明的网络图片；用他人作品的，确认版权或授权。

## 七、结尾

1. 服务告知类结尾写咨询电话（工作电话）、办理地点或下一步安排。
2. 活动报道、工作成效类停在最后一个事实上，或用一句话说明后续安排。
3. 不写"点赞、在看、转发朋友圈"之类的诱导语（平台规则另有要求的从其规定），不写"让我们一起……"式空泛号召。

## 八、常见毛病

1. 标题党、网络流行语，账号像营销号；
2. 第一屏全是铺垫，读者看到第三段才知道发生了什么；
3. 服务告知类关键要素缺失，读者还得打电话问；
4. 人物稿编细节、编对话、编心理活动；
5. 照片未经同意使用，或学生、患者信息暴露；
6. 医院推文出现疗效保证，学校推文宣传升学率和"状元"，国企推文提前透露未公开的经营数据。
