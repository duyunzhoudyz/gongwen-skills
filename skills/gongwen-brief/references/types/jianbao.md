# 工作简报

按期编号、定期或不定期编发的内部刊物，用来向上级报告、向平级和下级通报工作情况。一期可以只有一篇（专题简报），也可以有几篇（综合简报）；会议期间编发的叫会议简报。

> 说明：简报没有国家标准格式。本文件的报头、报尾写法是机关常见做法，各单位样式不同，以本单位已有简报和单位画像为准。用户给了往期简报的，照往期的报头、栏目和报送范围写。
>
> 提供往期简报作格式参考时，请用户先删去"内部资料"等标注和各篇正文，只保留报头、报尾样式；也可以直接描述报头格式。带"内部资料"等标注发来的，按开工检查第 1 条停止处理。

## 一、三种简报

| 类型 | 一期的内容 | 写法要点 |
|---|---|---|
| 工作简报（综合） | 2～5 篇信息，可分栏目（如"工作动态""基层经验""问题反映"） | 每篇有自己的标题，各篇按信息写法（`references/types/xinxi.md`）；不同单位、不同时段、不同口径的数字分篇对应，不混用 |
| 专题简报 | 围绕一项专项工作，一期一篇或几篇 | 写本期这一阶段的新进展，不重复上一期已报的内容 |
| 会议简报 | 会议进展、讨论情况、会议议定事项 | 讨论发言按"代表认为""与会人员提出"归纳，发言内容只来自会议记录，不添加；议定事项写法与纪要衔接，正式纪要交 gongwen-minutes |

## 二、报头

报头在首页上部，与正文之间用一条分隔线隔开，常见内容依次为：

1. 简报名称：如"某局工作简报""迎评工作简报"，用本单位已有名称；
2. 期号：写"第×期"，按本单位顺序连续编号，可加"（总第×期）"；增刊写"增刊第×期"；用户没给期号的写【待补：期号】；
3. 编印单位和印发日期：同一行，左写"某某办公室编"，右写日期（如"2026年10月20日"），日期用阿拉伯数字；没给日期的写【待补：印发日期】；
4. 本单位要求标注的其他项目（如"内部资料"），由用户按本单位规定在定稿时自行加注，本 skill 不在稿中添加。用户的材料本身带有"内部资料""秘密"等标注的，按开工检查第 1 条停止处理。

## 三、正文

1. 每篇一个标题，标题写法同政务信息：主体、做法、效果；可以用栏目名统领几篇。
2. 综合简报的篇目顺序：按用户指定的栏目；没有指定的，按"领导关注的重点工作、工作动态、基层经验、问题反映"排。
3. 每篇一般 500～800 字，全期一般不超过 3000 字（工具约定）。
4. 编者按、按语：表达编发单位对本期内容的看法和要求，只在用户要求或用户提供了领导批示、编发意图时写，一般不超过 150 字，不加入正文没有的事实和评价。没有依据的不写，也不用"编者按：本期内容很有借鉴意义"之类的空话占位。
5. 转载下级单位报来的信息，在标题下或文末注明来源单位（如"（某街道供稿）"），不改变原意；数据有冲突的标【待核实】，不替下级"统一"数字。

## 四、报尾

报尾在末页下部，与正文之间用分隔线隔开，常见内容：

1. 报送范围：按"报：（上级机关或领导）""送：（平级、不相隶属的单位）""发：（下级单位、本单位各部门）"分行写；
2. 印数：如"（共印20份）"，用户没给的可以省略；
3. 报送范围只按用户给的写，没给的写【待补：报送范围】。不为"显得重要"扩大报送范围；同一内容已通过其他渠道报过的，提醒用户避免重复报送（工具约定，参照减负规定第12条"同类材料最多报一次"的精神，见 `references/_shared/rules/jianfu.md`）。

## 五、纯文本模板

网页环境和 `正文.txt` 按以下纯文本写，排版时再转为版式：

```text
某局工作简报
第12期
某局办公室编　　　　　　　　2026年10月20日
────────────────────────
某局推行“一表通”　基层报表数量减少四成
（正文，按信息写法）

某街道建立网格员“每日一巡”制度
（正文）
────────────────────────
报：区委办公室，区政府办公室
送：区委组织部
发：局属各单位，机关各科室
（共印30份）
```

模板中的分隔线只作示意，排版时用版式线条代替。

## 六、排版

gongwen-format 目前没有简报版式。需要 Word 文件的：
1. 用 gongwen-format 的"材料"版式排正文，再按本单位往期简报手工加报头、报尾；
2. 或把正文贴进本单位的简报 Word 模板。

在起草说明"所作假设"中写明采用哪种方式。

## 七、常见毛病

1. 期号断号、重号，或沿用上期期号；
2. 一期里几篇的数据口径不一，如一篇写"1—9月"、一篇写"全年预计"，读者以为是同一个数；
3. 编者按拔高，加入正文没有的成效判断；
4. 报送范围过宽，或同一内容既报简报又报信息、又报专报；
5. 会议简报加入会上没有的发言内容，或把讨论意见写成议定事项。
