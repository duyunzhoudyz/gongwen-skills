# 文种与常用材料速查

> - 来源：《党政机关公文处理工作条例》（中办发〔2012〕14号）第八条、第九条、第十五条；GB/T 9704-2012 第 10 章；国务院办公厅《关于实施〈国家行政机关公文处理办法〉涉及的几个具体问题的处理意见》（国办函〔2001〕1号）；《交通运输部公文处理办法》（交办发〔2014〕58号）；湖南大学《请示报告事项签报制度》；华南师范大学、北京航空航天大学公文处理办法。
> - 版本：条例为2012年7月1日起施行的现行版本；各单位制度为核验日公开可查的版本，可能已修订。
> - 核验日期：2026-10-16
> - 本文件为要点整理，不替代原文。“适用”栏引自条例第八条；方向、标题、结构、惯用语、常见错误为公文写作通行做法（实务），各单位可能不同，以本单位制度和单位画像为准。

## 一、使用说明

1. 起草前先按第六部分定文种，再查本文件对应条目，再按 `references/_shared/rules/tiaoli.md` 第五部分检查行文规则。
2. 行文方向只用三个词：上行文、平行文、下行文。
3. 惯用语是可选项，不是必写项。结语与开头语意重复时只留一个。
4. 要素行（格式见 `references/_shared/style/output-format.md` 第一节第9款，不得放进起草说明）：通知、通报、函、批复等有主送机关（公告、通告、纪要除外）；请示、报告有发文字号、签发人（未知写待补）和主送机关，请示结语“妥否，请批示”；各类公文有落款和成文日期，有附件的写附件说明，按各文种“惯用语”收尾；工作方案、调研报告、总结等印发或报送的同样有落款和成文日期。确定不了的才标待补。

## 二、法定文种（15 种）

### 2.1 决议
| 项目 | 内容 |
|---|---|
| 适用 | 会议讨论通过的重大决策事项（第八条（一）） |
| 方向 | 下行文 |
| 标题 | “某某会议关于……的决议”；标题下用圆括号题注通过日期和会议 |
| 结构 | 依据或背景；决议事项；号召或要求 |
| 惯用语 | 开头“某某会议审议了……”“会议决定：”；结尾提出号召 |
| 常见错误 | 未经会议表决通过的事项用决议；缺题注；与决定混用 |

### 2.2 决定
| 项目 | 内容 |
|---|---|
| 适用 | 对重要事项作出决策和部署；奖惩有关单位和人员；变更或撤销下级机关不适当的决定事项（第八条（二）） |
| 方向 | 下行文 |
| 标题 | “某某关于……的决定”；“关于表彰……的决定”；“关于给予某某……处分的决定” |
| 结构 | 缘由和依据；决定事项（可分条）；执行要求或希望 |
| 惯用语 | 开头“为……，根据……，经研究，决定……”；规范性决定结尾“本决定自×年×月×日起施行。” |
| 常见错误 | 一般性工作安排用决定（应用通知）；奖惩决定缺事实或依据；须会议表决通过的写成决定（应用决议） |

### 2.3 命令（令）
| 项目 | 内容 |
|---|---|
| 适用 | 公布行政法规和规章；宣布施行重大强制性措施；批准授予和晋升衔级；嘉奖有关单位和人员（第八条（三）） |
| 方向 | 下行文；使用主体受法律限制，企事业单位不用 |
| 标题 | 公布令一般不另拟标题；嘉奖令可用“关于……的命令”。版式：机关全称加“命令”或“令”，下空二行编令号（GB/T 9704 10.2），令号实务写作“第×号” |
| 结构 | 公布对象、通过的会议或批准机关、施行日期；签发人职务、签名章、成文日期 |
| 惯用语 | “《……》已经……通过，现予公布，自×年×月×日起施行。” |
| 常见错误 | 无权机关使用；正文冗长；令号套用发文字号的六角括号格式 |

### 2.4 公报
| 项目 | 内容 |
|---|---|
| 适用 | 公布重要决定或者重大事项（第八条（四）） |
| 方向 | 下行文，公开发布 |
| 标题 | “某某会议公报”“某某年国民经济和社会发展统计公报”“联合公报” |
| 结构 | 会议或事项概况；重要决定或重大事项分述；号召（会议公报） |
| 惯用语 | 开头“某某会议于×年×月×日至×日在某地举行。” |
| 常见错误 | 发布一般性工作信息；企事业单位使用 |

### 2.5 公告
| 项目 | 内容 |
|---|---|
| 适用 | 向国内外宣布重要事项或者法定事项（第八条（五）） |
| 方向 | 下行文，公开发布 |
| 标题 | “某某公告”或“某某关于……的公告”；可编“第×号”（实务） |
| 结构 | 公告事项（缘由从简）；结语 |
| 惯用语 | 结尾“特此公告。”“现予公告。” |
| 常见错误 | 停水停电、道路施工、考试安排等局部事项用公告（应用通告或通知）。企事业单位的招聘公告、招标公告和上市公司信息披露公告属于习惯用法或其他法规规定，不是条例所指的公告 |

### 2.6 通告
| 项目 | 内容 |
|---|---|
| 适用 | 在一定范围内公布应当遵守或者周知的事项（第八条（六）） |
| 方向 | 下行文，面向一定范围内的单位和公众 |
| 标题 | “某某关于……的通告” |
| 结构 | 缘由和依据；通告事项（分条）；施行日期或起止时间；结语 |
| 惯用语 | 开头“为……，根据……，现将有关事项通告如下：”；结尾“特此通告。” |
| 常见错误 | 与公告混用；向下级机关布置工作用通告（应用通知）；缺依据或起止时间 |

### 2.7 意见
| 项目 | 内容 |
|---|---|
| 适用 | 对重要问题提出见解和处理办法（第八条（七）） |
| 方向 | 上行、下行、平行均可。上行按请示性公文的程序和要求办理；下行有明确要求的应遵照执行，无明确要求的可参照执行；平行供对方参考（国办函〔2001〕1号第1条。该文依附的2000年办法已停止执行，现行条例未规定意见的方向，实务沿用） |
| 标题 | “某某关于……的意见”；“实施意见”“指导意见” |
| 结构 | 总体要求（从简）；主要任务或措施（分条）；保障措施（精炼） |
| 惯用语 | 下行开头“为……，现提出以下意见。”；上行结尾“以上意见如无不妥，请批转……执行。” |
| 常见错误 | 写成论述文章；形势背景和重要意义铺垫过长（`references/_shared/rules/jianfu.md` 第2条）；照抄上位文件；上行意见不按请示程序 |

### 2.8 通知
| 项目 | 内容 |
|---|---|
| 适用 | 发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文（第八条（八）） |
| 方向 | 主要为下行文；向有关单位告知周知事项时也用 |
| 标题 | “某某关于……的通知”；“关于印发《……》的通知”；“关于批转……的通知”；紧急事项“紧急通知”。转发：标题以发文机关开头时，写“××转发××关于……的通知”，不加“关于”（如“某县人民政府办公室转发省人民政府办公厅关于加强农村供水工程运行管理的通知”；中央、省级公开实例如国办函〔2021〕132号）；不写发文机关时，写“关于转发××……的通知”，并省去被转发标题中的“关于”。两种写法全标题都只留一个“关于”，不出现“的通知的通知”。层层转发时，省略只加了转发语的中间层次；中间层是批转，或是政府、办公厅（室）转发部门文件的，保留这一层。被转发的公文标题一般不加书名号，印发、转发法规规章和规范性文件时加书名号。转发用于上级、同级和不相隶属机关的公文，批转用于下级机关的公文（以上为实务做法，以本单位规定为准） |
| 结构 | 缘由（一两句）；通知事项（分条）；执行要求；联系人和附件。会议通知写明时间、地点、参会人员、报名或回执方式 |
| 惯用语 | 开头“为……，现将有关事项通知如下：”；结尾“特此通知。”；转发“现将……转发给你们，请结合实际认真贯彻执行。” |
| 常见错误 | 标题出现“关于关于”“的通知的通知”；发文机关之后又写“关于转发”；转发时大段复述上级文件；会议通知缺要素；用通知表彰批评（应用通报或决定） |

### 2.9 通报
| 项目 | 内容 |
|---|---|
| 适用 | 表彰先进、批评错误、传达重要精神和告知重要情况（第八条（九）） |
| 方向 | 下行文 |
| 标题 | “某某关于表彰……的通报”“关于……情况的通报”“关于……问题的通报” |
| 结构 | 事实（时间、单位、经过、结果）；分析或定性；表彰或处理决定；要求或号召 |
| 惯用语 | 开头“现将……情况通报如下：”；结尾“特此通报。” |
| 常见错误 | 用通报部署工作（应用通知）；事实不清、定性不当；按月按季排名通报（`references/_shared/rules/jianfu.md` 第8条） |

### 2.10 报告
| 项目 | 内容 |
|---|---|
| 适用 | 向上级机关汇报工作、反映情况，回复上级机关的询问（第八条（十）） |
| 方向 | 上行文 |
| 标题 | “某某关于……的报告” |
| 结构 | 工作报告：基本情况、做法和成效、问题、下一步打算。情况报告：经过、原因、处理情况、下一步措施。答复报告：针对询问逐项答复 |
| 惯用语 | 开头“现将……情况报告如下：”；结尾“特此报告。” |
| 常见错误 | 夹带请示事项（条例第十五条（四））；结尾用“妥否，请批示”；把报告当请示等批复；写成论文 |

### 2.11 请示
| 项目 | 内容 |
|---|---|
| 适用 | 向上级机关请求指示、批准（第八条（十一）） |
| 方向 | 上行文；标注签发人（第九条（六）），由机关主要负责人签发（第二十二条） |
| 标题 | “某某关于……的请示”；不写“请示报告”，不写“关于申请……的请示”这类重复表述（实务） |
| 结构 | 请示缘由；请示事项；本单位意见或方案；结语 |
| 惯用语 | 结尾“妥否，请批示。”“当否，请批复。”“以上请示，请予审批。” |
| 行文规则 | 一文一事；原则上主送一个上级机关，不抄送下级；转报下级请示须提出倾向性意见；不送领导个人（第十五条（一）（三）（四）（五）） |
| 常见错误 | 一文多事；多头主送；先办后请；结尾用“特此报告”；缺本单位意见；未写联系人和电话（实务中多在附注处注明） |

### 2.12 批复
| 项目 | 内容 |
|---|---|
| 适用 | 答复下级机关请示事项（第八条（十二）） |
| 方向 | 下行文；主送报送请示的机关 |
| 标题 | “某某关于……的批复”“关于同意……的批复” |
| 结构 | 引叙来文标题和文号；批复意见（同意、部分同意或不同意及理由）；执行要求 |
| 惯用语 | 开头“你单位《关于……的请示》（某发〔2026〕5号）收悉。经研究，现批复如下：”；结尾“此复。”“特此批复。” |
| 常见错误 | 不引来文或文号引错；态度含糊；对报告作批复 |

### 2.13 议案
| 项目 | 内容 |
|---|---|
| 适用 | 各级人民政府按照法律程序向同级人大或人大常委会提请审议事项（第八条（十三）） |
| 方向 | 特定行文：同级人民政府向人大及其常委会 |
| 标题 | “某某人民政府关于提请审议《……（草案）》的议案” |
| 结构 | 案由；必要性和主要内容说明；提请审议 |
| 惯用语 | 结尾“现提请审议。” |
| 常见错误 | 政府以外的主体使用；与人大代表议案、公司董事会议案混同（后两者分别按人大和公司治理的规定办理） |

### 2.14 函
| 项目 | 内容 |
|---|---|
| 适用 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项（第八条（十四）） |
| 方向 | 平行文；可用信函格式（GB/T 9704 10.1） |
| 标题 | “某某关于……的函”；“关于商请……的函”；“关于……的复函” |
| 结构 | 发函缘由；事项；希望或请求；结语 |
| 惯用语 | 结尾“请予支持，盼复。”“请函复。”“特此函告。”；复函开头“你单位《关于……的函》收悉。现函复如下：”，结尾“特此函复。” |
| 常见错误 | 向有隶属关系的上级用函请求批准（应用请示）；向不相隶属的审批部门请求批准用请示（应用函）；语气居高临下或过分谦卑 |

### 2.15 纪要
| 项目 | 内容 |
|---|---|
| 适用 | 记载会议主要情况和议定事项（第八条（十五）） |
| 方向 | 下行或平行，印发与会单位和有关单位执行或周知 |
| 标题 | “某某会议纪要”；版式见 GB/T 9704 10.3 |
| 结构 | 会议概况（时间、地点、主持人、议题）；议定事项（分条）；出席、请假、列席人员名单（GB/T 9704 10.3） |
| 惯用语 | “会议听取了……”“会议认为……”“会议议定：”“会议要求：” |
| 常见错误 | 写成逐人发言的流水记录；把未形成一致意见的讨论写成议定事项；议定事项缺责任单位和时限；漏出席名单 |

## 三、签报

签报不在条例第八条之列，是部分机关、高校、企业在内部制度中规定的内部上行文。以本单位制度为准。签报是内部文书，主送一位领导的职务，不适用《条例》第十五条第（五）项关于不得以本机关名义向上级机关负责人报送公文的要求；稿首保留“签报”表头便于识别。

| 项目 | 内容 |
|---|---|
| 适用 | 本单位内设部门向本单位领导书面请示事项、汇报工作、反映情况、回复询问、提出建议 |
| 方向 | 内部上行文，不对外行文 |
| 标题 | “关于……的请示”或“关于……的报告”；签报单抬头印“签报” |
| 结构 | 标题；主送领导（一般一位）；正文：缘由、事项、本部门意见或方案；落款：部门、负责人签名、日期；拟办、会签栏 |
| 惯用语 | 请示类结尾“妥否，请批示。”；报告类结尾“特此报告。” |
| 常见错误 | 同时分送多位领导；绕过办公室直接送领导个人；本部门职责内的事项也上签报；一签多事；只摆问题不给方案 |

| 类型 | 示例 | 要点 | 出处 |
|---|---|---|---|
| 部委 | 交通运输部 | 用于部机关司局向部领导书面汇报工作、请示事项、反映情况、回复询问、提出见解和处理办法，是“具有特定格式的内部上行文”；主办司局负责人签署姓名，不加盖印章；一般只报一位部领导，不得同时分送多位，不抄送其他司局 | 《交通运输部公文处理办法》第十八条、第二十六条 |
| 高校 | 湖南大学 | 用于向校领导汇报或请示重要工作，以及不编发文字号但须校领导审签的公文；由标题、主送领导、正文、落款组成；一文一事；一般只报一位校领导；校办审核登记、统一编号后报送，不得直接送领导个人；本单位职责内事项不报签报；涉及其他单位的先会签 | 湖南大学《请示报告事项签报制度》 |
| 央企 | 未查到可公开核实的制度原文 | 名称可能是签报、呈批件、请示单等，以本企业公文管理制度为准；用户未提供时按上两例的共同要点起草，并在起草说明中写明 | 无 |

签报与请示的分工：以本单位名义向上级机关请求批准，用请示；本单位内设部门向本单位领导请求批准，有签报制度的用签报，没有的按单位画像（实务中也有用请示或请示单的）。

## 四、常用材料（10 种）

这些材料不是法定文种。上报时作为报告的附件或以报告报送；下发时以通知印发，如“关于印发《2027年工作要点》的通知”。以下均为实务做法。

### 4.1 总结
- 适用：回顾评价一定时期的工作。用于上报、存档、会议交流。
- 标题：“某某单位2026年工作总结”；或主副标题，主标题概括主要成效。
- 结构：基本情况和主要成效；主要做法；问题与不足；下一步打算。
- 惯用语：开头“2026年，我单位围绕……，现将有关情况总结如下。”
- 常见错误：成效无数据或数据无来源；问题写成变相表扬；下一步打算空泛；与上年雷同。

### 4.2 计划
- 适用：对下一阶段工作作出安排。
- 标题：“某某单位2027年工作计划”。
- 结构：目标；任务和措施（写明时间、责任部门、完成标准）；保障。
- 惯用语：开头“为……，结合……，制定本计划。”
- 常见错误：目标无法衡量；任务无时间节点和责任部门；照抄上级部署。

### 4.3 工作要点
- 适用：列出年度或阶段工作要点，比计划简要，常以通知印发。
- 标题：“某某单位2027年工作要点”。
- 结构：总体要求（一段）；分条列重点任务，每条一句话任务加简要要求，可标责任部门。
- 惯用语：开头“2027年工作的总体要求是：……”
- 常见错误：写成计划或总结；要点过多不分主次；总体要求铺垫过长（`references/_shared/rules/jianfu.md` 第2条）。

### 4.4 汇报材料
- 适用：向上级领导检查调研、专题会议汇报工作。
- 标题：“某某单位关于……工作情况的汇报”。
- 结构：基本情况；主要做法和成效；困难和问题；下一步打算；需要上级支持的事项。
- 惯用语：开头“现将……工作情况汇报如下。”
- 常见错误：篇幅超出汇报时长；需上级审批的事项只在汇报材料中提出（应另行请示，条例第十五条（四））；只讲成绩不讲问题；一般性汇报和表态（`references/_shared/rules/jianfu.md` 第6条）。

### 4.5 调研报告
- 适用：反映调查研究的情况、问题和对策。
- 标题：“关于……情况的调研报告”；或主副标题。
- 结构：调研基本情况（时间、对象、方法、样本）；现状和成效；问题及原因；对策建议。
- 惯用语：开头“×月×日至×日，调研组采取……方式，赴……开展调研。现将调研情况报告如下。”
- 常见错误：没有调研记录支撑（`references/_shared/guardrails.md` 第六条第5项）；问题、原因、对策不对应；建议无法操作。

### 4.6 经验材料
- 适用：总结推广某项工作的做法和成效，用于交流、上报、刊发。
- 标题：主标题提炼做法或成效，副标题“——某某单位……工作经验”。
- 结构：导语；主要做法（分条）；取得成效（只用材料数据）；经验体会（工作性表述）。
- 惯用语：开头一句交代单位、做法和成效。
- 常见错误：做法与成效不对应；拔高定性；编造数据和案例；照搬其他单位经验。

### 4.7 述职报告
- 适用：领导干部或工作人员向组织、主管领导或职工群众报告本人履职情况。
- 标题：“述职报告”“2026年度述职报告”；合并述廉的写“述职述廉报告”。
- 结构：称谓；岗位职责概述；履职情况和主要工作；不足；下一步努力方向；述廉内容按单位要求单列。
- 惯用语：开头“根据……安排，现将本人……履职情况报告如下。”；结尾“以上述职，请予评议。”
- 常见错误：写成部门总结，个人作用不清；通篇用“我们”；缺本人事例时编造（`references/_shared/guardrails.md` 第六条第4项：只出提纲和填写指引）。

### 4.8 实施方案
- 适用：对落实某项任务作出具体安排，常以通知印发。
- 标题：“某某关于……的实施方案”或“……实施方案”。
- 结构：总体要求（目标）；主要任务（任务、责任部门、完成时限）；实施步骤（阶段和时间）；保障措施（精炼）。
- 惯用语：开头“为贯彻落实……，结合本单位实际，制定本方案。”
- 常见错误：照搬照抄上位文件（`references/_shared/rules/jianfu.md` 第2条）；任务无责任部门和时限；步骤与任务脱节；要求下级层层制定配套方案（`references/_shared/rules/jianfu.md` 第3条）。

### 4.9 讲话稿
- 适用：领导在会议、活动上的讲话。
- 标题：“在……会议上的讲话”，下注讲话人和日期。
- 结构：称谓；开场（一两句点明会议目的）；主体（分几点讲）；结尾（简短要求）。
- 惯用语：称谓“同志们：”（GB/T 15834 4.7.3.4）；开头“今天召开……会议，主要任务是……”
- 常见错误：超时（主要负责同志讲话不超过1小时，`references/_shared/rules/jianfu.md` 第6条）；书面腔重，不便口头表达；在讲话中设定督查检查考核事项（`references/_shared/rules/jianfu.md` 第7条）。

### 4.10 信息
- 适用：向上级办公室或信息部门报送工作动态、经验做法、问题建议（政务信息、工作信息）。
- 标题：一句话概括核心事实，写清主体、做法、效果，如“某区推行报表‘一表通’减少基层重复填报”。
- 结构：导语（时间、主体、事件、效果）；主体（做法和数据，分条）；结尾可省。
- 惯用语：开头直接写“近日，某区……”“今年以来，某局……”。
- 常见错误：标题空泛（只有“扎实推进”“多措并举”）；写成总结；时效性差；数据无来源；同类信息重复报送（`references/_shared/rules/jianfu.md` 第12条）。

## 五、企事业单位参照执行

1. 依据：条例第四十条“其他机关和单位的公文处理工作，可以参照本条例执行”；GB/T 9704-2012 第 1 章（其他机关和单位可以参照执行）；GB/T 15835-2011 第 1 章（政府和企事业单位公文可参照执行）。
2. 高校实例：《华南师范大学公文处理办法》（华师党委〔2024〕33号）第八条、《北京航空航天大学公文处理办法》（北航校字〔2021〕2号）第八条，都列 11 种：决议、决定、通告、意见、通知、通报、报告、请示、批复、函、纪要，不含命令（令）、公报、公告、议案。华南师范大学办法把条例中的“机关”改称“单位”“部门”。
3. 医院、国企：未查到可公开核实的代表性制度文本，按单位画像中的可用文种执行。
4. 工具默认：
   - 企事业单位不使用命令（令）、公报、议案；
   - 公告慎用，局部事项改用通告或通知；
   - 国企董事会的议案、决议按《公司法》和公司章程办理，不按条例的议案、决议起草；
   - 内设部门向本单位领导行文，优先使用签报（单位有签报制度时）。

## 七、易混文种辨析

### 7.1 请示与报告
| 维度 | 请示 | 报告 |
|---|---|---|
| 目的 | 请求指示、批准 | 汇报工作、反映情况、答复询问 |
| 时机 | 事前 | 事中、事后或应询 |
| 是否需要答复 | 需要批复 | 不需要 |
| 事项 | 一文一事 | 可综合汇报，不得夹带请示事项（第十五条（四）） |
| 结语 | “妥否，请批示。” | “特此报告。” |

判断：正文中只要有一项需要上级表态，就把这一项单独写成请示。

### 7.2 请示与函
| 维度 | 请示 | 函 |
|---|---|---|
| 关系 | 有隶属关系的上级机关 | 不相隶属机关，含无隶属关系的审批部门 |
| 方向 | 上行文 | 平行文 |
| 版式 | 文件格式，标注签发人 | 可用信函格式 |
| 对方答复 | 批复 | 复函或审批函 |
| 例 | 某医院向主管的卫生健康委请求批准 | 区教育局向区财政局申请追加经费：“关于商请追加……经费的函” |

### 7.3 通知、通告与公告
| 维度 | 通知 | 通告 | 公告 |
|---|---|---|---|
| 对象 | 下级机关和有关单位 | 一定范围内的单位和公众 | 国内外 |
| 事项 | 要求执行或周知的事项；批转、转发 | 应当遵守或周知的事项 | 重要事项或法定事项 |
| 主送机关 | 有 | 一般无 | 无 |
| 发布方式 | 印发 | 张贴、媒体发布 | 媒体发布 |

判断：有明确受文机关的用通知；面向社会且有遵守要求的用通告；向国内外宣布重大或法定事项的用公告。

### 7.4 意见与通知
| 维度 | 意见 | 通知 |
|---|---|---|
| 内容 | 对重要问题提出见解和处理办法，政策性、指导性强 | 具体事项的执行或周知，操作性强 |
| 方向 | 上行、下行、平行均可 | 主要为下行 |
| 约束力 | 下行时有明确要求的遵照执行，无明确要求的参照执行 | 要求执行的须执行 |
| 组合 | 常以通知印发或由上级批转 | 可用来印发、批转、转发意见 |

判断：提出一整套政策措施用意见；布置一项具体工作用通知。

### 7.5 纪要与会议记录
| 维度 | 纪要 | 会议记录 |
|---|---|---|
| 性质 | 法定文种（第八条（十五）） | 内部原始记录，不是公文 |
| 内容 | 提炼主要情况和议定事项 | 按时间顺序如实记录发言和过程 |
| 形成 | 会后整理，经审定后印发 | 会中记录，存档备查 |
| 用途 | 议定事项交有关单位执行 | 作为依据和凭证 |

判断：要发给有关单位执行的写纪要；只存档的写会议记录。

### 7.6 通报与通知
| 维度 | 通报 | 通知 |
|---|---|---|
| 目的 | 表彰、批评、告知情况，以事实教育引导 | 布置工作，提出执行要求 |
| 重心 | 事实和评价 | 任务和要求 |
| 结语 | “特此通报。” | “特此通知。” |

判断：重点是“发生了什么、怎么看”用通报；重点是“要做什么”用通知。重大奖惩也可用决定。

### 7.7 批复与复函
| 维度 | 批复 | 复函 |
|---|---|---|
| 针对 | 下级机关的请示 | 不相隶属机关的来函（询问、商洽、请求批准） |
| 方向 | 下行文 | 平行文 |
| 依据 | 第八条（十二） | 第八条（十四）：答复问题、答复审批事项 |
| 开头 | “你单位《关于……的请示》收悉。” | “你单位《关于……的函》收悉。” |
| 结语 | “此复。” | “特此函复。” |

判断：来文是下级的请示，用批复；来文是函，用复函。
