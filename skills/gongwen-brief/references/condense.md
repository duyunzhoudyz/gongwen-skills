# 从长材料提炼信息

用户给的是经验材料、总结、调研报告、汇报材料，要的是一篇 500～800 字的信息或一篇新闻稿。这是换文体：从长材料里挑一个点，按信息的写法重写。只缩短篇幅、文体不变的（如 8000 字报告压到 3000 字），交 gongwen-polish；要写 1500 字以上的书面经验材料，交 gongwen-report；会上口头交流发言交 gongwen-speech。

## 一、五步法

### 第一步　定一个点

长材料往往写了五六项工作，信息只写一个点。按“新、特、实”挑（`references/types/xinxi.md` 第二部分）：
1. 有前后对比数据的，优先；
2. 本单位独有的机制、做法，优先；
3. 各地普遍在做、材料里也没有数据的，不选。

各模式都直接选推荐角度成稿，候选角度写进起草说明（教学模式写进写作要点），每个一句话说明依据的材料段落和数据：

```text
候选角度
1. 定时定点投放（材料第二部分第1段）：有准确率前后对比，62%→85%。推荐。
2. 积分兑换（第二部分第3段）：有参与户数，无效果数据。
3. 督导员队伍（第三部分）：做法常见，无数据。
```

用户明确要求先看角度的，只交角度、标题和导语（SKILL.md 第三步第3条）。

### 第二步　挑 2～3 条做法

围绕选定的点，从材料中挑出直接支撑它的做法，每条配材料里最硬的一个数据或事例。挑不出数据的做法，可以写，但不为它编数据。

### 第三步　删

按顺序删：
1. 背景、意义、上级要求、“领导高度重视”；
2. 过程性描述：开了几次会、发了什么文、成立了什么小组（机制本身是做法核心的除外）；
3. 与选定的点无关的其他工作；
4. 空泛表态和评价：“取得明显成效”“群众满意度不断提高”（没有数据的）；
5. 重复举例：同一做法举了三个例子，留最有说服力的一个；
6. 下一步打算（信息一般不写，问题建议类除外）。

### 第四步　重写标题和导语

标题和导语按信息写法重新写（`references/types/xinxi.md` 第三、四部分），不沿用原材料的大标题。原材料的小标题可以改写为做法的条目名。

### 第五步　核对

1. 篇幅在目标范围内（默认 500～800 字）；
2. 每个数字都能在原材料找到，口径和限定条件没丢；
3. 标题中的数字概括与做法条数一致；
4. 成效没有因为删掉上下文而被放大（“试点小区”没有变成“全区”）。

## 二、删什么、留什么

留：时间、主体、具体做法；做法中的机制和数据；前后对比和材料中有的群众反馈；限定条件（时段、范围、口径）；一个最有说服力的事例。

只删不改：保留下来的事实和数据，措辞可以压缩，数值、范围、状态不变。

## 三、数字和事实不变

1. 压缩后不新增原材料没有的数字、事例、引语、评价；
2. 原材料的“约”“左右”“初步统计”照留；
3. 有 Python 环境时运行 `python scripts/fact_diff.py <原材料> 正文.txt --ledger`，“正文中有、台账中没有”的清单必须为空，非空的逐条改正（此处把原材料当作台账使用）；
4. 原材料本身数字前后矛盾的，不替用户选一个，正文标【待核实】，起草说明列出两处说法。

## 四、正误对照

原材料先写形势背景和“成立领导小组”，后面才有12个小区试点、准确率由62%提高到85%的数据。

- 误（压缩后的信息开头）：近年来，某街道高度重视垃圾分类工作，成立领导小组，多措并举，全面推行定时定点投放，全街道分类准确率大幅提升。
  问题：留了铺垫和过程，删了数据；“12个小区试行”变成“全面推行”，“85%”变成“大幅提升”。
- 正：今年7月以来，某街道在12个小区试行定时定点投放，三个月后生活垃圾分类准确率由62%提高到85%。
