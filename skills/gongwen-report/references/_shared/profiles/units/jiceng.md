# 单位类型画像：基层

适用于县（市、区）党委、政府及其部门，乡镇党委、政府，街道党（工）委、办事处。村（社区）见 `shequ.md`。

## 一、规则基线与参照依据

| 依据 | 适用方式 | 要点 |
|---|---|---|
| 《党政机关公文处理工作条例》、GB/T 9704-2012 | 直接适用 | 同党政机关，见 `dangzheng.md` |
| 《整治形式主义为基层减负若干规定》（2024 年 8 月） | 直接适用，基层最直接相关 | 发文和会议计划管理；督查检查考核统筹；填表报数通过省级平台，同类材料最多报一次；不得把是否开会发文、拍照留痕作为评判工作优劣的标准 |
| 乡镇（街道）履行职责事项清单 | 用户提供时适用 | 清单外事项未经省级统一部署不得擅自下放（减负规定第 16 条） |
| 当地减负清单、督查检查考核年度计划 | 用户提供时适用 | 迎检材料的范围和次数 |

## 二、发文体系

| 发文主体 | 发文机关标志示例 | 发文字号示例 |
|---|---|---|
| 县委、县政府 | 中共某县委员会文件、某县人民政府文件 | X委发、X政发〔2026〕N号 |
| 县直部门 | 某县某局文件 | X某发〔2026〕N号 |
| 乡镇党委、政府 | 中共某镇委员会文件、某镇人民政府文件 | X镇党发、X镇政发〔2026〕N号 |
| 街道党（工）委、办事处 | 中共某街道委员会（工作委员会）文件、某街道办事处文件 | X街党发、X街办发〔2026〕N号 |

代字以本地规定为准，上表只示意结构。

1. **行文关系**：乡镇政府向县政府请示、报告；向县直部门请求支持，两者不相隶属，用函（《条例》第八条）。街道办事处是区（县）政府的派出机关，行文关系同理。
2. **内设机构**：乡镇站所、中心等内设机构一般不对外正式行文，以本地规定为准（参照《条例》第十七条）。
3. **对村（社区）**：布置工作多用通知。不得把村（社区）作为行政执法、城市管理、招商引资等事务的责任主体（减负规定第 15 条）。
4. **内部文种**：站所、办公室向乡镇领导请示多用签报或请示单，内部运转。

## 三、常用文种与典型材料清单

| 频次 | 法定文种 | 常用材料 |
|---|---|---|
| 几乎每周 | 通知、纪要 | 政务信息、工作台账更新、迎检汇报 |
| 每月或每季 | 请示、报告、函、通报 | 落实上级部署的实施方案、督查自查报告、专项工作汇报 |
| 每年 | 报告 | 年度总结与计划、述职述责述廉、民主生活会和组织生活会材料、党建工作报告 |
| 事件触发 | 通报、通知 | 巡视巡察、审计、督查整改材料；防汛、森林防火、安全生产等应急通知和信息报告；信访事项相关材料 |

常用法定文种约 6 种：通知、请示、报告、函、纪要、通报。

## 四、决策程序与行文特点

1. **集体决策**：重大事项经党委会议（乡镇党委、街道党（工）委）集体讨论决定；县级行政事务经政府常务会议研究，乡镇、街道行政事务经乡镇长办公会、街道主任办公会研究。
2. **上级部署驱动**：多数材料由上级文件、督查、考核触发，时限紧，常出现同一事项多头报送。
3. **对上材料**：汇报写"做了什么、效果如何、存在什么困难、需要上级支持什么"，困难和诉求要具体。
4. **对下材料**：给村（社区）的通知要写清任务、时限、联系人，不转嫁责任。

## 五、术语表

| 术语 | 解释 |
|---|---|
| 履行职责事项清单 | 列明乡镇（街道）基本履职、配合履职等事项的清单，清单外事项不得随意下放 |
| 属地管理 | 按地域划分管理责任；写材料时分清属地责任与部门职责 |
| 网格化管理 | 把辖区划为网格，由网格员负责信息采集和日常服务 |
| 政务信息 | 向上级报送的工作信息，按被采用情况计分排名 |
| 迎检 | 迎接上级督查、检查、考核，需准备汇报、自查报告、佐证台账 |
| 台账 | 记录工作过程和结果的表册，是迎检和整改的事实依据 |
| 一表通 | 部分地区推行的基层报表整合做法，同类数据一次采集、多方共享 |
| 最多报一次 | 能自动生成或共享获取的数据不再要求基层报送（减负规定第 12 条） |
| 包村（包片）干部 | 乡镇干部分片联系村（社区），负责督促落实 |
| 驻村第一书记、工作队 | 上级选派到村的干部，材料中注意区分派出单位与所在村 |
| 河长制、林长制 | 分级分段落实河湖、林草保护责任的制度 |

## 六、红线与禁忌

1. 虚报数据；整改未完成却标"已完成"；台账补记、倒签日期。
2. 面向群众的通知出现没有法律依据的强制措施，如擅自规定罚款、拘留、断水断电、取消待遇。
3. 把行政执法、招商引资等责任压给村（社区）。
4. 照搬上级方案，不结合本地实际；措施缺失时编造"特色做法"。
5. 公示名单超范围公开个人信息，身份证号、手机号、家庭住址须脱敏。
6. 把拍照留痕、学习笔记、点赞转发量写成工作成效（减负规定第 8 条、第 14 条）。

## 七、年度写作节点

| 时间 | 节点与材料 |
|---|---|
| 1–2 月 | 年度工作部署会讲话；春节走访慰问通知；节前安全检查 |
| 3–5 月 | 春季森林防火、春耕生产等季节性通知；一季度工作汇报 |
| 6–9 月 | 安全生产月（6 月）；防汛防台；上半年总结 |
| 10–12 月 | 年度考核迎检、年终总结、次年计划、述职 |
| 全年 | 政务信息；督查迎检；整改材料；信访相关材料 |
| 换届年 | 县乡领导班子和人大换届相关材料（每 5 年一次，以组织部门部署为准） |

## 八、版式差异

1. 参照 GB/T 9704-2012，与党政机关一致。
2. 不得用"白头"、便笺代替正式文件来规避发文数量管理（减负规定第 1 条）；本身不属于正式公文的工作提示，按本地规定处理。
3. 面向群众张贴的通知可简化版式，但必须有落款单位、日期和公章。

## 九、文风特点

1. 短、实、准：先写结论和数据，再写做法。
2. 政务信息讲究"标题有亮点、开头即结论、数据要实"，篇幅以上级信息部门要求为准。
3. 面向群众的文书用大白话，写清时间、地点、要求和咨询电话。
4. 汇报材料与台账数据一致，问题和诉求不回避。

## 十、对各 skill 的提示

| skill | 提示 |
|---|---|
| gongwen-draft | 乡镇向县直部门请求支持用函，向县政府用请示；面向群众的通知逐句查法律依据 |
| gongwen-brief | 政务信息按"做法、成效、数据"组织，数据来自用户台账 |
| gongwen-report | 迎检汇报按检查表逐项对应；数据与台账一致，缺失标【待补】 |
| gongwen-implement | 把上级方案拆到村（社区）、到人、到时间；本地措施缺失标【待补】 |
| gongwen-rectify | 整改状态以台账为准，"已完成"须有佐证 |
| gongwen-review | 法规关重点查面向群众的文书；查前后数据一致、是否照抄上级文件 |
