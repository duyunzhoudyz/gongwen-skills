# 只出框架时的交付模板

述职缺本人事例、调研报告缺调研记录（`references/_shared/guardrails.md` 第六条第 4、5 款），以及用户一条素材都没给时，不生成完整正文，按本文件交付框架。先用一句话说明原因，例如：“述职报告要写本人的真实经历，您还没提供个人事例，我先给提纲和填写指引，您补上事例后我再成稿。”不说教，不拒绝整个任务。

## 目录

一、述职报告提纲和填写指引
二、调研提纲和调研报告框架
三、素材收集清单

## 一、述职报告提纲和填写指引

### （一）提纲

按德、能、勤、绩、廉组织（《中华人民共和国公务员法》第三十五条规定考核德、能、勤、绩、廉；事业单位、国企按本单位考核通知的栏目调整）。述责述廉的栏目以组织部门或纪检监察机构的通知为准，用户没提供通知的，按下面的通用栏目。

```text
述职述责述廉报告

称谓（按述职会议对象，如“各位领导、同志们：”）
开头：任职岗位、任职时间、分管或负责的工作范围（一段）
一、政治素质和思想作风（德）
二、履职能力（能）
三、工作作风和勤勉敬业（勤）
四、主要工作实绩（绩）
五、履行管党治党责任情况（述责，领导干部适用）
六、廉洁自律情况（廉）
七、存在的不足
八、下一步努力方向
结尾：以上述职，请予评议。
```

### （二）填写指引

每一部分列出要提供的事实和可用的句式。句式中的下划线由用户填，填不出的那一项就不写，不要用套话补。

| 部分 | 需要用户提供的事实 | 句式示例 |
|---|---|---|
| 开头 | 岗位名称、任职起始时间、分管或负责的科室和工作 | 本人自____年____月起任____，负责____工作。 |
| 德 | 参加了哪些学习（名称、次数）、写过的学习体会或讲课题目 | 全年参加____学习____次，围绕____为科室讲课____次。 |
| 能 | 解决过的一两件难题；新掌握的业务或技能；取得的证书 | 针对____问题，本人____（做法），____（结果）。 |
| 勤 | 出勤、加班、值班、牵头的急难任务（时间、事项） | ____期间，本人____（承担的任务），____（结果）。 |
| 绩 | 3～5 件本人牵头或主办的工作：事项、本人角色、做法、结果数据 | 本人牵头____，通过____（做法），____（数据结果）。 |
| 述责 | 落实“一岗双责”的具体动作：开过的会、谈过的话、查过的问题、整改结果 | 全年主持研究____工作____次，对分管科室开展廉政谈话____人次。 |
| 廉 | 遵守廉洁规定的具体做法、个人有关事项报告情况；由本人确认的表态 | 本人按规定报告个人有关事项____（本人确认后填写）。 |
| 不足 | 本人在工作中真实存在的 1～3 个不足，最好有具体事例 | 在____工作中，____（具体表现），导致____。 |
| 努力方向 | 与上面不足对应的改进做法 | 针对____，____年将____。 |

提醒用户：“绩”是重点，写本人做的事，单位成绩可以引用，但要写清本人在其中做了什么；不足写本人的具体不足，“对自己要求过高”“工作太投入”属于变相表扬；廉洁表态由本人确认后再写进正文，本 skill 不代替本人表态。

## 二、调研提纲和调研报告框架

### （一）调研提纲

```text
关于____情况的调研提纲

一、调研目的：弄清____（一两句，来自用户或领导交办的要求）
二、调研对象：____（单位、部门、群体，写到可以联系的层级）
三、调研方式：座谈、个别访谈、实地察看、问卷、调阅资料（按用户条件选）
四、时间安排：【待定】（由用户确定）
五、调研问题
（一）面向分管领导或管理部门：现状和主要做法；遇到的主要困难；对上级的建议
（二）面向一线人员或服务对象：具体经历；办事或工作中最费时费力的环节；改进建议
（三）面向相关部门：职责衔接中的堵点；数据和信息共享情况
六、需要收集的数据和资料：____（列出指标名称、时段、口径，如“2024—2026年办件量，按月”）
```

拟问题时：一个问题只问一件事，问得出事实，不问“您对这项工作满意吗”这类只能答是或否的问题；不预设结论，不写“请谈谈取得的显著成效”“请谈谈存在的突出问题”，改为“这项工作开展以来有哪些变化”“哪个环节最费时间”；对不同对象问他们能回答的事。

### （二）调研报告框架

```text
关于____情况的调研报告

开头：调研时间、组织者、对象、方式、样本数量（调研后按记录填写）
一、基本情况（调研后按资料填写：现状数据、主要做法）
二、主要问题（每个问题对应调研记录中的出处）
三、原因分析（写调研中了解到的原因，区分受访者说法和调研组判断）
四、对策建议（每条建议对应一个问题，写清谁来做、做什么）
```

告诉用户：调研结束后，把座谈记录、访谈记录、问卷结果或数据表发来，按记录成稿。框架中各部分不预填任何发现。

## 三、素材收集清单

用户一条素材都没给时交付。按提纲每部分列出要什么、一般到哪里找：

| 提纲部分 | 需要的素材 | 一般出处 |
|---|---|---|
| 总体情况 | 年度主要指标完成值、与上年对比 | 统计报表、业务系统、财务快报 |
| 主要工作 | 每项重点工作的做法、时间、结果 | 月度工作记录、会议纪要、工作台账 |
| 典型事例 | 1～3 个具体事例：时间、经过、结果 | 工作日志、信息简报、表扬记录 |
| 存在问题 | 未完成的指标、滞后的工作、上级检查指出的问题 | 考核反馈、督查通报、自查记录 |
| 下一步打算 | 明年的目标值、计划开展的工作 | 年度计划草案、上级下达的任务 |

用户拿到清单后补什么写什么。用户坚持先要稿的，出框架稿：结构完整，所有事实位置标【待补：说明】，起草说明写明“本稿为框架稿，事实均待补”。
