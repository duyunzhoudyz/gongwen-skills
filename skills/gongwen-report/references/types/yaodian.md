# 工作要点

## 一、用途

列出年度或阶段的重点工作，比计划简要，一般以通知印发（如"关于印发《2027年工作要点》的通知"，印发通知交 gongwen）。高校常写党政工作要点，机关常写年度工作要点，科室、部门也可写本部门要点。

## 二、常见结构框架

框架一：总体要求加分板块要点（最常用）

```text
某某单位2027年工作要点
总体要求（一段）
一、板块一
（一）要点一。具体内容一两句。（责任部门）
（二）要点二。……
二、板块二
……
```

框架二：总体要求、主要目标、重点任务、工作要求

```text
一、总体要求
二、主要目标
三、重点任务
四、工作要求
```

框架三：要点加任务分解表（用户要求时）

正文写总体要求和要点，附件为任务分解表：序号、任务、牵头部门、配合部门、完成时限。表格交付 Word 时由 gongwen-format 转换。

## 三、各部分写法

1. 总体要求：一段，工具约定不超过 200 字。政治性提法和上级精神只用用户提供的原文，没有提供的用通用、稳定的表述，并标【待核实：请对照最新原文】（`references/_shared/guardrails.md` 第二条第 4 款）。
2. 板块：按职责分 4～8 个板块，每个板块 3～6 条要点（工具约定）。按重要程度排序，主责主业在前。
3. 每条要点：先用一句话点明要做的事，再写对象、重点或推进方式。一条只写一件事，相近事项合并。
4. 责任部门：台账有的写在要点末尾括号内；没有的统一写【待补：责任部门】，或在起草说明中说明"责任部门待分工后补"。
5. 保持状态：已定的写成任务；用户说"还在研究""拟"的，写"研究制定""拟开展"，不写成既定安排。
6. 措辞用"要""推进""完成"等部署性动词，不用"建议""可以考虑"。

## 四、篇幅建议

工具约定：单位年度工作要点 2000～4000 字；部门、科室要点 1000～2000 字。

以通知印发的工作要点属于文件。部署综合性工作的，`references/_shared/rules/jianfu.md` 未设字数上限，仍要短实新，超过 5000 字时在起草说明中提示压缩；部门专项要点在党政机关、基层、社区不超过 4000 字。

## 五、常见毛病

1. 写成总结，大段回顾去年成绩。工作要点只写今年要做的事，去年情况最多在总体要求中带一句。
2. 写成计划，每条要点展开三四段。要点一条一两句。
3. 要点过多、不分主次，几十条平铺。
4. 总体要求铺垫过长（`references/_shared/rules/jianfu.md` 第2条）。
   - 误：当前，我们正处在……的关键时期，面临……，必须深刻认识……的重要意义。（三段）
   - 正：2027年工作的总体要求是：……（一段，提法取自用户提供的原文）
5. 动词虚，没有对象。
   - 误：加强队伍建设，提升服务能力，推进工作落实。
   - 正：完成全体窗口人员业务轮训，每人不少于24学时。（学时数取自用户材料）
6. 部署内容用"建议""可以考虑"（`references/_shared/style/defensive.md` 第五部分）。

## 六、单位差异提示

- 党政机关：总体要求的提法从严，按严谨模式核对原文；要点与上级年度部署逐条对应。
- 高校：党政工作要点按党建思政、人才培养、学科建设、科学研究、师资队伍、社会服务、办学保障组织；学院要点逐条承接学校要点。
- 医院：按党建、医疗质量安全、学科建设、运营管理、教学科研、后勤保障组织。
- 国企：按党建、经营指标、改革任务、安全生产、风险防控组织；经营指标只用用户提供的数。
- 基层：要点不向村（社区）设定考核排名、责任状（`references/_shared/rules/jianfu.md` JF-11、JF-12）。
