# 调研报告

## 一、用途

反映调查研究的情况、问题和对策，供领导决策参考。前提是已经调研、有调研记录。

调研记录包括：座谈记录、个别访谈记录、问卷结果、实地察看记录、调阅资料摘录、调研数据表。没有记录的，按 `references/frameworks.md` 第二部分只出调研提纲和报告框架，不预制报告（`references/_shared/guardrails.md` 第六条第 5 款）。

## 二、常见结构框架

框架一：标准式

```text
关于某某情况的调研报告
开头：调研时间、组织者、对象、方式、样本（一段）
一、基本情况
二、主要问题
三、原因分析
四、对策建议
```

框架二：问题导向式（问题少而深时）

```text
开头：调研概况
一、问题一：表现、原因、建议
二、问题二：表现、原因、建议
三、问题三：表现、原因、建议
```

框架三：典型调研（学习外地或基层经验）

```text
一、调研对象的主要做法
二、取得的成效
三、对本单位的启示
四、建议
```

## 三、各部分写法

1. 开头：写实际发生的调研：何时、谁带队、去了哪些单位、用了什么方式、访谈了多少人、回收了多少问卷。全部取自记录，缺的标【待补】。记录只有总数的（如“访谈10人次”），不自行拆分构成（单位、群众、部门等）。
2. 台账来源写到记录：如“座谈记录3第2条”“问卷第5题统计”。
3. 区分四种内容，写法不同：
   - 数据：照录，注明口径；
   - 直接观察：写“调研组在某地看到……”；
   - 受访者说法：写“部分受访人员反映……”，注明人数或范围，不写成定论；
   - 调研组判断：写在原因分析和建议里，以记录为依据。
4. 不把有限样本写成普遍结论。
   - 误：辖区居民普遍反映早高峰公交候车时间长。（记录中只走访了2个小区的15户居民）
   - 正：走访的2个小区15户居民中，有11户反映早高峰候车超过20分钟。
5. 问题、原因、建议一一对应：每条建议回答一个问题，写清建议谁来做、做什么。建议是上行文用语，可以用“建议”（`references/_shared/style/defensive.md` 第五部分）。
6. 结论态度明确，不写“各有利弊、需综合权衡”（`references/_shared/style/defensive.md` 第四部分）。
7. 材料是统计表（各站点、乡镇、企业的逐项数据）的，要用足数据：除逐项数据外，给出汇总数、平均值等必要的派生数，计算正确，分母口径写清（如“有交易额的6个站点平均2.4万元”，不含未填报的站点），不只逐项罗列；算式记入台账，正文只写结果。

## 四、篇幅建议

工具约定：调研报告 3000～5000 字；报送领导参阅的调研专报 1500～2500 字。附件（问卷统计表、典型案例）另计。

## 五、常见毛病

1. 没有调研记录，先写报告，再去“找材料”印证。遇到这种需求，只出提纲和框架。
2. 以偏概全（见第三部分第 4 条）。
3. 把受访者意见当事实写。
   - 误：该项目审批时间长达半年。
   - 正：两家受访企业反映，该项目从申报到批复用时约半年。（起草说明“待核实”一行请以审批系统记录为准）
4. 对策与问题脱节，或建议无法操作。
   - 误：建议进一步加强统筹协调，形成工作合力。
   - 正：建议由区交通运输局牵头，在2027年6月前调整两条线路早高峰发车间隔，并在两个小区站点增设候车亭。（时间、部门出自调研记录或用户意见；没有的不编，写“建议有关部门……”）
5. 问题写成工作总结，通篇讲成绩。
6. 统计表只逐项罗列，没有汇总数、平均值，或分母没写清（见第三部分第 7 条）。

## 六、单位差异提示

- 党政机关：调研报告常报送领导参阅，篇幅从短；建议对应本机关职权，超出职权的写“建议提请某某研究”。
- 基层：上级来调研时，配合材料是汇报材料，不是调研报告；不以调研之名行督查检查考核之实（`references/_shared/rules/jianfu.md` 第7条）。调研提纲里“轻车简从”“不要求准备汇报材料”等是调研组自己的安排，jianfu.md 表中无此条，不标条号。
- 医院：临床调研涉及患者的，样本信息脱敏；指标口径与病案首页、HIS 一致。
- 高校：教学调研、学生调研不出现学号和姓名；问卷数据注明回收率。
- 国企：市场调研、经营调研涉及未公开数据的，提醒用户确认可否输入联网工具。
