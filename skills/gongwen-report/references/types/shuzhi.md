# 述职报告（含述职述廉、述职述责述廉）

## 一、用途

领导干部或工作人员向组织、主管领导或职工群众报告本人履职情况，用于年度考核、任期考核、干部考察。常见形式：
- 述职报告：只述履职；
- 述职述廉报告：加廉洁自律情况；
- 述职述责述廉报告：领导干部加履行管党治党责任情况。栏目以组织部门、纪检监察机构的通知为准。

述职写的是本人的真实经历。用户没有提供本人事例的，只出提纲和填写指引（`references/_shared/guardrails.md` 第六条第 4 款，模板见 `references/frameworks.md` 第一部分）。

## 二、常见结构框架

框架一：德、能、勤、绩、廉（公务员年度考核常用，依据《中华人民共和国公务员法》第三十五条）

```text
称谓
开头：岗位、任职时间、分管或负责的工作
一、德　二、能　三、勤　四、绩　五、廉
六、存在的不足
七、下一步努力方向
结尾：以上述职，请予评议。
```

框架二：履职情况为主线（中层干部、科室负责人常用）

```text
一、履行岗位职责情况（按分管工作分条）
二、履行管党治党责任情况（述责）
三、廉洁自律情况（述廉）
四、存在的不足
五、下一步努力方向
```

框架三：目标对照式（任期述职、目标责任考核）

```text
一、年度（任期）目标完成情况（逐项对照目标）
二、重点工作推进情况
三、团队管理和队伍建设
四、存在的不足和改进措施
```

## 三、各部分写法

1. 称谓：按述职会议对象，如"各位领导、同志们："；书面报送的可省。
2. 开头：一段，写岗位、任职时间、分管或负责的工作范围。依据（"根据……安排"）只写用户提供的通知名称。
3. 主语：通篇用"本人"或"我"，不用"我们"。写集体工作时，分清三种作用：
   - 本人牵头、主持、具体承办的：写"本人牵头……"；
   - 班子或团队集体完成的：写"在班子集体研究下，本人负责……"；
   - 单位整体成绩：作为背景引用，写"科室全年完成……，本人负责其中……"。
4. 绩：占全文一半以上。写 3～5 件事，每件写本人角色、做法、结果数据，全部来自台账中标有"（本人：角色）"的条目。
5. 述责：写履行管党治党责任的具体动作，如主持研究的次数、开展的谈话、查找和整改的问题。政治性提法只用用户提供的原文，没有的标【待核实：请对照最新原文】，按严谨模式处理。
6. 述廉：只写用户提供的具体做法。"严格遵守……规定，没有……行为"之类的表态由本人确认后再写进正文，未经确认的放在填写指引中。
7. 不足：写本人的具体不足，最好有事例；不写变相表扬。
8. 努力方向：与不足对应，写具体做法。
9. 结尾："以上述职，请予评议。"或按通知要求。

## 四、篇幅建议

工具约定：书面述职 2000～3000 字；述职述责述廉合并的不超过 3500 字。现场述职按时长换算，约 200 字/分钟，5 分钟约 1000 字，8 分钟约 1600 字。通知有字数或时长要求的按通知。

## 五、常见毛病

1. 写成部门总结，通篇"我们""我科"，看不出本人做了什么。
2. 集体成绩据为己有。
   - 误：本人全年完成门诊量4.2万人次。
   - 正：本人作为科室主任，组织全科完成门诊4.2万人次。
3. 不足写成变相表扬。
   - 误：对自己要求过高，有时工作过于投入，忽视了身体健康。
   - 正：对新入职人员带教不够，全年只组织带教讲课2次，未达到科室计划的6次。（取自台账）
4. 述廉部分空表态，或替本人作没有核实的保证。
5. 千篇一律：几个人的述职用同一套结构和句子。多人共用一份台账时，各人只用本人条目，起草说明提示雷同风险。
6. 没有本人事例却生成了完整正文（违反红线第六条）。

## 六、单位差异提示

- 党政机关：领导干部述职述责述廉按组织部门、纪委监委通知的栏目和字数；述责部分的提法按严谨模式核对原文。
- 医院：科室主任述职常按医疗质量安全、学科建设、教学科研、科室管理、医德医风组织；指标用国考口径；年初集中述职（`references/_shared/profiles/units/yiyuan.md` 第七部分）。
- 高校：院系负责人按人才培养、学科建设、科研、师资、党建思政述职；教师述职按教学、科研、社会服务；辅导员谈心谈话记录等须本人亲笔的材料不代写。
- 中小学：教师、班主任述职按教育教学、班级管理、教研、家校沟通；不写学生成绩排名。
- 国企：经营管理人员述职先写经营业绩指标完成情况，再写改革、党建、安全；数据与财务快报、考核结果一致。
- 基层、社区：述职的工作实绩与工作台账一致；居民事例脱敏。
