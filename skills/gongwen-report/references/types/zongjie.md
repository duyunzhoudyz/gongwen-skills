## 一、用途

回顾一定时期的工作，说清做了什么、做成什么样、还差什么、下一步怎么办。用于上报、年度考核、存档、会议交流。

与相邻材料的区别：
- 汇报材料面向特定听众，有时长限制，按对方关切排序；总结是书面记录，按工作板块排序。
- 经验材料只写一两项做得好的工作；总结要写全，问题不能省。
- 述职报告写本人履职；总结写单位或部门整体。
- 上报时一般作为报告的附件，或以报告报送（`references/_shared/rules/doc-types.md` 第四部分 4.1），报送用的报告交 gongwen-draft。

## 二、常见结构框架

框架一：三段式（最常用，适合科室、部门年度总结）

```text
某某科2026年工作总结
开头：时期＋总体情况一两句＋“现将……总结如下。”
一、主要工作和成效
（一）板块一
（二）板块二
（三）板块三
二、存在的问题
三、2027年工作打算
```

框架二：先全貌后做法（适合单位综合年度总结，数据较多时）

```text
一、总体情况（主要指标完成情况，一段或一张表）
二、主要做法
三、问题和不足
四、下一年度工作安排
```

框架三：专项总结（适合某项专项行动、某项任务结束后）

```text
一、基本情况（任务来源、范围、时间、完成进度）
二、主要做法和成效
三、存在的问题及原因
四、下一步工作（含长效机制）
```

半年总结：用框架一或框架二，“总体情况”写明全年目标的完成进度（如“完成全年目标的52%”），下一步写下半年安排。

## 三、各部分写法

1. 开头：一到三句。写时期、主要数字、引出下文。不写“在……的正确领导下”“高度重视、精心组织”。
2. 主要工作和成效：
   - 按职责板块分，不按月份排；一般 3～5 个板块。
   - 每个板块 2～4 段，每段按“做了什么、数据或事例、结果”写。
   - 台账里有年初目标的，写完成情况对比；没有的不编目标值。
   - 小标题写“动作加对象”，标题提炼可交 gongwen-title。
3. 存在的问题：2～4 条。每条写清哪项工作、差在哪、影响是什么。原因能从台账看出的写一句，看不出的不推测。
4. 下一步打算：3～5 条。先对应前面的问题，再写下一年度重点工作。每条写清做什么；有责任部门和时限的写上。台账里有问题、没有对应措施的，按文种常规写出可执行措施，不夹带新数字、项目名。
5. 结尾：总结一般不写结尾段，最后一条打算写完即止，下接落款和日期。

## 四、篇幅建议

以下为工具约定，用户、画像或上级通知有要求的按其执行。

| 总结类型 | 篇幅 |
|---|---|
| 单位年度总结 | 3000～4000 字 |
| 科室、部门年度总结 | 2000～3000 字 |
| 半年总结 | 2000～3000 字 |
| 专项总结 | 1500～2500 字 |

篇幅分配：主要工作和成效约 55%～65%，存在的问题约 10%～15%，下一步打算约 20%～30%。

## 五、常见毛病

1. 流水账，按月份罗列。
   - 误：1月，召开年度工作会。2月，开展业务培训。3月，组织专项检查……
   - 正：（一）规范业务流程。全年修订制度4项，组织培训6期、覆盖120人次，开展专项检查12次，整改问题37个。
2. 成效没有数据。
   - 误：通过一年努力，服务质量明显提升，群众满意度不断提高。
   - 正：全年受理投诉18件，较上年减少9件。（满意度没有数据的，不写“满意度提高”）
3. 问题写成万能句。用户提供了对应事实时才可以用概括句，并且后面要跟事实。
   - 误：思想认识还不够到位，工作创新还有差距，队伍素质有待提高。
   - 正：两名新入职人员尚未取得上岗资质，窗口高峰期排队时间仍在30分钟以上。
4. 问题写成变相表扬。
   - 误：工作标准高、任务重，同志们经常加班加点，休息时间不足。
   - 正：全年有4个月的季度报表晚于规定时间报送，主要原因是数据需要手工汇总。
5. 下一步打算空泛，与问题脱节。
   - 误：进一步加强学习，进一步提升能力，推动各项工作再上新台阶。
   - 正：针对报表手工汇总耗时的问题，一季度上线报表自动汇总功能，由信息科负责。
6. 照搬上年总结或年初计划，只改年份和数字。起草前用户提供上年总结的，对比后在起草说明中提示雷同段落。
7. 开头铺垫形势和意义（`references/_shared/rules/jianfu.md` 第2条）。

## 六、单位差异提示

各单位类型的板块划分、称谓、指标见 `references/units.md`。要点：
- 党政机关：问题部分写真问题，数据与统计部门、上级通报口径一致。
- 医院：科室总结围绕医疗质量、运营效率、学科建设、教学科研；指标名称用所依据考核体系的正式名称，比率变化用百分点。
- 高校：学院总结按人才培养、学科建设、科学研究、师资队伍、党建思政；数据与学校口径一致。
- 中小学：学期为周期，按德育、教学、安全、家校协同组织；不写学生成绩排名。
- 国企：先写经营指标完成情况，再写改革、党建、安全；数据与财务快报一致。
- 基层、社区：与工作台账一致；社区面向居民会议的年度工作报告用大白话，民生实事逐项报告完成情况。

## 七、大会工作报告

职代会、教代会、党代会等代表大会上的工作报告，全文由本 skill 写；党代会党委工作报告叠加严谨模式。年度党建工作报告、书记抓党建述职交 gongwen-party，会上讲话交 gongwen-speech。

1. 结构：按会议通知或用户提供的上届报告；都没有的，用“过去工作回顾（届期或年度）、今后一个时期（或本年度）的目标任务、对代表的要求”三部分，用户要求时加“主要体会”。
2. 回顾部分按本文件第三部分写：数据只来自台账，问题写具体。目标任务部分按 `references/types/jihua.md` 写：目标值来自用户或上级下达，没有的标【待补：目标值】。
3. 提法：党代会报告的指导思想、上级精神等政治性表述只用用户提供的原文，没有的标【待核实：请对照最新原文】，起草说明附提法核对清单。职代会、教代会报告涉及职工、教职工切身利益的事项，审议程序以用户提供的本单位制度为准。
4. 届次、代表人数、会议日期只用会议通知中的；没有的标【待补】。
5. 篇幅：按会议通知或用户要求；没有要求的，工具约定 6000～10000 字，写进所作假设。宣读稿按约 200 字/分钟估算，会议主报告一般不超过 1 小时（`references/_shared/rules/jianfu.md` 第6条）。
