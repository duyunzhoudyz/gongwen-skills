# 经验材料

## 一、用途

总结某项工作的做法和成效，用于经验交流会发言、上报、刊发。特点是只写一两项做得好的工作，做法要具体到别人能照着做。

与总结的区别：总结写全面，问题不能省；经验材料写重点，一般不写问题，但成效必须有数据。

## 二、常见结构框架

框架一：做法加成效（最常用）

```text
主标题：概括做法或成效
副标题：——某某单位推行某某工作的做法
开头：一句话交代单位、做法和成效。
一、做法一
二、做法二
三、做法三
四、取得的成效（也可分散写在各条做法中）
```

框架二：问题、做法、成效

```text
开头：过去存在什么问题（一段，取自台账）
一、主要做法（分条）
二、取得的成效（与开头的问题对应）
三、几点体会（可选）
```

框架三：交流发言版

```text
称谓
开头：一两句，交代单位和交流的主题
主体：做法分条，每条讲一个具体事例
结尾：一句话，不写表态
```

## 三、各部分写法

1. 标题：主标题概括做法或成效，副标题用破折号引出单位和工作（副标题中的破折号属于公文正当写法）。小标题提炼、多套标题比较可交 gongwen-title。
2. 开头：一句话交代单位、做法、成效，不写背景铺垫。
   - 正：某街道推行“一站式”矛盾纠纷调处，今年1—10月调处纠纷126件，调处成功率【待补：成功率】。
3. 做法：写可复制的具体动作，如机制、流程、分工、工具、时间节点。每条做法最好配一个事例。
4. 成效：用数据，写清前后对比。没有数据的标【待补】，不用"成效显著""广受好评"顶替。
5. 体会：可选，一两条，从本单位的做法中归纳，不拔高为普遍规律。

## 四、篇幅建议

工具约定：交流发言 1500～2500 字（发言时长已知的按约 200 字/分钟换算）；上报经验材料 2000～3000 字；改写成政务信息的，篇幅按信息部门要求（信息交 gongwen）。

## 五、常见毛病

1. 拔高定性，没有依据。
   - 误：开创了全国基层治理的先河，为全省提供了可复制可推广的样板。
   - 正：删去。确有上级推广的，写"该做法被某某（用户提供的文件名）转发推广"。
2. 编造成效数据。用户说"加点数据显得有说服力"时，只用台账里的数，其余标【待补】，并在起草说明中说明原因（`references/_shared/guardrails.md` 第二条）。
3. 做法与成效不对应：写了三条做法，成效只有一句总括。
4. 照搬其他单位的经验表述。用户提供的外单位材料只作结构参考，不复制其做法和数据。
5. 把留痕当成效：拍照数量、学习笔记、点赞转发量、领导批示次数不作为工作成效（`references/_shared/rules/jianfu.md` 第8条）。
6. 做法空泛。
   - 误：坚持高位推动，强化统筹协调，形成工作合力。
   - 正：街道主任每周一召集综治、司法所、派出所会商一次，当周纠纷当周分流。（取自台账）

## 六、单位差异提示

- 基层、社区：经验多来自一线具体做法，用事例说话；群众事例中的姓名脱敏，使用前确认已获本人同意。
- 医院：临床经验涉及疗效的，不写"治愈率100%""根治"等表述；患者信息脱敏。
- 高校：教学改革经验的数据与学校口径一致；学生事例脱敏。
- 中小学：不以学生成绩排名作为成效。
- 国企：党建经验写清对经营的具体作用，避免党建与经营"两张皮"；涉及未公开经营数据的提醒用户。
