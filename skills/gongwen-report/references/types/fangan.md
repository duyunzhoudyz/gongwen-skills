# 实施方案

## 一、用途

对落实某项任务作出具体安排，写清目标、任务分工、时间步骤和保障，常以通知印发（印发通知交 gongwen）。专项行动方案、活动方案、整改方案可参照本结构。

与计划的区别：计划写一段时间内的全部工作；实施方案只针对一项任务，重在怎么组织实施。

## 二、常见结构框架

框架一：标准式

```text
某某关于开展某某工作的实施方案
开头：为……，根据《……》（用户提供），结合本单位实际，制定本方案。
一、工作目标
二、主要任务（每项写明牵头部门、配合部门、完成时限）
三、实施步骤（分阶段，写起止时间）
四、保障措施
```

框架二：任务清单式（任务多、分工细时）

```text
一、工作目标
二、重点任务（正文简述）
三、时间安排
四、工作要求
附件：任务分解表（序号、任务、牵头、配合、时限、成果形式）
```

框架三：分阶段式（活动、专项行动）

```text
一、工作目标
二、实施步骤
（一）动员部署阶段（起止时间）：任务……
（二）组织实施阶段（起止时间）：任务……
（三）总结验收阶段（起止时间）：任务……
三、工作要求
```

## 三、各部分写法

1. 开头：一句话写依据和目的，依据只写用户提供的上位文件名称。不写形势背景和重要意义（`references/_shared/rules/jianfu.md` 第2条）。
2. 工作目标：目标值来自上位文件或用户；没有的写【待补：目标值】。
3. 主要任务：
   - 每项任务写"任务、牵头部门、配合部门、完成时限、成果形式"，台账缺的标【待补】；
   - 用户提供上位文件的，逐条转化为本单位的具体措施，不照抄原文（JF-04）；本单位措施缺失的标【待补：本单位落实措施】。
   - 误：深入推进营商环境优化，持续提升政务服务效能。（上位文件原句）
   - 正：6月底前，将企业开办涉及的5个事项整合为一个窗口办理，由政务服务科牵头。（事项数、时间、部门取自用户材料）
4. 实施步骤：每个阶段写起止时间和本阶段完成的任务，与主要任务对应。
5. 保障措施：两三条，有具体主体和动作，不写"高度重视、加强领导"空表态（JF-03）。
6. 不加的内容（JF-05、JF-06、JF-07）：默认不写"请于某日前报送贯彻落实情况""各单位要制定配套方案""纳入年度考核""一票否决""签订责任状"。用户坚持要写的，照写，并在起草说明中提示减负规定的相关要求。
7. 措辞：用"要""于某日前完成"，不用"建议""尽量""可以考虑"（`references/_shared/style/defensive.md` 第五部分）。

## 四、篇幅建议

部署专项工作或具体任务的文件，党政机关、基层、社区一般不超过 4000 字（`references/_shared/rules/jianfu.md` 第2条）。工具约定：一般实施方案 2000～3500 字；医院、学校、国企的内部方案超过 4000 字时在起草说明中提示。任务分解表作为附件另计。

## 五、常见毛病

1. 照搬照抄上位文件（见第三部分第 3 条）。
2. 任务没有责任和时限。
3. 步骤与任务脱节：任务写了五项，步骤里只出现两项。
4. 保障措施比任务还长。
5. 层层要材料。
   - 误：各科室要于每月25日前报送工作进展情况，并制定本科室具体实施方案。
   - 正：删去；确需掌握进度的，写"办公室每月从业务系统中调取进度数据"（用户提供了此类安排的）。
6. 部署内容用建议式。
   - 误：建议各单位可以考虑建立周调度机制。
   - 正：各单位要建立周调度机制。

## 六、单位差异提示

- 党政机关：部门方案面向下级党委政府的，不写指令性要求（`references/_shared/rules/jianfu.md` JF-16）；需会签的提示用户。
- 基层：任务拆到村（社区）、到人、到时间，但不把执法、招商等责任转嫁给村（社区）（JF-12）。
- 医院："三重一大"事项的方案，提示用户在起草说明中写明须经党委会研究决定，不以党政联席会议代替党委会议。
- 高校：涉及教职工切身利益的，提示需经教代会审议；学术事项提示需经学术委员会审议。
- 中小学：进校园活动按白名单；不给教师摊派与教育教学无关的任务。
- 国企：重大事项方案提示党委前置研究；涉及职工切身利益的提示职代会审议。
