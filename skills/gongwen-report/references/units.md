# 单位差异：本 skill 的调整项

先读 `references/_shared/profiles/units/` 下对应的单位类型画像，再按本文件调整。装有对应行业包时，本行业专用文书交行业包，本文件只管通用文书；未安装的，专用文书也按本文件和单位画像写，不拒绝。取值顺序：本单位制度文件（用户提供）优先，其次是单位画像 `.gongwen/单位画像.md`，再次是单位类型画像和本文件，最后是国家规则基线。本单位制度与国标不一致的，按本单位制度写，并在起草说明中提示差异。

篇幅超限级别按 `references/_shared/rules/jianfu.md` 第一部分的工具约定：减负规定第1、2条直接约束党政机关；医院、学校、国企的内部发文不受字数条款直接约束，超限只作提示。

## 二、党政机关

1. 总结：按“主要工作和成效、存在问题、下一步打算”；问题写真问题，不写成变相表扬。数据与统计部门、上级通报口径一致，台账来源注明。
2. 工作要点、实施方案：总体要求的提法按严谨模式核对原文；措施写到“谁来做、做什么、何时完成”。
3. 汇报材料：领导调研汇报按领导关注事项排序；需要审批的事项另行请示。
4. 述职述责述廉：领导干部年底至年初集中述职，栏目按组织部门和纪委监委通知；述责部分逐条核对提法。
5. 党代会党委工作报告全文由本 skill 写，叠加严谨模式（`references/types/zongjie.md` 第七部分）；年度党建工作报告交 gongwen-party。
6. 节点：11—12 月年终总结和次年计划；1—2 月工作要点。

## 三、基层

装有 gongwen-grassroots 时，迎检汇报和自查交行业包，本节只管通用文书。

1. 迎检汇报：按检查通知或评分细则逐项对应，每项写落实情况和佐证材料名称；“已完成”须有台账佐证。
2. 总结：数据与工作台账一致；拍照留痕、学习笔记、点赞转发量不写成工作成效（减负规定第8条、第14条）。
3. 实施方案：任务拆到村（社区）、到人、到时间，不向村（社区）转嫁执法、招商等责任，不写“签订责任状”“制度上墙”。
4. 汇总模式最常用：多个站所、村（社区）报来的材料口径不一，口径冲突表必做。
5. 篇幅：短、实、准，先写结论和数据。

## 四、社区

装有 gongwen-grassroots 时，村（居）务公开、为民办实事清单等专用文书交行业包，本节只管通用文书。

1. 居委会向居民会议的年度工作报告：语言通俗，一句话一件事；民生实事逐项报告完成情况（做了什么、花了多少、惠及多少户），财务数据只用用户提供的。
2. 对街道的总结、汇报：用数据和事例说话，事例只来自用户提供的记录。
3. 居民姓名、电话、住址、低保和救助情况一律脱敏；使用居民事例前提醒用户确认已获本人同意。
4. 不写超出社区职权的承诺。

## 五、公立医院

装有 gongwen-hospital 时，等级评审自评、绩效考核自评分析、医疗质量分析报告、科室主任述职交行业包，本节只管通用文书。

1. 科室总结的常用指标：门急诊人次、出院人次、手术量和四级手术比例、平均住院日、CMI、次均费用、抗菌药物使用强度、不良事件上报、院感、满意度、教学科研。只写用户提供的，缺失标【待补】，台账来源注明系统（HIS、病案首页、手术麻醉系统）。
2. 指标名称用所依据考核体系的正式名称：绩效考核写“出院患者四级手术比例”，等级评审写“出院患者四级手术占比”，不写“大手术比例”；比率的变化用“百分点”；同比、环比写明基期。
3. 患者隐私：姓名、病案号、住院号、床号与姓名组合一律脱敏，写“患者张某，男，56岁”。
4. 党建内容写对业务的具体作用，不写空泛的“党建引领”，避免两张皮。
5. 述职：科室主任年初集中述职，按医疗质量安全、学科建设、教学科研、科室管理、医德医风组织。
6. 方案：涉及“三重一大”的提示须经党委会研究决定。
7. 节点：1 月绩效考核自评和科室主任述职；7 月半年总结；11—12 月年终总结。

## 六、高校

装有 gongwen-university 时，审核评估自评报告、学院年度工作总结交行业包，本节只管通用文书。本科教学质量报告、就业质量年度报告由本 skill 写，数据口径按学校状态数据库和就业部门的统计。

1. 学院总结按人才培养、学科建设、科学研究、师资队伍、党建思政组织；招生、就业、科研项目和经费数据只用用户提供的，并与学校口径（高基报表、状态数据库）一致。
2. 学院工作要点逐条承接学校党政工作要点。
3. 学生信息（学号、成绩、心理健康、家庭经济困难认定、处分）不进正文；学生事例脱敏。
4. 意识形态相关表述按严谨模式，以用户提供的权威原文为准。
5. 辅导员谈心谈话记录、听课记录等须本人亲历亲笔的材料，只出提纲和填写指引。
6. 节点：7 月学期总结；12 月至次年 1 月年度考核、述职、学院年度总结；2—3 月党政工作要点。

## 七、中小学

装有 gongwen-k12 时，学期工作计划和总结、班主任计划和总结、督导评估自评报告交行业包，本节只管通用文书。

1. 以学期为周期：学期初写计划，学期末写总结；按德育、教学、教研、安全、家校协同、后勤组织。
2. 学生人数、活动次数、质量数据只用用户提供的，与教育事业统计口径一致。
3. 不写学生成绩排名；学生姓名、家庭情况、心理健康、特殊教育需求不进正文。
4. 班主任计划总结具体到本班；学生评语不归本 skill（行业包未安装时，只出评语框架，用户提供每名学生的具体表现后再写）。
5. 计划中不给教师摊派与教育教学无关的任务。

## 八、国有企业

装有 gongwen-soe 时，经营分析报告、ESG 和社会责任报告、党建与经营融合经验材料交行业包，本节只管通用文书。

1. 年度工作报告、总结：先写经营指标完成情况（收入、利润总额等），再写原因和措施；改革、党建、安全分节写。指标完成值只用用户提供的，与财务快报、年报一致；同比、环比写明基期。
2. 汇总各部门材料时，数据口径打架最常见，口径冲突表必做。
3. 商业秘密：未公开的财务数据、投标报价、客户信息、技术参数，提醒用户确认可否输入联网工具；上市公司未披露的重大信息不进入任何对外材料。
4. 不写无依据的“行业第一”“国内领先”。
5. 方案：重大事项提示党委前置研究；涉及职工切身利益的提示职代会审议。
6. 述职：经营管理人员先写经营业绩，与考核结果一致。
7. 专业术语（如资产负债率、EBITDA）保留，首次出现可加简短说明。
