# 单位类型画像：高校

适用于公办普通高等学校，包括本科院校和高职院校。

## 一、规则基线与参照依据

| 依据 | 适用方式 | 要点 |
|---|---|---|
| 《高等教育法》第三十九条 | 直接适用 | 实行中国共产党普通高等学校基层委员会领导下的校长负责制 |
| 《中国共产党普通高等学校基层组织工作条例》（2021 年修订） | 直接适用 | 党委全面领导学校工作，实行民主集中制，重大问题集体讨论决定 |
| 中办《关于坚持和完善普通高等学校党委领导下的校长负责制的实施意见》 | 直接适用 | 党委与校长的职责划分；党委常委会和校长办公会的议事规则 |
| 《学校教职工代表大会规定》（教育部令第 32 号） | 直接适用 | 教代会每学年至少召开一次 |
| 学校章程、校内公文处理办法、议事规则 | 用户提供时优先 | 文种范围、代字、校内请示程序 |
| 《党政机关公文处理工作条例》、GB/T 9704-2012 | 参照 | 多数高校办法写明参照执行 |

## 二、发文体系

| 发文主体 | 发文机关标志示例 | 发文字号示例 |
|---|---|---|
| 学校党委 | 中共某大学委员会文件 | X大党发〔2026〕N号 |
| 学校（行政） | 某大学文件 | X大发〔2026〕N号 |
| 党委办公室、校长办公室（或合署的党政办公室） | 办公室版头 | X大党办发、X大校办发〔2026〕N号 |
| 职能部门、学院 | 部门版头或白头 | 以校内规定为准 |

代字以校内规定为准，上表只示意结构。

1. **两级公文**：校级公文事关全校规章制度、重要部署，一般经党委常委会、校长办公会审议或校领导同意，由校领导签发；部门公文处理本单位职责内的常规业务，由部门负责人签发。
2. **部门行文边界**：职能部门可就职权内事项向校内其他单位行文；涉及多个单位、未协商一致的不得行文。校内单位一般不得以本单位名义对校外正式行文。
3. **校内请示**：学院、部门向校领导请示用校内请示报告单或签报，经党政办公室审核后呈送；一事一报，需几位校领导批示的只报一份，由办公室协调。
4. **文种范围**：有的高校办法只列 11 种（决议、决定、通告、意见、通知、通报、报告、请示、批复、函、纪要），以本校办法为准。
5. **对外**：向教育部门请示、报告；与地方政府部门、企业、其他高校用函。

## 三、常用文种与典型材料清单

| 频次 | 法定文种 | 常用材料 |
|---|---|---|
| 几乎每周 | 通知、纪要 | 党委常委会和校长办公会纪要、校内请示、新闻稿、工作简报 |
| 每月或每季 | 请示、报告、函、通报 | 项目申报材料、专项工作报告、检查通报 |
| 每学期或每年 | 报告、意见 | 党政工作要点、学期计划与总结、书记校长讲话（开学、毕业、教代会）、教代会工作报告、学院年度总结、述职、本科教学质量报告、毕业生就业质量年度报告 |
| 按周期或事件 | 报告、决议 | 党代会报告；本科教育教学审核评估自评报告；学科评估材料；“双一流”建设相关材料；巡视整改材料 |

## 四、决策程序与行文特点

1. **党委全委会、党委常委会**：讨论决定学校改革发展、基本管理制度、内部组织机构设置及负责人人选等重大事项。
2. **校长办公会议（校务会议）**：学校行政议事决策机构，由校长主持。
3. **学术委员会**：学校最高学术机构，统筹行使学术事务的决策、审议、评定和咨询等职权（《高等学校学术委员会规程》），学术类议题须先经其审议。
4. **教代会**：审议学校发展规划、涉及教职工切身利益的事项。
5. **“三重一大”**：按教育部关于直属高校落实“三重一大”决策制度的要求和本校实施办法，集体讨论决定。
6. **院系层面**：通过党组织会议和党政联席会议研究决定，以校内规定为准。
7. **行文特点**：重要文件多轮征求意见（学院、部门、教代会、民主党派等）；学院数据须与学校口径一致。

## 五、术语表

| 术语 | 解释 |
|---|---|
| 党委领导下的校长负责制 | 高校领导体制，党委统一领导学校工作，校长依法独立负责地行使职权 |
| 立德树人 | 教育根本任务的规范表述 |
| 三全育人 | 全员育人、全过程育人、全方位育人 |
| 审核评估 | 本科教育教学审核评估；新一轮方案为教督〔2021〕1号，“两类四种”，自评报告是核心材料；后续周期以教育部文件为准 |
| 合格评估 | 面向新建本科院校的本科教学工作评估 |
| 学科评估 | 按一级学科对学科整体水平的评估 |
| 双一流 | 世界一流大学和一流学科建设 |
| 本科教学质量报告 | 本科高校按年度发布的教学质量报告，时间按教育部门当年通知 |
| 就业质量年度报告 | 高校按年度发布的毕业生就业质量报告 |
| 高基报表 | 高等教育事业基层统计报表，是学校各类材料数据口径的基准 |

| 课程思政 | 在各类课程中融入思想政治教育 |

| 校院两级管理 | 学校与学院分级管理，材料中分清校级和院级职责 |

## 六、红线与禁忌

1. 意识形态：涉及政治、民族、宗教、港澳台、历史问题的表述以权威原文为准；讲座、论坛、出版物、网络平台材料从严把关。
2. 学生隐私：学号、身份证号、成绩、心理健康、家庭经济困难认定、违纪处分等信息不得超范围公开；资助公示只公开规定事项。
3. 须本人亲历或亲笔的材料，如辅导员谈心谈话记录、听课记录，只出提纲和填写指引，不生成正文；思想汇报交 gongwen-party，本人给了要点的可以整理成文，没有要点的只出提纲。
4. 评估自评报告、质量报告、就业报告中的数据须与状态数据库、高基报表一致，不得编造或“修饰”。
5. 项目申报材料不得编造成果、论文、获奖。

## 七、年度写作节点

| 时间 | 节点与材料 |
|---|---|
| 2–3 月 | 春季开学；新学期工作会议讲话；党政工作要点 |
| 3–4 月 | 教代会（时间以学校安排为准） |
| 5–6 月 | 毕业典礼讲话；就业工作材料；招生宣传材料 |
| 7 月 | 学期总结；暑期工作会或战略研讨会材料 |
| 9 月 | 开学典礼讲话；迎新；教师节表彰 |
| 10–11 月 | 本科教学质量报告（按省级教育部门通知）；年度统计数据报送 |
| 12 月–次年 1 月 | 年度考核、述职、学院年度总结；就业质量年度报告（多在年底前后发布） |
| 按周期 | 党代会（每届）、审核评估、学科评估、巡视整改 |

## 八、版式差异

1. 校级公文用红头，参照 GB/T 9704-2012；部门公文用部门版头或白头，以校内规定为准。
2. 校内请示用学校统一的请示报告单格式，含主办单位、会签单位、拟办意见、校领导批示栏。
3. 评估自评报告、项目申报书按评估方或项目方模板，不套公文格式。

## 九、文风特点

1. 政治性和学术性并重；校级文件措辞规范，学术材料用学术语言。
2. 开学、毕业讲话面向学生，口语化，少套话，可用具体人和事（由用户提供）。
3. 自评报告用数据说话，问题部分写实。

## 十一、行业包详版要点（回灌）

本部分摘自行业包 gongwen-university 的详版画像 profile-detail.md（出处见该文件第七部分），供未装行业包时核心 skill 使用；装有行业包的，以行业包为准。

（一）学校类型差异。

| 类型 | 对写作的影响 |
|---|---|
| 以建设世界一流大学为目标的高校 | 审核评估多为第一类；学院总结中学科、科研板块比重高 |
| 已参加上轮审核评估的本科高校 | 审核评估第二类第1、2种；应用型高校突出产教融合、实践教学 |
| 新建本科院校 | 先参加合格评估，原则上获“通过”结论5年后参加审核评估（第二类第3种） |
| 高职院校 | 不参加本科审核评估；评估、建设类材料按职业教育主管部门当年文件 |
| 民办高校 | 设董事会、理事会等决策机构，同时设党组织；决策程序和发文主体以学校章程为准 |

依据：《普通高等学校本科教育教学审核评估实施方案（2021—2025年）》（教督〔2021〕1号），后续周期以教育部文件为准。

（二）校内层级与主语。学校材料用“学校”“我校”，学院材料用“学院”“我院”。同一事实在不同层级的写法不同：学院总结写“学院获批省级一流课程3门”，学校材料写“学校获批省级一流课程X门（其中某学院3门）”。学院引用学校数据注明“学校口径”；学校汇总学院数据用职能部门核定数，不把学院自报数直接相加。

（三）程序写法。“经学校党委常委会研究”“经学院党政联席会议研究”“经第X届教代会第Y次会议讨论通过”之类，只在用户材料写明时才写；材料没写的，不补写“经研究同意”，在起草说明中提示补充。学术类事项写明先经学术委员会审议；教代会讨论学校工作报告、财务工作报告和与教职工利益直接相关的方案（《学校教职工代表大会规定》第七条）。

（四）称谓。首次出现写全称（“中共某大学委员会”“某大学”），之后可用“学校党委”“学校”；校领导写职务不写姓名；学生写“某同学”“一名研究生”；校内机构名称按本校规范名称，前后统一。
