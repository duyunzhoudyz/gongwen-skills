# 文种速查卡

网页提示词版没有 `references/doc-types/` 下的细则，按本卡起草。条款均指《党政机关公文处理工作条例》。所有卡片共用四条：事实只用用户给的，缺的标【待补】；结语与文种对应；版头要素（发文字号、签发人）不写进正文；篇幅只有上限，事实少的写短，不为凑篇幅扩写。

## 目录

一、通知　二、请示　三、报告　四、函　五、通报　六、批复　七、意见　八、签报　九、决定、通告、公告　十、决议、命令、公报、议案

## 一、通知

部署性：
```text
某某关于做好……工作的通知
各……：
为……，根据……（用户给的依据），现将有关事项通知如下。
一、工作任务（每项写做什么、谁来做、何时完成）
二、工作要求（只写有具体动作的内容）
署名、成文日期、（联系人：……，电话：……）
```
会议：名称、时间（写到几时几分）、地点（写到房间）、参会人员（写范围和职务）、会议内容，五项必备；回执方式和截止时间、有关要求、联系人按用户给的写。参会名单作附件，联网工具中只写职务。
转发：标题去掉本文的"关于"，如"某区教育局转发省教育厅关于做好冬季校园安全工作的通知"；被转发的是意见的写"……关于……实施意见的通知"。只加了转发语的中间层省略；批转、政府转发部门文件的那一层保留。正文："现将《……》（文号）转发给你们，请结合实际认真贯彻执行。"本级要求只写用户给的本地措施，不复述原文。
印发："现将《……》印发给你们，请结合实际认真贯彻执行。"材料本身由其他 skill 起草。
不默认写：报送落实情况、纳入考核、一票否决、留痕要求。

## 二、请示

```text
某某关于……的请示
（一个上级机关）：
缘由：依据 → 现状（数据）→ 必要性
事项：批什么、拨多少、按什么方案（打算用"拟"，不用"决定"）
本单位意见：两个以上方案时写倾向和理由
妥否，请批示。
附件、署名、成文日期、（联系人：……，电话：……）
```
- 一文一事；主送一个；不抄送下级；不送领导个人。
- 标题不写"请示报告""关于申请……的请示"。
- 转报下级请示要有本机关意见；已经办了的事，如实写明并"恳请予以追认"，或改写报告。
误：我们考虑了几种办法，各有利弊，请领导研究。
正：恳请县政府拨付敬老院改造资金【待补：金额】万元，用于……。妥否，请批示。（金额、用途照用户材料写，没给的标【待补】）

## 三、报告（就一件事）

```text
情况报告：基本情况（时间、地点、经过、伤亡和损失）→ 处置情况 → 原因（未查明的写"原因正在调查"）→ 下一步 → 特此报告。
答复报告：引叙询问 → 逐项答复，先结论后依据 → 特此报告。
报送报告：根据……要求，现将《……》报上。→ 特此报告。
```
- 不夹带请示：出现"请批准""请拨付""妥否，请批示"的，抽出另写请示。
- 不推测原因和损失；个人信息脱敏。
- 突发情况首报不等原因查清，先报已掌握的情况；起草说明提示用户约定续报时间。
- 全面工作报告交 gongwen-report，落实情况报告交 gongwen-implement，整改报告交 gongwen-rectify。

## 四、函

```text
某某关于商请……的函
某某：
为……，现就……商请如下：（事项：要对方给什么、做什么、什么时候）
请予支持。（询问：请予函复。请批：请予审批。）

复函：你单位《关于……的函》（文号）收悉。经研究，现函复如下：一、（先给结论）……特此函复。
```
- 对象与本单位不相隶属；有隶属关系的上级用请示。
- 语气平和：不用"务必""必须"，也不写"万望""不胜感激"；不用"请批示"。
- 以内设机构名义对外发函的，改以本单位或办公室名义。

## 五、通报

```text
表彰：事实（具体做法、数据）→ 评价（与事实相称）→ 经……研究，决定对……予以通报表彰 → 号召。附件：名单。
批评：事实 → 定性（违反了什么规定）→ 处理决定 → 要求 → 特此通报。
情况：情况和数据 → 主要问题 → 要求 → 特此通报。
```
- 研究主体、表彰决定、处理决定只写用户给的，没有的标【待补：处理决定】。
- 不编事迹细节，不写"全市领先"；不按月、按季排名通报。
- 名单作附件，删去身份证号、手机号；批评涉及个人的写"张某"。

## 六、批复

```text
某某关于（同意）……的批复
（报来请示的机关）：
你单位《关于……的请示》（文号）收悉。经研究，现批复如下：
一、同意（原则同意、不同意）……
二、条件、要求或不同意的理由
三、执行要求（时限、程序）
此复。
```
- 批复意见由用户定；用户没说的标【待补：批复意见（同意、原则同意或不同意）】。
- 表态放在最前；原则同意写条件，不同意写理由；请示有几项就回应几项。
- 不写"原则上可行，待条件成熟后再议"。来文是函的用复函。

## 七、意见

下行：开头一两句 → 总体要求（目标，从简）→ 主要任务（措施、责任主体、时限）→ 保障措施（精炼）。用"要""应当"，不用"建议""可以考虑"。以上级文件为依据、要逐条拆任务的交 gongwen-implement。
上行：问题 → 建议（可以用"建议"）→ "以上意见如无不妥，请批转……执行。"按请示程序办。
平行：供对方参考，可以写"以上意见供参考"。

## 八、签报

```text
关于……的请示（汇报类：关于……情况的报告）
主送：一位领导的职务（如"分管院领导"）
缘由 → 事项（买什么、多少、多少钱、怎么采购）→ 本部门意见 → 会签情况
妥否，请批示。
落款：主办部门、日期
```
- 一签一事；只报一位领导，按本单位流程经办公室报送。
- 会签意见只写用户给的；未会签的列出需会签部门。
- "三重一大"事项写明须按本单位决策程序上会；国企写明是否属于党委前置研究事项。
- 医院：科室起草，职能部门审核，相关部门会签，报分管院领导。高校：学院起草校内请示报告单，党政办公室审核编号后呈送。国企：本部部门起草，相关部门会签，报分管领导。

## 九、决定、通告、公告

决定：动笔前核对是否重要事项、是否须会议表决（须表决的用决议）、发文权限。研究的会议和时间、称号、奖惩依据只写用户给的。党纪处分、政务处分不起草。
通告：发文机关须对事项有法定职权；社区、学校、医院不发约束公众的通告，改用通知或温馨提示。结构：依据 → 范围 → 时间 → 对象 → 行为要求 → 罚则依据 → 施行日期 → 特此通告。
公告：只用于向国内外宣布重要事项或法定事项；停水停电、施工、考试等局部事项用通知或通告。

面向群众的文书逐句查：
| 表述 | 处理 | 依据 |
|---|---|---|
| 罚款、拘留、吊销 | 不能自设；写"由某某机关依照《……》处理"，依据来自用户 | 《行政处罚法》第十六条 |
| 查封、扣押、强制拆除 | 删除 | 《行政强制法》第十条、第十三条 |
| 断水断电 | 删除 | 《行政强制法》第四十三条第二款 |
| 取消低保、停发补贴、影响入学 | 删除 | 国办发〔2018〕37号 |
| "一律""严惩""后果自负" | 改为说明性语言 | 措辞层级 |

## 十、决议、命令、公报、议案

只给结构说明、要点清单和需要用户提供的信息清单，不起草全文。国企董事会议案、决议按公司章程办理，有 gongwen-soe 的交给它。
