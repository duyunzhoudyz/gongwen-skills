## 一、四问定文种

按顺序回答，每问都要有答案；用户的话里能推断的不再问。

| 问 | 选项 | 从哪里找答案 |
|---|---|---|
| 1. 以谁的名义发 | 本单位、办公厅（室）、内设部门、联合发文 | 用户原话；单位画像"发文机关标志" |
| 2. 写给谁 | 有隶属关系的上级、下级；不相隶属的单位；本单位领导；社会公众 | 用户原话；不清楚的问一次 |
| 3. 要办什么事 | 请求批准、请求指示、汇报、部署、告知、表彰批评、商洽、询问、答复 | 用户原话中的动词："要钱""申请"是请求批准；"说明情况"是汇报；"让他们做"是部署 |
| 4. 本单位能用哪些文种 | 法定文种、签报等内部文种 | 单位画像"可用文种""内部文种"；没有画像按第五部分默认值 |

用问 2、问 3 查 `references/_shared/rules/doc-types.md` 第六部分决策表，再用问 1、问 4 过滤。

内设部门名义的判断：内设机构除办公厅（室）外不对外正式行文（《党政机关公文处理工作条例》第十七条第三款）。内设部门要对外办事的，改以本单位或办公室名义发；向本单位领导报告的，用签报。企事业单位以本单位制度为准。

## 二、口语说法速判表

| 用户可能这样说 | 文种 | 判断理由 |
|---|---|---|
| "找区财政局要点钱""跟医保局申请调整" | 函 | 不相隶属的审批部门，请求批准用函 |
| "向县政府要钱""请主管局批一下" | 请示 | 有隶属关系的上级，请求批准 |
| "科室想买台设备，报院长批" | 签报 | 内设部门向本单位领导请求批准 |
| "跟上级说一下事情经过""领导批示要我们说明情况" | 报告 | 汇报、答复询问，不需要批复 |
| "让下面各单位做……""布置一下……工作" | 通知 | 部署一项具体工作 |
| "通知大家开会""办个培训班" | 通知（会议） | 会议通知 |
| "把市里的文件转下去" | 通知（转发） | 转发上级公文 |
| "把我们定的方案发下去" | 通知（印发） | 印发本单位材料 |
| "表扬一批先进""通报一下这次检查发现的问题" | 通报 | 表彰、批评、告知情况 |
| "授予……称号""给予……奖励" | 决定 | 重大奖惩 |
| "下面报来的请示，领导同意了，回个文" | 批复 | 答复下级请示 |
| "兄弟单位来函问我们……，回复一下" | 复函 | 答复不相隶属单位 |
| "告诉老百姓这段时间不能……" | 通告（有职权的机关）；通知、温馨提示（社区、学校、医院） | 面向公众的遵守事项，看发文主体有无职权 |
| "就……问题提个指导性的文件" | 意见 | 一整套见解和处理办法 |

## 三、易混情形补充

1. 一件事里既要汇报又要请求：汇报部分写报告，请求部分单独写请示。只要有一项需要上级表态，这一项就单独成请示（第十五条第（四）项）。
2. 不相隶属单位，要对方周知或执行某事：一般用函；对方需要执行、本单位有业务指导职权的，可用通知（`references/_shared/rules/doc-types.md` 第六部分）。拿不准的用函。
3. 表彰用通报还是决定：授予荣誉称号、给予奖励的正式决定用决定；一般表扬、推广经验用通报（实务）。用户只说"表彰"的按通报写。
4. 通告还是通知：社区、学校、医院、企业不面向社会发布约束公众的通告，改用通知或温馨提示，转达有权机关的规定（见 `references/doc-types/tonggao.md` 第一部分）。
5. 请示还是意见（上行）：请上级批准一个具体事项用请示；向上级提出一套工作建议、请上级批转或采纳用意见。
6. 批复还是通知：答复下级的请示用批复；下级报来的是报告，需要回应的用通知或复函，不用批复。
7. 函的答复还是批复：来文是函，用复函，即使本单位是审批部门（如财政部门答复其他部门的请批函），也用复函或审批函。

## 四、用户指定的文种不当时

1. 先指出，写明依据。例："您说写请示，但区财政局和区人社局没有隶属关系，请求批准应当用函（《党政机关公文处理工作条例》第八条第（十四）项）。我按函来写。"
2. 按正确文种起草，在起草说明"所作假设"中写明改动理由和条款。
3. 用户坚持原文种的，按用户要求写，起草说明保留这条提示。
4. 教学模式在写作要点中多讲一句：这两个文种的区别在哪里，下次怎么判断。

## 五、本单位能用哪些文种

1. 有画像的，按画像"可用文种""内部文种"。
2. 没有画像的默认值：
   - 党政机关、基层：15 种法定文种，命令、公报、议案、决议按使用主体限制。党政机关内设部门向领导用签报或呈批件；基层站所、办公室向乡镇（街道）领导用请示单或签报，以画像为准。
   - 社区：一般不用红头文件；对上报送"申请"（请示性质）、情况报告，对居民用通知、告知书、温馨提示、公示。
   - 公立医院、高校、国有企业：不用命令、公报、议案；公告慎用；有签报。高校参照本校公文处理办法，有的只列 11 种（`references/_shared/rules/doc-types.md` 第五部分）。
   - 中小学：常用通知、请示、报告、函；对家长用致家长的信、通知。
3. 采用默认值的，在起草说明"所作假设"中写明。
