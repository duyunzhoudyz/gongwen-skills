# 批复

适用：答复下级机关请示事项（《党政机关公文处理工作条例》第八条第（十二）项）。下行文，主送报来请示的机关。通用要点见 `references/_shared/rules/doc-types.md` 2.12。

## 一、动笔前确认三件事

1. 来文是不是请示。来文是下级的请示，用批复；来文是不相隶属单位的函，用复函（`references/_shared/rules/doc-types.md` 7.7）；来文是报告的，一般不批复，需要回应的用通知或复函。
2. 批复意见是什么。同意、原则同意、部分同意还是不同意，由用户（领导）决定，本 skill 不替用户拿主意。用户没说的，问一次；用户说"直接写"的，表态处写【待补：批复意见（同意、原则同意或不同意）】，其余部分照常起草。
3. 本机关有没有权限批。超出本机关权限、需报上级决定的，告诉用户，批复中写明"该事项需报……审批"，或改为转报上级（见 `references/doc-types/qingshi.md` 第五部分）。

## 二、结构骨架

```text
标题：某某关于同意……的批复（或：某某关于……的批复）
主送：报来请示的机关：
引叙：你单位《关于……的请示》（某发〔2026〕N号）收悉。经研究，现批复如下：
一、表态（同意、原则同意、部分同意或不同意）
二、条件、要求或理由
三、执行要求（时限、程序、报备）
结语：此复。（或：特此批复。）
署名
成文日期
```

## 三、表态的写法

| 态度 | 写法 | 必须同时写 |
|---|---|---|
| 同意 | "同意你单位……" | 执行要求：按什么标准、在什么时间内完成 |
| 原则同意 | "原则同意你单位……" | 边界和条件：哪些要调整、按什么条件执行 |
| 部分同意 | "同意……；……暂不同意" | 不同意部分的理由 |
| 不同意 | "不同意你单位……" | 理由；有替代办法的写明 |

1. 表态放在第一条或引叙之后的第一句，不藏在执行要求里。
2. 请示有几个事项，批复逐项回应，不漏项。
3. 不写含糊表态："原则上可行，待条件成熟后再议""待研究后再行答复""视情况而定"（`references/_shared/style/defensive.md` 第七部分）。领导确实还没定的，不发批复，告诉用户先定意见。
4. 原则同意的条件、不同意的理由，只写用户提供的；用户没给的标【待补：条件】【待补：不同意的理由】。

## 四、各部分写法

1. 标题：同意的可以把结论写进标题，如"某某关于同意某街道设立社区养老服务站的批复"；不同意的用"某某关于……的批复"。
2. 引叙：写来文的完整标题和文号，只用用户给的；文号缺的标【待补：来文文号】。一份请示一份批复。
3. 执行要求：写具体动作和时限，如"请于12月31日前完成并报我委备案"；报备要求只写用户确定的，不另加层层报送（`references/_shared/rules/jianfu.md` JF-05）。
4. 依据：需要引用政策依据的，只用用户提供的文件名称和条款。
5. 篇幅：一般不超过1000字（工具约定），事实少的写短，不为凑篇幅扩写。

## 五、正误对照

误：你街道请示收悉。该事项原则上可行，待条件成熟后再议。
正：你街道《关于设立社区养老服务站的请示》（某街发〔2026〕15号）收悉。经研究，原则同意你街道在东湖社区设立养老服务站，先行运营一年，服务项目限于助餐和日间照料，并按以下要求执行：……此复。（社区、期限、服务项目、文号取自用户材料）

误：你局请示收悉。经研究，现批复如下：请你局加强组织领导，认真做好相关工作，确保取得实效。（通篇没有表态）
正：你局《关于调整办公用房的请示》（某发〔2026〕12号）收悉。经研究，同意你局将三楼档案室调整为便民服务窗口。请严格按照有关规定组织实施。

## 六、单位差异

| 单位类型 | 调整 |
|---|---|
| 党政机关 | 部门批复下级政府的请示，须在职权范围内；需经政府同意的，注明"经某某人民政府同意" |
| 基层 | 乡镇对村（社区）的申请多以批复或复函答复，以本地规定为准 |
| 公立医院、高校、国有企业 | 对内设部门的签报一般在签报单上批示，不另发批复；对下属单位的请示按本单位公文处理办法批复 |
| 中小学 | 学校很少发批复，对教职工个人申请一般不用批复 |

## 七、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | "你单位《关于……的请示》（某发〔2026〕N号）收悉。经研究，现批复如下：" |
| 表态 | "同意你单位……""原则同意你单位……，并按以下要求执行：""……暂不同意，理由是……" |
| 结语 | "此复。""特此批复。" |

## 八、自检

- [ ] 来文是请示；来函用了复函；报告没有批复。
- [ ] 批复意见来自用户，没有替用户决定同意或不同意。
- [ ] 表态在前、明确；原则同意写了条件，不同意写了理由。
- [ ] 请示的每个事项都有回应。
- [ ] 来文标题和文号来自用户或已标【待补】。
- [ ] 没有"待条件成熟后再议"一类含糊表态。
