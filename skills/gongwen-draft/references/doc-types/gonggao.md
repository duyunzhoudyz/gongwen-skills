# 公告

适用：向国内外宣布重要事项或者法定事项（《党政机关公文处理工作条例》第八条第（五）项）。公开发布，发布主体层级高。本 skill 列为 P1：可以起草，先判断是不是真的该用公告。通用要点见 `references/_shared/rules/doc-types.md` 2.5。

## 一、先判断该不该用公告

| 情形 | 用什么 |
|---|---|
| 国家机关向国内外宣布重要事项，或依法必须公告的法定事项（如法律规定须公告的征收、登记事项） | 公告 |
| 停水停电、道路施工、考试安排、活动通知等局部事项 | 通知或通告 |
| 在一定范围内要求公众遵守的事项 | 通告（见 `references/doc-types/tonggao.md`） |
| 企事业单位的招聘公告、招标公告、采购公告、上市公司信息披露公告 | 属于习惯用法或其他法规规定，不是条例所指的公告，按招标投标、政府采购、证券交易所等专门规定的格式写 |

用户要写的局部事项用了"公告"的，指出并改用通知或通告，起草说明写明理由；用户坚持的，按用户要求写，保留提示。

## 二、结构骨架

```text
标题：某某公告（或：某某关于……的公告）；可编"第×号"（实务）
正文：公告事项（缘由从简，一两句；事项分条）
结语：特此公告。（或：现予公告。）
署名
成文日期
```

## 三、写法

1. 法定事项的公告，依据的法律条款、公告内容、期限只用用户提供的；缺的标【待补】，依据标【待核实】。
2. 缘由一两句，不写背景和意义。
3. 事项写清对象、时间、地点、方式、联系途径。
4. 企业习惯用法的公告（招聘、采购等），按专门规定和用户提供的模板写，本 skill 只核对要素是否齐全、有无编造。
5. 篇幅：一般不超过1500字（工具约定），事实少的写短，不为凑篇幅扩写。

## 四、正误对照

误：某医院关于门诊楼电梯维修的公告
正：某医院关于门诊楼电梯维修的通知（院内局部事项）

误：某街道办事处关于辖区部分路段停水的公告
正：停水信息由供水企业或街道以通知、温馨提示形式发布，写清停水范围、起止时间、联系电话。

## 五、单位差异

| 单位类型 | 公告的使用边界 |
|---|---|
| 党政机关 | 只用于法律法规规定须公告的法定事项（如征收、登记）和本级须向社会宣布的重要事项；内部事项、工作部署不用公告 |
| 基层 | 乡镇（街道）一般不发公告，法律法规明确由乡镇人民政府公告的事项除外；停水、施工、防汛等局部事项用通知或通告 |
| 社区 | 不发公告；对居民用通知、温馨提示 |
| 公立医院 | 招聘、采购、招标按人事、政府采购、招标投标等专门规定的公告格式；门诊调整、停诊、搬迁等院务信息用通知 |
| 高校、中小学 | 招生、招聘、采购按专门规定的公告格式；校内事项、致家长的告知用通知 |
| 国有企业 | 停水停电停气等服务信息可按行业习惯用公告或通知，写清范围、时间、联系方式；上市公司信息披露按证券交易所规则，本 skill 只核对要素和有无编造 |

## 六、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | "根据《……》第×条规定，现将……公告如下："（依据来自用户） |
| 事项 | "一、……二、……"（对象、时间、地点、方式、联系途径分条写） |
| 结语 | "特此公告。""现予公告。" |

## 七、自检

- [ ] 属于重要事项或法定事项；局部事项已改用通知或通告。
- [ ] 发布主体有权发布；企业习惯用法的公告按专门规定处理。
- [ ] 依据、事项、期限来自用户或已标【待补】【待核实】。
- [ ] 结语"特此公告。"或"现予公告。"
