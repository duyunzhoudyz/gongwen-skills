# 签报

签报不在《党政机关公文处理工作条例》第八条之列，是部分机关、高校、企业在内部制度中规定的内部上行文：本单位内设部门向本单位领导请示事项、汇报工作、反映情况、提出建议。以本单位制度为准。通用要点和制度出处（《交通运输部公文处理办法》第十八条、第二十六条，湖南大学《请示报告事项签报制度》）见 `references/_shared/rules/doc-types.md` 第三部分。

## 一、什么时候用签报

| 情形 | 用什么 |
|---|---|
| 内设部门向本单位领导请求批准，单位有签报制度 | 签报（名称可能是呈批件、请示单、校内请示报告单） |
| 内设部门向本单位领导请求批准，单位没有签报制度 | 按单位画像；画像没写的，用“关于……的请示”，按内部请示格式写 |
| 以本单位名义向上级机关请求批准 | 请示 |
| 本部门职责范围内能决定的事项 | 不报签报，部门自行办理 |

单位有没有签报制度，看单位画像的“内部文种”字段；没有画像的，医院、高校、国企、党政机关默认有签报或同类内部文书，在起草说明“所作假设”中写明。

## 二、结构骨架

```text
签报（稿首单列一行表头，机检据此识别签报，不按标题当请示）
标题：关于……的请示（汇报类写：关于……情况的报告；内部文书，可省发文机关）
主送：（一位领导的职务，如“分管院领导”）
缘由：依据、现状、必要性
事项：请求批准的具体内容（金额、数量、方案）
本部门意见：倾向性方案和理由；有两个以上方案的比较后写倾向
会签情况：已会签的部门及意见；未会签的写明需会签部门
结语：妥否，请批示。（汇报类：特此报告。）
落款：主办部门、日期（负责人签名由用户填写）
附件：报价单、方案、测算表
```

签报单上的编号、拟办意见、领导批示栏由办公室或领导填写，起草时不写。

## 三、各部分写法

1. 一签一事。互不相干的两件事分两份签报。
2. 主送一位领导，写职务；签报是内部文书，主送领导职务不适用“请示不送领导个人”。需要几位领导审批的，只报一份，由办公室按程序呈送，不同时分送多位领导（《交通运输部公文处理办法》第二十六条；湖南大学签报制度）。
3. 不绕过办公室直接送领导个人，按本单位流转程序报送。
4. 事项写到领导能直接批：买什么、多少台、多少钱、从哪个渠道出资、怎么采购。金额、报价只用用户提供的，缺的标【待补】。请求事项、前置程序（如“党委会研究前不实施”）、时限也只写用户给的，推断的写进起草说明请用户确认。
5. 本部门意见要明确。有两个以上方案的，列表比较后写倾向（`references/_shared/style/defensive.md` 第七部分）。
6. 涉及其他部门职责的，先会签。会签部门和意见只写用户提供的，用户点名的部门全部列入；还没会签的，在起草说明中列出需会签的部门，正文“会签情况”写【待补：会签部门意见】。
7. 属于“三重一大”（重大事项决策、重要干部任免、重要项目安排、大额资金使用）的，写明须按本单位决策程序上会；国企写明是否属于党委前置研究事项清单。是否属于，由用户按本单位标准确认。
8. 篇幅：正文一般不超过1500字（工具约定），细节放附件；事实少的写短，不为凑篇幅扩写。

## 四、各类单位的签报

| 单位类型 | 常见名称 | 流转（以本单位制度为准） | 注意 |
|---|---|---|---|
| 党政机关 | 签报、呈批件 | 处室起草，办公厅（室）审核后呈报分管领导 | 只在机关内部运转，不编正式发文字号 |
| 基层 | 请示单、签报 | 站所、办公室报乡镇分管领导 | 不对外 |
| 公立医院 | 签报、请示单 | 科室起草，职能部门审核，相关部门会签，报分管院领导；重大事项按程序上院长办公会、党委会 | 设备购置、新技术准入、人员、经费；患者信息脱敏 |
| 高校 | 校内请示报告单、签报 | 学院、部门起草，党政办公室审核登记、统一编号后呈送校领导 | 本单位职责内事项不报；学院不以学院名义直接对校外行文 |
| 中小学 | 很少使用，多为口头或书面请示 | 处室报校长 | 按学校制度 |
| 国有企业 | 签报 | 本部部门起草，相关部门会签，报分管领导；重大事项提交总经理办公会或党委会 | 方案比选、依据、风险；商业秘密不进入联网工具 |

## 五、正误对照

误：主送“局长、分管副局长、办公室、财务科”
正：主送“分管局领导”；办公室、财务科列入会签，会签意见由用户提供。

误：本处拟更新一批执法记录仪，价格约几万元，请领导酌情考虑。
正：本处拟更新执法记录仪20台，经询价，合计【待补：报价金额】万元，拟从年度办公设备购置预算中列支。妥否，请批示。（台数、资金渠道取自用户材料，报价缺失标【待补】）

## 六、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | “为……，本部门拟……，现将有关情况请示如下：” |
| 事项 | “拟购置……×台，经询价，合计……万元，拟从……中列支。”“本部门倾向于方案×，理由是……” |
| 结语 | “妥否，请批示。”；汇报类用“特此报告。” |

## 七、自检

- [ ] 单位有签报制度（或按画像、默认值已在起草说明中写明）。
- [ ] 一签一事；主送一位领导，没有同时分送多位领导。
- [ ] 事项具体，金额、报价、台数来自用户或已标【待补】。
- [ ] 本部门意见明确；有多个方案的写了倾向。
- [ ] 稿首有“签报”表头；需会签的部门已全部列出；“三重一大”事项已提示决策程序。
