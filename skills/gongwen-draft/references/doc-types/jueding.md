# 决定

适用：对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项（《党政机关公文处理工作条例》第八条第（二）项）。下行文。本 skill 列为 P1：可以起草，动笔前先核对发文权限。通用要点见 `references/_shared/rules/doc-types.md` 2.2。

## 一、动笔前核对

1. 是不是重要事项。一般工作安排用通知；一般表扬用通报（`references/doc-types/tongbao.md` 第一部分）。
2. 是不是须经会议表决通过的事项。须表决通过并以会议名义发布的，用决议（见 `references/doc-types/p2.md`）。
3. 发文机关有没有这个权限，经过了什么程序。决定的事项、研究的会议和时间只写用户提供的，缺的标【待补：研究决定的会议和时间】。
4. 党纪处分、政务处分由纪检监察机关依照专门规定办理，本 skill 不起草这类处分决定，告诉用户原因。

## 二、三种决定的结构

```text
部署类
标题：某某关于……的决定
开头：为……，根据……，经……研究，决定……（一段）
决定事项：分条，结论先行
执行要求：责任主体、标准、时限
结尾：本决定自×年×月×日起施行。（规范性决定）或：请认真贯彻执行。

奖励类（表彰决定）
标题：某某关于表彰……的决定（或：关于授予……称号的决定）
事实：受表彰对象的主要事迹（来自用户）
决定：经……研究，决定授予……称号（给予……奖励）
号召：希望……；各……要……
附件：表彰名单

变更撤销类
标题：某某关于撤销（修改）……的决定
事实和理由：原决定的名称、文号，不适当之处，依据
决定事项：撤销或修改的内容、生效时间
后续处理：已执行部分怎么处理（来自用户）
```

## 三、写法

1. 决定事项写结论，不展开说理；分条写，一条一事。
2. 表彰决定的称号、奖励标准只写用户提供的；须按评比表彰管理规定履行审批程序的，在起草说明中提示用户确认已经批准。
3. 单位内部的奖惩决定只整理用户提供的事实、依据条款和处理结果，不判断该不该奖惩、给什么等级。依据条款缺的标【待补：依据条款】。
4. 涉及个人的，联网工具中正文用“张某”，姓名由用户在本地填入；不写身份证号、联系方式。
5. 撤销决定写清原决定的完整名称和文号（来自用户），写明生效时间。
6. 篇幅：一般不超过2000字（工具约定），事实少的写短，不为凑篇幅扩写。

## 四、正误对照

误：经研究，决定在全系统开展“安全生产月”活动，请各单位认真组织。（一般工作安排）
正：改用通知：“某某关于开展2026年‘安全生产月’活动的通知”。

误：为表彰先进，激励广大干部职工奋发有为，经研究，决定授予张某等10名同志“优秀共产党员”称号。（材料中没有研究会议，也没有称号的审批情况）
正：经【待补：研究决定的会议和时间】研究，决定授予张某等10名同志“优秀共产党员”称号。起草说明“待核实”一行请用户核对称号名称以批准文件为准及评比表彰审批手续。

## 五、单位差异

| 单位类型 | 调整 |
|---|---|
| 党政机关 | 规范性决定写施行日期；撤销下级不适当决定须在职权范围内 |
| 基层、社区 | 很少使用；社区居委会、村委会的重要事项按居民会议、村民会议决定，不发行政决定 |
| 公立医院、高校、国有企业 | 内部表彰、机构设置等决定以本单位名义发文；“三重一大”事项写明决策会议（来自用户） |
| 中小学 | 表彰教师、学生多用通报或表彰决定，按学校制度 |

## 六、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | “为……，经……研究，决定……”（研究主体和时间来自用户） |
| 事项 | “一、……二、……”（结论先行）；“决定授予……称号”“决定给予……奖励” |
| 结语 | “本决定自×年×月×日起施行。”（规范性决定）；“请认真贯彻执行。”；表彰决定以“希望……；各……要……”收尾 |

## 七、自检

- [ ] 确属重要事项；一般安排已改用通知，一般表扬已改用通报。
- [ ] 不属于须会议表决的决议，不属于党纪处分、政务处分。
- [ ] 研究决定的会议和时间、称号、依据条款来自用户或已标【待补】。
- [ ] 决定事项结论明确，分条清楚。
- [ ] 个人信息已处理。
