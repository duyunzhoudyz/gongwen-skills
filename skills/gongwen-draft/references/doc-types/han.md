# 函

适用：不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项（《党政机关公文处理工作条例》第八条第（十四）项）。平行文，可用信函格式（GB/T 9704-2012 10.1）。通用要点见 `references/_shared/rules/doc-types.md` 2.14。

## 一、四种函

| 种类 | 用途 | 标题 | 结语 |
|---|---|---|---|
| 商洽函 | 请对方配合、支持、协助 | 某某关于商请……的函 | 请予支持，盼复。请予协助，盼复。 |
| 询问函 | 向对方了解情况、征询意见 | 某某关于……有关问题的函 | 请函复。请予函复。 |
| 请批函 | 向不相隶属的主管部门请求批准 | 某某关于商请批准……的函 | 请予审批，盼复。请予批准。 |
| 复函 | 答复对方来函，包括审批部门的审批函 | 某某关于……的复函 | 特此函复。此复。 |

判断：对方和本单位有没有隶属关系。没有的，即使对方是审批部门（财政、发展改革、自然资源、医保等），请求批准也用函；有隶属关系的上级，用请示（`references/_shared/rules/doc-types.md` 7.2）。

## 二、结构骨架

```text
标题：某某关于商请……的函
主送：某某：
缘由：为……，根据……（一段）
事项：商洽、询问或请求的具体内容（金额、时间、方式、需要对方做什么）
希望：请予支持，盼复。
附件：1. ……
署名
成文日期
（联系人：……，电话：……）

复函
你单位《关于……的函》（某函〔2026〕N号）收悉。经研究，现函复如下：
一、……（先给结论：同意、不同意、部分同意，或对询问的答复）
二、……（依据和条件）
特此函复。
```

## 三、各部分写法

1. 一函一事。两件互不相干的事分两份函。
2. 事项写具体：要对方给什么、做什么、什么时候。金额、数量、时间只用用户给的，缺的标【待补】。
3. 请批函写清请求批准的事项和依据，附测算或方案；需要对方在某日前答复的，写明原因和日期（来自用户）。
4. 复函先给结论，再给依据和条件，不让对方通篇找答案。对方问了几项就答几项。
5. 复函引叙来函的标题和文号，只用用户给的，缺的标【待补：来函文号】。
6. 商洽、询问、请求类函必须有结语，写“请予支持，盼复”“请函复”之类，不止于“请予支持”；复函用“特此函复”。
7. 称对方“你单位”或“贵单位”均可，按本单位惯例，全文统一。
8. 以内设机构名义对外发函的，提示改由本单位或办公室发（第十七条第三款）；企事业单位以本单位制度为准。
9. 追加预算、调整预算一类事项，向财政部门发函；金额超过本地财政审批权限、需要政府决定的，以本地预算管理规定为准，在起草说明中提示用户确认。

## 四、语气

平行文，语气平和、平等。
1. 不用指令性措辞：“务必”“必须”“责令”“要求你单位于……前”。
2. 不过分谦卑：“万望”“恳请务必”“不胜感激”。
3. “恳请”“请予”“商请”可以用，每份函用一两处即可。

误：请你局务必于本月底前完成我镇集贸市场周边排水管网疏通。
正：我镇集贸市场周边排水管网有【待补：数量】处堵塞，雨天积水影响群众出行，商请你局将其纳入今年管网维护计划。请予支持。

## 五、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | “为……，现就……商请如下：”“现将……有关事项函告如下：” |
| 复函开头 | “你单位《关于……的函》收悉。经研究，现函复如下：” |
| 结语 | “请予支持，盼复。”“请函复。”“请予审批，盼复。”“特此函告。”“特此函复。”“此复。” |

## 六、正误对照

误：标题“某县文化和旅游局关于申请景区停车场临时用地的请示”，主送县自然资源局。
正：标题“某县文化和旅游局关于商请批准景区停车场临时用地的函”。县文化和旅游局与县自然资源局不相隶属，请求批准用函（第八条第（十四）项）。

误：（函的结尾）妥否，请批示。
正：请予支持。（“请批示”是请示的结语，函不用）

误：（复函）关于你单位来函所提事项，我委高度重视，进行了认真研究，原则上表示支持，具体事宜另行商定。
正：你单位《关于商请共建社区卫生服务站的函》收悉。经研究，同意在某社区共建卫生服务站，我委负责派驻全科医生2名。具体协议由双方于11月底前商定。特此函复。（同意的事项、人数、时间取自用户材料）

## 七、单位差异

| 单位类型 | 常见发函对象 |
|---|---|
| 党政机关 | 同级其他部门；不相隶属的上级部门（请批函） |
| 基层 | 乡镇向县直部门请求支持、商洽工作 |
| 社区 | 向辖区单位商请共建、协助；一般以社区居委会名义，加盖公章 |
| 公立医院 | 与医保部门、其他医院、高校、地方政府部门 |
| 高校 | 与地方政府部门、企业、其他高校；校内部门之间一般不用函 |
| 中小学 | 与街道、卫生健康、公安等单位商洽进校园事项、周边治理 |
| 国有企业 | 与政府部门、其他企业；与上级集团、国资监管机构有隶属关系的，用请示或报告 |

## 八、自检

- [ ] 对方与本单位不相隶属；有隶属关系的已改用请示。
- [ ] 一函一事，事项具体，金额、时间来自用户。
- [ ] 复函先给结论，逐项答复，引叙了来函标题和文号（或已标【待补】）。
- [ ] 语气平和，没有“务必”“必须”，也没有过分谦卑的话。
- [ ] 结语是函的结语，没有“请批示”；商洽、询问、请求类有“盼复”“请函复”。
