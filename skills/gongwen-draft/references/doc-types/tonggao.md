# 通告

适用：在一定范围内公布应当遵守或者周知的事项（《党政机关公文处理工作条例》第八条第（六）项）。面向一定范围内的单位和公众，一般不设主送机关。本 skill 列为 P1：可以起草，动笔前先核对发文主体和法律依据。通用要点见 `references/_shared/rules/doc-types.md` 2.6。

## 一、动笔前核对

1. 发文主体有没有职权。规定公众应当遵守的事项（禁止、限制、管制），须由在该事项上有法定职权的机关发布。居（村）委会是基层群众性自治组织，没有行政执法权；学校、医院、企业不面向社会发布约束公众的通告。这些单位要告知群众的，用通知、告知书、温馨提示，转达有权机关的规定。
2. 是通告还是公告、通知。有明确受文机关的用通知；面向社会、有遵守要求的用通告；向国内外宣布重要事项或法定事项的用公告（`references/_shared/rules/doc-types.md` 7.3）。
3. 依据是什么。通告事项的法律、法规、规章依据只用用户提供的，写明名称和条款；用户没给的标【待核实：依据的法律法规名称和条款】。

## 二、结构骨架

```text
标题：某某关于……的通告
开头：为……，根据《……》（用户提供的依据）等规定，现就……有关事项通告如下：
一、适用范围（区域、路段、场所）
二、适用时间（起止日期和时段）
三、应当遵守或者禁止的行为
四、例外情形（如执行任务的车辆）
五、违反规定的处理（依据和有权处理的机关）
六、咨询方式
七、施行日期（本通告自×年×月×日起施行）
结语：特此通告。
署名
成文日期
```

## 三、各部分写法

1. 范围、时间、对象、行为四项写实，不能缺。区域写到路段或四至；时间写到日和时段。缺的标【待补】。
2. 一条一事，用公众看得懂的话写。专业术语首次出现时简要说明。
3. 禁止性表述用“禁止”“不得”，说清禁止什么，不用“严厉打击”“后果自负”一类吓唬人的话。
4. 复杂的区域、路线用附图，正文写“具体范围见附图”。
5. 篇幅：一般不超过1500字（工具约定），事实少的写短，不为凑篇幅扩写。

## 四、法律表述

面向群众的文书（通告、居民通知、告知书）逐句检查以下表述：

| 表述 | 规则 | 依据 |
|---|---|---|
| 罚款、警告、没收、拘留、吊销等处罚 | 通告和其他规范性文件不能设定处罚。只能写“违反……规定的，由……（有权机关）依照《……》第×条处理”，依据和机关来自用户 | 《行政处罚法》第十六条：除法律、法规、规章外，其他规范性文件不得设定行政处罚 |
| 查封、扣押等强制措施 | 不能由通告设定 | 《行政强制法》第十条第四款：法律、法规以外的其他规范性文件不得设定行政强制措施 |
| 强制拆除等强制执行 | 不能由通告设定；写“由……（有权机关）依法处理” | 《行政强制法》第十三条：行政强制执行由法律设定 |
| 对不配合的居民停水、停电、停气 | 删除。供水供电企业的检修停水停电告知不在此列 | 《行政强制法》第四十三条第二款：行政机关不得对居民生活采取停止供水、供电、供热、供燃气等方式迫使当事人履行相关行政决定 |
| 取消低保、停发补贴、不予办理户口、影响子女入学 | 删除。与通告事项无关的权益限制，没有法律依据 | 国办发〔2018〕37号：行政规范性文件不得违法减损公民、法人和其他组织的合法权益或者增加其义务 |
| 纳入黑名单、公开曝光、通报所在单位 | 核对是否有法律法规依据；没有的删除；涉及个人信息的不得公开 | 同上 |
| “一律”“严惩”“后果自负” | 改为说明性语言 | `references/_shared/style/defensive.md` 第六部分 |

做法：
1. 用户材料里出现上表中没有依据的表述，删除或改写，在起草说明“修改说明”中逐条写明原文、改法、理由。
2. 用户坚持保留的，不照写，向用户说明上表的法律依据；可以写“违反规定的，由有关部门依法处理”。是否另行请有权机关发布，由用户决定。
3. 有 Python 环境时用 `python scripts/gongwen_lint.py 正文.txt --doc-type 通告 --checks legal` 辅助查找。

## 五、正误对照

误：春节期间小区内禁止燃放烟花爆竹，违者罚款200元，情节严重的移交派出所拘留，并对其家庭停止供水。（社区居委会发布）
正：改用社区通知：“根据【待核实：本市关于禁止燃放烟花爆竹的规定名称和条款】，本小区属于禁止燃放烟花爆竹区域。违反规定燃放的，由公安机关依法处理。请居民朋友共同遵守。”停水的表述删除。

误：本通告自发布之日起施行，解释权归本局所有。
正：本通告自2027年1月20日起施行，至2027年3月20日止。（起止日期取自用户；“解释权归……所有”不写）

## 六、单位差异

| 单位类型 | 调整 |
|---|---|
| 党政机关 | 在法定职权内发布；涉及多个部门的联合发布，部门之间先协商一致（第十六条第（四）项） |
| 基层 | 乡镇（街道）发布的通告以本级职权为限，执法事项写明有权执法的部门 |
| 社区 | 不发通告，改用通知或温馨提示，转达有权机关的规定，写明规定名称 |
| 公立医院、高校、中小学 | 院内、校内事项用通知；面向社会的公告性事项（如招生、招聘）按相关规定 |
| 国有企业 | 停水停电停气等服务信息用通知或公告（企业习惯用法），写清范围、时间、联系方式，不写处罚 |

## 七、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | “为……，根据《……》等规定，现就……有关事项通告如下：”（依据来自用户） |
| 事项 | “禁止……”“……不得……”“违反本通告规定的，由……（有权机关）依照《……》处理。” |
| 结语 | “本通告自×年×月×日起施行。”“特此通告。” |

## 八、自检

- [ ] 发文主体对通告事项有职权；没有的已改用通知或温馨提示。
- [ ] 范围、时间、对象、行为四项写实或已标【待补】。
- [ ] 没有自设罚款、拘留、强制措施和与事项无关的权益限制。
- [ ] 罚则写明有权机关和依据，依据来自用户或已标【待核实】。
- [ ] 有施行日期；结语“特此通告。”
