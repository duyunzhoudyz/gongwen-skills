# 报告（就一件事）

适用：向上级机关汇报工作、反映情况，回复上级机关的询问（《党政机关公文处理工作条例》第八条第（十）项）。上行文，不需要上级批复。通用要点见 `references/_shared/rules/doc-types.md` 2.10。

## 一、本 skill 写哪些报告

| 报告 | 例 | 归属 |
|---|---|---|
| 情况报告 | 突发事件、事故、舆情、工作中出现的问题的经过和处置 | 本 skill |
| 答复报告 | 回复上级的询问、领导批示要求说明的情况 | 本 skill |
| 交办事项报告 | 上级交办的一件具体事办得怎么样 | 本 skill |
| 报送报告 | 报送总结、方案、统计表等材料，材料作附件 | 本 skill 写报告这层外壳，材料由对应 skill 写 |
| 年度、半年、专项的全面工作报告 | 某局2026年工作报告 | gongwen-report |
| 贯彻落实上级文件的落实情况报告 | 按任务表逐项报进展 | gongwen-implement |
| 整改情况报告、自查报告 | 巡察反馈问题整改情况 | gongwen-rectify |

判断要点：只围绕一件事、一个事件、一次询问的，归本 skill；要回顾一个时期或一项工作全貌的，交 gongwen-report。

## 二、四种报告的结构

```text
情况报告
标题：某某关于……情况的报告
开头：×月×日，……发生……。现将有关情况报告如下：
一、基本情况（时间、地点、经过、影响范围、伤亡和损失）
二、处置情况（已采取的措施）
三、原因分析（已查明的；未查明的写“原因正在调查”）
四、下一步工作
结语：特此报告。

答复报告
标题：某某关于……有关情况的报告
开头：你单位（某领导批示、某某来文）要求说明……的情况。现报告如下：
正文：针对询问逐项答复，先写结论，再写依据和事实
结语：特此报告。

交办事项报告
标题：某某关于……办理情况的报告
开头：根据……（交办来源），我单位……。现将办理情况报告如下：
正文：办理过程；办理结果；未办结的原因和计划
结语：特此报告。

报送报告
标题：某某关于报送……的报告
正文：根据……要求，现将《……》报上。（需要时加一两句说明）
附件：……
结语：特此报告。
```

## 三、通用写法

1. 时效：突发情况先报已掌握的基本情况，不等原因查清；后续情况续报。起草首报时，在起草说明中提示用户约定续报时间（实务）。
2. 经过只写用户提供的事实。时间、地点、人数、伤亡、损失缺的标【待补】，说法不一的标【待核实】，不推测、不估算。
3. 原因只写已查明的。没有查明的写“原因正在调查”，不写“初步判断可能是……”一类推测，用户材料中明确写了初步判断的照写并注明“初步判断”。
4. 措辞客观：不推卸责任，也不替单位揽下尚未认定的责任；责任认定只写用户提供的结论。
5. 答复报告逐项回应询问，问几项答几项，先结论后依据；询问中有本单位答复不了的，写明原因，不回避。
6. 患者、学生、群众个人信息一律脱敏，写“患者张某”“一名学生”。
7. 篇幅：一般不超过3000字（工具约定）；报送报告正文一般不超过300字。事实少的写短，不为凑篇幅扩写。

## 四、不夹带请示

报告中不得夹带请示事项（第十五条第（四）项）。起草前和成稿后各查一遍：
1. 正文出现“请批准”“请拨付”“恳请支持……万元”“妥否，请批示”的，把请求事项抽出来另写请示，报告只写情况。
2. 只是反映困难、需要上级知道的，改为陈述：“因……，目前资金缺口约……万元。”不写请求句。
3. 用户坚持在报告中提出请求的，在起草说明中提示：上级对报告一般不作批复，请求事项可能得不到答复。

误：（校园安全工作情况报告结尾）另，拟更新校园监控设备一批，所需经费25万元，妥否，请批示。
正：报告结尾“特此报告。”；更新监控设备另写《某中学关于更新校园监控设备的请示》，起草说明写明拆分理由。

## 五、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | “现将……情况报告如下：”“根据……要求，现将……报告如下：” |
| 报送 | “现将《……》报上。”“现将……随文报送。” |
| 结语 | “特此报告。”；答复报告也可用“专此报告。” |

## 六、正误对照

误：此次事故造成的经济损失估计在50万元左右，主要原因可能是施工单位违规作业。（材料中没有损失数字和原因结论）
正：此次事故造成的直接经济损失正在核定。事故原因正在调查。

误：（答复报告）关于群众反映的问题，我局高度重视，迅速成立专班，认真研究，积极处理。
正：群众反映的3处公交站台破损问题，已于6月18日全部修复。（数字、日期取自用户材料）

## 七、单位差异

| 单位类型 | 调整 |
|---|---|
| 党政机关 | 部门向上级主管部门报告重大事项，须经本级党委、政府同意或授权（第十五条第（二）项） |
| 基层 | 突发事件按本地信息报送规定的时限报送，时限由用户提供 |
| 社区 | 向街道报送情况报告，语言平实，加盖公章 |
| 公立医院 | 医疗纠纷、不良事件、院感事件的报告脱敏；数据与病案首页、监测系统一致；对外报送前经职能部门审核 |
| 高校 | 学生相关事件严格脱敏；涉及意识形态的情况报告按严谨模式 |
| 中小学 | 校园安全事件写明学生人数、处置和家长沟通情况，不写学生姓名 |
| 国有企业 | 安全生产事故按规定时限报告，不迟报、瞒报；上市公司重大事项注意信息披露规定 |

## 八、自检

- [ ] 只围绕一件事；全面工作报告、落实情况报告、整改报告已转交。
- [ ] 没有夹带请示事项，结语是“特此报告。”
- [ ] 时间、地点、人数、伤亡、损失全部来自用户，缺的已标【待补】。
- [ ] 原因只写已查明的，没有推测。
- [ ] 答复报告逐项回应了询问。
- [ ] 个人信息已脱敏。
