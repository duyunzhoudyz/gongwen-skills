# 决议、命令（令）、公报、议案（只给结构说明）

这四种文种使用主体受法律或组织程序限制，多数用户用不到。本 skill 只给结构说明、要点清单和需要用户提供的信息清单，不起草全文。用户坚持要全文的，说明原因：这几类文书的内容由会议表决或法定程序决定，工具起草容易越位。通用要点见 `references/_shared/rules/doc-types.md` 2.1、2.3、2.4、2.13。

## 一、四种文种速查

| 文种 | 适用（第八条） | 使用主体 | 结构 | 需要用户提供 |
|---|---|---|---|---|
| 决议 | 会议讨论通过的重大决策事项 | 党的代表大会、党委全会、人大等会议 | 题注（通过日期和会议）；依据或背景；决议事项；号召 | 会议名称、通过日期、表决通过的决议事项原文 |
| 命令（令） | 公布行政法规和规章；宣布施行重大强制性措施；批准授予和晋升衔级；嘉奖 | 法律规定的机关和领导人；企事业单位不用 | 公布对象、通过的会议或批准机关、施行日期；签发人职务、签名章、成文日期 | 令号、被公布的法规规章名称、通过会议和日期、施行日期 |
| 公报 | 公布重要决定或者重大事项 | 党政领导机关、统计部门等；企事业单位不用 | 会议或事项概况；重要决定或重大事项分述；号召（会议公报） | 会议时间地点、出席情况、通过的决定原文、统计数据 |
| 议案 | 各级人民政府按照法律程序向同级人大或人大常委会提请审议事项 | 各级人民政府 | 案由；必要性和主要内容说明；提请审议 | 提请审议的草案名称、主要内容、政府常务会议讨论情况 |

## 二、交付内容

1. 结构说明：按上表给出该文种的结构和各部分写什么。
2. 要点清单：标题写法、版式要点（命令格式见 GB/T 9704-2012 10.2）、常见错误。
3. 信息清单：上表"需要用户提供"一栏，逐项列出。
4. 用户提供了会议通过的原文的，可以帮助整理格式和标点，不改动通过的内容。

## 三、容易混同的情形

1. 人大代表提出的议案、公司董事会的议案，不是条例所指的议案。人大代表议案按人大议事规则办理；国企董事会议案、决议按《公司法》和公司章程办理，安装了 gongwen-soe 行业包的交给它，没有安装的只给结构建议。
2. 未经会议表决的事项不用决议，用决定或通知。
3. 统计公报的数据只用统计部门发布的数，本 skill 不生成。
4. 嘉奖令、通缉令等有专门规定的，按专门规定办理。

## 四、正误对照

误：某局党组关于开展作风建设年活动的决议（未经会议表决的工作安排）
正：某局党组关于开展作风建设年活动的通知
