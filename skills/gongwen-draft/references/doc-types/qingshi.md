# 请示

适用：向上级机关请求指示、批准（《党政机关公文处理工作条例》第八条第（十一）项）。上行文，主送一个有隶属关系的上级机关，标注签发人（第九条第（六）项），由机关主要负责人签发（第二十二条）。通用要点见 `references/_shared/rules/doc-types.md` 2.11。

## 一、先排除三种情况

| 情况 | 应当用 | 依据 |
|---|---|---|
| 对方与本单位不相隶属，即使是审批部门 | 函 | 第八条第（十四）项 |
| 内设部门向本单位领导请求批准，单位有签报制度 | 签报 | `references/_shared/rules/doc-types.md` 第三部分 |
| 只是汇报情况，不需要上级表态 | 报告 | 第八条第（十）项 |

请示分两类，写法略有不同：
- 请求指示：政策不明确、遇到新问题，请上级明确怎么办。写清问题、本单位的理解和拟处理意见。
- 请求批准：经费、项目、编制、机构、人事、重大活动等，请上级同意。写清要批什么、批多少、按什么方案。

## 二、结构骨架

```text
发文字号：×〔2026〕×号（未知写【待补】）
签发人：×××（未知写【待补】）
标题：某某关于……的请示
主送：（一个上级机关）：
缘由：依据、现状、必要性（一到两段，用事实和数据）
事项：请求批准什么、拨付多少、同意哪个方案
本单位意见：倾向性方案和理由（有两个以上方案时）
结语：妥否，请批示。
附件：1. ……（测算表、方案、报价）
署名
成文日期
（联系人：……，电话：……）
```

发文字号、签发人两行写在标题之前，不放进起草说明；用户没给的写【待补：发文字号】【待补：签发人姓名】。

## 三、各部分写法

1. 标题：事由写请求的事项，如“关于拨付敬老院改造资金的请示”“关于增设便民服务窗口的请示”。不写“请示报告”；不写“关于申请……的请示”，“申请”和“请示”意思重复（实务）。
2. 主送：只写一个上级机关。需要其他上级知晓的列抄送；不抄送下级；不主送领导个人（第十五条第（一）（五）项）。受双重领导的，主送主管机关，必要时抄送另一个上级机关（第十五条第（六）项）。
3. 缘由：先写依据（用户提供的文件、会议决定），再写现状（数据、事实），再写必要性。缘由一般不超过全文的一半，请求事项不能埋在缘由里。不写形势背景。
4. 事项：具体到上级能直接批：金额、数量、名称、时间、方案。
   - 本单位的打算用“拟……”，不用“决定……”。未经批准的事项，本单位不能先决定。
   - 金额、数量只用用户给的，不改变请求的性质（用户说“申请拨付”，不改写成“追加”）。用户给了测算的写测算依据；没给的标【待补：测算依据】。
5. 本单位意见：有两个以上方案时，写明倾向和理由（`references/_shared/style/defensive.md` 第七部分）。只有一个方案时，事项本身就是意见。用户没说倾向的，标【待补：本单位倾向性意见】，不替用户选，在回复末尾问一次；用户说“直接写”的只标不问。
6. 结语：只用请示类结语，不写“特此报告”。确需上级在某日前答复的，写明原因和时限，原因和日期来自用户。
7. 附注：写联系人和电话。联网工具中可以只写【待补：联系人及电话】，定稿时由用户填入。
8. 篇幅：一般不超过2000字（工具约定），附件另计；事实少的写短，不为凑篇幅扩写。

## 四、一文多事的拆分

1. 数一数需要上级分别表态的事项。同一事项的配套内容算一事，如“新建便民服务中心”和“建设资金”；互不相干的算两事，如“增加编制”和“购置公务用车”。
2. 两事以上的，拆成两份请示，分别起草，起草说明中写明拆分理由（第十五条第（四）项）。
3. 用户坚持合写的，按用户要求写，起草说明保留这条提示。

## 五、转报下级请示

以本机关名义转报下级的请示，要提出倾向性意见，不得原文转报（第十五条第（三）项）。

```text
某某《关于……的请示》（某发〔2026〕N号）收悉。经审核，……（本机关意见及理由）。现转报你们，妥否，请批示。
附件：某某关于……的请示
```

用户没给本机关意见的，标【待补：本机关倾向性意见】。

## 六、事后请示与追认

事项已经办了再写请示，属于先办后请。做法：
1. 不把已办的事写成事前请求的口吻，如实写明已办的情况和原因。
2. 需要上级追认的，事项写“恳请予以追认”；只需让上级知道的，改写报告。
3. 起草说明中提示：先办后请属于程序问题，今后同类事项事前请示。

## 七、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | “根据……，结合……实际，现就……请示如下：”“为……，拟……，现将有关情况请示如下：” |
| 事项 | “恳请……拨付……万元，用于……”“拟采取以下方案：……” |
| 结语 | “妥否，请批示。”“当否，请批复。”“以上请示，请予审批。”“以上请示如无不妥，请批转……执行。”（请上级批转时） |

## 八、正误对照

误：标题“某镇人民政府关于申请拨付敬老院改造资金的请示报告”
正：标题“某镇人民政府关于拨付敬老院改造资金的请示”

误：关于敬老院改造经费，我们考虑了几种办法，各有利弊，请领导研究。
正：恳请县政府从县级预备费中拨付敬老院改造资金73万元。改造工程计划于11月开工，12月底前完工。妥否，请批示。（金额、时间取自用户材料）

误：经研究，我局决定于下月起延长办事大厅服务时间，现请示如下。
正：为方便群众下班后办事，我局拟自12月1日起将办事大厅服务时间延长至19时，现请示如下。

误：主送“县人民政府、县财政局、县民政局”
正：主送“县人民政府”；需要财政局、民政局知晓的，列抄送。

## 九、单位差异

| 单位类型 | 向谁请示 | 内部请示 | 特别注意 |
|---|---|---|---|
| 党政机关 | 上级机关或上级主管部门 | 处室向本机关领导用签报或呈批件 | 部门向上级主管部门请示重大事项，须经本级党委、政府同意或授权（第十五条第（二）项） |
| 基层 | 乡镇向县政府请示 | 站所、办公室向乡镇领导用请示单或签报 | 向县直部门请求支持用函 |
| 社区 | 向街道（乡镇）报送申请，属请示性质 | 两委会议研究 | 一般不用红头；加盖公章；重要事项先经社区党组织研究 |
| 公立医院 | 医院向卫生健康行政部门请示 | 科室向院领导用签报 | 医院与医保部门不相隶属，用函 |
| 高校 | 学校向教育部门请示 | 学院、部门向校领导用校内请示报告单或签报 | 学院不以本院名义直接向校外上级机关请示 |
| 中小学 | 学校向主管教育部门请示 | 处室向校长口头或书面请示 | 编制、经费等事项向主管教育部门请示，不越过主管部门直接找编制、财政部门 |
| 国有企业 | 公司向国资监管机构或上级集团请示 | 本部部门向公司领导用签报 | “三重一大”事项写明本企业决策程序完成情况（党委前置研究等），未完成的在起草说明中提示 |

## 十、自检

- [ ] 主送一个有隶属关系的上级机关，没有抄送下级，没有送领导个人。
- [ ] 一文一事；两事以上已拆分或已在起草说明中提示。
- [ ] 请求事项具体到金额、数量、方案；本单位打算用“拟”，没有用“决定”。
- [ ] 两个以上方案时写了倾向性意见；用户没给的已标【待补】。
- [ ] 结语是请示类结语；附注有联系人。
- [ ] 金额、文号、依据文件、日期全部来自用户或已标【待补】。
