# 意见

适用：对重要问题提出见解和处理办法（《党政机关公文处理工作条例》第八条第（七）项）。上行、下行、平行均可。通用要点见 `references/_shared/rules/doc-types.md` 2.7。

## 一、三个方向与归属

| 方向 | 用途 | 效力（国办函〔2001〕1号第1条，实务沿用） |
|---|---|---|
| 下行 | 指导意见、实施意见：对某项工作提出一整套政策措施 | 有明确要求的遵照执行，无明确要求的参照执行 |
| 上行 | 向上级提出工作建议，请上级批转或采纳 | 按请示性公文的程序和要求办理 |
| 平行 | 向不相隶属单位提出见解，供对方参考 | 供参考 |

归属：
1. 本单位就某个重要问题自主提出见解和办法的意见，归本 skill。
2. 以上级文件为依据、要逐条对应上级条款拆出任务的实施意见、贯彻落实意见，交 gongwen-implement（它有逐条对应和照抄检测）。
3. 只布置一项具体工作的，用通知；对征求意见稿的反馈，用函或按来文要求的格式回复。

## 二、下行意见

```text
标题：某某关于……的意见（或：……的指导意见、……的实施意见）
主送：各……：
开头：为……，现提出以下意见。（一两句，写目的和依据）
一、总体要求（工作目标，一段，从简）
二、主要任务（分条，每条写措施、责任主体、时限）
三、保障措施（精炼，只写有具体主体和动作的内容）
署名
成文日期
```

1. 开门见山，不写形势背景、重要意义、指导思想大段（`references/_shared/rules/jianfu.md` 第2条）。用户或单位要求保留“总体要求”的，压缩成一段。
2. 主要任务是正文主体，占篇幅的大部分。每条任务写具体措施；措施、责任主体和时限来自用户；责任主体没给的写“各部门”，必须由用户定的时限才标【待补】。用户材料只列了现状问题、没列措施的，不自行增列任务，在起草说明问是否增列。涉及其他部门职权的，起草说明写“附：需会签部门”，用户点名的部门全部列入。
3. 目标值来自用户或用户提供的上级文件，没有的写【待补：目标值】，不编“力争达到95%以上”之类的数。
4. 部署内容用“要”“应当”，不用“建议”“可以考虑”（`references/_shared/style/defensive.md` 第五部分）。授权下级自主选择的用“可以”。
5. 篇幅：除部署综合性工作外，一般不超过5000字；部署专项工作或具体任务的一般不超过4000字（减负规定第2条）。部署综合性工作的意见不受5000字限制，仍要压缩，超过5000字的在起草说明中提示（`references/_shared/rules/jianfu.md` 第三部分）。
6. 政治性提法只用用户提供原文中的表述；党委发文的意见叠加严谨模式，附提法核对清单。
7. 不写“纳入年度考核”“一票否决”，不要求下级制定配套文件和报送落实情况（JF-05～JF-07）；用户坚持的，在起草说明中提示。

## 三、上行意见

```text
标题：某某关于……的意见
主送：上级机关：
正文：问题和依据（简明）；意见和建议（分条，具体可行）
结语：以上意见如无不妥，请批转……执行。（请上级批转时）
```

1. 上行意见按请示的程序办：主送一个上级机关，标注签发人。
2. 建议写具体，可以用“建议”（`references/_shared/style/ai-tone.md` 第三部分）。
3. 只是请上级批准某一事项的，用请示，不用意见。

## 四、平行意见

1. 向不相隶属单位就某个问题提出见解，如会签意见、对对方工作的建议。
2. 结尾可以写“以上意见供参考”（`references/_shared/style/defensive.md` 第八部分第5条）。
3. 对方来文征求意见的，一般以函复或填写征求意见表回复，按来文要求办。

## 五、正误对照

误：一、指导思想　以……为指导，深入贯彻……精神，坚持……，着力……，为……提供坚强保障。（三百字，与本地任务无关）
正：为推进中小学课后服务提质增效，现提出以下意见。一、工作目标　到2027年，全区义务教育学校课后服务参与率达到【待补：目标值】。（目的直接写，目标值缺的标【待补】）

误：建议各学校可以考虑在开学前公布课后服务项目。
正：各学校要在每学期开学前公布课后服务项目和收费标准，具体项目由学校确定。（下行意见用要求式；“具体项目由学校确定”是授权，取自用户材料）

## 六、单位差异

| 单位类型 | 调整 |
|---|---|
| 党政机关 | 部门不得向下级党委、政府发布指令性意见（第十六条第（二）项）；以部门名义面向下级政府的，改为商洽口吻或由办公厅（室）行文（JF-16） |
| 基层 | 县级部门的意见面向乡镇时，不把执法、招商责任转嫁给村（社区）（JF-12） |
| 公立医院、高校、国有企业 | 内部意见按本单位制度；涉及教职工、职工切身利益的，提示需经教代会、职代会审议 |
| 社区、中小学 | 很少发意见；内部工作安排用通知或方案 |

## 七、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | “为……，现提出以下意见。”“为……，结合……实际，提出如下实施意见。” |
| 任务 | “……要……”“……应当于×年×月前……”；授权下级自主选择的用“……可以根据实际……” |
| 结语 | 下行意见一般不写结语；上行：“以上意见如无不妥，请批转……执行。”；平行：“以上意见供参考。” |

## 八、自检

- [ ] 方向和归属判断正确，需要逐条对应上级文件的已转 gongwen-implement。
- [ ] 开头一两句，没有大段形势背景和指导思想。
- [ ] 主要任务具体，有责任主体和时限，必须由用户定的已标【待补】；没有自增措施；用户点名的会签部门已全部列入起草说明。
- [ ] 下行意见用“要”“应当”，没有“建议”“可以考虑”。
- [ ] 篇幅在减负规定上限以内。
- [ ] 政治性提法来自用户原文；无原文的已列入“待核实”一行。
