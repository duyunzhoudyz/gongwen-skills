## 一、三种通报与相邻文种

| 种类 | 重点 | 标题 |
|---|---|---|
| 表彰通报 | 先进事迹和表彰决定，号召学习 | 某某关于表彰……的通报 |
| 批评通报 | 问题事实、性质、处理决定和警示要求 | 某某关于……问题的通报 |
| 情况通报 | 传达重要情况，提出工作要求 | 某某关于……情况的通报 |

相邻文种：
1. 重点是"发生了什么、怎么看"用通报；重点是"要做什么"用通知（`references/_shared/rules/doc-types.md` 7.6）。
2. 授予荣誉称号、给予奖励或处分的正式决定，多用决定（见 `references/doc-types/jueding.md`）；一般表扬、推广经验、警示教育用通报（实务）。用户只说"表彰一下"的，按通报写，在起草说明中写明判断。
3. 向上级反映情况用报告，向下级通报情况用通报。

## 二、结构骨架

```text
表彰通报
标题：某某关于表彰……的通报
主送：各……：
事实：时间、任务、主要事迹（集体和个人的具体做法、数据）
评价：一两句，与事实相称
决定：经……研究，决定对……等×个集体、×名个人予以通报表彰。（研究主体来自用户）
号召：希望受表彰的……；各……要……
附件：受表彰集体和个人名单
署名、成文日期

批评通报
事实：时间、单位或人员、经过、后果
定性：违反了什么规定（依据来自用户）
处理：已作出的处理决定（来自用户）
要求：举一反三的具体要求
结语：特此通报。

情况通报
情况：数据和事实（来自用户）
分析：主要问题及原因
要求：下一步具体要求
结语：特此通报。
```

## 三、各部分写法

1. 事实只用用户提供的。事迹要写具体做法和结果，没有的标【待补：主要事迹】，不编救人、加班、带病坚持之类的细节。
2. 评价与事实相称。不因为是通报就拔高（表彰）或加重（批评）定性，不写"全市领先""历史最好"一类没有依据的话。
3. 表彰决定和处理决定只写用户提供的：谁研究决定、表彰什么称号、给予什么处理。用户只有问题、没有处理决定的，以问题和当前状态收束，处理结果写【待补：处理决定】。
4. 号召和要求写具体动作，少用"认真学习、深刻反思"一类空话。
5. 名单与正文一致：正文写"×个集体、×名个人"的，与附件名单逐一核对数目。
6. 结语："特此通报。"表彰通报以号召收尾的，可以不写结语。
7. 篇幅：表彰、批评通报一般不超过2000字，情况通报一般不超过3000字（工具约定）；事实少的写短，不为凑篇幅扩写。

## 四、名单和个人信息

1. 在联网工具中起草时，受表彰个人的姓名放在附件名单里，正文用"×名同志"概括；名单中只保留姓名、单位、职务，删去身份证号、手机号等，并在起草说明"保密提示"中写明。
2. 批评通报涉及个人的，正文写"张某""某科室工作人员李某"；是否点名由用户依本单位规定决定。
3. 学生违纪、患者相关事件不发公开通报；确需内部通报的，一律脱敏，范围按本单位规定。

## 五、减负要求

1. 不按月、按季对下级排名通报（`references/_shared/rules/jianfu.md` 第8条、JF-11）。用户要求写排名的，在起草说明中提示。
2. 第8条规定不得将获得领导同志批示、在刊物和媒体刊发文章信息等作为督查检查考核内容，不把拍照留痕等作为评判工作优劣的标准。表彰依据以用户提供的评选结果为准；依据涉及上述内容的，在起草说明中提示用户核对。

## 六、正误对照

误：在文明城市创建工作中，广大干部群众不辞辛劳、无私奉献，涌现出一大批可歌可泣的先进典型。（材料中只有清理点位数和志愿服务时长）
正：9月1日至30日创建测评期间，各社区共清理卫生死角186处，志愿者累计服务【待补：时长】小时。（数字取自用户材料，缺的标【待补】）

误：（批评通报，材料中没有处理决定）对相关责任人员进行严肃追责问责。
正：相关责任人员的处理决定为【待补：处理决定】。

## 七、单位差异

| 单位类型 | 调整 |
|---|---|
| 党政机关 | 表彰须按评比表彰管理规定履行审批程序的，在起草说明中提示用户确认 |
| 基层 | 不搞按月排名通报；表彰名单核对村（社区）名称全称 |
| 社区 | 一般不发正式通报，表扬用公示或信息稿；不公开居民个人信息 |
| 公立医院 | 不良事件通报对事不对人，患者信息脱敏；医德医风批评通报的处理决定以医院研究结果为准 |
| 高校 | 学生违纪处分不超范围公开；表彰教职工按校级、部门两级分别发文 |
| 中小学 | 不发学生成绩排名通报；表彰学生的通报不写家庭情况 |
| 国有企业 | 安全生产事故通报写明事故等级和处理（来自用户）；不写未公开的经营数据 |

## 八、惯用语

| 位置 | 惯用语 |
|---|---|
| 开头 | 表彰、批评通报直接写事实："×月×日至×日，……"；情况通报："现将……情况通报如下：" |
| 决定 | "经……研究，决定对……等×个集体、×名个人予以通报表彰。""经……研究，决定给予……处理。"（研究主体和决定来自用户） |
| 结语 | 表彰通报以号召收尾："希望受表彰的……；各……要……"；批评、情况通报："特此通报。" |

## 九、自检

- [ ] 通报种类明确，结构与种类相符。
- [ ] 事迹、问题、数据、日期全部来自用户，没有编造细节。
- [ ] 评价与事实相称，没有无依据的拔高或加重。
- [ ] 表彰决定、处理决定来自用户，或已标【待补】。
- [ ] 正文数目与名单一致；名单没有身份证号、手机号。
- [ ] 没有按月、按季排名通报。
