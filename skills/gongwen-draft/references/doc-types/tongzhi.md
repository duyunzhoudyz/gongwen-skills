# 通知

适用：发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文（《党政机关公文处理工作条例》第八条第（八）项）。主要为下行文，向不相隶属单位告知需其周知的事项也可用通知。通用要点见 `references/_shared/rules/doc-types.md` 2.8，本文件写本 skill 的具体做法。

## 一、子类与判断

| 子类 | 用途 | 标题样式 | 正文篇幅上限（工具约定） |
|---|---|---|---|
| 部署性 | 布置一项具体工作 | 某某关于做好……工作的通知 | 一般3000字，专项部署4000字 |
| 会议 | 召开会议、举办培训 | 某某关于召开……会议的通知 | 800字 |
| 转发 | 转发上级、同级或不相隶属机关的公文 | 见第四部分 | 800字 |
| 批转 | 批转下级机关报来的公文 | 某某批转某某关于……的通知 | 500字 |
| 印发 | 印发本单位制定的方案、办法、要点 | 某某关于印发《……》的通知 | 500字 |
| 事务性 | 放假安排、机构调整、启用印章、任免、更正 | 某某关于……的通知 | 1000字 |

表中只是上限，事实少的写短，不为凑篇幅扩写。

判断顺序：
1. 本单位自己定的材料要发下去，用“印发”；上级、同级、不相隶属机关的文件要传下去，用“转发”；下级报来的文件经本级同意后发给其他下级，用“批转”。三个动词不混用。
2. 只布置一项具体工作，用部署性通知；提出一整套政策措施，用意见（`references/_shared/rules/doc-types.md` 7.4）。
3. 以上级文件为依据、需要拆成任务分解表和实施方案的，交 gongwen-implement；只转发、本级只加几条要求的，留在本 skill 写转发通知。
4. 会前发的是会议通知，归本 skill；会后整理的纪要和会议记录，交 gongwen-minutes。

## 二、部署性通知

```text
标题：某某关于做好……工作的通知
主送：各……：
开头：为……，根据……（用户提供的依据），现将有关事项通知如下。
一、工作任务（或：时间安排、工作内容）
二、责任分工
三、工作要求
附件：1. ……
署名
成文日期
（联系人：……，电话：……）
```

1. 开头一两句，写目的和依据。依据只写用户提供的文件名称和文号，没有的写“根据【待补：依据文件名称和文号】”。不写形势背景和重要意义（`references/_shared/rules/jianfu.md` JF-02）。
2. 每项任务写清做什么、谁来做、何时完成。责任单位和时限用户没给的标【待补】，不自定。
3. 工作要求只写有具体主体和动作的内容，删去“高度重视”“加强领导”一类空表态（JF-03）。
4. 默认不写：报送贯彻落实情况、制定配套方案、纳入年度考核、一票否决、签订责任状、上传工作照片留痕（JF-05～JF-08、JF-12）。用户坚持要写的，照写，在起草说明中提示减负规定的相关条款。
5. 措辞用“要”“应当”“于×月×日前完成”，不用“建议”“尽量”“可以考虑”（`references/_shared/style/defensive.md` 第五部分）。
6. 开头用了“现将有关事项通知如下”的，结尾“特此通知。”可以省略；本单位惯例保留的照用。

误：当前，安全生产形势复杂严峻，做好今冬明春安全生产工作具有十分重要的意义。为此，现将有关事项通知如下：
正：为做好今冬明春安全生产工作，现将有关事项通知如下。

误：建议各社区尽量在本月底前完成独居老人走访。
正：各社区要于5月31日前完成独居老人走访。（日期取自用户材料；没有的写“于【待补：完成时限】前完成”）

## 三、会议通知

| 要素 | 写法 | 用户没给时 |
|---|---|---|
| 会议名称 | 全称，与标题一致 | 【待补：会议名称】 |
| 时间 | 年月日，可加星期，写到几时几分；报到时间单列 | 【待补：会议时间】 |
| 地点 | 写到楼栋和房间；线上会议写平台和接入方式 | 【待补：会议地点】 |
| 参会人员 | 写范围和职务，如“各科室主任”；有名额限制的写明 | 【待补：参会范围】 |
| 会议内容 | 写会议主要议程；交流发言单位和时长 | 用户没给的不编议程，写【待补：会议主要内容】 |
| 报名或回执 | 方式、截止时间、报送渠道 | 【待补：回执方式和截止时间】；用户说不需要回执的不写 |
| 有关要求 | 材料准备、请假程序、着装等 | 用户没提的不加 |
| 联系人 | 姓名和电话 | 【待补：联系人及电话】 |

1. 前五项是必备要素，缺任何一项会议都开不成，必须写实或标【待补】，并在起草说明“待补事项”中排在最前。
2. 回执表、参会名单作为附件，正文写“附件：参会回执”。在联网工具中起草时，名单只写职务，姓名由用户在本地填入。
3. 交流发言、提交书面材料的要求只写用户给定的，不额外要求所有参会单位报送材料（`references/_shared/rules/jianfu.md` 第8条、JF-10）。
4. 会议要部署的事项已经发文部署过的，在起草说明中提示用户确认是否需要专门开会（JF-14）。
5. 时间写法：2026年12月9日（星期三）9时30分；不写“近期”。用户给了完整日期的，星期与日期是否对应，起草说明中提示用户核对。用户只说“下周三”“周五下午”的，正文写原话或【待补：具体日期】，不按当天日期推算，起草说明写“请确认‘下周三’对应的日期”（`references/_shared/guardrails.md` 第二条第7款）。

误：定于近期召开全校教学质量分析会，请各教研组长准时参加。
正：定于【待补：会议时间】在行政楼2楼会议室召开全校教学质量分析会。（“近期”等于没写时间，地点取自用户材料）

## 四、转发、批转通知

### （一）标题

先找最初的文件。被转发的文件本身是一份转发通知、中间机关只加了一句转发语的，直接转发最初的文件，省略中间层次。中间机关提出了具体要求、需要一并执行的，转发中间机关的文件，正文写明“连同……一并转发”。

以下两种中间层不省略，转发这一层的文件，正文引用这一层的标题和文号：
1. 中间层是“批转”：下级机关的文件经这一层批准才发给各下级，批转赋予了文件效力。
2. 中间层是政府、办公厅（室）转发部门的文件：部门文件经政府转发才对下级政府产生约束力。政府办公室转发上级政府办公厅文件这类只加转发语的层次，仍然省略。

误：某县人民政府转发市发展改革委2026年重点项目计划的通知（市政府是批转下发的，省略后看不出计划经市政府批准）
正：某县人民政府转发某市人民政府关于批转市发展改革委2026年重点项目计划的通知

再组标题。全标题只留一个“关于”，分两种写法：
- 标题写本机关名称的（默认），一律写“本机关转发……”，去掉本文的“关于”，见下表；
- 标题不写本机关名称的，写“关于转发……的通知”，并省去被转发标题中的“关于”，如“关于转发省教育厅做好冬季校园安全工作的通知”。

| 被转发文件的文种 | 标题写法 | 例 |
|---|---|---|
| 通知 | 本机关＋转发＋原发文机关＋关于＋事由＋的通知（两个“的通知”合为一个） | 某区教育局转发省教育厅关于做好冬季校园安全工作的通知 |
| 意见、办法、方案等 | 本机关＋转发＋原发文机关＋关于＋事由＋原文种＋的通知（事由与原文种之间的“的”省去） | 某县人民政府办公室转发市发展改革委关于推进城乡供水一体化实施意见的通知 |
| 印发类通知 | 本机关＋转发＋原发文机关＋关于印发《……》的通知 | 某区教育局转发市教育局关于印发《中小学课后服务管理办法》的通知 |

1. 上表写法有中央和省级的公开文件可循，如《国务院办公厅转发司法部关于审理政府信息公开行政复议案件若干问题指导意见的通知》（国办函〔2021〕132号），广东省人民政府办公厅2018年转发国办函〔2018〕55号的通知，标题为《广东省人民政府办公厅转发国务院办公厅关于加强政府网站域名管理的通知》。
2. 写了本机关名称又接“关于转发”的（如“某区教育局关于转发……”），按第一种写法改。本单位制度另有明文规定的从其规定，在起草说明中写明依据的制度和采用的写法。也有单位保留“……通知的通知”的写法，本 skill 默认不用。
3. 被转发的公文标题在标题中一般不加书名号；正文引用时加书名号并写文号（`references/_shared/rules/doc-types.md` 2.8）。
4. 有 Python 环境时，可运行 `python scripts/draft_check.py --fold-title "被转发文件的完整标题" --issuer "本机关名称"` 生成标题：推荐标题为第一种写法，备选标题为不写本机关名称的第二种写法；不传 `--issuer` 的只给第二种写法。脚本按上面两种例外保留中间层，并在提示中给出省略后的写法，由用户按本单位规定选用。

误：某区教育局关于转发某市教育局关于转发省教育厅关于做好冬季校园安全工作的通知的通知的通知
正：某区教育局转发省教育厅关于做好冬季校园安全工作的通知（市教育局只加了转发语，省略中间层次）

### （二）正文

```text
主送：各中小学、幼儿园，局属各单位：
转发语：现将《省教育厅关于做好冬季校园安全工作的通知》（某教发〔2026〕N号）转发给你们，请结合实际认真贯彻执行。
本级要求（用户提供时）：结合我区实际，提出以下要求：一、……二、……
署名
成文日期
```

1. 被转发文件的标题、文号只用用户给的，文号缺失的标【待补：原文号】。
2. 不复述被转发文件的内容。本级要求只写本地化的东西：本地重点、责任单位、本级时限，内容来自用户（JF-04）。
3. 用户说“直接转”的，只写转发语。用户要加要求但没给内容的，标【待补：本级落实要求】，不从被转发文件中摘句子凑数。
4. 报送要求：用户材料明确要求本级向下收集材料的，才在正文写报送要求，本级收集时限要早于上级时限、留出汇总时间，日期由用户定，没给的标【待补】。用户没有要求的，正文不加报送要求，只在起草说明中提示上级文件的报送时限（JF-05）。
5. 被转发文件随文附后。本单位规定要列附件说明的，按规定写。

批转：下级机关报来的文件经本级同意后发给其他下级，写“某某《关于……的意见》已经某某同意，现批转给你们，请认真贯彻执行。”同意的主体和时间只用用户给的。

## 五、印发通知

```text
标题：某某关于印发《……》的通知
主送：各……：
正文：现将《……》印发给你们，请结合实际认真贯彻执行。（需要时加一两句关键要求）
附件：……（被印发材料随文附后，或按本单位规定列附件说明）
署名
成文日期
```

1. 被印发的方案、要点、办法本身由 gongwen-report 等 skill 起草，本 skill 只写印发通知这层外壳。用户只要外壳的，不改动材料内容。
2. 正文不复述材料内容，不另写背景。施行日期写在材料中，正文不重复。
3. 不写“请于年底前报送执行情况”（JF-05）。

## 六、事务性通知

| 类型 | 必写内容 | 注意 |
|---|---|---|
| 放假、值班安排 | 起止日期、调休、值班要求、联系方式 | 日期与星期对应，在起草说明中提示核对 |
| 机构调整、更名 | 依据（批准文件）、调整内容、生效日期 | 依据文件名称和文号只用用户给的 |
| 启用印章 | 印章名称、启用日期、原印章处理 | 附印模，由用户提供 |
| 任免 | 依据（会议研究或批准文件）、姓名、职务 | 未公开的干部任免属于敏感信息，提示用户改用内网模型 |
| 更正 | 原文件名称和文号、原为什么、现改为什么 | 原文件信息只用用户给的 |

## 七、面向群众的通知

居民通知、患者须知、家长通知按以下要求写：
1. 写全时间、地点、对象、事项、要求、联系人，一句话说一件事，少用机关术语。
2. 不写没有法律依据的强制性表述，如罚款、拘留、断水断电、取消低保、“后果自负”。转达有关部门规定的，写明规定的发布部门和文件名称（只用用户给的），处罚权限归有权机关，见 `references/doc-types/tonggao.md` 第四部分。
3. 不公开个人信息：身份证号、手机号、住址、病情、救助对象详情。

误：拒不配合的，社区将上报执法部门并停止供水。
正：请各位居民于5月20日前完成登记。如有困难，请联系社区居委会（电话：【待补：社区办公电话】），我们上门办理。

## 八、单位差异

| 单位类型 | 调整 |
|---|---|
| 党政机关 | 部门不得向下级党委、政府发指令性通知（第十六条第（二）项）；需经政府同意的事项，注明“经某某人民政府同意” |
| 基层 | 面向村（社区）的通知不转嫁执法、招商等责任，不写“签订责任状”“制度上墙”（JF-12） |
| 社区 | 一般不发红头文件；对居民的通知语言通俗，带强制性的规定写明发布部门和依据 |
| 公立医院 | 院内通知可由职能部门白头发布；全院性部署用医院行文；患者须知注意隐私 |
| 高校 | 校级通知和部门通知分开，部门只就职权内事项发通知；涉及多个部门未协商一致的不发 |
| 中小学 | 致家长的通知语言通俗，不收集超出需要的学生和家庭信息 |
| 国有企业 | 公司发文与本部部门发文按公司公文管理办法区分；涉及职工切身利益的事项提示职代会程序 |

## 九、惯用语

| 子类 | 开头或转发语 | 结语 |
|---|---|---|
| 部署性 | “为……，根据……，现将有关事项通知如下。” | “特此通知。”（开头已有“通知如下”的可省） |
| 会议 | “经研究，定于……在……召开……会议。现将有关事项通知如下。” | 不写结语 |
| 转发 | “现将《……》（文号）转发给你们，请结合实际认真贯彻执行。” | 不写结语 |
| 批转 | “某某《关于……的意见》已经某某同意，现批转给你们，请认真贯彻执行。” | 不写结语 |
| 印发 | “现将《……》印发给你们，请结合实际认真贯彻执行。” | 不写结语 |
| 事务性 | “经研究，决定……。现将有关事项通知如下。” | “特此通知。” |

## 十、自检

- [ ] 子类判断正确，印发、转发、批转三个动词没有混用。
- [ ] 部署性通知每项任务有做什么、谁来做、何时完成，缺的已标【待补】。
- [ ] 会议通知五项必备要素（名称、时间、地点、参会人员、内容）都写实或已标【待补】。
- [ ] 转发通知标题只有一个“关于”，本机关名称之后没有接“关于转发”，没有“的通知的通知”；正文没有复述被转发文件。
- [ ] 没有自加报送落实情况、纳入考核、一票否决、留痕要求；用户要求写的已在起草说明中提示。
- [ ] 面向群众的通知没有无依据的强制性表述，没有个人信息。
