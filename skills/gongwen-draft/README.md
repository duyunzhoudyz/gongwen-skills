# 法定公文（gongwen-draft）

> 版本 1.0.0　成熟度：Beta（测试版）

帮机关、事业单位、国企的文字工作者起草和改写法定公文：通知、请示、报告、函、通报、批复、意见、签报，以及决定、通告、公告。它先判断该用哪个文种，再按《党政机关公文处理工作条例》查行文规则，然后按文种结构成稿。每个判断都写明条款；文号、金额这类事实和批复意见只用你给的，缺的标【待补】。

## 能做什么

| 功能 | 说明 |
|---|---|
| 判断文种 | “这事用请示还是函”“要不要写签报”，按写给谁、要办什么事、单位能用哪些文种给出结论和条款 |
| 查行文规则 | 多头主送、越级、一文多事、报告夹带请示等十余项，发现了就改，该拆分的拆分 |
| 起草 8 种常用文种 | 通知（部署、会议、转发、批转、印发、事务性）、请示、就一件事的报告、函（含复函）、通报、批复、意见、签报 |
| 起草 3 种慎用文种 | 决定、通告、公告：先核对发文权限；面向群众的通告逐句查处罚和强制措施 |
| 4 种少用文种 | 决议、命令（令）、公报、议案只给结构说明和需要你提供的信息清单 |
| 改写已有稿子 | 文种用错、行文规则有问题、结构不对的，先诊断再重写，事实一个不加 |
| 转发标题 | 把“关于转发……关于转发……的通知的通知”折叠成只有一个“关于”的标题 |

## 可以这样说

1. “领导让我给县自然资源局写个请示，景区停车场要临时用一块地。”（会告诉你对方不相隶属，应当用函，并按函来写）
2. “下周三开全校教学质量分析会，帮我发个会议通知，时间地点我发你。”
3. “市局转了省教育厅的冬季校园安全通知，我们区也要转下去，再加几条要求，标题别弄成一长串。”
4. “处里要换一批执法记录仪，帮我写个签报，报价还没拿到。”
5. “下面报来的请示领导同意了，但只同意一部分，帮我回个批复。”

## 输入

- 必需：要办的事和已知的事实。口头描述、领导批示、上级来文或原稿都可以，不用先整理。
- 最好说明：以谁的名义发、写给谁。没说的按默认处理，并在起草说明里写明。
- 批复、请示、通报中的判断（同意与否、倾向哪个方案、怎么处理）需要你给出；没给的会标【待补】，不会替你拿主意。
- 可选：单位画像 `.gongwen/单位画像.md`，里面写明可用文种和签报制度更好。没有画像也能用。
- 信息不全也会先出一稿：有题目、有一项具体事实就成稿，缺的标【待补】；需要你确认的问题最多 3 个，放在回复末尾。只有你要求先看提纲、只有题目没有任何事实、材料涉密时才不出全文。
- 指定了字数的，按目标±10%写；素材不够时，回复第一段会说明差距并列出要补的材料，不用套话凑字数。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 纯文本正文，从标题写到成文日期，可直接粘进 Word 或交给 gongwen-format 排版；拆成几份时为 `正文-报告.txt`、`正文-请示.txt` |
| `起草说明.md` | 任务卡和文种判断，所作假设，待补和待核实事项，需会签部门，修改说明和保密提示 |
| `原稿.txt` | 改写已有稿子时保存的原稿，供核对事实 |

在网页大模型里使用提示词版时，依次输出正文和起草说明；路线还有下一站的，再输出交接卡。

## 注意事项

1. **保密**：请勿输入涉密信息和内部敏感信息；材料涉密的，请使用单位内网部署的模型。材料带密级标识时会停止处理；出现身份证号、手机号时会提醒你脱敏。未公开的干部任免、未披露的经营数据，也请先确认能否输入联网工具。
2. **不编造**：文号、金额、依据文件和各类决定只用你提供的。缺的标【待补】，存疑的标【待核实】，都汇总在起草说明里。
3. **判断留给你**：批复同意不同意、请示倾向哪个方案、通报怎么处理，由你或领导决定；党纪处分、政务处分决定不起草。
4. **面向群众的文书**：不写没有法律依据的罚款、拘留和断水断电。社区和学校、医院要告知群众的，会改用通知或温馨提示。
5. **做减法**：默认不写形势背景，不加“报送落实情况”“纳入考核”“一票否决”一类要求；你坚持要写的会照写，并在起草说明中提示减负规定。
6. **以本单位制度为准**：签报和两级发文的规定，转发标题的写法，各单位不同。本单位公文处理办法与本工具默认做法不一致的，按办法执行。
7. **机检**：有 Python 环境时调用 `scripts/gongwen_lint.py` 和 `scripts/draft_check.py` 检查；没有运行时按人工清单自检，并在起草说明中注明。

## 成熟度

Beta。可以全流程起草的是“能做什么”中列出的 8 种常用文种和 3 种慎用文种；15 种法定文种和签报都能做文种判断和行文规则检查。决议、命令、公报、议案只给结构说明，纪要交 gongwen-minutes。评测用例见 `evals/`。已知局限：

- 签报、两级发文、转发标题写法按公开可查的机关和高校制度整理，医院、国企未查到可公开核实的代表性制度文本，以本单位制度为准；
- `scripts/draft_check.py` 的检查基于关键词，会漏报和误报，P2 项需人工判断；
- 决议、命令、公报、议案只给结构说明，不起草全文；国企董事会议案、决议交 gongwen-soe 行业包。
