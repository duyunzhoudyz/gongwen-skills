# 本地化改写与照抄检测

《整治形式主义为基层减负若干规定》第2条要求配套文件"直接提出具体落实措施，不得简单照搬照抄上位文件"。本文件说明什么算照抄、怎样改写成本地措施、怎样读重合检测的结果。示例均为虚构，其中的数量、单位、日期不得用于实际起草。

## 一、什么算照抄，什么不算

算照抄：
1. 任务、措施段落与上级原文连续相同15字以上（忽略标点）。
2. 只换了主语（"各地要"改"各区要"）或换了近义词，没有本单位的对象、数量、时间、责任主体。
3. 把单位名称换成别的单位，这段话照样能用。

不算照抄，可以保留：
1. 书名号内的上级文件名称、文号。
2. 标题和正文中照录的行动名称、事项名称，如"农村人居环境整治提升百日攻坚行动"。
3. 目标指标的数值照录，如"重大隐患整改率达到100%"。
4. 带引号的底线要求原文，如落实"严禁以罚代管"要求。
5. 政治性提法和上级精神的原文表述（`references/_shared/guardrails.md` 第二条第4款）。

## 二、改写成本地措施

本地内容都来自用户。用户没给的，标【待补】，不编。

| 动作 | 上级原文 → 本单位写法 |
|---|---|
| 换主体 | "各地要摸清老旧管网底数" → "市城管局牵头摸清老旧管网底数" |
| 落对象 | "人员密集场所" → "全市2650家餐饮场所和14个农贸市场" |
| 加数量和时间 | "全覆盖检查" → "11月25日前逐家检查完毕" |
| 写方法 | "督促安装报警装置" → "检查时当场下达整改通知，商户15日内自行安装，街道复查" |
| 删空话 | "提高群众安全用气意识"一类目的句，本单位方案不重复 |

缺本地材料时，保留一句任务名称，接【待补】，删掉照抄的展开：
- 误：（四）强化宣传教育培训。通过多种形式开展燃气安全宣传进社区、进企业、进学校活动，提高群众安全用气意识。（上级原文）
- 误：（四）加强安全用气宣传。采取多种方式推动燃气安全知识进社区、进企业、进校园，增强群众安全意识。（同义替换）
- 误：（四）强化宣传教育培训。通过多种形式开展燃气安全宣传【待补：场次】进社区、进企业、进学校活动。（【待补】插在照抄句中间，检测会漏掉）
- 正：（四）开展安全用气宣传【待补：宣传的组织单位、方式和场次】。

## 三、没有脚本时的人工比对

1. 按要点表逐段读方案的目标、任务、措施，对照上级对应条款，找出连续15字以上相同的句子（忽略标点）。
2. 每段问三个问题：主体是不是本单位的部门、科室？有没有本单位的对象、数量、时间？把单位名称换掉，这段还能不能照用？第一、二问答"否"或第三问答"能"的，按第二部分处理。
3. 照抄的段落占任务段落一半以上的，视为整体照抄，逐段处理。
4. 起草说明写"未运行重合检测，已人工逐段比对，处理照抄段落n段"，列出段落位置和对应上级条款。

## 四、读懂重合检测结果

命令：`python scripts/overlap_check.py 正文.txt 上级文件.txt --json`，多份上级文件依次列在后面。

| 字段 | 含义和用法 |
|---|---|
| `char_count` | 稿件正文字数，去掉空白、标点、书名号内的文件名称和【】标记 |
| `references[].percent` | 与该参照的重合率；单份上级文件看 `references[0].percent`，超过30%要处理 |
| `combined.percent` | 全部参照合计的重合率，多份上级文件时看这个 |
| `paragraphs` | 高重合段落（本段一半以上与参照相同），`line` 为稿件行号，逐段处理 |
| `references[].fragments` | 重合片段：稿件行号、参照行号、原文，用来定位照抄的句子 |
| `fragments[].quoted` | 片段在引号内（“”「」或成对的半角双引号）；核对确属指标、底线要求、提法原文的可以保留 |

处理要点：
1. 首段依据句与上级文件的目的句相同的，改成"为贯彻落实《……》，结合我市实际，制定本方案。"
2. 标题行、目标指标段被标为高重合的，行动名称和指标数值照录不算照抄，删掉前后照抄的修饰语即可，在检测结果中写明保留理由。
3. 上级的工作要求、禁止性规定被标为高重合的，改写成本单位怎么执行：谁做、用什么渠道、谁来查。原文需要保留的，加引号照录。
4. 重合率低不等于已经转化，同义替换也能降低重合率。重合率达标后，仍按第三部分的三个问题过一遍任务段落。
5. 检测结果写"重合率××%"，不写"查重通过""符合减负要求"之类的结论。
