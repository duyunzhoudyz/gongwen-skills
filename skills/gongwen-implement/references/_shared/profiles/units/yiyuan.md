# 单位类型画像：公立医院

适用于各级公立医院，包括综合医院、专科医院、中医医院。

## 一、规则基线与参照依据

| 依据 | 适用方式 | 要点 |
|---|---|---|
| 中办《关于加强公立医院党的建设工作的意见》（2018 年 6 月） | 直接适用 | 党委领导下的院长负责制；党委会议和院长办公会议议事规则；书记、院长分设 |
| 医院章程、院内公文处理办法、议事规则、签报管理规定 | 用户提供时优先 | 代字、签发权限、议题上会程序 |
| 《党政机关公文处理工作条例》、GB/T 9704-2012 | 参照 | 《条例》第四十条：其他机关和单位可以参照执行 |
| 《医疗质量管理办法》《医疗质量安全核心制度要点》 | 业务依据 | 18 项核心制度是质量类材料的基本框架 |
| 国家公立医院绩效考核（三级医院依据《国务院办公厅关于加强三级公立医院绩效考核工作的意见》，国办发〔2019〕4号）及当年操作手册 | 业务依据 | 指标名称、口径以当年手册为准 |
| 《三级医院评审标准（2022 年版）》及实施细则 | 业务依据 | 等级评审自评材料的结构依据 |

## 二、发文体系

| 发文主体 | 发文机关标志示例 | 发文字号示例 | 主要用途 |
|---|---|---|---|
| 医院党委 | 中共某医院委员会文件 | X医党发〔2026〕N号 | 党建、干部、纪检、意识形态 |
| 医院（行政） | 某医院文件 | X医发〔2026〕N号 | 医疗、运营、行政、后勤 |
| 党委办公室、院长办公室 | 部门版头或白头 | X医党办发、X医办发〔2026〕N号 | 院内事务性通知 |
| 职能部门 | 白头加盖部门章 | 以院内规定为准 | 医务、护理、质控等院内业务通知 |

代字以院内规定为准，上表只示意结构。

1. **党政两套代字**：党委发文与行政发文分开编号。属于党委、行政各自职权的事项不联合发文。
2. **部门发文**：职能部门可就职权内事项向院内科室发通知；一般不以部门名义对院外正式行文，以院内办法为准。
3. **签报**：科室向院领导请示设备购置、人员、经费、新技术新项目准入等事项，用签报或请示单；经职能部门审核、相关部门会签后报分管院领导，重大事项按程序上会。
4. **对外**：向卫生健康行政部门请示、报告；与医保部门、其他医院、高校等不相隶属单位用函。

## 三、常用文种与典型材料清单

| 频次 | 法定文种 | 常用材料 |
|---|---|---|
| 几乎每周 | 通知、纪要 | 党委会和院长办公会纪要、院内信息、新闻稿、签报 |
| 每月或每季 | 请示、报告、函、通报 | 医疗质量分析报告、院感监测报告、护理质量分析、运营分析、不良事件通报 |
| 每年 | 报告 | 院长年度工作报告（职代会）、党委工作报告、年度总结与计划、科室主任述职、绩效考核自评、满意度分析 |
| 事件触发 | 报告、通报 | 不良事件根因分析（RCA）、医疗纠纷情况报告、突发公共卫生事件信息、等级评审自评、巡视巡察和审计整改 |

## 四、决策程序与行文特点

1. **领导体制**：公立医院实行党委领导下的院长负责制。党委发挥把方向、管大局、作决策、促改革、保落实的领导作用。
2. **党委会议**：研究决定医院改革发展、财务预决算、"三重一大"、内部组织机构设置，以及涉及医务人员权益保障等重大问题。
3. **院长办公会议**：医院行政、业务议事决策机构。重要行政、业务工作先由院长办公会议讨论，再由党委会议研究决定。
4. **禁止事项**：不得以党政联席会议代替党委会议。
5. **专业委员会**：医疗质量、药事、伦理等委员会的论证意见，是相关议题上会的前置材料。
6. **行文特点**：数据密集，指标多；党建材料要写出对业务的实际作用，避免"两张皮"。

## 五、术语表

| 术语 | 解释 |
|---|---|
| 国考 | 国家公立医院绩效考核的俗称；三级公立医院指标分医疗质量、运营效率、持续发展、满意度评价四个方面；国家卫生健康委 2026 年启动 2025 年度工作的通知称"绩效监测" |
| 国家监测指标 | 国考指标体系中以"▲"标注的指标，主要由病案首页、财务年报等自动生成；2019 年版为 26 项 |
| 星号指标 | 一线口头说法，所指不一：有时指国家监测指标，有时指评审细则中带"★"的核心条款。写作时问清所指，以手册或细则原文标注为准 |
| 病案首页 | 住院病历首页数据，是国考和 DRG/DIP 的主要数据源，按月上传国家医院质量监测系统 |
| DRG | 疾病诊断相关分组，按诊断、治疗方式、病情复杂程度等把住院病例分组，医保按组付费 |
| DIP | 按病种分值付费，医保支付方式之一 |
| CMI | 病例组合指数，反映收治病例的平均技术难度，数值越高病例越复杂 |
| RW | 相对权重，某一 DRG 组资源消耗相对于平均水平的倍数 |
| 时间、费用消耗指数 | 同类病例住院时间、费用与区域平均水平之比，小于 1 表示消耗较低 |
| 四级手术 | 风险高、过程复杂、难度大、资源消耗多或涉及重大伦理风险的手术（《医疗机构手术分级管理办法》） |
| 低风险组病例死亡率 | DRG 低风险组中死亡病例的比例，反映医疗质量安全 |
| 核心制度 | 医疗质量安全核心制度，共 18 项，如首诊负责、三级查房、危急值报告 |
| 不良事件、RCA、PDCA | 医疗安全不良事件；根本原因分析；计划、执行、检查、处理循环 |
| 等级评审 | 按评审标准对医院分级评定，三级医院现行标准为 2022 年版 |
| 抗菌药物使用强度 | 以 DDDs 表示，是合理用药的常用指标 |
| MDT | 多学科诊疗 |

## 六、红线与禁忌

1. 患者隐私：姓名、病案号、住院号、身份证号、床号与姓名组合、可识别的影像资料一律脱敏，写作"患者张某，男，56 岁"。
2. 数据不可溯源：国考、质控数据须与病案首页、HIS、财务报表一致；不得编造或"修饰"指标值。
3. 议题跳过前置程序："三重一大"事项未经党委会议研究决定即执行；以党政联席会议代替党委会议。
4. 新闻稿、公众号中出现保证疗效、"治愈率 100%""最先进""根治"等表述。
5. 医疗纠纷、不良事件、院感数据未经职能部门和院办审核即对外。

## 七、年度写作节点

| 时间 | 节点与材料 |
|---|---|
| 1 月 | 上年度绩效考核自评和数据核对（2019 年各地实施方案多定在 1 月底前，近年以国家年度启动通知为准）；科室主任述职；目标责任书 |
| 1–3 月 | 年度工作会、职代会报告；年度质量安全改进工作方案 |
| 5 月 | 护士节（5 月 12 日）表彰与讲话 |
| 7 月 | 半年工作总结、半年质量分析 |
| 8 月 | 中国医师节（8 月 19 日）表彰与讲话 |
| 11–12 月 | 年终总结、次年计划、预算 |
| 每月 | 病案首页数据上传；医疗质量、院感、运营分析 |
| 按周期 | 等级评审、各类专项检查迎检 |

## 八、版式差异

1. 参照 GB/T 9704-2012；部分医院在版头加院徽，按院内办法执行。
2. 签报用院内统一的签报单：标题、主办科室、请示事项、会签科室意见、职能部门意见、院领导批示栏。
3. 党委会纪要与院长办公会纪要分开编号、分开印发。
4. 质量分析报告图表多，图表用黑白灰，便于打印。

## 九、文风特点

1. 指标名称与官方口径一致，如写"四级手术占比"，不写"大手术比例"。
2. 专业术语首次出现写全称；面向全院职工的讲话少用缩写。
3. 用数据说话，同比、环比写明基期；比率的变化用"百分点"。
4. 党建材料写具体业务成效，不写"党建引领"之类的空泛表述。

## 十、对各 skill 的提示

| skill | 提示 |
|---|---|
| gongwen-report | 科室总结关注：门急诊人次、出院人次、手术量与四级手术占比、平均住院日、CMI、次均费用、抗菌药物使用强度、不良事件上报、院感、满意度、教学科研；数据只用用户提供的，缺失标【待补】，注明数据来源系统 |
| gongwen-review | 额外检查：患者隐私；指标名称和口径是否与国考一致；百分比与百分点；对外稿件中的疗效表述；议题是否经过院长办公会和专业委员会 |
| gongwen-minutes | 党委会和院长办公会分开整理；议题材料写明前置讨论情况 |
| gongwen-draft | 科室向医院请示按画像用签报或请示；医院向卫生健康委用请示，与医保部门用函 |
| gongwen-data | 合并科室指标表时保留原始口径；国家监测指标不自行改变计算方法 |
| gongwen-speech | 职代会院长报告、医师节和护士节讲话面向医护人员，少套话，多具体人和事（由用户提供） |
