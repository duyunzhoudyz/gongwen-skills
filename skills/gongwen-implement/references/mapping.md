# 对标对表：要点表、任务分解表、核对表

本文件是第一、二步的细则。要点表把上级文件拆成一条一条，任务分解表把每一条落到本单位的人和时间，核对表逐条确认没有漏项。示例均为虚构，其中的数量、单位、日期不得用于实际起草。

## 一、上级文件要点表

先登记文件信息，只抄原文，缺的写【待补】；再列表。

```text
上级文件：某省人民政府办公厅关于开展城镇燃气安全专项整治行动的通知（某政办发〔2026〕21号，2026年9月28日）
主送：各市、县（市、区）人民政府，省政府各部门
```

| 条款 | 类型 | 要点（压缩原文） | 上级时限 | 本单位关系 |
|---|---|---|---|---|
| 二（一） | 重点任务 | 对燃气经营企业逐一检查经营许可、气瓶充装、安全制度；无证经营、违规充装依法查处 | 无单列 | 主办 |
| 四（三） | 报送要求 | 各市报送专项整治工作总结至省住房城乡建设厅 | 12月15日前 | 主办 |

一句话里既有任务又有时限的，在"上级时限"栏写明。"原则上""力争""确保""全覆盖""一律"这类定标准的词不增不减，否则加码检查失去依据。

本单位关系的判定：
1. 主办：原文点名本级或本单位（"各市""各高校""各医疗机构"），或用户说明由本单位牵头。原文写"各地要……"的，本单位是地方党委政府或其办公室的按主办；是政府组成部门的，只有本部门职责内的部分算主办，其余为协办或待确认。
2. 协办：原文或用户说明由其他单位牵头、本单位配合。
3. 不涉及：原文写明由别的主体承担（如"省住房城乡建设厅制定标准"），或用户说明与本单位职责无关，理由写进核对表。
4. 待确认："有关部门按职责分工负责"之类，原文和用户都没有说清的。不靠部门名称猜。

## 二、任务分解表正误对照

各列的填法见本 skill 第二步。

1. 任务栏
   - 误：深入开展燃气经营企业安全检查，切实消除风险隐患。（上级原句换了个开头）
   - 正：对全市52家燃气经营企业逐家检查经营许可和气瓶充装记录，对无证经营、违规充装的移交执法。
   - 正（缺本地材料）：对全市燃气经营企业逐家开展检查【待补：企业数量和检查方式】。
2. 牵头单位
   - 误：牵头单位：市住房城乡建设局、市市场监管局。（两个牵头等于没有牵头）
   - 误：牵头单位：各科室。（不是属地任务，谁也不负总责）
   - 正：牵头单位：市住房城乡建设局；配合单位：市市场监管局。几个部门分头办的拆成几行，各有一个牵头；属地任务写"各街道办事处（区消防安全委员会办公室统筹）"。
3. 完成时限
   - 误：长期坚持。误：12月31日前。（上级要求12月10日前完成排查）
   - 正：12月4日前。（用户确认，或用户授权倒排）
4. 成果形式
   - 误：工作台账、影像资料、学习笔记。（上级没有要求的留痕）
   - 正：隐患问题清单和整改销号记录。（上级原文要求"建立问题隐患和整改措施清单"）上级和用户都没说的，写【待补：成果形式】。

## 三、对标对表核对表

放在起草说明中，标题为"附：对标对表核对表"。

| 上级条款 | 要点（简） | 本单位关系 | 对应任务或段落 | 结论 |
|---|---|---|---|---|
| 二（一） | 燃气经营企业检查 | 主办 | 任务1 | 已对应 |
| 四（二） | 严禁以罚代管 | 主办 | 方案"四、工作要求"第2条 | 已对应 |
| 附件第3项 | 省级部门修订燃气安全标准 | 不涉及 | 无 | 不涉及：原文由省住房城乡建设厅承担 |
| 二（三） | 老旧管网更新改造清单 | 主办 | 无 | 漏项：已补任务3，措施【待补】 |

1. "待确认"的条款，结论栏写"待确认：请明确是否由本单位承担"，同时列入起草说明的待核实事项。
2. 反向核对：对应条款为"本单位自定"的任务，在表末单列，注明加码检查的结论。
3. 落实情况报告阶段沿用同一张核对表，任务序号不变，便于逐项报进展。

## 四、多份上级文件

1. 每份文件给一个代号（甲、乙），条款号写成"甲二（一）""乙3"；能写文件的环境，比对副本存为 `上级文件-甲.txt`、`上级文件-乙.txt`。
2. 同一事项几份文件都有要求的，合并为一行任务，条款号都写上。
3. 要求不一致的（时限不同、指标不同），列入起草说明"附：上级要求差异表"（事项、各文件的要求和条款、本稿取法）；默认时限取较早的、指标按直接上级文件，写进"所作假设"，请用户确认。
4. 既有国家文件又有省级文件的，以直接上级的文件为主拆任务，国家文件用来核对有没有遗漏。
