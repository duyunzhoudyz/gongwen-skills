# 对标对表：要点表、任务分解表、核对表

本文件是第一、二步的细则。示例均为虚构。

## 一、上级文件要点表

先登记文件信息，只抄原文，缺的写【待补】；再列表。

```text
上级文件：某省人民政府办公厅关于开展住宅电梯安全隐患专项整治行动的通知（某政办发〔2026〕37号，2026年4月16日）
主送：各市、县（市、区）人民政府，省政府各部门
```

| 条款 | 类型 | 要点（压缩原文） | 上级时限 | 本单位关系 |
|---|---|---|---|---|
| 二（一） | 重点任务 | 对住宅小区在用电梯逐台检查维保记录、安全保护装置、应急救援电话；超期未检、带病运行的依法查处 | 无单列 | 主办 |
| 四（三） | 报送要求 | 各市报送专项整治工作总结至省市场监管局 | 7月20日前 | 主办 |

一句话里既有任务又有时限的，在“上级时限”栏写明。“原则上”“力争”“确保”“全覆盖”“一律”这类定标准的词不增不减，否则加码检查失去依据。

本单位关系的判定：
1. 主办：原文点名本级或本单位（“各市”“各高校”“各医疗机构”），或用户说明由本单位牵头。原文写“各地要……”的，本单位是地方党委政府或其办公室的按主办；是政府组成部门的，只有本部门职责内的部分算主办，其余为协办或待确认。
2. 协办：原文或用户说明由其他单位牵头、本单位配合。
3. 不涉及：原文写明由别的主体承担（如“省市场监管局制定维保质量评价办法”），或用户说明与本单位职责无关，理由写进核对表。
4. 待确认：“有关部门按职责分工负责”之类，原文和用户都没有说清的。不靠部门名称猜。

## 二、任务分解表正误对照

各列的填法见本 skill 第二步。

1. 任务栏
   - 误：深入开展住宅电梯安全检查，切实消除风险隐患。（上级原句换了个开头）
   - 正：对全市1386台住宅电梯逐台检查维保记录和安全保护装置，对超期未检、带病运行的移交执法。
   - 正（缺本地材料）：对全市住宅电梯逐台检查，不写台数。
2. 牵头单位
   - 误：牵头单位：市市场监管局、市住房城乡建设局。（两个牵头等于没有牵头）
   - 误：牵头单位：各科室。（不是属地任务，谁也不负总责）
   - 正：牵头单位：市市场监管局；配合单位：市住房城乡建设局。几个部门分头办的拆成几行，各有一个牵头；属地任务写“各街道办事处（区市场监管局统筹）”。
3. 完成时限
   - 误：长期坚持。误：7月31日前。（上级要求7月10日前完成排查）
   - 正：7月3日前。（用户确认，或用户授权倒排）
4. 成果形式
   - 误：工作台账、影像资料、学习笔记。（上级没有要求的留痕）
   - 正：隐患问题清单和整改销号记录。（上级原文要求“建立隐患问题和整改责任清单”）上级和用户都没说的，按任务性质写常规成果，不新增留痕。

## 三、对标对表核对表

放在起草说明之后，标题为“附：对标对表核对表”。

| 上级条款 | 要点（简） | 本单位关系 | 对应任务或段落 | 结论 |
|---|---|---|---|---|
| 二（一） | 住宅电梯检查 | 主办 | 任务1 | 已对应 |
| 四（二） | 不得向物业企业摊派检测费用 | 主办 | 方案“四、工作要求”第2条 | 已对应 |
| 附件第3项 | 省级部门制定维保质量评价办法 | 不涉及 | 无 | 不涉及：原文由省市场监管局承担 |
| 二（三） | 老旧电梯更新改造项目清单 | 主办 | 无 | 漏项：已补任务3 |

1. “待确认”的条款，结论栏写“待确认：请明确是否由本单位承担”，同时列入起草说明“待核实”一行。
2. 反向核对：对应条款为“本单位自定”的任务，在表末单列，注明加码检查的结论。
3. 落实情况报告阶段沿用同一张核对表，任务序号不变，便于逐项报进展。

## 四、多份上级文件

1. 每份文件给一个代号（甲、乙），条款号写成“甲二（一）”“乙3”；能写文件的环境，比对副本存为 `上级文件-甲.txt`、`上级文件-乙.txt`。
2. 同一事项几份文件都有要求的，合并为一行任务，条款号都写上。
3. 要求不一致的（时限不同、指标不同），列入“附：上级要求差异表”（事项、各文件的要求和条款、本稿取法）；默认时限取较早的、指标按直接上级文件，写进起草说明“假设”，请用户确认。
4. 既有国家文件又有省级文件的，以直接上级的文件为主拆任务，国家文件用来核对有没有遗漏。
