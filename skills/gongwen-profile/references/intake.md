## 一、分轮问卷

### （一）轮次

每轮最多 3 问，跳过和补位规则见 SKILL.md 功能一第三步。

| 轮次 | 问什么（对应字段） | 跳过条件 |
|---|---|---|
| 第一轮　基本情况 | 单位类型（含级别）；层级与隶属；写作角色和默认模式 | 已有简版画像或交接卡已写明 |
| 第二轮　发文体系 | 发文字号格式（含是否党政两套代字）；红头或白头、印发机关；内部文种（签报、呈批件） | 用户说"我们不发正式文件"时只问内部文种 |
| 第三轮　写作习惯 | 常写文书；决策程序；篇幅偏好 | 角色是业务科室兼职写作的，决策程序可跳过 |
| 第四轮　约束和配套 | 红线与禁用表述；本单位制度文件；是否要建领导偏好卡、文风参数 | 用户说"就这些"时整轮跳过 |

"单位名称或代号""发文机关标志""可用文种"不单独问：用户顺带说了就填；没说的，单位名称写代号或留空，其余留空，读取时采用单位类型默认值。

### （二）问法

1. 每题带选项，选项取自单位类型画像，用户可以只回"一样""第 2 个"。
2. 一题只问一件事，不追问细节；用户答得含糊的照原话记，写【待核实：说明】。

误（一次问 6 件事，还问了领导姓名）：
请问您单位的全称是什么？领导是谁？发文字号怎么写？有几个科室？一年发多少文件？常写什么？

正（第二轮，公立医院）：
1. 发文字号是不是党委、行政两套？比如党委"X医党发〔2026〕N号"、行政"X医发〔2026〕N号"。不一样的话，照一个真实的编号格式写给我（序号可以写 N）。
2. 科室向院领导请示用什么？签报、请示单，还是直接打报告？
3. 院级文件一般用红头，职能部门的院内通知用白头加部门章，你们也是这样吗？

### （三）答案落到字段

| 用户的回答 | 写入 |
|---|---|
| "一样""对" | 选项内容，来源写"用户确认" |
| 说了具体写法 | 照原话，来源写"用户告知" |
| "不清楚""回头问问" | 留空，列入待补事项 |
| "我们没有发文权" | 发文字号格式写"无（用户告知）"；平时以什么名义行文，列入待补事项或下一轮再问，不替用户补 |
| 前后两次说法不一 | 取后一次，写【待核实：前后说法不一】 |

## 二、从制度文件和已发文件提取

### （一）字段与条文对照

| 字段 | 一般在哪一章 | 找这些词 |
|---|---|---|
| 发文机关标志 | 公文格式、版头 | 发文机关标志、版头、文件格式 |
| 发文字号格式 | 公文格式、发文字号 | 发文字号、机关代字、六角括号、年份 |
| 红头或白头 | 公文种类、格式 | 文件格式、信函格式、便函、部门通知 |
| 印发机关 | 版记 | 印发机关、印发日期 |
| 党政两套代字 | 发文权限、行文规则 | 党委发文、行政发文、联合行文 |
| 可用文种 | 公文种类 | 公文种类主要有、适用于 |
| 内部文种 | 签报管理、请示报告 | 签报、呈批件、请示单、会签 |
| 决策程序 | 议事规则、"三重一大" | 前置研究、党委会、院长办公会、校长办公会、董事会 |
| 篇幅偏好 | 文风、精简文件 | 篇幅、字数、不超过、精简 |
| 红线与禁用表述 | 保密、信息公开、宣传 | 不得、严禁、保密、对外发布 |
| 写作角色和默认模式 | 制度文件里没有 | 只能问 |

### （二）提取规则

1. 只记条文写明的内容，括注文件名和条款号，如"（《某医院公文处理办法》第十二条）"。
2. 条文写"参照国家有关规定"而没写具体做法的，不替它展开，字段留空。
3. 写有"本办法自印发之日起试行"而不知是否转正的，同超过 5 年的一样，写【待核实：办法为2019年版，请确认是否修订】。
4. 一份文件里前后矛盾的，两种都记，写【待核实：第几条与第几条不一致】。

误：发文字号格式：按国家标准执行（制度文件没写，模型自己补了一句）
正：发文字号格式：（留空，起草说明待补事项写"制度文件未规定发文字号格式，请补充一个真实编号的格式"）

### （三）从已发文件提取

用户给了本单位已发的红头文件（有版头和版记即可，不必是全文）时，只看版式，不看内容：

| 文件部位 | 对应字段 | 怎么写 |
|---|---|---|
| 版头 | 发文机关标志；红头或白头 | 照录机关名称加"文件"；党委、行政两种版头都有的分别写 |
| 发文字号 | 发文字号格式；党政两套代字 | 代字照录，年份写"年"，序号写 N，如"X医发〔年〕N号" |
| 版记 | 印发机关 | 照录"印发机关"一栏的名称 |
| 标题末尾的文种 | 可用文种 | 只记出现过的文种，不据此推断"只用这几种" |

1. 来源写"据 2025 年已发文件版式（n 份）"；只有 1 份样本的，字段后写【待核实：仅据 1 份已发文件】。
2. 已发文件与制度文件不一致的（如办法规定六角括号，已发文件用方括号），两种都记，写【待核实：已发文件与办法第几条不一致】。
3. 文件有密级或内部标注的，按 SKILL.md 开工检查第 1 条停下，不提取。

## 三、各单位类型的问法和要点

| 单位类型 | 问卷中给的选项 | 另外要问 | 常见误填 |
|---|---|---|---|
| 党政机关 | 党委、政府、办公厅（室）、部门各自代字；处室用签报或呈批件 | 上行文由谁签发 | 把部门内设机构写成可以对外行文 |
| 基层 | 乡镇或街道代字；党委、政府两套 | 是否有当地减负清单、信息报送积分要求 | 把上级部门的代字当成本级 |
| 社区 | 一般无发文字号；以居委会、村委会名义发通知、告知书 | 通知张贴在哪里、是否发居民群 | 编一个发文字号 |
| 公立医院 | 党委、行政两套代字；科室向院领导用签报；重要事项先院长办公会再党委会 | 院内办法对签报会签的要求 | 把党政联席会写成决策会议 |
| 高校 | 校级和部门两级；部门不对校外正式行文；校内请示走党政办 | 学院能否发文、学院代字 | 学院直接对校外行文 |
| 中小学 | 校发；党组织会议、校长办公会；报教育局用请示、报告 | 教育局对篇幅、报送渠道的要求 | 照抄党政机关的 15 个文种 |
| 国有企业 | 党委、行政两套代字；签报；党委前置研究，再到董事会或经理层；议案 | 前置研究事项清单是否单独印发；所属层级（集团、子公司） | 把前置研究写成代替董事会决策 |
