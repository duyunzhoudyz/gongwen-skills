# 花脸稿学习：对照方法、改动分类、偏好条目

## 一、没有脚本时人工对照

1. 两稿按段编号，段内按句号、问号、感叹号、分号切句；先找两稿相同的句子作锚点，再比锚点之间的句子。文字很长的，先对照每段首尾句定位，再细看改动多的段落。
2. 每处改动记一行：位置（第几段第几句）、类型（删除、新增、改写、调整顺序、拆句、合句）、原稿片段、改稿片段；改写句逐字看删、加、换了哪些词。
3. 批注单独记：批在哪句话上、批了什么。
4. 记完统计：两稿各多少字；每类改动几处；同一个词被删或被换了几次。

## 二、改动分类

| 类别 | 怎么认 | 归纳成的偏好（示例） | 写进偏好卡哪一节 |
|---|---|---|---|
| 删评价词 | 删去“显著”“大力”“全面”“深入”等形容词、副词 | 删评价词，用数据说话 | 忌用表述 |
| 换词 | 同一位置 A 换成 B，多次出现 | 用“推动”不用“赋能” | 用词偏好·偏好的替换 |
| 删铺垫 | 删去首段的背景、意义、“在……领导下” | 开门见山 | 讲话风格·结构习惯 |
| 删表态 | 删去“我们将坚决……”“全力以赴” | 不写空泛表态，写具体安排 | 忌用表述 |
| 数据前置 | 数据挪到句首，或把“明显提升”改成具体数字 | 先说结果；数据代替评价 | 数据呈现偏好 |
| 数据口径 | 百分比改百分点，补基期，减少连用数字 | 比率变化用百分点 | 数据呈现偏好 |
| 拆长句 | 一句拆成两三句 | 多用短句 | 讲话风格·口语或书面 |
| 调整顺序 | 段落或句子换位置，如问题挪到成绩前 | 先讲问题再讲成绩 | 讲话风格·结构习惯 |
| 语气 | “建议”“可以考虑”改成“要”，或加上时限 | 部署写成要求，带时限 | 用词偏好 |
| 标题 | 小标题改成对仗、改短、去掉数字概括 | 小标题四字对仗 | 讲话风格·结构习惯 |
| 篇幅 | 整体删减三成以上 | 汇报不超过某字数 | 篇幅偏好 |
| 引用 | 删去或加上引文、上级讲话 | 引用须注明出处 | 引用习惯 |
| 批注意见 | 批注写“太虚”“数据呢”“开头太长” | 按批注内容归入上面各类 | 对应各节 |

不归纳为偏好的改动：
1. 事实更正：原有数字改成另一个数字（“4.6万人次”改“4.9万人次”），日期、人名、单位名称、文号改了。按 SKILL.md 功能三第三步第 1 条单列提醒。概括词换成具体数字的（“部分街道”改“5个街道”）不算，按上表“数据前置”处理。
2. 错别字、标点、格式更正：交给机检和 gongwen-review。
3. 一次性的内容取舍：删掉某项具体工作、加了领导临时交办的内容。
4. 对人的评价、情绪化的批注：“写的什么东西”“谁写的”。

## 三、偏好条目写法

格式：`- 做法（例：原稿片段→改稿片段；n 份稿件 m 处；来源日期 稿件类型；状态）`

1. 做法：动词开头，能照着做。例：“删去‘显著’‘大力’等评价词，改用数据”。
2. 例证：不超过 20 字，去掉人名、单位全称和具体数据，必要时把数字改成“×”。
3. 次数：写份数和处数，门槛见 SKILL.md 功能三第四步第 3 条。状态：2 份以上的省略；只有 1 份的只进改稿记录，在“归纳的偏好”栏该条后标“（观察中）”；1 份 3 处以上经用户确认的写“用户确认”；口述的写“用户告知”或“本人口述”。
4. 升级：学新稿件前先列出改稿记录里标“（观察中）”的偏好，与本次逐条比对，按 SKILL.md 功能三第五步第 3 条合并计份（polish 追加的行处数不详），原记录行不删。
   - 例：6 月“开门见山（观察中）”，9 月新稿又删首段铺垫，合计 2 份，写入“讲话风格·结构习惯：删去首段铺垫，开头直接写结果（2 份稿件 3 处；2026-06-05、2026-09-17）”，6 月行改“（已归纳）”。
5. 来源：改稿日期和稿件类型，多次的依次追加。只在某类文书出现的，写明“（讲话稿）”“（汇报材料）”。

## 四、冲突的问法

一次问完，最多 3 条：

```text
新学到的偏好和偏好卡里原有的说法有冲突，请选一下：
1. 原卡“常用：打造”，这次区长把 3 处“打造”都改成了“建设”。
   A. 以新为准，“打造”改列忌用  B. 保留原条目  C. 按文书类型区分（讲话保留，汇报不用）
```

## 五、写入示例

偏好条目写进卡内对应一节（节名照 profile-template.md 第二部分），卡首“更新日期”同步改；改稿记录每份稿件一行。虚构示例：

```markdown
| 2026-09-17 | 供暖保障工作汇报 | 删首段铺垫 1 处；“打造”改“建设”3 处；供暖面积数据更正 1 处（事实更正，不计偏好） | 用“建设”替代“打造”；开门见山（观察中） |
```
