## 一、文风参数.md 模板

一类文书一节。样本不足 2 篇的类型并入"综合"一节。脚本统计的量化参数写中位数和范围（P25～P75），不写平均数；人工估算的写"约 N（最短 a～最长 b），人工估算"，不写四分位（见第三部分）。

```markdown
# 文风参数（由 gongwen-profile 生成，可手动修改）

## 汇报材料
- 样本：3 篇，2025—2026 年，均经领导审定，已脱敏
- 统计方式：style_profile.py（或"人工估算"）

### 一、量化参数
| 参数 | 本单位 | 起草时怎么做 |
|---|---|---|
| 篇幅 | 2600 字（2300～2900） | 汇报材料默认按 2600 字左右安排 |
| 句长 | 38 字（31～46） | 句子比一般公文略短，超过 60 字的拆开 |
| 段长 | 150 字（120～190） | 一段只讲一件事 |
| 标题层级 | 一级 4 个（3～5），二级每篇 8 个（6～10） | 二级标题下不再分三级 |
| 一级标题句式 | 动词＋对象，8 字左右；对仗式占一半 | 小标题用"动词＋对象"，可两两对仗 |
| "一是……"使用率 | 每千字 2.1 处；3 篇都用 | 段内列举用"一是……二是……" |
| 顿号、冒号、破折号 | 每千字 18、4、0 个 | 不用破折号 |
| 措辞层级 | "必须""严禁"每千字 0.3 次；"建议"0 次 | 部署内容用"要"，"必须"留给底线要求 |
| 数据密度 | 每千字 22 个数字；3 篇都用百分数 | 成效段落每段至少一个数据，没有的标【待补】 |

### 二、高频表述
- 四字格：统筹推进（9 次/3 篇）、扎实开展（6 次/3 篇）
- 惯用语：开头"现将……汇报如下"（3 篇）；结尾"以上汇报，不妥之处，请批评指正"（3 篇）
- 标题领起词：强化（5 次/3 篇）、推进（4 次/2 篇）

### 三、定性观察
1. 开头：3 篇都在首段写总体数据，再引出下文。
2. 结构：先成效后问题，问题和下一步一一对应。
3. 标题：一级标题四字对仗，二级标题动宾短语。
4. 语气与措辞：部署用"要"，少用"必须"。
5. 数据呈现：数据放在句首，同比写百分比，比率变化写百分点。
6. 结尾：停在下一步安排上，加汇报结束语。
7. 过渡：段首多用"一是""同时"，不用"首先""其次"。

### 四、起草时的总体要求
（3～5 条，从上面各项提炼，按重要程度排）

### 五、不采纳的习惯
- 3 篇中 2 篇首段有"在……的坚强领导下"类铺垫：起草时开门见山；领导偏好卡要求保留的，压缩成一句
- 2 篇段首用"值得注意的是"：不用

## 维护记录
- 2026-10-16：首次学习，汇报材料 3 篇（gongwen-profile）
```

填写要求：
1. 不写原文段落、整句、标题原文和业务数据；四字格、惯用语、领起词只写短语本身。
2. 标题句式写成抽象格式，如"动词＋对象，8 字左右""四字对仗"。
3. "起草时怎么做"一栏每格一句，写成可以照做的要求，如句长中位数低于 40 字的写"长句拆短"，破折号接近 0 的写"不用破折号"，数据前置的写"成效句先写数据，没有的标【待补】"。参数是参考范围，事实不够时篇幅从短，不为贴近参数而扩写。
4. 样本没有审定的，在"样本"行写"初稿，未经领导审定"。

## 二、定性观察 7 项

每项写成"做法＋频次"，频次写"n 篇中 m 篇"。

| 观察项 | 看什么 |
|---|---|
| 开头方式 | 首段第一句是总体数据、依据（"根据……"）、背景铺垫还是直接引出 |
| 结构安排 | 成效、问题、打算的先后和篇幅比例；问题与措施是否对应 |
| 标题风格 | 字数、对仗、领起词、是否含数字概括 |
| 语气与措辞层级 | 必须、要、可以、建议各用在哪里；有无对冲语气 |
| 数据呈现 | 数据在句首还是句尾；同比、环比、百分点的写法；数据密度 |
| 结尾方式 | 结束语、号召式、停在具体安排上 |
| 常用过渡 | 段首用语、承上启下的句式 |

误：标题风格：如"强化党建引领　筑牢发展根基""深化改革创新　激发内生动力"（照抄标题原文）
正：标题风格：一级标题为两个四字短语对仗，中间空一格；4 篇中 3 篇如此

## 三、没有脚本时人工估算

在网页版或没有 Python 时使用，参数后注明"人工估算"。

1. 篇幅：数每篇正文字数（不含空白）；篇幅长、无法逐字数的，按段数乘段长估算。
2. 句长：每篇抽 3 段（开头、中间、结尾各 1 段），数每段字数和句号个数，字数除以句数，3 篇取中间值。
3. 段长：同样抽的段落，取字数的中间值。
4. 标题：数一级、二级标题个数和一级标题字数。
5. "一是……"：每篇有没有用，最多列到第几项。
6. 标点：破折号、"值得注意的是"一类的有没有，有几处；顿号多不多（多到一段里有 5 个以上即为"较多"）。
7. 高频表述：通读时把两篇以上都出现的四字格、开头和结尾套语记下来，只记短语。

估不准的项写"未统计"，不编数值。人工估算的参数写成"约 N（最短 a～最长 b），人工估算"，不写 P25、P75 这类四分位，也不写到小数。

## 四、不采纳的习惯

历史稿中出现、但与本项目规则冲突的写法，记入"五、不采纳的习惯"，起草时不模仿。2 篇以上都有的才记；只有 1 篇的不记。

| 习惯 | 依据 |

| "不是……而是……"对举 | 同上（二） |
| 破折号、"核心是："一类提示性冒号过密 | 同上（三） |
| 首段写形势背景、重要意义，"在……领导下"铺垫 | `references/_shared/guardrails.md` 第四条；ai-tone.md（十） |

以下属于公文正当写法，照常记为本单位习惯：一是二是、四字格、排比式小标题、"现将……如下"、"以上汇报，不妥之处，请批评指正"、密集的顿号并列（ai-tone.md 第二部分）。
