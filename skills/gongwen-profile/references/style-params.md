# 文风参数：补充项、观察项、人工估算、不采纳清单

## 一、文风参数.md 的写法

格式照 `references/_shared/profiles/profile-template.md` 第四部分：一类文书一节，每节依次写样本行、量化参数表（参数｜本单位｜起草时怎么做）、高频四字格和套语、不采纳的习惯，文件末尾一节“## 维护记录”。按需补充：

1. 量化参数表可加两行：措辞层级（“必须”“严禁”“建议”每千字各几次）、数据密度（每千字几个数字，是否用百分数）。
2. 高频表述之后加“定性观察”，按第二部分 7 项各写一句；再加“起草时的总体要求”3～5 条，按重要程度排。
3. 样本行照模板写，未经领导审定的写“初稿，未经领导审定”。

虚构片段，只示补充项：

```markdown
| 措辞层级 | “必须”“严禁”每千字 0.4 次；“建议”0 次 | 部署内容用“要”，“必须”留给底线要求 |
| 数据密度 | 每千字 17 个数字；5 篇都用百分数 | 成效段落每段至少一个数据，没有的标【待补】 |

- 定性观察：开头，5 篇中 4 篇首段先写总体数据；结尾，5 篇都停在下一步安排上
- 起草时的总体要求：开门见山，首段写总体数据；小标题用“动词＋对象”；不用破折号
```

填写要求：
1. 脚本统计的写中位数和范围（P25～P75），不写平均数；人工估算的写法见第三部分。
2. 不写原文段落、整句、标题原文和业务数据；四字格、套语、标题领起词只写短语本身；标题句式写成抽象格式，如“动词＋对象，8 字左右”“四字对仗”。
3. “起草时怎么做”每格一句，写成可以照做的要求，如句长中位数低于 40 字的写“长句拆短”，破折号接近 0 的写“不用破折号”。参数是参考范围，事实不够时篇幅从短，不为贴近参数而扩写。

## 二、定性观察 7 项

每项写成“做法＋频次”，频次写“n 篇中 m 篇”：
1. 开头方式：首段第一句是总体数据、依据（“根据……”）、背景铺垫还是直接引出。
2. 结构安排：成效、问题、打算的先后和篇幅比例；问题与措施是否对应。
3. 标题风格：字数、对仗、领起词、是否含数字概括。
4. 语气与措辞层级：必须、要、可以、建议各用在哪里；有无对冲语气。
5. 数据呈现：数据在句首还是句尾；同比、环比、百分点的写法；数据密度。
6. 结尾方式：结束语、号召式、停在具体安排上。
7. 常用过渡：段首用语、承上启下的句式。

误：标题风格：如“夯实基层基础　提升治理效能”（照抄标题原文）
正：标题风格：一级标题为两个四字短语对仗，中间空一格；5 篇中 4 篇如此

## 三、没有脚本时人工估算

网页版或没有 Python 时使用，参数后注明“人工估算”。

1. 篇幅：数每篇正文字数（不含空白）；太长的按段数乘段长估算。
2. 句长：每篇抽开头、中间、结尾各 1 段，字数除以句号个数，各篇取中间值。
3. 段长：同样抽的段落，取字数的中间值。
4. 标题：数一级、二级标题个数和一级标题字数。
5. “一是……”：每篇有没有用，最多列到第几项。
6. 标点：破折号、“值得注意的是”一类有几处；顿号一段 5 个以上即为“较多”。
7. 高频表述：两篇以上都出现的四字格、开头和结尾套语，只记短语。

估不准的项写“未统计”，不编数值。人工估算写“约 N（最短 a～最长 b），人工估算”，不写 P25、P75 这类四分位，也不写到小数。

## 四、不采纳的习惯

历史稿中出现、与本项目规则冲突的写法，2 篇以上都有的记入“不采纳的习惯”，起草时不模仿；只有 1 篇的不记：

1. 段首评论语（“值得注意的是”“毋庸置疑”）；“不是……而是……”对举；破折号、“核心是：”一类提示性冒号过密（`references/_shared/style/ai-tone.md` 第一部分（一）至（三））。
2. 首段写形势背景、重要意义或“在……领导下”铺垫（`references/_shared/guardrails.md` 第四条；ai-tone.md（十））；“取得明显成效”后面没有数据（ai-tone.md（七））。
3. “仅供参考”“建议考虑”“尽量”等免责和对冲（`references/_shared/style/defensive.md` 第一、三、五部分）。
4. 照抄上级文件原文（guardrails.md 第四条第 3 款）；篇幅超过减负规定上限（`references/_shared/rules/jianfu.md`）。

以下属于公文正当写法，照常记为本单位习惯：一是二是、四字格、排比式小标题、“现将……如下”、“以上汇报，不妥之处，请批评指正”、密集的顿号并列（ai-tone.md 第二部分）。
