# 单位画像与文风学习（gongwen-profile）

> 版本 1.0.0　成熟度：Beta（测试版）

把“我们单位怎么写材料、领导喜欢怎么改”记下来，以后起草、改稿、核稿时其他 gongwen skill 自动照着办。它建立和维护 `.gongwen/` 目录下的四个纯文本文件：单位画像、领导偏好卡、禁用词、文风参数。你可以随时打开手改。

它只负责建档、学习和维护，不替你写稿、改稿。

## 能做什么

| 功能 | 说明 |
|---|---|
| 完整建档 | 分几轮问你，每轮最多 3 个问题；或者直接读你们的公文处理办法、议事规则、签报管理规定，把发文字号、党政两套代字、内部文种、决策程序等字段提取出来，注明出自哪一条；也可以从已发的红头文件的版头、发文字号、版记里提取格式 |
| 文风学习 | 读 3～10 篇本单位历史稿，统计句长、段长、各级标题、“一是……”用得多不多、顿号和破折号密度、高频四字格和套语、篇幅分布，再归纳开头、结构、数据呈现等习惯。只记参数和习惯，不保存原文 |
| 花脸稿学习 | 给它原稿和领导改过的稿子，或者一份带修订痕迹、批注的 Word 文档，它逐句对比，归纳出领导的偏好（如“删形容词”“数据前置”“不用‘着力’”），每条带例证、次数和日期，追加到领导偏好卡。你直接告诉它的偏好（“局长讲话不引古诗词”）也能记进去 |
| 禁用词管理 | 增删禁用和慎用表述，每条写明级别、原因、替换建议、适用范围 |
| 画像体检 | 查字段缺漏、与同类单位常见做法的差异、可能过期的信息、画像里有没有混进人名电话 |

## 可以这样说

1. “我刚调到医院院办，帮我把单位画像建完整，我们的公文处理办法发你了。”
2. “这几篇是我们局这两年的年终总结和汇报材料，你学学我们的文风。”
3. “这是院长改过的汇报稿，红色的都是他改的，你看看他喜欢怎么写。”
4. “记一下，局长不喜欢‘打造’‘赋能’这种词，以后写他的材料别用。”
5. “我们的画像是去年建的，帮我看看有没有过时的地方。”

## 输入

- 完整建档：回答问卷即可；有本单位公文处理办法、议事规则的，发给它会少问很多。
- 文风学习：3～10 篇本单位历史稿（.txt、.docx、.md，或直接粘贴），最好是领导审定过的定稿。请先删去人名、电话、证件号。
- 花脸稿学习：原稿和改稿两份；或一份带修订痕迹的 .docx。告诉它改稿的是哪位领导（写职务即可）、改稿日期。
- 禁用词、体检：直接说。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，写入当前目录的 `.gongwen/`：

| 文件 | 内容 |
|---|---|
| `单位画像.md` | 单位类型、发文体系、决策程序、写作角色、篇幅偏好、信息报送要求、红线等 18 个字段，每项注明来源 |
| `领导偏好卡.md` | 一位领导一张卡：用词、忌用、数据呈现、篇幅、引用习惯、历次改稿记录 |
| `禁用词.md` | 禁用、慎用表述表 |
| `文风参数.md` | 按文书类型分节的量化参数、高频表述、定性观察、起草时怎么做、不采纳的习惯 |

修改已有文件前，它会先列出变更单（原内容、改为、来源），你同意后才改，并把旧版本备份到 `.gongwen/历史/`。

在网页大模型里使用提示词版时，它输出完整的文件文本，请你自己保存，下次使用时粘贴在对话开头。

## 注意事项

1. **保密**：请勿输入涉密信息和内部敏感信息；材料涉密的，请使用单位内网部署的模型。历史稿、改稿带密级标识或“内部资料”“工作秘密”“严禁外传”等字样的，它会停下来不处理这一份；你说明是在内网模型上使用、已删去相关内容，或标识是误加的，它再继续。
2. **画像里不存个人信息**：不存人名、电话、证件号；领导只写职务；偏好卡只记写作偏好，不记对领导个人的评价。修订痕迹里的修订人姓名也不记录。
3. **不编造**：问不到的字段留空，读取时自动采用同类单位的默认做法，不会把默认值冒充成你们单位的规定。
4. **一次的改动不等于习惯**：领导只在一份稿子里改过的，先记入改稿记录“观察中”；在两份以上稿子里出现，或在一份稿子里出现 3 处以上且你确认是一贯习惯，才写进偏好条目。以后再学到同样的改法，它会把“观察中”的记录合并计数、升级成偏好条目。你直接告诉它的偏好不受这个限制。
5. **不学坏习惯**：历史稿里的“值得注意的是”、背景铺垫、免责句等写法会列为“不采纳的习惯”，起草时不模仿；历史稿里的政治性提法不当作常用表述，提法以最新原文为准。
6. **画像可能含内部信息**：不要把 `.gongwen/` 提交到公开仓库，建议加进 .gitignore。
7. **脚本**：`scripts/style_profile.py`（文风统计）和 `scripts/draft_diff.py`（花脸稿对比，能读 Word 修订痕迹和批注）只用 Python 标准库，不联网。没有 Python 时按人工步骤完成，并在说明里注明“人工估算”。

## 与其他 skill 的分工

| 需求 | 用哪个 |
|---|---|
| 第一次用，只想 3 个问题快速建个简版画像；不知道该写什么 | gongwen |
| 照我们单位的风格写总结、讲话、通知 | gongwen-report、gongwen-speech、gongwen-draft 等起草 skill，装有行业包的，本行业专用文书交对应行业包。都会读单位画像；偏好卡、禁用词、文风参数由各起草、改稿 skill 按自己的开工检查读取，详见各 skill 说明 |
| 按领导批注把稿子改好 | gongwen-polish（改完可以回来把批注归纳进偏好卡） |
| 核稿 | gongwen-review（读单位画像，并按禁用词表逐条比对：禁用的列 P1，慎用的列 P2） |

能直接调用其他 skill 的工具里会直接转过去；对应 skill 没装，或你在网页版使用的，它会给你一张交接卡，说明可以新开对话、先粘贴 `dist/prompts/<skill 名>.md` 再粘贴交接卡继续，并附上安装命令（见 `references/_shared/style/output-format.md` 第四部分）。

## 成熟度

Beta。五项功能的流程、两个脚本和单元测试已完成；评测用例见 `evals/`。已知局限：
- 文风统计的四字格和惯用语用规则提取，样本少时可能漏掉；标题句式分类较粗，由模型补充定性观察；
- 花脸稿对比的标签（评价词删减、换词、数据前移等）是启发式提示，归纳偏好仍要逐条看上下文；
- 修订痕迹只解析正文中的插入、删除、移动和批注，不解析格式修订和脚注；页眉页脚只用来查密级和内部标注；
- 两个脚本按规则识别密级和“内部资料”等标注，写法特殊的可能漏掉，它仍会自己看每份材料的首尾和页眉。
