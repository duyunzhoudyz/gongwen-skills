# 标题与提纲（gongwen-title）

起标题是写材料时最磨人的一步：发文标题被退回来说“要素不全”，转发文件的标题越写越长，总结的小标题被领导批“大而无当”“和内容对不上”。这个 skill 只管标题和提纲，帮你把标题起准、起顺，正文仍由你或其他 skill 来写。

## 能做什么

1. **公文标题**：检查发文机关、事由、文种三要素；纠正“关于”误用、“请示报告”这类文种叠用；把转发文件的标题从“关于……关于……的通知的通知”改顺；告诉你标题太长时在哪里回行，标点怎么用。一次给几个标题的，逐条写出改后标题、问题和依据。
2. **材料标题**：给总结、汇报材料、经验材料、调研报告、讲话稿等起单标题或主副标题，主标题里的数字只用你给的。
3. **小标题提炼**：读你写好的正文，默认给出对仗式、递进式、数字概括式（如“三个坚持”）三套小标题；书面上报、数据多的业务报告，或你是业务人员时，其中一套换成动宾式或主题词式。每套说明适合什么场合，再从这三套中推荐一套。总结里“存在的问题”“打算”这类固定部分保持规范名称。
4. **提纲搭建**：把零散的工作记录、数据整理成带标题层级的提纲，每节列出要点和对应的素材，缺什么标出来。
5. **标题与正文一致性检查**：逐节对照，指出“大而无当”“与正文脱节”“三个坚持只写了两条”这类问题，给出改法。

## 可以这样说

- “帮我看看这个标题对不对：关于对城区占道经营进行专项整治的通知”
- “市里转发了省厅的通知，我们区再转发，标题怎么写才不啰嗦？”
- “这是我们科的年终总结，帮我提炼几个小标题，最好对仗一点”
- “素材都在这儿了，先帮我搭个汇报提纲，正文我自己写”
- “领导说我小标题大而无当，你帮我逐条看看和正文对不对得上”

## 输入与输出

| 你提供 | 你得到 |
|---|---|
| 一个或几个发文标题，或文件事由和发给谁 | 修改后的标题、回行排法，以及每处修改的问题和依据 |
| 材料类型和主要内容 | 3 个标题备选（单标题或主副标题），标出推荐 |
| 写好的正文 | 3 套小标题方案，每套一句适用场合，最后推荐一套 |
| 工作记录、数据、零散素材 | 提纲：总标题备选、各级标题、每节要点和素材编号、建议字数、待补清单 |
| 带标题的正文 | 问题清单（位置、问题、依据、改法）和修改后的完整标题树 |

在 Claude Code、Codex、Cursor 等能写文件的工具里，小标题方案、标题备选和检查结果写入 `公文/<日期>-<标题>/标题方案.md`，从素材搭提纲时另写同目录 `提纲.md`，不会覆盖你已有的文件。在网页大模型里直接在对话中输出。

每次输出最后都有一段【起草说明】，列出所作假设、待补和待核实事项。

## 注意事项

- **涉密材料请勿输入联网 AI**。材料涉密的，请使用单位内网部署的模型。材料带密级标识时，skill 会停止处理。
- **首轮就给结果**。信息不全时先按默认值给出标题、方案或提纲，缺的标【待补】；需要你确认的问题最多 3 个，放在最后。
- **标题里的数据只用你给的**。主标题想要“数据亮点”而素材里没有，skill 会标【待补】，不会替你编一个数字。你材料里加了引号的做法名称、本单位提法，标题里原样保留。
- **只出标题和提纲，不写正文**。要整篇稿子，请用 gongwen-report（总结、汇报、述职、方案等）、gongwen-draft（通知、请示等法定公文）或 gongwen-speech（讲话）；装有行业包时，本行业专用文书交对应行业包。
- **述职、对照检查这类本人材料**，你没给个人事例时只出提纲和填写指引。
- **本单位有公文处理办法的，以本单位为准**。转发标题的写法、主标题用空格还是逗号，各单位习惯不同，skill 会在说明里标出“实务做法”，你可以按单位习惯调整。
- 标题好不好最终要你和领导判断，skill 给的是有依据的备选。

## 和其他 skill 的分工

| 你想做的事 | 用哪个 |
|---|---|
| 说不清要写什么，或想知道能做什么 | gongwen |
| 写整篇总结、汇报、述职、调研报告、方案 | gongwen-report |
| 写通知、请示、报告、函等法定公文 | gongwen-draft |
| 写讲话稿、主持词、致辞 | gongwen-speech |
| 起标题、提炼小标题、搭提纲、查标题与正文是否一致 | gongwen-title |
| 压缩或扩写正文、按批注改稿 | gongwen-polish |
| 去掉 AI 腔 | gongwen-humanize |
| 去掉“仅供参考”“建议考虑”这类防御性表述 | gongwen-direct |
| 全文核稿：标点、数字、提法、保密 | gongwen-review |
| 排成国标 Word | gongwen-format |

能调用其他 skill 的工具里会直接转过去；对应 skill 没装或在网页大模型里时，skill 会给你一张交接卡、“新开对话粘贴 `dist/prompts/<skill 名>.md` 继续”的说明和安装命令。

## 成熟度

**Stable（1.0.0）**。v1.0 真实模型评测（Sonnet 5.5）中，A 组（装 skill）期望通过率 100.0%（100/100），编造 0 次，触发评测正例 9/10（1 条被判给 gongwen-draft）、反例 10/10，详见 `evals/results/v1.0-benchmark.md`。上面五项功能都已可用，评测用例 16 条、触发用例 20 条，覆盖党政机关、基层、社区、公立医院、高校、中小学、国有企业 7 类单位和 5 种角色模式。已知局限：

- 本 skill 不带机检脚本，标题检查和数字概括的条数核对由模型按清单人工完成；全文机检请用 gongwen-review。
- 转发标题默认写法：以发文机关开头时写“××转发××关于……的通知”，不写发文机关时写“关于转发……的通知”，全标题只留一个“关于”；单位另有规定的请在单位画像中写明。
- 标题回行按 2 号字每行约 20 字推算，实际以排版结果为准，可交 gongwen-format 排版后再看。
