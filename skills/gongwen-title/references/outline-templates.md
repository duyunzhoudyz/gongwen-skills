# 常见材料提纲骨架

> 骨架只给标题层级和每节写什么，具体要点一律来自用户素材，缺的标【待补】。篇幅比例是本项目建议值，用户或单位另有要求的从其要求。示例单位均为虚构。

目录：一、使用方法与输出样式　二、总结类　三、汇报类　四、调研报告　五、经验材料　六、述职报告　七、计划类　八、讲话稿　九、请示、报告　十、单位变体速查

## 一、使用方法与输出样式

1. 按材料类型选骨架，再按第十部分换成本单位的板块。
2. 骨架里的一级标题是“占位名”，提纲中要换成按本 skill 任务三规则拟的具体标题。
3. 骨架没有“背景和意义”一节。用户要求写的，只留一两句，放在开头段，不单设一级标题。
4. 素材撑不起的节，写【待补：需要的素材】，或建议删去。

输出样式（纯文本，可直接写入 `提纲.md`）：

```text
总标题备选
1. 某区政务服务中心2026年工作总结（推荐，上报存档用）
2. 一窗受理少跑腿　全程网办快开业
——某区政务服务中心2026年工作总结

一、主要工作和成效（约1300字）
（一）整合综合窗口，推行一窗受理
要点：部门窗口整合为综合窗口后的受理方式（素材2）
要点：群众平均等候时间变化【待补：整合前后数据】
（二）开通全程网办，简化开办流程
要点：企业开办全程网办的开通时间和办理量（素材3、6）
二、存在的问题（约300字）
要点：部分事项仍需线下核验原件（素材8）
三、2027年工作打算（约400字）
要点：【待补：中心明年重点任务】

未用素材：素材5（中心文体活动），与总结主题关系不大，建议不写。
篇幅合计：约2000字。
```

## 二、总结类

### 2.1 单位年度工作总结

开头段不设标题，一两句交代全年主线和总体成效（5%）；主要工作和成效按工作板块分 3～5 个二级标题，每个写做法加结果（60%）；存在的问题写 2～3 条真问题，不写成变相表扬（15%）；下一步打算与问题对应，写到具体任务（20%）。

常见坑：成效没有数据；问题与打算不对应；与上年总结雷同（`references/_shared/rules/doc-types.md` 4.1）。

### 2.2 部门、科室总结

同 2.1，“主要工作和成效”按本部门职责分块。业务科室可在开头加“主要指标完成情况”一节，集中列数据，后面各节只写做法。

## 三、汇报类

### 3.1 专题汇报（向上级领导汇报某项工作）

基本情况（对象、规模、进度，用数据，15%）；主要做法和成效（3～4 条做法，每条带结果，50%）；困难和问题（15%）；下一步打算（具体任务和时间，15%）；需要上级支持的事项（一两条，需要审批的另行请示，5%）。篇幅按汇报时长估算，每分钟约 200 字（实务）。

### 3.2 迎检汇报

一级标题按检查表或检查通知的条目逐项对应，顺序与检查表一致，每项写“落实情况、佐证材料、存在差距”。用户没给检查表的，按素材归类出提纲，在起草说明中写明“一级标题请对照检查通知调整”，回复末尾请用户提供检查表；不按经验臆造检查项。

## 四、调研报告

1. 调研前只出调研提纲：调研目的（一句话：要弄清什么问题）、调研对象和方式（去哪些单位、找哪些人、座谈还是问卷、看哪些数据）、调研内容（3～5 个要问清的问题，各列要收集的数据）、时间安排。不出“问题”“对策”两节的结论（`references/_shared/guardrails.md` 第六条第 5 款）。
2. 调研后的报告提纲：调研基本情况（时间、对象、方法、样本量，10%）、现状和成效（用调研数据说话，25%）、问题及原因（一一对应，35%）、对策建议（与问题一一对应，写到可操作，30%）。要点必须来自调研记录，没有记录的写【待补：调研发现】。

## 五、经验材料

开头段不设标题，一句话交代单位、做法和成效（10%）；主要做法 3 条左右，小标题提炼做法特点，适合对仗式或数字概括式（65%）；取得成效只用用户提供的数据和事例（20%）；体会可省（5%）。标题用主副标题，见 `references/title-patterns.md` 2.2。

## 六、述职报告（含述责述廉）

| 一级标题（占位） | 填写指引 |
|---|---|
| 开头段 | 岗位、任职时间、分管工作，一两句 |
| 履职情况和主要工作 | 本人牵头、亲自做的事，每项写本人作用和结果；用“我”，不用“我们” |
| 述责（按要求） | 履行主体责任、一岗双责的具体事 |
| 述廉（按要求） | 遵守廉洁纪律的具体情况，按单位要求的事项逐项写 |
| 不足 | 本人的真实不足，具体到事 |
| 下一步努力方向 | 与不足对应 |

用户没有提供个人事例时，提纲只写“填写指引：”，告诉用户每节填什么、数据到哪里找，不替用户编事例（`references/_shared/guardrails.md` 第六条第 4 款）。

## 七、计划类

1. 工作要点：“总体要求”一段，不设二级标题，不铺垫形势；“重点任务”分 4～8 条，每条一句话任务加简要要求，可标牵头部门，条目标题多用动宾式。
2. 工作计划：目标、任务和措施（写明时间、责任部门、完成标准）、保障三节；任务一节是主体，按工作板块分二级标题。
3. 实施方案：总体要求（目标，能量化的量化，10%）、主要任务（任务、责任部门、完成时限，55%）、实施步骤（阶段和时间节点，20%）、保障措施（精炼，15%）。部署内容的要点用“要”“于某日前完成”，不用“建议”“可以考虑”（`references/_shared/style/defensive.md` 第五部分）。

## 八、讲话稿

称谓和开场（一两句点明会议目的）；主体分 2～4 点，每点一个小标题，适合对仗式或数字概括式，写清要求和具体任务；结尾简短提要求，不喊口号。讲话稿的正文起草交 gongwen-speech。

## 九、请示、报告的简要提纲

| 文种 | 结构 |
|---|---|
| 请示 | 请示缘由；请示事项（具体到批什么、拨多少）；本单位意见或方案；结语“妥否，请批示” |
| 工作报告 | 基本情况；做法和成效；问题；下一步打算；结语“特此报告” |
| 情况报告 | 经过；原因；处理情况；下一步措施 |

这两类正文较短，一般不设多级小标题。请示、情况报告的正文交 gongwen-draft，全面工作报告交 gongwen-report。

## 十、单位变体速查

基层、高校、中小学的板块见本 skill“单位差异”一节，其余补充如下（详见 `references/unit-styles.md`）：

| 单位类型 | 总结、汇报的板块 |
|---|---|
| 党政机关 | 主要工作和成效、存在问题、下一步打算 |
| 社区 | 面向居民会议的年度报告按民生实事逐项报告完成情况 |
| 公立医院 | 科室总结先列主要指标（门急诊人次、出院人次、手术量、出院患者四级手术比例或占比、平均住院日等，名称照所依据考核体系，只用用户提供的），再写做法 |
| 国有企业 | 年度工作会报告按成绩、形势、任务展开；经营类材料正文先写指标完成情况，小标题不强制带指标数据；改革、党建、安全分节 |
