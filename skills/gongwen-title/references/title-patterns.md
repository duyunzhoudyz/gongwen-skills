# 标题样式库

> 示例中的单位、事项、数据均为虚构。标“实务”的是通行做法，各单位以本单位制度为准。“条例”指《党政机关公文处理工作条例》。依据栏只写外部标准条款或“实务”，不写本项目内部文件编号；面向群众、转译场景的说明从简。

目录：一、法定公文标题（1.1 结构　1.2 纠错补充　1.3 转发、批转、印发　1.4 回行）　二、材料标题（2.1 单标题　2.2 主副标题　2.3 按材料选风格）　三、小标题样式

## 一、法定公文标题

### 1.1 结构

发文机关名称 + 关于 + 事由 + 的 + 文种（条例第九条第（七）项）。

| 文种 | 示例 |
|---|---|
| 通知 | 某市市场监督管理局关于开展冬季食品安全专项检查的通知 |
| 印发 | 某县人民政府办公室关于印发《某县农村人居环境整治实施方案》的通知 |
| 请示 | 某区卫生健康局关于增设区第二人民医院发热门诊的请示 |
| 报告 | 某镇人民政府关于2026年度防汛工作情况的报告 |
| 函 | 某区教育局关于商请追加学校校舍维修经费的函；答复用“复函” |
| 批复 | 某县人民政府关于同意某镇调整集贸市场开放时间的批复 |
| 通报 | 某市应急管理局关于第三季度安全生产检查情况的通报 |
| 纪要 | 某医院2026年第12次院长办公会议纪要（不用“关于”） |
| 签报 | 关于购置急诊科除颤仪的请示（签报单抬头印“签报”） |

### 1.2 纠错补充

缺文种、文种叠用、事由与文种重复、介词叠用、文种错用、末尾加标点见本 skill 任务一第3条，会议名称、年份的标点见任务一第6条，此处只列其余情形。

| 问题 | 误 | 正 | 依据 |
|---|---|---|---|
| 缺事由 | 某市教育局通知 | 某市教育局关于做好2027年中考报名工作的通知 | 条例第九条第（七）项 |
| 事由空泛 | 关于有关事项的通知 | 关于调整2027年元旦假期值班安排的通知 | 实务 |
| 自创文种 | 某中学关于购置教学一体机的申请 | 报教育局用请示；报不相隶属单位用函 | 条例第八条 |
| 事由重复发文机关 | 某区市场监管局关于某区市场监管局开展电动自行车质量抽查的通知 | 某区市场监管局关于开展电动自行车质量抽查的通知 | 实务 |

### 1.3 转发、批转、印发

规则见本 skill 任务一第5条（实务）。以发文机关开头时写“转发”，不加“关于”；不写发文机关时写“关于转发”，省去被转发标题中的“关于”。

| 情形 | 被转发或印发的文件 | 本单位标题 |
|---|---|---|
| 转发上级通知 | 某省商务厅关于做好秋冬季消费促进工作的通知 | 某市商务局转发某省商务厅关于做好秋冬季消费促进工作的通知 |
| 转发上级意见 | 某市人民政府关于加快发展社区嵌入式养老服务的意见 | 某区人民政府办公室转发某市人民政府关于加快发展社区嵌入式养老服务意见的通知 |
| 不写发文机关 | 同第一行 | 关于转发某省商务厅做好秋冬季消费促进工作的通知 |
| 层层转发 | 市商务局只加了转发语的上述通知 | 某区商务局转发某省商务厅关于做好秋冬季消费促进工作的通知 |
| 批转下级 | 某县发展改革局2027年县级重点项目计划 | 某县人民政府关于批转县发展改革局2027年县级重点项目计划的通知 |
| 印发制度 | 某医院医疗设备采购管理办法（试行） | 某医院关于印发《某医院医疗设备采购管理办法（试行）》的通知 |

补充：被印发的文件还在起草的，其标题直接拟为“某某实施方案”“某某办法”，不带“关于”，避免印发标题里出现两个“关于”。已定稿的文件，书名号内照录原标题，不删改。

### 1.4 回行

规则见本 skill 任务一第7条（GB/T 9704-2012 7.3.1）。

```text
例一，两行，上短下长
误：某县人民政府办公室关于做好冬季农村道
　　路交通安全工作的通知（拆开了“道路”）
正：某县人民政府办公室
　　关于做好冬季农村道路交通安全工作的通知

例二，三行，菱形
误：某市人民政府办公室关于印发《某市城市更新
　　专项资金管理办法（试行）》
　　的通知（末行只剩“的通知”）
正：某市人民政府办公室
　　关于印发《某市城市更新专项资金管理办法
　　（试行）》的通知
```

## 二、材料标题

### 2.1 单标题

| 材料 | 示例 |
|---|---|
| 总结、计划、工作要点 | 某区政务服务中心2026年工作总结；某区教育局2027年工作要点 |
| 汇报材料、调研报告 | 关于某县农村供水保障工作情况的汇报；关于某市社区养老服务站运营情况的调研报告 |
| 述职报告 | 2026年度述职报告（合并述廉的写述职述廉报告） |
| 实施方案 | 某街道老旧小区加装电梯工作实施方案 |
| 讲话稿 | 在全区安全生产工作会议上的讲话（下注讲话人和日期） |
| 信息 | 某镇建立村级事务清单压减村干部填表负担（主体＋做法＋效果） |

### 2.2 主副标题

主标题提炼主旨，副标题另起一行，用破折号引出单位、时间、事项和材料类型（GB/T 15834-2011 4.10.3.9）。

```text
一张清单管到底　小区改造少扯皮
——某街道2026年老旧小区改造工作经验
```

| 问题 | 误 | 正 |
|---|---|---|
| 主标题空泛 | 多措并举抓落实　扎实推进见成效 | 一张清单管到底　小区改造少扯皮 |
| 拔高、无出处 | 打造全省领先的政务服务高地 | 一窗受理少跑腿　全程网办快开业 |
| 编造数据亮点 | 改造满意度达98%（素材没有） | 不写数据，或写满意度【待补：数据】 |
| 主副标题重复 | 老旧小区改造工作经验——某街道老旧小区改造经验 | 主标题改为提炼做法 |
| 末尾加标点或用逗号 | 一张清单管到底，小区改造少扯皮。 | 去掉句号，中间空一字 |

### 2.3 按材料选风格

| 材料 | 主标题写什么 | 示例 |
|---|---|---|
| 总结 | 全年工作主线或主要成效，平实 | 一窗受理少跑腿　全程网办快开业 |
| 汇报材料 | 工作主题，便于领导抓重点 | 补齐供水短板　保障农村饮水安全 |
| 经验材料 | 做法的特点，可以口语化 | 一张清单管到底　小区改造少扯皮 |
| 调研报告 | 直指问题或结论 | 社区养老服务站“开得起”还要“转得动” |
| 讲话稿 | 主题或要求，副标题交代会议 | 把安全责任落到每个岗位——在全区安全生产工作会议上的讲话 |

述职报告一般用单标题。

## 三、小标题样式

样式定义、默认三套和替换规则见本 skill 任务三第2、3条，三种默认样式的正例见本 skill“输出规范”中的小标题方案输出样式（某区政务服务中心全年做了三件事：整合综合窗口、开通企业开办全程网办、分批开展窗口人员业务轮训）。

```text
对仗式：同级结构、字数相同；每条不分前后两半也可以，如“一、整合综合窗口　二、开通全程网办　三、开展业务轮训”
误：一、整合综合窗口，推行一窗受理　二、开通全程网办　三、强化培训，全面提升窗口工作人员综合业务能力水平（结构、字数都不齐）

递进式：顺序不能互换。常见顺序：基础、重点、保障；摸底、整改、长效；问题、原因、对策
误：一、轮训人员　二、整合窗口　三、开通网办（互换后意思不变，不是递进）

数字概括式：总括数字等于条数，关键字位置一致
误：四个推进（只列三条）
误：三个推进　一、推进窗口整合　二、开通全程网办　三、推进业务轮训（第二条没有“推进”）

动宾式：一、整合部门窗口为综合窗口　二、开通企业开办全程网办　三、分批开展窗口人员业务轮训
主题词式：一、综合窗口　二、全程网办　三、业务轮训
```

| 样式 | 适用 |
|---|---|
| 对仗式 | 口头汇报、述职、交流发言，听众要记住几块工作 |
| 递进式 | 整改报告、调研报告、分阶段推进的工作 |
| 数字概括式 | 经验材料、交流发言、领导讲话，追求好记；条数少于 3 条或各条动作差别很大时不用 |
| 动宾式 | 书面上报、计划、实施方案，清楚优先 |
| 主题词式 | 数据多的业务报告、质量分析，按板块组织，标题下直接写指标 |
