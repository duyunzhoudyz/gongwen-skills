# 标题样式库

> 示例中的单位、事项、数据均为虚构。标“实务”的是通行做法，各单位以本单位制度为准。条款号对应 `references/_shared/rules/` 下的要点文件。

## 一、法定公文标题

### 1.1 结构

发文机关名称 + 关于 + 事由 + 的 + 文种（《党政机关公文处理工作条例》第九条（七））。

| 文种 | 样式 | 示例 |
|---|---|---|
| 通知 | 某某关于……的通知 | 某市市场监督管理局关于开展2026年冬季食品安全专项检查的通知 |
| 印发 | 某某关于印发《……》的通知 | 某县人民政府办公室关于印发《某县农村人居环境整治实施方案》的通知 |
| 请示 | 某某关于……的请示 | 某区卫生健康局关于增设区第二人民医院发热门诊的请示 |
| 报告 | 某某关于……情况的报告 | 某镇人民政府关于2026年度防汛工作情况的报告 |
| 函 | 关于商请……的函；关于……的复函 | 某区教育局关于商请追加学校校舍维修经费的函 |
| 批复 | 关于……的批复；关于同意……的批复 | 某县人民政府关于同意某镇调整集贸市场开放时间的批复 |
| 通报 | 关于……情况的通报；关于表彰……的通报 | 某市应急管理局关于2026年第三季度安全生产检查情况的通报 |
| 决定 | 某某关于……的决定 | 某集团有限公司关于表彰2026年度安全生产先进单位的决定 |
| 纪要 | 某某会议纪要（不用“关于”） | 某医院2026年第12次院长办公会议纪要 |
| 签报 | 关于……的请示（或报告），签报单抬头印“签报” | 关于购置急诊科除颤仪的请示 |

### 1.2 纠错对照

| 问题 | 误 | 正 | 依据 |
|---|---|---|---|
| 缺文种 | 某县卫生健康局关于开展医疗机构消防检查 | ……消防检查的通知 | 条例第九条（七） |
| 缺事由 | 某市教育局通知 | 某市教育局关于做好2027年中考报名工作的通知 | 同上 |
| 事由空泛 | 关于有关事项的通知 | 关于调整2027年元旦假期值班安排的通知 | 实务 |
| 文种叠用 | 关于增设发热门诊的请示报告 | 关于增设发热门诊的请示 | doc-types 2.11 |
| 自创文种 | 某中学关于购置教学一体机的申请 | 报教育局用请示；报不相隶属单位用函 | 条例第八条 |
| 事由与文种重复 | 关于申请拨付校舍维修经费的请示 | 关于拨付校舍维修经费的请示 | doc-types 2.11 |
| 介词叠用 | 关于对2026年度先进集体进行表彰的决定 | 关于表彰2026年度先进集体的决定 | 实务 |
| 事由重复发文机关 | 某区民政局关于某区民政局开展养老机构检查的通知 | 某区民政局关于开展养老机构检查的通知 | 实务 |
| 末尾加标点 | 关于开展安全生产检查的通知。 | 去掉句号 | GB/T 15834 B.4 |
| 会议名称加书名号 | 关于召开《全市安全生产工作会议》的通知 | 关于召开全市安全生产工作会议的通知 | GB/T 15834 A.13.1 |
| 年份范围用短横线 | 某县养老服务体系建设规划（2026-2028年） | （2026—2028年） | GB/T 15834 4.13.3.2 |
| 年份简写 | 关于做好26年度考核工作的通知 | 关于做好2026年度考核工作的通知 | GB/T 15835 5.1.4 |

### 1.3 转发、批转、印发

规则（实务，见 doc-types 2.8）：全标题只留一个“关于”；去掉被转发文件文种前的“的”；层层转发只写最初发文机关；被转发的公文标题不加书名号，印发的规章、制度、方案加书名号；批转对下级，转发对上级和不相隶属机关。

| 情形 | 被转发或印发的文件 | 本单位标题 |
|---|---|---|
| 转发上级通知 | 某省教育厅关于做好2026年秋季学期学校安全工作的通知 | 某市教育局关于转发某省教育厅做好2026年秋季学期学校安全工作通知的通知 |
| 转发上级意见 | 某市人民政府关于加快发展社区嵌入式养老服务的意见 | 某区人民政府办公室关于转发某市人民政府加快发展社区嵌入式养老服务意见的通知 |
| 层层转发 | 市教育局已转发的上述省教育厅通知 | 某区教育局关于转发某省教育厅做好2026年秋季学期学校安全工作通知的通知 |
| 批转下级 | 某县发展改革局2027年县级重点项目计划 | 某县人民政府关于批转县发展改革局2027年县级重点项目计划的通知 |
| 印发制度 | 某医院医疗设备采购管理办法（试行） | 某医院关于印发《某医院医疗设备采购管理办法（试行）》的通知 |

补充：
1. 也有“某某转发某某关于……的通知”的写法（不在“转发”前加“关于”），全标题同样只有一个“关于”。同一单位统一用一种。
2. 被印发的文件还在起草的，其标题直接拟为“某某实施方案”“某某办法”，不带“关于”，避免印发标题里出现两个“关于”。已定稿的文件，书名号内照录原标题，不删改。
3. 被转发、印发文件的标题必须来自用户提供的文件，没有时写【待补：原文件标题】。

### 1.4 回行

规则（GB/T 9704-2012 7.3.1）：词意完整、排列对称、长短适宜，梯形或菱形。2 号字每行约 20 字（推算）。

例一，两行，上短下长：

```text
误：某县人民政府办公室关于做好冬季森
　　林防火工作的通知（拆开了“森林”）
正：某县人民政府办公室
　　关于做好冬季森林防火工作的通知
```

例二，三行，菱形：

```text
误：某市人民政府办公室关于印发《某市
　　数字政府建设三年行动方案（2026—2028年）》
　　的通知（末行只剩“的通知”）
正：某市人民政府办公室关于印发
　　《某市数字政府建设三年行动方案
　　（2026—2028年）》的通知
```

## 二、材料标题

### 2.1 单标题

| 材料 | 样式 | 示例 |
|---|---|---|
| 总结 | 单位 + 时间 + 工作总结 | 某医院急诊科2026年工作总结 |
| 计划、工作要点 | 单位 + 时间 + 计划（要点） | 某区教育局2027年工作要点 |
| 汇报材料 | 关于……工作情况的汇报 | 关于某县农村供水保障工作情况的汇报 |
| 调研报告 | 关于……情况的调研报告 | 关于某市社区养老服务站运营情况的调研报告 |
| 述职报告 | 时间 + 述职报告；合并述廉的写述职述廉报告 | 2026年度述职述廉报告 |
| 实施方案 | 单位 + 事项 + 实施方案 | 某街道老旧小区加装电梯工作实施方案 |
| 讲话稿 | 在……会议上的讲话，下注讲话人和日期 | 在全区安全生产工作会议上的讲话 |
| 信息 | 一句话：主体 + 做法 + 效果 | 某镇建立村级事务清单压减村干部填表负担 |

### 2.2 主副标题

主标题提炼主旨，副标题另起一行，用破折号引出单位、时间、事项和材料类型（GB/T 15834-2011 4.10.3.9）。

```text
一张清单管到底　小区改造少扯皮
——某街道2026年老旧小区改造工作经验
```

| 问题 | 误 | 正 |
|---|---|---|
| 主标题空泛 | 多措并举抓落实　扎实推进见成效 | 一张清单管到底　小区改造少扯皮 |
| 拔高、无出处 | 打造全省领先的急诊救治高地 | 缩短救治时间　守住急诊防线 |
| 编造数据亮点 | 改造满意度达98%（素材没有） | 不写数据，或写满意度【待补：数据】 |
| 主副标题重复 | 老旧小区改造工作经验——某街道老旧小区改造经验 | 主标题改为提炼做法 |
| 副标题符号错 | 用冒号或圆括号引出副标题 | 用破折号，另起一行 |
| 末尾加标点 | 一张清单管到底，小区改造少扯皮。 | 去掉句号，中间空一字 |

### 2.3 按材料选风格

| 材料 | 主标题写什么 | 示例 |
|---|---|---|
| 总结 | 全年工作主线或主要成效，平实 | 缩短救治时间　守住急诊防线 |
| 汇报材料 | 工作主题，便于领导抓重点 | 补齐供水短板　保障农村饮水安全 |
| 经验材料 | 做法的特点，可以口语化 | 一张清单管到底　小区改造少扯皮 |
| 调研报告 | 直指问题或结论 | 社区养老服务站“开得起”还要“转得动” |
| 讲话稿 | 主题或要求，副标题交代会议 | 把安全责任落到每个岗位——在全区安全生产工作会议上的讲话 |
| 述职报告 | 一般用单标题 | 2026年度述职报告 |

## 三、小标题样式

任务三的三套方案默认取 3.1～3.3；书面上报、数据多的业务报告和转译模式，用 3.4 或 3.5 替换其中一套（通常替换 3.3），推荐只在给出的三套中选（SKILL.md 任务三第 2、3 条）。

示例正文：某医院急诊科全年做了三件事，一是调整预检分诊流程，二是开通胸痛、卒中绿色通道，三是分层级开展急救培训。

### 3.1 对仗式

同级各条结构相同、字数相同。每条内部前后两半可以对仗，但不强制。

```text
正：一、优化预检分诊，缩短候诊时间
　　二、打通绿色通道，提高救治效率
　　三、开展分层培训，提升急救能力
正：一、调整分诊标准
　　二、开通绿色通道
　　三、开展分层培训（每条内部不分前后两半，同级三条结构、字数相同，也是对仗式；字数不求相同的是 3.4 动宾式）
误：一、优化预检分诊，缩短候诊时间
　　二、打通绿色通道
　　三、强化培训，全面提升医护人员急救能力水平（三条结构、字数都不齐）
```

适用：口头汇报、述职、交流发言，听众要记住几块工作。

### 3.2 递进式

各条有先后、因果或由浅入深的关系，顺序不能互换。常见顺序：摸底、整改、长效；打基础、抓重点、建机制；问题、原因、对策（调研报告）。

```text
正：一、理顺分诊流程（基础）
　　二、打通救治通道（重点）
　　三、培养急救梯队（保障）
误：一、强化培训　二、优化流程　三、开通通道（顺序互换后意思不变，不是递进）
```

适用：整改报告、调研报告、分阶段推进的工作。括号里的“基础”等字只用于说明，不写进标题。

### 3.3 数字概括式

总括数字统领，各条含同一关键字且位置一致。数字等于实际条数。

```text
正：三个加强
　　一、加强分诊管理
　　二、加强通道建设
　　三、加强梯队培训
误：四个强化（只列三条）
误：三个加强　一、加强分诊管理　二、推进通道建设　三、加强梯队培训（第二条没有“加强”）
```

适用：经验材料、交流发言、领导讲话，追求好记。条数少于 3 条或各条动作差别很大时不用。

### 3.4 动宾式

```text
一、调整预检分诊流程
二、开通胸痛卒中绿色通道
三、开展分层级急救培训
```

适用：书面上报、计划、实施方案，清楚优先。

### 3.5 主题词式

```text
一、预检分诊
二、绿色通道
三、急救培训
```

适用：数据多的业务报告、质量分析，按板块组织，标题下直接写指标。
