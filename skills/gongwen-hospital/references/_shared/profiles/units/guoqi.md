# 单位类型画像：国有企业

适用于国有独资、国有控股企业及其所属企业，包括上市公司。

## 一、规则基线与参照依据

| 依据 | 适用方式 | 要点 |
|---|---|---|
| 《中国共产党国有企业基层组织工作条例（试行）》（2019 年 12 月） | 直接适用 | 党委（党组）发挥把方向、管大局、保落实的领导作用；重大经营管理事项须经党委（党组）研究讨论后，再由董事会或经理层作出决定 |
| 中办《关于中央企业在完善公司治理中加强党的领导的意见》（2021 年） | 直接适用（地方国企多参照） | 制定党委（党组）前置研究讨论重大经营管理事项清单 |
| 中办、国办《关于进一步推进国有企业贯彻落实"三重一大"决策制度的意见》（2010 年） | 直接适用 | 重大事项决策、重要干部任免、重要项目安排、大额资金使用须集体决策 |
| 《公司法》、公司章程、董事会议事规则、董事会授权管理办法 | 直接适用 | 股东会、董事会、经理层职权和议事程序 |
| 《企业民主管理规定》（2012 年） | 直接适用 | 职代会每年至少召开一次；厂务公开 |
| 证券监管和交易所信息披露规则 | 上市公司适用 | 定期报告、临时公告、可持续发展报告 |
| 企业公文处理办法 | 用户提供时优先 | 一般参照《党政机关公文处理工作条例》和 GB/T 9704-2012 制定 |

## 二、发文体系

| 发文主体 | 发文机关标志示例 | 发文字号示例 |
|---|---|---|
| 党委（党组） | 中共某集团有限公司委员会文件 | X党发〔2026〕N号 |
| 公司（行政） | 某集团有限公司文件 | X发〔2026〕N号 |
| 办公室 | 办公室版头 | X办发〔2026〕N号 |
| 本部部门 | 部门版头 | 以公司规定为准，如 X人资发〔2026〕N号 |
| 董事会 | 不用红头 | 议案、决议按董事会议事规则编号 |

代字以公司规定为准，上表只示意结构。

1. **党政两套代字**：党委（党组）发文管党建、干部、纪检、意识形态；公司发文管经营管理。各自职权内的事项不联合发文。
2. **部门级发文**：本部部门可在授权范围内就专业事项向所属企业发文，以公司公文管理办法为准。
3. **签报**：本部部门向公司领导请示、报告事项的内部文种。一事一报，写清事由、依据、方案比选、请示事项和部门意见，经相关部门会签后呈批。
4. **董事会文书**：议案提交董事会审议，决议记载董事会决定，格式和签署按公司章程。
5. **对外**：向国资监管机构、上级集团请示、报告；与政府部门、其他企业用函。上市公司的公告由董事会办公室按交易所规则编制，不按公文写。

## 三、常用文种与典型材料清单

| 频次 | 法定文种和内部文种 | 常用材料 |
|---|---|---|
| 几乎每周 | 通知、纪要、签报 | 党委会、总经理办公会纪要；新闻稿 |
| 每月或每季 | 请示、报告、函、通报 | 月度和季度经营分析；安全生产通报；改革任务台账更新 |
| 每年 | 报告、决议、议案 | 年度工作会报告（董事长、总经理）；职代会报告；党建工作报告；年度预算；经营业绩考核材料；社会责任、ESG 或可持续发展报告；述职述廉 |
| 事件触发 | 签报、议案、报告 | "三重一大"议题材料；投资项目决策材料；巡视巡察和审计整改；安全生产事故报告；合规审查意见 |

## 四、决策程序与行文特点

1. **党委前置研究**：党委（党组）研究讨论是董事会、经理层决策重大问题的前置程序。前置研究不代替董事会、经理层依法决策。
2. **前置事项清单**：哪些事项须前置研究，以本企业清单为准；清单外事项按授权由董事会或经理层决策。
3. **董事会、经理层**：常用表述为董事会"定战略、作决策、防风险"，经理层"谋经营、抓落实、强管理"。
4. **授权**：董事会可向董事长、经理层授权，授权有清单和期限；授权不授责。
5. **职代会**：审议涉及职工切身利益的重大事项；年度工作报告通常提交职代会。
6. **议题材料要件**：议题名称、背景与依据、方案及比选、需决策事项、前置程序说明（党委前置研究、合法合规审查、专家论证、职代会审议等）。

## 五、术语表

| 术语 | 解释 |
|---|---|
| 党委前置研究讨论 | 重大经营管理事项先经党委（党组）研究讨论，再由董事会或经理层决定 |
| 前置研究讨论事项清单 | 企业列明须经党委前置研究的事项范围 |
| 三重一大 | 重大事项决策、重要干部任免、重要项目安排、大额资金使用 |
| 双向进入、交叉任职 | 党委班子成员按程序进入董事会、经理层，董事会、经理层中的党员按规定进入党委 |
| 四同步、四对接 | 2016 年全国国有企业党的建设工作会议提出：党的建设和国有企业改革同步谋划、党的组织及工作机构同步设置、党组织负责人及党务工作人员同步配备、党的工作同步开展；体制、机制、制度、工作对接 |
| 授权不授责 | 董事会授权后仍对授权事项承担责任 |
| 一利五率 | 国资委对中央企业的经营指标体系。2025 年口径为利润总额，以及净资产收益率、研发经费投入强度、全员劳动生产率、资产负债率、营业收现率；以当年要求为准 |
| 经营业绩考核 | 出资人对企业负责人的年度和任期考核，年初签订责任书 |
| 任期制和契约化管理 | 经理层成员按任期和契约约定的目标考核、兑现 |
| 三项制度改革 | 劳动、人事、分配制度改革 |
| 两金 | 应收账款和存货 |
| 合规管理 | 企业对经营管理行为的合规审查和风险防控 |
| ESG、可持续发展报告 | 环境、社会和公司治理信息披露；沪深交易所对部分上市公司要求强制披露 |
| 厂务公开 | 企业向职工公开重大事项和涉及职工利益的事项 |
| 三管三必须 | 管行业必须管安全、管业务必须管安全、管生产经营必须管安全（《安全生产法》） |

## 六、红线与禁忌

1. 决策程序倒置：应前置研究的事项未经党委研究即提交董事会或经理层；先执行后补程序。
2. 商业秘密：未公开的财务数据、投标报价、客户信息、技术参数不进入对外材料，不输入联网 AI 工具。
3. 信息披露违规：上市公司未公开的重大信息不得先出现在新闻稿、公众号、讲话稿中。
4. 数据口径打架：经营分析数据与财务快报、年报不一致；各部门数据未经统一口径直接汇总。
5. 涉及职工切身利益的事项未经职代会审议即印发。
6. 无依据的"行业第一""国内领先"；安全事故信息迟报、瞒报、漏报。

## 七、年度写作节点

| 时间 | 节点与材料 |
|---|---|
| 1–2 月 | 年度工作会暨职代会：董事长、总经理报告；经营业绩责任书；党建工作会 |
| 每月初 | 上月经营分析 |
| 3–4 月 | 年报；社会责任、ESG 或可持续发展报告（强制披露的上市公司在 4 月 30 日前与年报同时披露）；一季度经营分析 |
| 6 月 | 安全生产月 |
| 7–8 月 | 半年经营分析；年中工作会；上市公司半年报（8 月底前） |
| 10 月 | 前三季度经营分析；上市公司三季报 |
| 11–12 月 | 下年度预算；年终总结；述职述廉；年度考核 |
| 按周期 | 巡视巡察整改、审计整改、改革任务阶段总结 |

## 八、版式差异

1. 参照 GB/T 9704-2012 使用企业红头。部分企业公文管理办法与国标有差异（如年份括号写法），按企业办法执行，并在起草说明中提示差异。
2. 签报用企业统一签报单：编号、标题、主办部门、会签部门意见、拟办意见、领导批示栏。
3. 董事会议案、决议按董事会议事规则格式，不用红头。
4. 经营分析表格和图表多，金额单位全文统一。

## 九、文风特点

1. 讲效益、讲数据：先写指标完成情况，再写原因和措施。
2. 年度工作会报告常按"成绩、形势、任务"展开；任务写到指标、责任部门、时限。
3. 党建材料写清对经营的具体作用，避免党建与经营"两张皮"。
4. 专业术语（如 EBITDA、资产负债率）保留，首次出现可加说明。

## 十、对各 skill 的提示

| skill | 提示 |
|---|---|
| gongwen-minutes | 议题材料核对前置程序是否完成；党委会、董事会、总经理办公会纪要分开 |
| gongwen-data | 经营分析围绕收入、利润总额、"一利五率"、两金等；口径与财务数据一致，同比、环比写明基期 |
| gongwen-report | 年度工作报告的经营指标完成值只用用户提供的；改革、党建、安全分节写 |
| gongwen-review | 程序关重点查前置研究和职代会审议；另查商业秘密、未披露信息、数据一致性 |
| gongwen-draft | 本部部门向公司领导用签报，不用正式请示文件；公司向国资监管机构用请示或报告，与政府部门用函 |
| gongwen-brief | 新闻稿核对是否含未公开的经营数据和重大事项 |
