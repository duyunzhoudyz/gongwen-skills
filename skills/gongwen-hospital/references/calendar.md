# 医院专用文书写作日历

> 用法：用户问“最近要准备什么材料”，或任务卡缺统计周期时参考。国家文件的印发时间每年不同，下表写的是 2026 年的时间，仅作示例，用于判断大致节点，引用时标“据本包资料”，年度以当年通知为准；标“院内安排”的以本院为准。通用材料（年终总结、讲话、纪要）的节点见 `references/_shared/profiles/units/yiyuan.md` 第七部分，由核心 skill 处理。
> 核验日期：2026-10-16。

| 时间 | 节点 | 本包文书 | 依据或说明 |
|---|---|---|---|
| 每月 | 上传上一个月的住院病案首页数据（已参加监测的医院，每月15日前） | 月度质量分析中的首页质量部分 | 国家卫生健康委办公厅2026年7月3日通知 |
| 每月 | 月度医疗质量、院感监测、不良事件统计 | 质量分析（月） | 《医疗质量管理办法》第十一条“定期”，频次按本院规定 |
| 每季度 | 质控分析会、医疗质量与安全管理委员会会议 | 质量分析（季）；需要会议决定的事项写成议题 | 院内安排 |
| 1月 | 年度质量分析；科室主任年度述职 | 质量分析（年）、科室主任述职 | 院内安排 |
| 2—3月 | 国家医疗质量安全改进目标印发（2026年为2月14日） | 质量分析中增加“年度改进目标”一节；PDCA 选题 | 制定本院落实方案交 gongwen-implement |
| 5—6月 | 年度纠风工作要点印发（2026年成文于5月22日，6月8日公布） | 行风材料（自查报告、情况报告） | 制定本院纠风实施方案交 gongwen-implement |
| 7月起 | 国家启动上一年度二级和三级公立医院绩效监测（2026年为7月3日） | 绩效分析：数据核对、自评；结果反馈后写结果分析 | 时间以当年通知为准 |
| 7月 | 半年质量分析 | 质量分析 | 院内安排 |
| 事件触发 | 发生严重不良事件、警告事件 | RCA；完成后追踪改进成效 | 时限按本院不良事件管理制度 |
| 收到反馈后 | 卫生健康部门院感专项检查、医疗质量安全检查、安全生产检查反馈问题 | 整改方案、整改台账、整改情况报告 | 报送时限按反馈通知 |
| 评审周期内 | 等级评审周期为4年；申请评审前开展自评 | 等级评审自评报告 | 《三级医院评审标准（2025年版）》使用说明 |
| 年底 | 九项准则落实情况自查、医德考评 | 行风材料 | 院内安排，以上级部署和本院医德考评办法为准 |

提示用户时的写法（示例）：
- “10月是三季度质量分析和整改报送的集中时间，需要的话可以发三季度数据表。”
- “明年1月科室主任述职，科室数据和您本人的工作事例可以先整理起来。”
