# 医院专用文书术语表

> 用法：起草和自检时对照本表写指标名称和术语。同一个指标在不同体系中的写法可能不同（如绩效考核写“出院患者四级手术比例”，2025年版评审标准写“出院患者四级手术占比”），写哪个体系的材料就用哪个体系的原名。
> 出处缩写：“国办4号”指《国务院办公厅关于加强三级公立医院绩效考核工作的意见》（国办发〔2019〕4号）附件；“评审2025”指《三级医院评审标准（2025年版）》（国卫医政发〔2025〕4号）第二部分。指标的定义、公式、导向以当年操作手册和本省细则为准。
> 核验日期：2026-10-16。基础术语（DRG、CMI、四级手术、核心制度等）另见 `references/_shared/profiles/units/yiyuan.md` 第五部分。

**国家监测指标**：国办4号附件中标“▲”的指标，2019年版共26项，主要由病案首页、财务年报、满意度平台等自动生成。医院不自行计算国家监测指标的“国家值”，写材料时引用国家反馈结果或本院上报数据，并注明是哪一个。

**星号指标**：一线口头说法，有时指国家监测指标，有时指评审细则中带“★”的条款。正文不写“星号指标”，按所指写原名。

## 二、DRG 与 DIP 术语

| 术语 | 含义 | 写作要点 |
|---|---|---|
| DRG（疾病诊断相关分组） | 按诊断、治疗方式、病情复杂程度等把住院病例分组 | 卫生健康部门用于绩效评价，医保部门用于付费，两套分组和权重不同 |
| DIP（按病种分值付费） | 医保支付方式之一 | 与 DRG 不同时写进同一指标 |
| CHS-DRG 2.0、DIP 2.0 | 国家医保局 2.0 版分组方案（医保办发〔2024〕9号），2025年起统一使用 | 写医保结算数据时注明分组版本 |
| RW（相对权重） | 某一 DRG 组资源消耗相对于平均水平的倍数 | |
| CMI（病例组合指数） | 例均权重：总权重除以出院病例数，总权重为各组 RW 乘以该组病例数之和 | 写明口径（卫健绩效评价或医保结算）；入组率低时 CMI 会失真，台账记下入组率 |
| 入组率 | 入组病例数占应入组病例数的比例 | 由分组系统给出，不自行计算 |
| 时间消耗指数、费用消耗指数 | 同类病例住院时间、费用与比较基准之比 | 等于1为基准水平 |
| 低风险组 | DRG 中死亡风险最低的一组 | 该组出现死亡病例，提示医疗质量问题 |
| 特例单议 | 医保对不适合按 DRG/DIP 标准支付的病例单独审议 | 只写用户提供的件数 |
| 结余、超支 | 医保结算与实际费用之差 | 属内部运营数据，面向职代会等较大范围前确认能否公开 |

## 三、质量管理工具

| 工具 | 用途 | 写作要点 |
|---|---|---|
| PDCA（质量环） | 计划、执行、检查、处理的持续改进循环 | 《医疗质量管理办法》第四十七条列举的工具；改善前后同口径、同时长比较 |
| 品管圈（QCC） | 一线人员组成小组解决本岗位质量问题 | 常用“目标达成率”“进步率”，算法见 `references/data-rules.md` |
| 根本原因分析（RCA） | 对已发生的不良事件追查系统原因 | 非惩罚性；根本原因落在系统层面 |
| 失效模式与效应分析（FMEA） | 事前识别流程中可能的失效并排序 | 用于高风险流程的前瞻性分析 |
| 鱼骨图（因果图） | 按类别列出可能原因 | 报告中可写成文字版：类别加原因 |
| 柏拉图（帕累托图） | 找出占多数的少数主要问题 | 文字版写“前三类问题占全部问题的X%” |
| 5个为什么 | 对一个原因连续追问 | 追问到可以采取系统措施的层面为止 |
| 单病种管理、临床路径管理 | 病种层面的过程质量管理 | 《医疗质量管理办法》第四十七条列举的工具 |

## 四、不良事件分级分类

依据：国卫办医政发〔2023〕13号附件2《医疗质量安全不良事件分级分类标准》（核对所用为福建省卫生健康委转发件）。写 RCA、质量分析时用此分类，本院另有分级办法的按本院办法，并在起草说明中写明采用哪一套。

| 类别 | 含义 | 对应等级 |
|---|---|---|
| Ⅰ类（警告事件） | 发生不良事件，造成患者死亡 | I级：患者死亡 |
| Ⅱ类（有后果事件） | 发生不良事件，造成患者伤害 | E级：暂时性伤害，需治疗或干预；F级：暂时性伤害，需住院或延长住院；G级：永久性伤害；H级：需要治疗挽救生命 |
| Ⅲ类（无后果事件） | 发生不良事件，未造成患者伤害 | B级：事件发生但未累及患者；C级：累及患者但未造成伤害；D级：累及患者，需监测或干预以防止伤害 |
| Ⅳ类（隐患事件） | 未发生不良事件，存在引发风险的条件 | A级 |

表中等级字母按 A～I 分级惯例对应（I 级为死亡），写进报告前以附件原文为准；附件编号和用语与本院转发件不一致的，按转发件原文写。一些地方标准和团体标准用“Ⅰ级至Ⅳ级”的另一套命名，不与上表混用。

## 五、医疗质量安全核心制度

依据《医疗质量管理办法》第四十七条、《医疗质量安全核心制度要点》（国卫医发〔2018〕8号），共18项：首诊负责制度、三级查房制度、会诊制度、分级护理制度、值班和交接班制度、疑难病例讨论制度、急危重患者抢救制度、术前讨论制度、死亡病例讨论制度、查对制度、手术安全核查制度、手术分级管理制度、新技术和新项目准入制度、危急值报告制度、病历管理制度、抗菌药物分级管理制度、临床用血审核制度、信息安全管理制度。

写材料时用制度全称，如“手术安全核查制度”，不写“三方核查制度”。

## 六、组织与程序术语

| 术语 | 写法 |
|---|---|
| 党委会议、院长办公会议 | 正文用全称，纪要和议题中不简称“党委会”“办公会”（本院惯例另有规定的除外） |
| 党委领导下的院长负责制 | 照此原文写，不改写为“党委领导、院长负责” |
| “三重一大” | 重大事项决策、重要干部任免、重要项目安排、大额度资金使用；范围和金额标准按本院规定 |
| 专业委员会 | 写全称，如“医疗质量与安全管理委员会”“药事管理与药物治疗学委员会”“医学伦理委员会”，以本院设置为准 |
| 职工代表大会 | 首次出现写全称，之后可写“职代会” |
| 签报 | 院内请示事项的文书，格式按本院签报单 |
| 医德“一票否决”制 | 中办2018年意见原文用语，医德考评材料可直接引用 |

## 七、缩写的写法

1. 首次出现写“中文全称（英文缩写）”，如“病例组合指数（CMI）”“根本原因分析（RCA）”“多学科诊疗（MDT）”，之后可用缩写。
2. 面向全院职工、职代会、患者的材料少用缩写；对外材料尽量不用。
3. 系统名称首次出现写全称，如“国家医院质量监测系统（HQMS）”“国家医疗质量管理与控制信息网（NCIS）”。
