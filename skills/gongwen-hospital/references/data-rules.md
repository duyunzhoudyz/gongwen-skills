# 指标台账与数据写法

> 用于第二步建台账、第四步写指标、第五步对账。通用数字用法见 `references/_shared/rules/gbt15835.md`、`references/_shared/rules/data-expression.md`，本文件只写医院特有的做法。“工具约定”是本项目为落地而定的做法，不是国家规定。例句中的科室、数值、日期均为示意。

## 一、指标台账

把用户给的数据和事实拆成一条一条，整理成 `素材台账.md`（网页版放在起草说明之后“附：指标台账”）。

| 序号 | 类别 | 内容 | 统计周期 | 口径与来源系统 | 来源 | 状态 |
|---|---|---|---|---|---|---|
| 1 | 指标 | 出院患者微创手术占比 26.3% | 2026年4—6月 | 病案首页（HQMS 上传口径） | 《二季度质量数据》第4行 | 已确认 |
| 2 | 指标 | 时间消耗指数 1.03 | 2026年4—6月 | 用户未说明是卫健还是医保口径 | 用户消息 | 待核实 |
| 3 | 程序 | 药事管理与药物治疗学委员会已于5月论证 | | | 用户消息 | 已确认 |

1. 类别只用六种：指标、工作事项、案例、问题、下步打算、程序（议题的前置程序、整改的佐证）。
2. 一条只记一个数或一件事。统计周期写到月；用户只说“今年”“上季度”的，照记原话，状态“待核实”，不按当天日期推算起止月份。
3. 口径与来源系统按 `references/profile-detail.md` 第三部分填写；用户没说的写“未说明”，状态“待核实”。
4. 以下情况状态一律记“待核实”：原话带“大概”“约”“差不多”“大致”“多”；没有统计周期；同一指标两处数值不同；卫健口径和医保口径分不清；数值明显超出常理（如 CMI 为 108）。
5. 由台账数据算出的数另起一行，类别写“指标”，内容写算式，来源写“由第 3、5 条计算”。
6. 系统生成的指标（国家监测指标的国家值、DRG 组数、CMI、入组率、满意度）不自行计算，只登记用户给出的结果。
7. 台账同样脱敏：患者写“患者张某”，当事医务人员写“当班护士甲”。

## 二、指标的写法

一个指标写全四样：名称、统计周期、数值、比较对象。

误：今年微创手术比例明显提升，CMI 大幅增长。
正：2026年4—6月，出院患者微创手术占比为26.3%，较上年同期提高1.9个百分点；CMI为0.94（卫生健康部门绩效评价口径），上年同期为0.91。

1. 名称用 `references/glossary.md` 第一部分的规范写法，按所写体系选用。
2. 比较写明基期：同比写“较上年同期”，环比写“较上季度（上月）”，不混用。
3. 用户只给了本期数、没给比较数的，只写本期数，不写“有所提高”。
4. 用户给确数的，不加“约”“左右”；给口头约数（“大概”“差不多”“大致”）的，正文照写约数（如“口头反馈约95%”），起草说明请用户核实准确数，不得去掉“约”写成确数（`references/_shared/rules/data-expression.md` 第八部分第3条）。

## 三、计算与表述

| 要写的 | 算法 | 写法 |
|---|---|---|
| 增减量 | 本期数－比较期数 | 出院人次增加286人次 |
| 增幅（增长率） | （本期数－比较期数）÷比较期数×100% | 门诊人次增长4.2% |
| 百分率之差 | 本期率－比较期率 | 微创手术占比提高1.9个百分点 |
| 指数的变化 | 本期值－比较期值 | CMI 由0.91提高到0.96，提高0.05 |
| 天数的变化 | 本期天数－比较期天数 | 平均住院日缩短0.3天 |
| 占比 | 部分÷总体×100% | 日间手术占择期手术的21.5% |
| 评审条款符合比例 | 符合条款数÷纳入评审的条款数×100% | 甲等不低于90%、乙等不低于80%、丙等不低于70%（评审2025 使用说明） |
| 目标达成率（品管圈常用，工具约定） | （改善后－改善前）÷（目标值－改善前）×100% | 目标达成率为82.4% |
| 进步率（品管圈常用，工具约定） | （改善后－改善前）÷改善前×100% | 降低类指标取绝对值，并写明“降低” |

1. 百分点只用于两个百分率相减。CMI、消耗指数、RW 等指数和平均住院日不用百分点（机检 HOS-006）；CMI 不带百分号（HOS-007）。
2. 每个算出来的数，在台账中写算式，在起草说明中写“第X部分的增幅由台账第3、5条计算”。
3. 用户给的率没有分子分母的，照用，不反推例数。
4. 品管圈、PDCA 竞赛或医院另有算法的，按其规定，起草说明写明采用哪种算法。

## 四、导向与达标判断

1. 指标有导向：逐步提高（如出院患者四级手术比例）、逐步降低（如并发症发生率、费用增幅）、监测比较。写“改善”还是“退步”先看导向，导向以当年操作手册为准；用户没给手册的，按默认导向判断：逐步提高——手术占比、微创手术占比、四级手术比例、医疗服务收入占比、满意度；逐步降低——并发症发生率、低风险组病例死亡率、费用增幅、抗菌药物使用强度。表中没有的，起草说明请用户对照当年手册。正文和起草说明都注明“导向以当年手册为准”，不因没有手册放弃分类。
2. 有标准值才写“达标”“未达标”。标准值写明来源（评审细则第几条、手册、本院目标责任书），来源由用户提供；没有的，起草说明请用户提供。
3. 不用“全面达标”“均符合要求”概括；逐项列出达标和未达标的数量，未达标的逐个写原因。
4. 国家反馈的等级、排名、分位数只写用户提供的原文结果，注明是哪一年度的结果。

## 五、口径冲突与数据质量

| 冲突 | 处理 |
|---|---|
| HIS 统计与病案首页（上报口径）不一致 | 报上级的材料用上报口径；两处都列入台账，正文用一处并注明，差异写进起草说明 |
| 卫生健康部门绩效评价的 DRG 数据与医保结算的 DRG 数据不一致 | 分开写，不比较、不相加；述职中两种都要写的，分两句并各注口径 |
| 院内不良事件系统与国家平台例次不一致 | 写明取自哪处；差异列入起草说明“待核实”一行 |
| 科室报的数与职能部门统计不一致 | 不取平均、不挑大的，正文并列写明两处来源，起草说明附口径冲突表 |

口径冲突表列为：序号｜指标｜各处数值｜冲突类型｜本稿处理｜请谁确认。

病案首页质量问题的写法：
1. 可以写首页填写和编码的问题（如主要诊断选择错误、手术操作漏填）及其对指标的影响，措施写“按编码规范填写、加强首页质控”。
2. 不写、不建议为提高指标而调整编码（高编高套），这类建议属于违规，见 `references/redlines.md` 第四条。
   - 误：将部分二级手术编为四级手术，提高四级手术比例。
   - 正：病案科对手术科室开展首页填写核查，漏填的四级手术按实际补录。

## 六、小样本、排名与隐私

1. 分母小的率（工具约定：分母不足30例）同时写例数，如“本季度死亡3例，手术患者住院死亡率0.5%”，不单凭率的变化下结论。
2. 科室排名、科室间比较只在用户提供了排名或各科数据时写；同类科室之间比较，不把内科和外科放在一起排。
3. 病例很少时，时间、科室、病种组合起来能认出患者，对外材料和全院通报中去掉这类组合，写“某手术科室”“三季度”。
4. 涉及医务人员个人的数据（工作量、处方量、医德考评结果）只写用户提供的、且按本院规定可以在该范围公开的部分。
