# 党委会议、院长办公会议议题材料

> 依据：中共中央办公厅《关于加强公立医院党的建设工作的意见》（2018年）："院长办公会议是医院行政、业务议事决策机构""重要行政、业务工作应当先由院长办公会议讨论通过，再由党委会议研究决定""不得以党政联席会议代替党委会议"；党委讨论和决定"三重一大"等重大问题。议题格式、"三重一大"范围和金额标准以本院议事规则为准。核验日期 2026-10-16。
> 会后的纪要、会议记录、督办清单交 gongwen-minutes；需要报上级审批的请示交 gongwen-draft。

## 一、用途与上会路径

1. 用途：科室或职能部门把需要会议决定的事项写成议题材料，经分管院领导同意后提交院长办公会议，重大事项再提交党委会议。
2. 先判断上哪个会（判断不了的标【待核实：本院议事规则】）：
   - 一般行政、业务事项：院长办公会议决定；
   - 重要行政、业务工作：院长办公会议讨论通过后，提交党委会议研究决定；
   - 党的建设、干部、纪检、意识形态等党委职权事项：党委会议；
   - 涉及职工切身利益的（如绩效分配方案）：按本院规定提交职工代表大会审议或听取意见。
3. 高校附属医院须报学校的事项、国企举办的医院须报集团（公司）前置研究的事项，写进前置程序（`references/profile-detail.md` 第四部分）。

## 二、默认结构

本院有议题申请单或议题报告模板的，按模板；没有的，按下面的结构。

```text
关于购置磁共振成像设备的议题

汇报单位：医学装备部
汇报人：医学装备部主任
分管院领导：某副院长

一、议题事由
（要解决什么问题，依据什么，两三句）

二、方案比较
（两个以上方案的内容、费用、资金来源、效益、风险；只有一个方案的写明为什么没有备选）

三、前置程序履行情况
（逐项写：已履行、尚未履行、不适用）

四、提请会议决定的事项
1. 同意……
2. 同意……

附件：1. 论证意见　2. 测算表　3. 征求意见汇总
```

## 三、写法要点

1. 一题一议。一份议题只提一件需要决定的事，相关联但可以分开决定的分成两个议题。
2. 议题名称写成"关于……的议题"，事由写清楚要决定什么，不写成"关于××工作的汇报"。
3. 方案比较写事实和测算：费用、资金来源、预期效益、风险，数据只用用户提供的，测算写算式。比较后写明汇报单位的倾向方案和理由，不写"两种方案各有利弊，请领导研究"（`references/_shared/style/defensive.md` 第四部分）。
4. 提请决定的事项写成会议可以直接表决的句子：同意什么、金额上限、资金来源、执行部门、时限。
   - 误：请会议研究购置设备事宜。
   - 正：同意购置磁共振成像设备1台，预算不超过【待补：金额】万元，资金来源为【待补】，由医学装备部按政府采购程序组织实施。
5. 前置程序如实写。没有履行的写"尚未"并说明安排，不写成已履行；"先执行、后补程序"的，起草说明提示程序倒置风险（`references/redlines.md` 第五条）。
6. 不用党政联席会议作为决策会议（机检 HOS-004）；涉及"三重一大"的，写明拟提交党委会议研究决定（机检 HOS-005）。
7. 篇幅短：正文一般不超过 2000 字（工具约定），细节放附件。
8. 党委会议议题叠加严谨模式：政治性表述只用用户提供的原文，没有的标【待核实：请对照最新原文】。

## 四、前置程序核对表

按本院议事规则增删。起草时逐项向用户确认，没确认的写【待核实】。

| 程序 | 适用情形 | 写法示例 |
|---|---|---|
| 职能部门审核、相关部门会签 | 一般都要 | 已经财务部、审计部会签 |
| 专业委员会论证 | 设备购置、药品遴选、新技术新项目、伦理事项等 | 医学伦理委员会于2026年5月12日审查通过 |
| 合法性审查 | 合同、制度、涉法事项 | 已经法务部门审查 |
| 财务测算、资金来源 | 涉及资金 | 资金来源为医院自有资金 |
| 征求意见 | 涉及多个部门或职工利益 | 已征求临床科室意见，收到意见12条，采纳9条 |
| 分管院领导同意 | 一般都要 | 已经分管副院长同意 |
| 院长办公会议讨论 | 提交党委会议的重要行政、业务工作 | 已经2026年第18次院长办公会议讨论通过 |
| 职工代表大会审议 | 涉及职工切身利益 | 拟提交职工代表大会审议 |
| 上级审批或报备 | 按规定须报上级的 | 按规定报市卫生健康委备案 |

## 五、常见毛病与正误对照

例句中的设备、金额、日期均为示意，起草时只用用户材料中的事实。

1. 把汇报写成议题。
   - 误：关于2026年医学装备工作情况的汇报。（没有要决定的事）
   - 正：关于购置磁共振成像设备的议题。
2. 只有一个方案，或比较后不表态。
   - 误：方案一投入大、效果好，方案二投入小、见效慢，各有利弊，请会议研究。
   - 正：两方案相比，方案一一次投入【待补】万元，可同时承担神经系统和心脏检查；方案二……建议采用方案一。
3. 程序写倒。
   - 误：设备已于8月完成采购，现提请会议追认。
   - 正：起草说明提示"先执行后上会属于程序倒置"，正文如实写采购时间，提请会议研究的事项按用户确认的内容写。
4. 用党政联席会议决策（机检 HOS-004）。

## 六、只出框架的情形

用户只说了议题名称，没有方案内容、金额和程序信息的：交付议题结构、前置程序核对表和需要补充的信息清单，提请决定的事项写成带【待补】的句式。

## 七、自检要点

- [ ] 判断了上哪个会，涉及"三重一大"的写明了党委会议程序。
- [ ] 一题一议，提请决定的事项可以直接表决。
- [ ] 方案比较有数据和倾向性意见，数据都在台账中。
- [ ] 前置程序逐项如实写，没确认的标了【待核实】。
- [ ] 没有党政联席会议决策的表述。
- [ ] 有 Python 时运行 `python scripts/hospital_check.py 正文.txt --type 议题`。
