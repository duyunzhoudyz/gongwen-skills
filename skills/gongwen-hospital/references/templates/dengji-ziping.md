> 依据：《三级医院评审标准（2025年版）》（国卫医政发〔2025〕4号）及本省实施细则；中医医院用《三级中医医院评审标准（2026年版）》；二级医院参照三级标准和本省二级医院细则。核验日期 2026-10-16。

## 一、用途与报送

1. 用途：医院在申请评审前或评审周期中，对照前置要求和监测指标逐项自查，形成自评报告，随评审申请材料报送；也用于院内迎评动员和差距梳理。
2. 报送对象：三级医院一般报省级卫生健康行政部门，二级医院按本省规定。报送用的请示或报告交 gongwen-draft，本模板只写自评报告本身。
3. 任务卡列明三件事：医院级别和类别；本省实施细则的名称和版本（自评报告的章节以细则为准）；评审周期（起止年份）。缺的写进所作假设或标【待补】，问题放在回复末尾，不阻塞起草。
4. 2025年版国家标准取消了“现场检查”部分，由前置要求和监测指标两部分组成；各省仍可线上线下结合开展评审。本省细则另设现场检查或自评条款的，按细则增加相应章节。

## 二、默认结构

本省有自评报告模板的，按模板；没有的，按下面的结构。

```text
某医院三级医院评审自评报告

一、医院基本情况
（床位规模、科室设置、人员、功能定位落实情况，只写用户提供的数据，注明统计时点）

二、自评工作开展情况
（组织方式、时间、覆盖范围、数据核查方法，一段即可）

三、前置要求自查情况
（一）床位规模和科室设置
（二）依法执业和规范服务
（三）公益性责任和行风诚信
（四）安全管理与重大事件
（每节写：评审周期内是否发生所列情形；发生的，写明事项、时间和处理结果）

四、监测指标自评情况
（一）资源配置与运行数据指标
（二）医疗服务能力与医院质量安全指标
（三）重点专业质量控制指标
（四）单病种（术种）质量控制指标
（五）重点医疗技术临床应用质量控制指标
（每章写：纳入指标数、符合数、不符合数；不符合的逐项写差距和原因）

五、数据质量核查情况
（数据来源系统、与国家平台上报数据的核对方式、发现的差异和处理）

六、存在的主要问题
（具体到指标或条款）

七、整改措施和计划
（问题、措施、责任部门、时限一一对应）

附件：1. 前置要求自查表　2. 监测指标自评表　3. 佐证材料清单
```

第二部分各章名称取自 2025 年版标准第二部分。本省细则的章节名称不同的，用细则的名称。

## 三、写法要点

1. 写本院做法和数据，不复述标准条文。标准条文写一句“对照第X节”即可，篇幅用在本院的事实上。
2. 前置要求逐节写明结论，结论由用户确认：
   - 用户确认未发生的，写“评审周期内未发生本节所列情形”；
   - 用户没有确认的，写【待核实：评审周期内是否发生本节所列情形】，不替医院下结论；
   - 发生过的，如实写事项、时间、处理和整改情况，不回避；
   - 材料中可能触及前置要求的事实，逐条列出请用户确认是否属于所列情形，不自行下结论，也不隐去。常见的有：实际开放床位多于核定床位（对应第一节“床位规模和科室设置”），发生火情、安全事故，受到行政处罚。
3. 监测指标按“全或无”和“区间赋分兼顾持续改进”两种原则判断（标准使用说明）：规模类、配比类指标达到标准即符合；连续监测指标按本地区基线和改进趋势判断。基线和本地区标准由用户提供，没有的标【待补】。
4. 多年数据合并按标准使用说明：规模类和配比类指标的中位数和最后一年必须达标；连续监测指标趋势与管理目标一致或呈波动的，用中位数或平均数，趋势相反的用最差的数据。写自评结论前按此取值，起草说明写明取值方法。
5. 符合比例要计算：符合条款数÷纳入条款数×100%，写算式。只有用户提供了逐条自评结果，才写“符合比例为X%”；不写“达到甲等标准”一类结论，等次由评审结论确定。
6. 数据与上报一致：每个指标写数据来源（HQMS、NCIS、卫生资源统计年报等），与国家平台上报值不一致的，正文用上报值并在“数据质量核查情况”中说明差异。核查时差距10%以上（含正负）即为错误数据，错误数据超过核查条款10%的按违反前置要求第三节第（五）条处理，所以数据不一致的地方必须列出，不能调和。
7. 不适用的指标（如专科医院不开展的专业），写“不适用”并说明理由，不留空。
8. 问题与整改一一对应，整改措施写到责任部门和时限；措施缺的标【待补：整改措施】。

## 四、数据项清单

按用户提供的取用，缺的列入起草说明“待补事项”并写明一般到哪里找：

| 数据 | 一般来源 |
|---|---|
| 核定床位数、实际开放床位数、总床位数、单体院区床位数、分院区数量 | 卫生资源统计年报、医院执业登记 |
| 卫生技术人员数与开放床位数比、医护比、各专科医师配置 | 电子化注册系统、人事部门 |
| 核定床位使用率、开放床位使用率、出院患者四级手术占比、CMI | HQMS、病案首页、统计报表 |
| DRG 组数、时间消耗指数、费用消耗指数、DRG低风险组病例死亡率 | 卫生健康部门 DRG 绩效评价结果 |
| 医院获得性指标（手术并发症、医院感染等） | 病案首页、院感监测系统 |
| 重点专业、单病种、重点医疗技术质控指标 | NCIS、国家单病种质量管理与控制平台 |
| 年度国家医疗质量安全改进目标落实情况 | 质控科统计 |

## 五、常见毛病与正误对照

例句中的指标、数值均为示意，起草时只用用户材料中的事实。

1. 照抄标准条文。
   - 误：医院严格落实医疗质量安全核心制度，建立健全各项管理制度，确保医疗质量持续改进。
   - 正：医院修订核心制度实施细则18项，2026年开展核心制度落实专项检查【待补：次数】次，发现问题【待补：条数】条，已整改【待补：条数】条。
2. 替医院下前置要求结论。
   - 误：评审周期内，医院未发生任何违反前置要求的情形。（用户没有确认）
   - 正：评审周期内是否发生本节所列情形【待核实：请医务部、院办逐条确认】。
3. “全面达标”式概括。
   - 误：各项监测指标均达到或优于标准要求。
   - 正：第三章纳入指标36项，符合31项，不符合5项，分别是……
4. 数据与上报值不一致却不说明。
   - 误：正文写出院患者手术占比45.6%（HIS 统计），未提上报值。
   - 正：出院患者手术占比44.1%（HQMS 上报口径）；HIS 统计为45.6%，差异原因【待核实：请病案科说明】。
5. 用已废止的 2022 年版条款编号（机检 HOS-016）。
6. 只写成绩，不写差距；或把计划写成已完成。

## 六、只出框架的情形

1. 用户没有提供任何指标数据、自查结果和其他具体事实（首轮交付情形②）：交付本模板的结构、前置要求自查表（空表）、监测指标自评表（空表，列为：章节｜指标名称｜标准值及来源｜本院值｜统计周期｜数据来源｜是否符合｜说明）和数据收集清单（指标、来源系统、责任科室），不写正文结论。
2. 用户只给了部分数据：有数据的章节成稿，其余写【待补】，起草说明列出数据收集清单。

## 七、自检要点

- [ ] 依据写的是 2025 年版标准（中医医院为 2026 年版中医标准），本省细则名称已写或标【待补】。
- [ ] 前置要求每节都有用户确认的结论，或标了【待核实】。
- [ ] 每个指标都有统计周期和数据来源，与上报值的差异已列出。
- [ ] 符合比例有算式，没有写“达到甲等”一类结论。
- [ ] 不适用的指标写明了理由。
- [ ] 问题与整改措施一一对应。
