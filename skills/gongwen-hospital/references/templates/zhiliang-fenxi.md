# 医疗质量分析报告（月、季、年）

> 依据：《医疗质量管理办法》（国家卫生计生委令第10号）第十一条、第十二条（质量管理委员会和科室定期分析、评估、反馈）；《医疗质量安全核心制度要点》（国卫医发〔2018〕8号）；当年国家医疗质量安全改进目标。分析频次和报告格式以本院规定为准。核验日期 2026-10-16。

## 一、用途与篇幅

1. 用途：质控科或医务部向医疗质量与安全管理委员会、院长办公会议、质控分析会报告一个周期的质量状况；科室版由科室质控小组写给科室和职能部门。
2. 篇幅（工具约定，本院有规定的按规定）：月报 1500～3000 字；季报 3000～5000 字；年报 5000 字左右，详细数据放附表。会上宣读的按约 200 字/分钟折算。
3. 读者是院领导和科主任，先给结论和需要决定的事，再给数据。

## 二、默认结构

```text
某医院2026年第二季度医疗质量分析报告

一、总体情况
（三到五句：本期质量总体结论，3～5个关键指标，与比较期的变化，最突出的一个问题）

二、主要指标监测情况
（一）医疗服务量与效率
（二）医疗质量安全
（三）合理用药
（四）核心制度落实与病历质量
（五）医院感染
（六）不良事件报告
（七）年度改进目标落实情况
（只写用户提供了数据的部分，没有数据的部分整节不写，起草说明列出）

三、存在的问题及原因分析
（按问题写：表现、涉及科室、原因；原因只用材料）

四、改进措施
（对应第三部分的问题：措施、牵头科室、完成时限、评价指标）

五、提请会议研究的事项
（没有的省略）

附表：主要指标监测表（指标｜本期｜比较期｜变化｜导向｜数据来源）
```

## 三、写法要点

1. 总体情况先下结论，用数据支撑，不写“在院党委的正确领导下”一类铺垫。
2. 每个指标写全名称、周期、数值、比较（`references/data-rules.md` 第二部分）。同比和环比不混用；季报一般写同比，月报可写环比并注明。
3. 只写有变化、有问题、有改进的指标，平稳的指标进附表，不在正文逐个罗列。
4. 异常指标要下钻：哪几个科室、哪类病例、哪个环节。下钻数据没有的写【待补：科室分布】，不推测。
5. 原因分析只用材料中的事实（科室反馈、病历检查记录、访谈）。材料只有现象没有原因的，写“原因待科室分析，【待补：原因】”，起草说明提示用 RCA 或鱼骨图分析。
6. 改进措施写成可检查的动作：做什么、谁牵头、何时完成、用哪个指标看效果。措施内容、牵头部门、时限只来自材料；只写“加强培训”“提高认识”的，标【待补：具体措施】。
7. 上期提出的改进措施，本期写落实情况（已完成、正在推进、未启动），状态只用用户提供的。
8. 分母小的率同时写例数；科室排名只在用户提供了排名时写（`references/data-rules.md` 第六部分）。
9. 病例描述一律脱敏：患者张某，男，56岁；不写床号与姓名。

## 四、数据项清单

| 板块 | 常用数据 | 一般来源 |
|---|---|---|
| 服务量与效率 | 门急诊人次、出院人次、手术台次、平均住院日、床位使用率、CMI、DRG 组数 | HIS、病案首页 |
| 质量安全 | 住院死亡率、手术患者住院死亡率、非预期重返手术室再次手术率、出院后0—31天非预期再住院率、手术并发症、低风险组病例死亡率 | 病案首页 |
| 合理用药 | 抗菌药物使用强度、处方点评合格率 | 药学部 |
| 核心制度与病历 | 核心制度落实检查结果、病历甲级率、首页填写质量 | 质控科、病案科 |
| 医院感染 | 医院感染发病率、手卫生依从率、I类切口手术部位感染率 | 院感监测系统 |
| 不良事件 | 上报例次、每百出院人次报告例次、分级分类构成 | 不良事件上报系统 |
| 改进目标 | 当年国家医疗质量安全改进目标对应指标 | 质控科 |

## 五、常见毛病与正误对照

例句中的科室、数值、日期均为示意，起草时只用用户材料中的事实；材料没有的标【待补】。

1. 数据堆砌，没有结论。
   - 误：本季度门诊人次……出院人次……手术台次……平均住院日……（逐项罗列二十个数）
   - 正：第二季度医疗质量总体平稳，手术患者住院死亡率与上年同期持平；需关注的是神经内科院内压力性损伤上升，本季度发生4例，上年同期1例。
2. 原因靠推测。
   - 误：压力性损伤增多主要是患者高龄、护士责任心不足所致。
   - 正：4例均为长期卧床患者，其中3例的翻身记录有超过2小时的间隔（护理记录）。其他原因【待补：护理部分析】。
3. 措施空泛。
   - 误：进一步加强压力性损伤防范，切实提高护理质量。
   - 正：护理部牵头修订卧床患者翻身流程，【待补：完成时限】；以下一季度院内压力性损伤例次评价效果。（示意材料为护理部的整改意见“修订翻身流程”；材料没有时限，标【待补】，不替医院定日期）
   - 材料没有措施的，正文写【待补：具体措施和牵头部门】；“护理系统增加翻身到时提醒”一类起草者想到的做法，写进起草说明“附：可供参考的改进思路”。
4. 同比和环比混用，或用“百分点”写指数（机检 HOS-006）。
5. 把上期措施写成“已完成”，但用户材料只说“已部署”。

## 六、只出框架的情形

用户没有提供本期数据和其他具体事实的（首轮交付情形②）：交付结构和“本期需要的数据清单”（指标、来源系统、提供科室），不写结论。只提供了部分板块数据的，有数据的板块成稿；总体情况、问题及原因、改进措施等必备部分保留，缺的写【待补：该补什么】；没有数据的监测板块不硬凑。
