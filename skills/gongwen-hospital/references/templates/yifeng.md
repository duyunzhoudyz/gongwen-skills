## 二、九项准则落实情况自查报告

```text
某医院关于落实《医疗机构工作人员廉洁从业九项准则》情况的自查报告

一、自查工作开展情况
（组织、范围、方式、时间，一段）

二、落实情况
（一）合法按劳取酬，不接受商业提成
（二）严守诚信原则，不参与欺诈骗保
（三）依据规范行医，不实施过度诊疗
（四）遵守工作规程，不违规接受捐赠
（五）恪守保密准则，不泄露患者隐私
（六）服从诊疗需要，不牟利转介患者
（七）维护诊疗秩序，不破坏就医公平
（八）共建和谐关系，不收受患方“红包”
（九）恪守交往底线，不收受企业回扣
（每项写：制度和措施、检查情况、发现的问题；各项的标题以准则原文为准）

三、发现的问题
（逐条写：问题、涉及范围、性质）

四、整改措施
（问题｜措施｜责任部门｜时限）
```

九项的标题按准则原文核对后使用；用户没有提供准则原文的，起草说明提示“九项标题请对照国卫医发〔2021〕37号原文核对”。

## 三、行风建设情况报告

```text
某医院2026年行风建设工作情况报告

一、主要工作和成效
（按当年纠风工作要点的重点任务对应写；只写用户提供的事实和数据）

二、问题线索处置情况
（投诉、举报、信访件数和办结情况，数据来源写明）

三、存在的问题

四、下一步工作
```

当年纠风工作要点由用户提供；没有的，按用户材料中的工作板块组织，不自行列“今年重点”。

## 四、医德考评方案和结果报告

1. 方案：考评对象、内容、方式（自评、科室评价、单位评价）、等次、结果运用、时间安排。等次和结果运用按上级部署和本院办法，用户没提供的标【待补】，不自定等次比例。
2. 结果报告：参评人数、各等次人数、“一票否决”情形及处理（只写用户提供的、按规定可以在该范围公开的内容）、发现的问题和改进。
3. 医务人员个人的考评结果不写进面向全院的材料。

## 五、写法要点

1. 每项写“做了什么、查了什么、发现什么”，不写“始终坚持”“全面落实”一类的空话。
2. 数据（投诉件数、退还红包例次、查处件数）只用用户提供的，写明统计周期和来源（纪检监察、行风办、投诉管理）。没有的标【待补】，不写“零投诉”“零红包”之类的结论。
3. 发现的问题写具体：哪类问题、涉及哪些环节或科室、几件。自查没发现问题的，写“本次自查未发现××方面的问题”，并写清自查范围，不写“不存在任何问题”。
4. 违纪违规案例只用用户提供的通报原文，不改写情节，不补充细节；通报原文没有公开姓名的，用“某科室医师”。
5. 依据写现行文件：九项准则替代了“九不准”（机检 HOS-017）。
6. 提法、上级要求的表述，只用用户提供的原文；没有的用通用、稳定的表述，起草说明请对照最新原文。

## 六、数据项清单

| 数据 | 一般来源 |
|---|---|
| 行风类投诉、举报、信访件数和办结情况 | 投诉管理办公室、行风办、信访办 |
| 医务人员主动退还红包、拒收礼品的例次和金额 | 行风办登记 |
| 统方监控拦截次数、处方点评和超常预警结果 | 信息中心、药学部 |
| 专项检查次数、覆盖科室数、发现问题条数 | 行风办、纪检监察部门的检查记录 |
| 查处件数和处理结果（只用按规定可公开的部分） | 纪检监察部门的通报原文 |
| 医德考评参评人数、各等次人数 | 人事科、医德考评工作组 |
| 医药代表接待登记、捐赠和资助审批 | 行风办、财务部门 |

## 七、常见毛病与正误对照

例句中的数据均为示意，起草时只用用户材料中的事实。

1. 空泛表态。
   - 误：医院始终坚持把行风建设摆在突出位置，全面落实九项准则，行风持续向好。
   - 正：2026年医院开展九项准则专项检查，覆盖临床医技科室（次数、科室数、问题条数材料有则写，没有则省略）。
2. 绝对化结论。
   - 误：全年实现零投诉、零红包。
   - 正：全年受理行风类投诉【待补：件数】件，均已办结；医务人员主动退还患者红包【待补：例次】例次（行风办登记）。
3. 引用已废止的“九不准”（机检 HOS-017）。
4. 改写或补充违纪案例情节。

## 八、只出框架的情形

1. 用户没有提供任何自查事实和数据的：交付结构和每项需要补充的事实清单，不写落实情况。
2. 医务人员个人医德自评没有本人事例的：只给填写指引（写哪几方面、每方面写什么样的具体事例），不代写；有事例的据实整理成文。思想汇报交 gongwen-party。

## 九、自检要点

- [ ] 每项都有具体做法或数据，数据有来源和周期。
- [ ] 没有“零投诉”“全面落实”一类无依据的结论。
- [ ] 案例与通报原文一致，人员信息按通报的公开程度处理。
- [ ] 依据是九项准则，不是“九不准”。
- [ ] 报纪检、报上级党组织的材料，提法都有原文，没有的已列入起草说明。
