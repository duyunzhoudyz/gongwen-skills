# 科室主任述职

> 依据：述职的组织方式、栏目和时间以本院考核通知为准；DRG 指标口径见 `references/glossary.md` 第二部分；医保分组方案为医保办发〔2024〕9号（2025年起统一使用 2.0 版）。“本人事例不代写”依据 `references/_shared/guardrails.md` 第六条第4款。核验日期 2026-10-16。
> 院领导的述职述责述廉、职能部门负责人的一般述职交 gongwen-report；本模板只管临床、医技科室主任（含副主任、护士长按此参照）带业务指标的述职。

## 一、用途与形式

1. 用途：年度或任期考核时，科室主任向医院考核组、院领导或职工代表报告履职情况。
2. 形式：书面述职一般 2000～3000 字，以本院考核通知为准。现场述职（含口头稿）也由本包写，按时长折算篇幅，一并给出，不转 gongwen-speech（写法见第四部分）。
3. 任务卡列明：书面还是现场（时长多少）；考核通知规定的栏目；数据的统计周期和口径。缺的按默认（书面述职、本模板栏目）写进所作假设，问题放在回复末尾，不阻塞起草。

## 二、默认结构

```text
2026年度述职报告
（××科主任　某某）

一、基本情况
（科室规模、本人任职时间、年度目标责任书的主要目标，三五句）

二、履职情况和主要成效
（一）医疗质量与安全
（二）医疗服务能力与 DRG 运营
（三）学科建设与人才培养
（四）教学与科研
（五）科室管理
（六）医德医风与廉洁自律

三、存在的问题和不足

四、下一步工作打算
```

本院考核通知规定了栏目的，按通知；高校附属医院一般在（四）中增加本科教学、研究生培养、住院医师规范化培训。

## 三、写法要点

1. 分清科室成绩和本人作用。科室数据写科室，本人做了什么写本人，用“本人牵头”“本人主持”“本人主刀”等，这些角色必须来自用户原话。
   - 误：本人全年完成支气管镜诊疗860例。（材料只写了科室全年860例）
   - 正：科室全年完成支气管镜诊疗860例，本人操作【待补：例数】例；本人牵头开设慢阻肺随访门诊，随访患者【待补：人数】人。
2. DRG 指标写明口径和版本：卫生健康部门绩效评价口径，或医保结算口径（CHS-DRG 2.0 等）。两种口径的 CMI、组数、消耗指数分开写，不比较、不相加。材料没说口径的，标【待核实：CMI 口径】。
3. 指数的变化写差值：“CMI由0.91提高到0.96”，不写“提高5个百分点”（机检 HOS-006），CMI 不带百分号（HOS-007）。
4. 结果和原因连起来写，原因只用材料：四级手术比例提高，是因为开展了哪项新技术、新增了哪个亚专业，材料没有的不补。
5. 经济指标写结构和效率（医疗服务收入占比、次均费用增幅、成本控制），不写个人开单量和收入提成；医保结余、亏损等数据面向职代会或全院时，提示确认能否公开（`references/redlines.md` 第九条）。
6. 医德医风与廉洁自律只写用户提供的事实（如拒收红包例次、参加警示教育），没有的给填写指引，不替用户写“严守纪律，无违规违纪”一类表态。
7. 问题写具体：哪项指标没完成、差多少、原因是什么；不写“学科建设还有差距”一类的万能句。没有的标【待补：存在的问题】，起草说明给三个启发提问（哪项目标没完成、上级检查指出过什么、哪项工作比计划慢）。
8. 下一步打算与问题对应，写目标值的，目标值来自用户或目标责任书。

## 四、现场口头稿

时长换算和口语化借用 gongwen-speech 的讲稿规则，按本部分执行，不必另调用该 skill。

1. 字数＝分钟数×语速，默认每分钟约 200 字（经验值），画像或领导偏好卡写了语速的按其换算，以目标±10%为准。如 10 分钟约 2000 字，5 分钟约 1000 字。
2. 素材撑不起目标时长、差距超过 30% 的，按 `references/_shared/guardrails.md` 第四条第2款：回复第一段说明素材能支撑的时长和字数、差距，附补料清单；栏目全部保留，缺本人事例处写【待补：本人……的具体事例】；【待补】不计入字数，不用表态和背景凑时长。
3. 口语化：整句一般不超过 40 字，一句一个意思；开头交底（如“我从四个方面汇报”），部分之间用一句过渡语；称谓开头用一次，大的转换处再用一两次；每段连用的数字不超过 3 个，挑最能说明问题的。
4. 与书面稿一致：口头稿的数只从书面稿和台账取，不新增；考核场合要和书面材料对得上，数字用原数，不取整；指数、百分点的写法和口径说明与书面稿相同。
5. 书面稿、口头稿都要的，一次交付：书面稿在前，口头稿另起，标题写“现场述职稿”；起草说明写时长测算（字数÷语速≈分钟数）。

## 五、数据项清单

| 板块 | 常用数据 | 一般来源 |
|---|---|---|
| 医疗质量与安全 | 手术患者并发症发生率、非预期重返手术室再次手术率、低风险组病例死亡率、不良事件上报例次、病历甲级率 | 质控科、病案首页 |
| 服务能力与 DRG | 出院人次、手术台次、出院患者四级手术比例、微创手术占比、CMI、DRG 组数、时间和费用消耗指数、平均住院日 | 病案首页、DRG 绩效评价或医保结算 |
| 学科与人才 | 新技术新项目例数、亚专业设置、人才引进和培养 | 医务部、人事部门 |
| 教学科研 | 带教人数、科研项目和经费、论文（只写用户提供的，期刊名称核实） | 科教部门 |
| 科室管理 | 平均住院日、床位使用率、成本控制、绩效分配改革 | 运营管理部 |

## 六、常见毛病与正误对照

例句中的科室、数值均为示意，起草时只用用户材料中的事实。

1. 把科室成绩全写成个人成绩（见第三部分第1条）。
2. 口径混用。
   - 误：科室CMI为0.98，比医保结算的0.89高出不少，说明病例难度大。
   - 正：卫生健康部门绩效评价口径下，科室CMI为0.98；医保结算口径（CHS-DRG 2.0）下为0.89。
3. 只列数据不说做法。
   - 误：四级手术比例为14.7%，CMI为0.98，时间消耗指数为1.06。
   - 正：科室开展经支气管镜冷冻肺活检【待补：例数】例，出院患者四级手术比例由上年的11.9%提高到14.7%，提高2.8个百分点。
4. 廉洁部分替用户表态（见第三部分第6条）。

## 七、只出框架的情形

用户只给了科室数据、没有本人事例的（首轮交付情形①）：说明述职要写本人的真实履职情况，交付提纲和填写指引，不生成完整正文。填写指引逐栏写清要补什么，例如：

| 栏目 | 请补充 | 示例（格式示意） |
|---|---|---|
| 医疗质量与安全 | 本人牵头或主持的质量改进事项，至少一件：做了什么、本人角色、结果 | 牵头修订科室危急值处置流程，危急值处置及时率由×%提高到×% |
| 学科建设 | 本人推动的新技术、亚专业、人才培养 | 主刀开展××技术×例 |
| 医德医风与廉洁自律 | 本人的具体做法和事例 | 拒收红包×次，参加医院警示教育×次 |

部分栏目有本人事例的，有事例的栏目成稿，缺的栏目写【待补：本人……的具体事例】，对应的填写指引放进起草说明。

## 八、自检要点

- [ ] 本人角色都来自用户原话，没有把科室成绩写成个人成绩。
- [ ] DRG 指标写明了口径和版本，两种口径没有混用。
- [ ] 指数变化写差值，没有“百分点”和百分号。
- [ ] 医德医风、廉洁部分只有用户提供的事实。
- [ ] 问题具体，下一步与问题对应。
- [ ] 现场口头稿时长在目标±10%内，或已在回复第一段说明差距和补料清单；数据与书面稿一致。
- [ ] 有 Python 时运行 `python scripts/hospital_check.py 正文.txt --type 述职`。
