## 二、发文与决策链条

1. 发文：党委和行政两套代字；科室对院领导用签报或请示单；医院对卫生健康行政部门用请示、报告，对医保部门等不相隶属单位用函（详见 yiyuan.md 第二部分）。本包的专用文书多数以“报告”“材料”形式报送，报送用的那份公文（请示、报告、函）交 gongwen-draft。
2. 议题的一般链条（以本院议事规则为准）：
   - 科室或职能部门提出；
   - 职能部门审核，相关部门会签；
   - 需要专业论证的，先经专业委员会论证，如医疗质量与安全管理委员会、药事管理与药物治疗学委员会、医学伦理委员会、医疗设备管理委员会；
   - 分管院领导同意；
   - 院长办公会议讨论；
   - 重大事项提交党委会议研究决定；
   - 涉及职工切身利益的，按本院规定提交职工代表大会审议或听取意见。
3. “三重一大”的具体范围、大额资金的金额标准，各院议事规则规定不同。用户没提供的，正文标【待核实：本院“三重一大”事项范围和金额标准】，不自行设定金额。
4. 委员会、会议的名称以本院为准。用户说“质管会”“药事会”的，正文写全称，全称不知道的标【待核实】。

## 三、数据来源系统

指标台账“口径与来源系统”一列按下表填写。用户没说来源的，写“用户消息”，状态记“待核实”。

| 系统或报表 | 常见数据 | 备注 |
|---|---|---|
| HIS（医院信息系统） | 门急诊人次、出院人次、收入、床位使用 | 院内口径，可能与上报口径不同 |
| 住院病案首页 / 国家医院质量监测系统（HQMS） | 手术占比、四级手术比例、微创手术占比、低风险组病例死亡率、并发症发生率 | 绩效监测的主要数据源，按月上传 |
| 国家医疗质量管理与控制信息网（NCIS） | 重点专业质控指标 | 2025年版评审标准列为数据来源之一 |
| 国家单病种质量管理与控制平台 | 单病种（术种）质控指标 | 同上 |
| 卫生资源统计年报 | 床位、人员、设备 | 同上 |
| 财务年报、成本核算系统 | 收支结构、费用增幅、人员支出占比 | 绩效监测运营效率类指标 |
| 满意度调查平台 | 门诊、住院患者满意度，医务人员满意度 | 由国家平台调查，医院不能自行替换 |
| 国家医疗质量安全不良事件报告与学习平台、院内不良事件上报系统 | 不良事件例次、分级 | 两处数字可能不一致，写明取自哪处 |
| 院感监测系统 | 医院感染发病率、手卫生依从率、I类切口手术部位感染率 | 院感质控指标定义以国家文件为准 |
| 医保结算清单、DRG/DIP 分组结果 | 医保口径的 DRG 组数、CMI、结余或亏损 | 与卫生健康部门绩效评价口径不同，不混用 |
| 电子化注册系统 | 医师、护士人数和结构 | 绩效监测人员类指标 |

## 四、医院类型差异

| 类型 | 等级评审 | 绩效考核（绩效监测） | 写作调整 |
|---|---|---|---|
| 三级综合医院 | 《三级医院评审标准（2025年版）》加本省实施细则 | 三级手册（55项） | 默认类型 |
| 三级专科医院 | 同上；重点专业质控指标、单病种按本专业纳入 | 三级手册 | 不适用的指标写“不适用”并说明理由，不留空 |
| 二级医院 | 参照三级标准，加本省二级医院评审细则 | 二级手册（28项，国家监测指标21项） | 不套用三级医院的功能定位表述 |
| 中医医院、中西医结合医院 | 《三级中医医院评审标准（2026年版）》及本省细则 | 由国家中医药局组织，手册另行发布；不在卫生健康委“二级和三级公立医院（不含中医医院）绩效监测”范围 | 中医特色指标按中医系列文件写，名称以原文为准 |
| 高校附属医院 | 同综合医院 | 同综合医院 | 医院党委与学校党委的关系、需要报学校的事项按学校规定（另读 `references/_shared/profiles/units/gaoxiao.md`）；述职增加临床教学、研究生培养；“三重一大”须报学校的，写进议题的前置程序 |
| 国有企业举办的医院 | 按所在省规定参加评审 | 是否纳入公立医院绩效监测，以主管部门通知为准 | 重大事项按集团（公司）党委前置研究的规定办理，议题写明需报集团决策的事项；商业秘密、决策程序另读 `references/_shared/profiles/units/guoqi.md`，集团制度由用户提供的从其规定 |
| 乡镇卫生院、社区卫生服务中心 | 一般不适用医院等级评审（已按二级医院标准建设和管理的，以当地规定为准） | 一般不在二级和三级公立医院绩效监测范围 | 本包的 RCA、院感整改、质量分析、行风材料可以用；评价类材料按当地卫生健康部门的要求，标【待核实：当地评价文件名称】 |
| 卫生健康行政部门（卫健委、卫健局） | 是组织方，不写医院自评 | 是组织方 | 写通知、通报、汇总报告的，交 gongwen-draft、gongwen-report，本包只提供术语和口径 |

## 五、院内角色与常写文书

| 角色 | 常写的本包文书 | 默认模式 | 本包的提醒 |
|---|---|---|---|
| 院办秘书、党办干事 | 议题、行风情况报告 | 高效模式 | 议题按前置程序逐项核对；党委会议题叠加严谨模式 |
| 质控科（医疗质量管理办公室）干事 | 质量分析、评审自评、绩效分析 | 高效模式；新入职的用教学模式 | 指标名称和口径与手册一致，写明来源系统 |
| 医务部、护理部、院感科 | RCA、PDCA、院感整改 | 转译模式 | 时间线只用记录；当事人用岗位代称 |
| 运营管理部、绩效办 | 绩效分析、DRG 运营分析 | 转译模式 | 卫健口径与医保口径分开 |
| 纪检监察、行风办 | 九项准则自查、行风情况报告、警示教育材料 | 严谨模式 | 案例只用通报原文；涉及人员按通报的公开程度处理 |
| 临床科室主任、护士长 | 科室主任述职、科室质量分析、PDCA | 转译模式 | 本人事例必须来自用户 |
| 分管院长、质控科长（审稿） | 审阅以上各类 | 审稿模式 | 只出问题清单和一页纸摘要 |
