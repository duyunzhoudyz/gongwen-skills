## 一、总览

| 单位类型 | 压缩超限级别 | 调语气最常见的转换 | 转译最常见的来源 | 不能动的 |
|---|---|---|---|---|
| 党政机关 | P1 | 报告改通知、请示改函 | 业务处室的工作记录 | 提法、上级文件原文、文号 |
| 基层 | P1 | 向县里的报告改成发给村（社区）的通知 | 站所、村（社区）报来的材料 | 台账数据 |
| 社区 | P1 | 对街道的汇报改成给居民的告知 | 网格员记录 | 居民信息（一律脱敏） |
| 公立医院 | P2 | 科室签报改成医院对外请示或函 | 科室主任、护士长的口头总结 | 指标名称和口径、患者信息 |
| 高校 | P2 | 学院请示改校内签报；校级通知改学院通知 | 系主任、辅导员的工作记录 | 学术用语、学生信息 |
| 中小学 | P2 | 学校通知改致家长的一封信 | 教研组、班主任的记录 | 学生信息 |
| 国有企业 | P2 | 部门签报改公司请示；总经理办公会要求改部门通知 | 业务部门的经营数据说明 | 经营数据、程序表述、商业秘密 |

压缩超限级别按 `references/_shared/rules/jianfu.md` 第一部分的工具约定：减负规定第1、2条直接约束党政机关；医院、学校、国企的内部发文超限只作提示。

## 二、党政机关

1. 压缩下行文件按减负规定第2条控制：专项不超过4000字，其他不超过5000字；“组织领导”“保障措施”部分优先压缩空表态（JF-03）。
2. 稿中提法密集，改前先把政治性提法、上级文件原文、领导原话圈出来，这些句子只能整句保留或整句删去。
3. 部门面向下级党委、政府的文件调成下行语气时，查 JF-16，不写指令性要求，改商洽口吻或建议由党委、政府办公室行文（`references/tone.md` 第二部分第2条）；面向部门所属单位的照常写要求。
4. 转发、印发类通知压缩时，不复述被转发文件内容，只留本级贯彻要求。

## 三、基层

1. 汇报材料压缩时先保台账数据和问题，删迎检式铺垫；“拍照留痕”“学习笔记”不写成工作成效（减负规定第8条、第14条）。
2. 向下的通知不加码：不添“签订责任状”“制度上墙”（JF-12），不添“每月报送”（减负规定第8条：不得频繁要求基层填表格报材料）。
3. 面向群众的稿子转大白话时，写清时间、地点、要求和咨询电话，原稿和材料没有的标【待补】，不自拟；涉及罚款、强制措施的原句不改，建议再核稿查法律依据。

## 四、社区

1. 对居民的稿子用服务和提醒的口气：“请……”“欢迎……”，不用“必须”“严禁”，有法律依据的安全要求除外。
2. 一句话一件事，写清“谁、什么时间、在哪里、带什么、找谁”，原稿和材料没有的标【待补】，不自拟。
3. 居民姓名、电话、住址、低保和救助情况一律脱敏；使用居民事例前提醒用户确认已获本人同意。

## 五、公立医院

1. 转译科室主任、护士长的口语时，指标名称照用原稿，不改成通俗说法，也不自行改名；三级公立医院绩效考核的正式指标名以国办发〔2019〕4号附件为准（如“出院患者四级手术比例”），对外报送需与考核口径一致而原稿用了简称的，保留原写法，起草说明请用户核对指标名称和口径。比率变化用百分点。
2. 缩写首次出现写全称；面向全院职工的讲话稿口语化时少用缩写。
3. 患者姓名、病案号、住院号一律脱敏；病例写成“张某，男，65岁”的形式，原稿就有的才写年龄性别。
4. 科室签报改成医院对外请示时，自称由“本科室”改为“我院”，主送改上级卫生健康行政部门，提醒按院内程序上会。

## 六、高校

1. 校级文件和学院文件语气不同：学院对学校用请示、签报（上行），对系、教研室用通知（下行）；两级发文的代字以学校规定为准。
2. 学术材料保留学术用语，不改成公文套语；数据与学校自评报告口径一致，不一致的在起草说明请用户核实。
3. 开学、毕业讲话口语化时面向学生，少套话；学生姓名、学号脱敏。

## 七、中小学

1. 致家长的稿子通俗、具体，写清时间、事项和需要家长配合的内容，原稿和材料没有的标【待补】，不自拟；不给家长布置超出范围的任务。
2. 对上材料的数据与教育事业统计口径一致。
3. 学生姓名、学号、家庭情况脱敏；评语类材料不在本 skill 处理范围。

## 八、国有企业

1. 经营数据、财务指标、专业术语（EBITDA、资产负债率）照用，首次出现可加说明。
2. “党委前置研究”“董事会审议”“总经理办公会研究”等程序表述压缩时不删，调语气时不改变决策主体。
3. 商业秘密（未公开的经营数据、客户、价格）提醒用户脱敏后再发。
4. 部门签报改公司请示时，自称由“本部门”改为“公司”，结语按公司公文管理办法。
