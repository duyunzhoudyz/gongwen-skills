# 语气与语体对照

调语气、转译、口语化或书面化共用本文件。只改表达，事实、数字、状态、义务强度不变。惯用语出自 `references/_shared/rules/doc-types.md` 各文种的“惯用语”栏，以本单位制度为准。

## 一、行文方向措辞对照表

| 位置 | 上行文（报告、请示、签报） | 平行文（函、复函） | 下行文（通知、通报、批复） |
|---|---|---|---|
| 自称 | 我局、我院、本部门 | 我局、我单位 | 本局、我局（落款为准） |
| 称对方 | 写机关全称或规范简称，如“县政府” | 你单位、贵局 | 各乡镇、各有关单位；批复称“你局” |
| 开头语 | 现将……情况报告如下：；现就……请示如下： | 现就……函商如下：；你单位《关于……的函》收悉。现函复如下： | 为……，现将有关事项通知如下：；你局《关于……的请示》收悉。经研究，现批复如下： |
| 请求或要求 | 恳请、拟、建议（上行可用） | 商请、请予支持、请协助 | 要、应当、必须、不得（按 `references/_shared/style/defensive.md` 第六部分分层） |
| 期望语 | 请予批准；请予审批 | 请予支持；请予函复 | 请结合实际认真贯彻执行 |
| 结语 | 报告：特此报告。请示：妥否，请批示。 | 特此函告。特此函复。 | 特此通知。特此通报。此复。 |

## 二、方向互转的做法

| 原→新 | 文种常见变化 | 必改 | 常缺、须标【待补】的 |
|---|---|---|---|
| 上行→下行 | 报告→通知 | 谁来做、向上请求的事项按 SKILL 正文调语气第 4、5 条；结语改“特此通知”；受文对象是下级党委、政府的，按本节第2条 | 完成时限、联系方式（原稿有报送安排的才写报送方式）；责任单位按受文对象写“各××” |
| 下行→上行 | 通知→报告 | “各单位要”改为“我局已部署”；结语改“特此报告” | 落实进展（不能把部署写成完成） |
| 上行→平行 | 请示→函（对方是不相隶属的审批部门） | “恳请县政府批准”改为“商请贵局”；结语改“请予函复” | 联系人 |
| 平行→上行 | 函→请示 | 原稿有的请示事项、倾向性意见写入；结语改“妥否，请批示” | 倾向性意见及理由（原稿没有的标【待补】，不代拟） |
| 下行→平行 | 通知→函（对方不相隶属） | 不得部署，改为告知或商洽；“要”改为“请” | 无 |
| 内部签报↔对外请示 | 签报主送一位分管领导；请示以单位名义报上级机关 | 自称由“本部门”改“我院”，主送改上级机关 | 单位意见 |

请示与函：请示适用于向上级机关请求指示、批准；函适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项（《党政机关公文处理工作条例》第八条第（十一）项、第（十四）项）。向不相隶属的审批部门请求批准用函。改不改文种由用户或领导定；要本 skill 判断该用什么文种的，转 gongwen-draft。

三条要守住的：
1. 状态不变。部署不是完成，要求不是结果。
   误：通知原文“各乡镇要于10月31日前完成排查”，改报告写成“各乡镇已于10月31日前完成排查”。
   正：“我局已部署各乡镇于10月31日前完成排查，完成情况【待补：截至报告日的排查进度】。”
2. 部门以自己名义面向下级党委、政府的，按 SKILL 正文调语气第 6 条处理（JF-16）；受文对象是部门所属单位（如县卫生健康局发各乡镇卫生院）的，照常写要求。
3. 改下行文不顺手加码：不添原稿没有的任务和“报送贯彻落实情况”“纳入年度考核”“签订责任状”（JF-05、JF-07、JF-12）；原稿有的照留，在说明中提示。

## 三、业务语言改公文语言

| 业务原话 | 公文表述 | 说明 |
|---|---|---|
| 搞了；弄好了 | 开展、实施；完成 | 原话说“基本弄好”的写“基本完成” |
| 还没弄完、卡住了 | 尚未完成、进度滞后 | 写明卡在哪个环节 |
| 抓紧弄 | 加快推进；于……前完成 | 有时限写时限 |
| 上面要求、领导说了 | 按照××要求 | 写明哪一级、哪个文件；不清楚的写“按照有关要求”，起草说明请用户核实出处 |
| 老百姓 | 群众、居民、患者、家长 | 按单位类型选 |
| 人手不够 | 人员力量不足 | 有缺口数的写数 |
| 钱不够 | 经费缺口……万元 | 没有金额的标【待补】 |
| 一大堆、不少 | 较多 | 有数写数，不改成“大量” |
| 挺好、还行 | 照实写做了什么、结果如何 | 不拔高成“成效显著” |
| 回头、过阵子 | 下一步；于……前 | 没有时间的不编时间 |

术语和数据：
1. 业务术语、指标名称照用原稿，不换近义词，不自行改名（“四级手术占比”照写；考核正式指标名为“出院患者四级手术比例”，对外报送需与考核口径一致的，保留原写法，起草说明“待核实”一行请用户核对指标名称和口径）。
2. 缩写首次出现写全称，如“疾病诊断相关分组（DRG）”；全称拿不准的保留缩写，起草说明请用户核实全称。
3. “涨了3个点”这类说法，分清百分点和百分比：两个百分数相减，差用“个百分点”（`references/_shared/rules/data-expression.md` 第三部分）。分不清的照写原数，起草说明请用户核实是百分点还是百分比。
   误：占比由24%提高到27%，增长3%。
   正：占比由24%提高到27%，提高3个百分点。

## 四、口语化和书面化

讲话稿口语化（拿来讲的稿）：

| 书面写法 | 讲的写法 |
|---|---|
| 名词前十五字以上的长定语 | 拆成两句，先说是什么，再说怎么样 |
| 上述、该、其 | 刚才说的、这项工作、他们 |
| 括注“（以下简称……）” | 删去，第二次直接用简称 |
| 截至2026年9月底 | 到2026年9月底（年份保留） |
| 顿号连列五项以上 | 先说“有五件事”，再分句说 |
| 段与段直接衔接 | 加过渡：下面，我讲第二个问题 |

开头加称谓（“同志们”“各位老师、同学们”），结尾与开头呼应。精确数据保留，概数可以用“近”“超过”（原稿有的才用）。不加原稿没有的金句、典故和引文。难懂的办学、政策提法不改写成大白话，整句删去或整句保留并加过渡。

书面化（讲话录音整理稿、发言改材料）：删口头禅（那么、这个、我跟大家讲）、现场称呼和互动语；重复的意思只留一次；设问、反问改陈述；句子补全主语；按讲话的层次加 一、（一）序号。这是冻结事实的例外：讲话人本人的话可以改表达，观点、表态、要求和数据不变，约数不精确化，拿不准的保留原话，起草说明请用户核实原意。

讲话时长按每分钟约200字核算（画像另有语速的按画像），写进说明。
