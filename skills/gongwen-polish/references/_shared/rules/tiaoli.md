## 一、总则与适用范围

| 条款 | 要点 | 对写作的含义 |
|---|---|---|
| 第二条 | 适用于各级党政机关公文处理工作 | 党政机关、基层直接适用 |
| 第四条 | 公文处理包括拟制、办理、管理 | 本项目只涉及拟制（起草、审核）和格式 |
| 第五条 | 原则：“实事求是、准确规范、精简高效、安全保密” | 对应红线：事实只来自用户、做减法、保密先于生成 |
| 第四十条 | “其他机关和单位的公文处理工作，可以参照本条例执行” | 医院、学校、国企参照执行，以本单位公文处理办法为准 |
| 第三十八条 | 党政机关公文含电子公文 | 电子公文同样适用本条例 |
| 第三十九条 | 法规、规章方面的公文和外事公文，依照有关规定处理 | 起草法规规章、外事文件时提示用户另查专门规定 |

## 二、公文的定义（第三条）

1. 公文是党政机关“实施领导、履行职能、处理公务的具有特定效力和规范体式的文书”。
2. 用途：传达贯彻方针政策，公布法规和规章，指导、布置和商洽工作，请示和答复问题，报告、通报和交流情况。
3. 两个要件：特定效力、规范体式。总结、讲话稿、调研报告等材料不是法定公文，需要以通知印发或作为报告附件报送时，才借助法定文种取得效力（实务）。

## 三、公文种类（第八条）

共 15 种。适用情形均为第八条原文的压缩表述。文种细节见 `references/_shared/rules/doc-types.md`。

| 项 | 文种 | 适用 |
|---|---|---|
| （一） | 决议 | 会议讨论通过的重大决策事项 |
| （二） | 决定 | 对重要事项作出决策和部署；奖惩有关单位和人员；变更或者撤销下级机关不适当的决定事项 |
| （三） | 命令（令） | 公布行政法规和规章；宣布施行重大强制性措施；批准授予和晋升衔级；嘉奖有关单位和人员 |
| （四） | 公报 | 公布重要决定或者重大事项 |
| （五） | 公告 | 向国内外宣布重要事项或者法定事项 |
| （六） | 通告 | 在一定范围内公布应当遵守或者周知的事项 |
| （七） | 意见 | 对重要问题提出见解和处理办法 |
| （八） | 通知 | 发布、传达要求下级机关执行和有关单位周知或者执行的事项；批转、转发公文 |
| （九） | 通报 | 表彰先进、批评错误、传达重要精神和告知重要情况 |
| （十） | 报告 | 向上级机关汇报工作、反映情况，回复上级机关的询问 |
| （十一） | 请示 | 向上级机关请求指示、批准 |
| （十二） | 批复 | 答复下级机关请示事项 |
| （十三） | 议案 | 各级人民政府按照法律程序向同级人大或者人大常委会提请审议事项 |
| （十四） | 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项 |
| （十五） | 纪要 | 记载会议主要情况和议定事项 |

签报不在第八条之列，属于部分机关、高校、企业内部规定的文种，见 `references/_shared/rules/doc-types.md` 第三部分。

## 四、格式要素（第九条至第十二条）

第九条列出 18 个要素。版式细节见 `references/_shared/rules/gbt9704.md`（右列为对应条款）。

| 项 | 要素 | 条例要点 | GB/T 9704 |
|---|---|---|---|
| （一） | 份号 | 印制份数的顺序号；涉密公文应当标注 | 7.2.1 |
| （二） | 密级和保密期限 | 涉密公文分别标注“绝密”“机密”“秘密”和保密期限 | 7.2.2 |
| （三） | 紧急程度 | 紧急公文标“特急”“加急”；电报标“特提”“特急”“加急”“平急” | 7.2.3 |
| （四） | 发文机关标志 | 全称或规范化简称加“文件”，也可只用全称或规范化简称；联合行文可并用或只用主办机关名称 | 7.2.4 |
| （五） | 发文字号 | 由机关代字、年份、发文顺序号组成；联合行文用主办机关的发文字号 | 7.2.5 |
| （六） | 签发人 | “上行文应当标注签发人姓名” | 7.2.6 |
| （七） | 标题 | 由发文机关名称、事由和文种组成 | 7.3.1 |
| （八） | 主送机关 | 主要受理机关；用全称、规范化简称或同类型机关统称 | 7.3.2 |
| （九） | 正文 | 公文的主体 | 7.3.3 |
| （十） | 附件说明 | 附件的顺序号和名称 | 7.3.4 |
| （十一） | 发文机关署名 | 署全称或规范化简称 | 7.3.5 |
| （十二） | 成文日期 | 署会议通过或负责人签发的日期；联合行文署最后签发机关负责人签发的日期 | 7.3.5.4 |
| （十三） | 印章 | 有署名的应当加盖印章，并与署名机关相符；有特定发文机关标志的普发性公文和电报可以不盖 | 7.3.5 |
| （十四） | 附注 | 印发传达范围等需要说明的事项 | 7.3.6 |
| （十五） | 附件 | 正文的说明、补充或参考资料 | 7.3.7 |
| （十六） | 抄送机关 | 主送以外需要执行或知晓的机关；称谓规则同主送机关 | 7.4.2 |
| （十七） | 印发机关和印发日期 | 送印机关和送印日期 | 7.4.3 |
| （十八） | 页码 | 公文页数顺序号 | 7.5 |

| 条款 | 要点 |
|---|---|
| 第十条 | 版式按照《党政机关公文格式》国家标准（GB/T 9704）执行 |
| 第十一条 | 汉字、数字、外文字符、计量单位和标点符号按有关国家标准执行（数字见 `references/_shared/rules/gbt15835.md`，标点见 `references/_shared/rules/gbt15834.md`）；民族自治地方可并用少数民族文字 |
| 第十二条 | 用纸采用国际标准 A4 型；特殊形式公文用纸根据实际确定 |

写作提示：
1. 机关名称写全称或规范化简称，不自造简称（第九条第（八）（十一）（十六）项）。
2. 成文日期以签发日期为准，起草时未签发的写 `【待补：成文日期】`。
3. 起草时不确定的发文字号、签发人、份号一律标 `【待补】`，不编造。

## 五、行文规则（第十三条至第十七条）

### 5.1 一般规则

| 编号 | 条款 | 规则 |
|---|---|---|
| X-01 | 第十三条 | 行文应当确有必要，讲求实效，注重针对性和可操作性 |
| X-02 | 第十四条 | 行文关系根据隶属关系和职权范围确定 |
| X-03 | 第十四条 | 一般不得越级行文；特殊情况越级的，应当同时抄送被越过的机关 |

### 5.2 向上级机关行文（第十五条）

| 编号 | 项 | 规则 |
|---|---|---|
| X-04 | （一） | 原则上主送一个上级机关；可抄送相关上级机关和同级机关；不抄送下级机关 |
| X-05 | （二） | 党委、政府的部门向上级主管部门请示、报告重大事项，应当经本级党委、政府同意或者授权；部门职权内的事项直接报上级主管部门 |
| X-06 | （三） | 以本机关名义转报下级的请示，应当提出倾向性意见，不得原文转报 |
| X-07 | （四） | 请示应当一文一事；不得在报告等非请示性公文中夹带请示事项 |
| X-08 | （五） | 除上级机关负责人直接交办事项外，不得以本机关名义向上级机关负责人报送公文，不得以本机关负责人名义向上级机关报送公文 |
| X-09 | （六） | 受双重领导的机关向一个上级机关行文，必要时抄送另一个上级机关 |

### 5.3 向下级机关行文（第十六条）

| 编号 | 项 | 规则 |
|---|---|---|
| X-10 | （一） | 主送受理机关，根据需要抄送相关机关；重要行文应当同时抄送发文机关的直接上级机关 |
| X-11 | （二） | 党委、政府办公厅（室）经授权可以向下级党委、政府行文；其他部门和单位不得向下级党委、政府发布指令性公文或提出指令性要求 |
| X-12 | （二） | 需经政府审批的具体事项，经政府同意后可以由职能部门行文，“文中须注明已经政府同意” |
| X-13 | （三） | 党委、政府的部门在职权范围内可以向下级党委、政府的相关部门行文 |
| X-14 | （四） | 涉及多个部门职权的事务，部门之间未协商一致的，不得向下行文 |
| X-15 | （五） | 向受双重领导的下级机关行文，必要时抄送其另一个上级机关 |

### 5.4 联合行文与内设机构（第十七条）

| 编号 | 款 | 规则 |
|---|---|---|
| X-16 | 第一款 | 同级党政机关、党政机关与其他同级机关必要时可以联合行文；属于党委、政府各自职权范围内的工作，不得联合行文 |
| X-17 | 第二款 | 党委、政府的部门依据职权可以相互行文 |
| X-18 | 第三款 | 部门内设机构除办公厅（室）外不得对外正式行文 |

### 5.5 起草时的检查动作

1. 请示：数一数请示事项，多于一项的建议拆分（X-07）；主送机关多于一个的提示用户（X-04）；抄送栏出现下级机关的提示删除（X-04）。
2. 报告：正文出现“请批准”“请批示”“妥否”等请求性语句的，提示改为请示另行报送（X-07）。
3. 转报下级请示：用户没有给出本机关意见的，标 `【待补：本机关倾向性意见】`（X-06）。
4. 主送或抄送中出现上级领导个人姓名的，提示改为主送机关（X-08）。
5. 内设科室、处室以自身名义对外发文的，提示改由本单位或办公室行文（X-18）；企事业单位以本单位制度为准。

## 六、公文拟制（第十八条至第二十二条）

### 6.1 程序（第十八条）

拟制包括起草、审核、签发三个程序。

### 6.2 起草要求（第十九条）

| 项 | 要求 | 工具做法 |
|---|---|---|
| （一） | 符合党的理论路线方针政策和国家法律法规，完整准确体现发文机关意图，同现行有关公文相衔接 | 政策提法只用用户提供的原文；需要对照的列入起草说明“待核实” |
| （二） | 从实际出发，实事求是，措施切实可行 | 措施落到本单位，缺失的标 `【待补】` |
| （三） | “内容简洁，主题突出，观点鲜明，结构严谨，表述准确，文字精练” | 默认做减法，见 `references/_shared/rules/jianfu.md` |
| （四） | “文种正确，格式规范” | 先做文种决策，见 `references/_shared/rules/doc-types.md` |
| （五） | 深入调查研究，充分论证，广泛听取意见 | 调研报告只基于用户提供的调研记录 |
| （六） | 涉及其他地区或部门职权的，必须征求意见，力求达成一致 | 起草说明中列出需会签的部门 |
| （七） | 机关负责人应当主持、指导重要公文起草 | 不适用于工具 |

### 6.3 审核重点（第二十条）

签发前由办公厅（室）审核。核稿 skill 按以下五项出意见：

| 项 | 审核重点 | 核稿检查项 |
|---|---|---|
| （一） | 行文理由是否充分，行文依据是否准确 | 依据文件名称、文号是否来自用户材料 |
| （二） | 是否符合方针政策和法律法规；是否完整准确体现发文机关意图；是否同现行公文相衔接；措施是否切实可行 | 提法核实、措施可操作性 |
| （三） | 涉及其他地区或部门职权的事项是否经过充分协商并达成一致 | 会签提示 |
| （四） | 文种是否正确，格式是否规范；人名、地名、时间、数字、段落顺序、引文是否准确；文字、数字、计量单位和标点符号用法是否规范 | 机检：`references/_shared/rules/gbt9704.md`、`references/_shared/rules/gbt15834.md`、`references/_shared/rules/gbt15835.md` 的可机检规则 |
| （五） | 其他内容是否符合起草要求 | 对照第十九条 |

需要发文机关审议的重要公文文稿，审议前由办公厅（室）进行初核（第二十条第二款）。

### 6.4 退回与签发（第二十一条、第二十二条）

1. 经审核不宜发文的，退回起草单位并说明理由；需进一步修改的，由起草单位修改后重新报送（第二十一条）。
2. 公文应当经本机关负责人审批签发（第二十二条）。
3. “重要公文和上行文由机关主要负责人签发”（第二十二条）。
4. 签发人应当签署意见、姓名和完整日期；圈阅或签名的，视为同意（第二十二条）。
5. 联合发文由所有联署机关的负责人会签（第二十二条）。

## 七、与写作相关的其他条款

| 条款 | 要点 | 对写作的含义 |
|---|---|---|
| 第二十四条（三） | 收文初审重点：是否应由本机关办理，是否符合行文规则，文种、格式是否符合要求，涉及其他部门的事项是否已协商、会签 | 不合规的来文会被退回，起草时按初审标准自查 |
| 第二十五条（一） | 印发前对审批手续、内容、文种、格式复核；需作实质性修改的，报原签批人复审 | 签批后的修改要提示用户走复审 |
| 第三十条 | 确定密级前按拟定密级先行采取保密措施 | 材料出现密级标识时停止处理（见 `references/_shared/guardrails.md` 第一条） |
| 第三十一条 | 涉密公文公开发布前应当履行解密程序；经批准公开发布的公文与正式印发的公文具有同等效力 | 不协助把涉密内容改写后公开 |
| 第三十三条 | 公文被撤销的，视为自始无效；被废止的，自废止之日起失效 | 引用依据文件时提示用户确认现行有效 |
| 第三十七条 | 新设立的机关应当提出发文立户申请 | 无发文资格的机构不宜以自身名义行文 |

## 八、按条款核查清单

| 检查项 | 依据 |
|---|---|
| 文种属于第八条所列，或属于本单位制度规定的文种 | 第八条、第十九条（四） |
| 标题含发文机关名称、事由、文种（实务中有省略发文机关名称的，按本单位惯例） | 第九条（七） |
| 上行文标注签发人 | 第九条（六） |
| 请示一文一事、主送一个上级机关、不抄送下级 | 第十五条（一）（四） |
| 报告不夹带请示事项 | 第十五条（四） |
| 转报下级请示有本机关倾向性意见 | 第十五条（三） |
| 不向上级领导个人报送 | 第十五条（五） |
| 部门向下级政府行文不含指令性要求；经政府同意的注明“已经政府同意” | 第十六条（二） |
| 内设机构不对外正式行文 | 第十七条第三款 |
| 人名、地名、时间、数字、引文准确 | 第二十条（四） |
| 版式、数字、标点符合国家标准 | 第十条、第十一条 |
