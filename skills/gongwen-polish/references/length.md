# 压缩与扩写

两者共用一条底线：事实只来自原稿和用户材料（`references/_shared/guardrails.md` 第二条、第四条）。

## 目录

一、压缩：定目标
二、压缩：算账和分配
三、压缩：四级删减
四、压缩：句内压缩
五、压缩：必保内容和压不下去时
六、扩写

## 一、压缩：定目标

| 情形 | 目标 | 依据 |
|---|---|---|
| 用户给了字数、页数或时长 | “以内”“不超过”为上限口径，其余为±10%（SKILL 正文压缩第 1 条） | guardrails 第四条第2款 |
| 偏好卡、画像有篇幅偏好 | 按偏好 | 单位画像 |
| 部署专项工作或具体任务的文件 | 一般不超过4000字 | 减负规定第2条 |
| 其他地方和部门文件 | 一般不超过5000字；部署综合性工作的不设上限，仍从严 | 同上 |
| 讲话稿、汇报发言 | 时长×每分钟约200字；主要负责同志讲话不超过1小时 | 减负规定第6条；200字/分钟为工具约定 |
| 总结、汇报材料等没有上限的 | 压到原稿的七成左右 | 工具约定，写进“所作假设” |
| 用户说“按减负规定压”，原稿已在上限以内 | 压到原稿的七成左右 | 同上；目标可在回复末尾确认 |

医院、学校、国企的内部发文不受字数条款直接约束，超限只作提示（`references/_shared/rules/jianfu.md` 第一部分）。要把材料压成政务信息、简报的，文种变了，转 gongwen-brief。

## 二、压缩：算账和分配

1. 删减量＝当前字数－目标字数。
2. 列出各部分字数（脚本 `polish_stat.py count --target` 会按比例给参考值；上限口径加 `--max`）。
3. 分配时不平均砍：铺垫多的部分多删，事实密的部分少删。例：6000字的汇报压到2400字：开头700→120（删形势背景和意义，只留时期和总体情况一两句）；一、主要做法和成效2900→1300（删复述上级文件，每类事例留数据最全的一个）；二、存在问题800→400（删万能句，留具体问题）；三、下一步打算1200→500（删表态，留有责任和时限的措施）；结尾400→80（删口号式总结）。

4. 每删完一级算一次字数，进入目标范围就停，不为凑整再删。

## 三、压缩：四级删减

按顺序删，前一级删完仍超目标才删下一级。

（一）铺垫。形势背景、重要意义、“在……的正确领导下”、“为深入贯彻……精神”的长引子。
例：“当前形势复杂严峻……在县委、县政府的正确领导下，我局高度重视……”删去，只留“今年汛期，我局排查隐患218处，整改210处。”

（二）复述。照抄上级文件原文、重复前文已说的数据、段末小结、首句重复小标题。上级文件只留名称和一句要求。
例：首句重复小标题的“我局强化隐患排查工作，”和段末“综上，……取得明显成效。”删去。

（三）空泛表态。“高度重视”“精心组织”“切实加强”“进一步提高认识”后面没有具体动作的句子整句删；带责任主体、时限的保留。

（四）重复举例。同类事例只留数据最全的一两个，其余写成“A社区等”。原稿没有总数的，不自己数出“共3个社区”，免得新增数字。

## 四、压缩：句内压缩

| 手法 | 误 | 正 |
|---|---|---|
| 合并同类项 | 开展消防检查12次。开展燃气检查8次。 | 开展消防检查12次、燃气检查8次。 |
| 删修饰语 | 积极主动、认真扎实地开展了大量排查工作 | 开展排查 |
| 去冗余结构 | 通过召开会议的方式对任务进行了部署 | 召开会议部署任务 |
| 删重复主语 | 我局……。我局……。 | 保留第一句主语 |
| 长句改短 | 一句话套三个“通过……” | 拆成两三句，每句一件事 |

只改表达。数字、单位、时限、责任主体、义务强度（必须、要、可以）原样保留。第一步第 4 条所列句子不做句内删改。

## 五、压缩：必保内容和压不下去时

必保内容见 SKILL 正文压缩第 5 条，另加政治性提法原句。删到只剩必保内容仍超目标的，照常交付这一稿，回复第一段按此说明：
“四级删减和句内压缩做完后正文约2800字，比目标多约400字，剩下的都是数据和措施。可选：放宽目标；指定可删的部分；把数据表转为附件。”

## 六、扩写

事实来源和不得加的内容见 SKILL 正文扩写第 1、2 条，另外不加群众评价，没有会议记录不写“多次召开专题会研究”。展开手法：
1. 做法展开成步骤：谁做的、做了什么、怎么做、结果如何，每一项都要在材料里找得到。
2. 补齐要素：时间、范围、对象、数量，材料里有就补。
3. 补漏项：材料中有、原稿漏写的工作，按原稿结构放进对应部分。
4. 过渡句一处不超过一句，不写成段的承上启下。

素材不够时按 SKILL 正文扩写第 3 条：改前估算素材可支撑的字数，写进“所作假设”，如“目标1800字，现有素材支撑约1000字”。补料清单可写成启发问题，如“这项工作有没有统计数据”“有没有一个具体的案例”“上级检查或考核有没有评价”。
