## 一、政治关

做法和标记写法见 `references/tifa-risk.md`，只标记，不替换。

| 必查项 | 怎么查 | 默认级别 | 依据 |
|---|---|---|---|
| 提法与用户提供的原文一致 | 引用的会议精神、讲话、上级文件表述，与用户给的原文逐字比对 | 不一致 P1 | guardrails 第二条第 4 款 |
| 疑似过时、停用或误写的提法 | 对照 tifa-risk.md 第三部分；机构名称看是否为改革前旧称 | P1 | tifa-risk.md 第三部分，写明该条来源和日期 |
| 数字概括类提法 | “两个……”“四个……”核对数字和每一项的字面；没有原文的不凭记忆判断 | P1；无原文时 P2 | tifa-risk.md 第二部分 |
| 引语和“金句” | 引号内的讲话、名言有无出处，出处是否来自用户材料 | 无出处 P1 | guardrails 第二条第 5 款 |

## 二、政策关

| 必查项 | 怎么查 | 默认级别 | 依据 |
|---|---|---|---|
| 目标、指标、时限与上级文件一致 | 逐项对照目标值、时限、责任主体 | 低于上级要求或晚于上级时限 P0；表述不一致 P1 | 条例第十九条（一）、第二十条（二） |
| 不照搬照抄上位文件 | 连续多句与上级文件相同、没有本单位措施 | P1 | 减负规定第2条（jianfu.md JF-04） |
| 引用文件 | 名称、文号是否来自用户材料；是否引用已废止文件 | 无法核对的 P2“待确认” | 条例第十九条（一）、第三十三条 |
| 政策依据 | “根据……规定”后的文件全称加书名号、与用户材料一致 | 不一致 P1 | 条例第二十条（一） |

## 四、法规关

面向群众的通知、通告、公示、告知书逐句查；函、报告、总结不查。机检 legal 类命中先给 P1，核实确无依据或无权限的升为 P0。不能运行脚本时，先搜下列词：

罚款、拘留、断水、断电、停水、取消低保、取消待遇、取消资格、扣发、不予办理、曝光、黑名单、追究法律责任、强制、一律、不配合将、后果自负。

| 必查项 | 怎么查 | 默认级别 | 依据 |
|---|---|---|---|
| 没有法律依据的强制措施 | 罚款、拘留、断水断电、取消低保、黑名单、曝光出现在社区、村、学校、科室名义的文书中 | 机检 P1，核实无依据或无权限的 P0 | jiceng.md、shequ.md 第六部分 |
| 收费事项 | 是否写明依据，依据是否由用户提供 | 无依据 P0 | zhongxiaoxue.md 第六部分第 5 条 |
| 个人信息公开范围 | 公示、名单超范围公开身份证号、手机号、住址、病情、家庭困难情况 | P0 | guardrails 第一条第 3 款 |
| 密级标识、内部资料 | 稿件带密级或“内部资料”等标识 | P0，按 SKILL.md 第二步暂停 | guardrails 第一条第 2 款 |
| 对外宣传的绝对化、保证性表述 | “治愈率100%”“根治”“国内领先”“行业第一”无依据 | P1 | yiyuan.md、guoqi.md 第六部分 |
| 双减和考试管理 | 给家长布置作业、要求家长批改作业、公布成绩排名 | P0 | zhongxiaoxue.md 第六部分第 2、3 条 |

误：对未按时缴纳校服费的学生，暂停其参加期末考试。
处理：P0，问题栏写“以停考催缴费用没有法律依据，收费本身也须写明依据”，建议栏写“删去停考表述；收费依据由用户提供”。

## 六、文字关

| 必查项 | 怎么查 | 默认级别 | 依据 |
|---|---|---|---|
| 错别字、漏字、多字 | 重点看人名、地名、机构名、专业术语 | P1；改变意思的 P0 | 条例第二十条（四） |
| 前后数字一致 | 同一指标各处数值一致；分项之和等于合计；百分比能由原始数推出 | 矛盾 P0 | 条例第二十条（四） |
| 百分比与百分点 | 比率的变化写成“提高5%” | P2 | 统计用语规范 |
| 数字写法 | 年份简写、范围写法、混写、全角数字 | P1 | GB/T 15835-2011 |
| 标点 | 序数后标点、并列书名号间顿号、省略号与“等”、半角标点、引号嵌套 | P1 | GB/T 15834-2011 |
| 数字概括与条数 | “三个方面”后面是否正好三条 | P2 | 条例第二十条（四） |
| 标记 | 【待补】【待核实】未补齐 P2，单独计数；写法不是【待补：说明】【待核实：说明】的 P1 | 见左 | guardrails 第二条；output-format.md 第一部分第 8 条 |
| 时间、日期 | 星期与日期是否对应；时间段首尾是否倒置；只写星期几的不替用户推算日期 | P1 | 条例第二十条（四） |

误：线上办件率达到76%，较上年提高了9%。
处理：P2，问题栏写“比率变化疑似应为百分点”，建议栏写“请核对口径，两个比率之差写作‘提高9个百分点’”。

## 七、格式关

按 GB/T 9704-2012 查文字层面的格式要素（下表条款号均指该标准）。字体、字号、页边距、行距、页码交 gongwen-format 诊断。

| 必查项 | 怎么查 | 默认级别 | 依据 |
|---|---|---|---|
| 发文字号 | 六角括号〔〕、年份四位、不加“第”、不编虚位 | P0 | 7.2.5 |
| 标题 | 发文机关、事由、文种齐全；末尾不加标点；不写“请示报告”；不重复“关于”“的通知” | P1 | 条例第九条（七）；GB/T 15834 B.4 |
| 主送机关 | 全称或规范化简称；末尾全角冒号 | P1 | 7.3.2 |
| 层次序数 | 一、→（一）→ 1. →（1），不跳号、不越级；序数后标点 | P1；越级 P2 | 7.3.3；GB/T 15834 B.3 |
| 附件说明 | “附件：1. 名称”，名称后不加标点，与附件标题一致 | P1 | 7.3.4 |
| 署名和成文日期 | 署名与发文机关一致；日期用阿拉伯数字、年份写全、月日不编虚位 | 虚位、汉字日期 P1，落款虚位 P0 | 7.3.5 |
| 附注 | 加圆括号 | P2 | 7.3.6 |
| 版记 | “抄送：”全角冒号，末尾句号；不用“抄报”；印发日期写法 | P1 | 7.4.2、7.4.3 |
| 上行文签发人 | 请示、报告有发文字号的，是否标注签发人 | P2 | 7.2.6 |
| 残留 | Markdown 符号、emoji、AI 自述、对话引导语 | Markdown P1，AI 自述 P0 | guardrails 第三条 |

企业、高校、医院按本单位公文处理办法；与国标不同的写法以单位画像为准，注明“按本单位规定”。

## 九、无脚本时的人工机检清单

实际不能运行脚本时（无 Python、脚本报错；不凭“网页版”字样推断，环境里能运行的就运行），按下列顺序查，在核稿意见中写“未运行机检，已按人工清单检查”；运行了的写“已运行机检”。

1. 残留：`#`、`**`、`- `、`>`、表情符号、“作为AI”“以下是为您”“仅供参考”“请根据实际情况调整”。
2. 版头和落款：发文字号的〔〕、四位年份、“第”和虚位；标题末尾标点；主送末尾全角冒号；落款日期的写法。
3. 序数：列出所有行首序数，查写法和连续性；“1、”“（一）、”“一，”都是错的。
4. 标点数字：“》、《”“、等”“……等”“...”，中文之间的半角标点、直引号；两位数年份、范围写法、“4千”混写、全角数字。
5. 附件说明和版记：冒号、序号、末尾标点。
6. 隐私和保密：18 位数字、以 1 开头的 11 位数字、“身份证”“病案号”“住院号”“学号”“住址”“床”；“秘密”“★”“内部资料”“工作秘密”。
7. 标记：统计【待补】【待核实】，按 P2 列出并单独计数。
8. 文风、文种和法规：第四、五、八部分各项的用词；有禁用词表的按表逐条搜索。
