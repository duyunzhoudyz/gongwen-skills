# 单位类型画像：党政机关

适用于省、市两级党委、人大、政府、政协机关及其工作部门。县乡两级见 `jiceng.md`。

## 一、规则基线与参照依据

| 依据 | 适用方式 | 要点 |
|---|---|---|
| 《党政机关公文处理工作条例》（中办发〔2012〕14号） | 直接适用 | 15 个文种、行文规则、拟制程序；详见 `references/_shared/rules/tiaoli.md` |
| GB/T 9704-2012《党政机关公文格式》 | 直接适用 | 版式要素、特定格式；详见 `references/_shared/rules/gbt9704.md` |
| GB/T 15834-2011、GB/T 15835-2011 | 直接适用 | 标点、数字用法 |
| 《整治形式主义为基层减负若干规定》（2024 年 8 月） | 直接适用 | 发文计划管理、篇幅上限、开门见山、不照搬上位文件 |
| 本机关公文处理实施细则、发文管理规定 | 用户提供时优先 | 代字、签发权限、会签范围 |

## 二、发文体系

| 发文主体 | 发文机关标志示例 | 发文字号示例 |
|---|---|---|
| 党委 | 中共某市委员会文件 | X委发〔2026〕N号 |
| 党委办公厅（室） | 中共某市委办公室文件 | X委办发〔2026〕N号 |
| 政府 | 某市人民政府文件 | X政发〔2026〕N号 |
| 政府办公厅（室） | 某市人民政府办公室文件 | X政办发〔2026〕N号 |
| 工作部门 | 某市某局文件 | X某发〔2026〕N号 |
| 函件 | 信函格式，版头为机关全称 | X政函〔2026〕N号、X某函〔2026〕N号 |

代字以本机关规定为准，上表只示意结构。

1. **两套体系**：党委、政府各成体系。属于党委、政府各自职权范围内的工作，不得联合行文（《条例》第十七条）。
2. **部门行文**：党委、政府的部门依据职权可以相互行文；部门内设机构除办公厅（室）外不得对外正式行文（第十七条）。部门不得向下级党委、政府发布指令性公文；部门之间未协商一致的，不得向下行文（第十六条）。
3. **内部文种**：处室向本机关领导请示、报告用签报或呈批件（各机关名称不一），只在机关内部运转，不编正式发文字号。
4. **签发**：重要公文和上行文由机关主要负责人签发（第二十二条）；上行文标注签发人（第九条）。

## 三、常用文种与典型材料清单

| 频次 | 法定文种 | 常用材料 |
|---|---|---|
| 几乎每周 | 通知、函、纪要 | 信息专报、汇报材料、领导讲话 |
| 每月或每季 | 请示、报告、通报、意见、批复 | 实施方案、调研报告、督查通报、季度工作分析 |
| 每年 | 报告（年度工作） | 工作要点、年度总结与计划、述职述责述廉、民主生活会对照检查材料、党建工作报告 |
| 事件触发 | 通报、通告、决定 | 巡视巡察、审计、督查整改方案和整改报告；迎检汇报；突发事件信息 |
| 少用 | 决议、命令（令）、公报、公告、议案 | 按机关职权使用，如政府向同级人大提出议案 |

## 四、决策程序与行文特点

1. **拟制流程**：起草，征求意见或会签，办公厅（室）审核，负责人签发。审核重点见《条例》第二十条：行文理由和依据；是否符合方针政策和法律法规；与现行公文是否衔接；涉及其他部门职权的是否协商一致；文种、格式和人名、地名、时间、数字是否准确。
2. **集体决策**：重大事项经党委（党组）会议、政府常务会议等集体讨论决定。议题材料写明依据、方案、征求意见情况和需决定事项。
3. **行文规则**：一般不越级；请示一文一事、原则上主送一个上级机关；报告不夹带请示；除上级负责人直接交办外，不以本机关名义向上级负责人个人报送公文（第十四条、第十五条）。
4. **特点**：口径要与上级文件一致；征求意见轮次多；讲话稿要体现讲话人身份和本地特点。

## 五、术语表

| 术语 | 解释 |
|---|---|
| 会签 | 文稿涉及其他部门职权时，由相关部门负责人签署意见 |
| 征求意见 | 发文前听取相关部门、下级单位意见，采纳情况一般要作说明 |
| 发文计划管理 | 发文实行计划管理、总量管控和立项制度，年度发文一般只减不增（减负规定） |
| 一致性评估 | 制发文件前评估是否与为基层减负要求一致（减负规定） |
| 签发人 | 上行文须标注，一般为机关主要负责人 |
| 签报、呈批件 | 机关内部向领导请示、报告的文书，不对外 |
| 归口管理 | 某类事项由指定部门统一负责，行文前先确认归口部门 |
| 双重领导 | 受双重领导的机关向一个上级机关行文，必要时抄送另一个上级机关 |
| 信息专报 | 向上级报送的政务信息，按采用情况计分 |
| 巡视巡察 | 党内监督方式，反馈问题后须报整改方案和整改情况报告 |
| 对标对表 | 对照上级部署逐条落实、不漏项 |

## 六、红线与禁忌

1. 政治性提法与党章、中央文件原文不一致，或自行“更新”提法。
2. 越级行文、多头主送、报告夹带请示、未协商一致向下行文。
3. 照搬照抄上位文件，配套文件不提具体落实措施（减负规定第 2 条）。
4. 以“红头”变“白头”、正式改便笺、多文合一等方式规避发文数量管理（减负规定第 1 条）。
5. 工作秘密、未公开文件内容输入联网 AI 工具，或写入公开稿件。
6. 数据口径与统计部门、上级通报不一致。

## 七、年度写作节点

| 时间 | 节点与材料 |
|---|---|
| 1–2 月 | 地方两会（政府工作报告相关材料）；年度工作会议讲话；工作要点 |
| 3 月 | 全国两会后的学习贯彻材料 |
| 4 月、10 月 | 一季度、前三季度工作分析 |
| 6–7 月 | 上半年总结；“七一”党建材料 |
| 11–12 月 | 年终总结、次年计划、述职述责述廉 |
| 年底至次年年初 | 民主生活会对照检查材料（以组织部门当年通知为准） |

## 八、版式差异

1. 严格执行 GB/T 9704-2012，是其他单位类型的参照基准。
2. 函用信函格式，纪要用纪要格式，命令用命令格式（GB/T 9704-2012 第 10 章）。
3. 上行文在版头标注签发人；平行文、下行文不标。
4. 联合行文时发文机关标志可并用联合发文机关名称，也可只用主办机关名称（GB/T 9704-2012 7.2.3）。

## 九、文风特点

1. 通知、请示、函、批复、通报等开门见山，一般不写形势背景、重要意义；讲话稿、工作方案、总结、调研报告可按文种惯例写简短背景（不超过一段）；除部署综合性工作外，文件一般不超过 5000 字，部署专项工作或者具体任务的文件一般不超过 4000 字。
2. 措施写到“谁来做、做什么、何时完成”，不停留在原则表述。
3. 会议主报告或主要负责同志讲话不超过 1 小时（减负规定），按每分钟约 200 字估算篇幅。
4. 层次清楚，常用“一是……二是……”；小标题可用对仗，但须与正文内容对应。

## 十、对各 skill 的提示

| skill | 提示 |
|---|---|
| gongwen-draft | 先判文种和行文方向；向不相隶属机关请求批准用函；部门不得向下级政府发指令性公文 |
| gongwen-report | 总结按“主要工作和成效、存在问题、下一步打算”组织；问题部分写真问题，不写成变相表扬 |
| gongwen-speech | 区分会议类型（部署、推进、总结）；领导人讲话和上级精神只用用户提供的原文 |
| gongwen-implement | 任务表与上级文件逐条对应；本地措施缺失时按上级要求和文种常规写出可执行措施，不照抄上级原文 |
| gongwen-review | 重点过政治关、政策关、权限关、程序关；核对会签和征求意见是否完成 |
| gongwen-format | 区分文件格式、信函格式、纪要格式；上行文核对签发人 |
