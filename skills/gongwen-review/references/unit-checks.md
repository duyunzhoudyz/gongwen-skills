# 不同单位类型的核稿重点

> 来源：`references/_shared/profiles/units/` 下 7 个画像中与核稿有关的内容。用法：第四步八关审读时，加上本单位类型的检查项；单位画像另有规定的，以画像为准。

## 目录

一、党政机关
二、基层（县乡政府及部门、乡镇、街道）
三、社区（居委会、村委会）
四、公立医院
五、高校
六、中小学
七、国有企业
八、单位类型判断不了时

## 一、党政机关

| 关口 | 检查项 | 默认级别 |
|---|---|---|
| 政治关 | 提法与党章、中央文件原文一致，不自行“更新” | P1 |
| 政策关 | 配套文件提出了具体落实措施，没有照搬照抄上位文件 | P1 |
| 权限关 | 部门没有向下级政府发指令性公文 | P1 |
| 程序关 | 不越级、不多头主送、报告不夹带请示；涉及其他部门职权的已会签或征求意见 | 夹带请示 P0，其余 P1 |
| 法规关 | 没有以“白头”、便笺、多文合一规避发文管理 | P1，并按 guardrails 第六条说明 |
| 文字关 | 数据口径与统计部门、上级通报一致 | 不一致 P1 |

## 二、基层（县乡政府及部门、乡镇、街道）

| 关口 | 检查项 | 默认级别 |
|---|---|---|
| 法规关 | 面向群众的通知逐句查强制措施：罚款、拘留、断水断电、取消待遇 | P0 |
| 法规关 | 公示名单不超范围公开身份证号、手机号、家庭住址 | P0 |
| 权限关 | 没有把行政执法、招商引资等责任压给村（社区） | P1 |
| 政策关 | 没有照搬上级方案；本地措施缺失时没有编造“特色做法” | P1 |
| 文风关 | 没有把拍照留痕、学习笔记、点赞转发量写成工作成效 | P2 |
| 文字关 | 汇报材料与台账数据一致；整改未完成的不写“已完成” | 不一致 P0 |

## 三、社区（居委会、村委会）

| 关口 | 检查项 | 默认级别 |
|---|---|---|
| 法规关 | 面向居民的文书没有“罚款”“拘留”“断水断电”“取消低保”“不配合将追责”。社区没有行政执法权 | P0 |
| 法规关 | 公示、通知、群消息不公开身份证号、手机号、家庭住址、病情、低保和救助对象详细情况 | P0 |
| 权限关 | 没有出具证明事项清单外的证明；没有以社区名义承诺超出职权的事项 | P1 |
| 程序关 | 涉及居民利益的重要事项，写明经居民会议或居民代表会议讨论；村级重大事项写明“四议两公开”程序 | 缺失 P1 |
| 文种 | 没有用“通告”名义发布带强制性的规定 | P1 |
| 文字关 | 时间、地点、联系人、电话在全文各处一致 | 不一致 P1 |

## 四、公立医院

| 关口 | 检查项 | 默认级别 |
|---|---|---|
| 法规关 | 患者姓名、病案号、住院号、身份证号、床号与姓名组合、可识别影像一律脱敏，写作“患者张某，男，56岁” | P0 |
| 文字关 | 指标名称用所依据考核体系的正式名称（绩效考核“出院患者四级手术比例”，评审标准“出院患者四级手术占比”），不写“大手术比例” | P1 |
| 文字关 | 比率变化用“百分点”；同比、环比写明基期 | P2 |
| 法规关 | 新闻稿、公众号中没有保证疗效、“治愈率100%”“根治”“最先进” | P1 |
| 程序关 | “三重一大”事项经党委会议研究决定；没有以党政联席会议代替党委会议；相关议题有专业委员会论证意见 | 缺失 P1，程序倒置 P0 |
| 程序关 | 医疗纠纷、不良事件、院感数据对外前经职能部门和院办审核 | P1 |

## 五、高校

| 关口 | 检查项 | 默认级别 |
|---|---|---|
| 政治关 | 涉及政治、民族、宗教、港澳台、历史问题的表述以权威原文为准 | P1 |
| 法规关 | 学号、身份证号、成绩、心理健康、家庭经济困难认定、违纪处分不超范围公开；资助公示只公开规定事项 | P0 |
| 文字关 | 评估自评报告、质量报告、就业报告的数据与状态数据库、高基报表一致 | 不一致 P1 |
| 程序关 | 学术类议题先经学术委员会审议；涉及教职工切身利益的经教代会审议 | 缺失 P1 |
| 辅助不代笔 | 辅导员谈心谈话记录、听课记录、思想汇报属本人亲历材料，核稿只看格式和表述，不代补内容 | 发现编造痕迹 P1 |
| 文种 | 学院向学校用校内请示或签报；学校与地方政府用函 | P1 |

## 六、中小学

| 关口 | 检查项 | 默认级别 |
|---|---|---|
| 法规关 | 学生姓名与成绩、家庭经济困难、心理健康、特殊教育需求、违纪处分不超范围公开 | P0 |
| 法规关 | 义务教育学校不公布考试成绩和排名，不在家长群传播 | P0 |
| 法规关 | 面向家长的通知不布置或变相布置家庭作业，不要求家长检查、批改作业 | P0 |
| 法规关 | 涉及收费的通知写明依据，依据由用户提供 | 无依据 P0 |
| 法规关 | 宣传稿使用学生姓名、照片的，已确认取得监护人同意 | 待确认 P2 |
| 文风关 | 评语贬损用语（“笨”“没出息”等，有损未成年人人格尊严） | P0 |
| 文风关 | 评语标签化用语 | P1 |

高中、中职材料的考试排名、家长作业项，按本省规定可降一级。

## 七、国有企业

| 关口 | 检查项 | 默认级别 |
|---|---|---|
| 程序关 | 应前置研究的事项已经党委（党组）研究讨论，再提交董事会或经理层；没有先执行后补程序 | 缺失 P1，倒置 P0 |
| 程序关 | 涉及职工切身利益的事项已经职代会审议，没有“投产后再审议” | P0 |
| 法规关 | 未公开的财务数据、投标报价、客户信息、技术参数没有进入对外材料 | P0 |
| 法规关 | 上市公司未公开的重大信息没有先出现在新闻稿、公众号、讲话稿中 | P0 |
| 文字关 | 经营数据与财务快报、年报一致；同比、环比写明基期；金额单位全文统一 | 不一致 P1 |
| 法规关 | 没有无依据的“行业第一”“国内领先” | P1 |
| 文种 | 本部部门向公司领导用签报；公司向国资监管机构用请示或报告，与政府部门用函 | P1 |

## 八、单位类型判断不了时

从发文机关、主送机关、术语判断（如“院长办公会”是医院，“董事会”是国企）；仍判断不了的按党政机关检查，在“待确认事项”中写明，不为此提问。
