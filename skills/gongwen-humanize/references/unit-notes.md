# 按单位类型调整

单位类型以单位画像为准；没有画像时从发文机关、落款、称谓判断，判断不出按党政机关处理并写进所作假设。本文件只列去 AI 味时需调整的地方。

| 单位类型 | 去 AI 味时要注意 |
|---|---|
| 党政机关 | 政治性提法、上级文件表述最密集，改稿前先圈出提法和引语，一律不动。机关常用语单独出现不改，一段密集堆叠时压缩。写到“谁来做、做什么、何时完成”的措施原句不要改虚。 |
| 基层（县乡、街道） | 稿件要“短、实、准”。“打通最后一公里”“全方位多层次”一类堆砌压缩为原稿中的具体做法。面向群众的通知用大白话，不改成机关腔。 |
| 社区 | 对居民的告知书、倡议书用服务和提醒语气，“亲爱的居民朋友们”可保留，不改成命令口吻。“赋能社区治理”“打造幸福共同体”一类空话，改为具体服务事项；没有事项的删去，不补编。 |
| 公立医院 | 指标名称和医学术语原样保留（如出院患者四级手术比例、CMI、DRG、平均住院日、抗菌药物使用强度），不换成通俗说法。“闭环管理”（用药闭环、危急值闭环）是医疗质量管理的规范说法，不按新八股词处理。“百分点”与“%”不得互换。患者信息按红线一处理。 |
| 高校 | 学术性材料中的“范式”“迭代”“维度”属于学术用语，可保留；行政文件和讲话稿中的同类词按新八股处理。开学、毕业讲话面向学生，口语和设问保留。学生信息按红线一处理。 |
| 中小学 | 面向家长的通知和一封信要通俗、亲切，“各位家长”“亲爱的家长朋友们”保留；结尾删去鸡汤后，原稿已有的致谢、祝福、请求句保留，没有的不新写（见 rewrite-guide（十一））。“赋能课堂”“全方位育人闭环”改为具体做法。“双减”等政策用语原样保留。学生姓名、成绩排名按红线一处理。 |
| 国有企业 | 经营术语和指标原样保留：一利五率、两金、EBITDA、资产负债率。“提质增效”“数智化”等是上级或集团专项行动正式名称的，按提法保留，不按套话压缩。安全生产中的“隐患排查治理闭环”是规范用语。商业秘密和未披露经营数据按红线一处理。 |

通用做法：

1. 用户提供了本单位范文的，范文惯用词句不当作 AI 腔改掉；范文只影响语气，不能突破“不动事实”的约束。
2. 行业规范术语与新八股词同形时（闭环、链路、矩阵），先判断是否规范说法，拿不准的保留并列入“保留未改”请用户确认。
