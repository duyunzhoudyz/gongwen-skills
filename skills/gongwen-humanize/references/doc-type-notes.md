# 按文书类型调整

本文件补充 `references/_shared/style/ai-tone.md` 第三部分，写明各类文书在去 AI 味时放宽什么、收紧什么、哪些必须原样保留。`--doc-type` 参数使用开发规范统一词表中的名称，下表第一列即参数值。

## 一、速查表

| 文书类型（--doc-type） | 放宽 | 收紧 | 必须原样保留 |
|---|---|---|---|
| 讲话稿、党课讲稿、研讨发言 | 口语、设问、反问、排比、“说到底”、全篇一两处“不是……而是……”、号召式结尾、感叹号 | 网络用语、自媒体称呼（家人们、宝子们）、互联网黑话、拟人化喻体、“值得注意的是”（机检对这三类豁免 AI-042，人工仍要改） | 称呼语“同志们”，过渡语“下面，我讲三点意见”，署名行破折号 |
| 信息、简报、新闻稿、公众号推文 | 事实之后的适度评价（“彰显了……担当”），破折号副标题 | 概括代替数据、鸡汤收尾、“未来可期” | 标题中的数字和亮点表述，导语中的时间、地点、主体 |
| 实施方案、贯彻落实方案、整改方案、工作要点、计划 | 顿号并列、字段冒号、“当……时”触发条件、目标表述“明显提升” | 新八股词（方案里最容易堆“赋能”“闭环”）、套话堆砌 | 任务分工表、责任单位、完成时限、“如下：”引语 |
| 总结、汇报材料、述职报告、经验材料、对照检查材料、心得体会、整改报告、自查报告、自评报告 | “以上汇报，不妥之处，请批评指正”；述职中的第一人称 | 概括代替数据（成效部分最严）、相邻句雷同、段落模板化 | 全部数字、排名、获奖情况、问题查摆中的“不同程度存在” |
| 调研报告 | “综上”；分析段的“关键在于”“这意味着”（后接具体分析） | 宏大开头、元话术（本报告将从……） | 调研时间、样本量、调研对象、引用的访谈原话 |
| 通知、通报、意见、决定、通告、公告 | “现将……通知如下”“特此通知”等惯用语 | 宏大开头、元话术、破折号 | 要求事项、时限、报送方式、联系人和电话 |
| 请示、报告、签报、函、批复、纪要、会议记录、议题材料 | 请示和报告的“综上”，纪要的“会议指出：”“会议要求：” | 段首评论语、翻案句、总结标签 | 请求事项和金额、“妥否，请批示”“特此函告”“此复”，纪要的议定事项和责任单位 |

## 二、各类补充说明

### （一）讲话稿

1. 讲话稿本来就要“像人说话”，AI 稿的问题多在书面腔和网络腔混杂。重点删网络用语和“值得注意的是”，口语化表达不改成书面语。
2. 相邻句排比是讲话稿的修辞手段，AI-044～046、049 对讲话稿不适用；但同一个排比骨架在全篇反复出现三次以上，压缩其中一处。
3. 领导讲话中引用的上级精神、领导人原话，即使带有对举和排比也一律不动。

### （二）信息

1. 信息讲“开头即结论、数据要实”。评价句前面没有数据支撑的，按（七）处理，缺数据标【待补】。
2. 结尾的“下一步，将继续……”属于信息常见收尾，保留一句，删去多余的展望和口号。

### （三）实施方案、贯彻落实方案、整改方案、工作要点、计划

1. 顿号和冒号密度天然偏高（顿号每千字 15～30 个属正常）。机检的顿号密度（AI-051）对这几类都已豁免，冒号密度（AI-013）对计划仍会报出；人工诊断时都不按密度改。
2. 任务表格、分工表中的内容只改明显的新八股词，表格结构和责任单位不动。

### （四）总结、汇报材料、述职报告、经验材料等

1. 成效部分逐句检查“有没有数据或事例”。有数据的把概括压缩；没有的按 rewrite-guide.md（七）加【待补】，并在起草说明列出，请用户补。
2. 述职报告、对照检查材料、心得体会需要本人真实经历（红线六）。AI 稿中没有本人具体事例、只有套话的段落，改写时不补编事例，标【待补：本人具体事例】，并在起草说明中提示由本人补写。
3. 经验材料可以保留适度的提炼性表述（“形成了‘一窗受理、集成服务’的做法”），提炼要有前文做法支撑。

### （五）法定公文

1. 法定公文篇幅短、格式固定，AI 腔多出现在开头（宏大背景）、过渡（“值得注意的是”）和结尾（“让我们共同努力”）。正文主体的要求事项一般不需要改。
2. 请示、批复、通知中态度不明、措辞含糊的问题归 gongwen-direct，本 skill 只处理句式和词汇。

## 三、短稿和机检阈值

1. 500 字以下的短稿，带密度阈值的规则（破折号、冒号、新八股词、机关套话、程度副词、顿号）可能因出现一次就超过阈值。以人工判断为准：一篇短信息里出现一次“助力”，不必改。
2. 机检结果与本文件或白名单冲突时，以本文件和白名单为准，并在修改说明中写明“未采纳的机检提示 N 条及原因”。
3. 单位画像目录下有 `.gongwen/文风参数.md` 的，按其中的阈值和偏好调整；有 `.gongwen/禁用词.md` 的，机检加 `--banned .gongwen/禁用词.md`，“禁用”的词一律替换，“慎用”的按语境判断，计入“新八股词”类。
