# 单位画像模板

本文件给出三份模板，供总入口 gongwen 和 gongwen-profile 为用户建档。

| 模板 | 生成位置 | 是否必需 |
|---|---|---|
| 单位画像 | `.gongwen/单位画像.md`；不存在时查找 `~/.gongwen/单位画像.md` | 建议建立；缺失时按 `references/_shared/profiles/roles.md` 第九节"无画像降级"处理 |
| 领导偏好卡 | `.gongwen/领导偏好卡.md` | 可选 |
| 禁用词 | `.gongwen/禁用词.md` | 可选 |

## 使用规则

1. 画像是纯文本，用户可以直接编辑。提示词版用户把画像内容粘贴在对话开头即可。
2. 建档只问完成任务需要的信息，不索取文件原件、人员名单、业务数据。画像中不写涉密信息和个人敏感信息；领导只写职务即可。
3. 字段缺失时按以下顺序取值，排在前面的优先：
   1. 本单位制度文件（用户提供）；
   2. 单位画像；
   3. 单位类型画像 `references/_shared/profiles/units/<文件名>.md` 中的默认值；
   4. 国家规则基线 `references/_shared/rules/`。
4. 本单位制度与国标不一致时按本单位制度执行，并在起草说明中给一条提示，写明与国标的差异。
5. skill 采用了画像中的设定时，在起草说明"所作假设"中写明，例如"按画像，科室向院领导请示用签报"。
6. skill 需要修改画像、偏好卡、禁用词时，先征得用户同意；只追加或修改相关条目，不整份覆盖。

## 一、单位画像

### （一）最小可用版

只需 3 个字段。总入口 gongwen 首次使用时用 3 个问题生成这一版，其余字段由单位类型画像提供默认值。

```markdown
# 单位画像

- 单位类型：公立医院
- 写作角色和默认模式：院办秘书；高效模式
- 常写文书：院长办公会纪要、季度医疗质量分析、签报
```

### （二）字段说明

| 字段 | 填写说明 | 示例 |
|---|---|---|
| 单位类型 | 7 选 1：党政机关、基层、社区、公立医院、高校、中小学、国有企业。决定读取哪份单位类型画像；可在括号内注明级别或类别 | 公立医院（三级甲等） |
| 单位名称或代号 | 可写名称，也可写代号；在联网工具中使用时建议写代号 | 某市某医院；或代号"A院" |
| 层级与隶属 | 行政级别或单位等级、主管部门；决定上行文主送谁、平行文发给谁 | 市卫生健康委直属 |
| 发文机关标志 | 版头上的发文机关名称；党政分开的分别写 | 党委："中共某医院委员会文件"；行政："某医院文件" |
| 发文字号格式 | 代字、年份、序号的写法，年份用六角括号；没有发文权的写"无" | 党委 X医党发〔2026〕N号；行政 X医发〔2026〕N号 |
| 红头或白头 | 哪些文件用红头，哪些用白头或部门通知 | 院级文件用红头；职能部门院内通知用白头加盖部门章 |
| 印发机关 | 版记中"印发机关"一栏，一般是发文机关的办公厅（室）或文秘部门 | 某医院办公室 |
| 党政两套代字 | 是否有党委、行政两套发文体系，各管哪些事 | 党委管党建、干部、纪检；行政管医疗、运营、后勤 |
| 可用文种 | 本单位实际使用的法定文种 | 通知、请示、报告、函、纪要、通报、批复 |
| 内部文种 | 本单位内部呈批用的文书和名称 | 签报（科室向院领导请示）；呈批单 |
| 常写文书 | 你最常写的 3–5 类材料 | 院长办公会纪要、季度医疗质量分析、科室总结 |
| 决策程序 | 重大事项由哪些会议、按什么顺序决定 | 重要行政、业务事项先经院长办公会讨论，再由党委会研究决定 |
| 写作角色和默认模式 | 岗位，加 5 种模式之一（教学、高效、转译、审稿、严谨） | 院办秘书；高效模式 |
| 篇幅偏好 | 各类材料的常用字数上限；讲话可写语速 | 汇报材料不超过 3000 字；信息不超过 800 字；讲话按每分钟约 200 字 |
| 红线与禁用表述 | 本单位特有的红线；禁用词清单另放禁用词.md | 患者姓名、病案号一律脱敏；不写未经认定的排名 |
| 本单位制度文件 | 公文处理办法、议事规则、签报管理办法等的路径或名称 | ./制度/某医院公文处理办法.pdf |
| 配套文件 | 领导偏好卡、禁用词、文风参数的路径 | .gongwen/领导偏好卡.md |

## 二、领导偏好卡

一位领导一张卡。讲话、汇报类材料起草前读取；gongwen-polish 按领导批注改稿后，向"历次改稿记录"追加一行。同一偏好在改稿记录中出现 2 次及以上，再归纳进上面的偏好条目，避免把一次性意见当成固定习惯。

```markdown
# 领导偏好卡

- 适用对象：（写职务即可，如"院长""分管副局长"）
- 更新日期：

## 讲话风格
- 口语或书面：（如：口语化，多用短句，喜欢设问开头）
- 结构习惯：（如：先讲问题再讲成绩；三段式；小标题用四字对仗）
- 时长与语速：（如：一般 15 分钟，每分钟约 200 字）

## 用词偏好
- 常用：（如："抓落实""见实效"）
- 偏好的替换：（如：用"推动"替代"赋能"）

## 忌用表述
- （如：不用"着力"；不用"高度重视"开头；不用网络流行语）

## 数据呈现偏好
- （如：数据前置，先说结果再说做法；同比用百分比，比率变化用百分点；不超过 3 个数字连用）

## 篇幅偏好
- （如：汇报不超过 2 页；讲话不超过 3000 字）

## 引用习惯
- （如：习惯引用上级会议原话，须注明出处；不引用古诗文。引用内容只能来自用户提供的原文）

## 历次改稿记录

| 日期 | 稿件 | 领导改动 | 归纳的偏好 |
|---|---|---|---|
| 2026-10-12 | 季度工作汇报 | 删去第一部分背景铺垫；把"取得显著成效"改为具体数字 | 开门见山；用数据代替评价 |
```

## 三、禁用词

起草时避开，核稿时逐条比对。"禁用"命中时在核稿意见中定为 P1 及以上；"慎用"命中时提示，由用户决定。

```markdown
# 禁用词

| 词语或表述 | 级别 | 原因 | 替换建议 | 适用范围 |
|---|---|---|---|---|
| 赋能 | 慎用 | 领导多次删改 | 推动、支持、提升 | 全部 |
| 全国领先 | 禁用 | 没有权威认定依据 | 写具体排名并注明来源；没有来源的不写 | 全部 |
| 高度重视 | 慎用 | 段首套话 | 直接写采取的措施 | 讲话、汇报 |
| 患者全名 | 禁用 | 隐私保护 | 张某、李某 | 全部 |
| 治愈率 100% | 禁用 | 不得作疗效保证 | 写具体病例数和随访结果 | 新闻稿、公众号 |
```

填写说明：

1. 级别只用"禁用""慎用"两档。
2. "原因"写清楚来源，如"领导批注""上级通知要求""本单位宣传规定"，便于日后清理过时条目。
3. "适用范围"可写：全部、讲话、汇报、对外发布、面向群众的文书。
4. 政治性提法的停用、更新以用户提供的上级原文为准；skill 不自行增删这类条目。
