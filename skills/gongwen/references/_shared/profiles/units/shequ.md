# 单位类型画像：社区

适用于城市社区居民委员会、村民委员会，以及社区（村）党组织。

## 一、规则基线与参照依据

| 依据 | 适用方式 | 要点 |
|---|---|---|
| 《城市居民委员会组织法》《村民委员会组织法》 | 直接适用 | 居（村）委会是基层群众性自治组织，不是行政机关，没有行政执法权；居民会议、村民会议决定涉及全体居民（村民）利益的重要事项 |
| 《整治形式主义为基层减负若干规定》第 15–17 条 | 直接适用 | 不得把村（社区）作为行政执法、城市管理、招商引资等事务的责任主体；村（社区）挂牌数量、名称、式样由省级统一规定 |
| 社区工作事项准入、村级组织工作事务清单、证明事项清单 | 用户提供时适用 | 清单外事项按程序报批；清单外证明不出具 |
| 《党政机关公文处理工作条例》、GB/T 9704-2012 | 参照 | 对上报送的正式材料参照其格式要素 |
| 街道（乡镇）对社区材料的要求 | 用户提供时优先 | 报送格式、时限、平台 |

## 二、发文体系

1. **一般不使用红头文件**。是否编号、用什么编号，以所在街道（乡镇）规定为准。
2. **对上**：向街道（乡镇）报送情况报告、工作总结、申请（请示性质），加盖公章，必要时经社区（村）党组织书记签字。
3. **对居民（村民）**：通知、告知书、倡议书、公示、温馨提示。带有强制性的规定不由社区发布；转达上级部门的要求时写明发布部门和依据文件。
4. **证明**：按证明事项清单出具，清单外的不出具，引导居民到有权部门办理。
5. **内部**：两委会议记录、居民会议记录、网格工作日志、各类台账。

## 三、常用文种与典型材料清单

| 频次 | 典型材料 |
|---|---|
| 几乎每周 | 居民通知、温馨提示、活动信息稿、台账更新、网格工作日志 |
| 每月或每季 | 各类报表和情况报告、迎检材料、志愿服务活动记录、党组织活动记录 |
| 每年 | 年度工作总结与计划；居（村）委会向居民会议或村民会议的工作报告；居务、村务、财务公开；述职 |
| 事件触发 | 防汛防台、消防、极端天气等安全通知；突发事件情况报告；信访、矛盾纠纷调解记录 |
| 每 5 年 | 换届选举相关公告、选民登记公示、工作报告（居、村委会每届任期 5 年） |

## 四、决策程序与行文特点

1. **党组织领导**：社区（村）党组织领导居（村）委会和各类组织。重要事项先经党组织研究。
2. **城市社区**：涉及全体居民利益的重要问题，由居民会议或居民代表会议讨论决定。
3. **农村**：村级重大事项一般按"四议两公开"：村党组织提议，村"两委"会议商议，党员大会审议，村民会议或村民代表会议决议；决议公开，实施结果公开。
4. **行文特点**：上接街道（乡镇）部署，下面对居民；材料以台账、记录、通知为主，正式公文少。

## 五、术语表

| 术语 | 解释 |
|---|---|
| 两委 | 社区（村）党组织委员会和居（村）民委员会 |
| 居民会议、村民会议 | 居（村）民自治的议事决策形式，可由代表会议行使部分职权 |
| 四议两公开 | 村级重大事项决策程序，见第四节 |
| 居务公开、村务公开 | 按规定公开事务、财务、决策事项，接受居（村）民监督 |
| 网格、网格员 | 社区划分的服务管理单元及其负责人员 |
| 社区工作者 | 在社区专职从事服务管理的人员 |
| 准入清单 | 进入社区的工作事项实行清单管理，清单外事项须按程序审批 |
| 证明事项清单 | 社区（村）可以出具的证明范围，清单外不出具 |
| 一表通 | 部分地区推行的基层报表整合做法，同类数据一次采集、多方共享 |
| 民生实事 | 年初确定、年底报告完成情况的为民办实事项目 |

## 六、红线与禁忌

1. 面向居民的文书出现没有法律依据的强制性表述，如"罚款""拘留""断水断电""取消低保""不配合将追责"。社区没有行政执法权。
2. 公示、通知、群消息超范围公开个人信息，如身份证号、手机号、家庭住址、病情、低保和救助对象的详细情况。
3. 台账数据虚报、补记、倒签日期；替居民代签名、代填意见。
4. 出具证明事项清单外的证明。
5. 用"通告"名义发布带强制性的规定；以社区名义承诺超出职权的事项。

## 七、年度写作节点

| 时间 | 节点与材料 |
|---|---|
| 1–2 月 | 春节走访慰问；节日安全提示；年度民生实事计划 |
| 3 月 | 学雷锋志愿服务活动 |
| 4–5 月 | 春季防火；防灾减灾日（5 月 12 日）宣传和演练 |
| 6–9 月 | 防汛防台；暑期青少年活动和安全提示 |
| 11 月 | 消防宣传（11 月 9 日前后） |
| 12 月 | 年终总结；向居民会议或村民会议报告工作；国家宪法日（12 月 4 日）宣传 |
| 全年 | 迎检材料、台账、各类报表；矛盾纠纷调解记录 |

## 八、版式差异

1. 对上报送的报告参照公文格式：标题、主送、正文、落款、日期、公章。
2. 张贴版通知用大字号、短段落，单独一行写清时间、地点、联系人和电话；公示注明公示期和监督电话。
3. 群消息版本去掉格式要素，保留关键信息，控制在一屏以内。

## 九、文风特点

1. 对居民说大白话，一句话一件事；写清"谁、什么时间、在哪里、带什么、找谁"。
2. 语气是服务和提醒，不用命令口吻。
3. 对上材料用数据和事例说话，事例只来自用户提供的记录。
