# gongwen 公文写作总入口

gongwen-skills 的总入口。说不清要写什么、第一次用、不知道该找哪个 skill 时，先找它。它帮你判断这份材料该怎么写、要走哪几步，再把你交给对应的 skill。在网页大模型（DeepSeek、豆包、Kimi 等）里使用时，它就是默认入口。

它自己不起草、不改稿：法定公文交 gongwen-draft，总结汇报交 gongwen-report，讲话交 gongwen-speech，纪要交 gongwen-minutes，信息交 gongwen-brief，其余见下文“与其他 skill 的分工”。

## 能做什么

1. **判断任务**：从你的话里判断单位类型、写作角色、文书类型、行文方向，判断不出、又影响路线的，最多问 3 个问题，放在回复末尾，不耽误下一步。
2. **规划路线**：告诉你要走哪几个 skill、按什么顺序。比如年终总结一般是成稿、去防御腔、去 AI 味、核稿、排版几步。路线首站要写法定公文的，顺带给一句文种初判（如“不相隶属，请求批准用函”），并写明《党政机关公文处理工作条例》的条款。
3. **交接**：能直接调用其他 skill 的工具里，按路线逐个调用；目标 skill 没装，或在网页版里，同时给你交接卡、“新开对话粘贴哪个提示词文件”的说明和安装命令，下一步拿来就能用。
4. **建简版单位画像**：第一次使用时，用 3 个字段（单位类型、写作角色和默认模式、常写文书）建档，以后不必每次说明。完整画像、学本单位文风、按领导改稿归纳偏好，交 gongwen-profile。
5. **写作日历**：你没有具体需求，或问“最近要写什么”时，按当前月份和单位类型，提示最近一般要写的材料，最多 3 条，每条注明该找哪个 skill。
6. **回答“你能做什么”**：按分组介绍 17 个核心 skill 和 5 个行业包，以及不做的事。

## 可以这样说

- “我刚到医院院办，第一次用，帮我看看能做什么。”
- “下周市里来督查，要准备哪些材料？”
- “领导让我写个东西，我也说不清是啥。”
- “这个月一般要写哪些材料？我在乡镇。”
- “提示说没装讲话那个 skill，现在怎么办？”

## 输入和输出

**输入**：一句话需求即可。要交给下一站的材料（工作记录、数据、会议记录、上级文件原文等），请先删去涉密内容和个人敏感信息。

**输出**：
- 一行判断（单位｜模式｜文书类型和方向｜路线），以及下一步做什么。
- 交接卡：只写任务信息，不抄录你的原始材料；你给的字数或时长、“下周三”这类时间、加引号的本单位提法，原样写进去。
- 在 Claude Code、Codex 等能写文件的工具里：画像写入 `.gongwen/单位画像.md`，不覆盖已有文件；文稿由下一站 skill 写入 `公文/<日期>-<标题>/`。
- 在网页版里：输出画像文本请你保存；需要换到其他 skill 时，给你交接卡，并告诉你复制哪个提示词文件（`dist/prompts/<skill名>.md`）。

## 与其他 skill 的分工

| 需求 | 交给 |
|---|---|
| 通知、请示、就一件事的报告、函、批复、通报、意见、签报；单纯问“用请示还是函” | gongwen-draft |

| 讲话、致辞、主持词、表态和交流发言 | gongwen-speech |
| 会议记录、纪要、上会议题材料、督办清单 | gongwen-minutes |
| 政务信息、简报、新闻稿、公众号推文 | gongwen-brief |
| 对照检查、党建工作报告、党课、心得体会 | gongwen-party |
| 上级文件落实、整改材料、数据和图表 | gongwen-implement、gongwen-rectify、gongwen-data |
| 标题提纲、改稿润色、去 AI 腔、去防御腔、核稿、排版 | gongwen-title、gongwen-polish、gongwen-humanize、gongwen-direct、gongwen-review、gongwen-format |
| 完整画像、文风学习、禁用词 | gongwen-profile |
| 乡镇街道社区、医院、高校、中小学、国企的专用文书 | 装有行业包的交 gongwen-grassroots、gongwen-hospital、gongwen-university、gongwen-k12、gongwen-soe；没装的由对应核心 skill 按单位画像处理 |

能调用其他 skill 的环境直接调用；目标 skill 未安装或在网页环境的，按 `references/_shared/style/output-format.md` 第四部分转交：给交接卡、“新开对话粘贴 dist/prompts/<skill>.md 继续”的说明和安装命令。

## 注意事项

- 请勿输入涉密信息和内部敏感信息。材料涉密的，请使用单位内网部署的模型。
- 判断和交接卡里的事实只来自你说的话和你的画像，推断出来的会标“（推断）”，请核对。
- 对照检查材料、个人述职等需要本人经历的材料，没有本人事例时，下一站只出提纲和填写指引。
- 不承诺“检测不出 AI”，不协助规避发文管理。
- 单位画像可能含内部信息，不要提交到公开仓库。

```text
gongwen/

│   ├── quick-ref.md         # 提示词版速查表
│   └── _shared/             # 共享资料（自动同步，勿手改）
├── scripts/                 # 机检脚本（自动同步，勿手改；本 skill 只用来定改稿路线）

```

修改 `routes.md`、`skill-map.md` 时，同步检查 `quick-ref.md` 中对应的精简内容；新增或调整 skill 分工时，以 `docs/下一轮工作计划.md` 第七节边界总表为准。
