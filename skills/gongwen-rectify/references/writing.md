# 进展报告、情况报告和自查报告的写法

三类材料共用三条规矩：先更新台账再动笔；统计句和每条状态都从台账来；逐条写到某个问题时用"问题N"指称，便于对账。

## 一、整改进展报告

用途：集中整改期间按月或按阶段向巡视巡察机构、纪检监察机关、组织部门或审计机关报进展。

```text
标题：关于某某巡察反馈意见整改进展情况的报告（2026年10月）

开头：一句话交代报告期，接统计句。
一、本期主要进展：只写本期状态有变化、有新进展的条目，按编号排。
二、尚未完成的问题：持续推进、未启动的逐条列出，每条写已做了什么、还差什么、预计完成时间、遇到的困难。
三、下一步安排：对着第二部分的问题写，一条对一条。

附件：整改台账（截至2026年10月31日）
```

1. 篇幅一般1000～2000字。上月已完成、本月无变化的条目不重复写。
2. 超过完成时限仍未完成的，如实写"已超期"、原因和调整后的完成时间，不回避。
3. 需要上级协调的事项单独写一段，写明请谁协调什么。
4. 状态有变化的条目，起草说明"修改说明"中列出原状态、新状态和依据。

## 二、整改情况报告

用途：集中整改期结束或审计整改期限届满时，报告整改落实的整体情况。

```text
标题：中共某某委员会关于某某巡察反馈意见整改落实情况的报告
      某某公司关于某某审计发现问题整改情况的报告

开头：反馈时间、问题总数，接统计句。
一、整改工作开展情况：领导小组、专题会议、民主生活会、对账销号等，一段写完。
二、反馈问题整改落实情况：按台账编号逐条写（见第四部分）。
三、长效机制建设：新建、修订的制度，写制度名称和文号。
四、尚未完成的问题和下一步打算：持续推进、长期坚持的逐条写计划。
```

1. 第一部分只写做了什么，用户给的会议次数、文件数照写，没给的不写数字；篇幅控制在全文六分之一以内。
2. 第二部分是主体。问题多的按反馈意见的分类分组（如"（一）落实全面从严治党方面"），组内按编号排。
3. 篇幅：问题不超过10个的，一般3000字以内；问题多的，逐条压缩到两三句，详情放附件台账。
4. 结尾停在下一步安排上。报送用的请示、函由 gongwen-draft 处理。
5. 报送对象按反馈要求写。巡视的集中整改进展情况报告，报开展巡视的党组织的同级纪检监察机关、组织部门和巡视工作领导小组办公室（巡视工作条例第三十四条第（六）项）。用户没说的，主送写【待补：主送机关】。

## 三、自查报告

用途：上级专项检查、督查发来检查清单（自查表、评分细则）后，逐项自查并报告。没有检查清单、只是回顾一段时间工作的，属于工作总结，交 gongwen-report。

```text
开头：依据哪个通知、自查时间范围和组织方式（用户提供的）。
一、自查基本情况：检查清单共几项，符合几项，存在问题几项。
二、逐项自查情况：按清单顺序，每项写检查内容、自查情况、结论（符合、不符合、不适用）。
三、发现的问题和原因
四、整改措施：问题进入整改台账，编号写"自-1""自-2"。

附件：自查表
```

1. 清单每一项都要有对应，不漏项、不并项。清单项多的，正文写不符合的项，全部项放附件自查表。
2. 结论只凭用户提供的自查记录。某项没有记录的，结论写【待补：自查情况】，不写"符合"。
3. 自评分、扣分只写用户给的，不替用户打分。
4. 发现的问题要具体（哪个环节、多少件、什么时间）。用户确认没有问题的才写"未发现问题"，并写明查了什么。
   - 误：经全面自查，我单位严格落实各项要求，未发现问题。（用户只给了两项的自查记录）
   - 正：清单共15项，已提供自查记录的2项符合要求；其余13项【待补：自查情况】。
5. 自查发现的问题，按 `references/ledger.md` 建台账，状态口径同样适用。

## 四、逐条写法

每个问题一段，顺序固定：问题（编号加原文或简称）、整改措施落实情况、成效（有佐证的事实）、状态句。状态句用台账口径，放在段末：

| 台账状态 | 段末状态句 |
|---|---|
| 已完成 | 该问题已完成整改。 |
| 立行立改 | 该问题已立行立改。 |
| 持续推进 | 该问题正在推进，预计2026年12月31日前完成。 |
| 长期坚持 | 该问题取得阶段性成效，需长期坚持。 |
| 未启动 | 该问题尚未启动，原因是……，计划于……启动。 |

- 误（台账为持续推进）：问题5：已修订《物资采购管理办法》，该问题已完成整改。
- 正：问题5：《物资采购管理办法》修订稿已于10月20日提交院长办公会审议，待审议通过后印发。该问题正在推进，预计11月30日前完成。

同一问题拆了子项的，按子项逐一写完成情况，最后写大项的状态句；有一个子项未完成，大项就是"正在推进"。

## 五、成效写法

1. 成效只写台账里有佐证的事实和数字：追回资金多少、清退多少、制度名称和文号、处理多少人、系统何时上线。
2. 用户没给数字的不写数字，结构上确需的标【待补】；不写"取得明显成效""群众满意度大幅提升"之类没有依据的评价。
   - 误：通过整改，耗材管理水平显著提升，群众满意度明显提高。
   - 正：10月完成全院高值耗材盘点，查明账实不符原因【待补：查明的项数】项，盘亏金额已由责任科室说明并按规定处理【待核实：处理结果和凭证】。
3. 金额写清口径：已追回、已归还原资金渠道、已调整账目、已完善手续，分别是多少（`references/status.md` 第四部分）。
4. 人员处理只写用户提供的类别和人数，如"给予诫勉谈话2人"；姓名按报送要求和用户意见处理，公开版本不写姓名。
5. 问题线索和信访件的办理只写件数和办结情况，不写举报人、被反映人和案情。

## 六、对外公开的版本

巡视工作条例第三十一条要求巡视进驻、反馈、整改等情况以适当方式公开。用户要公开版本时：

1. 以报送版为底稿，删去问题线索、信访件、人员处理的姓名和细节、内部财务数据、未公开的工作秘密。
2. 问题写类别和整改结果，不逐条照录涉及具体人员的原文。
3. 统计句保留，数字与报送版一致。
4. 在起草说明中列出删去的内容，请用户按本单位审批程序确认后再公开。
