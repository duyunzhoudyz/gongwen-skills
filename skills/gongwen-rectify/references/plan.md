# 整改方案写法

整改方案回答三件事：每个问题怎么改、谁负责、什么时候改完。正文写安排，逐条任务放在附件整改任务清单（即整改台账，见 `references/ledger.md`）。

## 一、结构

```text
标题：中共某某委员会关于落实某某巡察组反馈意见的整改方案
      某某医院关于某某审计发现问题的整改方案

开头一段（两三句）：何时收到哪个检查组的反馈、共几个问题，制定本方案。

一、整改目标
二、整改任务
三、工作安排
四、保障措施

附件：整改任务清单
```

1. 开头不写重要意义、形势背景，不写“深刻认识巡察整改的极端重要性”一类的表态（`references/_shared/rules/jianfu.md` JF-02）。
   - 误：巡察整改是一项严肃的政治任务，是检验“四个意识”的试金石……
   - 正：2026年8月18日，市委第六巡察组向公司党委反馈了巡察意见，指出4个方面9个问题。为抓好整改落实，制定本方案。
2. 整改目标一段写清：整改期限、要达到的结果（反馈问题逐条有措施、有责任人、有时限，按期完成并对账销号）。不写空泛的“取得明显成效”。
3. 整改任务按反馈意见自己的分类和顺序写，不另立分类。每条写：问题（照录原文或用“问题简称”加编号指称）、主要措施（一两句）、责任领导、责任部门、完成时限。详细措施和成效标准放附件。
4. 工作安排按时间写阶段，每段写起止日期和要做的事。日期来自用户或反馈要求，推算出来的写进起草说明“所作假设”。
5. 保障措施两三条，只写有主体、有动作的：领导小组（组长、副组长按用户提供的职务写）、定期调度、对账销号、整改不力的按规定问责。不写“高度重视”“加强领导”之类的空表态（JF-03）。小组组成、调度频次、销号程序、专题民主生活会只写用户给的；没说的标【待补：调度安排】或不写，不按常见做法补写；条例规定的流程只在起草说明“措施提示”中提示。
6. 篇幅：正文一般不超过4000字（部署专项工作，`references/_shared/rules/jianfu.md` 第三部分），附件另计。问题多的，正文只写主要措施，细节放附件。

## 二、问题照录与指称

1. 正文写到某个问题时，用“问题3：部分科室高值耗材领用登记不全，账实不符”或“问题3（高值耗材账实不符）”，编号与台账一致。
2. 照录原文的规则见 `references/ledger.md` 第三部分。方案中引用的问题表述必须与台账“问题表现”一致。
3. 反馈意见中的问题线索、信访件、涉及具体人员的内容，方案里只写“按规定处置巡察移交的问题线索【待补：件数】件”，不写人名和案情。

## 三、措施写法

1. 一条问题至少一条措施，措施对着问题和原因写。没有措施的标【待补：整改措施】，不编。
   - 误：强化责任意识，进一步加强制度建设，切实提升规范化水平。
   - 正：12月15日前修订《合同管理办法》，明确10万元以上合同须经法律顾问审核。（制度名称、金额标准来自用户）
2. 措施分三类，按需安排：立行立改的（检查期间已改完的，写成已完成的事实并附佐证）；限期整改的（写具体动作和日期）；长效机制的（建什么制度、什么机制）。
3. 措施用要求式措辞：“要”“于……前完成”，不用“建议”“可以考虑”“尽量”（`references/_shared/style/defensive.md` 第五部分）。
4. 不层层加码：不要求下级单位重复报送整改材料（`references/_shared/rules/jianfu.md` JF-09），不把整改任务以签责任状、制度上墙的方式转给乡镇（街道）、村（社区）（JF-12）。

## 四、原因分析

1. 原因只写用户提供或确认的。用户没提供的，台账和方案都标【待补：原因分析】。
2. 起草说明附“原因分析提示”，从主观上找原因，各问一句，由用户填写：
   - 制度：有没有制度，制度是否过时、有漏洞？
   - 执行：有制度为什么没执行，卡在哪个环节？
   - 监督：日常检查为什么没发现？
   - 能力和作风：经办人员是否清楚规定，责任是否压实？
3. 不把原因全推给客观条件（人手少、任务重、历史遗留），也不替用户写“思想认识不到位”一类的套话。

## 五、时限安排

| 整改来源 | 期限依据 | 方案写法 |
|---|---|---|
| 巡视 | 《中国共产党巡视工作条例》第三十四条：自收到反馈意见之日起集中整改6个月 | 集中整改期写到具体日期；之后转入常态化整改 |
| 巡察 | 条例第五十条：参照巡视规定，结合实际确定 | 按巡察机构的要求；没有要求的，参照6个月并写进“所作假设” |
| 审计 | 审计报告或审计决定写明的期限（《审计法》第五十二条：按照规定时间整改） | 照录审计文书的期限，用户没提供的标【待补】 |
| 督查、考核、专项检查 | 反馈通知的要求 | 照录通知期限 |

按日期倒排：先定集中整改期的截止日，再排各项措施的时限；时限晚于截止日的，起草说明中提示，属于长期坚持的除外。

## 六、发文主体

1. 巡视巡察整改方案以被巡视巡察的党组织名义印发（党委、党组、党工委、党总支），用党委发文代字。
2. 审计、督查整改方案以被检查单位名义印发，用行政代字。
3. 医院、高校、国企有党委和行政两套代字，按整改来源选用；校级、部门两级发文的，按反馈对象确定。见 `references/units.md`。
4. 方案通过什么程序审定（党委会、院长办公会、校长办公会、总经理办公会），按用户说明写；印发方案用的通知由 gongwen-draft 起草。

## 七、示例片段

材料（虚构）：县委巡察组反馈“部分村集体资产台账更新不及时，2026年上半年有4个村新增资产未登记入账”；用户说“已经让四个村补登了，以后每季度末盘点一次，农经站盯”。

方案正文：

（二）集体资产管理方面

问题4：部分村集体资产台账更新不及时，2026年上半年有4个村新增资产未登记入账。已督促4个村补登新增资产【待核实：是否已全部补登，补登日期】；今后每季度末组织一次资产盘点，农经站逐季检查。责任领导：【待补：分管领导职务】；责任部门：农经站；完成时限：补登于【待补：日期】前完成，按季盘点长期坚持。

用户只说“已经让四个村补登了”，没说已补登完毕，所以写“已督促”并标【待核实】，台账先记“持续推进”，拿到补登记录后再按 `references/status.md` 重新判定。
