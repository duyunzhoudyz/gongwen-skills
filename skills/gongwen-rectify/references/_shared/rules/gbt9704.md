## 一、适用范围与术语

1. 适用于各级党政机关制发的公文；其他机关和单位的公文可以参照执行（第 1 章）。医院、学校、国企参照执行，以本单位公文处理办法为准。
2. “字”：横向长度单位，一字为一个汉字的宽度（3.1）。“空二字”即空两个汉字宽。
3. “行”：纵向长度单位，一行为一个汉字的高度加 3 号汉字高度的 7/8（3.2）。“下空二行”按此计算。
4. 版心内要素分三部分（7.1）：
   - 版头：首页红色分隔线以上；
   - 主体：首页红色分隔线（不含）以下、末页首条分隔线（不含）以上；
   - 版记：末页首条分隔线以下、末条分隔线以上。
   - 页码在版心之外。

## 三、版头（7.2）

1. 份号（7.2.1）：需要标注时，顶格编排在版心左上角第一行。
2. 密级和保密期限（7.2.2）：顶格编排在版心左上角第二行；保密期限中的数字用阿拉伯数字。
3. 紧急程度（7.2.3）：顶格编排在版心左上角；三者同时出现时，自上而下依次为份号、密级和保密期限、紧急程度。
4. 发文机关标志（7.2.4）：全称或规范化简称加“文件”，或只用全称、规范化简称；居中；联合行文时主办机关名称在前，“文件”二字置于名称右侧并上下居中。
5. 发文字号（7.2.5）：
   - 位置：发文机关标志下空二行，居中；上行文居左空一字，与最后一个签发人姓名同一行。
   - 年份、顺序号用阿拉伯数字；年份标全称，用六角括号“〔〕”括入。
   - 顺序号不加“第”字，不编虚位（1 不编为 01），数字后加“号”。
   - 写法：某发〔2026〕5号。
6. 签发人（7.2.6）：“签发人”加全角冒号加姓名，居右空一字，在发文机关标志下空二行；多个签发人按机关顺序从左到右、自上而下排，一般每行两个姓名。
7. 版头分隔线（7.2.7）：见参数总表。

## 四、主体（7.3）

1. 标题（7.3.1）：红色分隔线下空二行，居中，可分一行或多行；回行时词意完整、排列对称、长短适宜，使用梯形或菱形排列。
2. 主送机关（7.3.2）：标题下空一行，居左顶格，回行仍顶格；最后一个机关名称后标全角冒号。名称过多致首页不能显示正文时，移至版记（见 7.4.2）。
3. 正文（7.3.3）：首页必须出现正文；编排于主送机关下一行。层次序数见第八部分。
4. 附件说明（7.3.4）：
   - 正文下空一行、左空二字编“附件”，后标全角冒号和附件名称。
   - 多个附件用阿拉伯数字标顺序号，如“附件：1. ××××”；回行时与上一行附件名称首字对齐。
   - 附件名称后不加标点符号。
5. 署名、成文日期和印章（7.3.5）：

| 情形 | 要点 | 条款 |
|---|---|---|
| 加盖印章 | 成文日期一般右空四字；印章红色，不得出现空白印章；单一机关行文时署名以成文日期为准居中，印章下压署名和日期，印章顶端距正文（或附件说明）一行之内 | 7.3.5.1 |
| 联合行文加盖印章 | 署名按机关顺序排列，印章一一对应下压署名；印章互不相交或相切，两端不超出版心 | 7.3.5.1 |
| 不加盖印章 | 正文（或附件说明）下空一行右空二字编署名；下一行编成文日期，首字比署名首字右移二字；日期较长时日期右空二字，署名相应左移 | 7.3.5.2 |
| 加盖签发人签名章 | 正文下空二行右空四字加盖签名章，签名章左空二字标签发人职务；签名章下空一行右空四字编成文日期；签名章一般红色 | 7.3.5.3 |
| 成文日期数字 | 阿拉伯数字，年月日标全，年份标全称，月日不编虚位 | 7.3.5.4 |
| 空间不足 | 可调整行距、字距 | 7.3.5.5 |

6. 附注（7.3.6）：居左空二字，加圆括号，编排在成文日期下一行。
7. 附件（7.3.7）：
   - 另面编排，在版记之前，与正文一起装订。
   - “附件”二字及顺序号用 3 号黑体，顶格编排在版心左上角第一行；附件标题居中编排在版心第三行。
   - 附件顺序号和标题与附件说明一致；格式要求同正文。
   - 不能与正文一起装订的，在附件左上角第一行顶格编发文字号，其后标“附件”及顺序号。

## 五、版记（7.4）

1. 分隔线（7.4.1）：与版心等宽；首条在版记第一个要素之上，末条与最后一面版心下边缘重合。
2. 抄送机关（7.4.2）：在印发机关和印发日期之上一行，左右各空一字；“抄送”后加全角冒号和机关名称，回行与冒号后首字对齐，最后一个机关名称后标句号。主送机关移至版记时，把“抄送”改为“主送”，置于抄送之上一行，二者之间不加分隔线。
3. 印发机关和印发日期（7.4.3）：编排在末条分隔线之上，印发机关左空一字，印发日期右空一字；日期用阿拉伯数字标全，月日不编虚位，后加“印发”。版记有其他要素时，用一条细分隔线与印发机关和印发日期隔开。

## 六、页码、表格及其他（7.5、8、9）

1. 页码（7.5）：编排在版心下边缘之下；单页码居右空一字，双页码居左空一字。版记页前有空白页的，空白页和版记页均不编页码。附件与正文一起装订时，页码连续编排。
2. 横排表格（8）：页码位置与其他页一致；单页码页表头在订口一边，双页码页表头在切口一边。
3. 计量单位、标点、数字（9）：分别符合 GB 3100、GB 3101、GB 3102，GB/T 15834，GB/T 15835。

## 七、特定格式（10）

| 格式 | 要点 | 条款 |
|---|---|---|
| 信函格式 | 发文机关标志用全称或规范化简称，上边缘距上页边 30 mm，推荐红色小标宋；联合行文用主办机关标志 | 10.1 |
| | 标志下 4 mm 印红色双线（上粗下细），距下页边 20 mm 印红色双线（上细下粗），线长均 170 mm | 10.1 |
| | 份号、密级、紧急程度顶格居版心左边缘，排在第一条双线下；发文字号顶格居版心右边缘，排在第一条双线下 | 10.1 |
| | 标题居中，与其上最后一个要素相距二行；首页不显示页码；版记不加印发机关、印发日期和分隔线，位于最后一面版心内最下方 | 10.1 |
| 命令（令）格式 | 发文机关标志为全称加“命令”或“令”，上边缘距版心上边缘 20 mm，推荐红色小标宋 | 10.2 |
| | 标志下空二行居中编令号，令号下空二行编正文；签发人职务、签名章和成文日期按 7.3.5.3 | 10.2 |
| 纪要格式 | 标志为“××××纪要”，上边缘距版心上边缘 35 mm，推荐红色小标宋 | 10.3 |
| | 出席人员：正文或附件说明下空一行左空二字编“出席”（3 号黑体）加全角冒号，冒号后用 3 号仿宋标单位和姓名，回行与冒号后首字对齐 | 10.3 |
| | 请假、列席人员另起一行，把“出席”改为“请假”“列席”，编法相同；纪要格式可以根据实际制定 | 10.3 |

## 八、层次序数及字体

| 层级 | 序数 | 字体（7.3.3） | 序数后标点（GB/T 15834） | 说明 |
|---|---|---|---|---|
| 第一层 | 一、 | 黑体 | 顿号（4.5.3.3、B.3.2） | 字号同正文，一般 3 号 |
| 第二层 | （一） | 楷体 | 不加点号（B.3.4） | |
| 第三层 | 1. | 仿宋 | 下脚点（B.3.3） | 部分单位要求加粗，按本单位规定 |
| 第四层 | （1） | 仿宋 | 不加点号（B.3.4） | |

1. 标准用语为“依次可以用”“一般”，属推荐做法；本项目输出默认采用（见 `references/_shared/style/output-format.md`）。
2. 标准未说明字体只用于序数还是整个标题行。实务中整个标题行用对应字体。
3. 序数用全角括号“（）”；“1.”的点用半角下脚点。

## 九、Word/WPS 实现说明

本部分均为实践值或推算，不是标准原文。排版后应打印一页实测核对。

| 项目 | 设置 | 性质 |
|---|---|---|
| 页边距 | 上 3.7 cm，下 3.5 cm，左 2.8 cm，右 2.6 cm | 由 5.1、5.2.1 推算 |
| 文档网格 | “页面设置→文档网格”选“指定行和字符网格”，每行 28 字、每页 22 行 | 实践值 |
| 网格设置顺序 | 先把“正文”样式设为仿宋_GB2312 三号，再设网格；否则字符跨度按旧字号计算 | 实践经验 |
| 固定行距 | 常用“固定值 28.9 磅”（实践值，非标准原文）。推算：版心高 225 mm≈637.8 磅，÷22≈29.0 磅；取 28.9 磅可保证 22 行放得下 | 实践值 |
| 字符间距 | 版心宽 156 mm≈442.2 磅，÷28≈15.8 磅，略小于三号字宽 16 磅；不用网格时需把字符间距紧缩约 0.2 磅 | 推算 |
| 字号磅值 | 二号 22 磅，三号 16 磅，四号 14 磅 | Word 字号对照 |
| 页码 | 页脚插入页码域，两侧加一字线“—”（U+2014），4 号宋体；奇偶页不同，奇数页居右空一字，偶数页居左空一字 | 实践做法 |
| 页码位置 | 一字线上沿距版心下边缘 7 mm，即距纸张下边缘约 28 mm；在 Word 中通过“页脚距边界”调整后打印核对 | 推算 |

字体名称与缺字体处理（字体严格模式）：

| 用途 | 标准用字体 | 字体名称 | 缺字体时 |
|---|---|---|---|
| 正文、第三四层 | 仿宋 | 仿宋_GB2312 | 不得替代，须安装该字体 |
| 第二层、签发人姓名 | 楷体 | 楷体_GB2312 | 不得替代，须安装该字体 |
| 第一层、密级、紧急程度、附件标识 | 黑体 | 黑体 | 不得替代，须安装该字体 |
| 标题、发文机关标志 | 小标宋 | 方正小标宋简体 | 不得替代，须安装该字体 |
| 页码 | 宋体 | 宋体 | 不得替代，须安装该字体 |

1. 缺字体时不得改用其他字体顶替（仿宋、楷体、华文中宋、宋体加粗等都不是标准字体），须指出缺哪些字体，引导用户自行下载安装后再核对。获取与安装方法见 gongwen-format（`python scripts/gw_fonts.py` 或其手动设置清单第十五部分）。
2. 仿宋_GB2312、楷体_GB2312 只含 GB 2312 字符集（6763 个汉字），人名、地名中的生僻字可能缺字，显示为其他字体。这是字符集范围问题，不是整体缺字体，处理办法：仅该字单独改用“仿宋”等大字符集字体，打印核对。
3. 方正小标宋简体为商业字体，需单位自行取得授权。本项目不提供、不打包任何字体文件（见开发规范第 10 节）。
4. 部分地区或单位规定使用方正仿宋_GBK 等字体，以本单位规定为准。
5. 用 python-docx 生成时，中文字体要同时设置 `w:eastAsia` 属性，否则中文可能回退到默认字体。
6. 工具不生成印章图像，不模拟红头印章。

## 十、可机检规则

编号只在本文件内使用，`lint_rules.json` 的 ID 由脚本作者另定。级别为建议值。“落款区”指正文最后若干行。

1. **G9-01 发文字号年份用六角括号**（7.2.5，P0）
   - 正：`某发〔2026〕5号`　反：`某发[2026]5号`、`某发（2026）5号`、`某发【2026】5号`、`某发﹝2026﹞5号`
   - 思路：`[一-鿿]{1,12}[\[［(（【﹝{｛]\s*(19|20)\d{2}\s*[\]］)）】﹞}｝]\s*第?\s*\d+\s*号`。﹝﹞是小写变体，视觉相近但不是“〔〕”（U+3014、U+3015）。
2. **G9-02 发文字号年份标全称**（7.2.5，P0）
   - 正：`〔2026〕`　反：`〔26〕`
   - 思路：`〔\d{2}〕`
3. **G9-03 顺序号不加“第”**（7.2.5，P0）
   - 正：`某发〔2026〕5号`　反：`某发〔2026〕第5号`
   - 思路：`〔\d{4}〕\s*第\s*\d+\s*号`。令号（如“第5号”）不带六角括号，不会误中。
4. **G9-04 顺序号不编虚位**（7.2.5，P0）
   - 正：`〔2026〕5号`　反：`〔2026〕05号`、`〔2026〕005号`
   - 思路：`〔\d{4}〕\s*0\d*\s*号`
5. **G9-05 日期月日不编虚位**（7.3.5.4、7.4.3）
   - 正：`2026年1月5日`　反：`2026年01月05日`
   - 思路：`\d{4}年0[1-9]月|月0[1-9]日`。落款区和印发日期为 P0，正文其他位置为 P1。
6. **G9-06 成文日期用阿拉伯数字**（7.3.5.4，P1）
   - 正：`2026年10月16日`　反：`二〇二六年十月十六日`（出现在落款区时）
   - 思路：落款区匹配 `[〇○零一二三四五六七八九]{4}年[一二三四五六七八九十]{1,2}月[一二三四五六七八九十]{1,3}日`
7. **G9-07 主送机关后用全角冒号**（7.3.2，P1）
   - 正：`各区卫生健康局：`　反：`各区卫生健康局:`、`各区卫生健康局`（后接正文）
   - 思路：标题后第一个非空行，长度不超过 80 字且不含句号时，检查是否以“：”结尾；以半角“:”结尾直接报。
8. **G9-08 附件说明格式**（7.3.4，P1）
   - 正：`附件：1. 某某工作方案`　反：`附件:1.某某工作方案`、`附件：某某工作方案。`
   - 思路：`^附件:` 报半角冒号；`^附件：.*[。；，、]$` 报附件名称后有标点；多附件时检查顺序号连续。
9. **G9-09 抄送格式**（7.4.2，P1）
   - 正：`抄送：市委办公室，市政府办公室。`　反：`抄送:市委办公室`、`抄送：市委办公室，市政府办公室`（末尾无句号）
   - 思路：`^抄送:` 报半角冒号；`^抄送：.*[^。]$` 报末尾缺句号。出现“抄报”的给 P2 提示：条例和标准只有“抄送”。
10. **G9-10 签发人格式**（7.2.6，P1）
    - 正：`签发人：张某`　反：`签发人:张某`
    - 思路：`^签发人:`
11. **G9-11 印发日期格式**（7.4.3，P1）
    - 正：`2026年10月16日印发`　反：`2026年10月16日发`、`2026.10.16印发`
    - 思路：版记末行匹配 `\d{4}年\d{1,2}月\d{1,2}日印发$`，不匹配时报。
12. **G9-12 页码格式**（7.5，P1，仅 docx 页脚）
    - 正：`—1—` 或 `— 1 —`　反：`-1-`、`—01—`、`第1页`、`1/5`
    - 思路：页脚文本匹配 `^—\s?[1-9]\d*\s?—$`，不匹配时报。标准未规定一字线与数字之间是否加空格。
13. **G9-13 层次序数写法**（7.3.3，P1）
    - 正：`一、`、`（一）`、`1.`、`（1）`　反：`1、`、`（一）、`、`一.`、`(1)`
    - 思路：`^\d+、`；`^（[一二三四五六七八九十]+）[、，.．]`；`^[一二三四五六七八九十]+[.．，]`；`^\(\d+\)`（半角括号）。
14. **G9-14 层次序数不回升、不跳级**（7.3.3，P2，函数实现）
    - 反：`一、`之后直接出现`1.`，跳过`（一）`。
    - 思路：按行首序数建层级栈，检查层级只逐级下降、同级序号连续。
15. **G9-15 附注加圆括号**（7.3.6，P2）
    - 正：`（此件公开发布）`　反：`此件公开发布`（位于成文日期下一行）
    - 思路：成文日期下一行以“此件”开头且未被“（）”包住时提示。
16. **G9-16 首页显示正文**（7.3.3，P2，仅 docx）
    - 思路：首页内容只有版头、标题和主送机关时提示。
