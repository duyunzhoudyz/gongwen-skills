## 一、用途

审核评估是对普通本科高校本科教育教学的周期性评估，每5年一个周期，2021—2025年一轮按《普通高等学校本科教育教学审核评估实施方案（2021—2025年）》（教督〔2021〕1号）实施；2026年起的新一轮以教育部当轮方案为准。程序依次为评估申请、学校自评、专家评审（线上评估、入校评估）、反馈结论、限期整改、督导复查。《自评报告》在学校自评阶段形成并公示，是专家线上评估的主要材料。

本模板用于三种稿件：
1. 学校版《自评报告》（评估办统稿）；
2. 职能部门承担的指标章节（如教务处写"培养过程"）；
3. 学院（教学单位）版自评报告（校内迎评要求，结构参照学校版）。

不适用：评估结论反馈后的《整改方案》《整改报告》交 gongwen-rectify；迎评动员讲话交 gongwen-speech。高职院校不参加本科审核评估，按其主管部门当年文件写，本模板只作写法参考。

## 二、评估类型与报告结构

类型由学校党政领导班子集体研究确定（"两类四种"），用户没说明的，先问"选的是第一类还是第二类第几种"。

| 类型 | 适用学校 | 一级指标（自评结果部分的章） |
|---|---|---|
| 第一类 | 以建设世界一流大学为目标的高校 | 党的领导；质量保障能力；教育教学水平；教育教学综合改革（学校"自画像"，留白） |
| 第二类第1种 | 已参加上轮评估、以学术型人才培养为主 | 办学方向与本科地位；培养过程；教学资源与利用；教师队伍；学生发展；质量保障；教学成效（下设达成度、适应度、保障度、有效度、满意度，即"五个度"）；另加学校自选特色 |
| 第二类第2种 | 已参加上轮评估、以应用型人才培养为主 | 同上 |
| 第二类第3种 | 通过合格评估5年以上、首次参加审核评估的地方应用型高校 | 同上，二级指标有差异 |

二级指标和审核重点以用户提供的指标体系、撰写说明或学校分解给学院的指标为准；材料已按二级指标分块的，照材料分块。都没有的只按一级指标搭框架，二级标题标【待核实：请对照本校采用的指标体系】，不凭记忆补写二级指标、审核重点和定量指标的底线值。

学校版的常见结构（多所高校转发的撰写说明一致，字数以本校通知为准）：

```text
第一部分　学校简介（约2000字以内）
第二部分　学校自评工作开展情况（约2000字以内）
第三部分　学校自评结果
　1.一级指标
　　1.1二级指标
　　　1.1.1审核重点（举措、成效、问题）
　　　支撑材料目录
　　1.x存在的问题、主要原因及下一步改进措施
附件1　学校自评问题清单
附件2　支撑材料目录
附件3　数据不一致情况说明
```

学院版：学院简介（约500字以内）、自评工作开展情况、自评结果（按学校分解给学院的指标逐条写），以本校评估办模板为准。

## 三、写法

1. 每个审核重点按"举措→成效→问题"三段写。举措写做了什么（制度、项目、投入）；成效写可核验的结果，带时段和来源；问题写这一重点上还差什么。
2. 成效写数据，数据后标注统计时段。来源于状态数据的写"（2025学年，状态数据）"之类的标注，或按本校要求在支撑材料目录中对应。
3. 支撑材料按本校规定编号，在正文相关处标注，如"[1.2-03]"；正文提到的制度文件、典型案例都要在支撑材料目录中能找到。用户没提供编号规则的，按"一级指标.二级指标-序号"编，写进起草说明"所作假设"。
4. "存在的问题、主要原因及下一步改进措施"每个一级指标单独一节。按"问题表现→产生根源→改进措施（含时限、责任单位）"写。多所高校的撰写说明要求问题、原因和改进措施不少于自评结果部分的三分之一，以本校通知为准；用户没提供问题素材的，标【待补】并在起草说明列启发提问，不自编问题。
5. 指标体系中的"重点阐述"提示语是写作提纲，不要照抄进正文。
6. 学院版的数据取学校分解下发的口径；学院自统数据与学校口径不一致的，列入口径冲突表，不在正文里选一个顺手的数。
7. 语言：写实、简洁，用陈述句，少用"全面""显著""有力"一类评价词；评价交给数据。
8. 参加过上轮评估的，"自评工作开展情况"写清上轮整改问题的落实情况（用户提供上轮问题清单时逐条对应）。

## 四、数据项与口径

| 类别 | 常见指标 | 来源与口径 |
|---|---|---|
| 规模结构 | 本科专业数、全日制在校生数、专任教师数、生师比 | 状态数据、高基报表，按统计时点；生师比、折合在校生数按教育部统计口径由学校统计部门提供，不自行折算 |
| 经费条件 | 生均年教学日常运行支出、教学日常运行支出占比、生均教学科研仪器设备值 | 状态数据；第二类指标体系中部分为必选定量指标，有无底线值、底线是多少，以本省、本校采用的指标体系文本为准，不凭记忆写数值 |
| 思政队伍 | 思政课专任教师与折合在校生比、专职党务和思政工作人员与师生比 | 第二类必选定量指标（如不低于1∶350、1∶100），以指标体系文本为准 |
| 教学过程 | 教授（副教授）为本科生授课比例、实践教学学分占比、一流课程数 | 状态数据、教务系统 |
| 学生发展 | 毕业率、学位授予率、毕业去向落实率、学科竞赛获奖 | 状态数据、就业部门口径 |
| 质量保障 | 评教覆盖、督导听课次数、质量报告发布 | 评估中心（质量办）台账 |

1. 定量指标数据由教育部评估中心依据状态数据提供的（多所高校的第二类撰写说明如此写明），正文引用时与《本科教学状态数据分析报告》一致；因采集时点不同造成不一致的，写进"数据不一致情况说明"。
2. 用户只给了概数（"300多门"）的，台账状态记"待核实"，正文写【待核实：准确数及统计时点】。
3. 比较写法："由2021学年的1∶18.6降至2025学年的1∶17.9"，两个时点都要有；只有一个时点的，不写"降低""提升"。
4. 百分比之间的变化用"百分点"（见 `references/_shared/rules/gbt15835.md` 和 `references/_shared/rules/data-expression.md`）。

## 五、常见毛病与正误对照

1. 写成成绩汇报，问题只有一句。
   - 误：学校本科教育教学取得显著成效，但仍存在一些不足，今后将进一步改进。
   - 正：问题一：实践教学基地使用不均衡。近三年签约基地86个，实际接收学生实习的41个【待核实：统计口径】。主要原因是……。改进措施：2027年6月前完成基地分类评估，由教务处牵头。
2. 问题写成变相表扬。
   - 误：教师投入教学精力过多，科研时间不足。
   - 正：45岁以下教师中主讲本科核心课程的比例为【待补：比例】，青年教师教学能力培训覆盖不全。
3. 举措堆制度名称，没有运行结果。
   - 误：出台《本科教学质量监控办法》等12项制度，构建了全方位质量保障体系。
   - 正：2024年修订《本科教学质量监控办法》，全年督导听课【待补：次数】次，反馈问题【待补：条数】条，已整改【待补：条数】条。
4. 照抄指标"重点阐述"原文当正文。删掉提示语，换成本校事实。
5. 学院数据与学校数据打架：学院写"专任教师126人"，学校状态数据为118人。列入口径冲突表，请人事处确认统计范围（是否含外聘、双肩挑）。
6. 堆砌荣誉、头衔，不写对本科教学的作用。荣誉只写与本科教学直接相关的，并写明对人才培养的支撑。

## 六、只出框架的情形

1. 用户只说"帮我写自评报告"，没有任何学校或学院的材料：交付按所选类型的章节框架、每节需要的数据清单和支撑材料清单，不生成正文。
2. 有举措材料、没有数据：举措照写，成效处标【待补：指标名及统计时段】，起草说明列"数据需求清单"（指标、来源部门、口径），请评估办向职能部门收集。
3. 问题部分没有素材：正文标【待补：本指标存在的问题】，起草说明给3个启发提问，如"上轮评估指出的问题哪些还没解决""哪项必选定量指标接近底线""学生评教、毕业生调查反映最集中的意见是什么"。

## 七、出处

1. 教育部《普通高等学校本科教育教学审核评估实施方案（2021—2025年）》，教督〔2021〕1号，2021年1月印发（中国政府网2021年2月7日发布）：评估周期、"两类四种"、程序、自评报告公示、问题清单、整改期限。
2. 第一类一级指标名称及"五个度"：北京交通大学审核评估网站发布的第一类《自评报告》撰写模板（2023年），据《普通高等学校本科教育教学审核评估（2021-2025）工作指南》编写。
3. 第二类"教学成效"下的5个二级指标（"五个度"）：据省级转发的《普通高等学校本科教育教学审核评估指标体系（试行）》核对（2026年10月）。
4. 第二类一级指标、字数建议（总字数4万字以内）、问题部分不少于三分之一、定量指标由评估中心提供、数据与《本科教学状态数据分析报告》一致、附件三项、必选定量指标示例：西昌学院发布的第二类第2种《自评报告》撰写指导书（2025年），引述上述《工作指南》。
5. 各校撰写说明中的字数、编号规则是校内要求，以本校评估办当年通知为准。
