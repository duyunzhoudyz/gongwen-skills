## 一、用途与分工

高校实行校级和部门两级公文。本模板解决两件事：
1. 一件事该以学校（学校党委）名义发，还是以部门、学院名义发，用什么文种，走什么程序；
2. 学院、部门向校领导请示，用校内请示（签报、请示报告单）怎么写。

分工：本包做发文主体判断，起草校内签报。判断结果是部门公文（如教务处通知）、校级正式公文（以学校或学校党委名义的通知、请示、报告、函等）或对校外行文的，起草交 gongwen-draft：Agent 环境直接调用；网页环境输出交接卡，把发文主体、文种、程序的判断结论写进“已确认”一栏。会议纪要交 gongwen-minutes。

各校代字、版头、签报格式不同，用户提供了本校公文处理办法或签报制度的，以本校规定为准（四层覆盖第一层）。

## 二、两级发文判断

| 事项 | 发文主体 | 程序和文种 |
|---|---|---|
| 全校性规章制度、重要部署、涉及全校的重大事项 | 学校或学校党委（党的建设、思想政治、干部工作用党委名义；教学、科研、行政用学校名义；两方面都涉及的党政联合） | 一般经党委常委会、校长办公会审议或校领导同意，校领导签发；交 gongwen-draft |
| 职能部门职权内的常规业务（如学期考试安排、项目申报校内通知） | 部门 | 部门负责人签发；部门公文，起草交 gongwen-draft |
| 涉及多个部门职权、部门之间未协商一致的事项 | 不得行文 | 先协商或报校领导协调，必要时以学校名义发 |
| 学院、部门请求学校批准、请校领导决策 | 学院、部门 | 校内请示（签报），经党政办公室审核后呈送 |
| 对校外（上级教育部门、地方政府、企业、其他高校）正式行文 | 学校 | 向上级请示、报告；对不相隶属单位用函；部门一般不以本部门名义对校外正式行文；交 gongwen-draft |
| 学术事务（学科、专业设置、学术评价） | 按学校章程，先经学术委员会审议 | 审议后再按上面各行确定 |
| 涉及教职工切身利益的方案（福利、校内分配、聘任考核奖惩办法） | 学校 | 按《学校教职工代表大会规定》第七条由教代会讨论通过后发布 |

判断步骤：
1. 先看事项属于谁的职权：一个部门职权内、跨部门、全校。
2. 再看写给谁：校内单位、校领导、校外。
3. 最后查程序：是否需要学术委员会、教代会、党委常委会或校长办公会审议。用户材料没写审议情况的，不写“经……研究同意”，在起草说明中提示补充程序。

## 三、校内请示（签报、请示报告单）

适用：学院、部门向校领导请求批准事项、请示决策。部门职责范围内能自行决定的事项不报签报。

结构：

```text
关于某学院改造本科教学实验室的请示
某副校长：（主送一位分管校领导，称谓按本校格式）
（缘由）说明为什么要办，一两段，写事实和数据。
（事项）请求批准什么：项目内容、经费数额、来源、时间。
（方案）有两个以上方案的，比较后写明倾向性意见和理由。
（会签）涉及其他部门的，写明已会签的部门和意见；未会签的先会签。
妥否，请批示。
某学院（部门负责人签名）
2026年10月16日
（联系人、电话：按本校请示报告单的栏目填写）
```

规则：
1. 一事一报。两件事拆成两份。
2. 一般只报一位校领导（分管校领导）；需要几位校领导批示的，只报一份，由党政办公室协调，不同时分送，不直接送领导个人。
3. 经费请示写清金额、来源（学院自有经费、学校专项、横向结余等，按用户材料）和预算科目；材料没写来源的标【待补：经费来源】。
4. 有倾向性意见：用户材料只摆问题不给方案的，请用户补出方案；用户没给的，标【待补：本单位建议方案】，不自编。
5. 学院向学校请示不用正式请示文件格式（发文字号、版头），按本校请示报告单或签报格式；学院不越过学校直接向上级教育部门请示。
6. 结尾用“妥否，请批示。”或“以上请示，请予审批。”，不用“供领导参考”。

## 四、部门公文（判断后交 gongwen-draft）

部门公文的起草交 gongwen-draft。本包先查下面几条，把结论写进交接卡或调用说明：
1. 是否在本部门职权内：涉及其他部门职责的，确认已协商一致，正文写“会同某部门”；未协商一致的不行文。
2. 是否超出职权：不以部门名义向学院、部门提出超出职权的考核、问责要求；需要全校执行的，改以学校名义发。
3. 版头和代字：按本校规定（部门版头或白头），用户提供了本校公文处理办法的写进交接卡。
4. 面向学生的通知不公开学号、成绩、资助、处分等个人信息；公示名单只公开本校规定的事项。
5. 不用“白头”“便笺”规避学校发文管理（`references/_shared/guardrails.md` 第六条第3款）。

## 五、常见毛病与正误对照

1. 一份签报主送多位校领导。
   - 误：主送：校长、分管教学副校长、分管财务副校长
   - 正：主送分管教学的副校长一位，由党政办公室按程序协调其他校领导阅批。
2. 签报夹带多件事：“关于实验室改造及增设研究生招生方向的请示”。拆成两份。
3. 只摆问题不给方案。
   - 误：实验室设备老化，影响教学，请学校研究解决。
   - 正：拟分两期更新设备，一期更换32台套，需经费【待补：金额】万元，由学院自有经费承担一半，申请学校专项支持一半。妥否，请批示。
4. 职能部门以部门名义给地方政府发函。改以学校名义，交 gongwen-draft。
5. 未经教代会讨论的校内分配方案写“经教代会审议通过”。按材料实写程序，缺的提示补程序。

## 六、出处

1. 两级公文、部门行文边界、校内请示程序、对外行文：`references/_shared/profiles/units/gaoxiao.md` 第二部分。
2. 签报的结构和规则：`references/_shared/rules/doc-types.md` 第三部分（湖南大学《请示报告事项签报制度》等）。
3. 行文规则：《党政机关公文处理工作条例》第十四条（不越级）、第十五条（请示一文一事、主送一个上级）、第十六条第（四）项（未协商一致不得向下行文）、第十七条第三款（内设机构除办公厅（室）外不得对外正式行文），高校参照执行（条例第四十条），见 `references/_shared/rules/tiaoli.md` 第五部分。
4. 教代会讨论通过的事项：《学校教职工代表大会规定》（教育部令第32号，2012年1月1日起施行）第七条第（四）项。
5. 学校党委审议确定基本管理制度：《中国共产党普通高等学校基层组织工作条例》（2021年修订）第十条第（三）项。
