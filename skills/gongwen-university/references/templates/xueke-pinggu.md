## 一、用途

学科评估由教育部学位与研究生教育发展中心（学位中心）按一级学科组织。第五轮于2020年11月启动，以"立德树人成效"为根本标准，定量与定性评价相结合；下一轮的指标、篇幅和填报方式以学位中心当轮工作方案和填报系统为准。

本模板帮学科秘书、学院和研究生院（学科办）整理需要文字表述的部分：学科简介、简况表中的文字栏目、社会服务典型案例。数据栏目（论文、项目、获奖、人才名单）只做口径核对，不代填数字。

学位授权审核申请、学位授权点合格评估中的"简况表""自我评估报告"，结构以当年通知模板为准，写法可参照本模板第三至六部分。

## 二、材料构成

第五轮指标体系框架有四个一级指标，需要文字表述的部分如下（各项填报的个数、人数，如代表性学生、骨干教师、标志性成果、重大仪器设备、典型案例的数量，以当轮工作方案和填报说明为准，本包不列具体数字）：

| 一级指标 | 需要文字表述的内容（第五轮） |
|---|---|
| 人才培养质量 | 思想政治教育特色与成效；课程建设与教学改革的主要做法；在校生代表性成果；代表性毕业生职业发展情况 |
| 师资队伍与资源 | 师德师风建设机制与成效；代表性骨干教师；重大仪器设备对人才培养、科研和社会服务的支撑作用 |
| 科学研究水平 | 标志性学术成果，每项简述原创性、前沿性、突破性内容和学术贡献，附代表性论文支撑 |
| 社会服务与学科声誉 | 社会服务总体情况和典型案例；《学科简介》（供国内声誉调查专家参考） |

篇幅和个数以填报系统为准。用户没提供限制的，在起草说明中提示"字数、个数以当轮填报系统为准"，不自定上限。

## 三、学科简介

第五轮要求《学科简介》描述本学科基本情况、学科方向与优势特色、人才培养目标、生源情况、国内外影响。按这五项组织：

```text
一、基本情况（建设历史一两句，学位点层次，师生规模，统计时点）
二、学科方向与优势特色（3至5个方向，每个写清研究对象、代表性成果、特色所在）
三、人才培养目标
四、生源情况（报考、录取、生源结构，写数据和时段）
五、国内外影响（学术组织任职、重要会议、标准制定、成果应用，写事实不写评价）
```

写法：
1. 优势特色用事实说明：哪个方向、什么成果、被谁采用。
   - 误：本学科特色鲜明、优势突出，在国内具有重要影响。
   - 正：水资源方向主持制定行业标准2项【待核实：标准编号】，成果在3个省份的灌区推广应用。
2. 不写排名、"国内领先""国际一流"之类的自我评价；用户提供了第三方评价原文的，注明出处后可以引用。
3. 学科方向名称与简况表、代表性教师所属方向一致。

## 四、简况表文字栏目

| 栏目 | 写法 |
|---|---|
| 思想政治教育特色与成效 | 第五轮重点看"三全育人"综合改革，突出课程思政、社会实践、意识形态阵地管理、基层党组织建设、思政队伍建设的特色做法和成效。每项写做法、覆盖面、可核验结果；政治性表述只用用户提供的原文，叠加严谨模式 |
| 课程建设与教学改革 | 写改了什么（课程体系、教学方式、质量督导）、怎么改、改后结果 |
| 标志性学术成果简述 | 一项成果一段：解决了什么科学问题，创新点，学术贡献；只用用户提供的成果和评价，不加"填补空白""国际领先"等未提供依据的定性 |
| 重大仪器设备支撑作用 | 设备名称和价值来自资产台账；写支撑了哪些课程、课题、服务项目，带数据 |
| 代表性毕业生 | 只写本人同意公开的信息；职务、业绩以用户提供为准 |

## 五、社会服务典型案例

第五轮对社会服务总体情况和典型案例综合评价，强调突破性贡献；哲学社会科学学科更强调文化传承创新与智库作用，自然科学学科更强调科技成果转化应用与解决关键核心技术问题。部分自然科学学科有"涉密案例"，按保密规定在专门渠道填报，本包不处理（见 `references/redlines.md` 第一条）。

案例结构：

```text
案例名称：动作加对象加结果，如"研发盐碱地改良技术，支撑某省20万亩耕地提质"
一、服务需求（服务对象面临的问题，一两句）
二、主要做法（团队、技术或成果、合作方式、起止时间）
三、贡献与成效（可核验的数据：采纳、应用、转化金额、效益；注明证明材料）
四、示范意义（一两句，写可推广的做法，不写口号）
证明材料清单：采纳证明、应用证明、合同、批示件等
```

写法：
1. 成效只写有证明材料的。用户说"效益很大"但没有证明的，写【待补：效益数据及证明材料】。
2. 时间在评估规定的统计期内，用户没说统计期的，标【待核实：是否在统计期内】。
3. 成果按署名单位认定、不随人走：引进人才在原单位取得的成果不写进本学科案例。用户材料中出现"某教授调入前主持完成"的，提醒删除。
4. 领导批示、采纳情况只写用户提供的原文要点，不改写批示内容，不推测批示级别。
   - 误：研究报告得到省领导高度肯定，为全省决策提供了重要参考。
   - 正：研究报告获【待核实：批示人职务】批示（批示件见证明材料3），相关建议被纳入《某省……方案》【待核实：文件名称及文号】。
5. 多个案例覆盖不同方向和服务类型，避免同一团队、同一项目拆成多个案例。

## 六、数据规则与常见毛病

1. 数据栏目以学校科研、人事、研究生管理系统为准，按评估要求的统计期和署名单位口径；学院自统数与研究生院汇总数不一致的，列入口径冲突表。
2. 论文"录用"不等于"发表"，项目"立项"不等于"结题"，获奖"公示"不等于"授奖"，按用户材料中的实际状态写。
3. 第五轮对弄虚作假的处理：被认定造假并剔除的数据不得重新填报或调整到其他学科，并视情节通报。材料中有疑似拔高、挪用的，起草说明中提示。
4. 常见毛病：用堆砌荣誉代替贡献描述；案例写成工作总结（只有做法没有成效）；成效没有证明材料；学科方向名称前后不一；照搬往年或兄弟学科材料（用户提供往年材料的，有 Python 时用 `scripts/overlap_check.py` 查重合段落）。

## 七、出处

1. 教育部学位与研究生教育发展中心《第五轮学科评估指标体系框架》说明（2020年11月，各校转发的附件1）：四个一级指标、思政教育、在校生代表性成果、代表性骨干教师、标志性成果、重大仪器设备、社会服务典型案例和涉密案例、《学科简介》五项内容。各项填报数量本包未能联网复核，以当轮填报说明为准。
2. 教育部有关负责人就第五轮学科评估答记者问（2020年11月，澎湃新闻等转载）：教师成果按署名单位认定、不随人走；引进人才在原单位取得的成果不在新单位统计；造假数据剔除后不得再报。
3. 第六轮学科评估截至2026年10月未查到学位中心正式工作方案，届时以当轮方案为准。
