# 高校术语表

只收本包文书常用、容易写错的术语。解释用于理解和核对用法，写进正文的政治性表述仍以用户提供的原文为准。简版画像中已有的术语（党委领导下的校长负责制、立德树人、三全育人、双一流、高基报表、教代会、课程思政、意识形态工作责任制、校院两级管理）见 `references/_shared/profiles/units/gaoxiao.md` 第五部分。

## 一、评估类

| 术语 | 解释 | 出处 |
|---|---|---|
| 审核评估 | 普通本科高校本科教育教学审核评估，每5年一个周期 | 教督〔2021〕1号（2021—2025年） |
| 两类四种 | 第一类面向以建设世界一流大学为目标的高校；第二类分三种：学术型、应用型、首次参评的地方应用型高校 | 同上 |
| 合格评估 | 面向新建本科院校的本科教学工作评估；原则上获"通过"结论5年后参加审核评估 | 同上 |
| 自评报告 | 学校自评阶段形成并公示的报告，是专家线上评估的主要材料 | 同上 |
| 问题清单 | 专家组综合线上评估和入校评估提出的问题清单；学校自评也形成自评问题清单 | 同上；各校撰写说明 |
| 整改方案、整改报告 | 评估结论反馈后30日内提交整改方案，原则上两年内完成整改并提交整改报告 | 同上（整改材料交 gongwen-rectify） |
| 状态数据 | 本科教学基本状态数据，经高等教育质量监测国家数据平台采集，生成《本科教学状态数据分析报告》 | 各校审核评估撰写说明 |
| 五个度 | 培养目标的达成度、社会需求的适应度、师资和条件的保障度、质量保障运行的有效度、学生和用人单位的满意度 | 第一类"质保效果"、第二类"教学成效"的指标 |
| 必选定量指标 | 第二类指标体系中规定底线值的定量指标，如思政课专任教师与折合在校生比 | 第二类指标体系，以本省、本校采用的文本为准 |
| 学科评估 | 按一级学科对学科整体水平的评估，由学位中心组织；第五轮2020年启动 | 学位中心第五轮工作方案（2020年11月） |
| 代表作评价 | 第五轮科研评价凝练标志性成果、以代表性论文支撑，不以引用等计量指标为主要依据 | 第五轮指标体系框架说明 |

## 二、教学与人才培养类

| 术语 | 解释 | 出处 |
|---|---|---|
| 以本为本 | 坚持本科教育在人才培养中的核心地位，是审核评估"本科地位"的审核重点 | 第二类指标"本科地位" |
| 四个回归 | 回归常识（学生刻苦读书学习）、回归本分（教师潜心教书育人）、回归初心（高等学校倾心培养社会主义建设者和接班人）、回归梦想（高等教育倾力实现教育报国、教育强国梦）；审核评估"本科地位"看推进四个回归的举措与成效 | 新时代全国高等学校本科教育工作会议（2018年6月）；第二类指标"本科地位"。写进正文的表述以用户提供的原文为准 |
| 一流课程、一流专业 | 国家级和省级一流本科课程、一流本科专业建设点 | 以教育部、省教育厅公布名单为准 |
| 本科教学质量报告 | 本科高校按年度发布的教学质量报告 | 时间按省级教育部门当年通知 |
| 毕业去向落实率 | 就业统计指标，按届统计 | 以学校就业部门当年上报口径为准 |
| 教授为本科生授课比例 | 教授（副教授）主讲本科课程的比例 | 状态数据口径 |

## 三、科研与学科类

| 术语 | 解释 | 出处 |
|---|---|---|
| 纵向项目、横向项目 | 纵向指政府部门、基金委等立项的项目；横向指企事业单位委托的项目 | 高校科研管理通行分类，以本校科研管理办法为准 |
| 到账经费、合同经费 | 到账指实际到校的经费；合同指合同或任务书约定的总额 | 同上 |
| 活页 | 国家社科基金年度项目《课题论证活页》，用于匿名通讯初评 | 2026年国家社科基金年度项目申报公告 |
| 限项 | 申报和在研项目数量的限制规定 | 当年申报公告、项目指南 |
| 包干制、预算制 | 国家自然科学基金的两种资金管理方式；2026年青年科学基金项目（A、B、C类）实行包干制 | 国科金发计〔2026〕2号 |
| 署名单位认定 | 成果按署名单位统计，不随人走 | 第五轮学科评估答记者问 |

## 四、学生工作类

| 术语 | 解释 | 出处 |
|---|---|---|
| 辅导员九项职责 | 思想理论教育和价值引领、党团和班级建设、学风建设、学生日常事务管理、心理健康教育与咨询工作、网络思想政治教育、校园危机事件应对、职业规划与就业创业指导、理论和实践研究 | 教育部令第43号第五条 |
| 专职辅导员配备 | 按总体上师生比不低于1∶200设置专职辅导员岗位 | 教育部令第43号第六条 |
| 谈心谈话 | 辅导员与学生的个别谈话；记录由辅导员本人填写 | 各校学生工作制度 |
| 学业预警 | 对学分、成绩未达要求学生的提示和帮扶 | 以本校学籍管理规定为准 |
| 家庭经济困难学生认定 | 资助工作的认定程序和等级，属个人敏感信息 | 以本校资助工作文件为准 |

## 五、管理与程序类

| 术语 | 解释 | 出处 |
|---|---|---|
| 党政联席会议 | 院系讨论和决定本单位重要事项的会议 | 《中国共产党普通高等学校基层组织工作条例》第十一条 |
| 学术委员会 | 学校最高学术机构，学术事务先经其审议 | 《高等学校学术委员会规程》 |
| 两委工作报告 | 党代会上的党委工作报告和纪委工作报告 | 以学校党委召开大会的通知和议程为准 |
| 签报、请示报告单 | 学院、部门向校领导请示事项的内部上行文 | 各校签报制度，见 `references/_shared/rules/doc-types.md` 第三部分 |
| 部门公文 | 职能部门在职权内向校内单位发的公文，部门负责人签发 | 各校公文处理办法 |
