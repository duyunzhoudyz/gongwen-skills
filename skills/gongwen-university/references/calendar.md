# 高校写作日历

按月份提示本包文书的常见节点。具体日期以当年上级通知和学校安排为准；本表中的具体日期只列已核实的2026年数据，其他年份不套用。通用节点（开学、毕业典礼讲话、工作要点等）见 `references/_shared/profiles/units/gaoxiao.md` 第七部分，相应文书交核心 skill。

| 时间 | 本包相关文书 | 说明 |
|---|---|---|
| 1月 | 学院年度工作总结（收尾）、辅导员学期工作写实 | 学校年度考核多在12月至次年1月 |
| 2—3月 | 国家自然科学基金申报书形式审查 | 2026年集中接收期为3月1日至3月20日16时（国科金发计〔2026〕2号），依托单位校内截止时间更早 |
| 3—4月 | 教代会学校工作报告提纲 | 教代会每学年至少召开一次，时间以学校安排为准 |
| 5—6月 | 国家社会科学基金年度项目申报书和活页形式审查 | 2026年申报系统5月29日零时至6月7日17时开放，单位线上审核6月15日17时前完成 |
| 6—7月 | 辅导员毕业生离校谈话提纲；学院学期总结 | 以学校安排为准 |
| 9月 | 新生入学谈心谈话提纲 | 迎新后集中开展，以本校学生工作要求为准 |
| 10—11月 | 本科教学质量报告（交 gongwen-report，数据按 `references/data-caliber.md` 对齐状态数据口径） | 按省级教育部门当年通知 |
| 12月 | 学院年度工作总结、辅导员年度工作写实 | 以学校年度考核通知为准 |
| 按周期 | 审核评估自评报告 | 每5年一个周期；2021—2025年一轮按教督〔2021〕1号，新一轮以教育部方案为准；评估前一年多开始自评 |
| 按周期 | 学科评估材料 | 第五轮2020年启动；下一轮以学位中心工作方案为准 |
| 按周期 | 党代会报告提纲 | 高校党委每届任期5年 |
| 随时 | 校内请示（签报）；发文主体判断（部门公文起草交 gongwen-draft） | 按需 |

使用规则：
1. 用户问"最近要准备什么"的，按当月给2至3项，注明"以当年通知为准"。
2. 不报未核实的具体截止日期；本表没有的项目（教育部人文社科项目、省级项目等）提示用户以当年申报通知为准。
