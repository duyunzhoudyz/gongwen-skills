# 高校数据口径与素材台账

自评报告、学科评估材料、学院总结共用。核心规则：学校材料的数据以权威来源为准，学院材料的数据与学校口径一致，比不齐的列表请人确认，不悄悄选一个。

## 一、权威来源

| 数据 | 权威来源 | 注意 |
|---|---|---|
| 本科教学基本状态数据 | 高等教育质量监测国家数据平台，及其生成的《本科教学状态数据分析报告》 | 审核评估自评报告的数据与之一致；采集时点不同造成差异的，写进"数据不一致情况说明" |
| 学生数、教职工数等事业统计 | 高等教育事业基层统计报表（高基报表） | 按统计时点（学年初）；学校各类材料的规模数据以此为基准 |
| 科研项目、经费、成果 | 学校科研管理系统、科研处核定数 | 经费分到账额和合同额；项目分立项、在研、结题 |
| 学科评估数据 | 评估规定的统计期内、按署名单位认定的数据 | 引进人才在原单位的成果不计入 |
| 就业数据 | 学校就业部门核定数、就业质量年度报告 | 指标名称和统计时点以当年上报口径为准 |
| 人事数据 | 人事处 | 专任教师、教职工、外聘、双肩挑分开统计 |
| 经费、资产 | 财务处、资产处 | 按会计年度（自然年） |

## 二、常见口径冲突

| 冲突 | 例 | 处理 |
|---|---|---|
| 学年与自然年 | 学院按2026年统计招生，学校按2026级 | 按材料用途统一为一种，正文注明时段 |
| 届与年 | "2026年就业率"与"2026届毕业去向落实率" | 就业用"届" |
| 到账与合同 | 科研经费"1500万元"是合同额，到账1086万元 | 分开写，注明口径 |
| 状态升级 | 论文录用写成发表，项目公示写成获批 | 按实际状态写 |
| 统计范围 | 专任教师含不含外聘、双肩挑 | 请人事处确认，列入口径冲突表 |
| 人与人次 | 竞赛参与"860人"与"860人次" | 分开，不相加 |
| 校院重复 | 两个学院都报了同一项联合成果 | 学校材料只计一次，注明牵头单位 |
| 时点不同 | 学院9月统计，状态数据按学年初时点 | 以状态数据为准，差异写说明 |

## 三、素材台账（简版）

1. 把用户材料拆成一条一条，列为：序号｜类别｜内容｜来源｜状态。类别只用：工作事项、数据、案例、问题、下步打算。
2. 来源写到文件名和段落，或"用户消息""单位画像""状态数据分析报告第X页"。
3. 状态只有"已确认""待核实"两种：带"约""多""左右"的，没有口径或时段的，几份材料说法不一的，都记"待核实"。
4. 由台账数据算出的增幅、占比另起一行，来源写"由第3、5条计算"，算式写进内容。比率之间的变化写"百分点"。
5. 台账同样脱敏，不出现学生姓名、学号。

冲突放在起草说明末尾，标题"附：口径冲突表"：

|---|---|---|---|---|---|
| 1 | 专任教师数 | 学院自报126人；状态数据118人 | 统计范围不一致 | 正文用状态数据，标【待核实】 | 人事处 |

## 五、对账

1. 成稿后把正文中每个统计数逐个回查台账，找不到的补出处或改为【待补】。
2. 有 Python 环境时运行 `python scripts/fact_diff.py 素材台账.md 正文.txt --ledger`，输出的"正文中有、台账中没有"清单逐条处理。
3. 学院材料与学校口径对账：用户提供了学校下发的数据表的，把它也登记进台账（来源写"学校口径"），再运行上面的对账。

出处：状态数据一致性和"数据不一致情况说明"见 `references/templates/shenhe-pinggu.md` 第七部分；学科评估署名单位规则见 `references/templates/xueke-pinggu.md` 第七部分；台账方法与 gongwen-report 一致。
