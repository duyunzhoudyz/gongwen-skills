# 高校材料核稿附加清单

本包第五步自检时逐项过一遍；用户把本包产出交 gongwen-review 全面核稿时，把本清单作为单位专项检查项附上。级别：P0 必改，P1 建议改，P2 提示。

## 一、所有高校材料

| 检查项 | 级别 |
|---|---|
| 正文没有学号、身份证号、手机号、成绩排名、心理状况、资助认定、处分详情，没有学生真实姓名 | P0 |
| 没有密级或“内部资料”标识的材料内容被摘录 | P0 |
| 每个统计数都能在素材台账找到，注明了统计时段（学年、自然年、届） | 缺出处 P0，缺时段 P1 |
| 数据与学校口径（状态数据、高基报表、职能部门核定数）一致；冲突已列表 | 不一致 P1 |
| 成果状态没有升级（录用、公示、立项、合同额照实写） | P0 |
| 政治性提法有出处；没有原文的已标【待核实】并列入提法核对清单 | P1 |
| 没有写未经程序的“经审议通过”“经研究同意” | P1 |
| 校内机构名称前后一致 | P2 |

## 二、审核评估自评报告

| 检查项 | 级别 |
|---|---|
| 章节与所选评估类型（第一类或第二类第几种）的一级、二级指标一致 | P1 |
| 每个一级指标都有“存在的问题、主要原因及下一步改进措施” | P1 |
| 问题部分篇幅符合本校撰写说明（多所高校要求不少于自评结果三分之一） | P2 |
| 问题按“表现、原因、措施”写，措施有时限和责任单位 | P1 |
| 没有照抄指标“重点阐述”提示语 | P1 |
| 正文提到的制度、案例都能在支撑材料目录中找到，编号对应 | P1 |
| 定量数据与《本科教学状态数据分析报告》一致，差异已写说明 | P1 |

## 三、学科评估材料

| 检查项 | 级别 |
|---|---|
| 案例成效都有证明材料；没有的已标【待补】 | P0 |
| 成果按署名单位认定，没有引进人才在原单位的成果 | P0 |
| 案例在统计期内 | P1 |
| 没有“国际领先”“填补空白”等无依据定性 | P1 |
| 学科方向名称在简介、简况表、代表性教师中一致 | P1 |
| 涉密内容未进入本材料 | P0 |

## 四、申报书形式审查

按 `references/templates/shenbao-xingshi.md` 第三至五部分。另查：
| 检查项 | 级别 |
|---|---|
| 审查意见中没有照抄申请人姓名、单位、号码 | P0 |
| 本包没有改写申报书的学术内容 | P0 |
| 依据写到当年通知条目；没有依据的没有定为P0 | P1 |

## 五、学院年度工作总结

| 检查项 | 级别 |
|---|---|
| 对照了学校下达的目标任务；未完成的如实写 | P1 |
| 没有把学校成绩、个人荣誉写成学院成效 | P1 |
| 问题具体，打算与问题对应 | P1 |
| 与上年总结没有大段雷同（有往年稿时） | P2 |

## 六、辅导员材料

| 检查项 | 级别 |
|---|---|
| 没有生成谈心谈话记录、听课记录；整理本人笔记的没有添加笔记以外的内容 | P0 |
| 提纲问题为开放式，没有诱导和评判 | P1 |
| 心理关注类只写倾听和转介程序，没有诊断和治疗建议 | P0 |
| 写实中的事例都来自用户记录 | P0 |

## 七、两级公文与校内请示

| 检查项 | 级别 |
|---|---|
| 发文主体与事项职权相符；部门没有对校外正式行文 | P0 |
| 签报一事一报，只主送一位校领导 | P1 |
| 请示有具体请求事项和倾向性意见；经费写明金额和来源 | P1 |
| 涉及其他部门的已写明会签情况 | P1 |
| 结尾用“妥否，请批示。”一类请示惯用语 | P1 |

## 八、教代会和党代会报告提纲

| 检查项 | 级别 |
|---|---|
| 回顾与上一年度工作要点（或上届大会任务）逐项对应 | P1 |
| 指导思想、提法全部有原文出处，没有的已标【待核实】 | P0 |
| 任期或学年起止时点前后一致 | P1 |
| 没有预写表决结果 | P1 |
| 附了数据需求、提法核对、程序事项三张清单 | P2 |
