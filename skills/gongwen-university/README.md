# 行业包·高校（gongwen-university）

> 版本 1.0.0　成熟度：Beta（测试版）

帮高校的办公室、评估办、科研处、学院和辅导员写本行业专用的材料：审核评估自评报告、学科评估材料、申报书形式审查、学院年度总结、辅导员材料、发文判断和校内签报、教代会和党代会报告提纲。数据只用你给的，并与学校口径对齐；缺的标【待补】，存疑的标【待核实】；须本人亲笔的记录只给提纲。

学校总结、讲话、纪要、通知这类通用文书，请用核心插件 gongwen 中对应的 skill，它们会读取高校画像：本科教学质量报告、就业质量报告用 gongwen-report，部门通知和学校公文用 gongwen-draft，写好的稿子全面核稿用 gongwen-review。本包需要先安装 gongwen。

## 能做什么

| 文书 | 说明 |
|---|---|
| 审核评估自评报告 | 学校版、学院版、职能部门承担的章节。按所选评估类型（第一类、第二类第几种）搭章节，每个审核重点写举措、成效、问题，单列问题和改进措施；数据与状态数据对齐，冲突列表请你确认 |
| 学科评估材料 | 学科简介、简况表中的文字栏目（思政教育、标志性成果简述等）、社会服务典型案例。成效只写有证明材料的，成果按署名单位认定 |
| 申报书形式审查 | 国家社科基金、国家自然科学基金等申报书和活页的形式审查：资格、限项、匿名、字数、名称一致、签章附件。只审不写 |
| 学院年度工作总结 | 先对照学校下达的目标写完成情况，再按人才培养、学科、科研、师资、党建等板块写 |
| 辅导员材料 | 工作写实（只整理你的记录）、谈心谈话提纲和记录填写指引（不代写记录；谈话后发来本人笔记的，可以整理格式，不添加内容） |
| 发文判断与校内签报 | 判断一件事该以学校还是部门名义发、用什么文种、走什么程序；起草学院、部门给校领导的签报。部门通知和学校名义的公文转 gongwen-draft 起草 |
| 教代会、党代会报告提纲 | 提纲加数据需求、提法核对、程序事项三张清单；全文转 gongwen-report |

## 可以这样说

1. "明年迎审核评估，评估办让学院先写'培养过程'这一章，材料发你。"
2. "国社科活页写完了，帮我看看有没有暴露身份的地方，字数超没超。"
3. "学院年终总结要交学校考核，这是全年流水账，数据要和学校的对上。"
4. "我是辅导员，下周要和几个挂科的学生谈话，帮我列个提纲。"
5. "学院想改造实验室，要给分管副校长打个签报，帮我起草。"

## 输入

- 必需：你手头的材料。工作记录、数据表、学院自评素材、案例素材、申报书或活页都可以，不用先整理。
- 最好提供：学校评估办或科研处的撰写说明、当年申报通知、学校下达的年度目标、本校公文处理办法或签报制度。有这些，本包按它们执行；没有的，按本包资料执行，并在起草说明中写明"以当年通知为准"。
- 可选：单位画像 `.gongwen/单位画像.md`。没有画像也能用，最多问 3 个问题。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 纯文本正文，可直接粘进 Word 或交给 gongwen-format 排版 |
| `起草说明.md` | 所作假设、待补、待核实、保密提示；按需附口径冲突表、数据需求清单、提法核对清单 |
| `素材台账.md` | 每条事实的内容、来源和状态 |
| `提纲.md` | 提纲（大会报告提纲只交这一份和三张清单） |
| `形式审查意见.md` | 申报书形式审查的分级问题清单 |

在网页大模型里使用提示词版时，依次输出正文、起草说明和附表；需要转到下一个 skill 时，会给你一张交接卡。

## 注意事项

1. **保密**：请勿输入涉密信息和内部敏感信息；材料涉密的，请使用单位内网部署的模型。标有"内部资料"的评估反馈、巡视材料会停止处理；涉密科研项目不处理。学生姓名、学号、成绩、心理状况、资助认定、处分会提醒你脱敏，稿中改用"某同学"。
2. **不编造**：成果、获奖、人才称号、批示、满意度只用你提供的；论文录用不写成发表，合同额不写成到账。
3. **不代笔的几类材料**：谈心谈话记录、听课记录、思想汇报只给提纲和填写指引，谈话后提供本人笔记的只整理格式；项目申请书不写正文，只做形式审查、栏目结构说明和语言问题标注。这是本项目"辅助不代笔"的底线；国家自然科学基金另有明文，2026年通告一（二）8 规定不得使用由生成式人工智能直接生成的申请书。
4. **以当年文件为准**：评估、申报要求每年调整。本包核实了2026年国家社科基金和国家自然科学基金的要点、2021—2025年审核评估方案和第五轮学科评估框架，其他年份和项目请提供当年通知。
5. **提法**：党代会报告、思政相关材料的提法只用你提供的原文，没有的标【待核实】。
6. **机检**：有 Python 时会运行 `scripts/gongwen_lint.py`、`scripts/fact_diff.py` 和本包的 `scripts/proposal_check.py`（申报书匿名、字数、名称一致性检查，只在本机运行）；没有时按人工清单检查并注明。

## 成熟度

Beta。7 类专用文书的模板、红线、核稿附加清单和评测用例（20 条）已完成，申报书形式检查脚本带单元测试。已知局限：
- 各校的撰写说明、签报格式、代字差别大，本包给的是通用写法，请提供本校文件；
- 高职院校的评估和建设类材料只提供通用写法；
- 评估、申报的年度要点需要每年更新，欢迎测试者反馈当年的变化。
